# Задача Demo1: Сложи два числа

**Блок:** Demo
**Сложность:** easy
**Темы:** sum, numbers

## Условие

Напиши функцию `task_demo1_add(a, b)`, которая принимает два числа и возвращает их сумму.

## Аргументы

- `a` — целое число
- `b` — целое число

## Возвращает

Целое число — результат сложения `a + b`.

## Правила

- Сложи два числа и верни результат.
- Не используй сторонние библиотеки.

## Пример

```python
task_demo1_add(2, 3)
# -> 5
```

<details>
<summary>Эталонное решение</summary>

```python
def task_demo1_add(a, b):
    return a + b
```
