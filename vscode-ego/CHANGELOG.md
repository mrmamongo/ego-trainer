# Changelog

## Unreleased

- Челленджи по этапам (ADR-0018): программа из нескольких файлов, которая растёт по этапам.
  - «Cogito: Начать челлендж» создаёт папку `challenges/<id>/` со стартовыми файлами и `.cogito/challenge.json`; существующие файлы никогда не перезаписываются.
  - В списке задач у челленджа виден порядок этапов и их статусы, следующий непройденный этап подсвечен; открыть можно любой этап.
  - Панель этапа показывает условие, все этапы со статусами и кнопки «Проверить этап» и «Запустить».
  - «Cogito: Проверить этап» отправляет файлы проекта (по `include`, с лимитами `max_files`/`max_bytes`) и показывает результаты по этапам; если этап пройден, предлагается открыть следующий, а сломанные прошлые этапы называются явно.
  - «Cogito: Запустить программу» открывает терминал в папке проекта и запускает `main.py` (`uv run python`, локальный `.venv` или интерпретатор из новой настройки `ego.pythonPath`).
  - В панели результатов у каждого этапа свой заголовок.

## 0.2.5 — 2026-10-29

- Мягкие рекомендации курсов: плашка «сначала пройди…» у проекта, к которому стоит перейти после другого, без запрета открывать задачи.
- Разбор экзамена XL-A по типам задач в кабинете: сколько решено из «найди баг», «правки» и «новый код».
- Сюда же влиты исправления установки обновлений из 0.2.4.

## 0.2.4 — 2026-10-26

- Исправлена установка обновлений в новых версиях VS Code: путь `vscode-userdata:` преобразуется в локальный `file:`, который поддерживает установщик VSIX.
- Для перехода с версий 0.2.0–0.2.3 скачай [актуальный VSIX](https://cogito.born-in-july.ru/extension/download) и установи его через Extensions → ⋯ → Install from VSIX… один раз. После перезагрузки окна дальнейшие обновления можно устанавливать кнопкой «Обновить» в Cogito.

## 0.2.3 — 2026-10-26

- При ошибке обновления Cogito сохраняет причину отказа VS Code, в том числе строки и списки ошибок, вместо сообщения `undefined`.
- В журнале «Cogito: обновления» указываются версия и этап сбоя: скачивание, проверка файла, сохранение или установка.
