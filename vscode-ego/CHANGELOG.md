# Changelog

## 0.2.5 — 2026-10-29

- Мягкие рекомендации курсов: плашка «сначала пройди…» у проекта, к которому стоит перейти после другого, без запрета открывать задачи.
- Разбор экзамена XL-A по типам задач в кабинете: сколько решено из «найди баг», «правки» и «новый код».
- Сюда же влиты исправления установки обновлений из 0.2.4.

## 0.2.4 — 2026-10-26

- Исправлена установка обновлений в новых версиях VS Code: путь `vscode-userdata:` преобразуется в локальный `file:`, который поддерживает установщик VSIX.
- Для перехода с версий 0.2.0–0.2.3 скачай [актуальный VSIX](https://cogito.born-in-july.ru/extension/download) и установи его через Extensions → ⋯ → Install from VSIX… один раз. После перезагрузки окна дальнейшие обновления можно устанавливать кнопкой «Обновить» в Cogito.

## 0.2.3 — 2026-10-26

- При ошибке обновления Cogito сохраняет причину отказа VS Code, в том числе строки и списки ошибок, вместо сообщения `undefined`.
- В журнале «Cogito: обновления» указываются версия и этап сбоя: скачивание, проверка файла, сохранение или установка.
