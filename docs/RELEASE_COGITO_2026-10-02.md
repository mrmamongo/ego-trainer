# Cogito: объединённый релиз 2026-10-02

На `https://cogito.born-in-july.ru` опубликован образ
`ego-trainer:cogito-f60d259` из исходников `f60d259e965832784716cfc6f5627f675c54a3d3`.
В `master` объединены админка, настройки в БД, Forgejo, OAuth MCP,
студенческий AI с отдельной проверяющей моделью, бюджет и проверка понимания,
студенческая веб-панель и расширение VS Code.

## Возврат в редактор

Новое расширение возвращает пользователя через URI handler VS Code / Insiders.
`asExternalUri` добавляет привязку к окну. Сервер принимает только URI нашего
расширения с фиксированным путём и числовым `windowId`. JWT выдаётся отдельным
запросом после проверки PKCE verifier и одноразового ticket.
Подробности: [вход через Forgejo](FORGEJO_AUTH.md).

Сначала обновлён сервер. Пользователю нужно установить новый VSIX и начать
новый вход. Старые расширения продолжают работать через loopback callback.
Forgejo OAuth application и callback MCP `/mcp-callback` не менялись.

## Проверки

- Полная локальная Python регрессия: **533 passed, 9 skipped**.
- Расширение: **52 unit tests**, TypeScript, bundle, activation smoke и VSIX.
- Установленный пакет в контейнере: **186 passed, 1 skipped** по OAuth, AI,
  MCP, runtime, админке, прогрессу и серверной проверке задач.
- Все 40 серверных исходников и статических файлов в образе совпали с
  опубликованной рабочей копией по SHA-256.
- До переключения образ проверен на отдельной копии серверной БД/MCP storage.
- После переключения: Docker health, HTTPS, `/student`, Forgejo providers,
  OAuth discovery и MCP без токена; REST без JWT возвращает 401.
- Авторизованные чтения проверили каталог, настройки и AI access. Все 33 задачи,
  существующие аккаунты, роли, связи Forgejo и прогресс сохранены.
- Новый публичный native start принимает разрешённый VS Code URI и отклоняет
  произвольный HTTPS callback. Админка и студентская страница открылись в Chrome
  без JavaScript errors.

Реальное завершение входа в обновлённом VS Code требует пользовательского
браузера и нового установленного VSIX. Ответы настоящих AI-провайдеров ещё не
проверены: пользователь вносит конфигурации сам; AI сейчас выключен.
