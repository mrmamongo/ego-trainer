# Бриф: публичный лендинг и минимальная аналитика

Документ для агента, который будет делать лендинг. Всё ниже проверено по коду
ветки `claude/thematic-task-sets-bdd914` и по продакшену на 2026-10-24.

## 1. Задача

1. Публичная страница проекта: что это, кнопка «Скачать расширение для VS Code»,
   как установить, вход в кабинет студента.
2. Минимальная аналитика без сторонних сервисов: сколько заходят, скачивают,
   сколько живых установок расширения и сколько студентов занимается.
3. Всё под временным брендом: имя продукта меняется (домен `cogito.ru` занят,
   новое имя ещё не выбрано). Бренд должен меняться в одном месте.

## 2. Текущее состояние

**Продакшен.** `https://cogito.born-in-july.ru`, сервер `31.130.149.12`,
каталог `/opt/cogito`, контейнер `cogito-cogito-server-1` за Traefik
(`/opt/kad-arbitr/traefik/dynamic.yml`, общий с соседними сервисами).
Образы выкатываются надстройкой поверх текущего: `FROM <текущий образ>` и `COPY`
изменённых файлов в `/usr/local/lib/python3.11/site-packages/...`. Смотри
`docs/RELEASE_COGITO_VSTART_2026-10-21.md` и раздел 7.

**Маршруты** (`ego_server/main.py`):

| Путь | Что отдаёт | Доступ |
|---|---|---|
| `/` | `static/admin.html`, вход в панель наставника и администратора | публично (вход внутри) |
| `/student`, `/student/tasks/{id}` | `static/student.html` + `student.js`, кабинет студента в браузере | публично (вход внутри) |
| `/ide`, `/ide/task/{id}`, `/ide/room/{id}` | браузерная IDE | публично (вход внутри) |
| `/static/*` | статика, в т.ч. `static/branding/` (иконки, `cogito-mark.svg`) | публично |
| `/extension/latest`, `/extension/download` | метаданные и `.vsix` последней версии расширения | публично |
| `/auth/*`, `/tasks/*`, `/lessons/*`, `/progress/*`, `/check`, `/run`, `/ai/*`, `/admin/*` | REST API | JWT |
| `/health` | `{"status": "ok"}` | публично |
| `/mcp` и OAuth-маршруты MCP | MCP для наставников | OAuth |

**Шлюз (важно).** В Traefik есть правило `cogito-api` с проверкой JWT (ForwardAuth на
`/auth/me`) для путей: `/auth/me`, `/admin`, `/admin/*`, `/tasks*`, `/progress*`,
`/check*`, `/run`, `/ai*`. Всё остальное попадает в общее правило без проверки.
Следствия:
- новые публичные страницы (`/`, `/start` и т.п.) и `/extension/*` работают без правок шлюза;
- **HTML-страницу админки нельзя переносить на `/admin`**: шлюз потребует токен ещё до
  загрузки формы входа. Если лендинг занимает `/`, админку переносить на путь вне списка,
  например `/panel` или `/console`;
- `/lessons` сейчас не в защищённом списке (сервер сам требует токен). Добавление его
  в список — отдельная правка общего конфига Traefik, только по согласованию с владельцем.

**Расхождение статики (проверь первым делом).** На проде 2026-10-23 выкатили
тему админки (`auth-theme-20261023`: `admin.html`, `main.py` с `Cache-Control: no-store`),
её файлы есть только на сервере и незакоммиченными в основном чекауте
`C:\Work\ego-trainer` (там же `student.css`, `student-navigation.js`,
`student-task-page.js`, `student-tutor.js` — другой вариант кабинета студента).
В git ветки этого нет. Прежде чем менять `admin.html`/`student.html`, сравни их с тем,
что реально отдаёт прод, иначе откатишь чужую работу.

**Оформление кабинета студента** (`static/student.html`, светлая тема):
`--ink #172033`, `--muted #68738a`, `--line #e5e9f1`, `--paper #fff`, `--canvas #f4f6fb`,
`--accent #6558d9`, `--accent-dark #4c40ba`, `--mint #dff6ed`, `--green #167a55`,
`--amber #946200`, `--rose #b04454`; шрифт `Inter, ui-sans-serif, system-ui, …`
(без загрузки с CDN). Знак бренда — `static/branding/cogito-mark.svg`.
Админка — тёмная, shadcn-стиль с синими акцентами.

## 3. Лендинг: содержание

Аудитория: начинающий разработчик (джун) и его наставник. Тон дружелюбный, на «ты»,
без маркетинговых штампов. Русский язык.

Блоки:
1. **Первый экран.** Имя продукта (временный бренд), одна фраза о сути: курс Python
   с автопроверкой прямо в VS Code, от первой переменной до продуктовых задач.
   Кнопки: «Скачать расширение» (версия из `/extension/latest`) и «Войти в кабинет» (`/student`).
2. **Как это устроено** (3–4 карточки, факты из раздела 6):
   решаешь задачи в VS Code; проверка в песочнице за секунды; теория рядом с задачей;
   таблицы трассировки и сборка кода из строк; после решения короткая защита понимания.
3. **Что внутри курса.** Лестница папок (раздел 6) — от переменных до мини-проектов
   и продуктовых задач XL-A.
4. **Установка за 3 шага.** 1) скачать `.vsix`; 2) VS Code → Extensions → «…» →
   «Install from VSIX…» или `code --install-extension <файл>.vsix`; 3) в VS Code
   выполнить «<Бренд>: Войти» (вход через Forgejo). Дальше расширение обновляется само.
5. **Для наставника.** Панель (`/`, потом новый путь), MCP для работы с курсом из агента.
6. **Подвал.** Контакты/ссылка на Forgejo, версия расширения.

Требования: одна HTML-страница в `ego_server/static/` + маршрут в `main.py`,
без внешних скриптов, шрифтов и трекеров; адаптив до 360px; работает без JS
(кнопка скачивания ведёт на `/extension/download`, JS только подставляет версию);
`Cache-Control: no-store` как у остальных страниц; светлая тема в палитре кабинета.

## 4. Аналитика: минимальная и своя

Принципы: без cookies, без сторонних скриптов, без хранения IP и полного User-Agent,
только суточные агрегаты. Ботов отсекать грубо по User-Agent (`bot|crawl|spider|curl`).

Что считать:

| Метрика | Источник |
|---|---|
| Просмотры лендинга и кабинета по дням | счётчик при отдаче страницы |
| Скачивания `.vsix` по версиям и дням | счётчик в `GET /extension/download` |
| Живые установки и их версии | `GET /extension/latest`: расширение уже ходит туда раз в сутки (`vscode-ego/src/updateCheck.ts`); добавить заголовок `X-Cogito-Extension-Version` (имя заголовка — под новый бренд) и считать по дням и версиям |
| Активные студенты за день / неделю | уже есть: таблица `runs` (`student_id`, `created_at`) |
| Решённые задачи по дням | уже есть: `progress` (`status = 'passed'`, `last_run_at`) |
| Новые регистрации | уже есть: `students.created_at` |

Хранение: новая таблица, например
`analytics_daily(day TEXT, metric TEXT, key TEXT, count INTEGER, PRIMARY KEY(day, metric, key))`,
upsert `count = count + 1`. Миграция только аддитивная, по образцу `ego_server/db.py`
(там уже есть `_migrate_add_lessons_table`).

Показ: `GET /admin/analytics?days=30` (роли admin/mentor, через существующий
`require_role`) и блок в обзоре админки (`admin-ui/src/components/Overview.svelte`;
админка собирается Svelte-сборкой в `ego_server/static/admin/` — учитывай расхождение
из раздела 2).

Новое имя ещё не выбрано (варианты, которые обсуждались: «Трасса», «Пошагово»,
«Разбор», «Ступени», Stepwise). Сделай так, чтобы имя, короткое описание и знак

Чек-лист настоящего ребрендинга (не входит в задачу лендинга, но учитывай):
домен и HTTPS-сертификат; правило Host в Traefik; `EGO_PUBLIC_URL`;
адреса возврата в двух OAuth-приложениях Forgejo (вход и MCP `/mcp-callback`);
название, категория команд и тексты расширения (`vscode-ego/package.json`, сейчас
«Cogito: …»; внутренние id `ego.*` не менять); имя файла `cogito-<версия>.vsix` в
`ego_server/extension_dist.py`; тексты админки и кабинета; редирект со старого домена.

## 6. Факты для текста

- Курс «Python с нуля»: 10 папок, 195 задач, 56 карточек теории.
  Папки: переменные (13), функции (22), циклы и роли переменных (24), числа и
  выражения (8), `range` и `while` (22), `break`/`continue`/вложенные циклы (22),
  строки (22), списки (22), функции глубже (20), мини-проекты (20: угадайка,
  шифр Цезаря, проверка пароля, системы счисления).
- XL-A: 27 продуктовых задач в девяти историях (чатботы, агенты, игры, MMO):
  найти баг, внести правку, написать новое.
- Типы задач: трассировка (интерактивная таблица в VS Code), собрать из строк
  (перетаскиванием), найди баг, допиши, напиши сам, правки готового кода.
- Теория — карточки рядом с задачей, у каждой задачи ссылки на нужные карточки;
  после неудачной проверки расширение предлагает «Повтори теорию».
- Роли переменных и «паспорт роли»: методика объяснения циклов.
- Проверка — в песочнице на сервере; при ошибке в задачах на трассировку
  правильный ответ не показывается.
- Защита понимания после решения (учебный AI-помощник, включается администратором).
- Расширение: дерево «проект → папка → теория и задачи», личный кабинет
  (прогресс по папкам, «Продолжить», статусы защиты), вход через Forgejo,
  выгрузка только изменившихся задач, автообновление с сервера.

## 7. Выкатка и проверки

- Тесты: `uv run --all-extras pytest -q` (14 падений на этой ветке старые и известные:
  захардкоженное «33 задачи» и `test_catalog_archive`); расширение:
  `npm run -s compile && npm run -s test:unit && npm run -s smoke` в `vscode-ego/`.
- Песочница проверки на Windows под нагрузкой ловит ложные таймауты: верификаторы
  запускать с `--timeout 30`.
- Выкатка — только по прямому согласию владельца. Схема прошлых релизов: сверить
  хеши заменяемых файлов в текущем образе с git, собрать надстройку, прогнать
  кандидата на копии БД и контента, бэкап в `/opt/cogito/releases/<релиз>/backup`,
  переключить `COGITO_IMAGE` в `.env`, откат при падении health, проверить, что
  `students`, `progress`, `runs`, `service_settings` не изменились.
- Прогресс студентов не трогать: id задач не менять.

## 8. Готово, когда

- `/` (или выбранный путь) отдаёт лендинг; админка доступна по новому пути вне
  защищённого списка шлюза, старые закладки на `/` ведут на лендинг со ссылкой «Для наставника».
- Кнопка скачивания отдаёт текущий `.vsix`, версия на странице совпадает с `/extension/latest`.
- Счётчики пишутся, `GET /admin/analytics` отдаёт агрегаты, блок виден в обзоре админки.
- Бренд меняется в одном месте.
- Тесты на маршруты, счётчики (в т.ч. отсечение ботов) и миграцию проходят.
