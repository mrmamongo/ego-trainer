# Задача G5: Группировка по длине

**Блок:** G — NLP пайплайн
**Сложность:** easy
**Темы:** группировка, динамический батчинг, длина последовательности

## Условие

Чтобы ускорить обучение, модели группируют тексты одинаковой длины в один батч. Это уменьшает padding и лишние вычисления. Сгруппируй последовательности по длине их токенов.

## Аргументы

- `sequences` — список словарей:
```python
[
    {"id": "s1", "tokens": [101, 234, 456]},
    {"id": "s2", "tokens": [101, 234]},
    {"id": "s3", "tokens": [101, 234, 456, 789]},
]
```

## Возвращает

Словарь: длина -> список `id`, у которых такая длина `tokens`.

## Правила

- Ключ результирующего словаря — длина списка `tokens` (`len(seq["tokens"])`).
- Значение — список `id` всех последовательностей с такой длиной.

## Пример

```python
>>> sequences = [
...     {"id": "s1", "tokens": [101, 234, 456]},
...     {"id": "s2", "tokens": [101, 234]},
...     {"id": "s3", "tokens": [101, 234, 456, 789]},
... ]
>>> task_g5_group_by_length(sequences)
{
    2: ["s2"],
    3: ["s1"],
    4: ["s3"],
}
```

<summary>Эталонное решение</summary>

```python
def task_g5_group_by_length(sequences):
    result = {}
    for s in sequences:
        length = len(s["tokens"])
        if length not in result:
            result[length] = []
        result[length].append(s["id"])
    return result
```
