# Задача G1: Частотный словарь

**Блок:** G — NLP пайплайн
**Сложность:** easy
**Темы:** токены, частотный словарь, словарь-счётчик

## Условие

Перед тобой список токенов (слов, разбитых на кусочки). Посчитай, сколько раз каждый токен встречается. Это первый шаг построения словаря языковой модели — частоты нужны, чтобы потом выкидывать редкие токены.

## Аргументы

- `tokens` — список строк: `["the", "cat", "sat", "on", "the", "mat"]`

## Возвращает

Словарь: токен -> количество вхождений. Порядок ключей — как в списке (первое появление определяет порядок).

## Правила

- Порядок ключей в результате — как в исходном списке (первое появление токена определяет его позицию).
- Каждый ключ отображается в количество его вхождений.

## Пример

```python
>>> task_g1_token_frequency(["the", "cat", "the"])
{"the": 2, "cat": 1}
```

<details>
<summary>Эталонное решение</summary>

```python
def task_g1_token_frequency(tokens):
    result = {}
    for t in tokens:
        if t not in result:
            result[t] = 0
        result[t] += 1
    return result
```
