# Задача G2: Очистка словаря

**Блок:** G — NLP пайплайн
**Сложность:** easy
**Темы:** vocab, фильтрация словаря, min_count

## Условие

В `vocab` лежат токены и их частоты. Нужно убрать те, что встречаются реже `min_count` раз. Это уменьшает размер модели: редкие токены не несут полезного сигнала и только раздувают матрицы эмбеддингов.

## Аргументы

- `vocab` — словарь: `{"the": 50, "cat": 3, "xyz": 1, ...}`
- `min_count` — число. Токены с частотой `< min_count` удаляются.

## Возвращает

Новый словарь, в котором только токены с частотой `>= min_count`.

## Правила

- В результат попадают только токены с частотой `>= min_count`.
- Оригинальный `vocab` не меняй — верни новый словарь.

## Пример

```python
>>> task_g2_vocab_filter({"the": 50, "cat": 3, "xyz": 1}, 2)
{"the": 50, "cat": 3}
```

<details>
<summary>Эталонное решение</summary>

```python
def task_g2_vocab_filter(vocab, min_count):
    return {token: count for token, count in vocab.items() if count >= min_count}
```
