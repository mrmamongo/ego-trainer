# Задача G3: Обрезка последовательности

**Блок:** G — NLP пайплайн
**Сложность:** easy
**Темы:** truncation, обрезка, context window

## Условие

У модели есть лимит входных токенов (context window). Если текст длиннее лимита — обрезаем с конца, оставляя только первые `max_len` токенов.

## Аргументы

- `tokens` — список целых чисел (ID токенов): `[101, 234, 456, 789, 102]`
- `max_len` — максимальная длина. Если `len(tokens) > max_len` — обрезать.

## Возвращает

Список токенов. Если он был длиннее `max_len` — верни первые `max_len`. Если короче или равен — верни как есть.

## Правила

- Если длина больше `max_len` — вернуть первые `max_len` элементов.
- Если длина меньше или равна `max_len` — вернуть список без изменений.

## Пример

```python
>>> task_g3_truncate_sequence([101, 234, 456, 789, 102], 3)
[101, 234, 456]

>>> task_g3_truncate_sequence([101, 234], 5)
[101, 234]
```

<details>
<summary>Эталонное решение</summary>

```python
def task_g3_truncate_sequence(tokens, max_len):
    return tokens[:max_len]
```
