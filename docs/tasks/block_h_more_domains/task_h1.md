# Задача H1: Складываем стаки предметов

**Блок:** H — Игры
**Сложность:** medium
**Темы:** инвентарь, словари-счётчики, агрегация

## Условие

В инвентаре игрока один и тот же предмет может лежать несколькими стаками. Функция должна объединить все стаки одинаковых предметов, сложив их количества, и вернуть словарь «название предмета → суммарное количество».

## Аргументы

- `items` — список словарей вида `[{"name": "Iron Ore", "qty": 5}, {"name": "Iron Ore", "qty": 3}, ...]`

## Возвращает

Словарь: `name` -> суммарное `qty`. Например: `{"Iron Ore": 8, "Herb": 12}`

## Правила

- Для каждого предмета суммируем `qty` по совпадающему `name`.
- Порядок ключей в результате не важен.

## Пример

```python
items = [
    {"name": "Iron Ore", "qty": 5},
    {"name": "Iron Ore", "qty": 3},
    {"name": "Herb", "qty": 12},
]
# → {"Iron Ore": 8, "Herb": 12}
```

<details>
<summary>Эталонное решение</summary>

```python
def task_h1_inventory_stack(items):
    result = {}
    for item in items:
        n = item["name"]
        result[n] = result.get(n, 0) + item["qty"]
    return result
```
