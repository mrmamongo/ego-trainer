## Статус материалов XL-M

Это самостоятельные учебные заготовки для работы с `student.py`. Стартовый
код может содержать намеренные ошибки или незавершённые реализации; он не
является эталоном и не свидетельствует о прохождении задания.

Эти файлы не импортируются платформой как задачи без подготовки условий
`task_*.md`, эталонов `.solution.py`, тестов `.tests.py` и метаданных каталога.
Проверка и уточнение учебных контрактов отслеживаются в Beads: `ego-trainer-uom`.
В наборе сохранены исходные идентификаторы, примеры и варианты стартового кода;
неоднозначные условия требуют уточнения перед автоматической оценкой.

# XL-M — продуктовые задачи для LLM, agents и MMO

Набор из 25 задач. Каждая задача находится в отдельной папке и содержит `student.py`.
Описание, входные данные и критерии поведения находятся в docstring в начале файла.

| Задачи | Тема | Типы |
|---|---|---|
| 01–09 | LLM | баги (01, 02, 04, 05, 07, 09), правки (03), новый код (06, 08) |
| 10–17 | Agents | баги (10, 12, 13, 16), правки (11, 14, 17), новый код (15) |
| 18–25 | Игры и MMO | баги (18, 19, 21, 23, 25), правки (22), новый код (20, 24) |

Задачи с намеренно неисправным стартовым кодом: 01, 02, 04, 05, 07, 09, 10, 12, 13, 16, 18, 19, 21, 23, 25.
Остальные задачи содержат каркас, который студент должен реализовать или расширить.

Комбинации подходов между задачами:
- LLM-03 + LLM-07 → история чата с system prompt и валидацией
- LLM-08 + Agents-11 → retry с backoff для tool call
- Agents-10 + Agents-12 → цикл агента и топологический разрешение
- Agents-13 + Agents-15 → пул воркеров и агрегация результатов
- Games-18 + Games-19 → loot table и cooldown ability
- Games-22 + Games-23 → dungeon step и трекинг квестов
- Games-21 + Games-24 → экономика и торговля
