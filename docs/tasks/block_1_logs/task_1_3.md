# Задача 1.3: Медленные запросы

**Блок:** 1 — Логи (агрегация)
**Сложность:** medium
**Темы:** логи, фильтрация, проекция (выбор ключей)

## Условие

Функция находит все лог-записи с временем ответа больше 500 мс и возвращает их в сокращённом виде — только с ключами `"timestamp"` и `"service"`. Это позволяет собрать список медленных запросов для последующего анализа без лишних полей.

## Аргументы

- `logs` — список словарей. У каждого есть ключи `"timestamp"`, `"service"`, `"response_time_ms"`.

## Возвращает

Список словарей, где `response_time_ms > 500`. В каждом словаре оставлены только ключи `"timestamp"` и `"service"`. Остальные ключи выброшены.

## Правила

- В результат попадают только записи с `response_time_ms > 500` (строго больше).
- В каждом словаре результата остаются только ключи `"timestamp"` и `"service"`.
- Остальные ключи (включая `"response_time_ms"`, `"level"`, `"status"`) выбрасываются.

## Пример

```python
>>> task_1_3_slow_requests(logs)
[
    {"timestamp": "2026-07-10T10:00:01", "service": "api"},
    {"timestamp": "2026-07-10T10:00:02", "service": "auth"},
]
```

<details>
<summary>Эталонное решение</summary>

```python
def task_1_3_slow_requests(logs):
    return [
        {"timestamp": e["timestamp"], "service": e["service"]}
        for e in logs if e["response_time_ms"] > 500
    ]
```
