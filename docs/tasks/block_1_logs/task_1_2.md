# Задача 1.2: Ошибки по сервисам

**Блок:** 1 — Логи (агрегация)
**Сложность:** medium
**Темы:** логи, группировка, словари-счётчики, агрегация

## Условие

Функция группирует ERROR-записи по сервисам и считает, сколько ошибок у каждого сервиса. Результат — словарь «имя сервиса → количество ошибок», позволяющий быстро понять, какой сервис «болеет» сильнее остальных.

## Аргументы

- `logs` — список словарей. У каждого есть ключи `"level"` и `"service"`.

## Возвращает

Словарь: имя сервиса → сколько у него `ERROR`-записей.

## Правила

- Учитываются только записи с `level == "ERROR"`.
- Сервисы без ошибок в результат попадать НЕ должны.
- Имя сервиса берётся из поля `"service"`.

## Пример

```python
>>> task_1_2_errors_by_service(logs)
{"api": 2, "auth": 5, "db": 1}
```

<details>
<summary>Эталонное решение</summary>

```python
def task_1_2_errors_by_service(logs):
    d = {}
    for e in logs:
        if e["level"] == "ERROR":
            svc = e["service"]
            d[svc] = d.get(svc, 0) + 1
    return d
```
