# Задача 1.1: Подсчёт ошибок

**Блок:** 1 — Логи (агрегация)
**Сложность:** medium
**Темы:** логи, подсчёт, фильтрация по полю

## Условие

Функция проходит по списку лог-записей и считает, сколько из них имеют уровень `"ERROR"`. Это базовая агрегация для оценки общего количества ошибок в системе.

## Аргументы

- `logs` — список словарей. Каждый словарь — одна строка лога. У каждого словаря есть ключ `"level"` (строка).

## Возвращает

Число — сколько в списке записей с `level == "ERROR"`.

## Правила

- Считаются только записи, у которых `level` равен `"ERROR"` (точное совпадение строки).
- Остальные уровни (`"INFO"`, `"WARNING"` и т. д.) игнорируются.

## Пример

```python
>>> logs = [
...     {"level": "INFO", ...},
...     {"level": "ERROR", ...},
...     {"level": "INFO", ...},
... ]
>>> task_1_1_count_errors(logs)
1
```

<details>
<summary>Эталонное решение</summary>

```python
def task_1_1_count_errors(logs):
    return sum(1 for e in logs if e["level"] == "ERROR")
```
