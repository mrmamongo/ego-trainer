# Задача 1.4: Алёрт на 500-е

**Блок:** 1 — Логи (агрегация)
**Сложность:** medium
**Темы:** логи, множества, дедупликация, фильтрация

## Условие

Функция собирает список сервисов, которые хотя бы раз вернули HTTP-статус 500. Такой список нужен для алёрта: если сервис хоть раз упал в 500-ю ошибку, он должен попасть в отчёт на исследование. Дубликаты недопустимы — каждый сервис упоминается один раз.

## Аргументы

- `logs` — список словарей. У каждого есть ключи `"service"` и `"status"`.

## Возвращает

Список строк — имена сервисов, которые хотя бы раз вернули `status == 500`. Дубликатов быть НЕ должно. Порядок не важен.

## Правила

- В результат попадают сервисы, у которых есть хотя бы одна запись с `status == 500`.
- Дубликатов быть НЕ должно — каждый сервис встречается в списке один раз.
- Порядок сервисов в результате не важен.

## Пример

```python
>>> logs = [
...     {"service": "api", "status": 500, ...},
...     {"service": "auth", "status": 200, ...},
...     {"service": "api", "status": 500, ...},
...     {"service": "db", "status": 500, ...},
... ]
>>> task_1_4_services_with_500(logs)
["api", "db"]
```

<details>
<summary>Эталонное решение</summary>

```python
def task_1_4_services_with_500(logs):
    return list({e["service"] for e in logs if e["status"] == 500})
```
