# else у цикла: не было break

У `for` и `while` тоже бывает `else`. Он выполняется, если цикл **закончился сам** (элементы кончились), и **не** выполняется, если цикл был прерван командой `break`.

```python
def check(numbers):
    for number in numbers:           # 1
        if number < 0:               # 2
            result = "есть минус"    # 3
            break                    # 4
    else:                            # 5
        result = "минусов нет"       # 6
    return result                    # 7
```

Запомни: `else` стоит на одном уровне с `for`, а не с `if`.

| Вход | Что происходит | Какая строка присваивает `result` |
|---|---|---|
| `[3, -1, 5]` | на `-1` срабатывает `break`, `else` пропускается | строка 3 |
| `[3, 1, 5]` | `break` не было, список закончился, `else` выполняется | строка 6 |
| `[]` | тело не выполнилось ни разу, `break` тоже не было | строка 6 |

Читай `else` как «если не нашли»: цикл искал минус; если `break` не случился, значит, не нашёл.

## То же самое с флагом

`else` не обязательный. Ту же логику даёт значение «по умолчанию» (как флаг):

```python
result = "минусов нет"             # значение на случай «не нашли»
for number in numbers:
    if number < 0:
        result = "есть минус"
        break
```

Оба варианта правильные. `else` удобен, когда в случае «не нашли» нужно выполнить не одно присваивание, а несколько действий, или когда внутри функции хочется сразу вернуть ответ:

```python
def has_divisor(n):
    for d in range(2, n):
        if n % d == 0:
            break
    else:
        return False        # делителей не нашли
    return True             # сюда попадаем только после break
```

## continue и else

`continue` на `else` не влияет: он лишь пропускает остаток прохода. Цикл по-прежнему закончится сам, и `else` выполнится.
Работает `else` и у `while`: он выполняется, когда условие цикла стало ложным, а не по `break`.

## Частые ошибки

Поставить `else` на уровень `if`. Тогда он сработает на каждом подходящем элементе, а не один раз в конце:

```python
for number in numbers:
    if number < 0:
        result = "есть минус"
        break
    else:                     # неверно: относится к if, срабатывает на каждом неотрицательном
        result = "минусов нет"
```

Ждать, что `else` сработает после `break`: нет, он как раз для случая, когда `break` не было.

## Проверь себя

```python
for n in [2, 4, 6]:
    if n > 5:
        answer = "большое"
        break
else:
    answer = "все маленькие"
```

1. Что окажется в `answer`?
2. А если список `[2, 4]`?

<details><summary>Ответ</summary>

1. `"большое"`: на `6` сработал `break`, значит `else` пропущен.
2. `"все маленькие"`: `break` не было, `else` выполнился.

</details>
