# Вложенные циклы

Внутри цикла может быть другой цикл. Тогда **внутренний выполняется целиком на каждый проход внешнего**: стартует с начала, доходит до конца, и только потом внешний берёт следующий элемент.

```python
total = 0                           # 1
for i in range(1, 3):               # 2  внешний: i = 1, 2
    for j in range(1, 4):           # 3  внутренний: j = 1, 2, 3
        total = total + i * j       # 4
```

Тело (строка 4) выполняется `2 * 3 = 6` раз. Трассировка по порядку:

| Выполнение строки 4 | i | j | `i * j` | total после |
|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | 2 | 3 |
| 3 | 1 | 3 | 3 | 6 |
| 4 | 2 | 1 | 2 | 8 |
| 5 | 2 | 2 | 4 | 12 |
| 6 | 2 | 3 | 6 | 18 |

Смотри на столбцы: `j` пробегает `1, 2, 3` полностью, потом `i` меняется на `2`, и `j` снова стартует с `1`. «Быстрая» переменная — внутренняя, «медленная» — внешняя.

Число выполнений тела = (проходов внешнего) × (проходов внутреннего). Для пары списков `a` и `b` внутри побывают **все пары** «элемент из a и элемент из b».

## Начальные значения — до внешнего цикла

Накопитель, счётчик, сборщик заводят **до всех циклов**. Если поставить `total = 0` внутрь внешнего цикла, он будет обнуляться на каждом его проходе.

## break влияет только на внутренний цикл

`break` выходит из **ближайшего** цикла, то есть из того, внутри которого написан.

```python
count = 0                           # 1
for i in range(1, 4):               # 2
    for j in range(1, 4):           # 3
        if j > i:                   # 4
            break                   # 5
        count = count + 1           # 6
```

| i | какие j успели выполнить строку 6 | почему внутренний цикл закончился | count после |
|---|---|---|---|
| 1 | 1 | при `j = 2` сработал `break` | 1 |
| 2 | 1, 2 | при `j = 3` сработал `break` | 3 |
| 3 | 1, 2, 3 | `break` не сработал, `j` закончились | 6 |

Внешний цикл от `break` не пострадал: `i` дошёл до 3. Итог `count = 6`.

## return выходит из всего сразу

Из вложенных циклов можно выскочить одним `return`: функция завершается, сколько бы уровней вложенности ни было.

```python
def has_common(a, b):
    for x in a:
        for y in b:
            if x == y:
                return True        # нашли пару: выходим из обоих циклов и из функции
    return False                   # прошли все пары, общих нет
```

`return False` стоит **после обоих циклов**: «нет» можно сказать только когда проверены все пары.

## Ряд из звёздочек: "*" * 3

Умножение строки на число повторяет её: `"*" * 3` даёт `"***"`, `"*" * 1` даёт `"*"`, а `"*" * 0` — пустую строку `""`.
Строки-ряды растущей длины удобно получать из номера ряда: `"*" * row`. Обычно для этого хватает одного цикла, а не двух.

## Частые ошибки

Обнулить накопитель внутри внешнего цикла:

```python
for i in range(1, 4):
    total = 0                        # неверно: затирается на каждом i
    for j in range(1, 4):
        total = total + i * j
```

Решить, что `break` во внутреннем цикле остановит внешний. Не остановит: внешний просто перейдёт к следующему элементу. Если нужно выйти совсем, используй `return` или флаг.

Поставить `return False` внутрь внешнего цикла: функция вернёт ответ после первой же строки проверок.

## Проверь себя

```python
count = 0
for i in range(3):
    for j in range(2):
        count = count + 1
```

1. Сколько раз выполнится тело?
2. Сколько станет, если внутри после `count = count + 1` добавить `break`?

<details><summary>Ответ</summary>

1. `3 * 2 = 6`.
2. `3`: `break` обрывает внутренний цикл на первом же его проходе, а внешний делает все три прохода.

</details>
