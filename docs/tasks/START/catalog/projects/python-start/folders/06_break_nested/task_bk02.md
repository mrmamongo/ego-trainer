# Задача BK02: Пропуск вместо остановки

## Условие

### Как это работает

`continue` пропускает остаток тела **в текущем проходе** и сразу переходит к следующему элементу. Цикл при этом **не заканчивается**.

```python
total = 0
for number in [5, -2, 3]:
    if number < 0:
        continue
    total = total + number
```

| Проход | number | `number < 0`? | что произошло | total после прохода |
|---|---|---|---|---|
| 1 | 5 | нет | прибавили | 5 |
| 2 | -2 | да, `continue` | прибавление пропущено | 5 |
| 3 | 3 | нет | прибавили | 8 |

Проходов три, хотя на втором ничего не прибавилось: цикл дошёл до конца списка.

### Задание

Открой файл задачи. Впиши вместо каждого `None` ответ. `total_pass_2` и `total_pass_3` — значение `total` после тела цикла
на 2-м и 3-м проходе, `passes_started` — сколько проходов начал цикл, `skipped` — сколько раз сработал `continue`,
`total_final` — значение `total` после цикла.

**Сначала реши в голове или на бумаге, код не запускай.**

## Правила

- Меняй только строчки с `None`.
- Строки `def task_bk02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать `continue` от `break`: цикл продолжается, пропускается только остаток тела.
- Считать проходы и пропуски по таблице.

## Проверка понимания

Чему равно `number` после цикла? Что изменилось бы в ответе, если бы вместо `continue` стоял `break`?
