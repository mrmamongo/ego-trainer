# Задача BK11: Простое число

## Условие

### Как это работает

Вопрос «есть ли среди чисел хоть одно подходящее?» решается циклом, который **ищет** такое число. Если нашёл, сразу выходит (`break`). Если искал до конца и не нашёл, срабатывает `else` у цикла (или можно использовать флаг).

```python
def is_all_small(numbers):
    for number in numbers:
        if number > 10:
            break
    else:
        return True        # break не было: больших нет
    return False           # сюда попали после break: большое нашли
```

То же с флагом:

```python
def is_all_small(numbers):
    ok = True
    for number in numbers:
        if number > 10:
            ok = False
            break
    return ok
```

Число `n` **простое**, если оно больше 1 и не делится ни на одно число от 2 до `n - 1`. Значит, нужно искать **делитель**: нашли — число не простое.

### Задание

Напиши функцию `task_bk11_is_prime(n)`: верни `True`, если `n` простое, иначе `False`. Числа меньше 2 простыми не считаются.

## Аргументы

- `n` — целое число (может быть отрицательным или нулём).

## Возвращает

`True` или `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Делители перебирай циклом `for d in range(2, n)`. Используй `break` и `else` (или флаг).

## Пример

```python
task_bk11_is_prime(7)    # -> True
task_bk11_is_prime(9)    # -> False   (9 делится на 3)
task_bk11_is_prime(2)    # -> True    (range(2, 2) пуст, делителей нет)
task_bk11_is_prime(1)    # -> False
```

## Учебные цели

- Искать делитель циклом и выходить по `break`.
- Использовать `else` у цикла (или флаг) для ответа «не нашли».

## Проверка понимания

Почему для `n = 2` цикл не выполняется ни разу, а функция всё равно правильно отвечает `True`? Почему число `1` нужно проверить отдельно, до цикла?
