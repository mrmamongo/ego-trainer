# Задача BK01: Цикл оборвался

## Условие

### Как это работает

`break` обрывает цикл сразу: остаток тела и все оставшиеся элементы пропускаются, а программа идёт на первую строку **после** цикла.
Переменная цикла остаётся на том значении, на котором цикл остановился.

```python
total = 0
for number in [5, 2, 0, 7]:
    if number == 0:
        break
    total = total + number
```

| Проход | number | `number == 0`? | total после прохода |
|---|---|---|---|
| 1 | 5 | нет | 5 |
| 2 | 2 | нет | 7 |
| 3 | 0 | да, `break` | 7 |

Число `7` из списка цикл даже не увидел. После цикла `number` равно `0`, а `total` равно `7`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `total_pass_1` и `total_pass_2` — значение `total` после тела цикла на 1-м и 2-м проходе,
`passes_started` — сколько проходов цикл начал, `number_final` и `total_final` — значения после всего цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_bk01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, на каком проходе срабатывает `break`.
- Помнить, что после `break` строка с прибавлением не выполняется, а переменная цикла остаётся на элементе-«стопе».

## Проверка понимания

Сколько раз выполнится строка `total = total + number`? Почему `9` в сумму не попал?
