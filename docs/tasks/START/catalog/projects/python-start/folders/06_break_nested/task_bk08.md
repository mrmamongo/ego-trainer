# Задача BK08: Бесконечный цикл с выходом

## Условие

### Как это работает

Условие `while True` всегда верно, поэтому такой цикл сам не остановится. Его останавливает `break`, который стоит под `if`:

```python
n = 1
count = 0
while True:
    n = n * 2
    count = count + 1
    if n > 10:
        break
```

| Проход | n после `n = n * 2` | count | `n > 10`? |
|---|---|---|---|
| 1 | 2 | 1 | нет |
| 2 | 4 | 2 | нет |
| 3 | 8 | 3 | нет |
| 4 | 16 | 4 | да, `break` |

Проверка стоит **после** изменения `n`, поэтому в `n` остаётся значение, из-за которого вышли (`16`). Цикл безопасен, потому что `n` растёт и условие рано или поздно выполнится.

### Задание

В файле цикл `while True` с `break`. Впиши вместо каждого `None` ответ: `n_pass_2` и `n_pass_3` — `n` после тела цикла на 2-м и 3-м проходе,
`big_at_pass_3` — верно ли на 3-м проходе, что `n > 50` (`True` или `False`), `steps_final` и `n_final` — значения после цикла.

**Сначала реши в голове или на бумаге, код не запускай.**

## Правила

- Меняй только строчки с `None`.
- Строки `def task_bk08_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что `while True` заканчивается только через `break`.
- Следить за значениями по проходам и находить проход, на котором срабатывает выход.
