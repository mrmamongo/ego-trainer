# Задача BK06: Сумма положительных

## Условие

### Как это работает

Когда «плохие» элементы нужно **пропустить**, удобно отсеять их сразу в начале тела командой `continue`, а ниже писать основное действие:

```python
def sum_small(numbers):
    total = 0
    for number in numbers:
        if number > 100:
            continue                  # большое пропускаем
        total = total + number        # остальное складываем
    return total
```

Всё, что стоит ниже `continue`, в этом проходе пропускается, а цикл идёт к следующему элементу.

### Задание

Напиши функцию `task_bk06_sum_positive(numbers)`: сложи только **положительные** числа (строго больше нуля). Нули и отрицательные пропусти.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Сумму положительных чисел; если их нет, то `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `sum` не используй. Пропускай ненужные числа через `continue`.

## Пример

```python
task_bk06_sum_positive([1, -2, 3])     # -> 4
task_bk06_sum_positive([-1, 0, -5])    # -> 0
task_bk06_sum_positive([])             # -> 0
```

## Учебные цели

- Писать цикл-фильтр с `continue`.
- Помнить, что после пропуска цикл продолжается, а не заканчивается.
