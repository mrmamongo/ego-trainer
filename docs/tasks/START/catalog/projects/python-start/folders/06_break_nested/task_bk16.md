# Задача BK16: Есть общий элемент

## Условие

### Как это работает

Вопрос «есть ли общий элемент?» требует проверять пары, но искать дальше после первой находки не нужно. Из вложенных циклов выходят одним `return`:
он завершает сразу и внутренний цикл, и внешний, и всю функцию.

```python
def has_big_pair(a, b):
    for x in a:
        for y in b:
            if x + y > 100:
                return True      # нашли: выходим из обоих циклов сразу
    return False                 # проверили все пары, не нашли
```

Ответ «нет» можно дать только **после обоих циклов**, когда проверены все пары. Если поставить `return False` внутрь, функция ответит «нет» после первой же неудачной пары.

### Задание

Напиши функцию `task_bk16_has_common(a, b)`: верни `True`, если хотя бы одно число есть и в списке `a`, и в списке `b`, иначе `False`.

## Аргументы

- `a`, `b` — списки целых чисел (могут быть пустыми).

## Возвращает

`True` или `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Решай вложенными циклами с ранним `return`; операторы `in` и множества пока не нужны.

## Пример

```python
task_bk16_has_common([1, 2, 3], [3, 4])   # -> True
task_bk16_has_common([1, 2], [3, 4])      # -> False
task_bk16_has_common([], [1])             # -> False
```

## Учебные цели

- Использовать ранний `return` для выхода из вложенных циклов.
- Ставить ответ «не нашли» после всех циклов.
