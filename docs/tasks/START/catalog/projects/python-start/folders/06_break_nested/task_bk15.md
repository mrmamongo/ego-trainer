# Задача BK15: Пары с нужной суммой

## Условие

### Как это работает

Вложенные циклы по двум спискам перебирают **все** пары `(x, y)`, где `x` из первого списка, а `y` из второго. Счётчик растёт на единицу для каждой подходящей пары:

```python
def count_equal_pairs(a, b):
    count = 0
    for x in a:
        for y in b:
            if x == y:
                count = count + 1
    return count
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до обоих циклов | `0` | `count = count + 1` — только если пара подошла | после обоих циклов |

Одинаковые значения в списках дают разные пары: для `a = [1, 1]`, `b = [2]` и цели `3` ответ `2`, потому что пар две (первая единица с двойкой и вторая единица с двойкой).

### Задание

Напиши функцию `task_bk15_count_pairs_with_sum(a, b, target)`: посчитай, сколько существует пар (`x` из `a`, `y` из `b`), у которых `x + y` равно `target`.

## Аргументы

- `a`, `b` — списки целых чисел (могут быть пустыми).
- `target` — целое число, нужная сумма.

## Возвращает

Целое число — количество подходящих пар.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_bk15_count_pairs_with_sum([1, 2, 3], [4, 5, 6], 7)   # -> 3   ((1, 6), (2, 5), (3, 4))
task_bk15_count_pairs_with_sum([1, 1], [2, 2], 3)         # -> 4
task_bk15_count_pairs_with_sum([], [1], 1)                # -> 0
```

## Учебные цели

- Перебирать все пары двух списков и считать подходящие.
- Не путать порядок: каждая пара учитывается отдельно.

## Проверка понимания

Почему для `([1, 1], [2, 2], 3)` ответ `4`, а не `1`? Сколько проверок выполняет функция для списков из 5 и 6 элементов?
