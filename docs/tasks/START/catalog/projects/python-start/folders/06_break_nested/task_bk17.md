# Задача BK17: Лесенка из звёздочек

## Условие

### Как это работает

Умножение строки на число повторяет строку: `"*" * 3` даёт `"***"`, `"*" * 1` даёт `"*"`, `"*" * 0` даёт пустую строку `""`.
Так из номера ряда получается ряд нужной длины.

```python
def rows_of_dots(n):
    rows = []
    for size in range(1, n + 1):
        rows.append("." * size)
    return rows
```

Для `n = 3` получится `[".", "..", "..."]`: ряд номер 1 из одной точки, ряд номер 2 из двух, ряд номер 3 из трёх. Это сборщик: `rows = []` до цикла, `rows.append(...)` в теле.

### Задание

Напиши функцию `task_bk17_staircase(n)`: верни список из `n` строк-рядов лесенки из звёздочек. Первая строка состоит из одной `"*"`, вторая из двух, и так до `n`.

## Аргументы

- `n` — целое число от 0.

## Возвращает

Список строк: `["*", "**", ..., "*" * n]`. Для `n = 0` — пустой список `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Каждый ряд строй через `"*" * номер_ряда`.

## Пример

```python
task_bk17_staircase(3)   # -> ["*", "**", "***"]
task_bk17_staircase(1)   # -> ["*"]
task_bk17_staircase(0)   # -> []
```

## Учебные цели

- Использовать повторение строки `"*" * k`.
- Собирать список рядов в цикле по `range`.

## Проверка понимания

Что вернёт `"*" * 0`? Почему для `n = 0` цикл `range(1, n + 1)` не выполняется ни разу?
