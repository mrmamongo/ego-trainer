# Задача BK20: Пропускаем то, что не влезло

## Условие

### Как это работает

**Что изменилось по сравнению с BK19: ровно одно слово, но смысл другой.**

В BK19 первая цена, которая не влезла, останавливала весь обход (`break`). Теперь такая цена просто **пропускается** (`continue`), а дальше мы смотрим остальные: следующая может быть меньше и влезть.

Всё остальное то же самое:

- `total` — накопитель, прибавляем **только взятые** цены;
- `result` — сборщик, добавляем **только взятые** цены;
- цена влезает, если `total + price <= budget`.

Главная тонкость: после пропуска `total` **не меняется**. Следующая цена проверяется по прежней сумме.

Сравнение на примере `prices = [4, 8, 3, 2]`, `budget = 10`:

| Проход | price | `total + price` | влезает? | BK19 (`break`) | BK20 (`continue`) |
|---|---|---|---|---|---|
| 1 | 4 | 4 | да | берём, `[4]` | берём, `[4]` |
| 2 | 8 | 12 | нет | **стоп**, итог `[4]` | пропускаем, total остаётся 4 |
| 3 | 3 | 7 | да | (не смотрели) | берём, `[4, 3]` |
| 4 | 2 | 9 | да | (не смотрели) | берём, `[4, 3, 2]` |

BK19 вернёт `[4]`, BK20 вернёт `[4, 3, 2]`.

### Задание

В файле уже лежит решение BK19. Напиши функцию `task_bk20_take_skip_too_big(prices, budget)`: иди по `prices` с начала, бери цену, если она влезает в бюджет вместе с уже взятыми; цену, которая не влезает, **пропусти** и иди дальше. Верни список взятых цен в исходном порядке.

## Аргументы

- `prices` — список целых положительных чисел (может быть пустым).
- `budget` — целое число от 0.

## Возвращает

Список взятых цен в порядке их следования в `prices`. Сумма взятых не больше `budget`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `sum`, `max`, `min`, `sorted` не используй. Исходный список не меняй.

## Пример

```python
task_bk20_take_skip_too_big([4, 8, 3, 2], 10)   # -> [4, 3, 2]   (8 не влезла и пропущена)
task_bk20_take_skip_too_big([20, 1], 10)        # -> [1]
task_bk20_take_skip_too_big([11, 12], 10)       # -> []
```

## Учебные цели

- Заменить «остановиться» на «пропустить» и увидеть, как меняется результат.
- Помнить, что после пропуска накопитель остаётся прежним.

## Проверка понимания

Почему для `([6, 5, 4, 1], 10)` ответ `[6, 4]`, а не `[6, 4, 1]`? Какая сумма получилась бы с единицей?
