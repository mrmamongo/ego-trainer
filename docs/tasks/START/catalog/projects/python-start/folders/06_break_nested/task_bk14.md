# Задача BK14: Сумма таблицы умножения

## Условие

### Как это работает

Внутри одного цикла по `range` можно запустить второй. Накопитель при этом заводят **один раз, до внешнего цикла**, а прибавляют в самом глубоком теле:

```python
def sum_of_sums(n):
    total = 0
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            total = total + i + j
    return total
```

Для `n = 2` пары идут так: `(1, 1)`, `(1, 2)`, `(2, 1)`, `(2, 2)`, а `total` растёт `2`, `5`, `8`, `12`.
Тело выполняется `n * n` раз.

### Задание

Напиши функцию `task_bk14_table_sum(n)`: верни сумму произведений `i * j` по всем парам, где `i` и `j` независимо принимают значения от `1` до `n` включительно.
Для `n = 2` это `1*1 + 1*2 + 2*1 + 2*2 = 9`.

## Аргументы

- `n` — целое число от 0 (при `n = 0` пар нет).

## Возвращает

Целое число — сумму всех произведений `i * j`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Решай двумя вложенными циклами `for ... in range(...)`, готовых формул не используй.

## Пример

```python
task_bk14_table_sum(1)   # -> 1
task_bk14_table_sum(2)   # -> 9
task_bk14_table_sum(3)   # -> 36
task_bk14_table_sum(0)   # -> 0
```

## Учебные цели

- Накапливать сумму во вложенных циклах.
- Заводить накопитель до обоих циклов.

## Проверка понимания

Сколько раз выполнится тело для `n = 4`? Что получится, если `total = 0` оказалось внутри внешнего цикла: сумма всей таблицы или только последней строки?
