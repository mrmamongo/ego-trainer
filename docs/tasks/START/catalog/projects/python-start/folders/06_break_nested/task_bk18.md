# Задача BK18: Две кости

## Условие

### Как это работает

Бросаем две кости. У каждой от `1` до `6` очков. Все варианты результата — это все пары `(a, b)`, где `a` пробегает значения `1..6` (первая кость),
а `b` — тоже `1..6` (вторая). Варианты `(1, 2)` и `(2, 1)` считаются **разными**.

```python
def count_equal_dice():
    count = 0
    for a in range(1, 7):
        for b in range(1, 7):
            if a == b:
                count = count + 1
    return count
```

Здесь `range(1, 7)` даёт числа `1..6` (семёрка не входит). Всего пар `6 * 6 = 36`; одинаковых среди них `6`.

### Задание

Напиши функцию `task_bk18_dice_ways(total)`: верни, сколькими способами на двух костях может выпасть сумма `total`. Способы считаются упорядоченными парами.

## Аргументы

- `total` — целое число (может быть любым, в том числе нереальным: 0, 1, 13).

## Возвращает

Количество упорядоченных пар `(a, b)`, где `a` и `b` от 1 до 6 и `a + b == total`. Если таких пар нет, то `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Перебирай пары двумя вложенными циклами по `range(1, 7)`.

## Пример

```python
task_bk18_dice_ways(7)    # -> 6   ((1, 6), (2, 5), (3, 4), (4, 3), (5, 2), (6, 1))
task_bk18_dice_ways(2)    # -> 1   ((1, 1))
task_bk18_dice_ways(13)   # -> 0
```

## Учебные цели

- Перебирать все варианты двумя вложенными циклами.
- Считать подходящие варианты счётчиком.

## Проверка понимания

Почему для суммы `3` ответ `2`, а не `1`? Сколько всего пар перебирает функция при любом `total`?
