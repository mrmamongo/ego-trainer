# Задача BK07: Первое кратное

## Условие

### Как это работает

Если нужно найти **первый** подходящий элемент, дальше искать незачем. В функции для этого проще всего поставить `return` прямо внутри цикла:
он сразу завершает и цикл, и функцию. А `return` с «не нашли» стоит **после** цикла.

```python
def first_big(numbers, limit):
    for number in numbers:
        if number > limit:
            return number        # нашли первый: выходим из функции
    return -1                    # цикл закончился, подходящих не было
```

Для диапазона чисел вместо списка используют `range(a, b + 1)`: он перебирает числа от `a` до `b` **включительно** (последнее число в `range` не входит, поэтому пишем `b + 1`).
Число `n` делится на `k` без остатка, если `n % k == 0`.

### Задание

Напиши функцию `task_bk07_first_multiple(a, b, k)`: верни первое число из отрезка от `a` до `b` включительно, которое делится на `k`. Если такого нет, верни `-1`.

## Аргументы

- `a`, `b` — целые числа, границы отрезка (если `a > b`, отрезок пустой).
- `k` — целое положительное число.

## Возвращает

Первое число отрезка `[a, b]`, делящееся на `k`, либо `-1`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Перебирай числа циклом `for ... in range(...)`.

## Пример

```python
task_bk07_first_multiple(1, 10, 3)   # -> 3
task_bk07_first_multiple(8, 10, 7)   # -> -1
task_bk07_first_multiple(0, 5, 3)    # -> 0   (ноль делится на любое число)
```

## Учебные цели

- Искать первое подходящее число и сразу выходить.
- Различать «нашёл — `return` внутри цикла» и «не нашёл — `return` после цикла».

## Проверка понимания

Почему `return -1` стоит после цикла, а не внутри него? Что вернёт функция для `(7, 7, 7)`?
