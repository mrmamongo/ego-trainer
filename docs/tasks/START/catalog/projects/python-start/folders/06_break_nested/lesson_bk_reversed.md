# reversed: обход с конца

Иногда список нужно обойти **с конца**: от последнего элемента к первому. Для этого пишут `reversed(список)`:

```python
for number in reversed([1, 2, 3]):
    ...                                # number: 3, потом 2, потом 1
```

Сам список при этом **не меняется**: `reversed` лишь подсказывает циклу, в каком порядке выдавать элементы.
`reversed(...)` — не список, по нему можно ходить циклом `for`, но нельзя написать `[0]`.

## Зачем это нужно

Когда важны последние элементы. Пример: «последние два числа больше 5». С начала списка мы не знаем, какие из больших окажутся последними, а с конца — первые найденные и есть нужные, и можно сразу остановиться.

## Собрали с конца — результат тоже «с конца»

Элементы попадают в `result` в порядке обхода, то есть от нового к старому. Если нужен исходный порядок, список в конце разворачивают.

```python
def last_two_big(numbers):
    result = []
    for number in reversed(numbers):     # 1
        if number > 5:                   # 2
            result.append(number)        # 3
            if len(result) == 2:         # 4
                break                    # 5
    result.reverse()                     # 6
    return result
```

Пусть `numbers = [9, 1, 7, 8, 2]`:

| Проход | number | `number > 5`? | result после прохода |
|---|---|---|---|
| 1 | 2 | нет | `[]` |
| 2 | 8 | да | `[8]` |
| 3 | 7 | да, длина 2, `break` | `[8, 7]` |

После цикла `result = [8, 7]` (от нового к старому), строка 6 разворачивает его в `[7, 8]`: так, как числа стояли в исходном списке.

## Два способа вернуть исходный порядок

1. **Метод `result.reverse()`** — разворачивает сам список `result` на месте. Он ничего не возвращает (как `append`), поэтому писать `result = result.reverse()` нельзя: в `result` попадёт `None`.
2. **Второй цикл**: `for item in reversed(result): final.append(item)` — собирает новый список `final` в нужном порядке.

Оба способа дают один результат. Метод короче.

Не вызывай `numbers.reverse()` на списке, который пришёл в функцию как параметр: ты изменишь список вызывающего кода. Для чужих списков используй `reversed(numbers)`.

## Обойти с конца не до самого начала

Если первый элемент нужно обработать отдельно, можно ходить по номерам: `range(len(numbers) - 1, 0, -1)`. У `range` три числа: «откуда, докуда (не включая), с каким шагом». Шаг `-1` значит «назад».

```python
numbers = [10, 20, 30, 40]
for index in range(len(numbers) - 1, 0, -1):   # index: 3, 2, 1 (нулевой не включён)
    print(numbers[index])                      # 40, 30, 20
```

Номер `0` не включается, поэтому `numbers[0]` в этот обход не попадёт.

## Частые ошибки

Забыть вернуть порядок: результат окажется «задом наперёд».

```python
for number in reversed(numbers):
    if number > 5:
        result.append(number)
return result                  # неверно: порядок обратный
```

```python
result.reverse()               # верно: развернули перед return
return result
```

Написать `result = result.reverse()`: после этого `result` равно `None`.

## Проверь себя

```python
result = []
for n in reversed([4, 9, 2, 6]):
    if n > 3:
        result.append(n)
result.reverse()
```

1. Какие значения получал `n` по порядку?
2. Что в `result` до `reverse`, а что после?

<details><summary>Ответ</summary>

1. `6, 2, 9, 4`.
2. До: `[6, 9, 4]` (двойка не прошла условие). После: `[4, 9, 6]`.

</details>
