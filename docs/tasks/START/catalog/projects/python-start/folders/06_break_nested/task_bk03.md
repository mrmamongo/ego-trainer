# Задача BK03: Один цикл, два слова

## Условие

### Как это работает

Два цикла ниже различаются одним словом, но делают разное:

- `break` останавливает **весь** цикл: остальные элементы не рассматриваются;
- `continue` отбрасывает **только текущий** элемент: цикл идёт дальше.

```python
a = 0
for number in [1, 7, 2]:
    if number > 5:
        break
    a = a + number         # a станет 1: на 7 цикл остановился

b = 0
for number in [1, 7, 2]:
    if number > 5:
        continue
    b = b + number         # b станет 3: 7 пропущено, 2 добавлено
```

### Задание

В файле два цикла по одному и тому же списку `[3, 8, 2, 9]`; «большое» значит больше `5`.
Впиши вместо `None` значения `a_final`, `a_passes` (сколько проходов начал первый цикл), `b_final`, `b_passes` и `number_final`
(чему равно `number` после **обоих** циклов).

**Сначала реши в голове или на бумаге, код не запускай.**

## Правила

- Меняй только строчки с `None`.
- Строки `def task_bk03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Сравнить поведение `break` и `continue` на одних и тех же данных.
- Увидеть, что `break` ограничивает ответ тем, что стоит до первого «неподходящего», а `continue` нет.

## Проверка понимания

Почему `b_final` больше `a_final`? Какие элементы списка не увидел первый цикл?
