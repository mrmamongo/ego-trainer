# Задача BK10: Нашли или нет: else

## Условие

### Как это работает

У цикла может быть `else`. Он выполняется, если цикл **закончился сам** (элементы кончились), и **пропускается**, если цикл оборвал `break`.

```python
answer = "?"
for number in [1, 4, 9]:
    if number > 3:
        answer = "big"
        break
else:
    answer = "small"
```

Здесь на `4` срабатывает `break`, `else` пропускается, и `answer` равно `"big"`. Для списка `[1, 2, 3]` `break` не сработает, цикл закончится сам, выполнится `else`, и `answer` станет `"small"`.

Запомни: `else` стоит на одном уровне с `for`.

### Задание

В файле два цикла с `else`. Впиши вместо `None` ответы: `first_final`, `second_final` (строки в кавычках, например `"even"`), `number_after_first` и `number_final` (значения `number` после первого и после второго цикла), `else_ran_second` (`True` или `False`).

**Сначала реши в голове или на бумаге, код не запускай.**

## Правила

- Меняй только строчки с `None`.
- Строки `def task_bk10_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Определять по `break`, выполнится ли `else` у цикла.
- Читать `else` как «если не нашли».

## Проверка понимания

В каком из двух циклов сработал `break`? Что было бы в `first`, если бы в первом списке стояло число `8`?
