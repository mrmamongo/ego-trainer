# Задача BK09: Команды до стоп-слова

## Условие

### Как это работает

Счётчик считает, сколько элементов подошло. Если нужно считать только до особого элемента, цикл останавливают командой `break`.
Проверку на стоп-значение ставят **до** прибавления к счётчику: иначе стоп-элемент попадёт в счёт.

```python
def count_before_end(words):
    count = 0
    for word in words:
        if word == "end":
            break
        count = count + 1
    return count
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — пока не встретили стоп | после цикла |

### Задание

Напиши функцию `task_bk09_count_commands(commands)`: посчитай, сколько команд стоит в списке до первой команды `"stop"`. Сама команда `"stop"` не считается.
Если `"stop"` в списке нет, посчитай все команды.

## Аргументы

- `commands` — список строк-команд (может быть пустым). Слова сравниваются точно: `"Stop"` и `"stop"` — разные строки.

## Возвращает

Целое число — количество команд до первого `"stop"` (или всех, если его нет).

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `len` не используй: считай счётчиком.

## Пример

```python
task_bk09_count_commands(["go", "go", "stop", "go"])   # -> 2
task_bk09_count_commands(["go", "turn"])               # -> 2
task_bk09_count_commands(["stop", "go"])               # -> 0
```

## Учебные цели

- Считать элементы счётчиком до стоп-значения.
- Ставить `break` до увеличения счётчика.

## Проверка понимания

Что вернёт функция для `["go", "stop", "stop"]`? Что получится, если поставить `count = count + 1` **выше** проверки на `"stop"`?
