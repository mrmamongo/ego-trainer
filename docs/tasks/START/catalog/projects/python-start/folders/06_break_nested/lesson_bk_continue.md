# continue: пропустить элемент

`break` обрывает весь цикл. А `continue` обрывает только **текущий проход**: остаток тела пропускается, и цикл берёт следующий элемент.

## Пример: сумма без отрицательных

```python
def sum_non_negative(numbers):
    total = 0
    for number in numbers:           # 1
        if number < 0:               # 2
            continue                 # 3
        total = total + number       # 4
    return total
```

Пусть `numbers = [4, -6, 5]`:

| Проход | number | `number < 0`? | что произошло | total после прохода |
|---|---|---|---|---|
| 1 | 4 | нет | строка 4 выполнена | 4 |
| 2 | -6 | да, `continue` | строка 4 пропущена | 4 |
| 3 | 5 | нет | строка 4 выполнена | 9 |

Цикл прошёл **все три** прохода, но на втором ничего не прибавил. Это главное отличие от `break`: после `continue` цикл продолжается.

## continue и обычный if

Тот же результат можно получить и без `continue`:

```python
for number in numbers:
    if number >= 0:
        total = total + number
```

`continue` удобен, когда «плохие» элементы нужно отбросить сразу в начале тела, а потом спокойно писать основной код без лишней вложенности.
Как записать — дело вкуса, главное понимать, что делает каждая форма.

## Что после continue не выполняется

Всё, что в теле написано **ниже** `continue`, в этом проходе пропускается — включая счётчики и `append`.
Поэтому проверку с `continue` ставят **перед** строками, которые нужно пропустить.

```python
for number in numbers:
    count = count + 1           # выполнится всегда: стоит выше continue
    if number < 0:
        continue
    total = total + number      # пропускается для отрицательных
```

## Осторожно с while

В `for` следующий элемент берёт сам цикл. В `while` переменную, от которой зависит условие, меняешь ты сам. Если `continue` стоит **раньше**, чем изменение переменной, то цикл вернётся к проверке с тем же значением и не закончится никогда.

```python
i = 0
while i < 5:
    if i == 2:
        continue        # опасно: i так и останется 2, цикл зависнет
    i = i + 1
```

В задачах этой папки мы используем `continue` в `for`, там такой беды нет.

## Частые ошибки

Написать `continue` без условия: все проходы будут пропущены.

```python
for number in numbers:
    continue                    # неверно: всё, что ниже, никогда не выполнится
    total = total + number
```

Перепутать с `break`: сумма «до первого отрицательного» и «без отрицательных» — разные задачи (подробнее в карточке «Остановиться или пропустить»).

## Проверь себя

```python
total = 0
for n in [3, -1, 4, -1, 5]:
    if n < 0:
        continue
    total = total + n
```

1. Сколько проходов начал цикл?
2. Чему равно `total` после цикла?
3. Чему равно `n` после цикла?

<details><summary>Ответ</summary>

1. Пять: `continue` не завершает цикл, он только пропускает остаток тела.
2. `12` (`3 + 4 + 5`).
3. `5`: последний элемент списка.

</details>
