# Задача BK12: Собери пары с чётной суммой

## Условие

### Как это работает

Чтобы перебрать **все пары** «элемент из первого списка и элемент из второго», один цикл кладут внутрь другого. Внешний цикл берёт элемент `x` из `a`,
а внутренний для этого `x` по очереди берёт все `y` из `b`.

```python
def count_equal_pairs(a, b):
    count = 0
    for x in a:
        for y in b:
            if x == y:
                count = count + 1
    return count
```

Для `a = [1, 2]`, `b = [1, 2]` пары идут в таком порядке: `(1, 1)`, `(1, 2)`, `(2, 1)`, `(2, 2)`. Равны две пары, поэтому функция вернёт `2`.

Отступы показывают вложенность: тело внутреннего цикла сдвинуто ещё на один шаг. Счётчик `count` заводится **до обоих** циклов, а `return` стоит **после** них.

### Задание

В файле задачи в комментарии записаны строки функции `task_bk12_count_even_pairs(a, b)`, но они перемешаны и без отступов.
Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали.
Функция должна посчитать, сколько существует пар (`x` из `a`, `y` из `b`), у которых сумма `x + y` чётная.

## Аргументы

- `a`, `b` — списки целых чисел (могут быть пустыми).

## Возвращает

Целое число — количество пар с чётной суммой; если один из списков пуст, то `0`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_bk12_count_even_pairs([1, 2], [3, 4])   # -> 2   ((1, 3) и (2, 4))
task_bk12_count_even_pairs([1], [2])         # -> 0
task_bk12_count_even_pairs([], [1, 2])       # -> 0
```

## Учебные цели

- Собрать шаблон «счётчик пар»: `count = 0` до циклов, внутренний цикл с отступом, `if` и `count` в самом глубоком теле.
- Видеть, что внутренний цикл проходит весь список `b` для каждого `x`.

## Проверка понимания

Сколько раз выполнится проверка `if` для `a` из 3 элементов и `b` из 4? Что случится, если `count = 0` поставить внутрь цикла `for x in a`?
