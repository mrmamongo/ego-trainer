# Задача BK19: Берём, пока влезает

## Условие

### Как это работает

Это первая ступень лесенки из четырёх задач (BK19-BK22). Дан список цен и бюджет. Идём по списку с начала и берём цены, пока их **общая сумма не превышает бюджет**.
На первой цене, которая уже не влезает, **останавливаемся** и ничего дальше не берём.

В этом цикле три переменные, и у каждой своя роль:

| Имя | Роль | Начальное значение | Как меняем в теле |
|---|---|---|---|
| `price` | текущий элемент | подставляет `for` | не меняем |
| `total` | накопитель: сколько уже набрали | `0` | `total = total + price` — только когда цена взята |
| `result` | сборщик: что взяли | `[]` | `result.append(price)` — только когда цена взята |

Цена **влезает**, если `total + price <= budget`. Не влезает, если `total + price > budget`. Эту проверку делают **до** того, как цену берут.

Пример: `prices = [5, 3, 4, 1]`, `budget = 9`.

| Проход | price | `total + price` | влезает? | что делаем | total | result |
|---|---|---|---|---|---|---|
| 1 | 5 | 5 | да | берём | 5 | `[5]` |
| 2 | 3 | 8 | да | берём | 8 | `[5, 3]` |
| 3 | 4 | 12 | нет | **стоп** (`break`) | 8 | `[5, 3]` |
| — | 1 | (цикл уже закончился) | | | | |

Заметь: последняя цена `1` влезла бы (`8 + 1 = 9`), но мы её не увидели, потому что остановились на `4`.

### Задание

Напиши функцию `task_bk19_take_while_fits(prices, budget)`: иди по `prices` с начала, бери цены, пока сумма взятых не превышает `budget`.
На первой цене, которая не влезает, остановись. Верни список взятых цен в исходном порядке.

## Аргументы

- `prices` — список целых положительных чисел (может быть пустым).
- `budget` — целое число от 0.

## Возвращает

Список взятых цен в том порядке, в котором они стояли в `prices`. Сумма взятых цен не больше `budget` (ровно `budget` допустимо). Если первая же цена не влезает, то `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `sum`, `max`, `min`, `sorted` не используй. Исходный список не меняй.

## Пример

```python
task_bk19_take_while_fits([4, 3, 5, 1], 10)   # -> [4, 3]   (4+3=7, 7+5=12 не влезло: стоп; единицу не смотрим)
task_bk19_take_while_fits([4, 6], 10)         # -> [4, 6]   (ровно 10 допустимо)
task_bk19_take_while_fits([20, 1], 10)        # -> []
```

## Учебные цели

- Объединить накопитель, сборщик и `break` в одном цикле.
- Проверять «влезает» по сумме **уже взятых** цен плюс текущая.

## Проверка понимания

Почему для `([2, 9, 1, 1], 10)` ответ `[2]`, хотя вторая единица тоже поместилась бы? Что здесь решает слово `break`?
