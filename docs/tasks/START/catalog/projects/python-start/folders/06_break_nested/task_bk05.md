# Задача BK05: Сумма до нуля

## Условие

### Как это работает

Накопитель суммы, как раньше, но цикл должен **остановиться** на особом числе. Проверку ставят **до** прибавления: тогда стоп-число в сумму не попадёт.

```python
def sum_before_ten(numbers):
    total = 0
    for number in numbers:
        if number == 10:
            break
        total = total + number
    return total
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + number` — пока не встретили стоп | после цикла |

Если стоп-числа в списке нет, цикл дойдёт до конца и сложит всё.

### Задание

Напиши функцию `task_bk05_sum_until_zero(numbers)`: сложи числа от начала списка до первого нуля. Сам ноль и всё, что после него, в сумму не входит.

## Аргументы

- `numbers` — список целых чисел (может быть пустым, числа могут быть отрицательными).

## Возвращает

Сумму чисел до первого нуля. Если нуля нет, то сумму всех чисел. Для пустого списка или если ноль стоит первым — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `sum` не используй. Для остановки используй `break`.

## Пример

```python
task_bk05_sum_until_zero([3, 4, 0, 5])   # -> 7
task_bk05_sum_until_zero([1, 2, 3])      # -> 6
task_bk05_sum_until_zero([0, 9])         # -> 0
```

## Учебные цели

- Сочетать накопитель и `break`.
- Ставить проверку стоп-значения до прибавления.

## Проверка понимания

Что изменится в ответе, если поставить проверку на ноль **после** строки `total = total + number`? Почему это не заметно в сумме, но заметно, например, в счётчике?
