# Задача RV01: Лучший игрок недели

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Напиши функцию `task_rv01_best_player(players)`: верни **имя** игрока с наибольшим счётом. Если у нескольких игроков счёт одинаковый, побеждает тот, чьё имя раньше по алфавиту (строки сравниваются через `<`). Для пустого списка верни `None`.

## Аргументы

- `players` — список словарей `{"name": строка, "score": целое}`; имена не повторяются (список может быть пустым).

## Возвращает

Имя лучшего игрока (строка) или `None`, если игроков нет.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Не используй `max`, `min`, `sorted` и метод `sort`: найди лучшего циклом.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv01_best_player([{"name": "Боря", "score": 50}, {"name": "Аня", "score": 50}, {"name": "Вика", "score": 40}])   # -> "Аня"
task_rv01_best_player([])   # -> None
```

## Учебные цели

- Проверить роль «лучший на данный момент» с запасным правилом при равенстве.
