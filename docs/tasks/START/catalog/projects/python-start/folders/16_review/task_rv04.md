# Задача RV04: Таблица лидеров портит список

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Функция `task_rv04_leaderboard(scores)` должна вернуть **новый** список очков от большего к меньшему, а исходный список оставить как был. Сейчас порядок в ответе правильный, но после вызова список вызывающего кода почему-то тоже изменился. Найди ошибку и исправь.

## Аргументы

- `scores` — список целых чисел (может быть пустым).

## Возвращает

Новый список тех же чисел, отсортированный по убыванию.

## Правила

- Исправь ошибку в готовой функции, переписывать всё с нуля не нужно.
- Исходный список `scores` после вызова должен остаться таким же, как был.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
scores = [5, 9, 1]
task_rv04_leaderboard(scores)   # -> [9, 5, 1]
scores                          # -> [5, 9, 1]  (не изменился)
```

- Проверить, что сортировка не портит входной список.
