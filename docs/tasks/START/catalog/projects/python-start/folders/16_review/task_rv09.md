# Задача RV09: Награда за невыполненный квест

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Функция `task_rv09_claim_reward(quest, claimed_ids)` выдаёт награду за квест. Правила:

1. если `progress` меньше `goal`, квест не выполнен: отказ с кодом `"not_finished"`;
2. если `id` квеста уже есть в `claimed_ids`, награду уже брали: отказ с кодом `"already_claimed"`;
3. иначе награда выдаётся.

Игроки жалуются: монеты пришли за квест, который ещё не закончен. Найди ошибку и исправь.

## Аргументы

- `quest` — словарь `{"id": строка, "goal": целое, "progress": целое, "reward": целое}`.
- `claimed_ids` — список `id` квестов, награду за которые уже выдавали.

## Возвращает

При выдаче `{"status": "granted", "coins": reward}`, при отказе `{"status": "rejected", "reason": код}`.

## Правила

- Исправь ошибку в готовой функции, переписывать всё с нуля не нужно.
- Менять нужно проверки; формат ответов и порядок правил оставь как в условии.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv09_claim_reward({"id": "q1", "goal": 5, "progress": 5, "reward": 50}, [])
# -> {"status": "granted", "coins": 50}
task_rv09_claim_reward({"id": "q1", "goal": 5, "progress": 2, "reward": 50}, [])
# -> {"status": "rejected", "reason": "not_finished"}
```

## Учебные цели

- Найти «ложный успех»: отказ, который не прерывает функцию.

## Проверка понимания

Почему при невыполненном квесте функция всё равно доходит до выдачи награды?
