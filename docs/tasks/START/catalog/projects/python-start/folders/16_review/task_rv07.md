# Задача RV07: Скидка новым клиентам

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Раньше функция `task_rv07_discount` принимала только сумму заказа и возвращала процент скидки: 15 при сумме от 5000, 5 при сумме от 1000, иначе 0. Теперь магазин добавляет правило для **новых клиентов**: если клиент новый и сумма заказа не меньше 500, скидка 20 процентов, даже если по старым правилам скидка больше или меньше. Если клиент новый, но сумма меньше 500, скидка считается по старым правилам.

Добавь второй параметр `is_new` (по умолчанию `False`). Измени готовую функцию, не пиши её с нуля: старые вызовы с одним аргументом должны давать прежние ответы.

## Аргументы

- `total` — целая сумма заказа, не меньше `0`.
- `is_new` — `True`, если клиент новый; необязательный, по умолчанию `False`.

## Возвращает

Целый процент скидки: `20`, `15`, `5` или `0`.

## Правила

- Измени готовый код, а не пиши функцию с нуля.
- Вызов с одним аргументом должен давать прежний результат.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv07_discount(6000)          # -> 15 (как раньше)
task_rv07_discount(6000, True)    # -> 20
task_rv07_discount(300, True)     # -> 0
```

## Учебные цели

- Проверить добавление правила в готовую функцию: порядок проверок и сохранение старого поведения.

## Проверка понимания

Какой ответ получился бы для `(6000, True)`, если поставить новое правило после старых?
