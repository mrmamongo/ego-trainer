# Задача RV03: Имя пользователя

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Пользователь ввёл имя при регистрации. Напиши функцию `task_rv03_check_username(raw)`:

1. сначала нормализуй текст: убери пробелы по краям и переведи в нижний регистр;
2. если после этого в имени меньше 3 символов, верни `"too_short"`;
3. если в имени есть символ не из набора `abcdefghijklmnopqrstuvwxyz0123456789_`, верни `"bad_char"`;
4. иначе верни `"ok"`.

Проверки идут именно в таком порядке: первая сработавшая и есть ответ.

## Аргументы

- `raw` — строка, как её ввёл пользователь (может быть пустой).

## Возвращает

Строка-код: `"ok"`, `"too_short"` или `"bad_char"`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv03_check_username("  Anna_7 ")   # -> "ok"
task_rv03_check_username(" ab ")        # -> "too_short"
task_rv03_check_username("an na")       # -> "bad_char"
```

## Учебные цели

- Проверить методы строк, цикл по символам и порядок проверок.

## Проверка понимания

Какой код вернёт `"!!"` и почему не `"bad_char"`?
