# Задача RV10: Настройка по пути

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Конфиг хранится во вложенных словарях. Напиши функцию `task_rv10_get_path(data, path, default=None)`: путь `path` записан через точки, например `"profile.settings.theme"`. Иди по ключам по очереди и верни найденное значение. Если на каком-то шаге нужного ключа нет или дальше идти некуда (значение не словарь), верни `default`.

Рекурсия не нужна: хватит цикла по частям пути.

## Аргументы

- `data` — словарь, внутри могут быть другие словари, списки, строки, числа и `None`.
- `path` — непустая строка ключей через точку.
- `default` — что вернуть, если пути нет; необязательный, по умолчанию `None`.

## Возвращает

Значение по пути (в том числе `None`, если оно там лежит) или `default`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
data = {"profile": {"settings": {"theme": "dark"}}, "id": 7}
task_rv10_get_path(data, "profile.settings.theme")        # -> "dark"
task_rv10_get_path(data, "profile.settings.lang", "ru")   # -> "ru"
task_rv10_get_path(data, "id.value", "?")                 # -> "?"
```

## Учебные цели

- Проверить шаг за шагом чтение вложенного словаря и значение по умолчанию.

## Проверка понимания

Чем отличаются «ключа нет» и «ключ есть, а значение `None`»? Что вернёт функция в каждом случае?
