# Задача RV06: Имена по номерам

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Напиши функцию `task_rv06_names_by_ids(users, ids)`: для каждого номера из `ids` (в том же порядке) найди имя пользователя с таким `id`. Если пользователя с таким номером нет, на его место поставь `"?"`. Номера в `ids` могут повторяться: тогда и имена повторяются.

## Аргументы

- `users` — список словарей `{"id": целое, "name": строка}`; `id` не повторяются (список может быть пустым).
- `ids` — список целых номеров (может быть пустым).

## Возвращает

Новый список имён той же длины, что и `ids`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
users = [{"id": 1, "name": "Аня"}, {"id": 2, "name": "Боря"}]
task_rv06_names_by_ids(users, [2, 5, 1])   # -> ["Боря", "?", "Аня"]
```

## Учебные цели

- Проверить построение индекса «id -> имя» и безопасное чтение по ключу.

## Проверка понимания

Что произойдёт, если читать `index[user_id]` без проверки, когда такого номера нет?
