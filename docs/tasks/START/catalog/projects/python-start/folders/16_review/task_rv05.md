# Задача RV05: Выручка по клиентам

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Напиши функцию `task_rv05_totals_by_customer(orders)`: сгруппируй заказы по клиенту и сложи суммы заказов каждого клиента. Ключи итогового словаря идут в порядке, в котором клиенты **впервые** появились в списке.

## Аргументы

- `orders` — список словарей `{"customer": строка, "total": целое от 0}` (может быть пустым).

## Возвращает

Новый словарь `{клиент: сумма всех его заказов}`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Не импортируй `collections`: хватит обычного словаря.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv05_totals_by_customer([{"customer": "Аня", "total": 100}, {"customer": "Боря", "total": 50}, {"customer": "Аня", "total": 30}])   # -> {"Аня": 130, "Боря": 50}
task_rv05_totals_by_customer([])   # -> {}
```

## Учебные цели

- Проверить словарь-накопитель по ключу и порядок ключей.

## Проверка понимания

Что вернёт функция для клиента, у которого единственный заказ на сумму 0? Пропадёт ли он из словаря?
