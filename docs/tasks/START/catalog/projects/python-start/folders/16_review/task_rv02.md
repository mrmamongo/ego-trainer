# Задача RV02: Свежие сообщения в бюджет

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Чат хранит стоимости сообщений от старых к новым. Напиши функцию `task_rv02_pick_recent(costs, budget)`: иди по сообщениям **от новых к старым** и бери сообщение, если оно влезает в остаток бюджета. Если не влезает, **пропусти** его и иди дальше: более старое может быть дешевле. Верни стоимости взятых сообщений в **исходном порядке** (от старых к новым).

## Аргументы

- `costs` — список целых положительных чисел (может быть пустым).
- `budget` — целое число от 0.

## Возвращает

Новый список взятых стоимостей в том же порядке, в каком они шли в `costs`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Входной список менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv02_pick_recent([4, 8, 3, 2], 10)   # -> [4, 3, 2]
task_rv02_pick_recent([9, 9], 5)          # -> []
```

## Учебные цели

- Проверить обход с конца, пропуск без остановки и возврат в исходном порядке.

## Проверка понимания

Чем бы ответ отличился для `[2, 6, 1]` и бюджета 7, если идти с начала, а не с конца?
