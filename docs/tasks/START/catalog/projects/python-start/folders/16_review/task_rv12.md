# Задача RV12: Команда undo

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Раньше `task_rv12_run` выполняла команды над числом (стартует с `0`): `"add N"` прибавляет, `"sub N"` вычитает, `"reset"` обнуляет. Незнакомые команды игнорируются. Функция возвращает кортеж `(значение, сколько команд выполнено, сколько проигнорировано)`.

Теперь добавь команду `"undo"`: она возвращает число к тому, что было **перед последней ещё не отменённой** командой `add`, `sub` или `reset`. Выполненный `undo` считается в «выполнено». Если отменять нечего, `undo` игнорируется и считается в «проигнорировано».

Все старые сценарии без `undo` должны давать точно такие же ответы, как раньше. Измени готовую функцию, не пиши её с нуля.

## Аргументы

- `commands` — список непустых строк-команд (может быть пустым).

## Возвращает

Кортеж `(value, applied, ignored)`.

## Правила

- Измени готовый код, а не пиши функцию с нуля.
- Ответы для старых сценариев (без `undo`) не должны измениться.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_rv12_run(["add 5", "sub 2"])                  # -> (3, 2, 0)  как раньше
task_rv12_run(["add 5", "add 3", "undo"])         # -> (5, 3, 0)
task_rv12_run(["undo", "add 1"])                  # -> (1, 1, 1)
```

## Учебные цели

- Проверить правку функции с несколькими ветками так, чтобы старое поведение не сломалось.

## Проверка понимания

Что вернёт `["add 5", "undo", "undo"]` и почему второй `undo` попал в «проигнорировано»?
