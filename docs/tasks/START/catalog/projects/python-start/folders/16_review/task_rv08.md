# Задача RV08: Проверка заказа в лавке

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Напиши функцию `task_rv08_validate_request(request, prices)`: проверь заказ в лавке гильдии и верни ответ.

Проверки идут **строго в таком порядке**, первая сработавшая даёт код отказа:

1. `"no_user"` — в заказе нет ключа `"user"` или имя пустое;
2. `"unknown_item"` — товара `request["item"]` нет в словаре `prices`;
3. `"bad_qty"` — количество `request["qty"]` меньше 1 или больше 10;
4. `"not_enough_gold"` — золота `request["gold"]` меньше, чем цена товара, умноженная на количество.

Если ни одна проверка не сработала, заказ принят.

## Аргументы

- `request` — словарь `{"user": строка, "item": строка, "qty": целое, "gold": целое}`; ключа `"user"` может не быть.
- `prices` — словарь `{товар: цена}`.

## Возвращает

Словарь `{"status": "done", "reason": None}` при успехе или `{"status": "rejected", "reason": код}` при отказе.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
prices = {"sword": 50, "potion": 5}
task_rv08_validate_request({"user": "anna", "item": "potion", "qty": 2, "gold": 20}, prices)
# -> {"status": "done", "reason": None}
task_rv08_validate_request({"user": "anna", "item": "sword", "qty": 2, "gold": 20}, prices)
# -> {"status": "rejected", "reason": "not_enough_gold"}
```

## Учебные цели

- Проверить порядок проверок и отказ как значение с кодом.

## Проверка понимания

Какой код отказа получит заказ без имени пользователя и с неизвестным товаром сразу?
