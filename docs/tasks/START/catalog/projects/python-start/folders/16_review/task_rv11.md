# Задача RV11: Применить правки к профилю

## Условие

Сначала попробуй без теории: это проверка, а не урок.

### Задание

Напиши функцию `task_rv11_apply_changes(profile, changes)`: примени правки по очереди и верни **новый** профиль. Исходный профиль и его список `tags` менять нельзя, а в ответе список `tags` должен быть своим, не общим со входным.

Правка — кортеж одного из трёх видов:

- `("set", поле, значение)` — записать значение в поле `"name"` или `"level"`;
- `("add_tag", тег)` — добавить тег в конец `tags`, если такого ещё нет;
- `("remove_tag", тег)` — убрать тег из `tags`, если он там есть; если нет, ничего не делать.

## Аргументы

- `profile` — словарь `{"name": строка, "level": целое, "tags": список строк}`.
- `changes` — список правок (может быть пустым).

## Возвращает

Новый словарь профиля с применёнными правками.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Входной профиль и его список `tags` должны остаться без изменений.
- Ответ не должен делить изменяемые данные со входом.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
profile = {"name": "Аня", "level": 1, "tags": ["new"]}
task_rv11_apply_changes(profile, [("set", "level", 2), ("add_tag", "dev"), ("remove_tag", "new")])
# -> {"name": "Аня", "level": 2, "tags": ["dev"]}
profile   # -> {"name": "Аня", "level": 1, "tags": ["new"]}  (не изменился)
```

## Учебные цели

- Проверить копию словаря с вложенным списком и применение пакета изменений.
