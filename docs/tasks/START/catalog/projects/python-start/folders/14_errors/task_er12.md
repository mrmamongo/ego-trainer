# Задача ER12: Собери цену с охранными условиями

## Условие

### Как это работает

**Охранное условие** (guard clause) — это `if … return` в самом начале функции: оно сразу отсекает неподходящие данные. Когда все охранные условия пройдены, остаток функции может спокойно делать основную работу.

```python
def discount(price, percent):
    if price < 0:
        return "bad_price"
    if percent < 0:
        return "bad_percent"
    return price - price * percent // 100
```

Без охраны основную работу пришлось бы прятать внутри вложенных `if … else`. С охраной получается плоская лесенка: проверки сверху, работа внизу.

Порядок охранных условий — это порядок ответов: если неверны сразу цена и процент, ответит та проверка, которая стоит выше. Отступы показывают вложенность: `return` стоит под своим `if` на один шаг вправо.

### Задание

В файле задачи записаны строки функции `task_er12_final_price(price, percent)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция проверяет сначала цену, потом процент, и только после этого считает итог.

## Аргументы

- `price` — целое число (может быть отрицательным).
- `percent` — целое число скидки (может быть отрицательным или больше 100).

## Возвращает

- `"bad_price"`, если `price` меньше `0`;
- иначе `"percent_below_0"`, если `percent` меньше `0`;
- иначе `"percent_over_100"`, если `percent` больше `100`;
- иначе итоговая цена `price - price * percent // 100`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Цена проверяется раньше процента: для `price = -5` и `percent = 150` ответ `"bad_price"`.

## Пример

```python
task_er12_final_price(200, 25)    # -> 150
task_er12_final_price(-5, 10)     # -> "bad_price"
task_er12_final_price(100, 101)   # -> "percent_over_100"
```

## Учебные цели

- Собрать функцию из охранных условий и основной работы.
- Увидеть, что порядок охранных условий определяет ответ.

## Проверка понимания

Что вернёт функция для `price = -5` и `percent = 150`? Что изменится, если поставить проверки процента выше проверки цены?
