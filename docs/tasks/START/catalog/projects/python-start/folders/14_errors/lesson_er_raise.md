# raise: бросить исключение самому

Исключения бросает не только Python. Ты можешь сам сказать: «такие данные недопустимы, дальше работать нельзя». Для этого есть `raise`:

```python
def parse_age(text):
    age = int(text)
    if age < 0:
        raise ValueError("меньше нуля")
    return age
```

`parse_age("-3")` не вернёт значение, а бросит `ValueError` с сообщением «меньше нуля». Всё, что стоит после `raise`, не выполняется.

## Заменить чужое сообщение своим

`int("abc")` бросает `ValueError` с длинным английским сообщением. Если нужно своё, ловим и бросаем заново:

```python
def parse_age(text):
    try:
        age = int(text)
    except ValueError:
        raise ValueError("не число")
    if age < 0:
        raise ValueError("меньше нуля")
    return age
```

Теперь у функции три выхода: возраст или `ValueError` с одним из сообщений. Это её **договор**: кто вызывает `parse_age`, знает, какие ошибки ждать.

## Бросить или вернуть значение по умолчанию?

| Ситуация | Что лучше |
|---|---|
| ошибка ожидаема, и вызывающему всё равно (`safe_int("abc", 0)`) | вернуть значение по умолчанию |
| данные неверны, и дальше с ними работать нельзя | бросить исключение |
| нужно объяснить пользователю, что не так | исключение с понятным сообщением |

Значение по умолчанию **прячет** ошибку. Для ввода пользователя иногда это нормально («не вышло, возьму 0»), а для денег и ID — нет: тихое `0` вместо суммы хуже ошибки.

## Частые ошибки

Бросить `Exception("плохо")` без смысла: сообщение должно говорить, **что именно** не так и (по возможности) с каким значением.

Вернуть строку `"error"` вместо `raise`: вызывающий может не заметить её и посчитать как результат. Исключение пропустить нельзя.

## Проверь себя

```python
def percent(part, total):
    if total <= 0:
        raise ValueError("всего должно быть больше нуля")
    return part * 100 // total
```

1. Что вернёт `percent(1, 4)`?
2. Что произойдёт при `percent(1, 0)`?

<details><summary>Ответ</summary>

1. `25`.
2. Функция бросит `ValueError("всего должно быть больше нуля")` и ничего не вернёт.

</details>
