# Задача ER06: Возраст с понятными ошибками

## Условие

### Как это работает

Функция может не только **вернуть** значение, но и **бросить** исключение командой `raise`. Тогда вызывающий узнаёт, что именно не так, по типу и сообщению:

```python
def parse_level(text):
    try:
        level = int(text)
    except ValueError:
        raise ValueError("не число")      # заменяем чужое сообщение своим
    if level < 1:
        raise ValueError("меньше единицы")
    return level
```

| Вызов | Результат |
|---|---|
| `parse_level("3")` | вернёт `3` |
| `parse_level("abc")` | бросит `ValueError("не число")` |
| `parse_level("0")` | бросит `ValueError("меньше единицы")` |

Проверки идут по порядку, и первая сработавшая бросает исключение.

Чтобы тест мог увидеть исключение, функция задачи `task_er06_age` вызывает `parse_age` через помощника `given_capture(fn, *args)`: он вернёт либо результат, либо `["error", "ТипОшибки", "сообщение"]`. Помощник уже написан, не меняй его.

### Задание

Напиши функцию `parse_age(text)`: она возвращает возраст (целое число) или **бросает** `ValueError` с одним из сообщений:

- `"не число"`, если `text` нельзя превратить в целое число;
- `"меньше нуля"`, если возраст отрицательный;
- `"больше 150"`, если возраст больше 150.

Функцию `task_er06_age` менять не нужно.

## Аргументы

- `text` — строка (может быть пустой, дробной, с пробелами по краям).

## Возвращает

`task_er06_age(text)` возвращает возраст или список `["error", "ValueError", "<сообщение>"]`.

## Правила

- Ошибки бросай командой `raise ValueError("...")`, а не возвращай текст.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Текст сообщений должен совпадать с условием слово в слово.

## Пример

```python
task_er06_age("25")     # -> 25
task_er06_age("abc")    # -> ["error", "ValueError", "не число"]
task_er06_age("-3")     # -> ["error", "ValueError", "меньше нуля"]
task_er06_age("200")    # -> ["error", "ValueError", "больше 150"]
```

## Учебные цели

- Бросать исключение с нужным типом и сообщением.
- Заменять сообщение чужой ошибки своим.

## Проверка понимания

Почему `"-3"` получает сообщение «меньше нуля», а не «не число»? Что вернёт `task_er06_age("150")` и почему не ошибку?
