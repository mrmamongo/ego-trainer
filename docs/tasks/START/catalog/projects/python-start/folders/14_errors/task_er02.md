# Задача ER02: Ошибка в цикле: try вокруг шага или вокруг цикла

## Условие

### Как это работает

Где поставить `try`, зависит от того, что должно случиться после ошибки. Сравни два способа обработать список строк:

```python
total = 0
for text in ["4", "x", "6"]:
    try:
        total = total + int(text)    # try вокруг ОДНОГО шага
    except ValueError:
        total = total + 100
```

Ошибка на `"x"` ловится внутри прохода, и цикл идёт дальше: считаются все три элемента.

```python
total = 0
try:
    for text in ["4", "x", "6"]:     # try вокруг ВСЕГО цикла
        total = total + int(text)
except ValueError:
    total = total + 100
```

Ошибка на `"x"` выбрасывает из цикла целиком: после `except` цикл не продолжится, и `"6"` уже не обработается.

| Где `try` | Что после ошибки |
|---|---|
| вокруг одного прохода | цикл продолжается со следующего элемента |
| вокруг всего цикла | цикл прерван, остальные элементы пропущены |

### Задание

Открой файл задачи. В нём два способа на одних и тех же данных. Впиши вместо каждого `None` ответ: `total_a_iter_2` и `total_a_final` — значения `total_a` после 2-го прохода и после всего цикла в первом способе, `total_b_final` — итог второго способа, `last_text` — какое значение имеет переменная `text` после второго цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Составь таблицу по проходам: что прибавили на каждом.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_er02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, что `try` вокруг одного прохода не прерывает цикл.
- Видеть, что `try` вокруг цикла прерывает его на первой ошибке.
