# Задача ER17: Первая плохая запись в тексте

## Условие

### Как это работает

Текст из нескольких строк часто содержит записи вида `имя;возраст`. Чтобы найти первую плохую, нужно пройти по строкам и для каждой выполнить проверки. Готовая функция `given_parse_age(text)` из файла задачи (та же, что в задаче ER06) возвращает возраст или **бросает** `ValueError` с сообщением. Сообщение ты достаёшь через `as`:

```python
try:
    age = given_parse_age("abc")
except ValueError as error:
    message = str(error)       # "не число"
```

Номер строки считают с единицы: `index + 1`, если идёшь по `range(len(lines))`. Пустые строки пропускают, но в нумерации они **считаются**.

### Задание

Напиши функцию `task_er17_first_error_line(text)`. Текст разбей на строки методом `split("\n")`. Каждая непустая строка (пустой считается и строка из одних пробелов) должна быть записью `имя;возраст`. Найди **первую** плохую строку и верни кортеж `(номер строки, сообщение)`. Проверки одной строки идут в таком порядке:

1. Если после разбиения по `;` частей не две — сообщение `"ожидается имя;возраст"`.
2. Если имя пустое после `strip()` — сообщение `"пустое имя"`.
3. Если `given_parse_age(возраст)` бросила `ValueError` — сообщение этой ошибки (`"не число"`, `"меньше нуля"`, `"больше 150"`).

Если все записи хорошие (или текст пуст), верни `None`.

## Аргументы

- `text` — строка из нескольких строк, разделённых `"\n"` (может быть пустой).

## Возвращает

Кортеж `(номер строки с единицы, сообщение)` или `None`.

## Правила

- Для разбора возраста используй `given_parse_age`, не переписывай её.
- Остановись на первой плохой записи: дальше текст можно не смотреть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_er17_first_error_line("Аня;20\nБоря;30")                 # -> None
task_er17_first_error_line("Аня;20\nБоря;abc\nВера;-1")       # -> (2, "не число")
task_er17_first_error_line("Аня;20\n\nБоря")                  # -> (3, "ожидается имя;возраст")
```

## Учебные цели

- Достать сообщение исключения через `except … as error`.
- Нумеровать строки с единицы и учитывать пустые.

## Проверка понимания

Почему в третьем примере номер равен `3`, хотя пустая строка пропускается? Что вернёт функция для `";20"`?
