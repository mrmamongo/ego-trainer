# Задача ER05: Деление без падения

## Условие

### Как это работает

Деление на ноль бросает `ZeroDivisionError`. Ожидаемую ошибку ловят по типу, а остальные не трогают:

```python
def average(total, count):
    try:
        return total / count
    except ZeroDivisionError:
        return 0
```

| Вызов | Что произойдёт |
|---|---|
| `average(10, 4)` | `10 / 4`, вернётся `2.5` |
| `average(10, 0)` | `10 / 0` бросит `ZeroDivisionError`, вернётся `0` |

В `try` положили только одну строку: так в `except` не попадёт чужая ошибка.

### Задание

Напиши функцию `task_er05_safe_divide(a, b)`: она возвращает `a / b`, а при делении на ноль — текст `"деление на ноль"`.

## Аргументы

- `a`, `b` — целые числа (`b` может быть нулём).

## Возвращает

Результат `a / b` (число с точкой) или строку `"деление на ноль"`.

## Правила

- Решай через `try` и `except ZeroDivisionError`; условия `if` и `a if cond else b` в этой задаче не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_er05_safe_divide(10, 2)   # -> 5.0
task_er05_safe_divide(7, 2)    # -> 3.5
task_er05_safe_divide(5, 0)    # -> "деление на ноль"
```

## Учебные цели

- Ловить `ZeroDivisionError` вместо предварительной проверки.
- Возвращать понятный текст вместо падения.

## Проверка понимания

Что вернёт `task_er05_safe_divide(0, 5)`? Чем отличается деление `0 / 5` от `5 / 0`?
