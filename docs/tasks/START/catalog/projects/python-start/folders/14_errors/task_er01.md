# Задача ER01: Что выполнится: try, except, else, finally

## Условие

### Как это работает

Блок `try` выполняется, пока не случится ошибка. Дальше Python выбирает, какие части сработают:

```python
log = ""                    # 1
try:                        # 2
    log = log + "a"         # 3
    n = int("7")            # 4
except ValueError:          # 5
    log = log + "b"         # 6
else:                       # 7
    log = log + "c"         # 8
finally:                    # 9
    log = log + "d"         # 10
```

| Часть | Выполняется |
|---|---|
| `try` | до первой ошибки |
| `except ValueError` | только если в `try` была `ValueError` |
| `else` | только если в `try` ошибки **не было** |
| `finally` | всегда |

Здесь ошибки нет: сработают строки 3, 4, 8 и 10, и в `log` будет `"acd"`. Если бы в строке 4 стояло `int("x")`, строка 4 бросила бы ошибку, остаток `try` пропустился бы, и сработали бы `except` и `finally`: `log` стал бы `"abd"`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ: `True` или `False` для вопроса «выполнилась ли строка?» и строку в кавычках для `log_final`.

**Сначала реши в голове или на бумаге, код не запускай.** Для каждой части реши: что бросит строка 4 и какие блоки сработают.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_er01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, в каком порядке работают `try`, `except`, `else` и `finally`.
- Видеть, что остаток `try` после ошибки пропускается.
