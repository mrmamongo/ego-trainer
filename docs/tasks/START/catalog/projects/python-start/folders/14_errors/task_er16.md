# Задача ER16: Повтор при временной ошибке

## Условие

### Как это работает

Некоторые ошибки временные: сервер не успел ответить (`"timeout"`), и вторая попытка может получиться. Другие постоянные: доступ запрещён (`"forbidden"`), и повторять бессмысленно. Простое правило:

| Исход попытки | Что делать |
|---|---|
| `"ok"` | остановиться, всё получилось |
| `"timeout"` | повторить, если попытки ещё остались |
| любая другая ошибка | остановиться, повтор не поможет |

В реальной программе попытка — вызов сети, а между попытками ждут. Здесь мы **ничего не вызываем и не ждём**: исходы попыток уже лежат в списке `fn_results` и берутся по порядку, как будто это ответы по очереди.

```python
def first_ok(outcomes, limit):
    attempts = 0
    while attempts < limit:
        outcome = outcomes[attempts]    # исход следующей попытки
        attempts = attempts + 1         # попытку потратили
        if outcome == "ok":
            return attempts, outcome
    return attempts, "no_ok"
```

Попытки считают тем же приёмом, что и в цикле с накопителем: счётчик растёт на каждой попытке, а цикл останавливается либо по условию, либо досрочным `return`.

### Задание

Напиши функцию `task_er16_retry(fn_results, max_attempts)`. Она берёт исходы из `fn_results` по порядку, не больше `max_attempts` штук:

- получила `"ok"` — остановиться, исход `"ok"`;
- получила `"timeout"` — потратить попытку и продолжить, если попыток ещё хватает;
- получила другую ошибку — остановиться сразу, исход равен этой ошибке.

Верни кортеж `(сколько попыток потрачено, итоговый исход)`. Если все попытки закончились на `"timeout"`, итоговый исход `"timeout"`.

## Аргументы

- `fn_results` — список строк-исходов (`"ok"`, `"timeout"`, `"forbidden"` и так далее); его длина не меньше `max_attempts`.
- `max_attempts` — целое число, не меньше `1`.

## Возвращает

Кортеж `(attempts, outcome)`.

## Правила

- Смотри на исход номер `attempts` (счёт с нуля) только пока `attempts < max_attempts`.
- Входной список не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_er16_retry(["ok"], 3)                           # -> (1, "ok")
task_er16_retry(["timeout", "timeout", "ok"], 3)     # -> (3, "ok")
task_er16_retry(["timeout", "forbidden", "ok"], 3)   # -> (2, "forbidden")
task_er16_retry(["timeout", "timeout"], 2)           # -> (2, "timeout")
```

## Учебные цели

- Различать временные и постоянные ошибки.
- Считать попытки и вовремя останавливаться.
