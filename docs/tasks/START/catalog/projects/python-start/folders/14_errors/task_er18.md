# Задача ER18: Все проблемы профиля

## Условие

### Как это работает

В задаче ER08 функция останавливалась на **первой** проблеме. Для формы с несколькими полями так неудобно: человек исправит одно поле, отправит снова и узнает про второе. Поэтому здесь нужны **все** проблемы сразу. Вместо `return` на первой найденной проблеме проблемы **собирают** в список (роль «сборщик» из папки про циклы), а в конце возвращают весь список:

```python
def check_card(card):
    problems = []
    if "title" not in card:
        problems.append("title: missing")
    if "hp" in card and card["hp"] < 0:
        problems.append("hp: out_of_range")
    return sorted(problems)
```

Каждая проблема записана строкой `путь: код`. Для вложенных данных путь идёт через точку: поле `city` внутри словаря `address` — это `address.city`. Если вложенного словаря нет вовсе, нет смысла проверять его поля: достаточно одной проблемы `address: missing`.

Коды проблем одного вида полей:

| Код | Когда |
|---|---|
| `missing` | ключа нет |
| `wrong_type` | тип значения не тот |
| `empty` | строка пустая (после `strip()`) |
| `out_of_range` | число вне допустимых границ |
| `bad_format` | значение неверного вида |

Итоговый список сортируют функцией `sorted(...)`: так порядок не зависит от порядка проверок.

### Задание

Напиши функцию `task_er18_validate_profile(profile)`. Профиль — словарь. Проверь поля и верни **отсортированный** список всех проблем в виде строк `"путь: код"` (пустой список, если профиль хороший):

- `name` — обязательна строка, не пустая после `strip()`. Проблемы: `name: missing`, `name: wrong_type`, `name: empty`.
- `age` — обязательно целое число (`bool` не считается числом) от `0` до `150`. Проблемы: `age: missing`, `age: wrong_type`, `age: out_of_range`.
- `address` — обязателен словарь. Проблемы: `address: missing`, `address: wrong_type`. Если это словарь, проверь внутри:
  - `address.city` — как `name`: `address.city: missing`, `address.city: wrong_type`, `address.city: empty`;
  - `address.zip` — обязательна строка ровно из 6 цифр. Проблемы: `address.zip: missing`, `address.zip: wrong_type`, `address.zip: bad_format`.
- `email` — необязателен; если ключ есть, то строка с символом `@`. Проблемы: `email: wrong_type`, `email: bad_format`.

## Аргументы

- `profile` — словарь с произвольным содержимым.

## Возвращает

Список строк, отсортированный по алфавиту; `[]` для хорошего профиля.

## Правила

- Профиль не меняй.
- Возвращай **все** найденные проблемы, а не только первую.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
good = {"name": "Аня", "age": 20, "address": {"city": "Омск", "zip": "644000"}}
task_er18_validate_profile(good)    # -> []

bad = {"name": " ", "age": 200, "address": {"city": "Омск"}}
task_er18_validate_profile(bad)
# -> ["address.zip: missing", "age: out_of_range", "name: empty"]
```

## Учебные цели

- Собирать все проблемы вместо остановки на первой.
- Записывать путь к вложенному полю через точку.
