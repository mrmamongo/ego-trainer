# Разбор команды: из текста в команду и аргументы

Пользователь вводит строку целиком: `add 120 кафе`. Программе нужны её части: **что** сделать (`add`) и **с чем** (`120`, `кафе`). Поиск этих частей называют **разбором** (парсингом).

## strip → split → lower

| Шаг | Код | Для `"  Add 120 кафе  "` |
|---|---|---|
| 1. убрать пробелы по краям | `line.strip()` | `"Add 120 кафе"` |
| 2. разрезать по пробелам | `... .split()` | `["Add", "120", "кафе"]` |
| 3. команду в маленькие буквы | `words[0].lower()` | `"add"` |

```python
def parse_command(line):
    words = line.strip().split()
    if len(words) == 0:
        return ["", []]
    return [words[0].lower(), words[1:]]
```

Первое слово — команда, всё остальное — **аргументы**. `words[1:]` — срез: список без первого элемента.

| Строка | `parse_command` вернёт |
|---|---|
| `"add 120 кафе"` | `["add", ["120", "кафе"]]` |
| `"  TOTAL  "` | `["total", []]` |
| `"   "` | `["", []]` |
| `"add"` | `["add", []]` |

## Проверка числа: isdigit

Всё, что пришло из `split()`, — **строки**. Число из текста получают через `int(...)`, но только после проверки: `int("abc")` завершится ошибкой и программа упадёт.

```python
if amount_text.isdigit():
    amount = int(amount_text)
```

| Текст | `isdigit()` | почему |
|---|---|---|
| `"120"` | `True` | все символы — цифры |
| `"-5"` | `False` | минус не цифра |
| `"3.5"` | `False` | точка не цифра |
| `"abc"` | `False` | буквы |

Дальше проверяют ещё и смысл: сумма должна быть **больше нуля**. `"0".isdigit()` равно `True`, но `0` — не расход. Поэтому условие: `if text.isdigit() and int(text) > 0`.

## Защитный порядок проверок

Сначала проверяем то, чего может **не быть** (нет аргумента), потом то, что можно проверить, только если аргумент есть:

```python
if len(args) < 1:                       # аргумента нет
    return "Сумма должна быть целым числом больше нуля"
text = args[0]
if not text.isdigit() or int(text) <= 0:     # есть, но не число больше нуля
    return "Сумма должна быть целым числом больше нуля"
```

Если поменять порядок и обратиться к `args[0]`, когда список пуст, получится ошибка `IndexError`.

## Пример целиком: трассировка проверки

Команда `add 0 кафе` доходит до ветки `add` одна за другой по строкам:

| Шаг | Проверка | Результат для `add 0 кафе` | Дальше |
|---|---|---|---|
| 1 | `len(args) < 1` | `2 < 1` → `False` | идём вниз |
| 2 | `not args[0].isdigit()` | `"0".isdigit()` → `True`, значит `not` → `False` | сравниваем вторую часть |
| 3 | `int(args[0]) == 0` | `0 == 0` → `True` | `return "Сумма должна быть целым числом больше нуля"` |
| 4 | `len(args) < 2` | не выполняется — вернулись на шаге 3 | — |
| 5 | `entries.append(...)` | не выполняется — вернулись на шаге 3 | — |

Для `add 120 кафе` тот же путь даёт на шаге 3 `120 == 0` → `False`, поэтому программа проходит дальше и записывает расход.

## Частые ошибки

Забыть, что `split()` даёт строки, и сложить со числом:

```python
total = total + args[0]         # неверно: str и int вместе — TypeError
total = total + int(args[0])    # верно
```

Проверять команду без `lower()`: `"Add 120 кафе"` не совпадёт с `"add"`.

Вызывать `int` до проверки: `int("x")` падает, а не возвращает `0`.

## Проверь себя

```python
words = "  PUT 7 Наличные ".strip().split()
```

1. Что равно `words`?
2. Что вернёт `words[0].lower()` и `words[1:]`?
3. Подходит ли `words[1]` под `isdigit()`?

<details><summary>Ответ</summary>

1. `["PUT", "7", "Наличные"]`.
2. `"put"` и `["7", "Наличные"]`.
3. Да: `"7"` состоит только из цифр.

</details>
