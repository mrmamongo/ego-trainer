# Задача PX05: Отмена последнего расхода

## Условие

### Как это работает

Пользователь часто ошибается и хочет убрать **последний** расход. У списка для этого есть метод `pop()` (папка 08, карточка `li-methods`):

```python
entries = [[120, "кафе"], [80, "такси"]]
last = entries.pop()         # last = [80, "такси"], entries = [[120, "кафе"]]
```

`pop()` **без индекса** убирает последний элемент и возвращает его. Если список пуст, `pop()` падает с ошибкой — поэтому сначала проверяем длину:

```python
if len(entries) == 0:                  # 1
    return "Нечего отменять"           # 2
entry = entries.pop()                  # 3: убрали с конца и запомнили
return f"Отменил: {entry[0]} ₽ — {entry[1]}"   # 4
```

Из ответа видно, что именно отменилось: сумма и категория берутся из `entry`, а не из начала списка. Для пустого списка `len(entries) == 0` — ответ `Нечего отменять`.

Отмена действует только на `entries`: после `undo` команды `total` и `report` считают уже **без** отменённого расхода.

Пункт `undo` уже стоит в справке `HELP_TEXT` в блоке «готово с прошлого шага».

**Что меняется по сравнению с прошлым шагом (PX04):** в `handle` перед строкой справки появляется ветка `undo`. `report` не меняется — и он сам честно перестаёт показывать отменённое. Сценарии прошлых шагов должны отвечать как раньше.

### Задание

Допиши ветку `undo` в `handle`: отменить последний расход и вернуть, что отменено; если расходов нет — `Нечего отменять`.

## Аргументы

- `lines` — список строк-команд сценария (может быть пустым).

## Возвращает

`task_px05_session` — список ответов. Для `undo` — `Отменил: <сумма> ₽ — <категория>` (значения последнего расхода), для пустых расходов — `Нечего отменять`.

## Правила

- Меняй только `handle`; готовый код и цикл не трогай.
- Функция должна **вернуть** строку через `return`, а не печатать её.
- Используй `pop()` без индекса; `del` и `remove` не нужны.
- Список `entries` после отмены должен стать короче на один элемент.

## Пример

```python
task_px05_session(["undo"])                                   # -> ['Нечего отменять']
task_px05_session(["add 120 кафе", "add 80 такси", "undo"])   # -> ['…', '…', 'Отменил: 80 ₽ — такси']
task_px05_session(["add 120 кафе", "undo", "total"])          # -> ['…', 'Отменил: 120 ₽ — кафе', 'Всего: 0 ₽']
```

## Учебные цели

- Убирать элемент с конца списка методом `pop()` и использовать его значение.
- Проверять `len` перед `pop`, чтобы программа не упала на пустом списке.
