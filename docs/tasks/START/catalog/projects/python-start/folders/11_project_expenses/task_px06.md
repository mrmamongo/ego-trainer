# Задача PX06: Отчёт: сначала дорогие и с процентами

## Условие

### Как это работает

Старый `report` выводил категории в порядке появления и без долей. Новый отчёт нужен, чтобы сразу видеть, **куда уходит больше всего**. Две правки (папка 09, карточка `fd-modify`): порядок строк и формат строки.

**Порядок: по сумме, от большей к меньшей.** Сначала собираем итоги по каждой категории, а потом сортируем пары «категория — сумма». Встроенные `sorted` и `sort` здесь не подходят: в нашей паре `[сумма, категория]` нужно сравнивать только сумму, а обработку ключа (`key=`) в курсе ещё не проходили. Поэтому сортируем своими циклами обмена:

```python
for i in range(len(sums)):                 # 1: каждая позиция списка
    for j in range(i + 1, len(sums)):      # 2: со всеми справа
        if sums[j] > sums[i]:              # 3: справа больше
            sums[i], sums[j] = sums[j], sums[i]     # 4: меняем местами суммы
            order[i], order[j] = order[j], order[i] # 5: и категории тоже
```

Обменивать надо **обе** пары данных одновременно — и суммы, и категории. Иначе суммы переставятся, а названия останутся на месте.

**Равные суммы остаются в порядке появления:** условие `sums[j] > sums[i]` строгое, поэтому равные не меняются местами.

**Формат строки:** `кафе: 150 ₽ (65%)`. Долю считают от общей суммы: `round(amount * 100 / total)` — это число, которое f-строка напечатает как `65`. Итоговая строка `Итого: …` остаётся последней.

Пример для такси 150, кафе 100, еда 60 (всего 310): такси 48%, кафе 32%, еда 19%.

**Что меняется по сравнению с прошлым шагом (PX05):** меняется только ветка `report`. Ответы `add`, `total`, `undo`, `help` и «Расходов пока нет» остаются как были. Сценарии прошлых шагов (кроме старого вида отчёта) должны отвечать как раньше.

### Задание

Измени ветку `report`: сортируй категории по сумме по убыванию (равные — в порядке появления) и выводи долю в процентах. Остальное не меняй.

## Аргументы

- `lines` — список строк-команд сценария (может быть пустым).

## Возвращает

`task_px06_session` — список ответов. Для `report` — строка с переводами строки: по строке `категория: сумма ₽ (процент%)` на категорию, по сумме от большей к меньшей, затем `Итого: сумма ₽`. Процент — целое число, округлённое до ближайшего (`round`). Без расходов — `Расходов пока нет`.

## Правила

- Меняй только ветку `report` в `handle`; остальные команды и цикл не трогай.
- Функция должна **вернуть** строку через `return`, а не печатать её.
- Встроенные `sorted`, `sort`, `sum`, `max` не используй: сортируй циклами обмена.
- Процент округляй встроенным `round`; число в скобках пиши без дробной части.

## Пример

```python
task_px06_session(["add 150 кафе", "add 80 такси", "report"])
# -> ['…', '…', 'кафе: 150 ₽ (65%)\nтакси: 80 ₽ (35%)\nИтого: 230 ₽']
task_px06_session(["add 100 еда", "add 100 кафе", "report"])
# -> ['…', '…', 'еда: 100 ₽ (50%)\nкафе: 100 ₽ (50%)\nИтого: 200 ₽']
```

## Учебные цели

- Отсортировать пары «ключ — значение» своими циклами обмена, не теряя связь между ними.
- Форматировать проценты через `round` внутри f-строки.
