# Задача PX04: Отчёт по категориям

## Условие

### Как это работает

Новая команда `report` печатает, сколько ушло на каждую категорию, а в конце — сколько всего. Каждая строка отчёта — f-строка `f"{category}: {amount} ₽"` (урок `px-report`), а строки склеиваются через `"\n".join(lines)`.

Порядок категорий в отчёте — **первое появление** в списке расходов. Его собирают двумя циклами:

```python
order = []                                  # 1: сборщик категорий
for entry in entries:
    if entry[1] not in order:               # 2: такая категория ещё не встречалась
        order.append(entry[1])
```

`entries` — список пар `[сумма, категория]`, категория лежит по индексу `1`. Для `[[100, "кафе"], [50, "еда"], [30, "кафе"]]` получится `["кафе", "еда"]`. Один сборщик `order` даёт **и** порядок, **и** список категорий — второй список заводить не нужно.

Итоги считают так: для каждой категории из `order` пробегаем по всем расходам и складываем подходящие суммы, а `total` — сумма всех расходов, как в `total`-команде.

| Категория | проход по `entries` | сумма |
|---|---|---|
| кафе | 100 подходит, 50 нет, 30 подходит | 130 |
| еда | 100 нет, 50 подходит, 30 нет | 50 |

Если расходов нет, отчёт пустой, поэтому ответ будет `Расходов пока нет` — проверка стоит до всех циклов.

Пункт `report` уже стоит в справке `HELP_TEXT` в блоке «готово с прошлого шага», но пока отвечает «Не понимаю команду.» — его и надо сделать настоящим.

**Что меняется по сравнению с прошлым шагом (PX03):** в `handle` перед строкой справки появляется ветка `report`. Другие команды не меняются. Сценарии прошлых шагов должны отвечать как раньше: `add` с проверками, `total`, `help` (справка уже с пунктом `report`).

### Задание

Напиши ветку `report` в `handle`: отчёт по категориям в порядке первого появления, затем `Итого: …`. Остальное не меняй.

## Аргументы

- `lines` — список строк-команд сценария (может быть пустым).

## Возвращает

`task_px04_session` — список ответов. Для `report` — одна строка с переводами строки внутри: по строке `категория: сумма ₽` на каждую категорию в порядке первого появления и последняя строка `Итого: сумма ₽`; без расходов — `Расходов пока нет`.

Пример ответа на `report` для кафе 150 и такси 80:

```
кафе: 150 ₽
такси: 80 ₽
Итого: 230 ₽
```

## Правила

- Меняй только `handle`; готовый код и цикл не трогай.
- Функция должна **вернуть** строку через `return`, а не печатать её.
- Встроенные `sum`, `sorted` и `count` не используй: итоги считай циклом и накопителем.
- Строки склеивай через `"\n".join(...)`; в конце ответа лишнего перевода строки нет.

## Пример

```python
task_px04_session(["report"])                 # -> ['Расходов пока нет']
task_px04_session(["add 80 еда", "add 150 кафе", "report"])
# -> ['Записал: 80 ₽ — еда', 'Записал: 150 ₽ — кафе', 'еда: 80 ₽\nкафе: 150 ₽\nИтого: 230 ₽']
```

## Учебные цели

- Собрать порядок категорий сборщиком с проверкой `not in`.
- Строить отчёт циклами и склеивать строки через `"\n".join(...)`.

## Проверка понимания

Какой отчёт будет для расходов `[[100, "кафе"], [50, "еда"], [30, "кафе"]]`? Почему `order` один, а не два списка «категории» и «порядок»?
