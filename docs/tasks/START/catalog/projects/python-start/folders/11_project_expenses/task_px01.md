# Задача PX01: Первая команда: add

## Условие

### Как это работает

Начинаем программу **«учёт расходов»**. Пользователь вводит команды, программа печатает ответы. Память программы — список `entries`, в нём каждый расход записан парой `[сумма, категория]`:

```python
entries = [[120, "кафе"], [50, "еда"]]
```

Первая команда — `add <сумма> <категория>`. Ей нужны две части: **разбор** строки (урок `px-parsing`) и **handle**, который разбор применяет.

```python
def parse_command(line):                     # 1
    words = line.strip().split()             # 2
    if len(words) == 0:                      # 3
        return ["", []]                      # 4
    return [words[0].lower(), words[1:]]     # 5
```

| Строка | 2: `words` | 5: результат |
|---|---|---|
| `"add 120 кафе"` | `["add", "120", "кафе"]` | `["add", ["120", "кафе"]]` |
| `"  ADD 80 такси "` | `["ADD", "80", "такси"]` | `["add", ["80", "такси"]]` |
| `""` | `[]` | `["", []]` |

`strip()` убирает пробелы по краям, `split()` режет на слова, `lower()` делает команду маленькой, а `words[1:]` берёт всё после команды — это аргументы. Пустая строка даёт команду `""`; такой команды не бывает, поэтому `handle` ответит «не понимаю».

Теперь `handle(entries, line)`:

```python
def handle(entries, line):
    command, args = parse_command(line)
    if command == "add":
        entries.append([int(args[0]), args[1]])       # состояние изменилось на месте
        return f"Записал: {args[0]} ₽ — {args[1]}"    # ответ — строка
    return "Не понимаю команду. Напиши help."
```

Тире в ответе — длинное тире `—`, перед ним и после него по пробелу: `Записал: 120 ₽ — кафе`.

**Цикл программы уже готов** внизу файла (`main` и `if __name__ == "__main__": main()`). Его не трогай: он просто вызывает `handle` для каждой введённой строки. Проверка вызывает `handle` прямо через `task_px01_session(lines)`: она заводит `entries = []`, по очереди отправляет строки в `handle` и собирает ответы. Так проверяются **сценарии** — ответы на несколько команд подряд.

### Задание

Напиши `parse_command(line)` и `handle(entries, line)`: команда `add` записывает расход и отвечает, любая другая строка — «Не понимаю команду. Напиши help.». Функция `task_px01_session` уже собрана, менять её не нужно.

## Аргументы

- `lines` — список строк-команд тестового сценария (может быть пустым).
- `parse_command` получает одну строку `line`.
- `handle` получает список `entries` и одну строку `line`.

## Возвращает

`parse_command` — список `[команда, аргументы]`, где команда — строка маленькими буквами, аргументы — список строк; для строки без слов — `["", []]`.

`handle` — строку-ответ. Для `add` — `Записал: <сумма> ₽ — <категория>`, для всего остального — `Не понимаю команду. Напиши help.`.

`task_px01_session` — список ответов, по одному на каждую строку.

## Правила

- Меняй только тела `parse_command` и `handle`; `task_px01_session`, `main` и `if __name__ == "__main__": main()` не трогай.
- Функции должны **вернуть** значение через `return`, а не печатать его.
- В этой задаче не проверяй, правильно ли записана сумма: для `add` всегда приходят ровно два аргумента.
- Если команда не `add`, строку `add` не угадывай — ответ «Не понимаю команду.» правильный.

## Пример

```python
task_px01_session(["add 120 кафе"])                       # -> ['Записал: 120 ₽ — кафе']
task_px01_session(["add 120 кафе", "add 50 еда"])         # -> ['Записал: 120 ₽ — кафе', 'Записал: 50 ₽ — еда']
task_px01_session(["total"])                              # -> ['Не понимаю команду. Напиши help.']
task_px01_session([])                                     # -> []
```

## Учебные цели

- Разобрать строку команды на имя и аргументы методами строк.
- Понять форму программы: `handle(entries, line)` меняет общий список и возвращает ответ.

## Проверка понимания

Что вернёт `parse_command("  ")` и почему `handle` в ответ не упадёт? Зачем `handle` нужен `entries`, если ответ — строка?
