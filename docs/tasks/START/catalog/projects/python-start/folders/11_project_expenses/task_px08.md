# Задача PX08: Целиком: учёт расходов

## Условие

### Как это работает

Это **итоговая задача проекта**: здесь нечего дорисовывать, нужно собрать программу заново — весь разбор строки и всех команд в одном `handle`. Так проходит проверка: если получилось собрать с нуля и все старые сценарии проходят, материал усвоен.

Проверялка показывает этот список команд как проверку без подсказок: у части сценариев ожидаемый ответ скрыт (`<скрыто>`), поэтому сначала считай ответ сам, а потом запускай проверку.

Устройство то же, что в шагах PX01–PX07. Память — два живых списка:

```python
entries = [[120, "кафе"], [50, "еда"]]          # расходы: [сумма, категория]
limits = [["кафе", 100], ["такси", 300]]        # лимиты: [категория, лимит]
```

`entries` и `limits` передаются в `handle` и меняются на месте. Цикл `main` и `task_px08_session` уже готовы и создают оба списка — писать нужно только `parse_command` и `handle`.

Разбор строки:

```python
words = line.strip().split()
if len(words) == 0:
    return ["", []]
return [words[0].lower(), words[1:]]
```

| Строка | `words` | результат |
|---|---|---|
| `"add 120 кафе"` | `["add", "120", "кафе"]` | `["add", ["120", "кафе"]]` |
| `"  ADD 80 такси "` | `["ADD", "80", "такси"]` | `["add", ["80", "такси"]]` |
| `""` | `[]` | `["", []]` |

| Команда | Что делает | Ответ |
|---|---|---|
| `add <сумма> <категория>` | проверить сумму (`isdigit()`, больше `0`), проверить категорию, записать `[сумма, категория]` | `Записал: 120 ₽ — кафе` |
| `total` | сложить все расходы | `Всего: 200 ₽` |
| `report` | итоги по категориям: по сумме от большей к меньшей, равные — в порядке появления, с долей `round(amount * 100 / total)` | `кафе: 150 ₽ (65%)\nтакси: 80 ₽ (35%)\nИтого: 230 ₽` |
| `undo` | убрать последний расход (`pop()`) | `Отменил: 80 ₽ — такси` |
| `limit <категория> <сумма>` | поставить или заменить лимит категории | `Лимит на кафе: 100 ₽` |
| `help` | справка с теми же названиями команд | текст ниже |
| другая | неизвестная команда | `Не понимаю команду. Напиши help.` |

Ответы на ошибки:

| Ситуация | Ответ |
|---|---|
| суммы нет, она не число или равна `0` | `Сумма должна быть целым числом больше нуля` |
| у `add` есть сумма, но нет категории | `Укажи категорию` |
| у `limit` меньше двух аргументов | `Укажи категорию и сумму лимита` |
| у `limit` сумма не число или `0` | `Сумма должна быть целым числом больше нуля` |
| `undo` без расходов | `Нечего отменять` |
| `report` без расходов | `Расходов пока нет` |

`HELP_TEXT` — ровно такой текст (это один ответ с переводами строки):

```
Команды:
add <сумма> <категория> — записать расход
total — сколько потрачено
report — отчёт по категориям
undo — отменить последний расход
limit <категория> <сумма> — поставить лимит на категорию
help — эта справка
exit — выйти
```

**Предупреждение о лимите.** После успешного `add` программа считает, сколько уже потрачено на эту категорию. Если есть лимит и сумма больше лимита, ответ становится двумя строками: `Записал: …` и второй строкой `Внимание: лимит на кафе превышен на 30 ₽` (на сколько именно больше). Ровно лимит — это ещё не превышение.

Список категорий для отчёта собирается через `not in`, суммы — накопителем, сортировка — двумя циклами обмена, где переставляются **и** суммы, **и** категории. Встроенные `sum`, `sorted`, `max` использовать нельзя.

### Задание

Напиши `parse_command` и `handle` со всеми семью ответами: `add` (с проверками и предупреждением о лимите), `total`, `report`, `undo`, `limit`, `help` и ответ на неизвестную команду. Готовый цикл и `task_px08_session` не трогай.

## Аргументы

- `entries` — список расходов `[сумма, категория]` (изменяется на месте).
- `limits` — список лимитов `[категория, лимит]` (изменяется на месте).
- `lines` — список строк-команд сценария (может быть пустым).

## Возвращает

`task_px08_session` — список ответов, по одному на каждую команду, в форматах из таблицы выше. Многострочные ответы (`report`, `help`, предупреждение о лимите) — **одна** строка с `\n` внутри.

## Правила

- Меняй только `parse_command` и `handle`; цикл `main` и `task_px08_session` не трогай.
- Функции должны **вернуть** строку через `return`, а не печатать её.
- Встроенные `sum`, `sorted`, `sort`, `max`, `count`, `dict` не используй: память — только списки, суммы — циклами.
- Повторный `limit` на ту же категорию заменяет лимит, а не добавляет второй.
- Ошибочная команда ничего не меняет: после неё `total` и `report` считают как до неё.

## Пример

```python
task_px08_session(["add 150 кафе", "add 80 такси", "report"])
# -> ['Записал: 150 ₽ — кафе', 'Записал: 80 ₽ — такси',
#     'кафе: 150 ₽ (65%)\nтакси: 80 ₽ (35%)\nИтого: 230 ₽']
task_px08_session(["limit кафе 100", "add 150 кафе"])
# -> ['Лимит на кафе: 100 ₽',
#     'Записал: 150 ₽ — кафе\nВнимание: лимит на кафе превышен на 50 ₽']
task_px08_session(["add 120 кафе", "undo", "undo"])
# -> ['Записал: 120 ₽ — кафе', 'Отменил: 120 ₽ — кафе', 'Нечего отменять']
```

## Учебные цели

- Собрать программу из нескольких команд в одном `handle` без готовых подсказок.
- Держать две «памяти» программы и не путать, какая команда какой список меняет.
