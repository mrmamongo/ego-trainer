# Задача PX02: Итог и справка: total и help

## Условие

### Как это работает

Программа уже записывает расходы. Теперь научим её **считать итог** и **объяснять команды**.

`total` — это накопитель по расходам (папка 03, карточка `l-accumulator`): `entries` — список пар `[сумма, категория]`, сумма лежит по индексу `0`, её и прибавляем.

```python
total = 0                        # 1
for entry in entries:            # 2
    total = total + entry[0]     # 3
return f"Всего: {total} ₽"       # 4
```

| Проход | entry | total после тела |
|---|---|---|
| 1 | `[120, "кафе"]` | 120 |
| 2 | `[80, "еда"]` | 200 |

Для пустых расходов тело не выполнится, и ответ будет `Всего: 0 ₽` — поэтому начинаем с `0`.

`help` просто возвращает готовый текст справки, который уже лежит в файле под именем `HELP_TEXT`.

**Что меняется по сравнению с прошлым шагом (PX01):** в `handle` появляются две ветки — `total` и `help`. Ветка `add` и ответ «Не понимаю команду.» остаются прежними. Пункт `total` в справке теперь **честный**: команда работает.

Сценарии прошлого шага должны отвечать как раньше: `add 120 кафе` → `Записал: 120 ₽ — кафе`, две записи подряд, незнакомая команда → «Не понимаю команду. Напиши help.».

### Задание

Допиши в `handle` команды `total` и `help`. Код прошлого шага лежит в блоке «готово с прошлого шага»; `HELP_TEXT` переменная лежит в решении — **скопируй её себе** в начало файла (это простой текст, без кода). Функция `task_px02_session` и готовый цикл остаются как есть.

## Аргументы

- `lines` — список строк-команд сценария (может быть пустым).

## Возвращает

`task_px02_session` — список ответов, по одному на каждую строку. Для `total` — `Всего: <сумма> ₽` (без расходов `Всего: 0 ₽`), для `help` — ровно текст справки:

```
Команды:
add <сумма> <категория> — записать расход
total — сколько потрачено
help — эта справка
exit — выйти
```

## Правила

- Меняй только `handle` (и добавь текст справки в начале файла); готовый код прошлого шага и цикл не трогай.
- Функция должна **вернуть** строку через `return`, а не печатать её.
- Встроенную функцию `sum` не используй: итог считай циклом и накопителем.
- Справка возвращается одной строкой с переводами строки внутри, без пробелов в конце строк.

## Пример

```python
task_px02_session(["total"])                           # -> ['Всего: 0 ₽']
task_px02_session(["add 120 кафе", "add 80 еда", "total"])   # -> ['…', '…', 'Всего: 200 ₽']
task_px02_session(["help"])                            # -> [текст справки]
```

## Учебные цели

- Собрать накопитель по элементам списка списков (`entry[0]`).
- Добавить в `handle` новые команды ветками `if`, не трогая старые.
