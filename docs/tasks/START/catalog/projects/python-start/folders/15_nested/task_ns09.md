# Задача NS09: delete_path: удалить по пути и убрать опустевшие ветки

## Условие

### Как это работает

`delete_path(data, path)` возвращает **новую** структуру без значения по пути. Вход менять нельзя. Если после удаления словарь-родитель остался пустым, он уже ничего не хранит, и его убирают тоже. Так цепочка пустых словарей «схлопывается» вверх.

| Данные | Путь | Результат |
|---|---|---|
| `{"a": {"b": 1, "c": 2}}` | `["a", "b"]` | `{"a": {"c": 2}}` |
| `{"a": {"b": 1}}` | `["a", "b"]` | `{}` (`"a"` опустел и убран) |
| `{"a": {"b": {"c": 1}}, "d": 2}` | `["a", "b", "c"]` | `{"d": 2}` (опустели `"b"` и `"a"`) |
| `{"a": {"b": 1}}` | `["a", "x"]` | `{"a": {"b": 1}}` (такого пути нет) |

Корневой словарь остаётся словарём, даже если опустел: `{}`.

Убирается только то, что опустело **из-за этого удаления**. Если `"a"` был пустым словарём с самого начала, а удалять пытались `["a", "x"]`, то `"a"` остаётся.

Рекурсивный набросок: удали ключ на своём уровне или спустись в ветку, получи от неё новый результат, и если он пуст, убери ветку:

```python
def delete_path(data, path):
    result = given_deep_copy(data)
    key = path[0]
    if key not in result:
        return result                          # такого пути нет
    if len(path) == 1:
        del result[key]
        return result
    child = result[key]
    if type(child) is not dict:
        return result                          # дальше идти нельзя
    ...                                        # спуститься в child и разобраться с пустотой
```

### Задание

Функция `task_ns09_delete_path(data, path)` сейчас удаляет только ключ верхнего уровня и меняет вход. Перепиши её так, чтобы она работала с любым путём, ничего не меняла во входе и убирала опустевшие ветки. Полную копию даёт готовый `given_deep_copy`.

### Что дальше

Забыть целую ветку памяти помощника и сообщить, какие значения удалены, ты сделаешь в продуктовой задаче [XL-A24](task:XL-A24). Там же будет обход листьев, а чтобы ничего не испортить у соседних данных, пригодится [XL-A22](task:XL-A22).

## Аргументы

- `data` — словарь с ключами-строками; значения: словари и простые значения.
- `path` — непустой список ключей-строк.

## Возвращает

Новый словарь без значения по пути. Если пути нет (нет ключа или на пути лежит не словарь), структура равна входной.

## Правила

- Входной `data` не меняй, в том числе вложенные словари.
- В результате не должно быть общих со входом словарей и списков.
- Модуль `copy` не используй; копию делает `given_deep_copy`.
- Функция `given_deep_copy` лежит в файле как готовая: не удаляй её.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
data = {"a": {"b": 1}, "c": 2}
task_ns09_delete_path(data, ["a", "b"])   # -> {"c": 2}
task_ns09_delete_path(data, ["a", "x"])   # -> {"a": {"b": 1}, "c": 2}
```

## Учебные цели

- Удалять по пути в копии.
- Убирать опустевшие ветки только там, где они опустели от удаления.

## Проверка понимания

Что вернёт `delete_path({"a": {}, "b": 1}, ["a", "x"])` и почему `"a"` остаётся? Что вернёт `delete_path({"a": {"b": {}}}, ["a", "b"])`?
