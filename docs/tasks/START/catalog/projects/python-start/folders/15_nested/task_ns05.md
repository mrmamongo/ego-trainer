# Задача NS05: Глубина вложенности

## Условие

### Как это работает

**Глубина** списка: сколько уровней скобок в самом глубоком месте, считая внешние. У `[1, 2]` глубина 1, у `[1, [2]]` глубина 2, у `[[[]]]` глубина 3. У пустого `[]` глубина тоже 1: скобки же есть.

Глубина списка это «самая большая глубина среди вложенных списков» плюс один за внешние скобки. Роль переменной: **лучший** (наибольший):

```python
def depth(items):
    deepest = 0                       # пока вложенных списков не видели
    for item in items:
        if type(item) is list:
            inner = depth(item)       # глубина вложенного
            ...                       # запомнить, если больше deepest
    return deepest + 1                # +1 за внешние скобки
```

| Вызов | deepest | Возвращает |
|---|---|---|
| `depth([3])` | 0 (списков внутри нет) | `1` |
| `depth([2, [3]])` | 1 (от `[3]`) | `2` |
| `depth([1, [2, [3]]])` | 2 | `3` |

### Задание

Допиши функцию `task_ns05_depth(items)`: она должна вернуть глубину списка.

## Аргументы

- `items` — список (может быть пустым), внутри числа, строки и другие списки.

## Возвращает

Целое число не меньше 1.

## Правила

- Встроенные `max` и `sorted` не используй: «лучший» запоминай через `if`.
- Входной список не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_ns05_depth([])                # -> 1
task_ns05_depth([1, [2, [3]]])     # -> 3
task_ns05_depth([[1], [2, [3]]])   # -> 3
```

## Учебные цели

- Использовать результат рекурсивного вызова как число.
- Выбирать наибольшее из результатов вложенных вызовов.

## Проверка понимания

Почему `deepest` начинается с `0`, а не с `1`? Чему равна глубина `[[], []]`?
