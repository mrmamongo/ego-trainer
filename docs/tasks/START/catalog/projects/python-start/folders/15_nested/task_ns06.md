# Задача NS06: Путь в словаре: найден, не найден, упёрся в число

## Условие

### Как это работает

Функция `get_path` идёт по ключам пути и на каждом шаге заменяет `current` на то, что лежит глубже. Остановиться она может двумя способами: ключа нет, или в руках не словарь (число, строка, список, `None`).

| Шаг | `current` до шага | Ключ | Что происходит |
|---|---|---|---|
| 1 | весь словарь | `"a"` | ключ есть, `current` становится `data["a"]` |
| 2 | `data["a"]` | `"b"` | ключа нет: возвращаем `default` |

Строка `current = current[key]` выполняется только когда шаг удался. Её счётчик показывает, сколько шагов вниз сделано.

### Задание

Открой файл задачи. В нём функция `get_path`, данные и три вызова. Впиши вместо каждого `None` ответ.

- `lang_value`, `theme_value`, `through_scalar` — что вернёт каждый из трёх вызовов (`a`, `b`, `c`);
- `steps_a`, `steps_b`, `steps_c` — сколько раз выполнилась строка 6 (`current = current[key]`) в каждом вызове.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу шагов.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_ns06_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, на каком шаге путь обрывается.
- Различать «нет ключа» и «упёрлись в не словарь».

## Проверка понимания

Что произойдёт на шаге с ключом `"x"` в вызове `c`, если убрать проверку `type(current) is not dict`?
