# Рекурсия: функция вызывает сама себя

Список может лежать внутри списка, тот ещё внутри одного, и так сколько угодно раз: `[1, [2, [3]]]`. Цикл `for` проходит один уровень. Чтобы пройти **любую** глубину, функция вызывает **саму себя** для вложенной части. Это и есть **рекурсия**.

## Два обязательных куска

| Кусок | Вопрос | Что делает |
|---|---|---|
| **база** | «когда задача уже такая простая, что отвечаем сразу?» | возвращает ответ без вызова самой себя |
| **шаг** | «как свести задачу к такой же, но меньшей?» | вызывает себя для части данных |

```python
def total(x):
    if type(x) is not list:        # база: не список, а число
        return x
    result = 0
    for item in x:
        result = result + total(item)   # шаг: то же самое для каждого элемента
    return result
```

Читать это нужно так: `total` умеет считать и число (сразу вернёт его), и список (сложит `total` всех элементов). Про глубину думать не надо: каждый вызов решает только свой уровень.

## Стопка вызовов для `total([1, [2, 3]])`

Пока внутренний вызов не закончился, внешний ждёт. Незаконченные вызовы лежат «стопкой».

| № | Вызов | Что происходит | Возвращает |
|---|---|---|---|
| 1 | `total([1, [2, 3]])` | список: идём по элементам | ждёт |
| 2 | `total(1)` | база: не список | `1` |
| 3 | `total([2, 3])` | список: идём по элементам | ждёт |
| 4 | `total(2)` | база | `2` |
| 5 | `total(3)` | база | `3` |
| 3 | `total([2, 3])` | `0 + 2 + 3` | `5` |
| 1 | `total([1, [2, 3]])` | `0 + 1 + 5` | `6` |

Вызовы заканчиваются в обратном порядке: последний начатый заканчивается первым.

## Без базы будет RecursionError

Каждый вызов занимает место в стопке, а оно ограничено (около тысячи вызовов). Если база забыта или никогда не достигается, вызовы идут без конца, и Python останавливает их ошибкой `RecursionError`:

```python
def count_down(n):
    return count_down(n - 1)       # базы нет: n уменьшается вечно
```

Так же ломается рекурсия по спискам, если база написана для **одного** элемента, а пустой список забыт: срез `items[1:]` от `[]` снова даёт `[]`, и вызовы не кончаются.

```python
def sum_list(numbers):
    if numbers == []:              # база: для пустого списка ответ 0
        return 0
    return numbers[0] + sum_list(numbers[1:])   # шаг: первый + сумма остальных
```

## Частые ошибки

- Нет базы или она недостижима: `RecursionError`.
- Шаг не уменьшает задачу: вызов с теми же данными вызывает себя снова.
- Забыли `return` перед рекурсивным вызовом: функция возвращает `None`.

## Проверь себя

Для `total([[4], 5])` напиши, сколько всего раз будет вызвана `total` и что она вернёт.

<details><summary>Ответ</summary>

Вызовы: `total([[4], 5])`, `total([4])`, `total(4)`, `total(5)`: четыре. Результат `9`.

</details>
