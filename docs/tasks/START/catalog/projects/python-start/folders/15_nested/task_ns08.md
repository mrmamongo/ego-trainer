# Задача NS08: set_path: записать по пути в новую структуру

## Условие

### Как это работает

`set_path(data, path, value)` кладёт `value` по пути `path` и возвращает **новую** структуру. Вход менять нельзя. Самый надёжный порядок: сначала **полная копия**, потом правки уже в копии.

```python
def set_path(data, path, value):
    result = given_deep_copy(data)       # ничего общего со входом
    current = result
    for key in path[:-1]:                # идём до предпоследнего ключа
        ...                              # если ветки нет, создаём пустой словарь
        current = current[key]
    current[path[-1]] = value            # последний ключ: записываем
    return result
```

| Данные | Путь | Значение | Результат |
|---|---|---|---|
| `{"a": {"b": 1}}` | `["a", "b"]` | `2` | `{"a": {"b": 2}}` |
| `{"a": {"b": 1}}` | `["a", "c"]` | `5` | `{"a": {"b": 1, "c": 5}}` |
| `{}` | `["x", "y"]` | `1` | `{"x": {"y": 1}}` (ветка `"x"` создана) |

Про «скопировать только изменяемую ветку, а остальное оставить общим» читай в карточке `ns-update-path`. В этой задаче так нельзя: у результата не должно быть ни одной общей со входом ветки. Полную копию даёт готовый помощник `given_deep_copy` из файла задачи (как он устроен, ты напишешь сам в `NS10`).

### Задание

Функция `task_ns08_set_path(data, path, value)` сейчас пишет прямо во вход и не умеет вложенные пути. Перепиши её по схеме выше. Если на пути лежит не словарь (например, число), его заменяет новый словарь: так путь можно довести до конца.

### Что дальше

Применить сразу пачку таких правок и сообщить, что изменилось, предстоит в продуктовой задаче [XL-A22](task:XL-A22). Исправлять утечку «правка у одного пользователя меняет другого» через общую ветку будешь в [XL-A23](task:XL-A23).

## Аргументы

- `data` — словарь с ключами-строками; значения: словари и простые значения.
- `path` — непустой список ключей-строк.
- `value` — простое значение (число, строка, `True`/`False`, `None`).

## Возвращает

Новый словарь, в котором по пути лежит `value`; недостающие ветки созданы, остальное сохранено. Вход остаётся прежним.

## Правила

- Входной `data` не меняй, в том числе вложенные словари.
- В результате не должно быть общих со входом словарей и списков, даже в соседних ветках.
- Модуль `copy` не используй; копию делает `given_deep_copy`.
- Функция `given_deep_copy` лежит в файле как готовая: не удаляй её.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
data = {"a": {"b": 1}, "c": 3}
task_ns08_set_path(data, ["a", "b"], 2)   # -> {"a": {"b": 2}, "c": 3}
# data остался {"a": {"b": 1}, "c": 3}
```

## Учебные цели

- Править копию, а не вход.
- Создавать недостающие ветки по пути.
