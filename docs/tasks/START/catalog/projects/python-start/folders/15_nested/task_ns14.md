# Задача NS14: merge_settings: настройки по умолчанию и пользователя

## Условие

### Как это работает

У приложения есть настройки по умолчанию, у пользователя свои. Итоговые настройки это **глубокое слияние**: то, что задал пользователь, перекрывает умолчания, а всё остальное берётся из умолчаний. Если у обоих по этому ключу лежат словари, сливаем их тем же правилом, на любую глубину.

Для каждого ключа из `user`:

| Что лежит | Что делаем |
|---|---|
| ключа нет в `defaults` | берём значение пользователя (копию) |
| у обоих словари | сливаем их рекурсивно |
| иначе (значения разных видов, списки, простые значения) | побеждает пользователь |

```python
defaults = {"lang": "ru", "ui": {"theme": "dark", "size": 12}}
user     = {"ui": {"size": 14}}
```

| Ключ | Откуда | Результат |
|---|---|---|
| `lang` | только в `defaults` | `"ru"` |
| `ui` | у обоих словари: сливаем | смотри строки ниже |
| `ui.theme` | только в `defaults` | `"dark"` |
| `ui.size` | у обоих, побеждает `user` | `14` |

Итог: `{"lang": "ru", "ui": {"theme": "dark", "size": 14}}`.

Результат должен быть **независим** и от `defaults`, и от `user`: ни одной общей коробки. Иначе правка итоговых настроек одного пользователя испортит общие умолчания, а вместе с ними и всех остальных. Копию делает готовый помощник `given_deep_copy` из файла задачи.

### Задание

Функция `task_ns14_merge_settings(defaults, user)` сейчас сливает только верхний уровень: вложенный словарь пользователя целиком затирает умолчания (и остаётся общим с `user`). Сделай глубокое слияние.

## Аргументы

- `defaults` — словарь настроек по умолчанию (может быть пустым).
- `user` — словарь настроек пользователя (может быть пустым).

Значения: словари, списки и простые значения (числа, строки, `True`/`False`, `None`).

## Возвращает

Новый словарь — слияние по правилам выше. Списки не сливаются: побеждает список пользователя целиком.

## Правила

- `defaults` и `user` не меняй, в том числе вложенные словари.
- В результате не должно быть общих с `defaults` и `user` словарей и списков.
- Модуль `copy` не используй; копию делает `given_deep_copy`.
- Функция `given_deep_copy` лежит в файле как готовая: не удаляй её.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
defaults = {"lang": "ru", "ui": {"theme": "dark", "size": 12}}
user = {"ui": {"size": 14}}
task_ns14_merge_settings(defaults, user)
# -> {"lang": "ru", "ui": {"theme": "dark", "size": 14}}
```

## Учебные цели

- Писать рекурсию по двум структурам сразу.
- Не пускать общие ветки в результат.
