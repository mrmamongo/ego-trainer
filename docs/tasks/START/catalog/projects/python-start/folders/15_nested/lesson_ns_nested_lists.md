# Списки списков: сумма, плоский список, глубина

Рекурсия по вложенным спискам всегда устроена одинаково: идём циклом по элементам, а на каждом смотрим, **список это или нет**.

```python
for item in items:
    if type(item) is list:
        ...        # вложенный список: вызываем себя
    else:
        ...        # обычное значение: работаем с ним
```

Роли переменных те же, что в цикле: накопитель, сборщик, лучший.

## Сумма (накопитель)

```python
def nested_sum(items):
    total = 0
    for item in items:
        if type(item) is list:
            total = total + nested_sum(item)
        else:
            total = total + item
    return total
```

## Плоский список (сборщик)

```python
def flatten(items):
    result = []
    for item in items:
        if type(item) is list:
            result = result + flatten(item)   # склеиваем с плоским списком вложенного
        else:
            result.append(item)
    return result
```

Порядок сохраняется: элементы идут в том же порядке, в котором встречаются при чтении слева направо. `flatten([1, [2, [3]], 4])` даёт `[1, 2, 3, 4]`.

## Глубина (лучший)

Глубина: сколько уровней скобок, считая внешние. У `[1, 2]` глубина 1, у `[1, [2]]` глубина 2, у пустого `[]` тоже 1.

```python
def depth(items):
    deepest = 0                      # самая глубокая вложенность среди элементов
    for item in items:
        if type(item) is list:
            inner = depth(item)
            if inner > deepest:
                deepest = inner
    return deepest + 1               # +1 за сами внешние скобки
```

Разбор `depth([1, [2, [3]]])`:

| Вызов | deepest | Возвращает |
|---|---|---|
| `depth([3])` | 0 (внутри нет списков) | `1` |
| `depth([2, [3]])` | 1 (от `[3]`) | `2` |
| `depth([1, [2, [3]]])` | 2 (от `[2, [3]]`) | `3` |

## Частые ошибки

Проверять `if item == list` вместо `type(item) is list`. Первое всегда `False`: сравнивается значение с самим типом.

Потерять результат вложенного вызова:

```python
flatten(item)                         # неверно: результат выброшен
result = result + flatten(item)       # верно
```

Не учесть пустой список внутри: `[[], 1]`. Хорошая рекурсия справляется с ним без отдельных `if`.

## Проверь себя

1. Чему равна `depth([[], [[]]])`?
2. Что вернёт `flatten([[], [[]]])`?

<details><summary>Ответ</summary>

1. `3`: `[[]]` на втором уровне, а внутри него ещё `[]`.
2. `[]`: в таких списках нет ни одного значения.

</details>
