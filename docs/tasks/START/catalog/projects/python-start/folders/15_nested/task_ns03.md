# Задача NS03: Сумма чисел во вложенных списках

## Условие

### Как это работает

Цикл `for` обходит один уровень списка. Если внутри лежат другие списки, для них нужно сделать то же самое, а значит, вызвать ту же функцию:

```python
def nested_sum(items):
    total = 0
    for item in items:
        if type(item) is list:
            total = total + nested_sum(item)   # вложенный список: тот же вопрос про него
        else:
            ...                                # обычное значение
    return total
```

| Вызов | item | Что делаем | total после |
|---|---|---|---|
| `nested_sum([1, [2, 3]])` | `1` | не список: прибавляем | 1 |
| то же | `[2, 3]` | список: прибавляем `nested_sum([2, 3])`, то есть `5` | 6 |

`type(item) is list` проверяет, что `item` именно список. Сравнивать с `== list` нельзя.

### Задание

Функция `task_ns03_nested_sum(items)` должна вернуть сумму всех **целых чисел** в списке `items` и во всех вложенных списках любой глубины. Строки среди значений пропускай. Сейчас функция умеет только плоский список и теряет всё, что лежит во вложенных. Допиши её.

## Аргументы

- `items` — список, в котором лежат целые числа, строки и другие такие же списки (глубина любая; список может быть пустым).

## Возвращает

Целое число — сумму всех целых чисел; если чисел нет, `0`.

## Правила

- Встроенную функцию `sum` не используй.
- Входной список не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_ns03_nested_sum([1, [2, [3]]])        # -> 6
task_ns03_nested_sum([1, "a", [2, "b"]])   # -> 3
task_ns03_nested_sum([[], [[]]])           # -> 0
```

## Учебные цели

- Писать рекурсию с проверкой «список или значение».
- Копить сумму во вложенных вызовах.

## Проверка понимания

Что вернёт функция для `[]`? Почему для `[[], [[]]]` она не падает и не зацикливается?
