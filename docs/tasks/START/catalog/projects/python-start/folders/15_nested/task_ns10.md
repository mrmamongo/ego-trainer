# Задача NS10: deep_copy своими руками

## Условие

### Как это работает

Глубокая копия: новый словарь или список на **каждом** уровне, а простые значения (числа, строки, `True`, `None`) возвращаются как есть, потому что неизменяемые. Рекурсия делает это для любой глубины:

| Что пришло | Что вернуть |
|---|---|
| словарь | новый словарь; значение каждого ключа — через `deep_copy` |
| список | новый список; каждый элемент — через `deep_copy` |
| всё остальное | само значение (база) |

```python
def deep_copy(x):
    if type(x) is dict:
        result = {}
        for key, value in x.items():
            result[key] = deep_copy(value)
        return result
    ...
```

Разбор `deep_copy({"a": [1, 2]})`:

| Вызов | Что делает | Возвращает |
|---|---|---|
| `deep_copy({"a": [1, 2]})` | новый словарь, копирует значение `"a"` | ждёт |
| `deep_copy([1, 2])` | новый список, копирует элементы | `[1, 2]` (новый) |
| `deep_copy(1)`, `deep_copy(2)` | база | `1`, `2` |

Результат равен входу, но не имеет с ним ни одной общей коробки.

### Задание

Функция `task_ns10_deep_copy(data)` сейчас делает только поверхностную копию (один уровень). Сделай полную. Модуль `copy` и `json` запрещены.

## Аргументы

- `data` — словарь, список или простое значение; внутри только словари, списки и простые значения.

## Возвращает

Копию того же вида. Для простого значения вернётся оно само.

## Правила

- Модули `copy` и `json` и функцию `deepcopy` не используй.
- Входные данные не меняй.
- В результате не должно быть общих со входом словарей и списков.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
a = {"items": [1, [2]]}
b = task_ns10_deep_copy(a)
b["items"][1].append(3)
# a остался {"items": [1, [2]]}
```

## Учебные цели

- Написать рекурсию с двумя шагами и общей базой.
- Понять, что `dict(a)` и `list(a)` копируют один уровень.
