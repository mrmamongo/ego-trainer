# Задача NS07: get_path: значение по пути

## Условие

### Как это работает

Путь `["profile", "settings", "lang"]` это тот же `data["profile"]["settings"]["lang"]`, только ключи лежат в списке. Идём по ним циклом и на каждом шаге проверяем две вещи: в руках словарь, и нужный ключ в нём есть. Если нет, возвращаем `default`.

```python
data = {"profile": {"settings": {"lang": "ru"}, "age": 30}}
```

| Путь | Что происходит | Ответ |
|---|---|---|
| `["profile", "settings", "lang"]` | три удачных шага | `"ru"` |
| `["profile", "theme"]` | ключа `"theme"` нет | `default` |
| `["profile", "age", "x"]` | `30` это не словарь | `default` |
| `[]` | шагов нет | сам `data` |

Решает только наличие ключа: если ключ есть, а значение `None`, `0` или `""`, вернуть нужно именно его, а не `default`.

### Задание

Функция `task_ns07_get_path(data, path, default)` должна вернуть значение по пути или `default`, если дойти до него нельзя. Сейчас она падает на отсутствующем ключе. Исправь.

## Аргументы

- `data` — словарь (значения могут быть словарями, списками и простыми значениями).
- `path` — список ключей-строк (может быть пустым).
- `default` — что вернуть, если путь не удался.

## Возвращает

Значение по пути (то, что там лежит, без копирования) или `default`. Для пустого пути возвращается сам `data`.

## Правила

- Входные данные не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
data = {"profile": {"settings": {"lang": "ru"}, "age": 30}}
task_ns07_get_path(data, ["profile", "settings", "lang"], "нет")   # -> "ru"
task_ns07_get_path(data, ["profile", "theme"], "нет")              # -> "нет"
task_ns07_get_path(data, ["profile", "age", "x"], "нет")           # -> "нет"
```

## Учебные цели

- Обходить путь циклом, а не фиксированной цепочкой ключей.
- Отличать «ключа нет» от «значение пустое».

## Проверка понимания

Что вернёт `get_path({"a": None}, ["a"], "нет")` и почему не `"нет"`? Что вернёт `get_path({"a": 5}, ["a", "b"], "нет")`?
