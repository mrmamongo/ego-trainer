# Задача NS04: Расплющить вложенный список

## Условие

### Как это работает

«Расплющить» значит достать все значения из вложенных списков в один плоский список. Роль переменной та же, что в цикле: **сборщик** `result = []`. Для вложенного списка мы получаем плоский список рекурсивным вызовом и приклеиваем его к своему:

```python
def flatten(items):
    result = []
    for item in items:
        if type(item) is list:
            result = result + flatten(item)
        else:
            result.append(item)
    return result
```

| Вызов | item | Что делаем | result после |
|---|---|---|---|
| `flatten([1, [2, 3], 4])` | `1` | не список: `append` | `[1]` |
| то же | `[2, 3]` | список: `result + flatten([2, 3])` | `[1, 2, 3]` |
| то же | `4` | `append` | `[1, 2, 3, 4]` |

Порядок сохраняется: значения идут так, как их читают слева направо.

### Задание

Функция `task_ns04_flatten(items)` должна вернуть **новый** плоский список со всеми значениями из `items` и вложенных списков любой глубины. Сейчас она просто копирует верхний уровень и оставляет вложенные списки внутри. Исправь.

## Аргументы

- `items` — список, в котором лежат любые значения (числа, строки) и другие такие же списки. Может быть пустым.

## Возвращает

Новый список без вложенных списков; порядок значений сохраняется. Пустые вложенные списки ничего не добавляют.

## Правила

- Входной список и его вложенные списки не меняй.
- Встроенную функцию `sum` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_ns04_flatten([1, [2, [3]], 4])   # -> [1, 2, 3, 4]
task_ns04_flatten([[], [[]]])         # -> []
```

## Учебные цели

- Собирать плоский результат из вложенных вызовов.
- Сохранять порядок значений.

## Проверка понимания

Что вернёт `flatten([[1], [], [2, [3]]])`? Что потеряется, если вызов `flatten(item)` записать без `result = result + ...`?
