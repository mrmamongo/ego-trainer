# Задача NS12: Сколько листьев в смешанной структуре

## Условие

### Как это работает

Данные бывают вперемешку: словарь со списками, список со словарями. **Лист** это значение, внутри которого уже ничего нет: число, строка, `True`/`False`, `None`. Словарь и список листьями не считаются: они контейнеры, считать надо то, что лежит в них.

Для разных видов значения разные шаги:

| Что пришло | Сколько листьев |
|---|---|
| словарь | сумма листьев всех его значений (ключи не считаем) |
| список | сумма листьев всех его элементов |
| всё остальное | `1` (база) |

```python
data = {"a": 1, "b": [2, {"c": None, "d": []}]}
```

| Часть | Листьев |
|---|---|
| `1` | 1 |
| `2` | 1 |
| `None` | 1 |
| `[]` | 0 (в нём ничего нет) |
| итого | 3 |

Пустой словарь и пустой список дают `0`, а `None` и `""` это листья (они лежат на месте, как значения).

### Задание

Функция `task_ns12_count_leaves(data)` должна вернуть число листьев. Сейчас она считает только элементы верхнего уровня. Исправь.

## Аргументы

- `data` — словарь, список или простое значение; внутри любая смесь словарей, списков и простых значений.

## Возвращает

Целое число — количество листьев.

## Правила

- Входные данные не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_ns12_count_leaves({"a": 1, "b": [2, {"c": None, "d": []}]})   # -> 3
task_ns12_count_leaves(7)                                           # -> 1
task_ns12_count_leaves([])                                          # -> 0
```

## Учебные цели

- Писать рекурсию, где у функции три случая: словарь, список, значение.
- Помнить, что пустой контейнер даёт ноль.

## Проверка понимания

Сколько листьев в `[[], {}, [[]]]`? А в `{"a": None}`?
