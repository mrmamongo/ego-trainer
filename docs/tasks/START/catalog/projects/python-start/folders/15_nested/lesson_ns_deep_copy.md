# Глубокая копия рекурсией

В карточке `di-copy` ты копировал нужные уровни вручную: «если глубина два, копируй два уровня». Но на данных любой глубины так не напишешь. Рекурсия делает это за один раз.

## Идея

| Что пришло | Что делаем |
|---|---|
| словарь | новый словарь; значение каждого ключа копируем **этой же функцией** |
| список | новый список; каждый элемент копируем этой же функцией |
| число, строка, `True`, `None` | возвращаем как есть: они неизменяемы, копировать нечего |

```python
def deep_copy(x):
    if type(x) is dict:
        result = {}
        for key, value in x.items():
            result[key] = deep_copy(value)      # шаг
        return result
    if type(x) is list:
        result = []
        for item in x:
            result.append(deep_copy(item))      # шаг
        return result
    return x                                     # база: неизменяемое значение
```

База здесь не одна: любое неизменяемое значение. Они заканчивают рекурсию.

## Разбор `deep_copy({"a": [1, {"b": 2}]})`

| Вызов | Что делает | Возвращает |
|---|---|---|
| `deep_copy({"a": [...]})` | новый словарь, копирует значение `"a"` | ждёт |
| `deep_copy([1, {"b": 2}])` | новый список, копирует элементы | ждёт |
| `deep_copy(1)` | база | `1` |
| `deep_copy({"b": 2})` | новый словарь, копирует `2` | `{"b": 2}` (новый) |
| `deep_copy(2)` | база | `2` |

Результат равен входу (`==`), но все словари и списки в нём **новые** (`is` даёт `False`).

## Сравни с `di-copy`

| | `dict(a)` | ручные уровни | `deep_copy` |
|---|---|---|---|
| сколько уровней | 1 | сколько написал | любая глубина |
| общие коробки с оригиналом | вложенные | те, что не скопировал | нет |
| код | одна строка | зависит от формы данных | одна функция на любую форму |

## Что можно, а что нет

Копировать неизменяемое не нужно, а вот забыть скопировать **список в словаре в списке** легко. Рекурсия не забывает: она одинаково обходит любой уровень.

В задачах этой папки в данных только словари, списки и простые значения. Модуль `copy` и его `deepcopy` здесь запрещены: цель в том, чтобы ты смог собрать копию сам.

## Частые ошибки

```python
if type(x) is dict:
    return dict(x)               # неверно: один уровень, значения общие
```

```python
result[key] = value              # неверно: забыли рекурсивный вызов
result[key] = deep_copy(value)   # верно
```

Забыть последний `return x`: для числа функция вернёт `None`.

## Проверь себя

```python
a = {"items": [1, [2]]}
b = deep_copy(a)
b["items"][1].append(3)
```

1. Чему равно `a`?
2. Чему равно `b`?

<details><summary>Ответ</summary>

1. `{"items": [1, [2]]}`: вложенный список скопирован, оригинал не изменился.
2. `{"items": [1, [2, 3]]}`.

</details>
