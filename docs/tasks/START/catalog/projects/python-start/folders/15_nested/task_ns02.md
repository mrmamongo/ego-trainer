# Задача NS02: Рекурсия без базы для пустого списка

## Условие

### Как это работает

В рекурсии должна быть **база**: случай, на котором функция отвечает сразу и не вызывает себя. Если базы нет или до неё никогда не дойти, вызовы идут без конца, и Python падает с `RecursionError`.

Вот сумма списка «первое число плюс сумма остальных». База написана для списка из одного числа:

```python
def sum_list(numbers):
    if len(numbers) == 1:
        return numbers[0]
    return numbers[0] + sum_list(numbers[1:])
```

| Вызов | Что происходит |
|---|---|
| `sum_list([4, 6])` | не база, считает `4 + sum_list([6])` |
| `sum_list([6])` | база: возвращает `6` |
| `sum_list([])` | не база, зовёт `sum_list([][1:])`, то есть снова `sum_list([])`, и так без конца |

Срез от пустого списка снова пустой, поэтому до «одного элемента» тут не дойти.

### Задание

Функция `task_ns02_sum_list(numbers)` должна вернуть сумму чисел списка, но для пустого списка падает с `RecursionError`. Найди причину и исправь: база должна быть для **пустого** списка.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Целое число — сумму элементов; для пустого списка — `0`.

## Правила

- Решение должно остаться рекурсивным: циклы `for` и `while` не используй.
- Встроенную функцию `sum` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_ns02_sum_list([1, 2, 3])   # -> 6
task_ns02_sum_list([])          # -> 0
```

## Учебные цели

- Находить рекурсию без достижимой базы.
- Выбирать базу по ответу для самого простого входа.

## Проверка понимания

Почему при правильной базе для `[]` база для списка из одного числа уже не нужна? Что вернёт функция для `[7]`?
