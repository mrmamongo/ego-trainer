# Сортировка: sort() и sorted()

Упорядочить список можно двумя способами. Они отличаются ровно тем, о чём прошлая карточка.

| | `nums.sort()` | `sorted(nums)` |
|---|---|---|
| Что делает с `nums` | **меняет на месте** | не трогает |
| Что возвращает | `None` | **новый** отсортированный список |

```python
nums = [3, 1, 2]
new = sorted(nums)      # new равен [1, 2, 3], nums остался [3, 1, 2]
res = nums.sort()       # nums стал [1, 2, 3], res равен None
```

Для функции, которая получила чужой список, безопасен `sorted(nums)`. `nums.sort()` испортит список вызывающего кода.

## По убыванию: reverse=True

```python
sorted([3, 1, 2], reverse=True)     # [3, 2, 1]
```

Слово `reverse=True` пишут внутри скобок. Метод `.sort(reverse=True)` работает так же, но на месте.

## Сортировка по ключу: key

По умолчанию числа сравниваются как числа, а строки — по алфавиту. Чтобы сравнивать по чему-то другому, передают `key=` — функцию, которая из элемента делает «что сравнивать». Скобки после имени функции **не** пишут.

```python
sorted(["ccc", "a", "bb"], key=len)      # ['a', 'bb', 'ccc']   - по длине
sorted([-5, 2, -1, 3], key=abs)          # [-1, 2, 3, -5]       - по модулю
```

## Равные ключи: порядок сохраняется

Сортировка **устойчива**: элементы с одинаковым ключом остаются в том порядке, в котором были.

```python
sorted(["bb", "a", "cc", "d"], key=len)  # ['a', 'd', 'bb', 'cc']
```

Слова `"a"` и `"d"` равны по длине, поэтому `"a"` остаётся перед `"d"`, как и в исходном списке. Так же `"bb"` перед `"cc"`.

## Три самых больших числа

Отсортируй по убыванию и возьми срез:

```python
sorted([5, 9, 1, 7, 3], reverse=True)[:3]   # [9, 7, 5]
```

Если элементов меньше трёх, срез просто возьмёт все, ошибки не будет.

## Частые ошибки

Записать результат `sort()`:

```python
nums = nums.sort()      # неверно: nums стал None
```

```python
nums.sort()             # верно, если можно менять на месте
nums = sorted(nums)     # верно, если нужен новый список
```

Написать `key=len(...)` или `key=len()`: ключ — это сама функция, `key=len`.

## Проверь себя

```python
words = ["pear", "fig", "apple", "kiwi"]
a = sorted(words, key=len)
b = sorted([4, 8, 1], reverse=True)
```

1. Чему равны `a` и `b`?
2. Изменился ли `words`?

<details><summary>Ответ</summary>

1. `a` равно `['fig', 'pear', 'kiwi', 'apple']` (у `pear` и `kiwi` длина 4, они остались в исходном порядке). `b` равно `[8, 4, 1]`.
2. Нет: `sorted` вернул новые списки.

</details>
