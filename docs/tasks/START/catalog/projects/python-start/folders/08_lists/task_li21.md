# Задача LI21: Слияние двух отсортированных

## Условие

### Как это работает

Два списка `a` и `b` уже отсортированы по возрастанию. Нужно получить один отсортированный список, не вызывая сортировку. Идея: у каждого списка свой **указатель** (индекс) на «первый ещё не взятый» элемент. Каждый раз берём меньший из двух и двигаем его указатель.

```python
i = 0                      # указатель в a
j = 0                      # указатель в b
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        result.append(a[i])
        i = i + 1
    else:
        result.append(b[j])
        j = j + 1
```

Пройдём `a = [1, 4]`, `b = [2, 3, 5]`:

| i | j | сравниваем | берём | result |
|---|---|---|---|---|
| 0 | 0 | `1` и `2` | `1` из a | `[1]` |
| 1 | 0 | `4` и `2` | `2` из b | `[1, 2]` |
| 1 | 1 | `4` и `3` | `3` из b | `[1, 2, 3]` |
| 1 | 2 | `4` и `5` | `4` из a | `[1, 2, 3, 4]` |

Теперь `i` равен длине `a`, и цикл закончился. В другом списке могли остаться элементы: они уже отсортированы и все не меньше взятых, поэтому добавляются хвостом `a[i:]` или `b[j:]`. Один из этих хвостов пуст.

### Задание

Напиши функцию `task_li21_merge_sorted(a, b)`: верни новый отсортированный список из всех элементов `a` и `b`.

## Аргументы

- `a`, `b` — списки целых чисел, каждый отсортирован по возрастанию (могут быть пустыми).

## Возвращает

Новый отсортированный по возрастанию список длиной `len(a) + len(b)`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- `sort` и `sorted` не используй: слей списки двумя индексами. Списки `a` и `b` менять нельзя.

## Пример

```python
task_li21_merge_sorted([1, 4], [2, 3, 5])   # -> [1, 2, 3, 4, 5]
task_li21_merge_sorted([], [1, 2])          # -> [1, 2]
task_li21_merge_sorted([1, 1], [1])         # -> [1, 1, 1]
task_li21_merge_sorted([], [])              # -> []
```

## Учебные цели

- Вести два независимых индекса по двум спискам.
- Не забывать про «хвост» списка, который остался после цикла.
