# Задача LI20: Найти в таблице

## Условие

### Как это работает

Нужно найти число в таблице и вернуть его **координаты**: номер строки и номер столбца. Для номеров ходим по `range`:

```python
for r in range(len(matrix)):
    for c in range(len(matrix[r])):
        if matrix[r][c] == x:
            return [r, c]
return [-1, -1]
```

`return` внутри внутреннего цикла завершает функцию сразу, из обоих циклов: нашли первое вхождение, дальше искать не нужно. Порядок обхода: строка за строкой, слева направо, поэтому «первое» — самое верхнее и левое.

`return [-1, -1]` стоит **после обоих циклов**: «нет» можно сказать, только когда проверено всё. `-1` не бывает настоящим номером, поэтому им отмечают «не найдено».

Строки могут быть разной длины и даже пустыми: внутренний `range(len(matrix[r]))` это учитывает.

### Задание

Напиши функцию `task_li20_find_in_matrix(matrix, x)`: верни `[row, col]` первого (по порядку обхода строка за строкой) элемента, равного `x`, или `[-1, -1]`, если такого нет.

## Аргументы

- `matrix` — список строк, каждая строка — список целых чисел (всё может быть пустым).
- `x` — искомое целое число.

## Возвращает

Список из двух чисел `[row, col]`; если `x` не найден — `[-1, -1]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Методы `index` и `in` для поиска по таблице не используй: ходи двумя циклами. Таблицу менять нельзя.

## Пример

```python
task_li20_find_in_matrix([[1, 2], [3, 4]], 4)   # -> [1, 1]
task_li20_find_in_matrix([[1, 2], [2, 1]], 2)   # -> [0, 1]
task_li20_find_in_matrix([[1, 2], [3, 4]], 9)   # -> [-1, -1]
task_li20_find_in_matrix([], 1)                 # -> [-1, -1]
```

## Учебные цели

- Находить координаты элемента во вложенных циклах по `range`.
- Ставить `return` внутри циклов для находки и после циклов для «не нашли».

## Проверка понимания

Что вернёт функция для `[[5, 5], [5, 5]]` и `x = 5`? Почему `return [-1, -1]` нельзя ставить внутрь внешнего цикла?
