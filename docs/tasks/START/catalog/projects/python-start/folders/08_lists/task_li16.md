# Задача LI16: Без повторов, по порядку

## Условие

### Как это работает

Нужно оставить каждое число один раз — при его **первой** встрече. Пусть `result` — сборщик. Перед тем как добавить число, спрашиваем: «а его там уже нет?»

```python
result = []
for number in nums:
    if number not in result:
        result.append(number)
```

`number not in result` даёт `True`, если числа в `result` ещё нет. Пройдём `[3, 1, 3, 2, 1]`:

| number | уже в result? | result после прохода |
|---|---|---|
| 3 | нет | `[3]` |
| 1 | нет | `[3, 1]` |
| 3 | да | `[3, 1]` |
| 2 | нет | `[3, 1, 2]` |
| 1 | да | `[3, 1, 2]` |

Проверять нужно именно `result` (то, что уже собрали), а не `nums`: в `nums` число есть всегда, ведь мы его оттуда взяли.

### Задание

Напиши функцию `task_li16_unique_in_order(nums)`: верни новый список, в котором каждое число из `nums` встречается один раз — на месте своего первого появления.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Новый список без повторов; порядок первых появлений сохранён.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Множества (`set`) и словари пока не нужны: решай сборщиком и проверкой `in`. Список `nums` менять нельзя.

## Пример

```python
task_li16_unique_in_order([3, 1, 3, 2, 1])   # -> [3, 1, 2]
task_li16_unique_in_order([5, 5, 5])         # -> [5]
task_li16_unique_in_order([])                # -> []
```

## Учебные цели

- Проверять наличие элемента оператором `in` / `not in`.
- Сохранять порядок первых появлений.

## Проверка понимания

Что произойдёт, если проверять `number not in nums` вместо `number not in result`? Что вернёт функция для `[1, 2, 3]`?
