# Методы списка: что меняют и что возвращают

Методы списка вызываются через точку: `nums.append(5)`. У каждого метода два вопроса: **что он делает со списком** и **что он возвращает**.

| Метод | Что делает | Что возвращает |
|---|---|---|
| `nums.append(x)` | добавляет `x` в конец | `None` |
| `nums.insert(i, x)` | вставляет `x` на место `i`, остальные сдвигаются | `None` |
| `nums.extend(other)` | добавляет в конец все элементы списка `other` | `None` |
| `nums.remove(x)` | удаляет **первое** вхождение `x` | `None` |
| `nums.pop()` | удаляет последний элемент | этот элемент |
| `nums.pop(i)` | удаляет элемент с индексом `i` | этот элемент |
| `nums.index(x)` | ничего не меняет | индекс первого `x` |
| `nums.count(x)` | ничего не меняет | сколько раз встретился `x` |
| `nums.sort()`, `nums.reverse()` | меняют порядок на месте | `None` |

Главное: методы, которые **меняют** список, чаще всего возвращают `None`. Результат такого вызова в переменную класть бессмысленно.

```python
nums = [3, 1, 2]
x = nums.sort()        # nums стал [1, 2, 3], а x равен None
nums = nums.append(4)  # неверно: nums стал None
```

Проверить, что в переменной `None`, можно так: `x is None` даст `True`.

## Трассировка

```python
nums = [3, 1, 2]            # 1
nums.append(5)              # 2
nums.insert(0, 7)           # 3
last = nums.pop()           # 4
nums.remove(1)              # 5
```

| После строки | nums | last |
|---|---|---|
| 1 | `[3, 1, 2]` | — |
| 2 | `[3, 1, 2, 5]` | — |
| 3 | `[7, 3, 1, 2, 5]` | — |
| 4 | `[7, 3, 1, 2]` | `5` |
| 5 | `[7, 3, 2]` | `5` |

## append или extend

`append` кладёт **один** элемент, даже если это список. `extend` добавляет **содержимое**.

```python
a = [1]
a.append([2, 3])    # [1, [2, 3]]  - вторым элементом лежит целый список
b = [1]
b.extend([2, 3])    # [1, 2, 3]
```

## in: есть ли элемент в списке

`x in nums` даёт `True`, если `x` есть в списке, и `False`, если нет. `x not in nums` — наоборот. Это проще, чем писать цикл с флагом.

```python
2 in [1, 2, 3]          # True
5 not in [1, 2, 3]      # True
```

## Когда метод падает

- `nums.remove(x)` и `nums.index(x)`: если `x` нет в списке, будет `ValueError`. Сначала проверь `x in nums`.
- `nums.pop()` у пустого списка: `IndexError`.
- Метод, который меняет список, изменит его и **у вызывающего кода**, если список пришёл параметром. Об этом следующая карточка.

## Проверь себя

```python
nums = [4, 4, 9]
a = nums.count(4)
b = nums.index(9)
c = nums.append(1)
```

1. Чему равны `a` и `b`?
2. Что лежит в `c` и что в `nums`?

<details><summary>Ответ</summary>

1. `a` равно `2` (две четвёрки), `b` равно `2` (индекс девятки).
2. `c` равно `None`, а `nums` стал `[4, 4, 9, 1]`.

</details>
