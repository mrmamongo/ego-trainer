# Задача LI10: Вставка в отсортированный список

## Условие

### Как это работает

Список `nums` уже отсортирован по возрастанию. Чтобы вставить `x` на нужное место, не нужно сортировать всё заново: достаточно **найти позицию** и склеить три куска.

Позиция — это индекс первого элемента, который не меньше `x`. Идём вперёд, пока элементы меньше `x`:

```python
pos = 0
while pos < len(nums) and nums[pos] < x:
    pos = pos + 1
```

Проверка `pos < len(nums)` стоит **первой**: если она ложна, второе условие не вычисляется, и `nums[pos]` не выйдет за границы.

Дальше результат — «всё до позиции», сам `x`, «всё с позиции»:

```python
nums[:pos] + [x] + nums[pos:]
```

Для `nums = [1, 3, 5]`, `x = 4` позиция будет `2`, и получится `[1, 3] + [4] + [5]`. Списки `nums` при этом не меняются: `+` и срезы строят новые.

### Задание

Напиши функцию `task_li10_insert_sorted(nums, x)`: `nums` отсортирован по возрастанию. Верни **новый** отсортированный список, в который добавлено `x`.

## Аргументы

- `nums` — отсортированный по возрастанию список целых чисел (может быть пустым).
- `x` — целое число.

## Возвращает

Новый отсортированный список на один элемент длиннее `nums`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- `sort`, `sorted` и `insert` не используй: позицию ищи сам. Список `nums` менять нельзя.

## Пример

```python
task_li10_insert_sorted([1, 3, 5], 4)   # -> [1, 3, 4, 5]
task_li10_insert_sorted([1, 3], 0)      # -> [0, 1, 3]
task_li10_insert_sorted([1, 3], 9)      # -> [1, 3, 9]
task_li10_insert_sorted([], 5)          # -> [5]
```

## Учебные цели

- Искать позицию вставки циклом `while` с безопасным порядком условий.
- Собирать новый список из срезов и `+`, не меняя исходный.

## Проверка понимания
