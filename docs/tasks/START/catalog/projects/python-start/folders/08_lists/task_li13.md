# Задача LI13: Собери квадраты чётных

## Условие

### Как это работает

Квадраты чётных чисел можно собрать двумя способами. Они дают один и тот же **новый** список:

```python
# цикл
result = []
for number in nums:
    if number % 2 == 0:
        result.append(number * number)
```

```python
# одна строка
result = [number * number for number in nums if number % 2 == 0]
```

В этой задаче строки на листе даны по одной, поэтому собирать нужно **форму с циклом**. Однострочную запись ты напишешь в следующих задачах.

Сборщик знакомый: `result = []` до цикла, `if` под `for`, `append` под `if`, `return` после цикла. Отступы показывают вложенность.

### Задание

В файле задачи в комментарии записаны строки функции `task_li13_even_squares(nums)`, но они перемешаны и без отступов.
Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали.
Функция должна вернуть новый список квадратов только чётных чисел в исходном порядке.

## Аргументы

- `nums` — список целых чисел (может быть пустым, числа могут быть отрицательными).

## Возвращает

Новый список квадратов чётных элементов `nums` в том же порядке; если чётных нет — `[]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_li13_even_squares([1, 2, 3, 4])   # -> [4, 16]
task_li13_even_squares([1, 3])         # -> []
task_li13_even_squares([])             # -> []
```

## Учебные цели

- Собрать сборщик с фильтром и вычисленным значением в `append`.
- Видеть соответствие «цикл ↔ списочное выражение» на одном примере.

## Проверка понимания

В какой части списочного выражения окажется `number * number`, а где `number % 2 == 0`? Что вернёт функция для `[1, 3]`?
