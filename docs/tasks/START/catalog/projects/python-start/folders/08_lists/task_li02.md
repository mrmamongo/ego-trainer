# Задача LI02: Поменять концы местами

## Условие

### Как это работает

Чтобы поменять две ячейки местами, одну нужно сначала запомнить (как `temp` в первой папке):

```python
first = result[0]
result[0] = result[-1]
result[-1] = first
```

Но эта замена **меняет список на месте**. Если сделать так с параметром функции, изменится список вызывающего кода. Поэтому сначала собери **свою копию** в `result`: пустой список и цикл с `append` (сборщик). Короткие способы копирования будут в следующих карточках.

```python
result = []
for number in nums:
    result.append(number)       # result теперь равен nums по содержимому, но это другой список
```

Дальше меняй концы уже в `result`, а `nums` не трогай. У пустого списка и списка из одного элемента менять нечего: у них нет двух разных концов (а для `[]` нет ни `[0]`, ни `[-1]`).

### Задание

Напиши функцию `task_li02_swap_ends(nums)`: верни **новый** список, в котором первый и последний элементы поменялись местами. Исходный список должен остаться прежним.

## Аргументы

- `nums` — список целых чисел (может быть пустым или из одного элемента).

## Возвращает

Новый список той же длины с поменянными концами; для `[]` — `[]`, для списка из одного элемента — его копия.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `nums` менять нельзя: проверка сравнит его до и после вызова. Результат должен быть другим списком, а не самим `nums`.
- Копию собери циклом и `append`; срезы и `list(...)` пока не нужны.

## Пример

```python
task_li02_swap_ends([1, 2, 3, 4])   # -> [4, 2, 3, 1]
task_li02_swap_ends([7, 8])         # -> [8, 7]
task_li02_swap_ends([5])            # -> [5]
task_li02_swap_ends([])             # -> []
```

## Учебные цели

- Менять элемент по индексу и обменивать два элемента через временную переменную.
- Не трогать входной список: собирать результат в отдельном.

## Проверка понимания

Что станет с `nums` у вызывающего кода, если пропустить копирование и писать `nums[0] = nums[-1]` прямо в параметре? Почему для `[5]` обмен ничего не меняет?
