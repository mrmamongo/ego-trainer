# Задача LI19: Суммы по строкам

## Условие

### Как это работает

Для таблицы нужно получить по одной сумме на каждую строку. Внешний цикл берёт строку, внутренний складывает её числа, а готовая сумма попадает в список-результат:

```python
def row_sums_demo(matrix):
    result = []
    for row in matrix:
        total = 0                       # для каждой строки с нуля
        for value in row:
            total = total + value
        result.append(total)
    return result
```

| Строка | total по ходу | в result |
|---|---|---|
| `[1, 2]` | 1, 3 | `3` |
| `[3, 4]` | 3, 7 | `7` |

Накопитель `total = 0` здесь стоит **внутри** внешнего цикла: сумма считается отдельно для каждой строки. А список `result` заводится **до** циклов.

Пустая строка `[]` даёт сумму `0`: внутренний цикл не выполнится, и `total` останется нулём.

### Задание

Напиши функцию `task_li19_row_sums(matrix)`: верни список сумм строк таблицы, по одной сумме на строку.

## Аргументы

- `matrix` — список строк, каждая строка — список целых чисел (таблица и строки могут быть пустыми).

## Возвращает

Список сумм строк в том же порядке; для пустой таблицы — `[]`, для пустой строки — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `sum` не используй: считай накопителем. Таблицу менять нельзя.

## Пример

```python
task_li19_row_sums([[1, 2], [3, 4]])   # -> [3, 7]
task_li19_row_sums([[5], [], [1, -1]]) # -> [5, 0, 0]
task_li19_row_sums([])                 # -> []
```

## Учебные цели

- Сочетать накопитель во внутреннем цикле и сборщик во внешнем.
- Понимать, где заводится каждая из двух переменных.

## Проверка понимания

Что получится, если вынести `total = 0` перед внешним циклом? Чему равна сумма пустой строки?
