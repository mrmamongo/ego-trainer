# Задача LI04: Без первого и последнего

## Условие

### Как это работает

Срез `nums[1:-1]` начинается с индекса 1 (второй элемент) и заканчивается перед последним. Он берёт всё **кроме первого и последнего**:

```python
[10, 20, 30, 40][1:-1]    # [20, 30]
[10, 20][1:-1]            # []
[10][1:-1]                # []
[][1:-1]                  # []
```

Срез не падает с ошибкой на коротких списках, он просто получается пустым. И это всегда новый список: `nums` остаётся как был.

### Задание

Напиши функцию `task_li04_middle(nums)`: верни новый список без первого и последнего элементов.

## Аргументы

- `nums` — список целых чисел (может быть пустым или из одного элемента).

## Возвращает

Новый список из элементов `nums` без первого и последнего; если элементов меньше трёх — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй срез. Список `nums` менять нельзя.

## Пример

```python
task_li04_middle([1, 2, 3, 4])   # -> [2, 3]
task_li04_middle([1, 2, 3])      # -> [2]
task_li04_middle([1, 2])         # -> []
task_li04_middle([])             # -> []
```

## Учебные цели

- Выбирать границы среза, чтобы отрезать первый и последний элемент.
- Видеть, что срез на коротком списке не вызывает ошибку.

## Проверка понимания
