# Списочное выражение: сборщик в одну строку

Роль «сборщик» знакома: `result = []`, цикл, `result.append(...)`. Для простых случаев Python позволяет записать то же самое **в одну строку**:

```python
result = []
for number in nums:
    result.append(number * 2)
```

```python
result = [number * 2 for number in nums]
```

Обе записи строят один и тот же **новый** список. Читается так: «`number * 2` для каждого `number` из `nums`».

## С условием

Условие `if` в конце — это тот же фильтр:

```python
result = []
for number in nums:
    if number > 0:
        result.append(number)
```

```python
result = [number for number in nums if number > 0]
```

## Как одно превращается в другое

| В цикле | В выражении |
|---|---|
| `result = []` | квадратные скобки `[ ... ]` |
| `for number in nums:` | `for number in nums` в середине |
| `result.append(выражение)` | `выражение` в самом начале |
| `if условие:` | `if условие` в самом конце |

Порядок: **что кладём — откуда берём — какие подходят**.

## Трассировка

```python
nums = [1, 2, 3, 4]
squares = [n * n for n in nums if n % 2 == 0]
```

| n | `n % 2 == 0`? | что кладём |
|---|---|---|
| 1 | нет | — |
| 2 | да | `4` |
| 3 | нет | — |
| 4 | да | `16` |

Получилось `[4, 16]`. А `nums` остался `[1, 2, 3, 4]`: выражение **читает** список и строит новый, ничего не меняя. Поэтому оно безопасно для чужих данных.

## Когда лучше обычный цикл

Списочное выражение хорошо для простого «превратить» и «отфильтровать». Возьми обычный цикл, если:

- нужны `break` или `continue`;
- в теле несколько действий или накопитель (сумма, счётчик);
- выражение не помещается в одну читаемую строку.

Правило: если приходится вчитываться, раскрой в цикл. Короткая запись — не цель.

## Частые ошибки

Поставить `if` не туда:

```python
[n for n in nums if n > 0 n * 2]       # ошибка: if только в конце
```

Забыть, что результат надо куда-то записать или вернуть: `[n * 2 for n in nums]` само по себе список строит и тут же теряет.

Думать, что выражение меняет `nums`. Оно всегда создаёт новый список.

## Проверь себя

```python
nums = [3, -1, 4, -5]
a = [n * 3 for n in nums]
b = [n for n in nums if n < 0]
```

1. Чему равны `a` и `b`?
2. Чему равен `nums`?

<details><summary>Ответ</summary>

1. `a` равно `[9, -3, 12, -15]`, `b` равно `[-1, -5]`.
2. Так же `[3, -1, 4, -5]`: выражения только читают список.

</details>
