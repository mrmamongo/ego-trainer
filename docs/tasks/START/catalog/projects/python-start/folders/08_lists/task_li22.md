# Задача LI22: Скидка на весь прайс

## Условие

### Как это работает

Магазин применяет скидку ко всему прайс-листу. Цена со скидкой считается так:

```python
price * (100 - percent) / 100        # скидка 20%: цена умножается на 80 / 100
```

Результат округляют до копеек: `round(..., 2)`.

**Почему возвращаем новый список, а не правим `prices`.** Прайс-лист нужен вызывающему коду и потом: показать старую цену рядом с новой, пересчитать скидку другим процентом, сравнить. Если функция перезапишет `prices`, старые цены потеряются, а два вызова подряд применят скидку **дважды**:

| Вызов | Что сделала бы функция «на месте» | Что делает функция с новым списком |
|---|---|---|
| первый, `-20%` | `prices` стал `[80.0]` | вернула `[80.0]`, `prices` по-прежнему `[100]` |
| второй, `-20%` | `prices` стал `[64.0]` — скидка на скидку | вернула `[80.0]`, потому что снова считает от `[100]` |

Поэтому безопасный вариант по умолчанию такой: **вход только читаем, результат строим новым списком**. Для этого отлично подходит списочное выражение: оно ничего не меняет и сразу создаёт новый список.

```python
[round(price * (100 - percent) / 100, 2) for price in prices]
```

### Задание

Напиши функцию `task_li22_apply_discounts(prices, percent)`: верни **новый** список цен со скидкой `percent` процентов, каждая цена округлена до 2 знаков. Исходный список `prices` менять нельзя.

## Аргументы

- `prices` — список цен (целые или дробные неотрицательные числа, может быть пустым).
- `percent` — скидка в процентах, число от `0` до `100`.

## Возвращает

Новый список цен `round(price * (100 - percent) / 100, 2)` в том же порядке; для `[]` — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `prices` менять нельзя: проверка сравнит его до и после вызова. Результат должен быть другим списком.
- Считай по формуле из условия, чтобы округление совпало с проверкой.

## Пример

```python
task_li22_apply_discounts([100, 50], 10)      # -> [90.0, 45.0]
task_li22_apply_discounts([19.99, 5], 20)     # -> [15.99, 4.0]
task_li22_apply_discounts([100], 0)           # -> [100.0]
task_li22_apply_discounts([], 10)             # -> []
```

## Учебные цели

- Строить новый список из входного, не меняя вход.
- Объяснить, почему возврат нового списка безопаснее правки аргумента.

## Проверка понимания

Что станет с `prices` у вызывающего кода после твоей функции? Что случилось бы при двух подряд вызовах со скидкой 20%, если бы функция правила `prices` на месте?
