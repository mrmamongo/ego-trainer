# Список списков: таблица

Элементом списка может быть другой список. Так хранят **таблицу**: каждый вложенный список — одна строка.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
]
```

- `len(matrix)` — сколько **строк** (`2`);
- `len(matrix[0])` — сколько **столбцов** в первой строке (`3`);
- `matrix[1]` — вторая строка, `[4, 5, 6]`;
- `matrix[1][2]` — строка с индексом 1, в ней элемент с индексом 2: `6`.

Сначала номер **строки**, потом номер **столбца**: `matrix[row][col]`.

| | col 0 | col 1 | col 2 |
|---|---|---|---|
| **row 0** | 1 | 2 | 3 |
| **row 1** | 4 | 5 | 6 |

## Обход: вложенные циклы

Все элементы подряд, строка за строкой:

```python
total = 0                           # 1
for row in matrix:                  # 2
    for value in row:               # 3
        total = total + value       # 4
```

Когда нужны номера, ходим по `range`:

```python
for r in range(len(matrix)):
    for c in range(len(matrix[r])):
        ...                         # matrix[r][c]
```

Внешний цикл — строки, внутренний — столбцы. Это тот же порядок, что в карточке про вложенные циклы: внутренний проходит целиком на каждый проход внешнего.

## Сумма по строкам

Накопитель заводим **внутри внешнего цикла**, потому что для каждой строки считаем заново:

```python
sums = []
for row in matrix:
    total = 0                       # для каждой строки с нуля
    for value in row:
        total = total + value
    sums.append(total)
# sums равно [6, 15]
```

Здесь `total = 0` внутри внешнего цикла — это правильно: нам нужна отдельная сумма на каждую строку.

## Ловушки

**Копия внешнего списка не копирует строки.** `m2 = matrix[:]` создаёт новый внешний список, но строки в нём те же самые, что и в `matrix`. Изменение `m2[0][0] = 99` изменит и `matrix`. Чтобы не трогать исходную таблицу, строй результат с нуля: новый внешний список и новые строки.

**Нельзя строить таблицу как `[[0] * 3] * 2`.** Обе строки окажутся одним и тем же списком. Правильно:

```python
table = [[0] * 3 for row in range(2)]     # две отдельные строки
```

## Проверь себя

```python
matrix = [[1, 2], [3, 4], [5, 6]]
```

1. Сколько строк и столбцов? Чему равен `matrix[2][0]`?
2. Какая таблица получится, если поменять строки и столбцы местами?

<details><summary>Ответ</summary>

1. Строк `3`, столбцов `2`. `matrix[2][0]` равно `5`.
2. `[[1, 3, 5], [2, 4, 6]]`: первая строка нового — первый столбец старого.

</details>
