# Задача LI05: Два имени одного списка

## Условие

### Как это работает

Строка `b = a` **не копирует** список: она даёт ему второе имя. Что сделали через одно имя, видно и через другое:

```python
a = [1, 2]       # 1
b = a            # 2
b.append(3)      # 3
```

| После строки | a | b |
|---|---|---|
| 1 | `[1, 2]` | — |
| 2 | `[1, 2]` | `[1, 2]` (тот же список) |
| 3 | `[1, 2, 3]` | `[1, 2, 3]` |

Копию делает срез: `c = a[:]`. После него `c` — отдельный список, и изменения `a` на нём не видны.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `len_a`, `len_b`, `len_c` — длины списков в конце; `b_first` и `c_first` — первые элементы `b` и `c` в конце.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_li05_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, что `b = a` даёт второе имя одному списку, а не копию.
- Отличать копию (`a[:]`) от второго имени.

## Проверка понимания

Почему после `b.append(3)` изменился и `a`? Почему `a[0] = 9` не изменило `c`?
