# Списки: индексы, len и изменение по номеру

Элементы списка лежат под **номерами** (индексами). Нумерация начинается с **нуля**, как у символов строки.

```python
nums = [10, 20, 30, 40]
```

| Индекс | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Значение | 10 | 20 | 30 | 40 |
| Отрицательный индекс | -4 | -3 | -2 | -1 |

- `nums[0]` — первый элемент, `10`;
- `len(nums)` — сколько элементов, `4`;
- последний индекс всегда `len(nums) - 1`, то есть `3`.

## Отрицательные индексы: счёт с конца

`nums[-1]` — последний элемент, `nums[-2]` — предпоследний. Это короче, чем `nums[len(nums) - 1]`, и значит то же самое.

## IndexError: такого номера нет

Если номер выходит за границы, Python останавливает программу с ошибкой `IndexError`:

```python
nums = [10, 20, 30, 40]
nums[4]      # IndexError: допустимы индексы 0..3 и -4..-1
[][0]        # IndexError: в пустом списке нет ни одного элемента
```

Поэтому, если список может быть пустым, сначала проверяй длину: `if len(nums) > 0:`. Для пустого списка нет ни `nums[0]`, ни `nums[-1]`.

## Список можно менять по номеру

В отличие от строки, у списка можно **заменить элемент**: `nums[1] = 25`. Слева стоит «ячейка», справа новое значение.

```python
nums = [10, 20, 30, 40]     # 1
nums[1] = 25                # 2
nums[-1] = nums[0] + 1      # 3
```

| После строки | nums |
|---|---|
| 1 | `[10, 20, 30, 40]` |
| 2 | `[10, 25, 30, 40]` |
| 3 | `[10, 25, 30, 11]` |

Справа всё считается по **старому** содержимому, потом результат кладётся в ячейку. Если индекс вне границ, будет `IndexError`: так нельзя «добавить» новый элемент, для этого есть `append`.

## Обмен двух элементов

Как в карточке про `temp`: чтобы поменять две ячейки местами, одну нужно сначала запомнить.

```python
first = nums[0]             # запомнили
nums[0] = nums[-1]          # на место первого — последний
nums[-1] = first            # на место последнего — запомненный
```

Для `[1, 2, 3]` получится `[3, 2, 1]`. Без `first` оба элемента стали бы равны последнему.

## Частые ошибки

Взять `nums[len(nums)]` как «последний»: такого индекса нет, последний — `len(nums) - 1`.

Взять `nums[0]` у пустого списка: проверь `len(nums)` заранее.

## Проверь себя

```python
nums = [4, 8, 15, 16]
nums[0] = nums[3] - nums[1]
```

1. Чему равны `nums[-2]` и `len(nums)`?
2. Что в `nums` после второй строки?

<details><summary>Ответ</summary>

1. `nums[-2]` равно `15`, `len(nums)` равно `4`.
2. `nums[3] - nums[1]` равно `16 - 8 = 8`, поэтому `nums` станет `[8, 8, 15, 16]`.

</details>
