# Задача LI18: Транспонировать таблицу

## Условие

### Как это работает

Транспонировать таблицу — поменять строки и столбцы местами: первый столбец становится первой строкой.

```python
[[1, 2, 3],        [[1, 4],
 [4, 5, 6]]   ->    [2, 5],
                    [3, 6]]
```

В новой таблице `new[col][row] = old[row][col]`. Значит, внешний цикл идёт по **столбцам** старой таблицы, а внутренний по её строкам, и для каждого столбца собирается новая строка:

```python
rows = len(matrix)
cols = len(matrix[0])
result = []
for col in range(cols):
    new_row = []                      # новая строка для каждого столбца
    for row in range(rows):
        new_row.append(matrix[row][col])
    result.append(new_row)
```

`new_row = []` заводится **внутри** внешнего цикла: для каждого столбца нужна своя пустая строка. Если вынести её наружу, все строки результата окажутся одним и тем же списком.

У пустой таблицы нет `matrix[0]`, поэтому её проверяют заранее.

### Задание

Напиши функцию `task_li18_transpose(matrix)`: верни новую таблицу, в которой строки и столбцы `matrix` поменялись местами. Все строки `matrix` одной длины.

## Аргументы

- `matrix` — прямоугольная таблица: список непустых строк одной длины; может быть пустой (`[]`).

## Возвращает

Новая таблица из `len(matrix[0])` строк по `len(matrix)` элементов; для `[]` — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Исходную таблицу и её строки менять нельзя; строки результата должны быть новыми списками.

## Пример

```python
task_li18_transpose([[1, 2, 3], [4, 5, 6]])   # -> [[1, 4], [2, 5], [3, 6]]
task_li18_transpose([[1, 2]])                 # -> [[1], [2]]
task_li18_transpose([[7]])                    # -> [[7]]
task_li18_transpose([])                       # -> []
```

## Учебные цели

- Менять местами индексы строки и столбца при обходе таблицы.
- Заводить новую строку внутри внешнего цикла.
