# Задача LI15: Только положительные

## Условие

### Как это работает

Условие в конце списочного выражения — это фильтр. Берётся только тот элемент, для которого условие истинно:

```python
[number for number in nums if number > 10]
```

Это сборщик из цикла `for ... if ... append`, записанный в одну строку. Для `nums = [5, 12, 30, 8]` получится `[12, 30]`.

Элемент можно не преобразовывать (`number`), а можно положить вычисленное (`number * 2`): условие `if` проверяет исходный элемент.

### Задание

Напиши функцию `task_li15_positives(nums)`: верни новый список только из положительных чисел `nums` в исходном порядке. Используй списочное выражение с `if`.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Новый список элементов `nums`, которые больше нуля; ноль не положителен.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Запиши решение одним списочным выражением. Список `nums` менять нельзя.

## Пример

```python
task_li15_positives([3, -1, 0, 5])   # -> [3, 5]
task_li15_positives([-2, -3])        # -> []
task_li15_positives([])              # -> []
```

## Учебные цели

- Записать фильтр списочным выражением с условием `if` в конце.
- Не включать границу: ноль не положителен.
