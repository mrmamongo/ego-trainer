# Задача LI07: Убрать все вхождения

## Условие

### Как это работает

Метод `nums.remove(x)` удаляет только **первое** вхождение и к тому же меняет список на месте. Для функции, которой передали чужой список, это плохо.

Безопасный способ — сборщик: начать с пустого списка и добавлять в него только то, что нужно оставить:

```python
def without_zeros(nums):
    result = []
    for number in nums:
        if number != 0:
            result.append(number)
    return result
```

Входной список только читается. Новый список строится отдельно, и вызывающий код получает и старые данные, и новые.

### Задание

Напиши функцию `task_li07_remove_all(nums, x)`: верни **новый** список из `nums` без всех элементов, равных `x`. Исходный порядок оставшихся сохрани, `nums` не меняй.

## Аргументы

- `nums` — список целых чисел (может быть пустым).
- `x` — целое число, которое нужно убрать.

## Возвращает

Новый список без элементов, равных `x`; если `x` нет в списке, то копия `nums`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Метод `remove` не используй. Список `nums` менять нельзя, результат должен быть другим списком.

## Пример

```python
task_li07_remove_all([1, 2, 1, 3], 1)   # -> [2, 3]
task_li07_remove_all([4, 5], 9)         # -> [4, 5]
task_li07_remove_all([2, 2], 2)         # -> []
```

## Учебные цели

- Фильтровать список сборщиком, не меняя исходный.
- Возвращать новый список, даже когда ничего не убрали.
