# Срезы списков: всегда новый список

Срезы списков работают по тем же правилам, что и срезы строк: `nums[a:b]` берёт элементы с индексами от `a` до `b - 1`. **Начало входит, конец не входит.**

```python
nums = [5, 6, 7, 8, 9]
```

| Срез | Результат | Пояснение |
|---|---|---|
| `nums[1:3]` | `[6, 7]` | индексы 1 и 2 |
| `nums[:2]` | `[5, 6]` | с начала до индекса 1 |
| `nums[2:]` | `[7, 8, 9]` | с индекса 2 до конца |
| `nums[-2:]` | `[8, 9]` | последние два |
| `nums[1:-1]` | `[6, 7, 8]` | без первого и последнего |
| `nums[::2]` | `[5, 7, 9]` | через один |
| `nums[::-1]` | `[9, 8, 7, 6, 5]` | задом наперёд |
| `nums[2:2]` | `[]` | пустой срез |
| `nums[:]` | `[5, 6, 7, 8, 9]` | копия всего списка |

В отличие от индекса, срез **не бывает ошибкой** по границам: `nums[3:100]` даст `[8, 9]`, а `nums[10:]` даст `[]`. Для короткого списка `[1]` срез `nums[1:-1]` просто пустой.

## Срез — это НОВЫЙ список

Результат среза лежит в отдельном списке. Менять его можно, исходный список от этого не меняется.

```python
nums = [5, 6, 7]            # 1
part = nums[:2]             # 2
part[0] = 0                 # 3
```

| После строки | nums | part |
|---|---|---|
| 2 | `[5, 6, 7]` | `[5, 6]` |
| 3 | `[5, 6, 7]` | `[0, 6]` |

Поэтому `nums[:]` — самый короткий способ **скопировать** список.

## Склеить списки: +

`a + b` строит **новый** список из элементов `a`, а затем `b`. Исходные списки не меняются.

```python
[1, 2] + [3]                # [1, 2, 3]
nums[2:] + nums[:2]         # [7, 8, 9, 5, 6]  - «прокрутили» список
```

`+` складывает только список со списком: `nums + 5` даст ошибку, нужно `nums + [5]`.

## Частые ошибки

Забыть, что конец не входит: `nums[0:2]` — это два элемента, а не три.

Перепутать индекс и срез: `nums[1]` — это **число**, а `nums[1:2]` — **список** из одного элемента (`[6]`).

## Проверь себя

```python
nums = [1, 2, 3, 4, 5]
```

1. Чему равны `nums[1:4]`, `nums[-2:]` и `nums[:0]`?
2. Как получить список без первого элемента?

<details><summary>Ответ</summary>

1. `[2, 3, 4]`, `[4, 5]` и `[]`.
2. `nums[1:]` — все элементы, начиная с индекса 1. Исходный `nums` не изменится.

</details>
