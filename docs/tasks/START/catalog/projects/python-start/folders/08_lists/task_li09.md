# Задача LI09: Что вернул метод

## Условие

### Как это работает

Одни методы списка **возвращают значение** (`pop`, `index`, `count`), другие только меняют список и возвращают `None` (`append`, `insert`, `remove`, `sort`).

```python
nums = [4, 6, 8]       # 1
a = nums.pop()         # 2
b = nums.sort()        # 3
```

| После строки | nums | a | b |
|---|---|---|---|
| 1 | `[4, 6, 8]` | — | — |
| 2 | `[4, 6]` | `8` | — |
| 3 | `[4, 6]` | `8` | `None` |

В `b` лежит `None`, потому что `sort` ничего не возвращает. Проверить это можно выражением `b is None`: оно даёт `True`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `x` и `y` — то, что вернули два `pop`; `z_is_none` — `True` или `False`; `first` — первый элемент `nums` после строки 9; `pos` — индекс тройки после строки 10.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_li09_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Различать методы, возвращающие значение, и методы, возвращающие `None`.
- Следить за содержимым списка после цепочки вызовов.

## Проверка понимания

Что лежало в `nums` после строки 6 и после строки 7? Почему писать `nums = nums.sort()` нельзя?
