# Задача LI14: Квадраты одной строкой

## Условие

### Как это работает

Списочное выражение — это сборщик в одну строку: «что кладём, для каждого элемента откуда».

```python
[number * 2 for number in nums]
```

| В цикле | В выражении |
|---|---|
| `result = []` | скобки `[ ... ]` |
| `for number in nums:` | `for number in nums` |
| `result.append(number * 2)` | `number * 2` в начале |

Для `nums = [1, 2, 3]` получится `[2, 4, 6]`. Список `nums` выражение не меняет, оно строит новый.

### Задание

Напиши функцию `task_li14_squares(nums)`: верни новый список квадратов чисел из `nums`. Запиши результат одним списочным выражением.

## Аргументы

- `nums` — список целых чисел (может быть пустым, числа могут быть отрицательными).

## Возвращает

Новый список, где каждый элемент — квадрат соответствующего элемента `nums`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Запиши решение одним списочным выражением: `return [ ... ]`. Список `nums` менять нельзя.

## Пример

```python
task_li14_squares([1, 2, 3])   # -> [1, 4, 9]
task_li14_squares([-2, 0])     # -> [4, 0]
task_li14_squares([])          # -> []
```

## Учебные цели

- Записать простое превращение списка списочным выражением.
- Помнить, что выражение возвращает новый список и не меняет исходный.

## Проверка понимания

Что вернёт выражение для пустого списка? Изменится ли `nums`, когда ты вызовешь функцию?
