# Задача LI03: Срезы

## Условие

### Как это работает

Срез `nums[a:b]` берёт элементы с индексами от `a` до `b - 1`: конец не входит. Результат — **новый** список.

```python
nums = [5, 6, 7, 8]    # 1
part = nums[1:3]       # 2
nums[1] = 0            # 3
```

| После строки | nums | part |
|---|---|---|
| 1 | `[5, 6, 7, 8]` | — |
| 2 | `[5, 6, 7, 8]` | `[6, 7]` |
| 3 | `[5, 0, 7, 8]` | `[6, 7]` |

Срез `part` уже не связан с `nums`: изменение `nums` на нём не сказалось.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a_sum` — сумма элементов списка `a`; `b_len` — его длина; `c_first` — первый элемент `c`; `d_last` — последний элемент `d`; `e_len` — длина `e`; `b_first_final` — первый элемент `b` после строки 7.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_li03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать срезы с пропущенными границами, отрицательными индексами и шагом.
- Помнить, что срез — новый список, не связанный с исходным.

## Проверка понимания

Почему `b[0]` остался `5`, хотя на строке 7 в `nums` первый элемент стал `0`? Чему равен срез `nums[10:]`?
