# Задача LI12: Слова по длине

## Условие

### Как это работает

Параметр `key=` говорит `sorted`, **по чему** сравнивать. `key=len` значит «сравнивать по длине слова»:

```python
sorted(["ccc", "a", "bb"], key=len)      # ['a', 'bb', 'ccc']
```

После `key=` пишут сам `len`, без скобок: функция не вызывается, её передают сортировке.

Сортировка **устойчива**: слова с одинаковой длиной остаются в том порядке, в котором стояли в исходном списке.

```python
sorted(["bb", "a", "cc", "d"], key=len)  # ['a', 'd', 'bb', 'cc']
```

`"a"` и `"d"` одной длины, и `"a"` стоит раньше в исходном списке. Так же `"bb"` раньше `"cc"`. Свой порядок для равных вводить не нужно.

### Задание

Напиши функцию `task_li12_sort_by_length(words)`: верни новый список слов, упорядоченный по возрастанию длины. Слова одинаковой длины сохраняют исходный порядок.

## Аргументы

- `words` — список строк (может быть пустым, могут быть повторы).

## Возвращает

Новый список тех же слов, от самого короткого к самому длинному.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `sorted` с `key=len`. Список `words` менять нельзя.

## Пример

```python
task_li12_sort_by_length(["ccc", "a", "bb"])        # -> ['a', 'bb', 'ccc']
task_li12_sort_by_length(["bb", "a", "cc", "d"])    # -> ['a', 'd', 'bb', 'cc']
task_li12_sort_by_length([])                        # -> []
```

## Учебные цели

- Сортировать по ключу `key=len`.
- Знать, что равные по ключу элементы сохраняют исходный порядок.

## Проверка понимания

Почему для `["bb", "a", "cc", "d"]` ответ начинается с `"a"`, а не с `"d"`? Почему нельзя написать `key=len()`?
