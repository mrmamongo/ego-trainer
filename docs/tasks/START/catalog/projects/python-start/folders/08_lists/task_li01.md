# Задача LI01: Номера и замена по номеру

## Условие

### Как это работает

Элемент списка берут по номеру: `nums[0]` — первый, `nums[-1]` — последний. Тот же номер слева от `=` **заменяет** элемент:

```python
nums = [7, 8, 9]       # 1
nums[1] = 0            # 2
nums[-1] = nums[0]     # 3
```

| После строки | nums |
|---|---|
| 1 | `[7, 8, 9]` |
| 2 | `[7, 0, 9]` |
| 3 | `[7, 0, 7]` |

Справа значение считается по текущему списку, потом кладётся в ячейку. Отрицательный индекс считает с конца: `-1` последний, `-2` предпоследний.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `first`, `last` — значения, прочитанные на строках 2 и 3; `second_final` и `third_final` — элементы `nums[1]` и `nums[2]` после всех строк; `size` — длина в конце.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_li01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать элементы по положительному и отрицательному индексу.
- Понимать, что присваивание по номеру меняет ячейку списка.

## Проверка понимания

Почему строка `nums[-2] = ...` изменила элемент с индексом 2, а не 1? Что бы случилось, если бы в списке было всего два элемента и мы написали `nums[2] = 5`?
