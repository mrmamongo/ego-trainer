# Задача LI06: Копия, которая не копия

## Условие

### Как это работает

Функция должна вернуть **отсортированную копию**, не трогая исходный список. Но в ней строка `copy = nums` не создаёт копию: это второе имя того же списка.

```python
def sorted_copy(nums):
    copy = nums          # второе имя, не копия
    copy.sort()          # сортирует тот же самый список
    return copy
```

| Что | Значение |
|---|---|
| `nums` до вызова | `[3, 1, 2]` |
| что вернула функция | `[1, 2, 3]` |
| `nums` после вызова | `[1, 2, 3]` — исходный список испорчен |

Результат выглядит правильно, но вызывающий код потерял свой порядок. Нужно сделать настоящую копию (`nums[:]`) и сортировать её.

### Задание

Функция `task_li06_sorted_copy(nums)` должна вернуть новый список из чисел `nums` по возрастанию, не меняя `nums`. Сейчас она сортирует и сам `nums`. Найди ошибку и исправь.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Новый отсортированный по возрастанию список; `nums` остаётся прежним.

## Правила

- Меняй только ту строку, которая «копирует» список; остальной код оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Проверка сравнит `nums` до и после вызова и убедится, что результат — другой список.

## Пример

```python
data = [3, 1, 2]
task_li06_sorted_copy(data)   # -> [1, 2, 3]
# data по-прежнему [3, 1, 2]
```

## Учебные цели

- Находить место, где «копия» оказалась вторым именем списка.
- Делать копию срезом и сортировать только её.

## Проверка понимания

Почему результат сортировки был правильным, а функция всё равно считалась неверной? Чем `copy = nums[:]` отличается от `copy = nums`?
