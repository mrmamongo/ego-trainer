# Задача LI11: Три самых больших

## Условие

### Как это работает

`sorted(nums, reverse=True)` строит **новый** список по убыванию, а `nums` остаётся прежним. Три самых больших — это первые три элемента такого списка:

```python
sorted([5, 9, 1, 7, 3], reverse=True)          # [9, 7, 5, 3, 1]
sorted([5, 9, 1, 7, 3], reverse=True)[:3]      # [9, 7, 5]
```

Если элементов меньше трёх, срез `[:3]` просто возьмёт все, ошибки не будет. Повторяющиеся числа не склеиваются: у `[5, 5, 3]` три элемента.

Метод `nums.sort(reverse=True)` тоже умеет сортировать по убыванию, но он сортирует **сам `nums`**, то есть испортит чужой список.

### Задание

Напиши функцию `task_li11_top3(nums)`: верни новый список из трёх самых больших чисел по убыванию (или из всех, если их меньше трёх).

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Список из не более чем трёх самых больших чисел `nums`, от большего к меньшему.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `sorted(..., reverse=True)`. Метод `sort` на `nums` вызывать нельзя: список `nums` должен остаться прежним.

## Пример

```python
task_li11_top3([5, 9, 1, 7, 3])   # -> [9, 7, 5]
task_li11_top3([4, 2])            # -> [4, 2]
task_li11_top3([5, 5, 3, 1])      # -> [5, 5, 3]
task_li11_top3([])                # -> []
```

## Учебные цели

- Получать новый отсортированный список функцией `sorted`.
- Брать первые элементы срезом, не боясь коротких списков.
