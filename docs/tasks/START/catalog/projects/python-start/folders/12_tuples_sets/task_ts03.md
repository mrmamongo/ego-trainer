# Задача TS03: Сдвиг точки

## Условие

### Как это работает

Кортеж **нельзя менять на месте**: присваивание по индексу вызывает ошибку.

```python
point = (3, 7)
point[0] = 5          # TypeError: 'tuple' object does not support item assignment
```

Чтобы получить «изменённый» кортеж, собирают **новый** из нужных частей:

```python
point = (5, point[1])     # новый кортеж (5, 7)
```

Старый кортеж остаётся таким, каким был, пока на него кто-то ссылается.

### Задание

Функция `task_ts03_move_x(point, new_x)` должна вернуть точку с новой координатой `x`, а `y` оставить прежней. Сейчас она падает с ошибкой. Найди её и исправь.

## Аргументы

- `point` — кортеж `(x, y)` из двух целых чисел.
- `new_x` — новое целое значение `x`.

## Возвращает

Новый кортеж `(new_x, y)`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Результат должен быть именно кортежем, не списком.

## Пример

```python
task_ts03_move_x((1, 2), 5)    # -> (5, 2)
task_ts03_move_x((4, 9), 4)    # -> (4, 9)
```

## Учебные цели

- Понимать, что кортеж нельзя менять присваиванием по индексу.
- Собирать новый кортеж вместо изменения старого.

## Проверка понимания

Почему `point[0] = new_x` падает, а `point = (new_x, point[1])` работает? Изменится ли исходный кортеж, который передали в функцию?
