# Кортеж: неизменяемый список

**Кортеж** (`tuple`) похож на список: элементы идут по порядку, у каждого есть номер, работают `len`, индексы и срезы. Но кортеж **нельзя изменить**: нельзя присвоить элементу, добавить или удалить. Записывают его в круглых скобках.

```python
point = (3, 7)          # 1
x = point[0]            # 2
size = len(point)       # 3
point[0] = 5            # 4  ошибка: TypeError
```

Строка 4 упадёт: кортеж не поддерживает присваивание по индексу (как и строки из папки про строки). Если нужно «изменённое» значение, строят **новый** кортеж:

```python
point = (5, point[1])   # новый кортеж (5, 7), имя point теперь указывает на него
```

## Скобки и запятые

Главное в кортеже запятые, а не скобки: `a, b` уже кортеж. Именно так `return low, high` из карточки про возврат нескольких значений отдаёт кортеж. Для кортежа из одного элемента запятая обязательна: `(4,)`, а `(4)` — просто число 4 в скобках.

## Распаковка

Кортеж можно разложить по именам: значения раздаются по порядку, и имён должно быть ровно столько, сколько элементов.

```python
point = (3, 7)          # 1
x, y = point            # 2
x, y = y, x             # 3
```

| После строки | point | x | y |
|---|---|---|---|
| 1 | `(3, 7)` | — | — |
| 2 | `(3, 7)` | `3` | `7` |
| 3 | `(3, 7)` | `7` | `3` |

Строка 3 меняет значения местами. Справа сначала собирается кортеж `(y, x)` = `(7, 3)` из **старых** значений, потом он распаковывается в `x` и `y`. Третья переменная для обмена не нужна. Сам `point` остался прежним: он неизменяем.

## Кортеж как запись

Список обычно хранит много однотипных вещей (оценки, слова). Кортеж хранит **фиксированную запись из нескольких частей**: `("Аня", 17)` — имя и возраст, `(3, 7)` — координаты. Порядок частей надо помнить и записать в условии.

| | список | кортеж |
|---|---|---|
| Запись | `[1, 2]` | `(1, 2)` |
| Менять на месте | да | **нет** |
| Для чего | много однотипных элементов | запись фиксированной формы |

## Частые ошибки

Пытаться изменить кортеж:

```python
point[0] = 5           # неверно: TypeError
```

```python
point = (5, point[1])  # верно: новый кортеж
```

Перепутать число имён и элементов: `a, b = (1, 2, 3)` даст ошибку.

## Проверь себя

```python
pair = (10, 20)
a, b = pair
a, b = b, a + b
```

1. Чему равны `a` и `b` в конце?
2. Что останется в `pair`?

<details><summary>Ответ</summary>

1. После распаковки `a = 10`, `b = 20`. В последней строке справа считается `(b, a + b)` = `(20, 30)` по старым значениям, поэтому `a = 20`, `b = 30`.
2. `pair` остался `(10, 20)`: кортеж не менялся.

</details>
