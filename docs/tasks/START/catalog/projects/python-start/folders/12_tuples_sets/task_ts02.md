# Задача TS02: Наименьшее и наибольшее

## Условие

### Как это работает

Функция может вернуть сразу два значения: `return low, high` упаковывает их в кортеж. Вызывающий код получает пару и может сразу распаковать её: `low, high = ...`.

Наименьшее и наибольшее ищут за один проход двумя «лучшими»: оба начинают с первого элемента, а в цикле каждый обновляется по своему условию.

```python
def low_high(nums):
    low = nums[0]
    high = nums[0]
    for n in nums:
        if n < low:
            low = n
        if n > high:
            high = n
    return low, high        # кортеж (low, high)
```

| Проход | n | low | high |
|---|---|---|---|
| старт | — | 5 | 5 |
| 1 | 5 | 5 | 5 |
| 2 | 8 | 5 | 8 |
| 3 | 2 | 2 | 8 |

(для `nums = [5, 8, 2]`)

### Задание

Напиши функцию `task_ts02_min_max(nums)`: верни кортеж `(наименьшее, наибольшее)`.

## Аргументы

- `nums` — непустой список целых чисел.

## Возвращает

Кортеж из двух чисел: сначала наименьшее, потом наибольшее. Для списка из одного числа оба равны этому числу.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `min`, `max` и `sorted`, а также метод `sort` использовать нельзя: ищи циклом.
- Список `nums` не меняй.

## Пример

```python
task_ts02_min_max([4, 9, 2, 7])   # -> (2, 9)
task_ts02_min_max([5])            # -> (5, 5)
task_ts02_min_max([-3, -8, -1])   # -> (-8, -1)
```

## Учебные цели

- Искать два «лучших» значения за один проход.
- Возвращать пару значений кортежем.
