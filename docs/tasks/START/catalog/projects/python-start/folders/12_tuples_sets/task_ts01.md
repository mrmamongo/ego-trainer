# Задача TS01: Распаковка и обмен

## Условие

### Как это работает

**Кортеж** — это набор значений в круглых скобках, как список, который нельзя менять. Его можно **распаковать**: разложить по именам, по порядку.

```python
point = (3, 7)      # 1
x, y = point        # 2
x, y = y, x         # 3
```

| После строки | point | x | y |
|---|---|---|---|
| 1 | `(3, 7)` | — | — |
| 2 | `(3, 7)` | `3` | `7` |
| 3 | `(3, 7)` | `7` | `3` |

Строка 3 меняет `x` и `y` местами. Справа сначала собирается кортеж из **старых** значений, потом он распаковывается. Сам `point` не меняется.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: построй таблицу по строкам и найди ошибку сам.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_ts01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Распаковывать кортеж в несколько имён.
- Понимать обмен `x, y = y, x` без третьей переменной.
- Помнить, что исходный кортеж при распаковке не меняется.
