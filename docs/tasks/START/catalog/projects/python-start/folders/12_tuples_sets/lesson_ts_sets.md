# Множество: только уникальные

**Множество** (`set`) хранит элементы **без повторов** и **без порядка**. Записывают в фигурных скобках, но пустое множество создают только так: `set()` (пустые `{}` — это не множество).

```python
words = ["a", "b", "a", "c", "b", "a"]     # 1
unique = set(words)                        # 2
has_c = "c" in unique                      # 3
unique.add("z")                            # 4
unique.add("a")                            # 5
unique.discard("b")                        # 6
```

| После строки | unique | len(unique) |
|---|---|---|
| 2 | `{"a", "b", "c"}` | 3 |
| 3 | `has_c` равно `True` | 3 |
| 4 | `{"a", "b", "c", "z"}` | 4 |
| 5 | то же самое: `"a"` уже есть | 4 |
| 6 | `{"a", "c", "z"}` | 3 |

`set(список)` выбрасывает повторы. `add(x)` добавляет элемент, а если он уже есть, ничего не происходит и ошибки нет. `discard(x)` убирает элемент, и если его не было, это тоже не ошибка.

## `in` быстрый

Проверка `x in множество` отвечает сразу, а для списка Python просматривает элементы по очереди. Поэтому, когда надо часто спрашивать «видел ли я это?», увиденное складывают в множество.

## Порядка нет

Множество не помнит, в каком порядке добавляли элементы: у него нет индексов и срезов, `unique[0]` — ошибка. Если порядок нужен, сделай из множества отсортированный список:

```python
sorted({"b", "c", "a"})        # ['a', 'b', 'c']
sorted(set([3, 1, 3, 2]))      # [1, 2, 3]
```

`sorted` возвращает обычный список, и проверка сравнивает именно списки. Порядок элементов у самого множества может быть любым, поэтому его нельзя сравнивать со списком.

## Роль «увиденные»

Пустое множество перед циклом, в теле — проверка и добавление:

```python
def first_seen_twice(items):
    seen = set()
    for item in items:
        if item in seen:
            return item       # уже видели: это повтор
        seen.add(item)
    return ""
```

## Частые ошибки

Создать пустое множество как `{}`:

```python
seen = {}          # неверно: это не множество
```

```python
seen = set()       # верно
```

Ждать, что `len(set(items))` равно `len(items)`: оно меньше, если в списке есть повторы. На этом строится проверка «есть ли повторы».

## Проверь себя

```python
s = set([4, 4, 1, 4])
s.add(1)
s.add(9)
s.discard(7)
```

1. Чему равна `len(s)`?
2. Чему равно `sorted(s)`?

<details><summary>Ответ</summary>

1. `3`: в `s` лежат `1`, `4` и `9`. Повторы не считаются, а `discard(7)` ничего не сломал.
2. `[1, 4, 9]`.

</details>
