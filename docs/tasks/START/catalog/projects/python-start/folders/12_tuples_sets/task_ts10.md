# Задача TS10: Сколько разных слов

## Условие

### Как это работает

Чтобы посчитать разные слова в тексте, нужно привести их к одному виду, а потом сложить в множество: оно само выбросит повторы.

1. `text.lower()` — все буквы строчные, чтобы `"Привет"` и `"привет"` стали одним словом.
2. `.split()` — список слов.
3. Знаки препинания по краям слова убирает `word.strip(".,!?")`: в скобках перечислены символы, которые срезаются с обоих концов слова. Внутри слова они остаются.
4. `add` в множество и в конце `len`.

```python
text = "Hi, hi! Bye."
unique = set()
for word in text.lower().split():       # "hi,", "hi!", "bye."
    unique.add(word.strip(".,!?"))      # "hi", "hi", "bye"
len(unique)                             # 2
```

### Задание

Напиши функцию `task_ts10_count_unique_words(text)`: верни количество разных слов в тексте. Регистр не учитывается, знаки `.`, `,`, `!`, `?` по краям слов отбрасываются.

## Аргументы

- `text` — строка (может быть пустой). Слова разделены пробелами, у каждого слова есть хотя бы одна буква; знаки `. , ! ?` стоят только в конце слов.

## Возвращает

Целое число: сколько различных слов в тексте; для пустой строки — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Исходную строку не меняй (строки и так неизменяемы: методы возвращают новую).

## Пример

```python
task_ts10_count_unique_words("Hello, hello! World.")   # -> 2
task_ts10_count_unique_words("a a a")                  # -> 1
task_ts10_count_unique_words("")                       # -> 0
```

## Учебные цели

- Нормализовать слова перед сравнением (`lower`, `strip`).
- Считать уникальные слова через `set` и `len`.

## Проверка понимания
