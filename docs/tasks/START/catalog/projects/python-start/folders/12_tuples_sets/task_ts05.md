# Задача TS05: Уникальные слова по алфавиту

## Условие

### Как это работает

Чтобы убрать повторы, список превращают в множество. У множества нет порядка, поэтому, когда порядок нужен, из него делают список через `sorted`:

```python
words = ["b", "a", "b", "c"]
unique = set(words)         # {"a", "b", "c"}, порядок не определён
result = sorted(unique)     # ['a', 'b', 'c']
```

`sorted` вернёт новый список и не тронет ни множество, ни исходный список.

### Задание

Напиши функцию `task_ts05_unique_sorted(words)`: верни список слов без повторов, по алфавиту.

## Аргументы

- `words` — список строк (может быть пустым, могут быть повторы).

## Возвращает

Новый список уникальных слов в порядке сортировки по умолчанию; для пустого списка — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Результат должен быть списком, не множеством.
- Исходный список `words` не меняй.

## Пример

```python
task_ts05_unique_sorted(["pear", "apple", "pear", "fig"])   # -> ['apple', 'fig', 'pear']
task_ts05_unique_sorted([])                                 # -> []
```

## Учебные цели

- Убирать повторы через `set`.
- Возвращать упорядоченный список из множества.
