# Задача TS04: Множество из списка

## Условие

### Как это работает

**Множество** (`set`) хранит только уникальные элементы. `set(список)` выбрасывает повторы, `len` считает, сколько элементов осталось, `in` отвечает, есть ли элемент. `add` добавляет элемент: если он уже есть, ничего не происходит.

```python
nums = [1, 2, 2, 3, 1]      # 1
s = set(nums)               # 2
s.add(2)                    # 3
s.add(9)                    # 4
```

| После строки | s | len(s) |
|---|---|---|
| 2 | `{1, 2, 3}` | 3 |
| 3 | `{1, 2, 3}` (двойка уже была) | 3 |
| 4 | `{1, 2, 3, 9}` | 4 |

Порядок элементов в множестве не важен, поэтому в этой задаче спрашиваем только про размеры и про `in`.
