# Задача TS06: Общие друзья

## Условие

### Как это работает

**Пересечение** `a & b` — элементы, которые есть и в `a`, и в `b`. Операции работают с множествами, поэтому списки сначала превращают в `set`, а в конце сортируют:

```python
mine = ["Аня", "Боря", "Вера"]
yours = ["Боря", "Глеб", "Вера"]
common = set(mine) & set(yours)     # {"Боря", "Вера"}
sorted(common)                      # ['Боря', 'Вера']
```

### Задание

Напиши функцию `task_ts06_common_friends(a, b)`: верни список имён, которые есть и в `a`, и в `b`, без повторов, по алфавиту.

## Аргументы

- `a`, `b` — списки строк (могут быть пустыми, внутри списка имена могут повторяться).

## Возвращает

Отсортированный список общих имён без повторов; если общих нет — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Результат должен быть списком, не множеством.
- Исходные списки не меняй.

## Пример

```python
task_ts06_common_friends(["Аня", "Боря", "Вера"], ["Боря", "Глеб", "Вера"])   # -> ['Боря', 'Вера']
task_ts06_common_friends(["a"], ["b"])                                        # -> []
```

## Учебные цели

- Применять пересечение множеств `&`.
- Приводить результат к отсортированному списку.

## Проверка понимания

Изменится ли результат, если поменять `a` и `b` местами? А если в `a` имя встречается дважды?
