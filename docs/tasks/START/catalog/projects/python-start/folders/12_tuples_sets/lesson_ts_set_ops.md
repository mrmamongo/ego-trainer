# Операции над множествами

Множества можно объединять, пересекать и вычитать, как круги на диаграмме Венна. Результат всегда **новое** множество, исходные не меняются.

```python
a = {1, 2, 3, 4}        # 1
b = {3, 4, 5}           # 2
```

| Запись | Смысл | Какая часть кругов | Результат |
|---|---|---|---|
| `a \| b` | объединение: есть в `a` **или** в `b` | всё закрашено | `{1, 2, 3, 4, 5}` |
| `a & b` | пересечение: есть и в `a`, **и** в `b` | только середина | `{3, 4}` |
| `a - b` | разность: есть в `a`, но **нет** в `b` | только левая часть | `{1, 2}` |
| `b - a` | наоборот: есть в `b`, но нет в `a` | только правая часть | `{5}` |
| `a ^ b` | симметричная разность: есть **ровно в одном** из двух | обе боковые части | `{1, 2, 5}` |

Обрати внимание: `a - b` и `b - a` дают разное, а `a | b`, `a & b` и `a ^ b` от порядка множеств не зависят.

## Из списков и обратно

Операции работают с множествами, поэтому списки сначала превращают в `set`, а в конце, если нужен порядок, делают `sorted`:

```python
mine = ["Аня", "Боря", "Вера"]
yours = ["Боря", "Глеб", "Вера"]
common = sorted(set(mine) & set(yours))     # ['Боря', 'Вера']
only_mine = sorted(set(mine) - set(yours))  # ['Аня']
```

## Частые ошибки

Перепутать, из чего вычитается: `set(yours) - set(mine)` даст `['Глеб']`, а не `['Аня']`.

Вернуть множество там, где в условии список:

```python
return set(mine) & set(yours)             # неверно: нужен список
return sorted(set(mine) & set(yours))     # верно
```

## Проверь себя

```python
x = {"a", "b", "c"}
y = {"c", "d"}
```

1. Что дают `x & y`, `x - y`, `y - x`?
2. Что даёт `sorted(x ^ y)`?

<details><summary>Ответ</summary>

1. `x & y` равно `{"c"}`, `x - y` равно `{"a", "b"}`, `y - x` равно `{"d"}`.
2. `['a', 'b', 'd']`: остались элементы, которые есть ровно в одном множестве (`"c"` есть в обоих, он выпал).

</details>
