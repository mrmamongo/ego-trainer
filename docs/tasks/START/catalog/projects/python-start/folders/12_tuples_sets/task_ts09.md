# Задача TS09: Первый повтор

## Условие

### Как это работает

Множество удобно как память «что я уже видел». Заводят пустое множество до цикла, а в цикле на каждом элементе спрашивают `in`: если элемент уже там, это повтор и можно сразу вернуть его (`return` внутри цикла сразу заканчивает функцию). Если нет, запоминают его через `add`.

```python
def first_seen_twice(items):
    seen = set()
    for item in items:
        if item in seen:
            return item
        seen.add(item)
    return ""
```

| Проход | item | seen до | Что делаем |
|---|---|---|---|
| 1 | `"x"` | `{}` | запоминаем |
| 2 | `"y"` | `{"x"}` | запоминаем |
| 3 | `"x"` | `{"x", "y"}` | уже видели: `return "x"` |

(для `items = ["x", "y", "x", "y"]`)

### Задание

Напиши функцию `task_ts09_first_repeat(items)`: верни первый элемент, который при просмотре слева направо **уже встречался раньше**. Если повторов нет, верни пустую строку `""`.

Важно, что значит «первый»: берётся тот элемент, чей повтор обнаружился раньше всех. Для `["a", "b", "c", "b", "a"]` ответ `"b"`: его второе вхождение стоит раньше, чем второе вхождение `"a"`.

## Аргументы

- `items` — список непустых строк (может быть пустым).

## Возвращает

Строку: первый обнаруженный повтор или `""`, если все элементы разные.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Запоминай увиденное в множестве (`set()`). Список для этого не годится: квадратные скобки-списки, `list(...)` и методы `count`, `index` использовать нельзя.

## Пример

```python
task_ts09_first_repeat(["a", "b", "a", "b"])        # -> 'a'
task_ts09_first_repeat(["x", "y", "y", "x"])        # -> 'y'
task_ts09_first_repeat(["a", "b", "c"])             # -> ''
```

## Учебные цели

- Использовать множество как память о просмотренном.
- Выходить из цикла через ранний `return`.
