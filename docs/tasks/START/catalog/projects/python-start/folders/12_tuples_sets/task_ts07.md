# Задача TS07: Только в первом списке

## Условие

### Как это работает

**Разность** `a - b` — элементы, которые есть в `a`, но **нет** в `b`. Порядок важен: `a - b` и `b - a` дают разное.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5}
a - b          # {1, 2}
b - a          # {5}
```

Для списков сначала делают `set`, а результат оборачивают в `sorted`:

```python
sorted(set([4, 1, 3]) - set([3]))     # [1, 4]
```

### Задание

Напиши функцию `task_ts07_only_in_first(a, b)`: верни отсортированный список элементов, которые есть в `a`, но нет в `b`. Повторов в результате быть не должно.

## Аргументы

- `a`, `b` — списки строк (могут быть пустыми, внутри списка могут быть повторы).

## Возвращает

Отсортированный список без повторов; если таких элементов нет — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Результат должен быть списком, не множеством.
- Исходные списки не меняй.

## Пример

```python
task_ts07_only_in_first(["Аня", "Боря", "Вера"], ["Боря", "Глеб"])   # -> ['Аня', 'Вера']
task_ts07_only_in_first(["a", "b"], ["b", "a"])                      # -> []
```

## Учебные цели

- Применять разность множеств `-`.
- Помнить, что порядок операндов разности важен.
