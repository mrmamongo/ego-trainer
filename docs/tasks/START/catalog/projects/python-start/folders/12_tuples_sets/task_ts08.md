# Задача TS08: Есть ли повторы

## Условие

### Как это работает

`set(items)` выбрасывает повторы, поэтому множество никогда не длиннее списка. Если длины разные, значит, часть элементов была лишней:

```python
len([1, 2, 1])          # 3
len(set([1, 2, 1]))     # 2   -> длины разные, повторы есть
len(set([1, 2, 3]))     # 3   -> длины равны, повторов нет
```

Получается проверка в одну строку: `len(set(items)) != len(items)`.

### Задание

Напиши функцию `task_ts08_has_duplicates(items)`: верни `True`, если в списке есть хотя бы два одинаковых элемента, иначе `False`.

## Аргументы

- `items` — список (может быть пустым); элементы можно сравнивать на равенство.

## Возвращает

`True` или `False`. Для пустого списка и списка из одного элемента — `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Решай через `len` и `set`: циклы (`for`, `while`) и методы `count`, `index` использовать нельзя.

## Пример

```python
task_ts08_has_duplicates([1, 2, 1])      # -> True
task_ts08_has_duplicates(["a", "A"])     # -> False
task_ts08_has_duplicates([])             # -> False
```

## Учебные цели

- Сравнивать размер списка и размер множества.
- Возвращать результат сравнения как `bool` напрямую.

## Проверка понимания

Почему `"a"` и `"A"` не считаются повтором? Можно ли после проверки сразу писать `return len(set(items)) != len(items)` без `if`?
