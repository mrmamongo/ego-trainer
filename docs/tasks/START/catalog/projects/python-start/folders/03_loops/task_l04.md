# Задача L04: Сколько всего букв

## Условие

### Как это работает

Функция `len(...)` возвращает **длину** — для строки это число символов (пробелы тоже считаются):

```python
len("кот")      # -> 3
len("a b")      # -> 3
len("")         # -> 0
```

Накопитель может копить не сами элементы, а то, что мы из них вычислили. Например, длины слов:

```python
def count_chars(words):
    total = 0
    for word in words:
        total = total + len(word)
    return total
```

Паспорт тот же, меняется только то, что прибавляем:

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + len(word)` | после цикла |

Для пустого списка слов — ни одной буквы, ответ `0`.

### Задание

Напиши функцию `task_l04_total_length(words)`: верни общее число символов во всех словах списка.

## Аргументы

- `words` — список строк (может быть пустым; слово может быть пустой строкой).

## Возвращает

Целое число — сумму длин всех слов.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `sum` не используй: нужен цикл с накопителем.

## Пример

```python
task_l04_total_length(["кот", "пёс"])   # -> 6
task_l04_total_length(["a b"])          # -> 3
task_l04_total_length([])               # -> 0
```

## Учебные цели

- Узнать `len()` для строки.
- Накапливать значение, вычисленное из элемента, а не сам элемент.
