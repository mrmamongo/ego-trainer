# Задача L05: Сумма равна последнему числу

## Условие

### Как это работает

Накопитель нужно завести **один раз, до цикла**. Если начальное значение стоит внутри цикла, оно выполняется на каждом проходе
и затирает всё накопленное:

```python
def total_price(prices):
    for price in prices:
        total = 0                  # плохо: обнуляем на каждом проходе
        total = total + price
    return total
```

| Проход | price | total после тела |
|---|---|---|
| 1 | 4 | 4 |
| 2 | 6 | 6 |

В итоге `total` равен только последнему элементу. А для пустого списка `total` вообще не появится, и `return total` упадёт с ошибкой.

Исправление — вынести `total = 0` из цикла, как в паспорте: «где заводим — до цикла».

### Задание

Функция `task_l05_sum_all(numbers)` должна вернуть сумму чисел, но возвращает только последнее. Найди ошибку и исправь.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Целое число — сумму элементов; для пустого списка — `0`.

## Правила

- Менять нужно положение строки с начальным значением; остальной код оставь как есть.
- Встроенную функцию `sum` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l05_sum_all([1, 2, 3])   # -> 6
task_l05_sum_all([])          # -> 0
```

## Учебные цели

- Находить накопитель, который обнуляется на каждом проходе.
- Заводить накопитель до цикла.

## Проверка понимания

Что вернёт исходная функция для `[1, 2, 3]` и почему? Почему для `[]` она падает, а исправленная — нет?
