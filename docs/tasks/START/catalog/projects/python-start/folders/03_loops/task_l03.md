# Задача L03: Сумма списка

## Условие

### Как это работает

Накопитель из прошлой задачи — это готовая заготовка для суммы. Паспорт тот же:

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + number` | после цикла |

Обрати внимание, где стоит `return`: **после** цикла, на уровне `for`, а не внутри него.

```python
def total_price(prices):
    total = 0
    for price in prices:
        total = total + price
    return total
```

Для пустого списка цикл не выполнится, и функция вернёт начальное значение `0` — это правильный ответ.

### Задание

Напиши функцию `task_l03_sum(numbers)`: верни сумму всех чисел списка.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Целое число — сумму элементов; для пустого списка — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `sum` не используй: цель — научиться делать накопитель самому.

## Пример

```python
task_l03_sum([1, 2, 3])   # -> 6
task_l03_sum([-5, 5])     # -> 0
task_l03_sum([])          # -> 0
```

## Учебные цели

- Писать цикл с накопителем: начальное значение до цикла, изменение в теле, `return` после цикла.
- Помнить, что начальное значение — ответ для пустого списка.
