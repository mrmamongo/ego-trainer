# Задача L09: Сколько длинных слов

## Условие

### Как это работает

Условие для счётчика может зависеть от **второго параметра** функции и от вычисления над элементом. Здесь нужно сравнить длину слова
(`len(word)`) с порогом `min_len`:

```python
def count_big(numbers, limit):
    count = 0
    for number in numbers:
        if number >= limit:
            count = count + 1
    return count
```

Паспорт счётчика не меняется:

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если слово подошло | после цикла |

### Задание

Напиши функцию `task_l09_count_long_words(words, min_len)`: верни, сколько слов имеют длину не меньше `min_len`.

## Аргументы

- `words` — список строк (может быть пустым).
- `min_len` — целое число от 0.

## Возвращает

Целое число — количество слов, у которых `len(word) >= min_len`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l09_count_long_words(["кот", "слон", "мышь"], 4)   # -> 2
task_l09_count_long_words(["дом", "лес"], 5)            # -> 0
task_l09_count_long_words([], 3)                        # -> 0
```

## Учебные цели

- Комбинировать `len()` и счётчик.
- Использовать параметр функции в условии внутри цикла.

## Проверка понимания

Почему условие записано как `>=`, а не `>`? Что вернёт функция для `(["a", ""], 0)`?
