# Задача L16: Все ли сдали

## Условие

### Как это работает

Флаг бывает и «наоборот»: сначала `True` («пока всё хорошо»), и он становится `False`, как только найден плохой элемент.

```python
def all_small(numbers, limit):
    all_ok = True
    for number in numbers:
        if number > limit:
            all_ok = False
    return all_ok
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `True` | `all_ok = False` — когда нашли нарушителя | после цикла |

А что для пустого списка? Проверять некого, и ни один элемент не нарушил условие, поэтому ответ `True`.
Опять работает правило: **начальное значение — это ответ для пустого списка.**

### Задание

Напиши функцию `task_l16_all_passed(scores, threshold)`: верни `True`, если все баллы не меньше порога `threshold`, иначе `False`. Для пустого списка ответ `True`.

## Аргументы

- `scores` — список целых баллов (может быть пустым).
- `threshold` — целый проходной балл.

## Возвращает

`True`, если каждый балл `>= threshold` (и для пустого списка), иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `all` и `any` не используй.

## Пример

```python
task_l16_all_passed([60, 70, 80], 60)   # -> True
task_l16_all_passed([60, 59, 80], 60)   # -> False
task_l16_all_passed([], 60)             # -> True
```

## Учебные цели

- Писать флаг с начальным значением `True`.
- Объяснять, почему для пустого списка ответ `True`.

## Проверка понимания

Почему для `[]` верно вернуть `True`? Что вернёт функция для `([50], 50)`?
