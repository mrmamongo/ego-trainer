# Накопитель: сумма в цикле

Часто в цикле нужно что-то **накапливать**: сумму цен, общую длину, итог.
Для этого заводят переменную-**накопитель** (обычно `total`): до цикла она получает начальное значение, а на каждом проходе к ней прибавляют очередной элемент.

```python
total = 0                   # 1
for price in [4, 6]:        # 2
    total = total + price   # 3
```

| Проход | price | total после тела |
|---|---|---|
| 1 | 4 | 4 |
| 2 | 6 | 10 |

Справа считается `total + price` по **старому** `total`, потом результат записывается обратно (как `n = n + 1` в первой папке).

## Паспорт роли «накопитель»

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + item` | после цикла |

**Начальное значение — ответ для пустого списка.** Для пустого списка тело не выполнится, и сумма останется `0`. Поэтому для суммы начинаем с `0`.

```python
def total_price(prices):
    total = 0
    for price in prices:
        total = total + price
    return total
```

`return` стоит **после** цикла, на том же уровне, что и `for`.

## Копить можно и вычисленное

Накопитель может копить не сами элементы, а то, что из них вычислили. Например, длины слов. `len(...)` возвращает длину: для строки это число символов (пробелы тоже считаются): `len("кот")` равно 3, `len("")` равно 0.

```python
def count_chars(words):
    total = 0
    for word in words:
        total = total + len(word)
    return total
```

Паспорт тот же, меняется только то, что прибавляем.

## Накопитель не всегда начинается с нуля

Начальное значение — то, с чего всё стартует. Например, баланс счёта начинается со `start`: `value = start`, а для пустого списка операций ответ — `start`.

## Частые ошибки

Завести накопитель внутри цикла — он затирается на каждом проходе:

```python
for price in prices:
    total = 0                  # неверно: обнуляем на каждом проходе
    total = total + price
return total                   # получится только последний элемент
```

```python
total = 0                      # верно: один раз, до цикла
for price in prices:
    total = total + price
```

Поставить `return` внутри цикла: функция выйдет на первом проходе и вернёт только первое число (а для пустого списка вернёт `None`).

```python
for price in prices:
    total = total + price
    return total               # неверно: выход после первого прохода
```

## Проверь себя

```python
total = 0
for n in [3, 5, 2]:
    total = total + n
```

1. Чему равно `total` после каждого прохода?
2. Что вернёт функция с таким телом для `[]`?

<details><summary>Ответ</summary>

1. После прохода 1 — `3`, после 2 — `8`, после 3 — `10`.
2. Тело не выполнится, останется начальное значение: `0`.

</details>
