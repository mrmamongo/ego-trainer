# Задача L13: return внутри цикла

## Условие

### Как это работает

В задаче про сумму `return` внутри цикла был ошибкой. Но бывает, что выйти из функции раньше нужно: как только нашли то, что искали,
остальные элементы можно не смотреть. `return` останавливает **всю** функцию, включая цикл.

```python
def first_big(numbers):
    for number in numbers:      # 1
        if number > 10:         # 2
            return number       # 3
    return 0                    # 4
```

- `first_big([3, 20, 50])`: на втором проходе `20 > 10`, выполняется `return 20`. Элемент `50` даже не рассматривается.
- `first_big([3, 4])`: условие ни разу не верно, цикл заканчивается сам, и выполняется `return 0` после цикла.
- `first_big([])`: тело не выполняется, сразу `return 0`.

Строка `return` после цикла — это ответ на случай «не нашли». Она выполнится, только если внутри цикла выход не сработал.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a`, `b`, `c` — значения, которые вернёт `first_negative` при трёх вызовах.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_l13_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что `return` внутри цикла завершает функцию сразу.
- Видеть, когда выполняется `return` после цикла.

## Проверка понимания

Сколько проходов цикла выполнится в вызове `first_negative([4, -2, -7])`? Почему `-7` не попадёт в ответ?
