# Задача L01: Список и цикл for

## Условие

### Как это работает

**Список** — несколько значений под одним именем, в квадратных скобках через запятую: `[3, 8, 1]`. Пустой список записывается `[]`.

Цикл `for` проходит по списку: тело цикла (строки с отступом) выполняется **по одному разу на каждый элемент**.
Переменная цикла получает не номер, а само **значение** очередного элемента: сначала первого, потом второго и так далее.

```python
prices = [5, 7]
for price in prices:       # 1
    double = price * 2     # 2
```

| Проход | price | double после тела |
|---|---|---|
| 1 | 5 | 10 |
| 2 | 7 | 14 |

После цикла в `price` остаётся последнее значение (7), в `double` — 14. Один проход — одно выполнение тела.

**Паспорт роли «текущий элемент»** (имена `item`, `number`, `word`, `price`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| в заголовке `for` | не нужно, цикл даёт сам | не меняем: значение подставляет цикл | не возвращаем, нужен только внутри тела |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `times_body_runs` — сколько раз выполнится тело цикла, `number_on_iteration_2` — чему равно `number` на втором проходе, `last_final` — значение `last` после цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_l01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что тело цикла выполняется по разу на каждый элемент списка.
- Знать, что переменная цикла получает значения элементов, а не их номера.

## Проверка понимания

Что окажется в `last`, если список `numbers` будет `[3, 8, 1, 6]`? Что изменится, если `last = number` заменить на `last = 0`?
