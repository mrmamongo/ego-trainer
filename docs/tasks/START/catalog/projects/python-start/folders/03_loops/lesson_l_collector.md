# Сборщик: пустой список и append

Иногда нужно вернуть не число, а **новый список** из подходящих элементов. Для этого заводят пустой список `[]`
и на подходящих проходах добавляют в него элемент методом `append`:

```python
result = []          # пустой список
result.append(5)     # теперь [5]
result.append(8)     # теперь [5, 8]
```

`append` добавляет элемент в **конец** списка и сам ничего не возвращает: пиши `result.append(x)`, а не `result = result.append(x)`.

## Паспорт роли «сборщик»

Имя обычно `result`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(item)` — только если элемент подошёл | после цикла |

Начальное значение — снова ответ для пустого списка: подходящих нет, значит, и собранный список пуст.

## Фильтр: берём только подходящие

**Отступы** показывают вложенность: `result.append(...)` стоит под `if`, а `if` — под `for`.

```python
def positives(numbers):
    result = []
    for number in numbers:
        if number > 0:
            result.append(number)
    return result
```

| Проход | number | условие | result после тела |
|---|---|---|---|
| 1 | 5 | да | `[5]` |
| 2 | -1 | нет | `[5]` |
| 3 | 8 | да | `[5, 8]` |

Условие может зависеть от параметра функции (`if number > limit:`). Порядок в новом списке такой же, как в исходном.
Исходный список функция **не меняет**: она строит и возвращает новый.

## Преобразование: добавляем на каждом проходе

Сборщику не обязательно проверять условие. Чтобы **преобразовать** каждый элемент, `append` вызывают на каждом проходе и добавляют результат вычисления:

```python
def plus_one(numbers):
    result = []
    for number in numbers:
        result.append(number + 1)
    return result
```

Длина нового списка такая же, как у исходного. Для пустого списка получится пустой.

## Частые ошибки

Завести `result = []` внутри цикла (список обнуляется на каждом проходе) или присвоить результат `append`:

```python
result = result.append(number)   # неверно: append возвращает None, список потерян
```

```python
result.append(number)            # верно
```

## Проверь себя

```python
result = []
for n in [3, 8, 5, 10]:
    if n > 4:
        result.append(n * 2)
```

1. Что лежит в `result` после цикла?
2. Что вернёт такая функция для `[1, 2]`?

<details><summary>Ответ</summary>

1. `3 > 4` нет; `8 > 4` да, добавляем 16; `5 > 4` да, добавляем 10; `10 > 4` да, добавляем 20. Итог `[16, 10, 20]`.
2. Ни одно число не подошло, остаётся начальное значение: `[]`.

</details>
