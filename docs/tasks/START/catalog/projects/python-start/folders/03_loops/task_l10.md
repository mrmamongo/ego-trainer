# Задача L10: Собери фильтр чётных

## Условие

### Как это работает

Иногда нужно вернуть не число, а **новый список** из подходящих элементов. Для этого заводят пустой список `[]`
и на подходящих проходах добавляют в него элемент методом `append`:

```python
result = []          # пустой список
result.append(5)     # теперь [5]
result.append(8)     # теперь [5, 8]
```

`append` добавляет элемент в **конец** списка и сам ничего не возвращает: пиши `result.append(x)`, а не `result = result.append(x)`.

**Паспорт роли «сборщик»** (имя `result`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(item)` — только если элемент подошёл | после цикла |

Начальное значение — снова ответ для пустого списка: подходящих нет, значит, и собранный список пуст.

**Отступы** показывают вложенность: `result.append(...)` стоит под `if`, а `if` — под `for`.

```python
def positives(numbers):
    result = []
    for number in numbers:
        if number > 0:
            result.append(number)
    return result
```

### Задание

В файле задачи в комментарии записаны строки функции `task_l10_evens(numbers)`, но они перемешаны и без отступов.
Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали.
Функция должна вернуть новый список только с чётными числами в исходном порядке.

## Аргументы

- `numbers` — список целых чисел (может быть пустым, числа могут быть отрицательными).

## Возвращает

Новый список с чётными числами из `numbers` в том же порядке; если чётных нет — `[]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_l10_evens([1, 2, 3, 4])   # -> [2, 4]
task_l10_evens([1, 3, 5])      # -> []
task_l10_evens([])             # -> []
```

## Учебные цели

- Узнать пустой список `[]` и метод `append`.
- Собрать шаблон сборщика: `[]` до цикла, `if` и `append` в теле, `return` после цикла.
