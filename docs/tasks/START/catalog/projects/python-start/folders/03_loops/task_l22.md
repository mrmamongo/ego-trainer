# Задача L22: Баланс счёта

## Условие

### Как это работает

Накопитель не обязан начинаться с нуля: его начальное значение — это то, с чего всё стартует. А ранний `return` позволяет остановиться,
как только случилось что-то особенное.

```python
def stop_at_ten(start, steps):
    value = start
    for step in steps:
        value = value + step
        if value > 10:
            return -1
    return value
```

Сначала применяем шаг, потом проверяем и, если нужно, выходим сразу: остальные шаги уже не важны.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `start` — с чего стартуем | `value = value + step` | после цикла (если не вышли раньше) |

Для пустого списка операций баланс не менялся: ответ — начальное значение `start`.

### Задание

Напиши функцию `task_l22_final_balance(start, operations)`. Баланс сначала равен `start`; по очереди применяется каждая операция
(положительное число — пополнение, отрицательное — списание). Если в какой-то момент баланс **стал меньше нуля**, сразу верни `-1`.
Иначе верни итоговый баланс.

## Аргументы

- `start` — начальный баланс, целое число от 0.
- `operations` — список целых чисел-операций (может быть пустым).

## Возвращает

Итоговый баланс или `-1`, если баланс хотя бы раз стал отрицательным. Баланс ровно `0` отрицательным не считается.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l22_final_balance(100, [50, -30])     # -> 120
task_l22_final_balance(100, [-50, -60])    # -> -1   (100 - 50 - 60 = -10)
task_l22_final_balance(50, [])             # -> 50
```

## Учебные цели

- Начинать накопитель не с нуля, а со значения, пришедшего в параметре.
- Сочетать накопление с ранним `return` по условию.

## Проверка понимания
