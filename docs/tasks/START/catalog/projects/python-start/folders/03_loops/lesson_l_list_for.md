# Список и цикл for

**Список** — несколько значений под одним именем, в квадратных скобках через запятую: `[3, 8, 1]`.
Пустой список записывается `[]`.

Цикл `for` проходит по списку: тело цикла (строки с отступом) выполняется **по одному разу на каждый элемент**.
Переменная цикла получает не номер, а само **значение** очередного элемента: сначала первого, потом второго и так далее.

```python
prices = [5, 7]
for price in prices:       # 1
    double = price * 2     # 2
```

| Проход | price | double после тела |
|---|---|---|
| 1 | 5 | 10 |
| 2 | 7 | 14 |

После цикла в `price` остаётся последнее значение (7), в `double` — 14. Один проход — одно выполнение тела.
Для пустого списка `[]` тело не выполнится ни разу.

## Паспорт роли «текущий элемент»

Имена обычно `item`, `number`, `word`, `price`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| в заголовке `for` | не нужно, цикл даёт сам | не меняем: значение подставляет цикл | не возвращаем, нужен только внутри тела |

## Как вести трассировку цикла

Таблица теперь не по строкам, а **по проходам**: на каждом проходе выпиши значение переменной цикла и то, что изменило тело.
Так ты видишь, сколько раз выполнилось тело и что осталось после последнего прохода.

## Частые ошибки

Думать, что переменная цикла — это номер:

```python
for number in [10, 20]:
    x = number + 1      # неверно думать, что number = 0, 1: это 10, затем 20
```

Верно: `number` — это сами значения списка, поэтому `x` будет 11, затем 21.

Другая ошибка — считать, что тело выполняется один раз «для всего списка»: оно выполняется **для каждого** элемента отдельно.

## Проверь себя

```python
last = 0
for number in [4, 9, 2]:
    last = number
```

1. Сколько раз выполнится тело цикла?
2. Чему равно `number` на втором проходе?
3. Чему равно `last` после цикла?

<details><summary>Ответ</summary>

1. Три раза: по разу на каждый из трёх элементов.
2. Второй элемент — `9`.
3. `last` каждый раз перезаписывается, остаётся значение с последнего прохода: `2`.

</details>
