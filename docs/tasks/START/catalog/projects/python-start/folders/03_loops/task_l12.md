# Задача L12: Удвоить каждое

## Условие

### Как это работает

Сборщику не обязательно проверять условие. Если нужно **преобразовать** каждый элемент, `append` вызывают на каждом проходе
и добавляют не сам элемент, а результат вычисления:

```python
def plus_one(numbers):
    result = []
    for number in numbers:
        result.append(number + 1)
    return result
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(...)` — на каждом проходе | после цикла |

Длина нового списка такая же, как у исходного. Для пустого списка получится пустой список.

### Задание

Напиши функцию `task_l12_doubled(numbers)`: верни новый список, в котором каждое число удвоено.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Новый список тех же размеров, где элемент на каждой позиции умножен на 2.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l12_doubled([1, 2, 3])   # -> [2, 4, 6]
task_l12_doubled([-1, 5])     # -> [-2, 10]
task_l12_doubled([])          # -> []
```

## Учебные цели

- Различать сборщик с фильтром (`if` + `append`) и сборщик-преобразователь (`append` на каждом проходе).
- Строить новый список, не изменяя исходный.
