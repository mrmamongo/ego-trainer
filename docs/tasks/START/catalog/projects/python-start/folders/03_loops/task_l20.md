# Задача L20: Самое короткое слово

## Условие

### Как это работает

«Лучший на данный момент» может сравнивать не сами элементы, а то, что из них вычислено, — например, длины слов.
Но в `best` по-прежнему хранится **само слово**:

```python
def longest(words):
    best = words[0]
    for word in words:
        if len(word) > len(best):
            best = word
    return best
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `words[0]` — первое слово | `best = word` — если слово лучше | после цикла |

**Ничьи.** Если новое слово по длине равно `best`, оно не лучше. Со строгим сравнением (`>` или `<`) `best` остаётся прежним,
то есть при равных длинах побеждает тот, кто был **раньше** в списке. Это именно то, что нужно в твоей задаче.

### Задание

Напиши функцию `task_l20_shortest_word(words)`: верни самое короткое слово. Если коротких несколько одинаковой длины, верни то, что идёт раньше в списке.

## Аргументы

- `words` — непустой список строк (слова могут быть пустыми).

## Возвращает

Строку — самое короткое слово (при ничьей — самое раннее из них).

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `min` не используй.

## Пример

```python
task_l20_shortest_word(["слон", "кот", "мышь"])   # -> "кот"
task_l20_shortest_word(["bb", "a", "c"])          # -> "a"
task_l20_shortest_word(["слово"])                 # -> "слово"
```

## Учебные цели

- Искать «лучшего» по вычисленному признаку (длине), храня само слово.
- Управлять ничьей с помощью строгого сравнения.

## Проверка понимания

Что изменится при ничьей, если заменить `<` на `<=`? Почему в `best` хранится слово, а не его длина?
