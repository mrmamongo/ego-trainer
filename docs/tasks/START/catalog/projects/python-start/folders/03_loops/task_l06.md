# Задача L06: Считает только первое число

## Условие

### Как это работает

`return` завершает функцию **сразу**, в том месте, где он выполнился. Если он стоит внутри цикла, функция выйдет уже на первом проходе:

```python
def total_price(prices):
    total = 0
    for price in prices:
        total = total + price
        return total          # плохо: выход после первого прохода
```

Для `[4, 6]` функция вернёт `4`, а для `[]` цикл не выполнится вообще, `return` не сработает и результатом будет `None`.

В паспорте накопителя сказано: «когда возвращаем — **после** цикла». Строка `return total` должна стоять на одном уровне с `for`, а не под ним.

### Задание

Функция `task_l06_total(numbers)` должна вернуть сумму чисел, но возвращает только первое. Найди ошибку и исправь.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Целое число — сумму элементов; для пустого списка — `0`.

## Правила

- Менять нужно положение (отступ) одной строки; остальной код оставь как есть.
- Встроенную функцию `sum` не используй.

## Пример

```python
task_l06_total([1, 2, 3])   # -> 6
task_l06_total([])          # -> 0
```

## Учебные цели

- Понимать, что `return` внутри цикла завершает функцию на первом же проходе.
- Ставить `return` накопителя после цикла.

## Проверка понимания

Что вернёт исходная функция для `[7, 8, 9]`? А для `[]`? Как отступ у `return` меняет смысл программы?
