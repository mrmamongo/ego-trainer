# Задача L07: Счётчик

## Условие

### Как это работает

**Счётчик** отвечает на вопрос «сколько элементов подошло?». Он отличается от накопителя: прибавляет не сам элемент, а всегда **единицу**,
и только когда условие верно.

```python
count = 0                    # 1
for age in [12, 30, 17]:     # 2
    if age >= 18:            # 3
        count = count + 1    # 4
```

| Проход | age | условие | count после тела |
|---|---|---|---|
| 1 | 12 | нет | 0 |
| 2 | 30 | да | 1 |
| 3 | 17 | нет | 1 |

**Паспорт роли «счётчик»** (имя `count`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если элемент подошёл | после цикла |

Правило прежнее: **начальное значение — это ответ для пустого списка.** Подходящих элементов нет — значит, `0`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `count_after_iter_1` … `count_after_iter_4` — значение `count` после тела цикла на каждом проходе, `count_final` — после всего цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_l07_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать счётчик (прибавляет 1 при условии) от накопителя (прибавляет значение элемента).
- Видеть, что на проходах, где условие неверно, переменная не меняется.

## Проверка понимания

Чему будет равен `count` в конце, если условие заменить на `score > 4`? Почему счётчик не меняется на неподходящем элементе?
