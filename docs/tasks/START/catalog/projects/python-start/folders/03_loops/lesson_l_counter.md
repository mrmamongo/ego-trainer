# Счётчик: сколько элементов подошло

**Счётчик** отвечает на вопрос «сколько элементов подошло?». Он отличается от накопителя: прибавляет не сам элемент, а всегда **единицу**, и только когда условие верно.

```python
count = 0                    # 1
for age in [12, 30, 17]:     # 2
    if age >= 18:            # 3
        count = count + 1    # 4
```

| Проход | age | условие | count после тела |
|---|---|---|---|
| 1 | 12 | нет | 0 |
| 2 | 30 | да | 1 |
| 3 | 17 | нет | 1 |

## Паспорт роли «счётчик»

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если элемент подошёл | после цикла |

Правило прежнее: **начальное значение — ответ для пустого списка.** Подходящих элементов нет — значит, `0`.

## Функция со счётчиком

```python
def count_adults(ages):
    count = 0
    for age in ages:
        if age >= 18:
            count = count + 1
    return count
```

`if` стоит **внутри** цикла: условие проверяется для каждого элемента отдельно. `return` — снаружи, после цикла.

Условие может зависеть от второго параметра функции или от вычисления над элементом:

```python
if len(word) >= min_len:
    count = count + 1
```

Для условия «число в диапазоне» две проверки соединяют через `and`: `if low <= n and n <= high:`.

## Частые ошибки

Прибавлять элемент вместо единицы:

```python
if age >= 18:
    count = count + age      # неверно: это сумма возрастов
```

```python
if age >= 18:
    count = count + 1        # верно: считаем штуки
```

Или поставить `count = count + 1` вне `if` — тогда посчитаются все элементы, а не только подходящие.

## Проверь себя

```python
count = 0
for n in [5, -2, 0, 8]:
    if n > 0:
        count = count + 1
```

1. Чему равно `count` после каждого из четырёх проходов?
2. Какой будет ответ для пустого списка?

<details><summary>Ответ</summary>

1. `5 > 0` да: `1`; `-2 > 0` нет: `1`; `0 > 0` нет (ноль не больше нуля): `1`; `8 > 0` да: `2`. Итог `2`.
2. Тело не выполняется, остаётся начальное значение `0`.

</details>
