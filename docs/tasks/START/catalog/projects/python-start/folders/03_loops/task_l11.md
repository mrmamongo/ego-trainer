# Задача L11: Кто сдал

## Условие

### Как это работает

Сборщик с условием — то же, что в прошлой задаче, но условие теперь зависит от параметра:

```python
def big_ones(numbers, limit):
    result = []
    for number in numbers:
        if number > limit:
            result.append(number)
    return result
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(item)` — только если элемент подошёл | после цикла |

Исходный список функция **не меняет**: она строит и возвращает новый.

### Задание

Напиши функцию `task_l11_passed(scores, threshold)`: верни новый список баллов, которые не меньше порога `threshold`, в исходном порядке.

## Аргументы

- `scores` — список целых баллов (может быть пустым).
- `threshold` — целый проходной балл.

## Возвращает

Новый список баллов, у которых `score >= threshold`; если таких нет — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Собирай результат циклом и `append`; другие способы фильтрации пока не нужны.

## Пример

```python
task_l11_passed([50, 70, 90], 60)   # -> [70, 90]
task_l11_passed([10, 20], 50)       # -> []
task_l11_passed([], 50)             # -> []
```

## Учебные цели

- Применять сборщик с условием от параметра.
- Помнить, что начальное значение сборщика — ответ для пустого списка.

## Проверка понимания

Что вернёт функция для `([60, 60], 60)`? Почему мы возвращаем `result`, а не исходный `scores`?
