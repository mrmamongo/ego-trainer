# Задача L24: Сколько в диапазоне

## Условие

### Как это работает

Итоговая задача: роли ты уже знаешь, осталось выбрать нужную. Вопрос «сколько элементов подошло?» — это **счётчик**.

Условие «число лежит между границами включительно» состоит из двух проверок, соединённых `and`:

```python
def count_teens(ages):
    count = 0
    for age in ages:
        if age >= 13 and age <= 19:
            count = count + 1
    return count
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если элемент подошёл | после цикла |

### Задание

Напиши функцию `task_l24_count_in_range(numbers, low, high)`: верни, сколько чисел списка лежат в диапазоне от `low` до `high` включительно.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).
- `low`, `high` — границы диапазона, целые числа, `low <= high`.

## Возвращает

Целое число — сколько элементов `n` удовлетворяют `low <= n <= high`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l24_count_in_range([1, 5, 10, 15], 5, 10)   # -> 2
task_l24_count_in_range([1, 2, 3], 10, 20)       # -> 0
task_l24_count_in_range([], 0, 10)               # -> 0
```

## Учебные цели

- Выбирать роль переменной по вопросу задачи.
- Составлять условие из двух проверок через `and` внутри счётчика.

## Проверка понимания
