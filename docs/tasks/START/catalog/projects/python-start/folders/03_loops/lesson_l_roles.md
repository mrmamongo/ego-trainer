# Роли переменных в цикле: паспорта

У каждой переменной цикла есть **роль**. Узнать её можно по **паспорту**: где переменная заводится, с чего начинается и как меняется в теле.
Если роль выбрана верно, код получается почти механически.

## Все роли одной таблицей

| Роль | Вопрос, на который отвечает | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|---|
| текущий элемент | «с каким элементом работаем?» | не нужно | значение подставляет сам `for` | не возвращаем |
| накопитель | «чему равна сумма?» | `0` | `total = total + item` | после цикла |
| счётчик | «сколько подошло?» | `0` | `count = count + 1` — только если элемент подошёл | после цикла |
| сборщик | «какие подошли?» | `[]` | `result.append(item)` | после цикла |
| флаг | «есть ли такой?» / «все ли такие?» | `False` (или `True`) | `found = True` — когда нашли | после цикла |
| лучший | «какой наибольший/наименьший?» | `numbers[0]` | `best = item` — если элемент лучше | после цикла |

## Главное правило

**Начальное значение — это ответ для пустого списка.** Если список пуст, тело цикла не выполнится ни разу, и функция вернёт именно то, с чего переменная началась.

- сумма пустого списка — `0`;
- подходящих элементов в пустом списке нет — счётчик `0`, сборщик `[]`;
- искать негде — флаг «нашли» это `False`;
- у пустого списка нет наибольшего, поэтому для «лучшего» список по условию не пуст.

## Пример: узнай роли по коду

```python
def demo(numbers):
    s = 0                  # 1
    n = 0                  # 2
    for x in numbers:      # 3
        s = s + x          # 4
        n = n + 1          # 5
    return s, n
```

- `x` — текущий элемент (его подставляет `for`);
- `s` — накопитель: прибавляется сам элемент `x`;
- `n` — счётчик: прибавляется всегда единица.

Отличие накопителя от счётчика: накопитель прибавляет **значение** элемента, счётчик — всегда **1**.

## Частые ошибки

Выбрать неверную роль для вопроса:

```python
# вопрос «сколько чисел больше 10?»
total = 0
for number in numbers:
    if number > 10:
        total = total + number    # неверно: это сумма больших чисел, а не их количество
```

```python
count = 0
for number in numbers:
    if number > 10:
        count = count + 1         # верно: счётчик, прибавляем единицу
```

## Проверь себя

Какую роль надо взять, чтобы ответить на вопрос?

1. «Какова сумма всех цен?»
2. «Есть ли в списке хотя бы одно отрицательное число?»
3. «Какие слова длиннее пяти букв?» (нужен список этих слов)

1. Накопитель: `total = 0`, `total = total + price`.
