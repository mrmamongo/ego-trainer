# Флаг и ранний return

Вопрос «есть ли в списке такой элемент?» или «все ли элементы такие?» требует проверить **все** элементы.
Ответ «нет» можно дать только **после** цикла, когда все проверены.

## Флаг

**Флаг** — переменная `True`/`False`, которая сначала говорит «пока не нашли», а в теле цикла меняется на «нашли».

```python
def has_big(numbers):
    found = False
    for number in numbers:
        if number > 100:
            found = True
    return found
```

### Паспорт роли «флаг»

Имя `found`; для вариантов «все ли…» — `all_ok`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `False` | `found = True` — когда нашли | после цикла |

Начальное значение — ответ для пустого списка: искать негде, значит «не нашли».

### Флаг «наоборот»

Для вопроса «все ли подходят?» флаг начинается с `True` («пока всё хорошо») и становится `False`, как только найден плохой элемент:

```python
def all_small(numbers, limit):
    all_ok = True
    for number in numbers:
        if number > limit:
            all_ok = False
    return all_ok
```

Для пустого списка ответ `True`: нарушителей нет. Снова работает правило «начальное значение — ответ для пустого списка».

## Ранний return

Есть и другой верный способ: выйти из функции сразу, как только нашли. `return` останавливает **всю** функцию, включая цикл.

```python
def first_big(numbers):
    for number in numbers:      # 1
        if number > 10:         # 2
            return number       # 3
    return 0                    # 4
```

- `first_big([3, 20, 50])`: на втором проходе `20 > 10`, выполняется `return 20`. Элемент `50` даже не рассматривается.
- `first_big([3, 4])`: условие ни разу не верно, цикл заканчивается сам, выполняется `return 0` после цикла.
- `first_big([])`: тело не выполняется, сразу `return 0`.

Схема для «есть ли?»: `return True` — **внутри** цикла при находке, `return False` — **после** цикла. Для поиска самого элемента после цикла возвращают запасное значение («не нашли»).

## return внутри цикла и после цикла

- `return` внутри `if` — «нашли, выходим».
- `return` после цикла — «ничего не нашли» (или итог накопителя).
- `return` внутри цикла **без** `if` или в `else` — функция выйдет на первом проходе.

## Частые ошибки

Сдаться на первом неподходящем элементе:

```python
def has_ten(numbers):
    for number in numbers:
        if number == 10:
            return True
        else:
            return False      # неверно: для [3, 10] вернёт False
```

```python
def has_ten(numbers):
    for number in numbers:
        if number == 10:
            return True
    return False              # верно: «нет» — только после цикла
```

## Проверь себя

```python
def f(numbers):
    for n in numbers:
        if n < 0:
            return n
    return 0
```

1. Что вернёт `f([4, -3, -7])`?
2. Что вернёт `f([4, 5])`?
3. Что вернёт `f([])`?

<details><summary>Ответ</summary>

1. На втором проходе `-3 < 0`, выполняется `return -3`. Ответ `-3`, `-7` не рассматривается.
2. Ни одно число не отрицательное, цикл закончился, `return 0`. Ответ `0`.
3. Тело не выполняется, сразу `return 0`. Ответ `0`.

</details>
