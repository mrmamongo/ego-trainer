# Лучший на данный момент

Чтобы найти наибольшее число, цикл помнит **лучшее на данный момент**. Каждый новый элемент сравнивают с ним и, если он лучше, заменяют.

## Откуда взять первое значение

Здесь `0` не подходит: в списке `[-5, -2]` ответ был бы `0`, а такого числа в списке нет.
Поэтому лучшим сначала объявляют **первый элемент**. Он записывается `numbers[0]`: в квадратных скобках номер элемента, счёт идёт с нуля, так что `0` — первый.

```python
numbers = [2, 7, 4]
best = numbers[0]        # 2
for number in numbers:
    if number > best:
        best = number
```

| Проход | number | best после тела |
|---|---|---|
| 1 | 2 | 2 |
| 2 | 7 | 7 |
| 3 | 4 | 7 |

На первом проходе элемент сравнивается сам с собой — это не страшно, `best` не изменится.

## Паспорт роли «лучший»

Имя `best`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `numbers[0]` — первый элемент | `best = number` — если элемент лучше | после цикла |

У пустого списка нет наибольшего, а `numbers[0]` вызвал бы ошибку. Поэтому в таких задачах список **гарантированно не пуст**, и правило про пустой список здесь не нужно.

## Наименьшее и свои критерии

Для наименьшего меняется только знак сравнения:

```python
def smallest(numbers):
    best = numbers[0]
    for number in numbers:
        if number < best:
            best = number
    return best
```

«Лучший» может сравниваться по вычисленному — например, по длине слова. Но в `best` по-прежнему хранится **само слово**:

```python
def longest(words):
    best = words[0]
    for word in words:
        if len(word) > len(best):
            best = word
    return best
```

## Ничьи

Если новое слово по длине равно `best`, оно не лучше. Со строгим сравнением (`>` или `<`) `best` остаётся прежним, то есть при равных длинах побеждает тот, кто был **раньше** в списке.

## Частые ошибки

Начать с нуля:

```python
best = 0                 # неверно: для [-5, -2] вернётся 0, которого нет в списке
```

```python
best = numbers[0]        # верно: начинаем с реального элемента
```

Ещё ошибка — положить в `best` длину вместо слова, а потом пытаться вернуть слово.

## Проверь себя

```python
best = numbers[0]
for number in numbers:
    if number > best:
        best = number
```

1. Чему равен `best` после каждого прохода для `[3, 1, 9, 9, 4]`?
2. Что вернёт такой код для `[-8, -3, -5]`?

<details><summary>Ответ</summary>

1. После прохода 1 — `3`; 2 — `3`; 3 — `9`; 4 — `9` (`9 > 9` неверно); 5 — `9`.
2. Лучший сначала `-8`, потом `-3` (больше), `-5` не лучше. Ответ `-3`.

</details>
