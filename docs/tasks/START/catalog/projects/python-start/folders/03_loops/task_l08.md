# Задача L08: Сколько положительных

## Условие

### Как это работает

Счётчик в функции выглядит так:

```python
def count_adults(ages):
    count = 0
    for age in ages:
        if age >= 18:
            count = count + 1
    return count
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если элемент подошёл | после цикла |

`if` стоит **внутри** цикла: условие проверяется для каждого элемента отдельно. `return` — снаружи, после цикла.
Для пустого списка подходящих элементов нет, ответ `0`.

### Задание

Напиши функцию `task_l08_count_positive(numbers)`: верни, сколько в списке положительных чисел. Ноль положительным не считается.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Целое число — количество элементов больше нуля.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l08_count_positive([1, -2, 3])   # -> 2
task_l08_count_positive([0, 0])       # -> 0
task_l08_count_positive([])           # -> 0
```

## Учебные цели

- Писать цикл со счётчиком и условием внутри.
- Помнить, что начальное значение счётчика — ответ для пустого списка.

## Проверка понимания

Что вернёт функция для `[0]`? Что изменится, если вместо `count = count + 1` написать `count = count + number`?
