# Задача L14: Проверяет только первый элемент

## Условие

### Как это работает

Вопрос «есть ли в списке такой элемент?» требует проверить **все** элементы. Ответ «нет» можно дать только после цикла,
когда все проверены. Если `return False` стоит внутри цикла (например, в `else`), функция сдаётся на первом же неподходящем элементе:

```python
def has_ten(numbers):
    for number in numbers:
        if number == 10:
            return True
        else:
            return False      # плохо: сдались на первом элементе
```

Для `[3, 10]` вернётся `False`, хотя десятка есть: после первого элемента `3` сработал `else`, и функция вышла.

Верная схема: `return True` — внутри цикла при находке, `return False` — **после** цикла.

### Задание

Функция `task_l14_contains(numbers, target)` должна вернуть `True`, если в списке есть число `target`, но проверяет только первый элемент. Найди ошибку и исправь.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).
- `target` — искомое целое число.

## Возвращает

`True`, если `target` встречается в `numbers`, иначе `False`.

## Правила

- Оставь цикл `for`; операцию `in` вне заголовка цикла не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l14_contains([1, 2, 3], 3)   # -> True
task_l14_contains([1, 2, 3], 9)   # -> False
task_l14_contains([], 1)          # -> False
```

## Учебные цели

- Находить `return False` внутри цикла, который обрывает поиск слишком рано.
- Выносить отрицательный ответ «не нашли» за цикл.

## Проверка понимания

Что вернёт исходная функция для `([5, 7], 7)` и почему? Что она вернёт для пустого списка?
