# Задача L17: Первое длинное слово

## Условие

### Как это работает

Когда нужно вернуть **сам найденный элемент**, а не «да/нет», удобно выходить сразу при находке:

```python
def first_big(numbers, limit):
    for number in numbers:
        if number > limit:
            return number
    return 0
```

Первый `return` — внутри `if`: нашли и сразу отдали. Второй — после цикла: не нашли, отдаём запасное значение.
Это и есть «начальное значение — ответ для пустого списка»: если искать негде или ничего не подошло, возвращается запасной ответ.

### Задание

Напиши функцию `task_l17_first_long_word(words, min_len)`: верни первое слово, длина которого не меньше `min_len`. Если такого слова нет, верни пустую строку `""`.

## Аргументы

- `words` — список строк (может быть пустым).
- `min_len` — целое число от 0.

## Возвращает

Первое подходящее слово (в порядке списка, не самое длинное!) или `""`, если подходящих нет.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_l17_first_long_word(["кот", "слон", "жираф"], 4)   # -> "слон"
task_l17_first_long_word(["дом", "лес"], 10)            # -> ""
task_l17_first_long_word([], 3)                         # -> ""
```

## Учебные цели

- Использовать ранний `return` при находке и запасной `return` после цикла.
- Отличать «первый подходящий» от «самый длинный».

## Проверка понимания

Почему для `(["aaaa", "bbbbb"], 3)` ответ `"aaaa"`, а не `"bbbbb"`? Что вернёт функция для пустого списка?
