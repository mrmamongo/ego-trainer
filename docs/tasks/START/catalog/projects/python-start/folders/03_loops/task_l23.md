# Задача L23: Назови роли

## Условие

### Как это работает

Теперь по коду видно, что у каждой переменной цикла есть **роль**. Узнать её можно по паспорту: с чего начинается и как меняется.

| Роль | Начальное значение | Как меняем в теле |
|---|---|---|
| накопитель | `0` | `total = total + item` — прибавляем значение |
| счётчик | `0` | `count = count + 1` — всегда единица, обычно под `if` |
| сборщик | `[]` | `result.append(item)` |
| флаг | `False` (или `True`) | `found = True` — когда нашли |
| лучший | `numbers[0]` | `best = item` — если элемент лучше |
| текущий элемент | не нужно | значение подставляет сам `for` |

```python
def demo(numbers):
    s = 0                  # 1
    n = 0                  # 2
    for x in numbers:      # 3
        s = s + x          # 4
        n = n + 1          # 5
    return s, n
```

Здесь `s` — накопитель (прибавляется `x`), `n` — счётчик (прибавляется 1), `x` — текущий элемент.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. Впиши роль каждой переменной строкой — **ровно** одним из вариантов: `"накопитель"`, `"счётчик"`, `"сборщик"`, `"флаг"`, `"лучший"`, `"текущий элемент"`.
`role_of_a`, `role_of_b`, `role_of_c`, `role_of_d` — роли переменных `a`, `b`, `c`, `d`.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`; пиши роль в кавычках, точно как в списке выше (с буквой «ё»).
- Строки `def task_l23_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Определять роль переменной по её начальному значению и изменению в теле.
- Различать накопитель и счётчик, сборщик и текущий элемент.
