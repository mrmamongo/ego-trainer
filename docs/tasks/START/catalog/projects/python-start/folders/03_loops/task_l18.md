# Задача L18: Лучший на данный момент

## Условие

### Как это работает

Чтобы найти наибольшее число, цикл помнит **лучшее на данный момент**. Каждый новый элемент сравнивают с ним и, если он лучше, заменяют.

Откуда взять первое значение? Здесь `0` не подходит: в списке `[-5, -2]` ответ был бы `0`, а такого числа в списке нет.
Поэтому лучшим сначала объявляют **первый элемент** списка. Он записывается `numbers[0]` (в квадратных скобках — номер элемента, счёт идёт с нуля, так что `0` — первый).

```python
numbers = [2, 7, 4]
best = numbers[0]        # 2
for number in numbers:
    if number > best:
        best = number
```

| Проход | number | best после тела |
|---|---|---|
| 1 | 2 | 2 |
| 2 | 7 | 7 |
| 3 | 4 | 7 |

**Паспорт роли «лучший»** (имя `best`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `numbers[0]` — первый элемент | `best = number` — если элемент лучше | после цикла |

Здесь список **гарантированно не пуст**: у пустого списка нет наибольшего, и `numbers[0]` вызвал бы ошибку. Поэтому правило про пустой список тут не нужно.
На первом проходе элемент сравнивается сам с собой — это не страшно, `best` не изменится.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `best_after_iter_1` … `best_after_iter_5` — значение `best` после тела цикла на каждом проходе, `best_final` — после всего цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_l18_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Узнать `numbers[0]` — первый элемент непустого списка.
- Следить, как «лучший на данный момент» заменяется только более хорошим значением.

## Проверка понимания

Почему в `if number > best` не срабатывает второй `9`? Чему равен `best_final`, если список `[-3, -8, -1]`?
