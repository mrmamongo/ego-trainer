# Задача L19: Наибольшее число

## Условие

### Как это работает

Шаблон «лучший на данный момент» на примере минимума (для максимума поменяй знак сравнения):

```python
def smallest(numbers):
    best = numbers[0]
    for number in numbers:
        if number < best:
            best = number
    return best
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `numbers[0]` — первый элемент | `best = number` — если элемент лучше | после цикла |

Здесь «лучше» значит «меньше». В твоей задаче «лучше» значит «больше». Список гарантированно не пуст, поэтому `numbers[0]` безопасен.

### Задание

Напиши функцию `task_l19_max_value(numbers)`: верни наибольшее число списка.

## Аргументы

- `numbers` — непустой список целых чисел (числа могут быть отрицательными).

## Возвращает

Наибольшее число из списка.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `max` не используй: цель — научиться делать «лучшего на данный момент» самому.

## Пример

```python
task_l19_max_value([3, 9, 2])      # -> 9
task_l19_max_value([-5, -2, -9])   # -> -2
task_l19_max_value([5])            # -> 5
```

## Учебные цели

- Писать «лучшего на данный момент»: старт с первого элемента, замена при более хорошем.
- Понимать, почему начальное значение `0` ломает ответ для отрицательных чисел.

## Проверка понимания

Что вернёт функция для `[-5, -2, -9]`, если начать с `best = 0`? Почему с `numbers[0]` ответ верный?
