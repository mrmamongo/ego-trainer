# Задача L21: Среднее арифметическое

## Условие

### Как это работает

Среднее — это сумма, делённая на количество. В цикле удобно вести **две** переменные с разными ролями: накопитель `total` и счётчик `count`.

Оператор `/` всегда даёт дробное число (`float`): `6 / 3` равно `2.0`, а `3 / 2` равно `1.5`.

```python
def mean_price(prices):
    total = 0
    count = 0
    for price in prices:
        total = total + price
        count = count + 1
    if count == 0:
        return 0.0
    return total / count
```

| Роль | Где заводим | Начальное значение | Как меняем в теле | Когда используем |
|---|---|---|---|---|
| накопитель `total` | до цикла | `0` | `total = total + price` | после цикла |
| счётчик `count` | до цикла | `0` | `count = count + 1` | после цикла |

Деление на ноль запрещено: для пустого списка `count` равен `0`, и делить нельзя. Поэтому пустой случай обрабатывается отдельно — по условию задачи он даёт `0.0`.
Количество можно было бы взять и функцией `len(numbers)`, но здесь потренируем счётчик.

### Задание

Напиши функцию `task_l21_average(numbers)`: верни среднее арифметическое чисел списка. Для пустого списка верни `0.0`.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Дробное число (`float`) — сумму, делённую на количество; для пустого списка — `0.0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `sum` и `len` для списка не используй: заведи накопитель и счётчик сам.

## Пример

```python
task_l21_average([1, 2, 3])   # -> 2.0
task_l21_average([1, 2])      # -> 1.5
task_l21_average([])          # -> 0.0
```

## Учебные цели

- Вести в одном цикле две переменные с разными ролями: накопитель и счётчик.
- Защищаться от деления на ноль для пустого списка.

## Проверка понимания

Что произойдёт, если для `[]` выполнить `total / count`? Чему равно `7 / 2` и чем оно отличается от `7 // 2`?
