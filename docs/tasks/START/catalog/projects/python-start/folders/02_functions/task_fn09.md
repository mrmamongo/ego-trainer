# Задача FN09: Собери функцию: чётное или нечётное

## Условие

### Как это работает

`%` — остаток от деления: `10 % 3` равно 1 (десять делится на три по три, остаётся один), `12 % 4` равно 0.
Число чётное, если при делении на 2 остаток 0. Условие «остаток равен нулю» пишут так: `n % 2 == 0`.

**Отступы** показывают, какие строки к чему относятся. Всё, что сдвинуто вправо под `if`, `else` или `def`, — их тело.

```python
def sign_word(x):
    if x > 0:
        return "плюс"
    else:
        return "не плюс"
```

- `def` стоит без отступа, всё остальное внутри функции сдвинуто на 4 пробела.
- `return "плюс"` сдвинут ещё на 4: он выполняется только под `if`.
- `else:` стоит на одном уровне с `if`, а под ним — свой `return` с отступом.

### Задание

В файле задачи в комментарии записаны строки функции `task_fn09_parity(n)`, но они перемешаны и без отступов.
Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали.
Функция должна вернуть `"чётное"` или `"нечётное"`.

## Аргументы

- `n` — целое число (может быть нулём и отрицательным).

## Возвращает

Строку `"чётное"`, если `n` делится на 2 без остатка, иначе `"нечётное"`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_fn09_parity(4)    # -> "чётное"
task_fn09_parity(7)    # -> "нечётное"
task_fn09_parity(0)    # -> "чётное"
```

## Учебные цели

- Понимать, что отступы показывают вложенность в `def`, `if` и `else`.
- Применять `%` для проверки чётности.
