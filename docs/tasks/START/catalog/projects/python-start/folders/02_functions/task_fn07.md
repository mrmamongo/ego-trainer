# Задача FN07: Допиши return

## Условие

### Как это работает

Переменная, которую ты посчитал внутри функции, сама наружу не выходит. Если в конце нет `return`, функция вернёт `None`.

```python
def zone_price(km):
    if km < 5:
        price = 100
    else:
        price = 250
    return price      # без этой строки результат — None
```

Здесь нужна ровно одна строка: вернуть то, что посчитали в ветках.

### Задание

Функция `task_fn07_delivery_days(city)` выбирает срок доставки в днях в зависимости от города, но не возвращает результат.
Допиши недостающую строку.

Москва — 1 день, Казань — 3 дня, любой другой город — 7 дней.

## Аргументы

- `city` — название города, строка.

## Возвращает

Целое число — срок доставки в днях: `1`, `3` или `7`.

## Правила

- Допиши одну недостающую строку, остальной код не меняй.
- Названия городов сравниваются точно, с большой буквы.

## Пример

```python
task_fn07_delivery_days("Москва")   # -> 1
task_fn07_delivery_days("Казань")   # -> 3
task_fn07_delivery_days("Омск")     # -> 7
```

## Учебные цели

- Замечать, что посчитанное значение нужно вернуть через `return`.
- Понимать, что ветвление `if/elif/else` задаёт значение переменной, а `return` отдаёт его наружу.
