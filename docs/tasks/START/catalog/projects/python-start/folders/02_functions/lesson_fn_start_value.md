# Начальное значение — ответ, когда условие не сработало

Если переменную меняет только `if`, а условие не сработало, переменная остаётся с тем значением, которое было **до** `if`
(как в задачах про ветвление в первой папке).

Поэтому **начальное значение — это ответ на случай, когда ни одно условие не сработало.**

```python
def bonus(points):
    extra = 0
    if points > 50:
        extra = 10
    return extra
```

- `bonus(80)`: условие верно, `extra` становится 10.
- `bonus(20)`: условие неверно, `extra` так и остаётся `0` — это и есть ответ «бонуса нет».

| Вызов | extra до `if` | условие | extra после `if` |
|---|---|---|---|
| `bonus(80)` | 0 | `80 > 50` да | 10 |
| `bonus(20)` | 0 | `20 > 50` нет | 0 |

## Как выбрать начальное значение

Задай себе вопрос: «что должна вернуть функция, если ни одно условие не подошло?». Это и есть строка до `if`.

Например, доставка стоит 300, но бесплатна от 1000:

```python
def delivery_cost(total):
    cost = 300            # по умолчанию платная
    if total >= 1000:
        cost = 0          # исключение: бесплатно
    return cost
```

## Частые ошибки

Оставить вместо начального значения `None` или вообще не завести переменную:

```python
def delivery_cost(total):
    cost = None           # неверно: при total < 1000 вернётся None, а не число
    if total >= 1000:
        cost = 0
    return cost
```

```python
def delivery_cost(total):
    cost = 300            # верно
    if total >= 1000:
        cost = 0
    return cost
```

Если переменной нет вообще (`cost` создаётся только внутри `if`), то при неверном условии `return cost` остановит программу ошибкой про имя.

## Проверь себя

```python
def f(n):
    result = 1
    if n > 10:
        result = 2
    return result
```

1. Что вернёт `f(3)`?
2. Что вернёт `f(10)`?
3. Что вернёт `f(11)`?

<details><summary>Ответ</summary>

1. `3 > 10` неверно, `result` остаётся 1.
2. `10 > 10` неверно (равно — не больше), ответ 1.
3. `11 > 10` верно, ответ 2.

</details>
