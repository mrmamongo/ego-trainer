# Задача FN15: Большее из трёх

## Условие

### Как это работает

Новых правил нет, нужен приём. Не сравнивай все пары чисел: держи в переменной «лучшее на данный момент» и по очереди проверяй каждое следующее число.

```python
def lowest_of_two_and_one(x, y, z):
    best = x
    if y < best:
        best = y
    return best
```

Здесь `best` сначала равен первому числу, а потом заменяется, если нашлось лучшее. Для третьего числа нужен ещё один такой `if`.

### Задание

Напиши функцию `task_fn15_max3(a, b, c)`, которая возвращает наибольшее из трёх чисел. Функцию `max()` использовать нельзя.

## Аргументы

- `a`, `b`, `c` — целые числа (возможно, отрицательные или равные).

## Возвращает

Целое число — наибольшее из трёх.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `max()` и `min()`.

## Пример

```python
task_fn15_max3(1, 2, 3)     # -> 3
task_fn15_max3(7, 2, 5)     # -> 7
task_fn15_max3(-4, -9, -4)  # -> -4
```

## Учебные цели

- Хранить «лучшее на данный момент» в переменной и обновлять его.
- Не терять результат, когда числа равны или отрицательны.

## Проверка понимания

Почему `best` в начале нельзя положить равным 0? Что произойдёт, если все три числа отрицательные?
