# Задача FN20: Вход в клуб

## Условие

### Как это работает

Напомним, как работают `and` и `or`:

- `A and B` верно, только если верны **оба**;
- `A or B` верно, если верно **хотя бы одно**.

Скобки задают порядок, как в арифметике: сначала то, что в скобках.

```python
def can_borrow(age, has_card, is_teacher):
    return age >= 14 and (has_card or is_teacher)
```

Здесь возраст нужен всем, а дальше достаточно **любого одного**: читательского билета или статуса учителя.
Параметры `has_card` и `is_teacher` — это `True` или `False`, их можно подставлять в условие прямо.

### Задание

Напиши функцию `task_fn20_can_enter(age, has_ticket, is_vip)`: пустят ли человека в клуб.

В клуб пускают только с 18 лет. VIP-гостям билет не нужен, остальным он обязателен.

## Аргументы

- `age` — возраст, целое число.
- `has_ticket` — есть ли билет, `True` или `False`.
- `is_vip` — VIP ли гость, `True` или `False`.

## Возвращает

`True`, если человека пустят, иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn20_can_enter(20, True, False)    # -> True
task_fn20_can_enter(20, False, False)   # -> False  (нет билета)
task_fn20_can_enter(20, False, True)    # -> True   (VIP без билета)
```

## Учебные цели

- Составлять условие из `and`, `or` и скобок.
- Возвращать логическое условие как `True`/`False`.

## Проверка понимания

Почему VIP младше 18 лет всё равно не пройдёт? Что изменится, если убрать скобки вокруг `has_ticket or is_vip`?
