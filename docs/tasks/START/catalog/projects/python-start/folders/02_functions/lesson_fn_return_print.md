# return и print: что вернула функция

Это две разные вещи:

- `print(...)` **показывает** значение на экране — для человека. Программа это значение дальше не получает.
- `return ...` **отдаёт** значение программе — туда, где функцию вызвали. На экране при этом ничего не появится.

Проверка в этих задачах всегда смотрит на то, что функция **вернула**. Напечатанное она не видит.

## None — «ничего»

Если в функции нет `return`, она всё равно что-то возвращает — особое значение `None` («ничего»).

```python
def say(n):
    print(n + 1)

def give(n):
    return n + 1

p = say(3)     # 1
q = give(3)    # 2
```

- Строка 1: на экране появится `4` (это сделал `print`). Но `return` в `say` нет, поэтому `p` — `None`.
- Строка 2: на экране ничего. `give` вернула 4, и `q = 4`.

## return сразу заканчивает функцию

Как только программа доходит до `return`, функция **заканчивается**. Строки ниже не выполняются, даже если их условия верны.

```python
def size(n):
    if n > 100:
        return "большой"
    if n > 10:
        return "средний"
    return "маленький"
```

- `size(500)`: оба условия верны, но первый `return` завершает функцию — ответ `"большой"`.
- `size(50)`: `50 > 100` неверно, идём дальше; `50 > 10` верно — `"средний"`.
- `size(10)`: `10 > 10` неверно (равно — не больше), остаётся последняя строка — `"маленький"`.

## Результат из веток: return в конце

Если ветки только записывают результат в переменную, не забудь вернуть её одной строкой после `if/else`. Без неё функция вернёт `None`:

```python
def zone_price(km):
    if km < 5:
        price = 100
    else:
        price = 250
    return price      # без этой строки результат — None
```

`return price` стоит с тем же отступом, что и `if`, то есть **вне** веток: он выполняется всегда, после выбранной ветки.
Если сдвинуть его под `else`, то при `km < 5` функция ничего не вернёт.

## Частые ошибки

```python
def area(w, h):
    print(w * h)      # неверно: покажет на экране, но вернёт None
```

```python
def area(w, h):
    return w * h      # верно: значение отдано вызвавшему
```

## Проверь себя

```python
def f(n):
    if n > 5:
        return "много"
    return "мало"
```

1. Что вернёт `f(9)`? А `f(5)`?
2. Что окажется в `r` после `r = print(3)`? (`print` — тоже функция, и у неё нет `return`.)

<details><summary>Ответ</summary>

1. `f(9)`: `9 > 5` верно, `return "много"`. `f(5)`: `5 > 5` неверно, доходим до последней строки — `"мало"`.
2. На экране появится `3`, а в `r` попадёт `None`.

</details>
