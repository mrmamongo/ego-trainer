# Задача FN01: Функция: определение и вызов

## Условие

### Как это работает

Функция — это кусочек кода с именем, который можно запускать, когда он нужен.

```python
def triple(k):
    answer = k * 3
    return answer
```

Тут три разные вещи:

1. `def triple(k):` **создаёт** функцию. Строки с отступом — её тело — при этом **не выполняются**. `k` — **параметр**: пустая ячейка для значения, которое придёт при вызове.
2. `triple(5)` — **вызов**. Только теперь программа заходит в тело, записывает 5 в `k` и выполняет строки по порядку.
3. `return answer` **отдаёт** значение назад, в то место, где функцию вызвали. Вызов `triple(5)` как бы заменяется этим значением.

```python
x = triple(5)       # 1
y = triple(x - 11)  # 2
```

| После строки | x | y |
|---|---|---|
| 1 | 15 | — |
| 2 | 15 | 12 |

Строка 1: `k = 5`, `answer = 15`, `return` отдаёт 15 — и оно записывается в `x`.
Строка 2: сначала считается аргумент `x - 11` = 4, потом вызов с `k = 4` даёт 12.

Помнишь `def task_v01_trace():` и `return ...` в задачах прошлой папки? Это такая же функция.
Проверка вызывает её, тело выполняется, а то, что стоит после `return`, — твои ответы. Теперь ты видишь эту рамку изнутри.
В этой задаче внутри рамки (в комментариях с номерами) написана ещё одна функция, `double`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. Ответы — значения `a`, `b`, `c` в самом конце.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, шаг за шагом проследив вызовы.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fn01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что `def` только создаёт функцию, а тело выполняется при вызове.
- Знать, что параметр получает значение аргумента, а `return` отдаёт результат туда, где был вызов.
- Видеть, что рамка `def task_..._trace()` / `return` — тоже обычная функция.

## Проверка понимания
