# Задача FN05: Функция печатает вместо возврата

## Условие

### Как это работает

Проверка вызывает твою функцию и смотрит, что она **вернула**. Экран ей не виден.
Если вместо `return` стоит `print`, значение показывается, но функция возвращает `None`.

```python
def area(w, h):
    print(w * h)      # плохо: покажет, но вернёт None
```

Исправление — заменить `print(...)` на `return ...`:

```python
def area(w, h):
    return w * h
```

### Задание

Функция `task_fn05_ticket_price(age)` должна вернуть цену билета в рублях по возрасту, но в каждой ветке стоит `print`.
Исправь её так, чтобы цена возвращалась.

Цена: до 7 лет — 0, от 7 до 17 лет включительно — 150, от 18 лет — 300.

## Аргументы

- `age` — возраст, целое число от 0.

## Возвращает

Целое число — цену билета: `0`, `150` или `300`.

## Правила

- Меняй только то, что функция делает с ценой; условия оставь как есть.
- Функция должна **вернуть** цену через `return`, а не печатать её.

## Пример

```python
task_fn05_ticket_price(5)    # -> 0
task_fn05_ticket_price(10)   # -> 150
task_fn05_ticket_price(30)   # -> 300
```

## Учебные цели

- Находить место, где значение печатается, но не возвращается.
- Заменять `print` на `return` без изменения условий.

## Проверка понимания

Объясни, что вернула исходная функция при `age = 10` и почему проверка с ней не справилась.
