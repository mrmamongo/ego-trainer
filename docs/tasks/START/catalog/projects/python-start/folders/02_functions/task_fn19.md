# Задача FN19: Тариф такси

## Условие

### Как это работает

Расчёт можно вести по шагам в одной переменной: сначала посчитать базовую сумму, потом применить условия одно за другим.
Каждый следующий шаг работает с тем, что получилось после предыдущего.

```python
def parcel_cost(kg, is_fragile):
    cost = 50 + 20 * kg
    if is_fragile:
        cost = cost + 100
    if cost > 500:
        cost = 500
    return cost
```

Это тот же приём, что в FN12: переменная `cost` обновляется по ходу функции.

### Задание

Напиши функцию `task_fn19_taxi_fare(km, is_night)`: стоимость поездки на такси.

1. Базовая сумма: `100 + 30 * km`.
2. Если поездка ночная (`is_night` равно `True`), сумма удваивается.
3. Если итог получился меньше 150, он поднимается до 150 (минимальная поездка).

## Аргументы

- `km` — длина поездки в километрах, целое число от 0.
- `is_night` — `True` для ночной поездки, иначе `False`.

## Возвращает

Целое число — стоимость поездки.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn19_taxi_fare(5, False)   # -> 250   (100 + 150)
task_fn19_taxi_fare(5, True)    # -> 500   (250 * 2)
task_fn19_taxi_fare(0, False)   # -> 150   (100 меньше минимума)
```

## Учебные цели

- Вести расчёт по шагам в одной переменной.
- Применять минимальную границу после остальных шагов.

## Проверка понимания

Почему проверка на 150 стоит после удвоения? Сколько стоит ночная поездка в 0 км?
