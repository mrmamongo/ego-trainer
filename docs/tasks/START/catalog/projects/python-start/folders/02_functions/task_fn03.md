# Задача FN03: return сразу заканчивает функцию

## Условие

### Как это работает

Как только программа доходит до `return`, функция **заканчивается**. Строки ниже не выполняются, даже если их условия верны.

```python
def size(n):
    if n > 100:
        return "большой"
    if n > 10:
        return "средний"
    return "маленький"
```

- `size(500)`: оба условия верны (`500 > 100` и `500 > 10`), но первый же `return` завершает функцию. Результат — `"большой"`. До второго `if` дело не доходит.
- `size(50)`: `50 > 100` неверно, идём дальше; `50 > 10` верно — `"средний"`.
- `size(10)`: `10 > 100` неверно, `10 > 10` тоже неверно (равно — не больше), остаётся последняя строка — `"маленький"`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. Ответы — текст, поэтому пиши его **в кавычках**, например `"A"`.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, шаг за шагом проследив вызовы.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fn03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Знать, что `return` немедленно завершает функцию.
- Понимать, что при нескольких верных условиях выполняется только первый встреченный `return`.

## Проверка понимания

Объясни, почему `grade(95)` вернёт `"A"`, а не `"B"`, хотя `95 >= 60` тоже верно.
