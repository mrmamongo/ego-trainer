# and, or и порядок проверок в if/elif

## True и False

Кроме чисел и текста есть значения `True` («да») и `False` («нет»). Результат сравнения — уже такое значение, поэтому его можно вернуть сразу:

```python
def is_round(n):
    return n % 10 == 0
```

Параметр тоже может быть `True` или `False`. Тогда условие пишут прямо по нему: `if is_vip:` значит «если `is_vip` равно `True`». Писать `== True` не нужно.

## and и or

- `A and B` — верно, только если верны **оба** условия;
- `A or B` — верно, если верно **хотя бы одно**.

Скобки задают порядок, как в арифметике: сначала то, что в скобках.

```python
def can_borrow(age, has_card, is_teacher):
    return age >= 14 and (has_card or is_teacher)
```

Возраст нужен всем, а дальше достаточно **любого одного**: билета или статуса учителя.

Високосный год: делится на 4 и не на 100, **или** делится на 400:

```python
(year % 4 == 0 and year % 100 != 0) or year % 400 == 0
```

## Цепочка if / elif / else — сверху вниз

Проверки идут **сверху вниз**, и срабатывает **первая** верная; остальные пропускаются. Поэтому порядок важен.

```python
def weather(t):
    if t >= 25:
        return "жарко"
    elif t >= 10:
        return "тепло"
    else:
        return "холодно"
```

- Для `t = 30` верны оба условия, но первый `return` завершает функцию.
- Для `t = 15` первое условие неверно, значит `t < 25`, и второе проверяет только нижнюю границу.

Поэтому диапазоны удобно разбирать **в одну сторону** и проверять только одну границу: следующая проверка уже знает, что предыдущие не сработали.
Особый или невозможный случай ставят **первым**:

```python
def side(x, y):
    if x == 0 or y == 0:
        return "на оси"      # особый случай — первым
    elif x > 0:
        return "справа"
    else:
        return "слева"
```

## Частые ошибки

Поставить общую проверку раньше частной:

```python
def weather(t):
    if t >= 10:
        return "тепло"       # неверно: 30 градусов тоже попадёт сюда
    elif t >= 25:
        return "жарко"       # до этой строки дело не дойдёт
```

Правильно — сначала самая строгая граница (`t >= 25`), потом более мягкая (`t >= 10`).

## Проверь себя

```python
def f(a, b):
    return a > 0 and (b > 0 or a > 10)
```

1. Чему равно `f(5, 3)`?
2. Чему равно `f(5, -1)`?
3. Чему равно `f(20, -1)`?

<details><summary>Ответ</summary>

1. `a > 0` верно, `b > 0` верно: `True and True` = `True`.
2. `a > 0` верно, но `b > 0` неверно и `a > 10` неверно: скобка `False`, итог `False`.
3. `a > 0` верно, `b > 0` неверно, зато `a > 10` верно: скобка `True`, итог `True`.

</details>
