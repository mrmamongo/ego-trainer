# Задача FN10: Собери функцию: большее из двух

## Условие

### Как это работает

Часто удобно в ветках только **записать результат в переменную**, а вернуть его одной строкой после `if/else`.
Эта строка `return` стоит на том же уровне, что и `if`, то есть **вне** веток: она выполняется всегда, после выбранной ветки.

```python
def label(n):
    if n > 0:
        text = "плюс"
    else:
        text = "не плюс"
    return text
```

Отступ у `return text` такой же, как у `if`. Если сдвинуть его под `else`, то при `n > 0` функция ничего не вернёт.

### Задание

В файле задачи в комментарии записаны строки функции `task_fn10_bigger(a, b)`, перемешанные и без отступов.
Собери из них тело функции и удали строку `return None`. Функция должна вернуть большее из двух чисел.

## Аргументы

- `a`, `b` — целые числа.

## Возвращает

Целое число — большее из `a` и `b`. Если числа равны, верни это число.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_fn10_bigger(3, 8)   # -> 8
task_fn10_bigger(9, 2)   # -> 9
task_fn10_bigger(5, 5)   # -> 5
```

## Учебные цели

- Собирать ветвление `if/else` с присваиванием переменной из готовых строк.
- Ставить `return` после ветвления на нужный уровень отступа.

## Проверка понимания

Что вернёт функция при `a = b`: `a` или `b`? Имеет ли это значение? Почему `return result` не должен стоять под `else`?
