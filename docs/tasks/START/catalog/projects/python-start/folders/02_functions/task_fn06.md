# Задача FN06: Аргументы по порядку

## Условие

### Как это работает

Когда у функции несколько параметров, значения из скобок вызова раскладываются **по порядку**:
первый аргумент — в первый параметр, второй — во второй. Имена переменных снаружи не важны, важна только позиция.

```python
def subtract(first, second):
    return first - second

r = subtract(10, 3)     # 1
s = subtract(3, 10)     # 2
w = 4                   # 3
t = subtract(w, 1)      # 4
```

| После строки | r | s | w | t |
|---|---|---|---|---|
| 1 | 7 | — | — | — |
| 2 | 7 | -7 | — | — |
| 4 | 7 | -7 | 4 | 3 |

В строке 2 те же числа, но в другом порядке — и ответ другой. В строке 4 в `first` попадает **значение** `w`, то есть 4.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. Ответы — значения `a`, `b`, `c` в самом конце.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, шаг за шагом проследив вызовы.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fn06_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Знать, что аргументы попадают в параметры по порядку.
- Понимать, что в параметр попадает значение переменной, а не её имя.
