# Функция: def, параметр, вызов, return

**Функция** — кусочек кода с именем, который можно запускать, когда он нужен.

```python
def triple(k):
    answer = k * 3
    return answer
```

Здесь три разные вещи:

1. `def triple(k):` **создаёт** функцию. Строки с отступом — её тело — при этом **не выполняются**.
   `k` — **параметр**: пустая ячейка для значения, которое придёт при вызове.
2. `triple(5)` — **вызов**. Только теперь программа заходит в тело, записывает 5 в `k` и выполняет строки по порядку.
3. `return answer` **отдаёт** значение назад, туда, где функцию вызвали. Вызов `triple(5)` как бы заменяется этим значением.

Помнишь `def task_v01_trace():` и `return ...` в задачах первой папки? Это такая же функция: проверка вызывает её, тело выполняется, а то, что стоит после `return`, — твои ответы.

## Пример

```python
x = triple(5)       # 1
y = triple(x - 11)  # 2
```

| После строки | x | y |
|---|---|---|
| 1 | 15 | — |
| 2 | 15 | 12 |

Строка 1: `k = 5`, `answer = 15`, `return` отдаёт 15 — оно записывается в `x`.
Строка 2: сначала считается аргумент `x - 11` = 4, потом вызов с `k = 4` даёт 12.

## Параметр живёт только внутри вызова

Параметр и переменные, созданные **внутри** функции, существуют, пока функция работает. Когда вызов закончился, они пропадают.
Снаружи их не видно, а переменные снаружи вызов не меняет.

```python
def add_tax(price):
    tax = price // 5
    return price + tax

base = 100
r = add_tax(base)
```

После этого `r = 120`, а `base` по-прежнему 100. Переменных `price` и `tax` снаружи **нет**: строка `z = tax` остановила бы программу с `NameError`, как в карточке про порядок создания переменных.
(`//` — деление нацело, про него будет отдельная карточка.)

## Частые ошибки

Написать `def` и ждать, что код выполнится:

```python
def triple(k):
    return k * 3
triple(5)       # вызов нужен: одного def мало, значение никуда не записано
```

```python
x = triple(5)   # верно: вызвали и сохранили результат в x
```

## Проверь себя

```python
def inc(n):
    return n + 1
```

1. Чему равно `a` после `a = inc(4)`?
2. Чему равно `b` после `m = 10`, `b = inc(m)`? Изменилось ли `m`?

<details><summary>Ответ</summary>

1. `n = 4`, `return 4 + 1`, значит `a = 5`.
2. В `n` попадает значение `m`, то есть 10; `b = 11`. Сама `m` не изменилась и осталась 10.

</details>
