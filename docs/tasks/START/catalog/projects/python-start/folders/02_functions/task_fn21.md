# Задача FN21: Сравни версии

## Условие

### Как это работает

Номер версии вида `2.5` сравнивают по частям: сначала **главное** число; только если оно одинаковое, смотрят на **второе**.
Так же сравнивают время по часам и минутам или слова по буквам.

| Сравниваем | Что решает |
|---|---|
| `1.9` и `2.0` | главные числа: 1 меньше 2, значит, `1.9` старше. Вторые числа даже не смотрим |
| `2.3` и `2.7` | главные равны, значит, решает второе: 3 меньше 7, `2.3` старше |
| `4.1` и `4.1` | всё равно, версии одинаковые |

Иначе говоря: пока старшая часть решает дело, младшую не смотрим. Если старшие равны, решает следующая.

### Задание

Напиши функцию `task_fn21_compare_versions(major1, minor1, major2, minor2)`: сравни две версии `major1.minor1` и `major2.minor2`.
Сначала сравнивается `major`; если они равны — `minor`.

## Аргументы

- `major1`, `minor1` — главный и второй номер первой версии.
- `major2`, `minor2` — главный и второй номер второй версии. Все числа целые, от 0.

## Возвращает

`-1`, если первая версия старше (меньше), `1`, если новее (больше), `0`, если версии равны.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn21_compare_versions(1, 2, 1, 3)   # -> -1  (1.2 старше 1.3)
task_fn21_compare_versions(2, 0, 1, 9)   # -> 1   (2.0 новее 1.9)
task_fn21_compare_versions(3, 4, 3, 4)   # -> 0
```

## Учебные цели

- Сравнивать составные значения по частям: сначала старшая, потом младшая.
- Возвращать разные значения для трёх исходов.

## Проверка понимания

Почему версия 2.0 новее 1.9, хотя `0 < 9`? Что вернёт функция для `(1, 5, 1, 5)`?
