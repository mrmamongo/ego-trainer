# Задача FN16: Какой треугольник

## Условие

### Как это работает

Когда вариантов несколько и они бывают «особыми», сначала отсекай **невозможный** случай, потом идут частные, а общий оставляй в `else`.
Порядок важен: каждая следующая проверка уже знает, что предыдущие не сработали.

```python
def pair_kind(x, y):
    if x == y:
        return "одинаковые"
    elif x > y * 10 or y > x * 10:
        return "очень разные"
    else:
        return "обычные"
```

Условия можно соединять через `or` («хотя бы одно верно») и `and` («оба верны»).

### Задание

Напиши функцию `task_fn16_triangle(a, b, c)`: по длинам трёх сторон определи вид треугольника.

Сначала проверь, существует ли такой треугольник: если какая-то сторона **не меньше** суммы двух других, это не треугольник.
Иначе: все три стороны равны — равносторонний; ровно две равны — равнобедренный; все разные — разносторонний.

## Аргументы

- `a`, `b`, `c` — длины сторон, положительные целые числа.

## Возвращает

Строку: `"не треугольник"`, `"равносторонний"`, `"равнобедренный"` или `"разносторонний"`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn16_triangle(3, 4, 5)   # -> "разносторонний"
task_fn16_triangle(5, 5, 5)   # -> "равносторонний"
task_fn16_triangle(1, 2, 3)   # -> "не треугольник"  (3 = 1 + 2)
```

## Учебные цели

- Упорядочивать проверки: сначала невозможный случай, потом частные.
- Составлять условия через `or` и `and`.

## Проверка понимания

Почему равносторонний нужно проверять раньше равнобедренного? Почему стороны 1, 2, 3 не образуют треугольник?
