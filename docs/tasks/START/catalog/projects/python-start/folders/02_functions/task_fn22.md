# Задача FN22: Четверть на плоскости

## Условие

### Как это работает

Точка на плоскости задаётся парой чисел `(x, y)`. Плоскость делится осями на четыре четверти:

| | `x > 0` | `x < 0` |
|---|---|---|
| `y > 0` | 1 | 2 |
| `y < 0` | 4 | 3 |

Если `x` или `y` равен нулю, точка лежит на оси и ни в одной четверти не находится.

Новых правил нет. Помогает порядок проверок: сначала отсекаем особый случай, потом разбираем обычные.

```python
def side(x, y):
    if x == 0 or y == 0:
        return "на оси"
    elif x > 0:
        return "справа"
    else:
        return "слева"
```

### Задание

Напиши функцию `task_fn22_quadrant(x, y)`, которая определяет номер четверти, в которой лежит точка.

## Аргументы

- `x`, `y` — координаты точки, целые числа.

## Возвращает

Целое число: номер четверти `1`, `2`, `3` или `4`, а если точка лежит на любой из осей (в том числе в начале координат) — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn22_quadrant(3, 4)    # -> 1
task_fn22_quadrant(-3, -4)  # -> 3
task_fn22_quadrant(0, 5)    # -> 0  (точка на оси)
```

## Учебные цели

- Сначала обрабатывать особый случай, потом общие.
- Описывать область условием из двух проверок через `and`.

## Проверка понимания

Что вернёт функция для `(0, 0)`? Почему проверку осей нужно делать раньше, чем знаки?
