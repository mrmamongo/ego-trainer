# Задача FN08: С чего начинается переменная

## Условие

### Как это работает

Если переменную меняет только `if`, а условие не сработало, переменная остаётся с тем значением, которое было до `if`
(как в задачах про ветвление из прошлой папки). Поэтому **начальное значение — это ответ на случай, когда ни одно условие не сработало**.

```python
def bonus(points):
    extra = 0
    if points > 50:
        extra = 10
    return extra
```

- `bonus(80)`: условие верно, `extra` становится 10.
- `bonus(20)`: условие неверно, `extra` так и остаётся `0` — это и есть ответ «бонуса нет».

Если оставить вместо начального значения `None`, то в таком случае функция вернёт `None`, а не число.

### Задание

Функция `task_fn08_delivery_cost(total)` считает стоимость доставки по сумме заказа. Доставка стоит 300 рублей,
а при сумме заказа от 1000 рублей — бесплатна. Сейчас вместо начального значения стоит `None`: впиши правильное.

## Аргументы

- `total` — сумма заказа в рублях, целое число от 0.

## Возвращает

Целое число — стоимость доставки: `300` или `0`.

## Правила

- Меняй только значение вместо `None`; остальные строки не трогай.

## Пример

```python
task_fn08_delivery_cost(500)    # -> 300
task_fn08_delivery_cost(1500)   # -> 0
```

## Учебные цели

- Понимать, что начальное значение переменной — это результат случая, когда условие не сработало.
- Не оставлять `None` там, где нужен настоящий результат.

## Проверка понимания

Что вернёт функция при `total = 2000`, если оставить `cost = None`? Почему `300` в начальное значение ставить нельзя?
