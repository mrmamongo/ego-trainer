# Задача FN02: Параметр живёт только внутри вызова

## Условие

### Как это работает

Параметр и переменные, созданные **внутри** функции, существуют только пока функция работает.
Когда вызов закончился, они пропадают. Снаружи их не видно, а переменные снаружи вызов не меняет.

```python
def add_tax(price):
    tax = price // 5
    return price + tax

base = 100
r = add_tax(base)
```

После этого `r` равно 120 (`tax` внутри было 20), а `base` по-прежнему 100.
Переменных `price` и `tax` снаружи **нет**: если написать `z = tax`, программа остановится с `NameError`
(как в задаче V12).

`//` — деление нацело, остаток отбрасывается: `7 // 2` равно 3. Подробнее про него будет позже.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `fee_exists_outside` — это `True` или `False`: есть ли переменная `fee` снаружи функции после строки 6.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, шаг за шагом проследив вызовы.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fn02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что параметры и локальные переменные живут только внутри вызова.
- Знать, что вызов функции не меняет переменные снаружи, если не присвоить результат.

## Проверка понимания

Почему `total` остался 200, хотя функцию вызвали с `total`? Что произойдёт, если после строки 6 написать `z = fee`?
