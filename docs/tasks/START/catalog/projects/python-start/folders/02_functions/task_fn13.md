# Задача FN13: Високосный год

## Условие

### Как это работает

Функция может вернуть `True` или `False`. Результат сравнения — уже такое значение, его можно вернуть сразу:

```python
def is_round(n):
    return n % 10 == 0
```

Несколько условий склеиваются словами:

- `A and B` — верно, только если верны **оба**;
- `A or B` — верно, если верно **хотя бы одно**.

`%` — остаток от деления: `n % 10 == 0` значит «n делится на 10 без остатка». Для сложных условий можно использовать скобки,
как в арифметике: `(A and B) or C`.

### Задание

Напиши функцию `task_fn13_is_leap(year)`, которая говорит, високосный ли год.

Год високосный, если он делится на 4 и при этом не делится на 100, **или** если он делится на 400.

## Аргументы

- `year` — год, целое число от 1.

## Возвращает

`True`, если год високосный, иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn13_is_leap(2024)   # -> True
task_fn13_is_leap(2023)   # -> False
task_fn13_is_leap(1900)   # -> False  (делится на 100, но не на 400)
```

## Учебные цели

- Возвращать результат сравнения как значение `True`/`False`.
- Соединять условия через `and` и `or`.
