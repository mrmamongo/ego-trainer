# Несколько параметров: аргументы по порядку

Когда у функции несколько параметров, значения из скобок вызова раскладываются **по порядку**:
первый аргумент — в первый параметр, второй — во второй, и так далее.
Имена переменных снаружи не важны, важна только **позиция**.

```python
def subtract(first, second):
    return first - second

r = subtract(10, 3)     # 1
s = subtract(3, 10)     # 2
w = 4                   # 3
t = subtract(w, 1)      # 4
```

| После строки | r | s | w | t |
|---|---|---|---|---|
| 1 | 7 | — | — | — |
| 2 | 7 | -7 | — | — |
| 3 | 7 | -7 | 4 | — |
| 4 | 7 | -7 | 4 | 3 |

- Строка 1: `first = 10`, `second = 3`, результат `10 - 3 = 7`.
- Строка 2: те же числа, но в другом порядке — и ответ другой: `3 - 10 = -7`.
- Строка 4: в `first` попадает **значение** `w`, то есть 4, а в `second` — 1. Результат 3.

## Как не перепутать

Перед каждым вызовом выпиши «параметр = значение» пары по порядку:

```
subtract(w, 1)  ->  first = 4, second = 1
```

Аргумент может быть и выражением: `subtract(w + 2, 1)` сначала посчитает `w + 2`, и только потом это значение попадёт в `first`.

## Частые ошибки

Думать, что порядок аргументов не важен:

```python
def power_diff(big, small):
    return big - small

power_diff(2, 9)    # неверно, если хотели «9 - 2»: получится -7
power_diff(9, 2)    # верно: 7
```

Ещё ошибка — передать меньше или больше аргументов, чем параметров: программа остановится с ошибкой, пока число значений не совпадёт.

## Проверь себя

```python
def f(a, b):
    return a * 10 + b
```

1. Чему равно `f(3, 7)`?
2. Чему равно `f(7, 3)`?
3. Чему равно `f(x, 1)` при `x = 2`?

<details><summary>Ответ</summary>

1. `a = 3`, `b = 7`: `3 * 10 + 7 = 37`.
2. `a = 7`, `b = 3`: `7 * 10 + 3 = 73`. Порядок меняет ответ.
3. `a = 2`, `b = 1`: `2 * 10 + 1 = 21`.

</details>
