# Задача FN11: Оценка по баллам

## Условие

### Как это работает

Проверки `if/elif` идут **сверху вниз**, и срабатывает первая верная. Поэтому границы удобно проверять от самой высокой вниз:
когда дошли до второго условия, первое уже точно было неверным.

```python
def weather(t):
    if t >= 25:
        return "жарко"
    elif t >= 10:
        return "тепло"
    else:
        return "холодно"
```

Для `t = 30` верны оба условия, но `return` в первом завершает функцию (как в FN03). Для `t = 15` первое условие неверно, значит, `t < 25`, и второе проверяет только нижнюю границу.

### Задание

Напиши функцию `task_fn11_mark(score)`, которая по баллам за экзамен возвращает оценку.

## Аргументы

- `score` — баллы, целое число от 0 до 100.

## Возвращает

Целое число — оценку: от 90 баллов — `5`, от 75 до 89 — `4`, от 60 до 74 — `3`, меньше 60 — `2`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn11_mark(95)   # -> 5
task_fn11_mark(75)   # -> 4
task_fn11_mark(30)   # -> 2
```

## Учебные цели

- Выстраивать цепочку `if/elif/else` от верхней границы вниз.
- Следить за границами: «от 90» включает 90.

## Проверка понимания

Почему во втором условии не нужно проверять `score < 90`? Какую оценку получит ровно 60 баллов?
