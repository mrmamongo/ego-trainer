# Задача FN12: Цена со скидкой

## Условие

### Как это работает

Значение бывает не только числом или текстом. Есть ещё `True` («да») и `False` («нет») — их можно передать в функцию как аргумент.
Условие можно писать прямо по такому параметру:

```python
def pay(total, is_vip):
    if is_vip:
        total = total - total // 10
    return total
```

`if is_vip:` — это «если `is_vip` равно `True`». Писать `== True` не нужно.

Переменную можно менять по ходу функции несколько раз: сначала применили одну скидку, потом проверили новую сумму для второй.
`total // 10` — десятая часть суммы (целая).

### Задание

Напиши функцию `task_fn12_final_price(price, is_member)`, которая считает итоговую цену заказа.

1. Участникам клуба (`is_member` равно `True`) даётся скидка 10%: из цены вычитается `price // 10`. Остальным скидки нет.
2. После этого, если получившаяся цена **больше** 5000, вычитается ещё 500. Это правило действует для всех.

## Аргументы

- `price` — цена в рублях, целое число от 0.
- `is_member` — `True` или `False`.

## Возвращает

Целое число — итоговую цену.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn12_final_price(1000, True)    # -> 900   (скидка 100)
task_fn12_final_price(1000, False)   # -> 1000
task_fn12_final_price(6000, False)   # -> 5500  (больше 5000: ещё минус 500)
```

## Учебные цели

- Менять переменную в несколько шагов и использовать результат первого шага во втором.
- Использовать параметр `True`/`False` прямо в условии.

## Проверка понимания

Почему вторая проверка идёт по цене после скидки, а не по исходной? Чему равен результат для `(5500, True)`?
