# Задача FN17: Время суток

## Условие

### Как это работает

Когда нужно разбить числа на диапазоны, не обязательно проверять обе границы. Идём по диапазонам снизу вверх и проверяем только **верхнюю** границу:
если дошли до следующей проверки, нижняя граница уже обеспечена тем, что предыдущие условия не сработали.

```python
def age_group(age):
    if age <= 12:
        return "ребёнок"
    elif age <= 19:
        return "подросток"
    else:
        return "взрослый"
```

Здесь второе условие не пишет `age >= 13`: к нему попадают только те, у кого `age > 12`.

### Задание

Напиши функцию `task_fn17_part_of_day(hour)`, которая по часу определяет время суток.

## Аргументы

- `hour` — час, целое число от 0 до 23.

## Возвращает

Строку: с 0 до 5 — `"ночь"`, с 6 до 11 — `"утро"`, с 12 до 17 — `"день"`, с 18 до 23 — `"вечер"` (границы включены).

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn17_part_of_day(3)    # -> "ночь"
task_fn17_part_of_day(12)   # -> "день"
task_fn17_part_of_day(23)   # -> "вечер"
```

## Учебные цели

- Разбивать числа на диапазоны цепочкой `if/elif` только по верхней границе.
- Следить за включением границ.

## Проверка понимания

Почему во втором условии не нужно проверять нижнюю границу? К какому времени суток относится ровно 6 часов?
