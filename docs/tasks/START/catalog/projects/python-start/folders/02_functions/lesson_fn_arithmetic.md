# Арифметика: //, % и abs

## Целое деление и остаток

Две операции:

- `//` — **целое деление**: сколько раз одно число полностью помещается в другое. `17 // 5` равно 3.
- `%` — **остаток** после такого деления. `17 % 5` равно 2.

```python
total_minutes = 135
hours = total_minutes // 60      # 2 полных часа
minutes = total_minutes % 60     # 15 минут остаётся
```

Проверка: `2 * 60 + 15 = 135`. Для любых чисел верно «делимое = (результат `//`) * делитель + (результат `%`)».

## Остаток 0 — делится нацело

Если остаток равен 0, всё поделилось ровно. Если не равен — остался «хвост».

- `n % 2 == 0` — число `n` чётное;
- `n % 10 == 0` — `n` делится на 10 без остатка;
- `x % y != 0` — остался хвост.

```python
def packs(items, per_pack):
    full = items // per_pack
    if items % per_pack != 0:
        full = full + 1          # неполная упаковка тоже нужна
    return full
```

`packs(17, 5)`: `17 // 5 = 3`, остаток `17 % 5 = 2` не ноль, значит упаковок 4. `packs(15, 5)`: остатка нет, упаковок 3.

## Модуль числа: abs

`abs(x)` — число без знака: `abs(-3)` равно 3, `abs(5)` равно 5. Он нужен, когда важна только «величина разницы», а не направление.

```python
def is_neighbor(a, b):
    diff = abs(a - b)
    return diff == 1
```

`is_neighbor(4, 5)` и `is_neighbor(5, 4)` дают `True`: разница по модулю в обоих случаях 1.

## Частые ошибки

Перепутать `//` и `/`, а `%` с процентами:

```python
7 // 2    # 3   целое деление
7 % 2     # 1   остаток, а не «7 процентов»
```

Ещё ошибка — забыть, что разница может быть отрицательной:

```python
diff = a - b          # неверно: при a < b получится отрицательное число
diff = abs(a - b)     # верно: всегда без знака
```

## Проверь себя

1. Чему равны `25 // 4` и `25 % 4`?
2. Чему равно `abs(3 - 8)`?
3. Что даст условие `n % 2 == 0` при `n = 9`?

<details><summary>Ответ</summary>

1. `4` помещается в 25 шесть раз (`6 * 4 = 24`), остаток 1: `25 // 4 = 6`, `25 % 4 = 1`.
2. `3 - 8 = -5`, модуль равен `5`.
3. `9 % 2 = 1`, а не 0, поэтому условие неверно (`False`) — число нечётное.

</details>
