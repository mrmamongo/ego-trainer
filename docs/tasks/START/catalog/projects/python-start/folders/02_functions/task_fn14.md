# Задача FN14: Сколько упаковок купить

## Условие

### Как это работает

Две операции:

- `//` — **целое деление**: сколько раз одно число полностью помещается в другое. `17 // 5` равно 3.
- `%` — **остаток** после такого деления. `17 % 5` равно 2.

```python
total_minutes = 135
hours = total_minutes // 60      # 2 полных часа
minutes = total_minutes % 60     # 15 минут остаётся
```

Если остаток есть (не равен 0), значит, после полных групп остался «хвост». А если остатка нет, всё поделилось ровно.
Эту проверку остатка можно записать условием `if x % y != 0:`.

### Задание

Напиши функцию `task_fn14_packs(items, per_pack)`: сколько упаковок нужно купить, чтобы вместить все предметы.
В одной упаковке `per_pack` штук. Упаковки продаются только целиком; нужно минимальное количество, которого хватит.
Модуль `math` использовать не нужно: решай через `//`, `%` и `if`.

## Аргументы

- `items` — сколько предметов нужно, целое число от 0.
- `per_pack` — штук в упаковке, целое число от 1.

## Возвращает

Целое число — минимальное количество упаковок.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn14_packs(12, 4)   # -> 3
task_fn14_packs(13, 4)   # -> 4
task_fn14_packs(0, 4)    # -> 0
```

## Учебные цели

- Различать целое деление `//` и остаток `%`.
- Округлять результат деления вверх через проверку остатка.

## Проверка понимания

Почему при `items = 0` ответ 0, а не 1? Что даёт `items % per_pack`, когда предметы делятся на упаковки ровно?
