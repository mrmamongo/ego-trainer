# Задача FN18: Ход коня

## Условие

### Как это работает

`abs(x)` — **модуль** числа, то есть число без знака: `abs(-3)` равно 3, `abs(5)` равно 5. Он нужен, когда важна только
«величина разницы», а не то, в какую сторону она направлена.

```python
def is_neighbor(a, b):
    diff = abs(a - b)
    return diff == 1
```

`is_neighbor(4, 5)` и `is_neighbor(5, 4)` дают `True`: разница по модулю в обоих случаях 1.
Результат сравнения можно сразу вернуть как `True` или `False`.

### Задание

Напиши функцию `task_fn18_knight_move(x1, y1, x2, y2)`: может ли шахматный конь за один ход перейти с клетки `(x1, y1)` на клетку `(x2, y2)`.

Конь ходит так: на 1 клетку по одной координате и на 2 по другой (в любую сторону). То есть разницы координат
по модулю равны `(1, 2)` или `(2, 1)`.

## Аргументы

- `x1`, `y1` — клетка, с которой идёт конь.
- `x2`, `y2` — клетка, на которую он хочет попасть. Все числа целые.

## Возвращает

`True`, если это ход коня, иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fn18_knight_move(1, 1, 2, 3)   # -> True   (разницы 1 и 2)
task_fn18_knight_move(5, 5, 3, 4)   # -> True   (разницы 2 и 1)
task_fn18_knight_move(1, 1, 2, 2)   # -> False  (разницы 1 и 1)
```

## Учебные цели

- Использовать `abs()` для разницы без учёта направления.
- Возвращать составное условие как `True`/`False`.
