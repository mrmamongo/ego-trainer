# Задача FN04: return и print — разные вещи

## Условие

### Как это работает

Это две разные вещи:

- `print(...)` **показывает** значение на экране — для человека. Программа это значение дальше не получает.
- `return ...` **отдаёт** значение программе — туда, где функцию вызвали. На экране при этом ничего не появится.

Если в функции нет `return`, она всё равно что-то возвращает — особое значение `None` («ничего»).

```python
def say(n):
    print(n + 1)

def give(n):
    return n + 1

p = say(3)     # 1
q = give(3)    # 2
```

- Строка 1: на экране появится `4` (это сделал `print`). Но `return` в `say` нет, поэтому `p` — `None`.
- Строка 2: на экране ничего. `give` вернула 4, и `q` равно 4.

Проверка в этой папке всегда смотрит на то, что функция **вернула**. Напечатанное она не видит.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `printed_on_screen` — число, которое появится на экране, `x_is_none` — `True` или `False`.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, шаг за шагом проследив вызовы.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fn04_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Различать вывод на экран (`print`) и возврат значения (`return`).
- Знать, что функция без `return` возвращает `None`.
