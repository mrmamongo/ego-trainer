# Задача N05: Площадь круга

## Условие

### Как это работает

Формула площади круга: `π * r ** 2`. Число π уже есть в модуле `math`, поэтому писать `3.14` не нужно.

```python
import math

def area(r):
    return math.pi * r ** 2
```

| Выражение | Значение |
|---|---|
| `r ** 2` при `r = 2` | `4` |
| `math.pi * 4` | `12.566370614359172` |
| `round(12.566370614359172, 2)` | `12.57` |

Модуль `math` импортируют в самом начале файла: `import math`. Дальше к его значениям и функциям обращаются через точку —
`math.pi`, `math.sqrt(...)`.

### Задание

Напиши функцию `task_n05_circle_area(r)`: верни площадь круга радиуса `r`, округлённую до **2 знаков** после точки через `round`.

## Аргументы

- `r` — радиус, целое число (может быть `0`).

## Возвращает

Дробное число — площадь `math.pi * r ** 2`, округлённая через `round(..., 2)`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- `import math` допиши в начале файла; пиши `math.pi`, а не `3.14`.
- Округли результат через `round(..., 2)` и **верни** его через `return`.
- Ответ должен быть дробным: не превращай его в целое через `int`.

## Пример

```python
task_n05_circle_area(1)   # -> 3.14
task_n05_circle_area(2)   # -> 12.57
task_n05_circle_area(0)   # -> 0.0
```

## Учебные цели

- Импортировать модуль `math` и пользоваться `math.pi`.
- Округлять дробный результат до нужного числа знаков.
