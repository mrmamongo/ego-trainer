# Задача N02: Что получится: round, //, % и **

## Условие

### Как это работает

Четыре правила, которые здесь проверяются:

- `round(x)` округляет до целого, а при **ровно половине** — к **чётному**: `round(2.5)` равно `2`, `round(3.5)` равно `4`.
- `round(x, 1)` округляет до одного знака после точки: `round(7.456, 1)` равно `7.5`.
- У отрицательных чисел `//` округляет **вниз**, а `%` берёт остаток от этого результата: `a == (a // b) * b + a % b`.
- Цепочка `**` считается **справа налево**.

```python
a = round(2.5)        # 1
b = round(3.5)        # 2
c = round(7.456, 1)   # 3
d = -7 // 2           # 4
e = -7 % 2            # 5
f = 2 ** 3 ** 2       # 6
```

| Строка | Что считается | Значение |
|---|---|---|
| 4 | `-7 // 2`: вниз от `-3.5` | `-4` |
| 5 | `(-4) * 2 + e = -7` | `1` |
| 6 | `2 ** (3 ** 2) = 2 ** 9` | `512` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a`, `b`, `c`, `d`, `e`, `f` — значения этих переменных **после** последней строки кода.
Все ответы здесь — целые числа, пиши их без кавычек и без точки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, посчитав каждое выражение по правилам выше.

## Правила

- Меняй только строчки с `None`; ответы — целые числа без кавычек.
- Строки `def task_n02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Помнить, что `round` при половине округляет к чётному.
- Правильно считать `//` и `%` для отрицательных чисел и порядок `**`.

## Проверка понимания
