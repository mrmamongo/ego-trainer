# Задача N03: Сумма цифр трёхзначного числа

## Условие

### Как это работает

Цифры числа можно достать без текста — через `//` и `%`:

- `% 10` — **последняя** цифра: `386 % 10` равно `6`;
- `// 10` — число **без последней** цифры: `386 // 10` равно `38`.

Три цифры трёхзначного числа `n` идут сверху вниз: сотни, десятки, единицы.

```python
n = 386
units = n % 10          # 6
tens = n // 10 % 10     # 8   (386 // 10 = 38, 38 % 10 = 8)
hundreds = n // 100     # 3
```

| Строка | Что считается | Значение |
|---|---|---|
| `units` | `386 % 10` | `6` |
| `tens` | `38 % 10` | `8` |
| `hundreds` | `3` | `3` |

Дальше цифры просто складываем: `3 + 8 + 6 = 17`. Цикл и строки здесь не нужны — цифр ровно три.

### Задание

Напиши функцию `task_n03_digit_sum3(n)`: верни сумму цифр трёхзначного положительного числа.

## Аргументы

- `n` — целое число от 100 до 999.

## Возвращает

Целое число — сумму цифр числа `n`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Тексты не используй: `str(n)` и обращение к символу запрещены.
- Цикл и `for` не нужны: цифр всегда три.
- Сумма — целое число, без `round`.

## Пример

```python
task_n03_digit_sum3(386)   # -> 17
task_n03_digit_sum3(100)   # -> 1
task_n03_digit_sum3(999)   # -> 27
```

## Учебные цели

- Доставать разряды числа через `//` и `%`.
- Обходиться без текста, когда нужны отдельные цифры.

## Проверка понимания
