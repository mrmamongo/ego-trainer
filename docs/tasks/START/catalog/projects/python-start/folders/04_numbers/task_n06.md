# Задача N06: Коробки через math.ceil

## Условие

### Как это работает

В задаче FN14 упаковки считали через `//` и проверку остатка. В модуле `math` для этого есть готовая функция:
`math.ceil(x)` округляет **вверх** до целого.

```python
import math

math.ceil(3.0)    # 3
math.ceil(3.25)   # 4
math.ceil(0.0)    # 0
```

Значит, коробки — это `math.ceil(items / per_box)`.

| Выражение | Значение |
|---|---|
| `13 / 4` | `3.25` |
| `math.ceil(3.25)` | `4` |
| `math.ceil(12 / 4)` | `3` |

Важно: делить нужно через `/`. Если написать `items // per_box` и сразу передать в `math.ceil`, `math.ceil(3)` вернёт `3`
и неполная коробка потеряется.

### Задание

Напиши функцию `task_n06_boxes(items, per_box)`: верни минимальное число коробок, куда поместятся все предметы.
Коробки целые; неполная коробка тоже считается.

## Аргументы

- `items` — сколько предметов, целое число от 0.
- `per_box` — сколько штук в коробке, целое число от 1.

## Возвращает

Целое число — количество коробок. Для `items = 0` — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- `import math` допиши в начале файла и используй `math.ceil`.
- Деление внутри `math.ceil` делай через `/`; `//` здесь не подходит.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_n06_boxes(13, 4)   # -> 4
task_n06_boxes(12, 4)   # -> 3
task_n06_boxes(0, 4)    # -> 0
```

## Учебные цели

- Округлять «вверх» через `math.ceil`.
- Сравнить с решением через `//` и `%`: результат одинаковый, запись короче.

## Проверка понимания

Что вернёт `math.ceil(12 // 4)` и почему это неверный ответ для `(12, 4)`? Когда `math.ceil` и `//` дают одинаковый ответ?
