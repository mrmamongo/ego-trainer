# Округление, отрицательные числа и модуль math

## round: округление до целого и до знаков

`round(x)` округляет до **целого**: `round(3.4)` равно `3`, `round(3.6)` равно `4`.
`round(x, n)` округляет до `n` знаков после точки: `round(7.456, 1)` равно `7.5`.

У `round` есть неожиданность: при ровно половине он округляет к **чётному** числу (так называемое «банковское округление»):

| Выражение | Результат | Почему |
|---|---|---|
| `round(2.5)` | `2` | 2 — чётное |
| `round(3.5)` | `4` | 4 — чётное |
| `round(7.456, 1)` | `7.5` | до одного знака |

Если такая неожиданность не нужна, задачу формулируют так, чтобы половины не встречались.

## // и % для отрицательных чисел

`//` — целое деление: результат округляется **вниз** (к меньшему числу), а не «к нулю».
Поэтому `-7 // 2` равно `-4` (а не `-3`).

`%` продолжает это правило: `a == (a // b) * b + a % b`. Отсюда `-7 % 2` равно `1`:
`(-4) * 2 + 1 = -7`. Остаток у положительного делителя всегда неотрицательный.

## Модуль math

Импортируют его в самом начале файла:

```python
import math
```

| Функция | Что делает | Пример |
|---|---|---|
| `math.sqrt(x)` | квадратный корень | `math.sqrt(9)` → `3.0` |
| `math.ceil(x)` | округляет **вверх** | `math.ceil(2.1)` → `3` |
| `math.floor(x)` | округляет **вниз** | `math.floor(2.9)` → `2` |
| `math.pi` | число π | `3.141592653589793` |

Дальше всё пишется через `math.`: `math.sqrt(16)`.

`math.ceil` удобен, когда считают «сколько коробок нужно»: `math.ceil(13 / 4)` равно `4`.

## Порядок операций и степень

Работают привычные правила: сначала `**`, потом `*`, `/`, `//`, `%`, потом `+` и `-`; скобки меняют порядок.
`2 + 3 * 4` равно `14`, а `(2 + 3) * 4` равно `20`.

`**` — возведение в степень: `2 ** 3` равно `8`. Цепочка `**` считается **справа налево**:
`2 ** 3 ** 2` — это `2 ** (3 ** 2)`, то есть `2 ** 9 = 512`.

## Частые ошибки

Думать, что `round` округляет всегда вверх:

```python
round(2.5)        # 2, а не 3: половина уходит к чётному
```

Забыть `import math`:

```python
result = math.sqrt(9)   # неверно: NameError, math ещё не объявлен
```

```python
import math
result = math.sqrt(9)   # верно: 3.0
```

## Проверь себя

1. Чему равны `math.ceil(5 / 2)` и `5 // 2`?
2. Чему равны `-9 // 4` и `-9 % 4`?
3. Чему равно `3 + 2 ** 2 * 3`?

<details><summary>Ответ</summary>

1. `math.ceil(5 / 2)` равно `3` (вверх), `5 // 2` равно `2` (вниз).
2. `-9 // 4` равно `-3`: `(-3) * 4 + 3 = -9`, значит `-9 % 4` равно `3`.
3. Сначала `2 ** 2 = 4`, потом `4 * 3 = 12`, потом `3 + 12 = 15`.

</details>
