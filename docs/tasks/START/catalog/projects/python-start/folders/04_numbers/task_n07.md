# Задача N07: Среднее без потери дробной части

## Условие

### Как это работает

Чтобы получить среднее, сумму делят на количество. Каким делением пользоваться — `/` или `//` — зависит от того,
дробный ответ нужен или нет.

- `/` всегда даёт `float`: `7 / 2` равно `3.5`;
- `//` даёт целое и **отбрасывает** дробную часть: `7 // 2` равно `3`.

Функция `task_n07_average(numbers)` возвращает число, но с одним условием: это должен быть **`float`**.
Посмотрим на её код:

```python
def task_n07_average(numbers):
    total = 0
    for number in numbers:
        total = total + number
    return total // len(numbers)   # проблема здесь
```

| Вызов | `total` | `len(numbers)` | Что вернёт функция |
|---|---|---|---|
| `[1, 2, 3]` | `6` | `3` | `2` (а должно быть `2.0`) |
| `[1, 2]` | `3` | `2` | `1` (а должно быть `1.5`) |

Список пуст — `len(numbers)` равно `0`, и делить нельзя: для пустого списка функция возвращает `0.0`.

### Задание

В файле задачи есть функция `task_n07_average(numbers)`, но она теряет дробную часть среднего. Найди ошибку и исправь её,
чтобы функция возвращала `float`-среднее. Для пустого списка верни `0.0`.

## Аргументы

- `numbers` — список целых чисел (может быть пустым).

## Возвращает

Дробное число (`float`) — сумму, делённую на количество; для пустого списка — `0.0`.

## Правила

- Исправь код функции; имя функции и параметры оставь как есть.
- Дели так, чтобы получилось дробное число: `/`, а не `//`.
- Пустой список обработай отдельно, чтобы не делить на `0`.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `sum` и `len` можно использовать как есть.

## Пример

```python
task_n07_average([1, 2, 3])   # -> 2.0
task_n07_average([1, 2])      # -> 1.5
task_n07_average([])          # -> 0.0
```

## Учебные цели

- Находить в коде деление, которое незаметно меняет тип ответа.
- Отличать `/` от `//` и выбирать нужное.

## Проверка понимания

Чем ответ исходной функции для `[1, 2]` отличается от правильного и почему? Почему для `[]` нужна отдельная проверка?
