# Типы чисел: int, float и str

В Python значение всегда чьё-то **типа**. Для чисел важны три:

| Тип | Что это | Примеры |
|---|---|---|
| `int` | целое число | `5`, `-3`, `0` |
| `float` | дробное число, с точкой | `2.5`, `7.0`, `0.1` |
| `str` | текст в кавычках | `"5"`, `"2.5"`, `"abc"` |

`"5"` и `5` — **разные** значения: первое — символ в кавычках, второе — число. Поэтому `"5" + 5` не работает:
Python не знает, склеивать ему текст с числом или складывать. Программа останавливается с ошибкой `TypeError`.

## Преобразование типов

Три функции меняют тип, сохраняя смысл значения:

- `int("5")` — из текста получаем число `5`; `int(2.9)` — отрезает дробную часть, получаем `2`;
- `float("2.5")` — из текста получаем число `2.5`; `float(7)` даёт `7.0`;
- `str(7)` — из числа получаем текст `"7"`.

```python
a = "7"              # 1
b = int(a) + 3       # 2
c = str(b) + a       # 3
```

| После | a | b | c |
|---|---|---|---|
| 1 | `"7"` | — | — |
| 2 | `"7"` | `10` | — |
| 3 | `"7"` | `10` | `"107"` |

В строке 2 `int(a)` превращает текст в число, и `7 + 3` складываются как числа. В строке 3 `str(b)` превращает `10` в текст,
и `"10" + "7"` склеиваются как текст.

## Деление `/` всегда даёт float

`6 / 3` равно `2.0`, а не `2`: результат `/` — всегда `float`, даже если делится нацело.
Если нужен целый результат, бери `//`: `7 // 2` равно `3`.

## Частые ошибки

Забыть преобразовать текст в число:

```python
age = "20"
next_age = age + 1      # неверно: TypeError, текст и число не складываются
```

```python
age = "20"
next_age = int(age) + 1 # верно: 21
```

## Проверь себя

1. Что получится: `int("5") + 5`?
2. Что получится: `str(5) + "5"`?
3. Чему равно `7 / 2` и чем оно отличается от `7 // 2`?

<details><summary>Ответ</summary>

1. `10`: текст превратился в число, числа сложились.
2. `"55"`: число превратилось в текст, тексты склеились.
3. `7 / 2` равно `3.5` — результат `/` всегда `float`. `7 // 2` равно `3` — это целое число, дробная часть отбрасывается.

</details>
