# Задача N08: Гипотенуза

## Условие

### Как это работает

По теореме Пифагора гипотенуза прямоугольного треугольника с катетами `a` и `b` равна `√(a² + b²)`.
Корень берут функцией `math.sqrt` из модуля `math`, а степень — оператором `**`.

```python
import math

a = 3
b = 4
square = a ** 2 + b ** 2     # 9 + 16 = 25
length = math.sqrt(square)   # 5.0
```

| Выражение | Значение |
|---|---|
| `a ** 2 + b ** 2` | `25` |
| `math.sqrt(25)` | `5.0` |
| `math.sqrt(a ** 2 + b ** 2)` | `5.0` |

`math.sqrt` всегда возвращает `float` (даже для `25` — это `5.0`). Чтобы убрать лишние знаки, результат округляют:
`round(..., 1)`.

| Вызов | `a² + b²` | Корень | `round(..., 1)` |
|---|---|---|---|
| `(3, 4)` | `25` | `5.0` | `5.0` |
| `(1, 1)` | `2` | `1.4142…` | `1.4` |

### Задание

Напиши функцию `task_n08_hypotenuse(a, b)`: верни длину гипотенузы прямоугольного треугольника с катетами `a` и `b`,
округлённую до **одного знака** после точки через `round`.

## Аргументы

- `a`, `b` — длины катетов, целые числа от `1`.

## Возвращает

Дробное число — `math.sqrt(a ** 2 + b ** 2)`, округлённое до одного знака.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- `import math` допиши в начале файла и используй `math.sqrt`.
- Степень пиши через `**`, а не умножением вручную.
- Округли `round(..., 1)` и **верни** результат через `return`.
- Ответ должен быть дробным: не превращай его в целое через `int`.

## Пример

```python
task_n08_hypotenuse(3, 4)   # -> 5.0
task_n08_hypotenuse(1, 1)   # -> 1.4
task_n08_hypotenuse(6, 8)   # -> 10.0
```

## Учебные цели

- Использовать `**` и `math.sqrt` вместе.
- Округлять результат корня до нужного числа знаков.
