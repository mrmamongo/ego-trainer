# Задача N01: Что получится: int, float, str

## Условие

### Как это работает

Тип значения видно по записи: `"7"` в кавычках — текст (`str`), `7` — целое (`int`), `7.5` — дробное (`float`).

| Функция | Что делает | Пример |
|---|---|---|
| `int(x)` | делает число из текста или отрезает дробную часть | `int("7")` → `7`, `int(7.9)` → `7` |
| `str(x)` | делает текст из числа | `str(7)` → `"7"` |
| `/` | всегда даёт `float` | `6 / 3` → `2.0` |
| `//` | целое деление, остаток отбрасывается | `7 // 2` → `3` |

`+` складывает два числа, а два текста склеивает. Текст и число сложить нельзя: программа остановится с ошибкой.

```python
a = "7"              # 1
b = int(a) + 3       # 2
c = str(b) + a       # 3
d = 7 / 2            # 4
e = 7 // 2           # 5
```

| Строка | Что считается | Значение |
|---|---|---|
| 2 | `int("7") + 3` — числа | `10` |
| 3 | `str(10) + "7"` — тексты | `"107"` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `b`, `c`, `d`, `e` — значения этих переменных **после** последней строки кода.
Число пиши без кавычек, текст — **в кавычках**, например `"107"`. `d` — результат `/`, поэтому запиши его с точкой.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по строкам.

## Правила

- Меняй только строчки с `None`.
- Текст пиши в кавычках, дробное число — с точкой (как `7.5`).
- Строки `def task_n01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Различать типы `int`, `float`, `str` по записи и по результату.
- Видеть, когда `int()` и `str()` меняют смысл операции.

## Проверка понимания

Почему `str(b) + a` склеивает, а не складывает? Что было бы, если бы в строке 3 стояло `b + a`?
