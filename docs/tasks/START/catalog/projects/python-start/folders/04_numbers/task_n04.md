# Задача N04: Цена с НДС из текста

## Условие

### Как это работает

С сайта или из файла цена приходит **текстом**: `"1290"`. Это не число, поэтому над ним нельзя посчитать проценты.
Сначала текст превращают в число: `int("1290")` даёт `1290`. Затем считают НДС и округляют результат.

```python
price = int("1290")                 # 1290
vat = price * 20 / 100              # 258.0
total = round(price + vat)          # 1548
```

| Выражение | Значение | Тип |
|---|---|---|
| `int("1290")` | `1290` | `int` |
| `price * 20 / 100` | `258.0` | `float` (из-за `/`) |
| `price + price * 20 // 100` | `1548` | `int` |

`/` всегда даёт `float`, а `round(...)` превращает дробное значение обратно в целое.

### Задание

Напиши функцию `task_n04_parse_price(text)`: преврати цену из текста в число, прибавь 20% (НДС) и верни итог,
округлённый до **целого** через `round()`.

## Аргументы

- `text` — цена в виде текста из цифр, например `"1290"` (целое положительное число, без пробелов и знаков).

## Возвращает

Целое число — цена с НДС, округлённая до целого.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Текст сначала преврати в число через `int(...)`; складывать текст с числом нельзя.
- Итог округли через `round(...)`; возвращай **целое** число, без точки (не `1548.0`).
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_n04_parse_price("1290")    # -> 1548
task_n04_parse_price("10")      # -> 12
task_n04_parse_price("0")       # -> 0
```

## Учебные цели

- Превращать текст в число перед вычислениями.
- Округлять денежный итог через `round`.

## Проверка понимания

Что произойдёт, если убрать `int(...)` и написать `text + 1`? Почему ответ для `"10"` — `12`, а не `12.0`?
