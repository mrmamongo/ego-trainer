# Текст и числа: кавычки и знак +

Если значение записано в **кавычках**, это **текст** (строка), а не число: `"2"` — это символ «2», а не число два.

Знак `+` ведёт себя по-разному:

- у **чисел** он складывает: `4 + 1` даёт `5`;
- у **текста** он склеивает: `"ab" + "cd"` даёт `"abcd"`.

## Пример

```python
s = "ab"     # 1
t = "cd"     # 2
u = s + t    # 3
p = 4        # 4
q = 1        # 5
r = p + q    # 6
```

| После строки | u | r |
|---|---|---|
| 3 | "abcd" | — |
| 6 | "abcd" | 5 |

В таблице (и в ответах к задачам) текст пишут **в кавычках**, число — **без** кавычек. Так сразу видно, что лежит в переменной.

## Частые ошибки

Складывать текст и число:

```python
a = "2"
b = 3
c = a + b    # неверно: программа остановится с ошибкой, текст и число не складываются
```

Если нужно сложить числа, пиши их без кавычек:

```python
a = 2
b = 3
c = a + b    # 5
```

Другая ошибка — думать, что `"2" + "3"` даст `5`. Это текст, поэтому получится `"23"`.

## Проверь себя

1. Что будет в `w` после `a = "до"`, `b = "ма"`, `w = a + b`?
2. Что будет в `z` после `x = "2"`, `y = "5"`, `z = x + y`? А после `x = 2`, `y = 5`, `z = x + y`?

<details><summary>Ответ</summary>

1. Текст склеивается: `w = "дома"`.
2. В первом случае это тексты, они склеиваются: `z = "25"`. Во втором числа складываются: `z = 7`.

</details>
