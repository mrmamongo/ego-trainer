# Задача V07: Текст и числа

## Условие

### Как это работает

Если значение записано в **кавычках**, это текст (строка), а не число: `"2"` — это символ «2», а не число два.

Знак `+` ведёт себя по-разному:

- у **чисел** он складывает: `4 + 1` даёт `5`;
- у **текста** он склеивает: `"ab" + "cd"` даёт `"abcd"`.

```python
s = "ab"     # 1
t = "cd"     # 2
u = s + t    # 3
p = 4        # 4
q = 1        # 5
r = p + q    # 6
```

| После строки | u | r |
|---|---|---|
| 3 | "abcd" | — |
| 6 | "abcd" | 5 |

Текстовое значение в таблице записывают в кавычках, число — без них.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.
Если ответ — текст, пиши его **в кавычках**, например `"ab"`. Число пиши без кавычек.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Отличать текст в кавычках от числа.
- Знать, что `+` склеивает текст и складывает числа.

## Проверка понимания

Объясни, чем `"1" + "1"` отличается от `1 + 1`. Что получится в каждом случае?
