# Копия значения и обмен через temp

## Строка q = p копирует значение

Строка `q = p` берёт то значение, которое у `p` **сейчас**, и записывает его в `q`.
После этого `p` и `q` — два независимых имени. Это как две записки с одним и тем же числом:
если исправить одну, вторая не изменится. Постоянной связи между ними нет.

```python
p = 7    # 1
q = p    # 2
p = 1    # 3
```

| После строки | p | q |
|---|---|---|
| 1 | 7 | — |
| 2 | 7 | 7 |
| 3 | 1 | 7 |

## Переменная сама не пересчитывается

Строка `s = a + b` считается **один раз**, в тот момент, когда до неё дошла программа. Если потом `a` или `b` изменятся, `s` **не пересчитается**.
Чтобы получить новую сумму, нужно ещё раз написать `s = a + b`.

```python
a = 2        # 1
b = 5        # 2
s = a + b    # 3
a = 10       # 4
```

| После строки | a | b | s |
|---|---|---|---|
| 3 | 2 | 5 | 7 |
| 4 | 10 | 5 | 7 |

## Обмен значений: нужна третья переменная

Две строки «скопировать туда, скопировать обратно» значения местами **не** меняют: старое значение стирается безвозвратно.

```python
p = 5    # 1
q = 9    # 2
p = q    # 3   теперь и p, и q равны 9: пятёрка потеряна
```

Поэтому берут **временную** переменную `t` — «карман», чтобы сохранить то, что иначе будет стёрто:

```python
u = 5    # 1
v = 9    # 2
t = u    # 3   запомнили старое u
u = v    # 4   теперь u можно перезаписать
v = t    # 5   достаём запомненное
```

| После строки | u | v | t |
|---|---|---|---|
| 2 | 5 | 9 | — |
| 3 | 5 | 9 | 5 |
| 4 | 9 | 9 | 5 |
| 5 | 9 | 5 | 5 |

## Частые ошибки

Обмен без запоминания:

```python
u = v    # неверно: старое u уже потеряно
v = u    # в v попадёт то же самое значение
```

```python
t = u    # верно: сначала сохранить
u = v
v = t
```

## Проверь себя

1. Что будет в `a` и `b` после `a = 3`, `b = a`, `a = 10`?
2. После `x = 1`, `y = 2`, `t = x`, `x = y`, `y = t` чему равны `x` и `y`?

<details><summary>Ответ</summary>

1. `b = a` скопировало 3. Потом изменилось только `a`. Ответ: `a = 10`, `b = 3`.
2. Это обмен через `t`: `x = 2`, `y = 1` (а `t = 1`).

</details>
