# Задача V02: Правая часть считается первой

## Условие

### Как это работает

В строке `n = n + 1` одно и то же имя стоит и слева, и справа. Это не уравнение, а команда из двух шагов:

1. Сначала считается **правая часть** — с тем значением, которое у переменной **сейчас** (старым).
2. Потом результат записывается под имя слева, и старое значение стирается.

```python
n = 4        # 1
n = n * 2    # 2
n = n - 3    # 3
```

| После строки | n |
|---|---|
| 1 | 4 |
| 2 | 8 |
| 3 | 5 |

Строка 2: берём старое `n` = 4, считаем `4 * 2` = 8, записываем 8.
Строка 3: берём уже новое `n` = 8, считаем `8 - 3` = 5, записываем 5.

## Учебные цели

- Понимать, что в `x = x + 2` сначала считается правая часть по старому значению.
- Видеть, что каждая следующая строка работает с результатом предыдущей.
