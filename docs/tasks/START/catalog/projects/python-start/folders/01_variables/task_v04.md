# Задача V04: Копия значения, а не связь

## Условие

### Как это работает

Строка `q = p` берёт то значение, которое у `p` **сейчас**, и записывает его в `q`.
После этого `p` и `q` — два независимых имени. Это как две записки, на которых написано одно и то же число:
если потом исправить одну записку, вторая не изменится. Никакой постоянной связи между ними нет.

```python
p = 7    # 1
q = p    # 2
p = 1    # 3
```

| После строки | p | q |
|---|---|---|
| 1 | 7 | — |
| 2 | 7 | 7 |
| 3 | 1 | 7 |

На строке 3 изменилось только `p`. Значение `q` осталось таким, каким его скопировали на строке 2.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать, что `b = a` копирует текущее значение, а не связывает имена.
- Видеть, что изменение одной переменной не меняет другую.

## Проверка понимания

Объясни, почему после `b = a` и последующего изменения `a` значение `b` не поменялось. Что стало бы с `b`, если бы имена были связаны навсегда?
