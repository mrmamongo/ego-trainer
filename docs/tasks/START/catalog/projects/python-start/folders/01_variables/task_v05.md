# Задача V05: Переменная сама не пересчитывается

## Условие

### Как это работает

Строка `s = a + b` считается **один раз**, в тот момент, когда до неё дошла программа.
Результат записывается в `s`. Если потом `a` или `b` изменятся, `s` **сам не пересчитается**:
чтобы получить новую сумму, нужно ещё раз написать строку с `s = a + b`.

```python
a = 2        # 1
b = 5        # 2
s = a + b    # 3
a = 10       # 4
```

| После строки | a | b | s |
|---|---|---|---|
| 1 | 2 | — | — |
| 2 | 2 | 5 | — |
| 3 | 2 | 5 | 7 |
| 4 | 10 | 5 | 7 |

На строке 4 изменилось `a`, но `s` так и осталось 7: пересчёта не было.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать, что результат вычисления записывается один раз и сам не обновляется.
- Уметь отличать «значение изменилось» от «значение нужно пересчитать строкой».

## Проверка понимания

Объясни, почему после изменения `count` значение `total` осталось прежним. Какую строку нужно добавить, чтобы `total` обновился?
