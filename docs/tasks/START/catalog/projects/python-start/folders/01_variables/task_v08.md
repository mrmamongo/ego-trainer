# Задача V08: Обмен, который теряет значение

## Условие

### Как это работает

Когда в переменную записывают новое значение, старое **стирается безвозвратно**.
Поэтому две строки подряд вида «скопировать туда, скопировать обратно» не меняют значения местами.

```python
p = 5    # 1
q = 9    # 2
p = q    # 3
```

| После строки | p | q |
|---|---|---|
| 1 | 5 | — |
| 2 | 5 | 9 |
| 3 | 9 | 9 |

После строки 3 число 5 пропало: его больше нет ни в `p`, ни в `q`. Вернуть его уже нечем.
Любая следующая строка может опираться только на то, что сейчас лежит в переменных.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать, что присваивание стирает старое значение без возможности вернуть.
- Видеть, почему «наивный» обмен двух переменных не работает.

## Проверка понимания

Объясни, почему после `a = b` и `b = a` обе переменные оказались одинаковыми. Откуда должно было взяться прежнее значение `a`?
