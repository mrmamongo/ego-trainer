# Задача V03: Копим сумму по шагам

## Условие

### Как это работает

Переменная может **копить** результат: на каждом шаге берём то, что уже накоплено, и добавляем новое.

```python
s = 0        # 1
s = s + 2    # 2
s = s + 7    # 3
```

| После строки | s |
|---|---|
| 1 | 0 |
| 2 | 2 |
| 3 | 9 |

Начинаем с `0`, потому что это «пустая копилка»: ноль ничего не меняет при сложении.
Без начальной строки прибавлять было бы не к чему — копилки ещё нет.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать переменную как копилку, которая накапливает результат.
- Знать, зачем накопитель сначала приравнивают к 0.

## Проверка понимания

Объясни, зачем в начале нужна строка `total = 0`. Что будет в копилке, если сначала положить в неё 10, а потом прибавить 3 и 4?
