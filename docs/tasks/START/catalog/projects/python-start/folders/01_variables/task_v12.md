# Задача V12: Нельзя взять то, чего ещё нет

## Условие

### Как это работает

Использовать переменную можно только **после** того, как ей что-то присвоили.
Если программа дошла до строки, где нужна ещё не созданная переменная, она **останавливается с ошибкой** `NameError`
(«имя не определено»). Строки ниже этой не выполняются вообще.

```python
a = 6        # 1
b = 2        # 2
c = a + d    # 3
d = 1        # 4
```

На строке 3 нужна переменная `d`, но её создаёт только строка 4 — а до неё дело не дошло.
Программа останавливается на **строке 3** с ошибкой про имя `d`. Переменная `c` так и не появится.

| Что произошло | Значение |
|---|---|
| Строка, где остановилась программа | 3 |
| Имя, которого не оказалось | `d` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.
В этой задаче ответы другие: номер строки, на которой программа остановится с ошибкой (число),
и имя переменной, которой не оказалось (текст **в кавычках**).

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Знать, что переменная должна быть создана до использования.
- Понимать, что при `NameError` программа останавливается на этой строке.

## Проверка понимания

Объясни, почему нельзя поменять местами смысл «сначала использую, потом создаю». Что изменится, если строку с присваиванием `z` поставить выше?
