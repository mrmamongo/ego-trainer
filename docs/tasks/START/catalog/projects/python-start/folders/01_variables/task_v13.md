# Задача V13: Итоговая трассировка

## Условие

### Как это работает

Новых правил здесь нет — нужно собрать всё вместе. Порядок действий всегда один:

1. Иди по строкам сверху вниз, по одной.
2. В присваивании сначала считай правую часть по **текущим** значениям, потом записывай результат.
3. У `if` проверь условие по текущим значениям: верно — выполни блок, неверно — пропусти.
4. После каждой строки обновляй таблицу: меняется только та переменная, которой присвоили.

```python
n = 10        # 1
k = 3         # 2
n = n + k     # 3
k = k * 2     # 4
if n > 12:    # 5
    n = n - 5 # 6
```

| После строки | n | k |
|---|---|---|
| 1 | 10 | — |
| 2 | 10 | 3 |
| 3 | 13 | 3 |
| 4 | 13 | 6 |
| 6 | 8 | 6 |

Условие `13 > 12` верно, поэтому строка 6 выполнилась.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.
Это итоговая задача папки: ведите таблицу по всем переменным.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Собрать вместе все приёмы трассировки: присваивание, накопление, ветвление.
- Уметь самостоятельно вести таблицу значений для нескольких переменных.

## Проверка понимания

Объясни, почему `total` в конце не равен просто сумме всех `price`. Какая строка изменила его последней?
