# Задача V11: Ветвление меняет переменную

## Условие

### Как это работает

Блок под `if` может изменить переменную — но только если условие верно **в тот момент**, когда программа до него дошла.
Условие проверяется с текущими значениями, а не с теми, что были раньше.

Знаки: `>` — «больше», `<` — «меньше».

```python
n = 3             # 1
if n > 5:         # 2
    n = 0         # 3
n = n + 4         # 4
if n > 5:         # 5
    n = 100       # 6
```

| После строки | n | Комментарий |
|---|---|---|
| 1 | 3 | |
| 3 | 3 | условие `3 > 5` неверно, строка 3 пропущена |
| 4 | 7 | |
| 6 | 100 | условие `7 > 5` верно, строка 6 выполнена |

Два одинаковых `if` подряд могут сработать по-разному: между ними значение уже изменилось.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.
Ответ `bonus_after_4_block` — значение `bonus` после блока под первым `if` (строки 3–4). Если блок не выполнялся, значение осталось прежним.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Проверять условие по текущему значению переменной, а не по прошлому.
- Уметь определить, выполнился ли блок `if`, и как он изменил переменную.

## Проверка понимания

Объясни, почему первый `if` не сработал, а второй сработал, хотя условие в них одинаковое. Что изменилось между ними?
