# Переменная должна появиться раньше, чем её используют

Использовать переменную можно только **после** того, как ей что-то присвоили.
Если программа дошла до строки, где нужна ещё не созданная переменная, она **останавливается с ошибкой** `NameError` («имя не определено»).
Строки ниже этой не выполняются вообще.

## Пример

```python
a = 6        # 1
b = 2        # 2
c = a + d    # 3
d = 1        # 4
```

На строке 3 нужна переменная `d`, но её создаёт только строка 4 — а до неё дело не дошло.
Программа останавливается на **строке 3** с ошибкой про имя `d`. Переменная `c` так и не появится, строка 4 не выполнится.

| Что произошло | Значение |
|---|---|
| Строка, где остановилась программа | 3 |
| Имя, которого не оказалось | `d` |

## Как искать такую ошибку

Идя по строкам сверху вниз, для каждого имени справа от `=` спрашивай: «а оно уже было записано выше?».
Если нет — это и есть место остановки. Всё, что записано выше, остаётся в таблице; всё, что ниже, не существует.

## Частые ошибки

Использовать накопитель до его создания и опечатки в именах:

```python
total = total + 5   # неверно: total ещё нет
```

```python
total = 0           # верно: сначала создать
total = total + 5
```

Ещё причина `NameError` — опечатка: записали `count`, а ниже используют `cout`.

## Проверь себя

1. На какой строке остановится программа: `x = 1`, `y = x + z`, `z = 5`?
2. Что будет в `m` после `m = 3`, `k = m + 1`, `m = k + 1`?

<details><summary>Ответ</summary>

1. На строке 2: `z` ещё не создана (её создаёт строка 3). Имя, которого нет, — `z`.
2. Ошибки нет: `m = 3`, `k = 4`, затем `m = 4 + 1 = 5`. Ответ: `m = 5`.

</details>
