# Задача V01: Что делает знак =

## Условие

### Как это работает

Переменная — это имя, под которым программа помнит **одно** значение.

Строка `x = 5` — это не «x равно 5», а **команда**: «запиши 5 под именем `x`».
Программа выполняет строки **сверху вниз, по одной**.

Если под именем уже что-то записано, новое присваивание **стирает старое**.
В каждый момент у переменной ровно одно значение.

Следить за этим удобно таблицей: строка кода → значения переменных **после** неё.

```python
x = 5    # 1
y = 3    # 2
x = 8    # 3
```

| После строки | x | y |
|---|---|---|
| 1 | 5 | — |
| 2 | 5 | 3 |
| 3 | 8 | 3 |

«—» значит, что переменной ещё нет. На строке 3 значение `x` заменилось, а `y` не изменился.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать `=` как команду записи, а не как равенство.
- Знать, что строки выполняются по порядку, а новое присваивание стирает старое значение.
- Уметь вести таблицу трассировки.

## Проверка понимания

Объясни, почему после строки 3 у `y` осталось прежнее значение, а у `x` нет.
Предскажи значения для своего примера из трёх строк.
