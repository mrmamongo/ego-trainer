# Задача V10: Присваивание внутри ветвления

## Условие

### Как это работает

Строка `if условие:` проверяет условие **в тот момент, когда до неё дошла программа**.
Если условие верно, выполняются строки с отступом под ним. Если нет, они пропускаются,
а выполняется блок под `else:`. Всегда выполняется **только один** из двух блоков.

Знак `>=` значит «больше или равно».

```python
age = 20                    # 1
if age >= 18:               # 2
    status = "взрослый"     # 3
else:                       # 4
    status = "ребёнок"      # 5
age = 10                    # 6
```

| После строки | age | status |
|---|---|---|
| 1 | 20 | — |
| 3 | 20 | "взрослый" |
| 6 | 10 | "взрослый" |

Условие `20 >= 18` верно, поэтому выполнилась строка 3, а строка 5 была пропущена.
Когда на строке 6 `age` изменилось, `status` не пересчитался: проверка уже прошла.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.
Если ответ — текст, пиши его **в кавычках**, например `"взрослый"`.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать, что из двух веток `if`/`else` выполняется только одна.
- Знать, что результат ветвления не пересчитывается при изменении данных позже.
