# Присваивание внутри if и else

Строка `if условие:` проверяет условие **в тот момент, когда до неё дошла программа**.
Если условие верно, выполняются строки с отступом под ним. Если нет, они **пропускаются**, и выполняется блок под `else:`.
Всегда выполняется **только один** из двух блоков.

Знаки сравнения: `>` — «больше», `<` — «меньше», `>=` — «больше или равно».

## Пример с else

```python
age = 20                    # 1
if age >= 18:               # 2
    status = "взрослый"     # 3
else:                       # 4
    status = "ребёнок"      # 5
age = 10                    # 6
```

| После строки | age | status |
|---|---|---|
| 1 | 20 | — |
| 3 | 20 | "взрослый" |
| 6 | 10 | "взрослый" |

Условие `20 >= 18` верно, поэтому выполнилась строка 3, а строка 5 пропущена.
Когда на строке 6 `age` изменилось, `status` не пересчитался: проверка уже прошла.

## Пример: if без else

Блок под `if` может изменить переменную, но только если условие верно **сейчас**.
Если условие неверно, переменная остаётся с тем значением, которое было до `if`.

```python
n = 3             # 1
if n > 5:         # 2
    n = 0         # 3
n = n + 4         # 4
if n > 5:         # 5
    n = 100       # 6
```

| После строки | n | Комментарий |
|---|---|---|
| 1 | 3 | |
| 3 | 3 | условие `3 > 5` неверно, строка 3 пропущена |
| 4 | 7 | |
| 6 | 100 | условие `7 > 5` верно, строка 6 выполнена |

Два одинаковых `if` подряд могут сработать по-разному: между ними значение уже изменилось.

## Частые ошибки

Считать, что выполнятся обе ветки, или что условие «запомнится» и потом пересчитается само:

```python
age = 20
if age >= 18:
    status = "взрослый"
else:
    status = "ребёнок"   # не выполнится: age >= 18 верно
```

Правильно: сначала проверь условие с текущим значением, выбери **одну** ветку, остальные строки вычеркни из трассировки.

## Проверь себя

1. Что будет в `x` после этого кода?

   ```python
   x = 4
   if x > 10:
       x = 0
   x = x + 1
   ```

2. Что будет в `word` после этого кода?

   ```python
   n = 7
   if n >= 5:
       word = "много"
   else:
       word = "мало"
   ```

<details><summary>Ответ</summary>

1. Условие `4 > 10` неверно, `x = 0` пропущено. Потом `x = 4 + 1`. Ответ: `x = 5`.
2. Условие `7 >= 5` верно, выполняется верхний блок. Ответ: `word = "много"`.

</details>
