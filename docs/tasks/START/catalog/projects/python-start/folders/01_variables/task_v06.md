# Задача V06: Порядок строк важен

## Условие

### Как это работает

Одни и те же строки в **другом порядке** могут дать другой результат, потому что каждая строка работает с тем, что осталось после предыдущей.

```python
n = 4        # 1       m = 4        # 1
n = n + 1    # 2       m = m * 2    # 2
n = n * 2    # 3       m = m + 1    # 3
```

| После строки | n | m |
|---|---|---|
| 1 | 4 | 4 |
| 2 | 5 | 8 |
| 3 | 10 | 9 |

В левом столбце сначала прибавили 1, потом умножили на 2: получилось 10.
В правом сначала умножили, потом прибавили: получилось 9.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` значение переменной после указанной строки.
В файле два отдельных кусочка кода: **A** и **B**. Номер строки пишется с буквой кусочка:
`A2` — вторая строка кусочка A, `B3` — третья строка кусочка B.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def ...` и `return ...` не трогай: это рамка для проверки. Что это такое, разберём в следующей папке.

## Учебные цели

- Понимать, что результат зависит от порядка строк.
- Уметь вести две независимые трассировки подряд.

## Проверка понимания

Объясни, почему `x = x + 3`, а затем `x = x * 10` даёт не то же самое, что в обратном порядке. Проверь это на числе 1.
