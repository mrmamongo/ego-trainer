# n = n + 1: правая часть считается первой

В строке `n = n + 1` одно и то же имя стоит и слева, и справа. Это **не уравнение** (такого числа не бывает), а команда из двух шагов:

1. Сначала считается **правая часть** — с тем значением, которое у переменной **сейчас** (старым).
2. Потом результат записывается под имя слева, и старое значение стирается.

## Пример

```python
n = 4        # 1
n = n * 2    # 2
n = n - 3    # 3
```

| После строки | n |
|---|---|
| 1 | 4 |
| 2 | 8 |
| 3 | 5 |

- Строка 2: берём старое `n` = 4, считаем `4 * 2` = 8, записываем 8.
- Строка 3: берём уже новое `n` = 8, считаем `8 - 3` = 5, записываем 5.

## Накопление по шагам

Так переменная может **копить** результат: на каждом шаге берём то, что уже накоплено, и добавляем новое.

```python
s = 0        # 1
s = s + 2    # 2
s = s + 7    # 3
```

| После строки | s |
|---|---|
| 1 | 0 |
| 2 | 2 |
| 3 | 9 |

Начинаем с `0`, потому что это «пустая копилка»: ноль ничего не меняет при сложении.
Без начальной строки прибавлять было бы не к чему — копилки ещё нет.

## Частые ошибки

Забыть начальную строку:

```python
s = s + 2    # неверно: s ещё не создана, программа остановится с ошибкой
```

```python
s = 0        # верно: сначала копилка
s = s + 2
```

## Проверь себя

1. Что будет в `k` после `k = 5`, `k = k + k`, `k = k - 1`?
2. Что будет в `total` после `total = 0`, `total = total + 4`, `total = total + 4`, `total = total + 1`?

<details><summary>Ответ</summary>

1. После строки 1 `k = 5`; строка 2: `5 + 5 = 10`; строка 3: `10 - 1 = 9`. Ответ: `9`.
2. 0, потом 4, потом 8, потом 9. Ответ: `9`.

</details>
