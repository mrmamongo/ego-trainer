# Задача S18: Что вернут методы

## Условие

### Как это работает

Методы строк **возвращают** результат, а исходную строку не меняют. Ответ метода записывают в новую переменную и дальше работают уже с ней.

```python
raw = "  a  b "
clean = raw.strip()          # "a  b"       (пробелы по краям убраны)
parts = clean.split()        # ["a", "b"]   (список слов)
"-".join(parts)              # "a-b"
clean.find("b")              # 3            (индекс первого "b"; нет такого — -1)
clean.endswith("b")          # True
```

Индексы в `"a  b"`: `a0`, пробел1, пробел2, `b3`. `len(parts)` — число слов в списке, здесь `2`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `clean_final` и `joined_final` — строки в кавычках, `n_parts_final`, `pos_final`, `missing_final` — числа, `ends_final` — `True` или `False`.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_s18_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.
- Текст пиши в кавычках, число без кавычек.

## Учебные цели

- Следить за тем, какие значения возвращают `strip`, `split`, `join`, `find`, `endswith`.
- Помнить, что `find` отвечает индексом или `-1`, а не `True`/`False`.
