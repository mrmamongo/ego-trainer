# Задача S03: Гласные в тексте

## Условие

### Как это работает

Счётчик по символам строится так же, как по числам: заводим `count = 0` до цикла и прибавляем единицу на подходящих проходах. Подходящий символ — гласный. Проверить, что символ входит в набор, можно через `in`:

```python
def count_a_or_o(text):
    count = 0
    for ch in text:
        if ch in "ао":
            count += 1
    return count
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count += 1` — только если символ подошёл | после цикла |

Заглавная `"А"` и маленькая `"а"` — разные символы. Чтобы не перечислять оба варианта, цикл идёт по `text.lower()`: это та же строка, но все буквы в ней маленькие.

Для пустой строки тело не выполнится, ответ останется `0`.

### Задание

Напиши функцию `task_s03_count_vowels(text)`: верни, сколько в тексте гласных букв. Гласные: русские `а е ё и о у ы э ю я` и английские `a e i o u`, в любом регистре.

## Аргументы

- `text` — строка (может быть пустой, может содержать пробелы, цифры и знаки).

## Возвращает

Целое число — количество гласных; для пустой строки или текста без гласных — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Считай циклом `for` по символам; метод `count` не используй.

## Пример

```python
task_s03_count_vowels("Привет")        # -> 2  (и, е)
task_s03_count_vowels("Hello World")   # -> 3  (e, o, o)
task_s03_count_vowels("rhythm")        # -> 0
```

## Учебные цели

- Применять роль «счётчик» к символам строки.
- Использовать `in` и `lower()` для проверки без учёта регистра.
