# Задача S07: Слово с заглавной

## Условие

### Как это работает

Метод `upper()` делает буквы большими, `lower()` — маленькими. Они возвращают **новую** строку: исходная не меняется.

```python
"кОт".upper()    # "КОТ"
"кОт".lower()    # "кот"
```

Чтобы поменять регистр только у части символов, строку собирают заново. В цикле по номерам решение принимает условие «это первый символ или нет»:

```python
def first_big_rest_same(text):
    result = ""
    for i in range(len(text)):
        if i == 0:
            result += text[i].upper()
        else:
            result += text[i]
    return result
```

Здесь остальные символы остаются как были, а в твоей задаче их нужно ещё и привести к маленьким.

### Задание

Напиши функцию `task_s07_capitalize_first(text)`: верни строку, где первая буква заглавная, а все остальные — маленькие.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Новая строка в виде «Слово»; для `""` — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Методы `capitalize()` и `title()` не используй; строй результат сам, символ за символом.

## Пример

```python
task_s07_capitalize_first("привет")        # -> "Привет"
task_s07_capitalize_first("ПРИВЕТ")        # -> "Привет"
task_s07_capitalize_first("hELLO wORLD")   # -> "Hello world"
task_s07_capitalize_first("")              # -> ""
```

## Учебные цели

- Пересобирать строку, меняя символы по номеру.
- Использовать `upper()` и `lower()` как методы, возвращающие новую строку.

## Проверка понимания
