# Задача S15: Лишние пробелы

## Условие

### Как это работает

Метод `strip()` убирает пробелы по краям, но не внутри. А `split()` уже разрезает текст на слова без пустых кусков. Если эти слова склеить обратно через `" ".join(...)`, получится текст ровно с одним пробелом между словами:

```python
"  a   b  ".split()              # ["a", "b"]
" ".join(["a", "b"])             # "a b"
" ".join("  a   b  ".split())    # "a b"
```

`join` вызывают у **разделителя**: строка до точки — то, что вставится между элементами.

Для текста без слов `split()` вернёт `[]`, а `" ".join([])` даёт `""`.

### Задание

Напиши функцию `task_s15_normalize_spaces(text)`: верни текст, где нет пробелов по краям, а между словами ровно один пробел.

## Аргументы

- `text` — строка (может быть пустой или из одних пробелов).

## Возвращает

Строка с одиночными пробелами между словами; для текста без слов — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `split()` и `join()`; `replace` не нужен.

## Пример

```python
task_s15_normalize_spaces("  hello   world ")   # -> "hello world"
task_s15_normalize_spaces("a  b  c")            # -> "a b c"
task_s15_normalize_spaces("   ")                # -> ""
```

## Учебные цели

- Склеивать список слов методом `join`.
- Понимать, что `split()` и `join` дополняют друг друга.
