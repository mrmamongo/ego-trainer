# Задача S20: Строка чека

## Условие

### Как это работает

В скобках f-строки можно писать не только имя, но и вычисление, и формат:

```python
def item_line(name, qty, price):
    return f"{name}: {qty} шт. по {price}"
```

Для `("Чай", 2, 35.5)` получится `"Чай: 2 шт. по 35.5"`. Формат `:.2f` ставят прямо после выражения:

```python
f"{qty * price:.2f}"      # 2 * 35.5 = 71.0  ->  "71.00"
```

Текст вне скобок, например буква `x` перед `{qty}`, остаётся в строке как есть.

### Задание

Напиши функцию `task_s20_receipt_line(name, qty, price)`: верни строку чека в виде `"<название> x<количество> = <стоимость>"`, где стоимость — количество, умноженное на цену, с двумя знаками после точки.

## Аргументы

- `name` — название товара (строка).
- `qty` — количество, целое число от 0.
- `price` — цена за штуку, число.

## Возвращает

Строка вида `"Хлеб x2 = 91.00"`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй одну f-строку; склеивать через `+` и вызывать `round` не нужно.

## Пример

```python
task_s20_receipt_line("Хлеб", 2, 45.5)   # -> "Хлеб x2 = 91.00"
task_s20_receipt_line("Чай", 1, 120)     # -> "Чай x1 = 120.00"
task_s20_receipt_line("Яблоко", 0, 30)   # -> "Яблоко x0 = 0.00"
```

## Учебные цели

- Использовать выражения внутри f-строки.
- Совмещать подстановку и формат `:.2f` в одной строке.

## Проверка понимания
