# f-строки: подставляем значения в текст

Склеивать текст и числа через `+` неудобно: числа надо переводить в строки.

```python
name = "Хлеб"
price = 45
line = name + ": " + str(price) + " ₽"      # "Хлеб: 45 ₽"
```

**f-строка** делает то же проще. Перед открывающей кавычкой ставят букву `f`, а всё, что нужно подставить, пишут в фигурных скобках:

```python
line = f"{name}: {price} ₽"                  # "Хлеб: 45 ₽"
```

Внутри скобок может быть любое выражение, не только имя:

```python
qty = 3
f"Итого: {qty * price} ₽"                    # "Итого: 135 ₽"
f"В слове {len(name)} буквы"                 # "В слове 4 буквы"
```

Переводить в `str` самому не нужно.

## Формат числа: {x:.2f}

После двоеточия можно задать вид числа. `:.2f` значит «дробное число с двумя знаками после точки», с округлением:

```python
x = 5
f"{x:.2f}"          # "5.00"
f"{12.5:.2f}"       # "12.50"
f"{3.14159:.2f}"    # "3.14"
f"{0:.2f}"          # "0.00"
```

Целое число тоже можно вывести так: Python сам сделает из `5` дробное `5.00`. Это удобно для денег: всегда ровно две цифры после точки.

## Пример: пошагово

```python
def price_line(name, qty, price):
    return f"{name} x{qty} = {qty * price:.2f}"
```

Для `("Чай", 2, 35.5)`:

| Часть | Значение |
|---|---|
| `{name}` | `Чай` |
| `x{qty}` | `x2` (буква `x` обычный текст, `{qty}` подставляется) |
| `{qty * price:.2f}` | `2 * 35.5 = 71.0`, формат даёт `71.00` |

Итог: `"Чай x2 = 71.00"`.

## Частые ошибки

Забыть букву `f`: тогда фигурные скобки останутся в тексте как есть.

```python
x = 5
"{x:.2f}"        # неверно: получится сама строка "{x:.2f}"
f"{x:.2f}"       # верно: "5.00"
```

Написать `:.2` вместо `:.2f`: без `f` это совсем другой формат. Для двух знаков после точки нужно именно `.2f`.

Поставить пробел внутри формата, например `{x: .2f}`: лишний пробел попадёт в результат.

## Проверь себя

```python
n = 4
p = 2.5
a = f"{n} шт."
b = f"{n * p:.2f}"
```

1. Чему равны `a` и `b`?
2. Как записать `"Цена: 7.00 ₽"` для `price = 7`?

<details><summary>Ответ</summary>

1. `a = "4 шт."`, `b = "10.00"` (4 · 2.5 = 10.0).
2. `f"Цена: {price:.2f} ₽"`.

</details>
