# Задача S21: Каждое слово с заглавной

## Условие

### Как это работает

Чтобы сделать заглавной первую букву каждого слова, режем текст на слова, обрабатываем каждое и склеиваем обратно. Сборщиком здесь служит **список**, потому что в конце его склеивает `join`:

```python
def first_big(text):
    result = []
    for word in text.split():
        result.append(word[:1].upper() + word[1:])
    return " ".join(result)
```

Срез `word[:1]` — первая буква, `word[1:]` — остальное. Остальное нужно ещё привести к маленьким буквам методом `lower()`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(...)` — обработанное слово | после цикла, через `" ".join(result)` |

Для текста без слов цикл не выполнится: `" ".join([])` даст `""`.

### Задание

Напиши функцию `task_s21_title_case(text)`: верни текст, где каждое слово начинается с заглавной буквы, а остальные буквы слова маленькие.

## Аргументы

- `text` — слова, разделённые ровно одним пробелом, без пробелов по краям (может быть пустой строкой).

## Возвращает

Строка того же вида; для `""` — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Методы `title()` и `capitalize()` не используй; собери слова сам.

## Пример

```python
task_s21_title_case("hello world")   # -> "Hello World"
task_s21_title_case("мОй дОм")       # -> "Мой Дом"
task_s21_title_case("")              # -> ""
```

## Учебные цели

- Объединять `split`, срезы, `upper`/`lower` и `join`.
- Использовать список как сборщик, который затем склеивают в строку.
