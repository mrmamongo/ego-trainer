# Строки не меняются: их пересобирают

В списке можно заменить элемент: `numbers[0] = 99`. Со строкой так **нельзя**.

```python
name = "кот"
name[0] = "т"        # TypeError: 'str' object does not support item assignment
```

Строка **неизменяема**: готовые символы остаются как есть. Хочешь другую строку — строишь новую.

## Как «заменить» символ: собрать заново

Сборщик строки уже знаком по прошлому уроку. Идём по номерам и для нужного места кладём другой символ:

```python
def hide_first(text):
    result = ""                         # 1
    for i in range(len(text)):          # 2
        if i == 0:                      # 3
            result += "*"               # 4
        else:                           # 5
            result += text[i]           # 6
    return result
```

Для `text = "кот"`:

| i | `text[i]` | `i == 0`? | result после прохода |
|---|---|---|---|
| 0 | `"к"` | да | `"*"` |
| 1 | `"о"` | нет | `"*о"` |
| 2 | `"т"` | нет | `"*от"` |

Исходная строка `text` осталась `"кот"`: мы её не меняли, а построили другую.

Для пустой строки цикл не выполнится, и вернётся `""`: ошибки нет, потому что мы нигде не обращаемся к `text[0]` напрямую.

## Методы тоже возвращают новую строку

`text.upper()` не меняет `text`, а **возвращает** строку большими буквами. Если результат не сохранить, он потеряется.

```python
word = "кот"
word.upper()              # результат нигде не сохранён, word по-прежнему "кот"
word = word.upper()       # теперь word равно "КОТ"
```

Так что запись `text[0] = text[0].upper()` ломается дважды: присваивать символу нельзя, а `upper()` ещё и вернёт новое значение, а не изменит старое.

## Частые ошибки

```python
def upper_first(text):
    text[0] = text[0].upper()    # неверно: TypeError
    return text
```

```python
def upper_first(text):
    result = ""
    for i in range(len(text)):
        if i == 0:
            result += text[i].upper()
        else:
            result += text[i]
    return result                # верно: построили новую строку
```

Ещё одна: вызвать `name.upper()` и вернуть `name`, ожидая, что она изменилась. Верно: `return name.upper()` или `name = name.upper()`.

## Проверь себя

```python
s = "abc"
s.upper()
t = s.upper()
```

1. Чему равны `s` и `t` после этих строк?
2. Что случится при `s[1] = "x"`?

<details><summary>Ответ</summary>

1. `s = "abc"` (первая строка ничего не сохранила), `t = "ABC"`.
2. `TypeError`: у строки нельзя присвоить символ по индексу.

</details>
