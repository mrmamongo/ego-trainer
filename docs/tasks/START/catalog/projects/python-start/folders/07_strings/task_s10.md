# Задача S10: Палиндром

## Условие

### Как это работает

**Палиндром** читается одинаково слева направо и справа налево: `"level"`. Проверить это можно сравнением строки с её развёрнутой копией:

```python
def simple_palindrome(text):
    return text == text[::-1]
```

Но для фраз вроде `"Race car"` мешают пробелы и регистр: `"Race car"` развернётся в `"rac ecaR"`. Поэтому сначала строят «чистую» копию сборщиком: без пробелов и с маленькими буквами. Потом сравнивают её с развёрнутой.

```python
clean = ""
for ch in text:
    if ch != " ":
        clean += ch.lower()
```

Для `"Ab a"` получится `clean = "aba"`, и `"aba" == "aba"[::-1]` даёт `True`.

### Задание

Напиши функцию `task_s10_is_palindrome(text)`: верни `True`, если текст — палиндром без учёта регистра и пробелов, иначе `False`.

## Аргументы

- `text` — строка из букв и пробелов (может быть пустой).

## Возвращает

`True` или `False`. Пустая строка и строка из одного символа — палиндромы.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `replace`: «чистую» копию собери циклом.
- Для разворота используй срез `[::-1]`.

## Пример

```python
task_s10_is_palindrome("level")               # -> True
task_s10_is_palindrome("Race car")            # -> True
task_s10_is_palindrome("hello")               # -> False
```

## Учебные цели

- Сочетать сборщик «чистой» строки и срез `[::-1]`.
- Игнорировать регистр через `lower()` и пробелы через условие.
