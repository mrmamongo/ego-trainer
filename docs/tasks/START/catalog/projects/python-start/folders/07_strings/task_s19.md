# Задача S19: Цена с рублём

## Условие

### Как это работает

В f-строке выражение в фигурных скобках подставляется в текст. После двоеточия задают формат: `:.2f` значит «число с двумя знаками после точки» (с округлением).

```python
price = 12.5
f"{price:.2f} руб."       # "12.50 руб."
f"{3:.2f} шт."            # "3.00 шт."
```

Буква `f` перед кавычкой обязательна: без неё скобки остаются в тексте как есть. Всё вне скобок (пробел, знак `₽`) попадает в результат без изменений.

### Задание

Напиши функцию `task_s19_format_price(amount)`: верни строку с суммой в формате «число с двумя знаками после точки, пробел, знак рубля».

## Аргументы

- `amount` — число (целое или дробное, не отрицательное).

## Возвращает

Строка вида `"12.50 ₽"`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй f-строку и формат `:.2f`; `round` и `str` не нужны.

## Пример

```python
task_s19_format_price(5)         # -> "5.00 ₽"
task_s19_format_price(12.5)      # -> "12.50 ₽"
task_s19_format_price(1234.567)  # -> "1234.57 ₽"
```

## Учебные цели

- Подставлять значение в f-строку.
- Форматировать число с двумя знаками после точки.

## Проверка понимания
