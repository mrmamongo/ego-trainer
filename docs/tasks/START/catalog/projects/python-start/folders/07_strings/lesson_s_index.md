# Строка как список символов: индексы

Строка похожа на список, только состоит из **символов**: букв, цифр, пробелов, знаков. Каждый символ стоит на своём месте, и у места есть номер — **индекс**. Нумерация идёт **с нуля**.

```python
word = "python"
```

| символ | p | y | t | h | o | n |
|---|---|---|---|---|---|---|
| индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| индекс с конца | -6 | -5 | -4 | -3 | -2 | -1 |

Чтобы достать символ, пишут `строка[индекс]`. Результат — снова строка, но из одного символа.

```python
word[0]     # "p"  — первый символ
word[3]     # "h"
word[-1]    # "n"  — последний символ
word[-2]    # "o"  — предпоследний
```

## Длина и последний символ

`len(word)` — число символов, здесь `6`. Последний индекс всегда на единицу меньше длины: `len(word) - 1`. Запись `word[-1]` делает то же самое короче.

```python
word = "кот"             # 1
first = word[0]          # 2
last = word[-1]          # 3
n = len(word)            # 4
mid = word[n - 2]        # 5
```

| после строки | first | last | n | mid |
|---|---|---|---|---|
| 2 | `"к"` | | | |
| 3 | `"к"` | `"т"` | | |
| 4 | `"к"` | `"т"` | 3 | |
| 5 | `"к"` | `"т"` | 3 | `"о"` |

В строке 5 индекс равен `3 - 2 = 1`, а `word[1]` — это `"о"`.

## Индекс по номеру в цикле

Когда нужен и символ, и его номер, берут уже знакомую связку `range(len(...))` (как в уроке про `reversed`):

```python
for i in range(len(word)):
    print(i, word[i])     # 0 p, 1 y, 2 t, ...
```

## IndexError: такого места нет

Если взять индекс за пределами строки, Python остановит программу ошибкой `IndexError: string index out of range`.

```python
"кот"[3]      # ошибка: допустимы 0, 1, 2 и -1, -2, -3
""[0]         # ошибка: в пустой строке нет ни одного символа
```

## Частые ошибки

Считать с единицы или брать `len` как последний индекс:

```python
word = "кот"
word[len(word)]          # неверно: индекса 3 нет, будет IndexError
```

```python
word[len(word) - 1]      # верно: "т"
word[-1]                 # то же самое, короче
```

Забыть, что пустая строка не имеет первого символа: `text[0]` для `""` падает. Сначала проверь `if text != "":` или `len(text) > 0`.

## Проверь себя

```python
s = "школа"
a = s[1]
b = s[-2]
c = s[len(s) - 1]
```

1. Чему равны `a`, `b`, `c`?
2. Что случится при `s[5]`?

<details><summary>Ответ</summary>

1. `a = "к"` (индекс 1), `b = "л"` (второй с конца), `c = "а"` (последний).
2. В строке 5 символов, индексы `0..4`, поэтому `s[5]` даст `IndexError`.

</details>
