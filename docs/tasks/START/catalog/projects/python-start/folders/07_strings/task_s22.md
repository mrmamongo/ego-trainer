# Задача S22: Буквы, цифры и остальное

## Условие

### Как это работает

Иногда за один проход нужно посчитать сразу несколько вещей: у каждой свой счётчик. Эти счётчики заводят **все до цикла**, а в теле `if/elif/else` решает, какому из них прибавить:

```python
def count_spaces_and_rest(text):
    spaces = 0
    rest = 0
    for ch in text:
        if ch == " ":
            spaces += 1
        else:
            rest += 1
    return [spaces, rest]
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла, каждый отдельно | `0` | `+= 1` в своей ветке `if/elif/else` | после цикла, одним списком |

Каждый символ попадает ровно в одну ветку, поэтому сумма счётчиков равна `len(text)`. Ответ несколько значений собирают в список: `return [spaces, rest]`.

### Задание

Напиши функцию `task_s22_count_char_types(text)`: верни список из трёх чисел `[буквы, цифры, прочее]`. «Прочее» — всё остальное: пробелы, знаки.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Список из трёх целых чисел в порядке `[буквы, цифры, прочее]`; для `""` — `[0, 0, 0]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Считай одним проходом по тексту, тремя счётчиками.
- Методы `count` и функцию `sum` не используй.

## Пример

```python
task_s22_count_char_types("abc123!")     # -> [3, 3, 1]
task_s22_count_char_types("Привет, мир") # -> [9, 0, 2]
task_s22_count_char_types("")            # -> [0, 0, 0]
```

## Учебные цели

- Вести несколько счётчиков в одном цикле.
- Использовать `isalpha()` и `isdigit()` с ветками `elif` и `else`.

## Проверка понимания

Чему равна сумма трёх чисел в ответе и почему? В какую ветку попадёт пробел?
