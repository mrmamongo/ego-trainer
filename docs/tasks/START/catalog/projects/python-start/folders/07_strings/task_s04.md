# Задача S04: Есть ли цифра

## Условие

### Как это работает

Флаг отвечает на вопрос «встретилось ли хоть раз?». Заводим `found = False`, а когда нашли подходящий символ, ставим `found = True`. Проверить, что символ — цифра, можно методом `isdigit()`:

```python
def has_space(text):
    found = False
    for ch in text:
        if ch == " ":
            found = True
    return found
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `False` | `found = True` — когда нашли | после цикла |

`"7".isdigit()` равно `True`, `"a".isdigit()` равно `False`. Для пустой строки искать негде, поэтому ответ `False`.

### Задание

Напиши функцию `task_s04_has_digit(text)`: верни `True`, если в строке есть хотя бы одна цифра, иначе `False`.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

`True` или `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Проверяй символы циклом и `isdigit()`; проверку целой строки одним вызовом не используй.

## Пример

```python
task_s04_has_digit("abc1")    # -> True
task_s04_has_digit("hello")   # -> False
task_s04_has_digit("")        # -> False
```

## Учебные цели

- Применять роль «флаг» к символам строки.
- Использовать `isdigit()` для одного символа.

## Проверка понимания
