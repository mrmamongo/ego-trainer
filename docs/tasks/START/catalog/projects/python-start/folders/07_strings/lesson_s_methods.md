# Методы строк

**Метод** — это действие, которое вызывают через точку: `строка.метод(...)`. У строк их много. Главное правило: метод **не меняет** исходную строку, а **возвращает новую** (или ответ). Результат нужно сохранить или сразу использовать.

```python
text = "  Привет, Мир  "
```

| Метод | Что делает | Пример результата |
|---|---|---|
| `lower()` | все буквы маленькие | `"ЕГЭ".lower()` даёт `"егэ"` |
| `upper()` | все буквы большие | `"кот".upper()` даёт `"КОТ"` |
| `strip()` | убирает пробелы по краям | `text.strip()` даёт `"Привет, Мир"` |
| `replace(a, b)` | заменяет каждое `a` на `b` | `"a-b-c".replace("-", "+")` даёт `"a+b+c"` |
| `split()` | режет по пробелам на **список** слов | `"раз  два три".split()` даёт `["раз", "два", "три"]` |
| `join(список)` | склеивает список строк через разделитель | `"-".join(["a", "b", "c"])` даёт `"a-b-c"` |
| `startswith(p)` / `endswith(p)` | начинается / заканчивается на `p`: `True` или `False` | `"report.txt".endswith(".txt")` даёт `True` |
| `find(p)` | индекс первого вхождения или `-1` | `"banana".find("an")` даёт `1`, `"banana".find("x")` даёт `-1` |
| `count(p)` | сколько раз `p` встречается | `"banana".count("a")` даёт `3` |
| `isdigit()` | все символы — цифры | `"2024".isdigit()` даёт `True` |
| `isalpha()` | все символы — буквы | `"abc1".isalpha()` даёт `False` |

## Пример: пошагово

```python
raw = "  red green  blue "        # 1
clean = raw.strip()               # 2
parts = clean.split()             # 3
joined = "-".join(parts)          # 4
```

| После строки | Значение |
|---|---|
| 2 | `clean = "red green  blue"` (пробелы по краям убраны, внутри остались) |
| 3 | `parts = ["red", "green", "blue"]` (лишние пробелы между словами исчезли) |
| 4 | `joined = "red-green-blue"` |

`split()` без аргументов делит по любым пробелам и выбрасывает пустые куски. Для пустой строки он вернёт пустой список `[]`.

`join` вызывают у **разделителя**, а не у списка: `"-".join(parts)`. Склеить можно только строки; числа сначала переводят через `str(...)`.

## Методы и циклы дружат

Метод можно вызвать у символа в цикле, у слова после `split()` и вообще у любой строки:

```python
for word in text.split():
    print(word[0])            # первая буква каждого слова
```

## Частые ошибки

Забыть сохранить результат:

```python
text = "  кот "
text.strip()                  # неверно: результат потерян, text не изменился
text = text.strip()           # верно
```

Принять `find` за «есть/нет»: он возвращает **индекс**, а не `True`. Если нужно только «есть ли», пиши `"an" in word` или проверяй `word.find("an") != -1`. Заметь: найденный индекс может быть `0`, а `0` в условии ведёт себя как «ложь».

Вызывать `join` у списка: `["a", "b"].join("-")` — ошибка, правильно `"-".join(["a", "b"])`.

## Проверь себя

```python
s = " a,b ,c "
t = s.strip()
n = t.count(",")
i = t.find("b")
```

1. Чему равны `t`, `n`, `i`?
2. Что вернёт `"-".join("кот".split())`?

<details><summary>Ответ</summary>

1. `t = "a,b ,c"`, `n = 2`, `i = 2` (индексы: `a0 ,1 b2 пробел3 ,4 c5`).
2. `"кот".split()` даёт `["кот"]`, склеивать нечего — получится `"кот"`.

</details>
