# Задача S12: Сколько слов

## Условие

### Как это работает

`split()` без аргументов делит строку по пробелам и возвращает **список слов**. Несколько пробелов подряд и пробелы по краям он игнорирует, пустых слов не создаёт:

```python
"раз  два   три ".split()     # ["раз", "два", "три"]
"   ".split()                 # []
```

Число слов — это длина списка: `len(text.split())`. Считать пробелы не надо: при нескольких пробелах подряд их количество не совпадает с числом слов.

### Задание

Напиши функцию `task_s12_count_words(text)`: верни, сколько слов в тексте. Слова разделены одним или несколькими пробелами.

## Аргументы

- `text` — строка (может быть пустой или состоять из одних пробелов).

## Возвращает

Целое число — количество слов.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `split()`; считать пробелы не нужно.

## Пример

```python
task_s12_count_words("раз два три")      # -> 3
task_s12_count_words("  раз   два  ")    # -> 2
task_s12_count_words("")                 # -> 0
```

## Учебные цели

- Применять `split()` и `len()` вместе.
- Помнить, что `split()` сам убирает лишние пробелы.

## Проверка понимания

Чему равно число слов в строке из одних пробелов? Почему нельзя просто посчитать пробелы и прибавить единицу?
