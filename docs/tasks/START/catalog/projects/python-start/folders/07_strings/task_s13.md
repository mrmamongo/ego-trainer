# Задача S13: Самое длинное слово

## Условие

### Как это работает

Роль «лучший» хранит самый подходящий элемент из просмотренных. Здесь «лучше» — длиннее. Слова получаем через `split()`, длину слова даёт `len(word)`.

```python
def first_longer_than_three(text):
    best = ""
    for word in text.split():
        if len(word) > len(best):
            best = word
    return best
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `""` — слов ещё нет | `best = word` — если слово **строго длиннее** | после цикла |

Начальное значение `""` подходит потому, что любое слово длиннее пустой строки, а для текста без слов ответ и должен быть `""`.

Условие `>` (строго больше) оставляет **первое** из слов равной длины: следующее такое же длинное уже не «лучше».

### Задание

Напиши функцию `task_s13_longest_word(text)`: верни самое длинное слово. Если таких несколько, верни то, что встретилось первым.

## Аргументы

- `text` — строка из слов, разделённых пробелами (может быть пустой).

## Возвращает

Самое длинное слово; для текста без слов — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `max`, `sorted` и ключи сортировки; ищи слово циклом.

## Пример

```python
task_s13_longest_word("кот пёс слон")      # -> "слон"
task_s13_longest_word("аа бб вв")          # -> "аа"
task_s13_longest_word("")                  # -> ""
```

## Учебные цели

- Применять роль «лучший» к словам строки.
- Выбирать между `>` и `>=` ради правила «первое из равных».

## Проверка понимания

Что изменится для `"аа бб вв"`, если заменить `>` на `>=`? Что вернёт функция для строки из одних пробелов?
