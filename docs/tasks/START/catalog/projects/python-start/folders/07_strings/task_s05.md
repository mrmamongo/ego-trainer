# Задача S05: Только буквы

## Условие

### Как это работает

Сборщик строки начинается с пустой строки `""`, а на подходящих проходах к нему дописывают символ:

```python
def no_spaces(text):
    result = ""
    for ch in text:
        if ch != " ":
            result += ch
    return result
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `""` | `result += ch` — только если символ подошёл | после цикла |

Метод `isalpha()` отвечает, является ли символ буквой: `"я".isalpha()` и `"z".isalpha()` дают `True`, а `"5".isalpha()` и `"!".isalpha()` — `False`.

Исходная строка не меняется: функция строит и возвращает новую.

### Задание

Напиши функцию `task_s05_only_letters(text)`: верни новую строку, в которой остались только буквы из `text` в исходном порядке. Цифры, пробелы и знаки выбрасываются.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Строка из букв исходной строки; если букв нет — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Собирай результат циклом: сборщик начинается с `""`, символы дописываются через `+=`.

## Пример

```python
task_s05_only_letters("a1b2-c")           # -> "abc"
task_s05_only_letters("Hello, World!")    # -> "HelloWorld"
task_s05_only_letters("123")              # -> ""
```

## Учебные цели

- Собирать новую строку циклом: `result = ""` и `result += ch`.
- Фильтровать символы методом `isalpha()`.
