# Задача S09: Строка наоборот

## Условие

### Как это работает

Срез с шагом `-1` идёт по строке с конца к началу:

```python
"abc"[::-1]       # "cba"
"кот"[::-1]       # "ток"
""[::-1]          # ""
```

Пустые границы значат «весь диапазон», а шаг `-1` — «назад». Исходная строка не меняется, срез возвращает новую.

```python
def reverse_demo(text):
    return text[::-1]
```

### Задание

Напиши функцию `task_s09_reverse_text(text)`: верни строку, записанную в обратном порядке.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Новая строка: символы `text` в обратном порядке.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Реши срезом `[::-1]`; `reversed` и цикл не нужны.

## Пример

```python
task_s09_reverse_text("abc")      # -> "cba"
task_s09_reverse_text("ab cd")    # -> "dc ba"
task_s09_reverse_text("")         # -> ""
```

## Учебные цели

- Применять срез с отрицательным шагом.
- Помнить, что срез возвращает новую строку и не ломается на пустой.

## Проверка понимания

Что вернёт `task_s09_reverse_text("а")`? Изменится ли исходная переменная, которую передали в функцию?
