# Срезы строк

**Срез** — это кусок строки. Записывается `s[a:b]`: от индекса `a` **до** индекса `b`, сам `b` не входит. Это то же правило, что у `range(a, b)`.

```python
s = "python"           # индексы: p0 y1 t2 h3 o4 n5
```

| Запись | Результат | Что значит |
|---|---|---|
| `s[1:4]` | `"yth"` | индексы 1, 2, 3 |
| `s[:2]` | `"py"` | с начала до индекса 2 (не включая) |
| `s[3:]` | `"hon"` | с индекса 3 до конца |
| `s[-2:]` | `"on"` | два последних символа |
| `s[:-1]` | `"pytho"` | всё, кроме последнего |
| `s[:]` | `"python"` | копия всей строки |

Если границу не писать, подставляется начало или конец.

## Шаг

Третье число — шаг, как в `range`: `s[a:b:шаг]`.

```python
s[::2]        # "pto"    — каждый второй символ
s[::-1]       # "nohtyp" — шаг -1: строка задом наперёд
```

`s[::-1]` — самый короткий способ развернуть строку.

## Срез не ломается на границах

В отличие от индекса, срез за пределами строки ошибку **не даёт**:

```python
"abc"[1:100]     # "bc"
""[:1]           # ""
"abc"[5:]        # ""
```

Поэтому срезы удобны там, где строка может оказаться пустой или короткой.

## Пересобрать строку срезами

Срезы часто заменяют цикл-сборщик. «Первая буква заглавная, остальное как было»:

```python
text = "кот"
text[:1].upper() + text[1:]        # "К" + "от" = "Кот"
```

Мы взяли `text[:1]`, а не `text[0]`: для `""` первый вернёт `""`, а второй упадёт с ошибкой.

## Частые ошибки

Думать, что конец включается:

```python
"python"[1:3]       # "yt", а не "yth": индекс 3 не входит
```

Путать `s[0:-1]` и `s[0:]`: первый отбрасывает последний символ, второй берёт всё.

Пытаться записать в срез: `s[1:3] = "xx"` — так же нельзя, как `s[1] = "x"`. Строку собирают заново: `s[:1] + "xx" + s[3:]`.

## Проверь себя

Пусть `s = "программа"` (индексы `п0 р1 о2 г3 р4 а5 м6 м7 а8`).

1. Чему равны `s[:3]`, `s[3:6]`, `s[-3:]`?
2. Что вернёт `s[::-1]`?

<details><summary>Ответ</summary>

1. `"про"`, `"гра"`, `"мма"`.
2. `"аммаргорп"`.

</details>
