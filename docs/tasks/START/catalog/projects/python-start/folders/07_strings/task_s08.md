# Задача S08: Что вырежет срез

## Условие

### Как это работает

Срез `s[a:b]` берёт символы с индекса `a` **до** индекса `b`, но `b` не входит (как в `range`). Если границу не писать, берётся начало или конец. Третье число — шаг: `s[::2]` берёт каждый второй, `s[::-1]` идёт с конца.

```python
s = "python"      # p0 y1 t2 h3 o4 n5
s[1:4]            # "yth"
s[:2]             # "py"
s[3:]             # "hon"
s[-2:]            # "on"
s[::2]            # "pto"
s[::-1]           # "nohtyp"
```

Результат среза — всегда строка (пусть даже пустая), поэтому ответ пишется в кавычках.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a_final` .. `f_final` — результаты срезов (строки в кавычках).

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_s08_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.
- Текст пиши в кавычках, число без кавычек.

## Учебные цели

- Читать границы среза: начало входит, конец нет.
- Узнавать срезы с пропущенной границей, отрицательным индексом и шагом.

## Проверка понимания
