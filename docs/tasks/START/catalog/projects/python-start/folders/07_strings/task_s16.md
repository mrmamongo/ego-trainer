# Задача S16: Заменить без replace

## Условие

### Как это работает

Встроенный `text.replace(old, new)` заменяет каждое вхождение `old` на `new`. Посмотрим, как это сделать самому: идём по тексту слева направо и ведём **номер позиции** `i`. На каждом шаге смотрим на кусок текста длиной `len(old)`, который начинается в позиции `i`:

- если кусок равен `old`, приписываем в результат `new` и перескакиваем **через весь найденный кусок** (`i += len(old)`);
- иначе приписываем один символ `text[i]` и сдвигаемся на единицу.

```python
def replace_dash(text):
    result = ""
    i = 0
    while i < len(text):
        if text[i:i + 1] == "-":
            result += "+"
        else:
            result += text[i]
        i += 1
    return result
```

Тут `old` из одного символа. Для длинного `old` срез берут так: `text[i:i + len(old)]`. Он не ломается у конца строки: там просто получится кусок короче, и равенство с `old` не сработает.

Совпадения не перекрываются: после замены мы пропускаем найденное целиком. Поэтому из `"aaa"` при замене `"aa"` на `"b"` получится `"ba"`: первые два символа заменились, а третий остался.

### Задание

Напиши функцию `task_s16_replace_all(text, old, new)`: верни строку, в которой каждое вхождение `old` заменено на `new` (слева направо, без перекрытий). Когда решишь, сравни результат со встроенным `text.replace(old, new)` на своих примерах: ответы должны совпасть.

## Аргументы

- `text` — строка (может быть пустой).
- `old` — непустая строка, которую ищем.
- `new` — строка-замена (может быть пустой).

## Возвращает

Новая строка после замены; если `old` в тексте нет — копия `text`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Метод `replace` не используй. Не используй также `split` и `join`.
- Решай циклом `while` (или `for` по номерам) и срезами; `find` разрешён, но не обязателен.

## Пример

```python
task_s16_replace_all("banana", "an", "AN")   # -> "bANANa"
task_s16_replace_all("aaa", "aa", "b")       # -> "ba"
task_s16_replace_all("hello", "z", "y")      # -> "hello"
task_s16_replace_all("a-b-c", "-", "")       # -> "abc"
```

## Учебные цели

- Сравнивать кусок строки (срез) с образцом и перескакивать через найденное.
- Собирать результат из символов и замен, не меняя исходную строку.

## Проверка понимания

Почему после совпадения `i` увеличивают на `len(old)`, а не на 1? Что вернёт функция для `("abab", "ab", "x")` и совпадает ли это с `"abab".replace("ab", "x")`?
