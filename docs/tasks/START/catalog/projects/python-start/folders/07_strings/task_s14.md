# Задача S14: Маска номера карты

## Условие

### Как это работает

Строку можно собрать из частей: `"*" * 3` даёт `"***"`, а срез `s[-4:]` даёт последние четыре символа. Склеим их через `+`:

```python
number = "12345678"
"*" * (len(number) - 4) + number[-4:]     # "****" + "5678" = "****5678"
```

Число звёздочек равно `len(number) - 4`. Если оно получится `0` или меньше, `"*" * 0` и `"*" * (-2)` дают пустую строку, а срез `number[-4:]` у короткой строки возвращает всё, что есть.

### Задание

Напиши функцию `task_s14_mask_card(number)`: верни номер карты, где все символы, кроме последних четырёх, заменены на `*`. Если в номере четыре символа или меньше, верни его без изменений.

## Аргументы

- `number` — строка из цифр (обычно 16 цифр, может быть короче и даже пустой).

## Возвращает

Строка той же длины, что `number`: звёздочки и последние четыре символа.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `replace`; собери результат из `"*" * n` и среза.

## Пример

```python
task_s14_mask_card("1234567812345678")   # -> "************5678"
task_s14_mask_card("12345")              # -> "*2345"
task_s14_mask_card("123")                # -> "123"
```

## Учебные цели

- Комбинировать умножение строки и срез с конца.
- Видеть, что срез и `"*" * n` не ломаются на коротких строках.

## Проверка понимания

Сколько звёздочек в ответе для 16-значного номера? Почему для `"123"` не нужна отдельная проверка длины?
