# Задача S01: Индексы: с начала и с конца

## Условие

### Как это работает

Символ строки достают по номеру: `word[0]` — первый, `word[1]` — второй и так далее. Отрицательный номер считает **с конца**: `word[-1]` — последний, `word[-2]` — предпоследний. Номер можно вычислить: `word[len(word) - 1]` — тоже последний.

```python
word = "кот"
word[0]     # "к"
word[-1]    # "т"
word[2 - 1] # "о"  (индекс 1)
len(word)   # 3
```

| символ | к | о | т |
|---|---|---|---|
| индекс | 0 | 1 | 2 |
| с конца | -3 | -2 | -1 |

Результат `word[i]` — это строка из одного символа, поэтому ответ пишется **в кавычках**.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a_final`, `b_final`, `c_final`, `d_final` и `e_final` — символы (текстом, в кавычках), `n_final` — длина слова (числом).

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_s01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.
- Текст пиши в кавычках, число без кавычек.

## Учебные цели

- Находить символ строки по индексу, в том числе отрицательному.
- Помнить, что нумерация идёт с нуля и последний индекс равен `len(word) - 1`.
