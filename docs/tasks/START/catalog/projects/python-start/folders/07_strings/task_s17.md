# Задача S17: Сжатие повторов

## Условие

### Как это работает

Нужно заменить серии одинаковых символов на «символ + длина серии»: `"aaabcc"` превратится в `"a3b1c2"`. Для этого держат **текущий символ** `current` и **счётчик** `count` его серии. Идём со второго символа (по номерам) и сравниваем с `current`:

- такой же — `count += 1`;
- другой — серия закончилась: дописываем `current + str(count)` в результат и начинаем новую серию.

```python
result = ""
current = text[0]
count = 1
for i in range(1, len(text)):
    if text[i] == current:
        count += 1
    else:
        result += current + str(count)
        current = text[i]
        count = 1
result += current + str(count)       # последняя серия никем не «закрыта»
```

Последнюю серию дописывают **после цикла**: её никто не прервал. Число переводят в текст через `str(...)`, иначе `+` не склеит строку с числом.

Пустую строку нужно обработать отдельно: у `""` нет `text[0]`.

### Задание

Напиши функцию `task_s17_compress(text)`: замени каждую серию одинаковых подряд идущих символов на символ и длину серии. Для пустой строки верни `""`.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Сжатая строка. Одиночный символ тоже получает длину `1`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Решай циклом; готовые средства для подсчёта серий не используй.

## Пример

```python
task_s17_compress("aaabccdd")   # -> "a3b1c2d2"
task_s17_compress("abc")        # -> "a1b1c1"
task_s17_compress("")           # -> ""
```

## Учебные цели

- Вести текущий символ и счётчик серии одновременно.
- Помнить о последней серии после цикла и о пустом входе.
