# Задача S06: Заглавная в начале: ошибка

## Условие

### Как это работает

Символ строки нельзя заменить присваиванием: строки **неизменяемы**.

```python
def hide_first(text):
    text[0] = "*"       # TypeError: 'str' object does not support item assignment
    return text
```

Чтобы получить «другую» строку, надо построить новую: идём по номерам и для нужного места берём другой символ.

```python
def hide_first(text):
    result = ""
    for i in range(len(text)):
        if i == 0:
            result += "*"
        else:
            result += text[i]
    return result
```

Для пустой строки цикл не выполнится, и вернётся `""`.

### Задание

Функция `task_s06_upper_first(text)` должна вернуть строку, где первая буква заглавная, а остальные символы такие же, как были. Сейчас она падает с ошибкой. Найди её и исправь: пересобери строку.

## Аргументы

- `text` — строка (может быть пустой).

## Возвращает

Новая строка с заглавным первым символом; для `""` — `""`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Собери новую строку циклом; срезы, `capitalize()` и `title()` не используй.

## Пример

```python
task_s06_upper_first("привет")   # -> "Привет"
task_s06_upper_first("мИР")      # -> "МИР"
task_s06_upper_first("")         # -> ""
```

## Учебные цели

- Узнавать ошибку «присваивание символу строки».
- Пересобирать строку через сборщик вместо правки на месте.

## Проверка понимания

Что именно упадёт в исходной функции и почему `text[0].upper()` один не изменил бы `text`? Почему для `""` исправленный вариант не падает?
