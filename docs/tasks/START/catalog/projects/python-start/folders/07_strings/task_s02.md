# Задача S02: Строка собирается по символам

## Условие

### Как это работает

Цикл `for ch in "мир"` по очереди выдаёт символы `"м"`, `"и"`, `"р"`. Если строку-накопитель `result` начать с `""`, то на каждом проходе к ней можно что-то приписать **справа** (`result + ch`) или **слева** (`ch + result`).

```python
result = ""
for ch in "ab":
    result = result + ch + ch
```

| Проход | ch | result после тела |
|---|---|---|
| 1 | `"a"` | `"aa"` |
| 2 | `"b"` | `"aabb"` |

Важно, с какой стороны приписываешь: `ch + result` ставит новый символ **в начало**, а `result + ch` — в конец.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `result_pass_1`, `result_pass_2`, `result_pass_3` — значение `result` после **всего** тела цикла (обеих строк) на 1-м, 2-м и 3-м проходе, `n_final` — длина `result` после цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_s02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.
- Текст пиши в кавычках, число без кавычек.

## Учебные цели

- Следить за строкой, которая растёт на каждом проходе.
- Различать приписывание символа справа и слева.

## Проверка понимания

Почему на втором проходе `result` равен `"им.."`, а не `"ми.."`? Чему равнялась бы строка, если бы в первой строке тела было `result + ch`?
