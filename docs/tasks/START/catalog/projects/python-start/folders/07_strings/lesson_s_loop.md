# Цикл по символам и роли переменных

По строке можно ходить циклом `for`, как по списку: переменная цикла по очереди получает каждый **символ**.

```python
for ch in "кот":
    print(ch)          # к, потом о, потом т
```

Имя `ch` (от *character*, «символ») — просто привычка. Для пустой строки `""` тело не выполнится ни разу.

## Три помощника, которые понадобятся сразу

Подробнее о них будет в уроке про методы, а пока достаточно знать три приёма:

- `ch in "аеёиоу"` — `True`, если символ `ch` встречается в строке справа;
- `ch.lower()` — тот же символ, но маленькой буквой (`"А".lower()` даёт `"а"`);
- `ch.isdigit()` — `True`, если символ — цифра.

И короткая запись: `result += ch` означает то же, что `result = result + ch`.

## Роли переменных не изменились

Паспорта те же, меняется только то, что лежит в переменной цикла: теперь это символ.

**Счётчик** (сколько букв «а»):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count += 1` — только если символ подошёл | после цикла |

```python
def count_a(text):
    count = 0
    for ch in text:
        if ch == "а":
            count += 1
    return count
```

**Сборщик новой строки** (все символы, кроме пробелов):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `""` (пустая строка) | `result += ch` — только если символ подошёл | после цикла |

```python
def no_spaces(text):
    result = ""                   # 1
    for ch in text:               # 2
        if ch != " ":             # 3
            result += ch          # 4
    return result
```

Для `text = "a b c"`:

| Проход | ch | `ch != " "`? | result после прохода |
|---|---|---|---|
| 1 | `"a"` | да | `"a"` |
| 2 | `" "` | нет | `"a"` |
| 3 | `"b"` | да | `"ab"` |
| 4 | `" "` | нет | `"ab"` |
| 5 | `"c"` | да | `"abc"` |

Начальное значение — снова ответ для пустого входа: из `""` получится `""`.

**Флаг** («есть ли цифра»):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `False` | `found = True` — когда нашли | после цикла |

```python
def has_digit(text):
    found = False
    for ch in text:
        if ch.isdigit():
            found = True
    return found
```

## Частые ошибки

Заменять вместо добавления:

```python
for ch in text:
    result = ch               # неверно: в result останется один последний символ
```

```python
for ch in text:
    result += ch              # верно: дописываем к тому, что уже накоплено
```

Завести сборщик строки как `[]`: тогда `result += ch` попытается склеить список и строку. Для строки сборщик начинается с `""`.

Поставить `return` внутрь цикла: функция вернёт ответ после первого символа.

## Проверь себя

```python
result = ""
for ch in "abc":
    result = result + ch + ch
```

1. Чему равен `result` после каждого прохода?
2. Что будет, если вместо `"abc"` взять `""`?

<details><summary>Ответ</summary>

1. После 1-го — `"aa"`, после 2-го — `"aabb"`, после 3-го — `"aabbcc"`.
2. Тело не выполнится, останется начальное значение: `""`.

</details>
