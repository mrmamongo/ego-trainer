# Задача S11: Собери инициалы

## Условие

### Как это работает

Метод `split()` режет строку по пробелам и возвращает **список слов**. Первую букву слова даёт `word[0]`, а сборщик строки дописывает её к результату:

```python
"Иван Петров".split()      # ["Иван", "Петров"]
"Иван"[0]                  # "И"
```

```python
def first_letters(text):
    result = ""
    for word in text.split():
        result += word[0]
    return result
```

Для `"Иван Петров"` получится `"ИП"`. Для пустой строки `split()` вернёт `[]`, цикл не выполнится, и ответ `""`.

**Отступы** показывают вложенность: `result += ...` стоит под `for`.

### Задание

В файле задачи в комментарии записаны строки функции `task_s11_initials(full_name)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция должна вернуть инициалы: первые буквы всех слов, каждая с точкой после.

## Аргументы

- `full_name` — строка из слов, разделённых пробелами (пробелов может быть несколько, строка может быть пустой).

## Возвращает

Строка вида `"И.П."`; для пустой строки — `""`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_s11_initials("Иван Петров")        # -> "И.П."
task_s11_initials("Анна Мария Ли")      # -> "А.М.Л."
task_s11_initials("")                   # -> ""
```

## Учебные цели

- Использовать `split()`, чтобы получить слова.
- Собрать шаблон сборщика строки: `""` до цикла, `+=` в теле, `return` после.

## Проверка понимания
