# Задача FD10: Сумма до нуля без минусов

## Условие

### Как это работает

Сейчас функция складывает числа до первого нуля:

```python
def task_fd10_sum_until_zero(nums):     # 1
    total = 0                           # 2
    for n in nums:                      # 3
        if n == 0:                      # 4
            break                       # 5
        total = total + n               # 6
    return total                        # 7
```

**Где реализовано старое правило:** остановка на нуле — строки 4–5. Добавление числа в сумму — строка 6. Эти строки остаются.

**Что меняется:** отрицательные числа теперь не прибавляют, но и цикл они не останавливают: нужно их **пропустить**. Для этого перед строкой 6 нужна новая ветка с `continue` (урок `bk-stop-or-skip`: остановка — `break`, пропуск — `continue`).

Нуль по-прежнему останавливает цикл, даже если после него идут другие числа.

### Задание

Раньше функция возвращала сумму чисел до первого нуля. Теперь отрицательные числа в сумму не входят, но дальше список просматривается:
стоп по-прежнему только на нуле. Измени готовую функцию.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Сумма неотрицательных чисел, которые стоят до первого нуля; если таких нет, то `0`.

## Правила

- Не переписывай функцию с нуля: остановку на нуле оставь как есть.
- Встроенную функцию `sum` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fd10_sum_until_zero([1, 2, 0, 5])     # -> 3 (как раньше)
task_fd10_sum_until_zero([1, -2, 3])       # -> 4
task_fd10_sum_until_zero([4, -1, 0, 9])    # -> 4
```

## Учебные цели

- Добавить в готовый цикл пропуск элементов, не нарушив остановку.
- Различать место для `break` и место для `continue`.

## Проверка понимания
