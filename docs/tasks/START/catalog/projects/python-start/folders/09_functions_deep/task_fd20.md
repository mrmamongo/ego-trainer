# Задача FD20: Сводка по словам

## Условие

### Как это работает

Итоговая функция часто состоит из нескольких помощников. Каждый отвечает за один факт, а главная функция собирает ответ.

```python
def count_long(words):
    count = 0
    for word in words:
        if len(word) > 3:
            count = count + 1
    return count

def first_word(words):
    if len(words) == 0:
        return "-"
    return words[0]

def task_demo(words):
    n = count_long(words)
    w = first_word(words)
    return f"длинных: {n}, первое: {w}"
```

Строка вида `f"... {n} ..."` подставляет значение переменной на место фигурных скобок. Главная функция не считает сама, она вызывает помощников и склеивает результат.

Работай по плану: сначала два помощника, потом главная функция.

### Задание

В файле три функции. Напиши все три.

1. `count_nonempty(words)` возвращает, сколько в списке непустых строк.
2. `longest_word(words)` возвращает самое длинное слово; если несколько равной длины, то первое из них. Если слов нет, верни `""`.
3. `task_fd20_summary(words)` собирает строку `f"{count} слов, самое длинное: {word}"`, где `count` получен из `count_nonempty`, а `word` из `longest_word`.
   Если непустых слов нет, вместо слова подставь `"-"`.

## Аргументы

- `words` — список строк (может быть пустым, строки могут быть пустыми).

## Возвращает

Строка вида `"3 слов, самое длинное: слон"`. Слово «слов» склонять не нужно.

## Правила

- Главная функция должна вызывать `count_nonempty` и `longest_word`.
- Встроенные `max` и `sorted` не используй.
- Имена функций и параметры оставь как есть.

## Пример

```python
task_fd20_summary(["кот", "слон", "мышь"])   # -> "3 слов, самое длинное: слон"
task_fd20_summary(["", "ab", ""])            # -> "1 слов, самое длинное: ab"
task_fd20_summary([])                        # -> "0 слов, самое длинное: -"
```

## Учебные цели

- Собрать итог из двух помощников.
- Обработать случай «слов нет» отдельно, до сборки строки.

## Проверка понимания

Почему из `["кот", "слон", "мышь"]` самым длинным будет `слон`, а не `мышь`? Что нужно изменить, если «пустыми» считать ещё и слова из одних пробелов?
