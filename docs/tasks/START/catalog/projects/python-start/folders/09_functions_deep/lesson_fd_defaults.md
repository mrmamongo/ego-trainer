# Значения по умолчанию и именованные аргументы

У параметра может быть **значение по умолчанию**. Если при вызове аргумент не передали, берётся оно.

```python
def price_with_tax(price, rate=10):          # 1
    return price + price * rate // 100       # 2

a = price_with_tax(200)                      # 3: rate = 10
b = price_with_tax(200, 20)                  # 4: rate = 20
```

| Вызов | price | rate | Результат |
|---|---|---|---|
| `price_with_tax(200)` | 200 | 10 (по умолчанию) | 220 |
| `price_with_tax(200, 20)` | 200 | 20 (передали) | 240 |

Параметры **без** значения по умолчанию ставят первыми, с ним — после них: `def f(a, b=1)` можно, `def f(a=1, b)` нельзя.

Так старый код вызова `price_with_tax(200)` продолжает работать, когда в функцию добавили новый параметр: ему дали значение по умолчанию.

## Именованные аргументы

При вызове аргумент можно назвать: `имя=значение`. Тогда порядок не важен, и можно пропустить параметры с умолчаниями.

```python
price_with_tax(200, rate=50)         # 300
price_with_tax(rate=50, price=100)   # 150
```

## Ловушка: изменяемое значение по умолчанию

Значение по умолчанию вычисляется **один раз**, когда Python читает `def`, а не при каждом вызове. Для числа это незаметно. Для списка — беда: все вызовы получают **один и тот же** список.

```python
def add_item(item, items=[]):     # неверно
    items.append(item)
    return items

first = add_item("яблоко")        # ["яблоко"]
second = add_item("груша")        # ["яблоко", "груша"]  <- старый список!
```

Список `[]` создан один раз и живёт между вызовами (вспомни `li-mutable`: список можно изменить «на месте»).

Правильный приём: по умолчанию ставят `None`, а новый список создают внутри.

```python
def add_item(item, items=None):
    if items is None:
        items = []                # новый список на каждый вызов
    items.append(item)
    return items
```

## Частые ошибки

Передать аргументы в другом порядке, чем в `def`, без имён: `price_with_tax(10, 200)` — это `price=10`, `rate=200`. Называй аргументы, когда их порядок легко перепутать.

## Проверь себя

```python
def total(price, count=1, bonus=0):
    return price * count - bonus
```

1. Что вернёт `total(50)`?
2. Что вернёт `total(50, bonus=5)`?
3. Что вернёт `total(count=2, price=30)`?

<details><summary>Ответ</summary>

1. `50` (count = 1, bonus = 0).
2. `45`: count остался 1, bonus = 5, значит `50 * 1 - 5`.
3. `60`: имена указаны, порядок не важен.

</details>
