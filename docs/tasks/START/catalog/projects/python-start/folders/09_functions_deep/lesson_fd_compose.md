# Функция вызывает функцию

Внутри функции можно вызывать другие функции — так же, как ты вызываешь их снаружи. Большую задачу удобно разбить на маленькие функции, у каждой из которых одно дело.

```python
def is_even(n):                      # 1
    return n % 2 == 0                # 2

def count_even(numbers):             # 3
    count = 0                        # 4
    for n in numbers:                # 5
        if is_even(n):               # 6
            count = count + 1        # 7
    return count                     # 8
```

`count_even` не знает, **как** проверяется чётность: она просто спрашивает `is_even`. Если завтра правило проверки изменится, поправить нужно только `is_even`.

## Как пройти по двум вызовам

Вызов `count_even([3, 4])` проходит так:

| Шаг | Что происходит | Где мы |
|---|---|---|
| 1 | `count = 0` | в `count_even` |
| 2 | `n = 3`, строка 6 вызывает `is_even(3)` | заходим в `is_even` |
| 3 | `3 % 2 == 0` — это `False`, `return` отдаёт `False` | выходим обратно |
| 4 | `if False:` — строка 7 пропущена | в `count_even` |
| 5 | `n = 4`, вызов `is_even(4)` отдаёт `True` | туда и обратно |
| 6 | `count = 1` | в `count_even` |

У каждого вызова **свои** параметры и переменные: `n` в `is_even` и `n` в `count_even` — это две разные «ячейки».

Вызов помощника можно вставить прямо в выражение: `return double(x) + 1` сначала вызывает `double(x)`, потом прибавляет `1`.

## Как разбивать задачу

1. Назови подзадачи словами: «привести слово к нормальному виду», «посчитать слова».
2. Каждой подзадаче дай функцию с понятным именем.
3. Главная функция только вызывает помощников по порядку.

## Частые ошибки

Забыть `return` в помощнике: он вернёт `None`, и вызывающая функция получит `None` вместо значения.

```python
def double(n):
    n * 2                 # неверно: результат посчитан и выброшен
```

```python
def double(n):
    return n * 2          # верно
```

## Проверь себя

```python
def double(n):
    return n * 2

def add_bonus(x):
    return double(x) + 1

result = add_bonus(double(3))
```

1. Чему равно `double(3)`?
2. Что вернёт `add_bonus(6)`?
3. Чему равно `result`?

<details><summary>Ответ</summary>

1. `6`.
2. Внутри `double(6)` даёт `12`, плюс `1` — `13`.
3. Сначала `double(3)` = `6`, потом `add_bonus(6)` = `13`. Значит, `result` равно `13`.

</details>
