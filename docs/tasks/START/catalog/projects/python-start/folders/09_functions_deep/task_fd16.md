# Задача FD16: Применить правило

## Условие

### Как это работает

Когда над каждым элементом нужно сделать одно из нескольких действий, выбор действия выносят в функцию-помощник, а главная функция только обходит список.

```python
def shift(n, mode):
    if mode == "up":
        return n + 1
    if mode == "down":
        return n - 1
    return n                        # неизвестный режим: ничего не меняем

def shift_all(nums, mode):
    result = []
    for n in nums:
        result.append(shift(n, mode))
    return result
```

Главная функция ничего не знает про `"up"` и `"down"`. А `shift` не знает про списки. Каждая отвечает за своё.
Главная функция **строит новый список** и не изменяет тот, что ей передали (урок `fd-pure`).

### Задание

В файле две функции. Напиши обе.

1. `transform(n, rule)` возвращает число `n`, изменённое по правилу: `"double"` — удвоить, `"square"` — возвести в квадрат (`n * n`), `"negate"` — сменить знак.
   Для любого другого правила верни `n` без изменений.
2. `task_fd16_apply(nums, rule)` возвращает **новый** список, в котором к каждому числу применён `transform` с этим правилом. Исходный список менять нельзя.

## Аргументы

- `n` — целое число.
- `rule` — строка: `"double"`, `"square"`, `"negate"` или любая другая.
- `nums` — список целых чисел (может быть пустым).

## Возвращает

`transform` — целое число. `task_fd16_apply` — новый список той же длины.

## Правила

- Выбор правила делай внутри `transform` через `if`; передавать функции как значения не нужно.
- В `task_fd16_apply` вызывай `transform` для каждого числа.
- Исходный список `nums` не изменяй: собирай результат в новом списке.

## Пример

```python
task_fd16_apply([1, 2, 3], "double")     # -> [2, 4, 6]
task_fd16_apply([1, -2, 3], "square")    # -> [1, 4, 9]
task_fd16_apply([1, -2], "negate")       # -> [-1, 2]
task_fd16_apply([5], "unknown")          # -> [5]
```

## Учебные цели

- Разделить работу: обход списка в одной функции, выбор действия в другой.
- Вернуть новый список, не меняя входной.

## Проверка понимания

Что вернёт `transform(0, "negate")`? Что изменится в `task_fd16_apply`, если добавить новое правило `"triple"`?
