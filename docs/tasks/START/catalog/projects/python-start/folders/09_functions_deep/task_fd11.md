# Задача FD11: Не влезло — пропусти

## Условие

### Как это работает

Функция набирает цены в пределах бюджета. Сейчас она останавливается на первой цене, которая не влезла:

```python
def task_fd11_take_within_budget(items, budget):   # 1
    result = []                                    # 2
    spent = 0                                      # 3
    for item in items:                             # 4
        if spent + item > budget:                  # 5
            break                                  # 6
        result.append(item)                        # 7
        spent = spent + item                       # 8
    return result                                  # 9
```

Для `items = [4, 8, 3, 2]` и `budget = 10`: берём 4 (потрачено 4), на 8 выходит 12 — строка 6 обрывает цикл. Ответ `[4]`.

**Где реализовано старое правило:** «остановиться на первом, кто не влез» — это слово `break` на строке 6, под условием на строке 5.

**Что меняется:** это слово. Теперь неподходящую цену нужно **пропустить** и смотреть дальше: `break` заменяем на `continue`. Остальные строки не трогаем. Накопитель `spent` растёт только на строке 8, поэтому после пропуска потрачено столько же, и следующие цены проверяются по прежней сумме.

### Задание

Раньше функция брала цены по порядку и останавливалась на первой, которая не влезает в бюджет. Теперь такую цену нужно пропустить, а остальные
проверять дальше. Измени готовую функцию.

## Аргументы

- `items` — список положительных целых цен в порядке просмотра (может быть пустым).
- `budget` — целый бюджет, не меньше `0`.

## Возвращает

Новый список взятых цен в исходном порядке; сумма взятых не превышает `budget`.

## Правила

- Измени только то, что нужно: не переписывай функцию с нуля.
- Сумма взятых цен может быть равна бюджету, но не больше его.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fd11_take_within_budget([1, 2, 3], 10)       # -> [1, 2, 3] (как раньше)
task_fd11_take_within_budget([4, 8, 3, 2], 10)    # -> [4, 3, 2]
task_fd11_take_within_budget([20, 3], 10)         # -> [3]
```

## Учебные цели

- Заменить остановку пропуском одним словом.
- Видеть, что накопитель после пропуска не меняется.

## Проверка понимания

Что вернёт исходная функция для `[4, 8, 3, 2]` и бюджета `10`? Почему после замены на `continue` число `3` попадает в ответ?
