# Вернуть несколько значений

`return` может отдать сразу несколько значений через запятую. Python упакует их в **кортеж** (tuple) — упорядоченный набор, который нельзя менять «на месте».

```python
def min_max(numbers):
    low = numbers[0]
    high = numbers[0]
    for n in numbers:
        if n < low:
            low = n
        if n > high:
            high = n
    return low, high            # возвращаем пару
```

## Распаковка

Результат можно принять в две переменные сразу: значения раскладываются по порядку.

```python
smallest, biggest = min_max([4, 9, 2, 7])
# smallest = 2, biggest = 9
```

Если записать `result = min_max([4, 9, 2, 7])`, то `result` — это кортеж `(2, 9)`, его части достают по индексу: `result[0]`, `result[1]`.

| Запись | Что получится |
|---|---|
| `return low, high` | кортеж `(2, 9)` |
| `a, b = min_max(...)` | `a = 2`, `b = 9` |
| `r = min_max(...)` | `r = (2, 9)`, `r[1]` равно `9` |

Количество имён слева должно совпасть с количеством значений: иначе будет ошибка.

## Когда это удобно

Когда функция считает несколько связанных вещей за один проход: наименьшее и наибольшее; количество, сумма и среднее. Порядок значений нужно знать наизусть и записать в условии (например, `(count, total, average)`).

Больше про кортежи пока не нужно: достаточно уметь вернуть пару и принять её.

## Частые ошибки

Перепутать порядок при распаковке: `high, low = min_max(...)` даст `high = 2`, `low = 9`. Имена не определяют порядок: он всегда такой, как в `return`.

Вернуть значения по отдельности двумя `return`:

```python
return low
return high        # никогда не выполнится
```

```python
return low, high   # верно
```

## Проверь себя

```python
def split_sum(numbers):
    positive = 0
    negative = 0
    for n in numbers:
        if n > 0:
            positive = positive + n
        else:
            negative = negative + n
    return positive, negative

p, q = split_sum([5, -2, 3, -1])
```

Чему равны `p` и `q`? Что вернёт `split_sum([])`?

<details><summary>Ответ</summary>

`p` равно `8` (5 + 3), `q` равно `-3` ((-2) + (-1)). Для пустого списка вернётся `(0, 0)`: оба накопителя остались на начальных значениях.

</details>
