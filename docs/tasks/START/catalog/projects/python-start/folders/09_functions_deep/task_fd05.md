# Задача FD05: Своя переменная и общая

## Условие

### Как это работает

Параметр и переменные, созданные внутри функции, **локальные**: они живут только во время вызова. Если у параметра то же имя, что у глобальной переменной, то внутри функции виден параметр, а глобальная остаётся нетронутой. А функция, у которой своей переменной с таким именем нет, **читает** глобальную в тот момент, когда её вызвали.

```python
rate = 10                         # 1

def with_tax(price):              # 2
    return price + price * rate // 100   # 3

def with_rate(price, rate):       # 4
    return price + price * rate // 100   # 5

a = with_tax(100)                 # 6: 110
b = with_rate(100, 50)            # 7: 150, внутри rate = 50
rate = 30                         # 8
c = with_tax(100)                 # 9: 130
```

В строке 7 внутри функции `rate` равно `50`, но глобальная `rate` осталась `10`.
В строке 9 `with_tax` читает глобальную `rate`, которая уже стала `30`.

### Задание

Открой файл задачи. Впиши вместо каждого `None` ответ. `a_after_7`, `b_after_8`, `c_after_9` и `d_after_11` — значения
переменных после своих строк, `total_after_9` — значение глобальной переменной `total` после строки 9.

**Сначала реши в голове или на бумаге, код не запускай.** Для каждого вызова реши: `total` здесь — параметр или глобальная?

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fd05_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Различать локальный параметр и глобальную переменную с тем же именем.
- Понимать, что функция без своей переменной читает глобальную в момент вызова.
