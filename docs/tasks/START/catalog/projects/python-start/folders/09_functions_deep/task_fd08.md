# Задача FD08: Оценка с плюсом

## Условие

### Как это работает

Сейчас оценка выставляется цепочкой проверок:

```python
def task_fd08_grade(score):          # 1
    if score >= 85:                  # 2
        return 5                     # 3
    if score >= 70:                  # 4
        return 4                     # 5
    if score >= 50:                  # 6
        return 3                     # 7
    return 2                         # 8
```

**Где реализовано старое правило:** в строках 2–8. Проверки идут сверху вниз, срабатывает первая подходящая, остальные не смотрятся. Для `90` вернётся `5` на строках 2–3.

**Что меняется:** появляется особый случай, ровно `100` баллов. Для него нужна **новая ветка**. Поставь её **первой**, перед строкой 2: число `100` тоже подходит под `score >= 85`, и если новая ветка будет после, она никогда не сработает.

**Что нельзя трогать:** строки 2–8. Для всех остальных баллов ответы остаются прежними.

### Задание

Раньше функция возвращала оценку от 2 до 5. Теперь за ровно 100 баллов ставят оценку `6` («отлично с плюсом»).
Для остальных баллов всё как было: от 85 — `5`, от 70 — `4`, от 50 — `3`, иначе `2`. Измени готовую функцию.

## Аргументы

- `score` — целое число баллов от `0` до `100`.

## Возвращает

Целое число: `6` при `score == 100`, иначе оценка от `2` до `5` по старым правилам.

## Правила

- Не переписывай функцию с нуля: добавь одну новую ветку.
- Старые границы (85, 70, 50) не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fd08_grade(100)   # -> 6
task_fd08_grade(99)    # -> 5
task_fd08_grade(60)    # -> 3
task_fd08_grade(10)    # -> 2
```

## Учебные цели

- Добавить новую ветку в готовую цепочку `if`.
- Понимать, что порядок веток важен: частный случай проверяют раньше общего.

## Проверка понимания
