# Задача FD06: Счётчик, который не сбрасывается

## Условие

### Как это работает

Если функция меняет глобальную переменную (`global count`), то результат зависит от того, сколько раз её вызывали раньше:

```python
count = 0

def count_big(numbers, limit):
    global count
    for n in numbers:
        if n > limit:
            count = count + 1
    return count
```

| Вызов | count до | count после | вернула |
|---|---|---|---|
| `count_big([5, 1, 9], 4)` | 0 | 2 | 2 |
| `count_big([7, 2], 4)` | 2 | 3 | **3**, а должно быть 1 |

Второй вызов продолжил счёт с прошлого. Исправление: счётчик должен быть **локальным** и заводиться внутри функции, до цикла. Тогда каждый вызов начинает с нуля и не зависит от других.

### Задание

Функция `count_big(numbers, limit)` должна вернуть, сколько в списке чисел больше `limit`. Но при втором вызове она прибавляет к результату первого.
Исправь её: убери `global` и глобальную переменную, заведи счётчик внутри функции. Функцию `task_fd06_report(first, second, limit)` не трогай:
она вызывает `count_big` дважды.

## Аргументы

- `first`, `second` — списки целых чисел (могут быть пустыми).
- `limit` — целое число.

## Возвращает

Кортеж из двух чисел: сколько элементов больше `limit` в `first` и в `second`.

## Правила

- Меняй только `count_big` и глобальную переменную `count` над ней.
- `task_fd06_report` не изменяй: по ней идёт проверка.
- `count_big` должна **вернуть** число через `return`.

## Пример

```python
task_fd06_report([5, 1, 9], [7, 2], 4)   # -> (2, 1)
task_fd06_report([], [], 4)              # -> (0, 0)
```

## Учебные цели

- Находить функцию, которая меняет глобальное состояние.
- Превращать глобальный счётчик в локальный и получать чистую функцию.

## Проверка понимания

Что вернёт исходный код для `([5, 1, 9], [7, 2], 4)` и почему во втором числе получилось не 1? Почему теперь не важно, сколько раз вызывали `count_big` раньше?
