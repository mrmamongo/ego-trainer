# Локальные и глобальные переменные

Переменная, созданная **внутри** функции, — **локальная**: она живёт только пока функция работает (параметры тоже локальные). Переменная, созданная **снаружи**, на верхнем уровне файла, — **глобальная**.

## Читать глобальную можно

```python
rate = 10                                # 1: глобальная

def with_tax(price):                     # 2
    return price + price * rate // 100   # 3

with_tax(200)                            # 4: 220
rate = 50                                # 5
with_tax(200)                            # 6: 300
```

Функция при каждом вызове заглядывает в глобальную `rate` **в тот момент**, поэтому на строке 6 результат другой. Это скрытая зависимость: ответ зависит не только от аргументов, но и от переменной, которую кто-то мог изменить.

## Присваивание создаёт локальную

```python
total = 100

def bump():
    total = total + 1           # ошибка: Python считает total локальной
    return total
```

Раз внутри функции есть `total = ...`, Python считает `total` локальной во **всей** функции. В правой части она ещё не получила значения — ошибка `UnboundLocalError`.

Параметр с тем же именем тоже закрывает глобальную:

```python
total = 100

def bump(total):
    total = total + 1
    return total

bump(5)       # 6, а снаружи total по-прежнему 100
```

## global — плохая идея

Чтобы изменить глобальную переменную, пишут `global total`. Это работает, но делает код хрупким:

```python
count = 0

def count_big(numbers, limit):
    global count
    for n in numbers:
        if n > limit:
            count = count + 1
    return count
```

Первый вызов даст верный ответ. Второй продолжит счёт с того места, где остановился первый: `count` не обнуляется. Результат зависит от того, сколько раз функцию вызывали раньше.

Хорошее правило: **всё нужное функции приходит через параметры, всё результатное уходит через `return`**. Накопители заводи внутри.

```python
def count_big(numbers, limit):
    count = 0                   # локальный, свежий на каждый вызов
    for n in numbers:
        if n > limit:
            count = count + 1
    return count
```

## Частые ошибки

Завести глобальный счётчик «чтобы не передавать лишнего». Выигрыш в одну строку обернётся ошибкой, которую трудно найти: функция «иногда» считает неверно.

## Проверь себя

```python
n = 5

def f(x):
    n = x + 1
    return n

a = f(10)
```

Чему равны `a` и `n` после вызова?

<details><summary>Ответ</summary>

`a` равно `11`. Глобальная `n` по-прежнему `5`: внутри функции `n = x + 1` создала новую локальную переменную и глобальную не тронула.

</details>
