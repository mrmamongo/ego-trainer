# Задача FD02: Сколько чётных

## Условие

### Как это работает

Большую работу удобно разделить: одна функция отвечает на маленький вопрос, другая её **использует**.

```python
def is_big(n):
    return n > 100

def count_big(numbers):
    count = 0
    for n in numbers:
        if is_big(n):
            count = count + 1
    return count
```

`count_big` не повторяет проверку `n > 100`, а спрашивает `is_big`. Если правило «большое» изменится, правка будет в одном месте.
`is_big(n)` возвращает `True` или `False`, и это значение прямо ставится в `if`.

Паспорт «счётчик» тот же, что и раньше: `count = 0` до цикла, `count = count + 1` на подходящих проходах, `return` после цикла.

### Задание

В файле две функции. Напиши обе.

1. `is_even(n)` возвращает `True`, если число `n` чётное, и `False`, если нечётное.
2. `task_fd02_count_even(nums)` возвращает, сколько в списке чётных чисел. **Внутри она должна вызывать `is_even`**, а не повторять проверку остатка сама.

## Аргументы

- `n` — целое число (может быть отрицательным или нулём).
- `nums` — список целых чисел (может быть пустым).

## Возвращает

`is_even` — `True` или `False`. `task_fd02_count_even` — целое число: количество чётных элементов; для пустого списка — `0`.

## Правила

- Имена функций и параметры оставь как есть.
- В `task_fd02_count_even` вызывай `is_even(n)` для каждого числа.
- Функции должны **вернуть** значение через `return`, а не печатать его.

## Пример

```python
is_even(4)                      # -> True
is_even(7)                      # -> False
task_fd02_count_even([1, 2, 3, 4])   # -> 2
task_fd02_count_even([])             # -> 0
```

## Учебные цели

- Написать маленькую функцию-помощник и вызвать её из другой функции.
- Использовать значение `True`/`False` прямо в условии `if`.
