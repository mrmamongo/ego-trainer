# Задача FD15: Статистика одним вызовом

## Условие

### Как это работает

Функция может вызывать помощников и вернуть собранные из них значения как кортеж. Так выглядит «сводка»:

```python
def count_items(nums):
    count = 0
    for n in nums:
        count = count + 1
    return count

def first_and_count(nums):
    return nums[0], count_items(nums)
```

`first_and_count([5, 6, 7])` вернёт `(5, 3)`. Порядок значений в кортеже всегда такой, как в `return`.

В файле задачи два готовых помощника: `count_items` считает элементы, `sum_items` их складывает. Оба уже написаны и работают, тебе нужно только их использовать.
Среднее равно сумме, делённой на количество: `total / count` (обычное деление даёт дробное число).

### Задание

Напиши `task_fd15_stats(nums)`: она возвращает кортеж `(количество, сумма, среднее)`. Количество и сумму получай через готовые `count_items` и `sum_items`.
Для пустого списка верни `(0, 0, 0)`.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Кортеж `(count, total, average)`: `count` — сколько элементов, `total` — их сумма, `average` — `total / count`; для пустого списка `(0, 0, 0)`.

## Правила

- Готовые функции `count_items` и `sum_items` не изменяй; вызывай их.
- Встроенные `len` и `sum` не используй.
- На ноль делить нельзя: пустой список обработай отдельно.

## Пример

```python
task_fd15_stats([2, 4, 6])   # -> (3, 12, 4.0)
task_fd15_stats([1, 2])      # -> (2, 3, 1.5)
task_fd15_stats([])          # -> (0, 0, 0)
```

## Учебные цели

- Собрать результат из вызовов нескольких помощников и вернуть его кортежем.
- Обработать пустой список до деления.
