# Чистые функции: вернуть новое, не трогать аргументы

**Чистая функция** делает две вещи: берёт аргументы и возвращает результат. Больше она ничего не меняет: ни глобальные переменные, ни списки, которые ей передали.

Вспомни `li-mutable`: список, переданный в функцию, — это **тот же самый** список, а не копия. Если функция вызовет `append` или присвоит элемент, список изменится и у того, кто её вызвал.

```python
def add_bonus_bad(scores, bonus):          # меняет аргумент
    for i in range(len(scores)):
        scores[i] = scores[i] + bonus
    return scores

marks = [3, 4]
new_marks = add_bonus_bad(marks, 1)
# marks тоже стал [4, 5]: исходные данные испорчены
```

Чистый вариант строит **новый** список:

```python
def add_bonus(scores, bonus):
    result = []
    for score in scores:
        result.append(score + bonus)
    return result

marks = [3, 4]
new_marks = add_bonus(marks, 1)
# marks остался [3, 4], new_marks равен [4, 5]
```

| | `add_bonus_bad` | `add_bonus` |
|---|---|---|
| `marks` после вызова | `[4, 5]` | `[3, 4]` |
| что вернула | тот же список | новый список |
| можно ли вызвать дважды | второй вызов прибавит ещё раз | всегда тот же ответ |

## Вложенные списки

Если внутри списка лежат другие списки (например, пары `["аня", 10]`), то копии одного внешнего списка мало: внутренние пары остались бы общими. Новую пару нужно создавать тоже:

```python
result.append([pair[0], pair[1] + points])   # новая пара
```

## Правило по умолчанию

**Возвращай новое значение — это безопасный выбор.** Менять аргумент «на месте» стоит только когда об этом прямо сказано в условии.

Чистую функцию легко проверять и легко менять: её результат зависит только от аргументов, и ничего «за кадром» не происходит.

## Частые ошибки

Думать, что `result = scores` делает копию. Это второе имя для того же списка:

```python
result = scores        # неверно: тот же список
result.append(0)       # поменяли и scores
```

```python
result = []            # верно: новый список, наполняем сами
for score in scores:
    result.append(score)
```

## Проверь себя

```python
def double_all(numbers):
    for i in range(len(numbers)):
        numbers[i] = numbers[i] * 2
    return numbers

data = [1, 2]
out = double_all(data)
```

1. Чему равен `data` после вызова?
2. Чистая это функция? Как её исправить?

<details><summary>Ответ</summary>

1. `[2, 4]`: функция изменила переданный список.
2. Нет. Нужно завести `result = []`, добавлять в него `n * 2` через `append` и вернуть `result`. Тогда `data` останется `[1, 2]`.

</details>
