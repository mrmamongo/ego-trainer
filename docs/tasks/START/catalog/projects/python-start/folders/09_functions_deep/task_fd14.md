# Задача FD14: Наименьшее и наибольшее

## Условие

### Как это работает

Функция может вернуть сразу два значения: `return a, b`. Python упаковывает их в пару (кортеж), а вызывающий код может сразу распаковать её в две переменные.

```python
def div_mod(a, b):
    return a // b, a % b

q, r = div_mod(17, 5)       # q = 3, r = 2
```

Порядок значений в `return` — это порядок в результате. В этой задаче нужно найти наименьшее и наибольшее число за один проход. Для каждого из них заводят своего «лучшего на данный момент»
(роль `best` из урока `l-best`): `low` и `high`. Начальное значение — первый элемент списка, ведь список непустой.

### Задание

Напиши функцию `task_fd14_min_max(nums)`: она возвращает пару `(наименьшее, наибольшее)`.

## Аргументы

- `nums` — непустой список целых чисел.

## Возвращает

Кортеж из двух чисел: сначала наименьший элемент, потом наибольший. Для списка из одного элемента они совпадают.

## Правила

- Встроенные `min` и `max` не используй.
- Верни пару одним `return`: `return low, high`.
- Меняй только тело функции; имя функции и параметры оставь как есть.

## Пример

```python
task_fd14_min_max([3, 1, 4, 1, 5])   # -> (1, 5)
task_fd14_min_max([7])               # -> (7, 7)
task_fd14_min_max([-2, -9, -4])      # -> (-9, -2)
```

## Учебные цели

- Вернуть из функции два значения кортежем.
- Искать наименьшее и наибольшее за один проход.

## Проверка понимания

Что вернёт функция для `[2, 2]`? Что получится, если распаковать результат как `high, low = task_fd14_min_max([4, 9])`?
