# Задача FD18: Очки без побочных эффектов

## Условие

### Как это работает

Таблица очков хранится как список пар `[имя, очки]`, например `[["аня", 10], ["борис", 5]]`. Мы хотим функцию, которая начисляет очки одному игроку и **возвращает новую таблицу**, а старую не трогает.

```python
def add_bonus(table, name):
    result = []
    for pair in table:
        if pair[0] == name:
            result.append([pair[0], pair[1] + 1])   # новая пара
        else:
            result.append([pair[0], pair[1]])       # тоже новая пара
    return result
```

Пары внутри тоже копируем: если положить в `result` саму `pair`, то и новая, и старая таблицы будут делить её, и изменение в одной появится в другой (урок `fd-pure`, раздел про вложенные списки).

| `table` | вызов | вернёт | `table` после вызова |
|---|---|---|---|
| `[["аня", 10]]` | `add_bonus(table, "аня")` | `[["аня", 11]]` | `[["аня", 10]]` (не изменилась) |

### Задание

Напиши `task_fd18_add_score(scores, name, points)`: верни **новый** список пар, в котором у игрока `name` очки увеличены на `points`, а все остальные пары такие же, как были.
Исходный список и его пары менять нельзя.

## Аргументы

- `scores` — список пар `[имя, очки]`; имена в нём не повторяются (не пустой).
- `name` — имя, которое **есть** в `scores`.
- `points` — целое число очков (может быть отрицательным или нулём).

## Возвращает

Новый список пар в том же порядке. И сам список, и пары в нём — новые объекты.

## Правила

- Не меняй `scores` и пары внутри него: ни `append`, ни присваивание элементам.
- Результат должен состоять из новых списков, не из тех же самых пар.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
scores = [["аня", 10], ["борис", 5]]
task_fd18_add_score(scores, "аня", 3)   # -> [["аня", 13], ["борис", 5]]
# scores остался [["аня", 10], ["борис", 5]]
```

## Учебные цели

- Написать чистую функцию, которая не меняет аргументы.
- Копировать вложенные списки, а не делить их с входом.

## Проверка понимания

Почему недостаточно написать `result = scores`, а потом менять `result`? Что будет, если положить в `result` саму `pair`, а не новую пару?
