# Задача FD01: Две функции по цепочке

## Условие

### Как это работает

Когда одна функция вызывает другую, Python «заходит» во вторую, выполняет её до `return`, а потом возвращается и подставляет результат на то место, где был вызов.

```python
def square(n):
    return n * n

def square_plus_one(x):
    return square(x) + 1

r = square_plus_one(3)
```

| Шаг | Что происходит |
|---|---|
| 1 | вызываем `square_plus_one(3)`, внутри `x = 3` |
| 2 | в выражении `square(x) + 1` сначала вызывается `square(3)`, внутри `n = 3` |
| 3 | `square` отдаёт `9`, выражение превращается в `9 + 1` |
| 4 | `square_plus_one` отдаёт `10`, и `r` получает `10` |

У каждого вызова свои параметры: `n` внутри `square` и `x` внутри `square_plus_one` — разные ячейки.
Если аргумент сам является вызовом, например `f(g(2))`, то сначала считается `g(2)`, потом его результат отправляется в `f`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ. `a_after_5`, `b_after_6` и `c_after_7` — значения переменных после соответствующих строк,
`double_calls_in_line_7` — сколько раз за выполнение строки 7 была вызвана функция `double`.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, проследив по шагам, какая функция в какую заходит.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fd01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Проследить цепочку из двух функций, где одна вызывает другую.
- Понять, что вызов-аргумент считается раньше внешнего вызова.
