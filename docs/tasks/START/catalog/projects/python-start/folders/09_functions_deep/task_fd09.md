# Задача FD09: Номер вместо числа

## Условие

### Как это работает

Сейчас функция находит первое отрицательное число и возвращает его самого:

```python
def task_fd09_first_negative(nums):      # 1
    for n in nums:                       # 2
        if n < 0:                        # 3
            return n                     # 4
    return 0                             # 5
```

**Где реализовано старое правило:** «первое отрицательное» — это условие `n < 0` (строка 3), просмотр слева направо (строка 2) и ранний `return` на первой находке (строка 4). Эти части остаются.

**Что меняется:** то, **что мы возвращаем**: строка 4 (`return n`) и строка 5 (`return 0`). Теперь нужен не само число, а его номер в списке (с нуля), а если отрицательных нет, то `-1`.
Чтобы знать номер, веди цикл по номерам: `for i in range(len(nums))`. Тогда число — это `nums[i]`, а номер — `i`.

Обрати внимание: `0` теперь настоящий номер (первый элемент), поэтому «не нашли» обозначают числом `-1`.

### Задание

Раньше функция возвращала первое отрицательное число из списка или `0`, если отрицательных нет. Теперь она должна возвращать
**номер** (индекс, с нуля) первого отрицательного числа, а если отрицательных нет, то `-1`. Измени готовую функцию.

## Аргументы

- `nums` — список целых чисел (может быть пустым).

## Возвращает

Индекс первого числа меньше нуля; `-1`, если такого числа нет. Ноль отрицательным не считается.

## Правила

- Не переписывай функцию с нуля: условие «первое отрицательное» оставь как есть.
- Нужен именно первый (самый левый) отрицательный элемент.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fd09_first_negative([3, -2, 5])    # -> 1
task_fd09_first_negative([-1, 2])       # -> 0
task_fd09_first_negative([1, 2, 3])     # -> -1
task_fd09_first_negative([])            # -> -1
```

## Учебные цели

- Менять то, что функция возвращает, не трогая правило поиска.
- Выбирать цикл по номерам, когда нужен индекс, и значение «не найдено».

## Проверка понимания
