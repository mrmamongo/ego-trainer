# Задача FD17: Собери конвейер из трёх вызовов

## Условие

### Как это работает

Результат одной функции можно передать следующей. Получается «конвейер»: каждый шаг делает своё и отдаёт результат дальше.

```python
def double(n):
    return n * 2

def add_one(n):
    return n + 1

def show(n):
    return "ответ: " + str(n)

def pipeline(x):
    a = double(x)
    b = add_one(a)
    return show(b)
```

| Шаг | Строка | Значение при `x = 3` |
|---|---|---|
| 1 | `a = double(x)` | `6` |
| 2 | `b = add_one(a)` | `7` |
| 3 | `return show(b)` | `"ответ: 7"` |

Порядок важен: строка использует переменную, которую должна создать строка выше. Если поставить `b = add_one(a)` раньше, чем `a` появилась, будет ошибка `NameError`.

### Задание

В файле задачи в комментарии записаны строки функции `task_fd17_report(text)`, но они перемешаны и без отступов. Собери из них тело функции:
расставь строки в правильном порядке, а строку `return None` удали. Все строки стоят на одном уровне внутри функции.
Функция чистит текст, считает слова и формирует ответ. Помощники `clean`, `count_words` и `label` лежат ниже и уже готовы.

## Аргументы

- `text` — строка, слова разделены пробелами или запятыми (может быть пустой).

## Возвращает

Строка вида `"слов: N"`, где `N` — количество слов в тексте после чистки.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Готовые помощники ниже не изменяй.

## Пример

```python
task_fd17_report("a,b,c")        # -> "слов: 3"
task_fd17_report("привет мир")   # -> "слов: 2"
task_fd17_report("")             # -> "слов: 0"
```

## Учебные цели

- Выстроить вызовы помощников в правильном порядке.
- Передавать результат одного вызова в следующий.
