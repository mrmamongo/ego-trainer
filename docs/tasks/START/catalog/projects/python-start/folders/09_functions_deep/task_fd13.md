# Задача FD13: Слова без повторов

## Условие

### Как это работает

Если в задаче есть повторяющаяся мелкая операция, её выносят в функцию-помощник с понятным именем. Главная функция тогда читается как план.

```python
def shout(word):
    return word.upper() + "!"

def shout_all(words):
    result = []
    for word in words:
        result.append(shout(word))
    return result
```

`shout_all` отвечает за обход списка, а `shout` — за то, что делать с одним словом. Чтобы поменять правило, правят только `shout`.

В этой задаче помощник приводит слово к «нормальному» виду: нижний регистр и без знаков `.`, `,`, `!`, `?` по краям. Метод `strip(".,!?")` убирает перечисленные знаки с обоих концов строки, а `lower()` делает буквы строчными.

### Задание

В файле две функции. Напиши обе.

1. `normalize(word)` возвращает слово строчными буквами без знаков `.`, `,`, `!`, `?` с обоих концов. Например, `"Привет!"` превращается в `"привет"`.
2. `task_fd13_count_unique_words(text)` возвращает, сколько разных слов в тексте. Слова берутся через `text.split()`, каждое **приводится через `normalize`**,
   пустые строки (когда от слова остались одни знаки) не считаются.

## Аргументы

- `word` — строка без пробелов.
- `text` — строка (может быть пустой), слова разделены пробелами.

## Возвращает

`normalize` — строка. `task_fd13_count_unique_words` — целое число разных слов после нормализации; для пустого текста — `0`.

## Правила

- Имена функций и параметры оставь как есть.
- Внутри `task_fd13_count_unique_words` вызывай `normalize` для каждого слова.
- Увиденные слова храни в списке; `set` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
normalize("Привет!")                                   # -> "привет"
task_fd13_count_unique_words("Привет, привет! Мир.")   # -> 2
task_fd13_count_unique_words("!!! ...")                # -> 0
```

## Учебные цели

- Выделить мелкую операцию в функцию-помощник и вызвать её из главной.
- Использовать список как «уже видели» для подсчёта разных слов.

## Проверка понимания
