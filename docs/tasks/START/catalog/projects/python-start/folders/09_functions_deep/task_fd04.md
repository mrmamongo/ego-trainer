# Задача FD04: Корзина помнит прошлое

## Условие

### Как это работает

Значение по умолчанию вычисляется **один раз**, когда Python читает строку `def`. Если там стоит `[]`, то все вызовы без этого аргумента получают **один и тот же** список:

```python
def add_item(item, items=[]):      # плохо
    items.append(item)
    return items

a = add_item("яблоко")             # ["яблоко"]
b = add_item("груша")              # ["яблоко", "груша"]: тот же список!
```

| Вызов | Какой список использован | Что внутри после вызова |
|---|---|---|
| `add_item("яблоко")` | созданный при `def` | `["яблоко"]` |
| `add_item("груша")` | тот же самый | `["яблоко", "груша"]` |

Чтобы каждый вызов получал свежий список, ставят по умолчанию `None`, а новый список создают внутри:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### Задание

Функция `add_item(item, items=[])` должна добавлять товар в список и возвращать его. Если список не передали, она должна начинать с пустого.
Но она запоминает товары между вызовами. Функция `task_fd04_two_baskets(first, second)` делает два вызова подряд и показывает ошибку.
Исправь `add_item`, а `task_fd04_two_baskets` не трогай.

## Аргументы

- `first`, `second` — товары (любые значения), которые кладут в две разные корзины.

## Возвращает

Кортеж из двух списков: в первом только `first`, во втором только `second`.

## Правила

- Меняй только функцию `add_item`: заголовок и начало тела.
- `task_fd04_two_baskets` не изменяй: по ней идёт проверка.
- Если `items` передали, функция должна добавить товар в него, как и раньше.

## Пример

```python
task_fd04_two_baskets("яблоко", "груша")   # -> (["яблоко"], ["груша"])
```

## Учебные цели

- Узнавать ловушку `items=[]` в значении по умолчанию.
- Заменять изменяемое умолчание на `None` и создавать список внутри.

## Проверка понимания

Что вернёт исходный код для `("яблоко", "груша")` и почему оба списка одинаковы? Когда создаётся пустой список в исправленной версии?
