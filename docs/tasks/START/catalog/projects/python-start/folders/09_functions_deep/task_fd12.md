# Задача FD12: Первая цена обязательна

## Условие

### Как это работает

Это та же функция, что в предыдущей задаче, уже с пропуском слишком дорогих цен:

```python
def task_fd12_take_within_budget(items, budget):   # 1
    result = []                                    # 2
    spent = 0                                      # 3
    for item in items:                             # 4
        if spent + item > budget:                  # 5
            continue                               # 6
        result.append(item)                        # 7
        spent = spent + item                       # 8
    return result                                  # 9
```

**Где реализовано старое правило:** «не влезло, значит пропусти» — строки 5–6, а набор цен — строки 7–8. Они остаются как есть.

**Что меняется:** первая цена теперь **обязательная**. Если даже одна она больше бюджета, ответ целиком пустой: `[]`. Раньше мы бы пропустили её и взяли что-нибудь другое.
Это условие, которое стоит проверить **до цикла**: новая ветка в начале функции (перед строкой 2). Цикл при этом не трогаем.

Список может быть пустым, и тогда первой цены нет: `items[0]` вызвало бы ошибку. Поэтому сначала проверь `len(items) > 0`.

### Задание

Раньше функция пропускала цены, которые не влезают в бюджет. Теперь **первая цена обязательна**: если она одна уже больше бюджета, верни пустой список.
Если первая цена влезает, всё работает как раньше. Измени готовую функцию.

## Аргументы

- `items` — список положительных целых цен (может быть пустым).
- `budget` — целый бюджет, не меньше `0`.

## Возвращает

Новый список взятых цен в исходном порядке; `[]`, если первая цена больше бюджета или список пуст.

## Правила

- Цикл с пропуском оставь как есть: новая проверка нужна только перед ним.
- Для пустого `items` функция должна вернуть `[]`, а не упасть с ошибкой.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_fd12_take_within_budget([4, 8, 3, 2], 10)   # -> [4, 3, 2] (как раньше)
task_fd12_take_within_budget([20, 3], 10)        # -> []
task_fd12_take_within_budget([12], 10)           # -> []
```

## Учебные цели

- Добавить защитное условие перед циклом, не меняя сам цикл.
- Помнить о пустом списке, когда обращаешься к `items[0]`.

## Проверка понимания

Что вернёт старая версия для `[20, 3]` с бюджетом `10`? Почему новая проверка должна идти перед циклом, а не внутри него?
