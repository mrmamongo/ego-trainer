# Задача FD03: Умолчания и именованные аргументы

## Условие

### Как это работает

Если у параметра есть значение по умолчанию, его можно не передавать: тогда берётся оно. Аргумент можно также назвать при вызове: `имя=значение`.

```python
def with_fee(amount, percent=5, extra=0):
    return amount + amount * percent // 100 + extra

x = with_fee(200)                 # percent = 5, extra = 0   -> 210
y = with_fee(200, 10)             # percent = 10             -> 220
z = with_fee(200, extra=7)        # percent = 5 (умолчание)  -> 217
```

| Вызов | amount | percent | extra |
|---|---|---|---|
| `with_fee(200)` | 200 | 5 | 0 |
| `with_fee(200, 10)` | 200 | 10 | 0 |
| `with_fee(200, extra=7)` | 200 | 5 | 7 |

Позиционные аргументы (без имён) занимают параметры слева направо. Названный аргумент попадает точно в свой параметр, остальные берут умолчания.

### Задание

Открой файл задачи. Впиши вместо каждого `None` ответ. `a_after_3`, `b_after_4`, `c_after_5` и `d_after_6` — значения переменных
после своих строк, `rate_in_line_5` — чему равен параметр `rate` внутри вызова на строке 5.

**Сначала реши в голове или на бумаге, код не запускай.** Для каждого вызова выпиши значения `price`, `rate`, `bonus`.
Напомним, что `//` делит нацело: `200 * 10 // 100` равно `20`.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_fd03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Определять, какое значение получит каждый параметр при вызове.
- Различать позиционные и именованные аргументы.
