# Задача FD19: Новый игрок в таблице

## Условие

### Как это работает

Сейчас функция начисляет очки игроку, который уже есть в таблице, и возвращает новую таблицу:

```python
def task_fd19_add_score(scores, name, points):          # 1
    result = []                                         # 2
    for pair in scores:                                 # 3
        if pair[0] == name:                             # 4
            result.append([pair[0], pair[1] + points])  # 5
        else:                                           # 6
            result.append([pair[0], pair[1]])           # 7
    return result                                       # 8
```

**Где реализовано старое правило:** «начислить очки найденному игроку» — строки 4–5, а копирование остальных пар — строки 6–7. Цикл не меняется: он по-прежнему возвращает новую таблицу и не трогает исходную.

**Что меняется:** имени может не быть в таблице. Тогда в **конец** нового списка нужно добавить пару `[name, points]`. Для этого надо понять, есть ли имя. Эту проверку выносим в отдельного **помощника** `find_index(scores, name)`:
он возвращает номер пары с этим именем или `-1`, если такой нет (как в задаче FD09).

Порядок правки: сначала напиши `find_index`, потом после цикла добавь: «если `find_index(scores, name) == -1`, то `result.append([name, points])`».

### Задание

Раньше имя всегда было в таблице. Теперь его может не быть: тогда в конец нового списка нужно добавить пару `[name, points]`.
Для известных имён всё остаётся как раньше. Поиск имени вынеси в помощника `find_index(scores, name)`. Измени готовую функцию.

## Аргументы

- `scores` — список пар `[имя, очки]`; имена не повторяются (может быть пустым).
- `name` — имя игрока (может отсутствовать в `scores`).
- `points` — целое число очков.

## Возвращает

Новый список пар. Если имя уже было, его очки увеличены на `points`. Если не было, в конце добавлена новая пара `[name, points]`. Входной список менять нельзя.

## Правила

- Старый цикл с копированием оставь как есть: добавь только новую проверку.
- Напиши помощника `find_index(scores, name)`: номер пары с таким именем или `-1`.
- Не меняй `scores` и пары внутри него; результат должен состоять из новых списков.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
scores = [["аня", 10], ["борис", 5]]
task_fd19_add_score(scores, "аня", 3)    # -> [["аня", 13], ["борис", 5]] (как раньше)
task_fd19_add_score(scores, "вика", 4)   # -> [["аня", 10], ["борис", 5], ["вика", 4]]
task_fd19_add_score([], "аня", 5)        # -> [["аня", 5]]
```

## Учебные цели

- Расширить готовую чистую функцию новой веткой, не ломая старое поведение.
- Вынести поиск в функцию-помощник и использовать её.
