# Задача MP14: Два новых правила

## Условие

### Как это работает

**Что изменилось по сравнению с MP12: появились два новых правила.**

1. **Спецсимвол.** В хорошем пароле должен быть хотя бы один символ из набора `!@#$%^&*`. Если ни одного нет, в список добавляется код `"no_special"`. Он идёт **последним**. Проверка символа: `ch in "!@#$%^&*"`.
2. **Известный пароль.** Пароли вроде `password` или `123456` подбирают первыми. В файле уже лежит список `COMMON` (его не нужно менять). Если пароль, переведённый в нижний регистр, есть в этом списке, в начало ответа добавляется код `"common"`. Нижний регистр нужен, чтобы `"Password"` тоже считался известным.

Итоговый порядок кодов: `common`, `short`, `no_digit`, `no_upper`, `no_lower`, `no_special`.

Список `COMMON` объявлен в файле **снаружи** функции. Читать такую переменную внутри функции можно без всяких ухищрений: `if pw.lower() in COMMON:`.

| pw | Результат |
|---|---|
| `"Abcdefg1!"` | `[]` |
| `"Abcdefg1"` | `["no_special"]` |
| `"Password"` | `["common", "no_digit", "no_special"]` |
| `"123456"` | `["common", "short", "no_upper", "no_lower", "no_special"]` |

Как работать: сначала проверь, что старые примеры (без `common` и спецсимвола) не сломались, потом добавь новый флаг `has_special` и новую проверку.

### Задание

В файле лежит `find_problems` из MP12. Измени `task_mp14_find_problems(pw)`: добавь код `"no_special"` в конец и код `"common"` в начало по правилам выше.

## Аргументы

- `pw` — пароль, строка (может быть пустой).

## Возвращает

Список кодов проблем в порядке `common`, `short`, `no_digit`, `no_upper`, `no_lower`, `no_special`. Если проблем нет, это `[]`.

## Правила

- Список `COMMON` и функцию `check_length` из блока «готово» не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `any` и `all` не используй.

## Пример

```python
task_mp14_find_problems("Abcdefg1!")   # -> []
task_mp14_find_problems("Abcdefg1")    # -> ["no_special"]
task_mp14_find_problems("Password")    # -> ["common", "no_digit", "no_special"]
task_mp14_find_problems("Ab1!")        # -> ["short"]
```

## Учебные цели

- Изменить готовую функцию под два новых правила и не сломать старые.
- Прочитать переменную, объявленную вне функции.
