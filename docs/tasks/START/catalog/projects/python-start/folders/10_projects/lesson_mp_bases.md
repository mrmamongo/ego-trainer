# Проект «Системы счисления»

Число можно записать по-разному: `255` (десятичная), `FF` (шестнадцатеричная), `11111111` (двоичная). Число одно и то же, меняется только запись. В проекте мы научимся переводить число между системами без готовых `bin`, `hex` и `int(text, base)`.

## Шаги проекта

| Шаг | Функция | Что нового |
|---|---|---|
| MP16 | `to_binary(n)` | цифры делением на 2 и остатком |
| MP17 | `to_base(n, base)` | любое основание 2..16, цифры `0-9A-F` |
| MP18 | `from_base(text, base)` | обратно: `n = n * base + цифра` |
| MP19 | `to_base(n, base)` | **изменение**: отрицательные числа, знак `-` в начале |
| MP20 | `convert(text, base_from, base_to)` | собираем конвертер из двух функций |

## Инструменты проекта

Операции `//` и `%` и цикл `while` (MP16, как цифры числа в цикле), строка-алфавит цифр и индекс (MP17), цикл по символам и `find` (MP18), ветка для знака (MP19), вызов функции внутри функции и срез `text[1:]` (MP20).

## Разбор шага: из числа в запись

Число `13` в двоичной системе:

```python
digits = "0123456789ABCDEF"
result = ""
n = 13
while n > 0:
    result = digits[n % 2] + result
    n = n // 2
```

| Проход | n до | `n % 2` | result после | n после |
|---|---|---|---|---|
| 1 | 13 | 1 | `"1"` | 6 |
| 2 | 6 | 0 | `"01"` | 3 |
| 3 | 3 | 1 | `"101"` | 1 |
| 4 | 1 | 1 | `"1101"` | 0 |

Ответ: `"1101"`. Цифры получаются от младшей к старшей, поэтому каждую новую приписываем **слева**.

## Обратный путь

`from_base("1101", 2)`: идём по цифрам слева направо, `n = n * 2 + цифра`. Получаем `1`, `3`, `6`, `13`. Круг замкнулся: `13` -> `"1101"` -> `13`.

## Частые ошибки

Приписывать цифры справа: запись получается перевёрнутой.

```python
result = result + digits[n % base]      # неверно: 13 даст "1011" вместо "1101"
```

```python
result = digits[n % base] + result      # верно: новая цифра становится первой
```

Другая ошибка — назвать параметр так же, как функцию (`from_base`): внутри уже нельзя вызвать одноимённую функцию. Поэтому в `convert` параметры называются `base_from` и `base_to`.

## Проверь себя

1. Какая запись у числа `20` в шестнадцатеричной системе?
2. Чему равно `from_base("2B", 12)`?

<details><summary>Ответ</summary>

1. `"14"`: `20 // 16 = 1`, остаток `4`.
2. `35`: `2 * 12 + 11`, где цифра `B` стоит на позиции `11`.

</details>
