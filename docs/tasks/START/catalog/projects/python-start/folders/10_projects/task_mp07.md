# Задача MP07: Шифруем целое сообщение

## Условие

### Как это работает

Теперь зашифруем целый текст. Идея знакомая: пройти циклом по символам и собрать новую строку. Строки в Python **не изменяются**, поэтому пишем не «заменить символ», а «приклеить символ к новой строке»:

```python
result = ""
for ch in text:
    result = result + shift_letter(ch, k)
```

`shift_letter` лежит в файле как готовая: она сдвигает только **строчные** буквы. Значит, с заглавными нужно поступить хитро: превратить в строчную, сдвинуть и снова сделать заглавной.

| Метод | Что делает | Пример |
|---|---|---|
| `ch.isupper()` | заглавная ли буква | `"A".isupper()` даёт `True`, `"a".isupper()` даёт `False` |
| `ch.lower()` | строчная версия | `"A".lower()` даёт `"a"` |
| `ch.upper()` | заглавная версия | `"d".upper()` даёт `"D"` |

Для `"Ab"` и `k = 1`:

| ch | заглавная? | что приклеиваем | result |
|---|---|---|---|
| `A` | да | `shift_letter("a", 1).upper()` даёт `B` | `B` |
| `b` | нет | `shift_letter("b", 1)` даёт `c` | `Bc` |

### Задание

Напиши функцию `task_mp07_encode(text, k)`: зашифруй `text` шифром Цезаря со сдвигом `k`. Строчные латинские буквы остаются строчными, заглавные латинские остаются заглавными, все остальные символы не меняются.

## Аргументы

- `text` — строка (может быть пустой).
- `k` — сдвиг, целое число.

## Возвращает

Новую строку той же длины. Для пустой строки — `""`.

## Правила

- Меняй только тело функции `task_mp07_encode`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функции `ord`, `chr` и методы `translate`, `maketrans` не используй.

## Пример

```python
task_mp07_encode("abc", 1)              # -> "bcd"
task_mp07_encode("Hello, World!", 3)    # -> "Khoor, Zruog!"
task_mp07_encode("xyz", 3)              # -> "abc"
task_mp07_encode("", 5)                 # -> ""
```

## Учебные цели

- Собрать новую строку в цикле по символам.
- Сохранить регистр буквы через `lower` и `upper`, вызывая готовую функцию.
