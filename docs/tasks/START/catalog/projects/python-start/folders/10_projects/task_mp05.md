# Задача MP05: Лучшая стратегия: делим пополам

## Условие

### Как это работает

Как угадывать быстрее всего? Не подряд, а **делением пополам**. Игрок знает, что число лежит между `low` и `high`, и называет число **посередине**. Подсказка отрезает половину возможных вариантов:

- ответ `"больше"`: загаданное правее середины, значит новая нижняя граница `low = middle + 1`;
- ответ `"меньше"`: загаданное левее, значит `high = middle - 1`.

Середину считают целочисленным делением: `middle = (low + high) // 2`. Число проходов заранее неизвестно, поэтому цикл `while`: пока `low <= high`, ещё есть что проверять.

Пример: `low = 1`, `high = 10`, загадано `8`.

| Шаг | low | high | middle | подсказка |
|---|---|---|---|---|
| 1 | 1 | 10 | 5 | "больше" |
| 2 | 6 | 10 | 8 | "угадал" |

Ответ: `2` шага. Для чисел от 1 до 100 хватает **7** шагов при любом загаданном числе. Поэтому в прошлом шаге лимит попыток по умолчанию был 7.

Если загаданное число вообще вне отрезка, границы сойдутся (`low` станет больше `high`), цикл закончится сам, и тогда нужно вернуть `-1`.

### Задание

Напиши функцию `task_mp05_best_strategy_steps(low, high, secret)`: верни, за сколько попыток игрок, называя каждый раз середину отрезка, угадает `secret`. Подсказки бери у `check_guess`.

## Аргументы

- `low` — нижняя граница отрезка, целое.
- `high` — верхняя граница отрезка, целое, `low <= high`.
- `secret` — загаданное целое число (обычно внутри отрезка).

## Возвращает

Число попыток (первая попытка — номер `1`). Если `secret` вне отрезка от `low` до `high`, верни `-1`.

## Правила

- Меняй только тело функции `task_mp05_best_strategy_steps`; функции из блока «готово с прошлого шага» не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Середину считай как `(low + high) // 2` на каждом шаге.
- Встроенные `min`, `max` и `math` не используй.

## Пример

```python
task_mp05_best_strategy_steps(1, 100, 50)   # -> 1
task_mp05_best_strategy_steps(1, 100, 25)   # -> 2
task_mp05_best_strategy_steps(1, 10, 8)     # -> 2
task_mp05_best_strategy_steps(1, 10, 15)    # -> -1
```

## Учебные цели

- Реализовать деление пополам циклом `while` с двумя границами.
- Понять, почему число шагов растёт очень медленно (около логарифма).

## Проверка понимания

Сколько шагов понадобится, если отрезок `1..1000`? Почему число шагов почти не растёт, когда отрезок вырос в десять раз?
