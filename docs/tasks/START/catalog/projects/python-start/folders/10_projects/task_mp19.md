# Задача MP19: Отрицательные числа

## Условие

### Как это работает

**Что изменилось по сравнению с MP17: число `n` теперь может быть отрицательным.**

Сейчас для `n = -5` цикл `while n > 0` не выполнится ни разу, и функция вернёт пустую строку. В обычной записи отрицательное число — это знак `-` и запись его модуля, поэтому делаем так же: запомнить знак, взять модуль, перевести как раньше, в конце приписать знак.

План изменений:

1. До цикла заведи `sign = ""`.
2. Если `n < 0`: `sign = "-"` и `n = -n` (теперь `n` положительное).
3. Цикл не меняется.
4. Верни `sign + result`.

Ноль остаётся особым случаем: `"0"` без знака, это проверка в самом начале.

| n | base | результат |
|---|---|---|
| 5 | 2 | `"101"` (как раньше) |
| -5 | 2 | `"-101"` |
| -255 | 16 | `"-FF"` |
| 0 | 2 | `"0"` |

Запусти сначала старые примеры: для положительных чисел ответ не должен измениться. Ты добавляешь возможность, а не переписываешь функцию.

### Задание

В файле лежит `to_base` из MP17. Измени `task_mp19_to_base(n, base)`, чтобы для отрицательных `n` она возвращала запись модуля с минусом в начале.

## Аргументы

- `n` — целое число (может быть отрицательным).
- `base` — основание, целое от `2` до `16`.

## Возвращает

Строку: для `n >= 0` как раньше; для `n < 0` — `"-"` и запись числа `-n`. Для `0` — `"0"`.

## Правила

- Функция `from_base` из блока «готово с прошлого шага» остаётся как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функции `bin`, `oct`, `hex`, `format` и форматирование вида `f"{n:x}"` не используй.

## Пример

```python
task_mp19_to_base(5, 2)       # -> "101"
task_mp19_to_base(-5, 2)      # -> "-101"
task_mp19_to_base(-255, 16)   # -> "-FF"
task_mp19_to_base(0, 2)       # -> "0"
```

## Учебные цели

- Расширить готовую функцию на новый случай, сохранив старое поведение.
- Запоминать знак отдельно от модуля.

## Проверка понимания

Что вернёт старая версия для `n = -16`, `base = 16`? Почему без отдельной проверки `n == 0` ответом для нуля стала бы пустая строка?
