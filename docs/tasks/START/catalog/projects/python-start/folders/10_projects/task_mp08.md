# Задача MP08: Расшифровываем

## Условие

### Как это работает

Получатель шифровки знает ключ `k` и хочет вернуть исходный текст. Расшифровка Цезаря — это тот же сдвиг, только **в обратную сторону**: если при шифровании каждую букву сдвинули на `k` вперёд, то теперь сдвигаем на `k` назад.

Писать новый цикл не нужно. Сдвиг назад на `k` — это то же самое, что сдвиг вперёд на `-k`, а шифровать мы уже умеем (`encode` лежит в файле как готовая). Новая функция просто **вызывает** старую с другим числом:

```python
def double(x):
    return x * 2

def quadruple(x):
    return double(double(x))     # собираем новую функцию из готовой
```

Проверка здравым смыслом: шифруем, потом расшифровываем тем же `k`, и текст должен вернуться:

| Действие | Результат |
|---|---|
| `encode("Attack", 3)` | `"Dwwdfn"` |
| `decode("Dwwdfn", 3)` | `"Attack"` |

А ещё: сдвиг на `29` равен сдвигу на `3` (29 − 26), поэтому расшифровка с `k = 29` тоже должна работать. Это обеспечено `% 26` внутри `shift_letter`.

### Задание

Напиши функцию `task_mp08_decode(text, k)`: верни исходный текст по шифровке `text` и ключу `k`.

## Аргументы

- `text` — шифровка (строка, может быть пустой).
- `k` — ключ, которым шифровали, целое число.

## Возвращает

Расшифрованную строку. Регистр букв и все не-латинские символы сохраняются.

## Правила

- Меняй только тело функции `task_mp08_decode`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Решение помещается в одну строку, но можно написать и цикл.

## Пример

```python
task_mp08_decode("Khoor, Zruog!", 3)   # -> "Hello, World!"
task_mp08_decode("bcd", 1)             # -> "abc"
task_mp08_decode("abc", 3)             # -> "xyz"
task_mp08_decode("", 4)                # -> ""
```

## Учебные цели

- Построить новую функцию из готовой: расшифровка как шифрование с ключом `-k`.
- Проверять пару «зашифровал, расшифровал» на примерах.

## Проверка понимания

Чему равно `decode(encode(text, k), k)` для любого текста из латинских букв? А что будет, если расшифровать ключом, отличным от `k`?
