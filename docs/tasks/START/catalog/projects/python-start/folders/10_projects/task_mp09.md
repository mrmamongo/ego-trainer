# Задача MP09: Добавим русский алфавит

## Условие

### Как это работает

**Что изменилось по сравнению с MP07: шифр должен понимать русские буквы.** Латинский текст шифруется как раньше, а к нему добавляется русский алфавит.

Русский алфавит в нашем шифре — **33 буквы**, и порядок надо знать точно, потому что от него зависит результат. Буква `ё` стоит сразу после `е`:

```python
russian = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"
```

Формула та же, только длина другая: `russian[(russian.find(low) + k) % 33]`. Сдвиг по кругу на 33, а не на 26.

| Текст | k | Результат | Почему |
|---|---|---|---|
| `привет` | 1 | `рсйгёу` | `е` -> `ё`, `т` -> `у` |
| `я` | 1 | `а` | после `я` круг замыкается |
| `ёж` | 1 | `жз` | `ё` -> `ж`, `ж` -> `з` |
| `Эхо` | 1 | `Юцп` | регистр сохраняется |

Как изменить код: в цикле добавь **ещё одну ветку**. Сначала проверь, русская ли буква (`low in russian`, где `low = ch.lower()`). Русскую сдвинь по формуле с `% 33`, сохранив регистр. Остальные ветки (латиница, прочие символы) оставь как были.

Сначала запусти старые примеры: латиница должна работать, как раньше. Потом проверь русский текст.

### Задание

В файле лежит `encode` из MP07. Измени `task_mp09_encode(text, k)` так, чтобы русские буквы тоже шифровались. Латинский текст и остальные символы работают как раньше.

## Аргументы

- `text` — строка (может быть пустой, может смешивать латиницу и кириллицу).
- `k` — сдвиг, целое число.

## Возвращает

Новую строку той же длины: латинские буквы сдвинуты по алфавиту из 26 букв, русские по алфавиту из 33 букв, регистр сохранён, остальные символы не изменены.

## Правила

- Порядок русского алфавита: `абвгдеёжзийклмнопрстуфхцчшщъыьэюя` (33 буквы, `ё` после `е`).
- Функция `shift_letter` из блока «готово с прошлого шага» остаётся как есть: можно её вызывать.
- Функции `ord`, `chr` и методы `translate`, `maketrans` не используй.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_mp09_encode("привет", 1)       # -> "рсйгёу"
task_mp09_encode("я", 1)            # -> "а"
task_mp09_encode("Hello", 3)        # -> "Khoor"
task_mp09_encode("Эхо, ok!", 1)     # -> "Юцп, pl!"
```

## Учебные цели

- Расширить готовую функцию, не ломая старое поведение.
- Помнить, что длина алфавита входит в формулу сдвига.

## Проверка понимания

Почему для русских букв в формуле стоит `% 33`, а не `% 26`? Что будет с буквой `я` при `k = 1`, если ошибочно оставить `% 26`?
