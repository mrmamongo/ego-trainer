# Задача MP16: Двоичная запись числа

## Условие

### Как это работает

Четвёртый проект — **системы счисления**. Мы привыкли к десятичной записи, где цифр десять, а разряды — это единицы, десятки, сотни. В **двоичной** системе цифр две (`0` и `1`), а разряды — это 1, 2, 4, 8, 16 и так далее. Например, `101` в двоичной записи — это `4 + 0 + 1 = 5`.

Как получить двоичную запись числа? Так же, как мы доставали десятичные цифры, только делим не на 10, а на **2**:

- `n % 2` — последняя двоичная цифра (остаток);
- `n // 2` — число без неё.

Повторяем, пока число не станет нулём. Цифры получаются **с конца**, поэтому каждую новую цифру приписываем **слева**: `result = str(n % 2) + result`.

Пример для `n = 6`:

| Проход | n до | цифра `n % 2` | result после | n после (`n // 2`) |
|---|---|---|---|---|
| 1 | 6 | 0 | `"0"` | 3 |
| 2 | 3 | 1 | `"10"` | 1 |
| 3 | 1 | 1 | `"110"` | 0 |

Ответ: `"110"` (`4 + 2 + 0 = 6`). Число `0` — особый случай: цикл не выполнится ни разу, а запись должна быть `"0"`, поэтому его возвращаем отдельно, до цикла.

### Задание

Напиши функцию `task_mp16_to_binary(n)`: верни двоичную запись неотрицательного числа `n` в виде строки.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Строку из символов `"0"` и `"1"` без лишних нулей в начале. Для `0` — строку `"0"`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `//` и `%` в цикле. Функции `bin`, `format`, `oct`, `hex` и форматирование вида `f"{n:b}"` не используй.

## Пример

```python
task_mp16_to_binary(6)     # -> "110"
task_mp16_to_binary(5)     # -> "101"
task_mp16_to_binary(1)     # -> "1"
task_mp16_to_binary(0)     # -> "0"
```

## Учебные цели

- Получить цифры другой системы счисления делением и остатком.
- Собрать строку, приписывая новые цифры слева.
