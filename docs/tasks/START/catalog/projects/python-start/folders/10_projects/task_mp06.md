# Задача MP06: Сдвиг одной буквы

## Условие

### Как это работает

Второй проект — **шифр Цезаря**. Древний римлянин заменял каждую букву сообщения на ту, что стоит на `k` мест дальше в алфавите. При `k = 3` буква `a` превращается в `d`, `b` в `e`, а `x` после `z` возвращается к началу и становится `a`.

Начнём с одной буквы. Алфавит запишем строкой, номер буквы найдём методом `find` (он возвращает `-1`, если символа в строке нет), а «возврат к началу» даст остаток от деления `%` на длину алфавита:

```python
alphabet = "abcdefghijklmnopqrstuvwxyz"
position = alphabet.find("x")        # 23
alphabet[(position + 3) % 26]        # (23 + 3) % 26 = 0 -> "a"
```

| Буква | position | position + 3 | `% 26` | Результат |
|---|---|---|---|---|
| `b` | 1 | 4 | 4 | `e` |
| `x` | 23 | 26 | 0 | `a` |
| `z` | 25 | 28 | 2 | `c` |

Остаток `%` в Python для положительного делителя всегда неотрицательный, поэтому сдвиг **назад** (`k` отрицательное) тоже работает: `(0 - 1) % 26` равно `25`, то есть буква `a` при `k = -1` становится `z`.

Всё, чего нет в алфавите (заглавные буквы, цифры, пробелы, знаки, русские буквы), шифр не трогает: `find` вернёт `-1`, и мы возвращаем символ как был.

### Задание

Напиши функцию `task_mp06_shift_letter(ch, k)`: сдвинь строчную латинскую букву `a`–`z` на `k` мест вперёд по кругу. Любой другой символ верни без изменений.

## Аргументы

- `ch` — строка ровно из одного символа.
- `k` — сдвиг, целое число (может быть отрицательным или больше 26).

## Возвращает

Строку из одного символа: сдвинутую букву или тот же символ, если это не строчная латинская буква.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функции `ord`, `chr` и методы `translate`, `maketrans` не используй: работай с алфавитом-строкой.

## Пример

```python
task_mp06_shift_letter("a", 3)    # -> "d"
task_mp06_shift_letter("x", 3)    # -> "a"
task_mp06_shift_letter("b", -1)   # -> "a"
task_mp06_shift_letter("A", 3)    # -> "A"
task_mp06_shift_letter("5", 2)    # -> "5"
```

## Учебные цели

- Найти номер символа в строке методом `find` и взять символ по номеру.
- Закольцевать сдвиг остатком `%` и не потерять «не-буквы».
