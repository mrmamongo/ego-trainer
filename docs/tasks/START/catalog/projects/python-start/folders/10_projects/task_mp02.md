# Задача MP02: Сколько попыток понадобилось

## Условие

### Как это работает

Теперь у игрока не одна попытка, а список `guesses`, и надо узнать, **с какой по счёту** попытки он угадал. Подсказывать каждую попытку заново не нужно: это уже умеет функция `check_guess` из прошлого шага. Она лежит в файле как готовая, ты просто **вызываешь** её.

Номер попытки — это счётчик. Он растёт на каждом проходе, а когда подсказка стала `"угадал"`, мы сразу возвращаем его через `return`:

```python
def first_big(numbers):
    position = 0
    for number in numbers:
        position = position + 1
        if number > 100:
            return position
    return -1
```

Особое значение `-1` ставят **после цикла**: туда программа доходит, только если ни один `return` внутри не сработал, то есть ничего не нашли.

| numbers | position на каждом проходе | ответ |
|---|---|---|
| `[5, 200, 7]` | 1, 2 | `2` |
| `[5, 7]` | 1, 2 | `-1` |

### Задание

Напиши функцию `task_mp02_count_tries(secret, guesses)`: верни, на какой по счёту попытке игрок угадал число (счёт с единицы). Если ни одна попытка не угадала, верни `-1`. Для вызова подсказки используй `check_guess`.

## Аргументы

- `secret` — загаданное целое число.
- `guesses` — список попыток (целые числа, может быть пустым).

## Возвращает

Номер первой верной попытки (первая попытка имеет номер `1`) или `-1`, если не угадал ни разу. Попытки после верной не считаются.

## Правила

- Меняй только тело функции `task_mp02_count_tries`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенную функцию `enumerate` не используй: заведи счётчик сам.

## Пример

```python
task_mp02_count_tries(5, [3, 8, 5, 9])   # -> 3
task_mp02_count_tries(5, [5, 5])         # -> 1
task_mp02_count_tries(5, [1, 2, 3])      # -> -1
task_mp02_count_tries(5, [])             # -> -1
```

## Учебные цели

- Вызвать готовую функцию из новой функции.
- Соединить счётчик и ранний `return`, а значение «не нашли» вернуть после цикла.

## Проверка понимания

Почему `return -1` нельзя поставить внутрь цикла, в ветку `else` у `if`? Что тогда вернётся для `(5, [3, 8, 5])`?
