# Задача MP20: Конвертер систем счисления

## Условие

### Как это работает

Соберём всё в один инструмент: запись в одной системе превратить в запись в другой. Работа делится на два шага, и оба уже готовы в файле:

1. `from_base(text, base_from)` — из записи в **число**;
2. `to_base(число, base_to)` — из числа в запись в **нужной системе**.

Число — общая «серединка» между любыми двумя системами. Функция получается из двух вызовов, один внутри другого:

```python
def convert(text, base_from, base_to):
    number = from_base(text, base_from)
    return to_base(number, base_to)
```

**Об именах.** Параметры названы `base_from` и `base_to`, а не `from_base` и `to_base`. Иначе параметр «закрыл» бы одноимённую функцию, и вызвать её внутри стало бы нельзя. Правило простое: имя параметра не должно совпадать с именем функции, которую вызываешь.

**Отрицательные числа.** `to_base` теперь понимает минус, а `from_base` нет: цифры `-` у неё нет. Поэтому если `text` начинается с `"-"`, отдели знак срезом: `text[1:]` — это текст без первого символа. Переведи остальное в число и поставь минус перед результатом (`-число`), а дальше `to_base` сама допишет знак.

| text | base_from | base_to | результат |
|---|---|---|---|
| `"FF"` | 16 | 2 | `"11111111"` |
| `"-FF"` | 16 | 10 | `"-255"` |

### Задание

Напиши функцию `task_mp20_convert(text, base_from, base_to)`: переведи запись `text` из системы `base_from` в систему `base_to`.

## Аргументы

- `text` — непустая запись числа: цифры `0`–`9`, `A`–`F`, перед ними может стоять один `"-"`.
- `base_from` — основание исходной записи, от `2` до `16`.
- `base_to` — основание результата, от `2` до `16`.

## Возвращает

Строку с записью того же числа в системе `base_to` (с минусом, если число отрицательное).

## Правила

- Меняй только тело функции `task_mp20_convert`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функции `int`, `bin`, `oct`, `hex`, `format` не используй.

## Пример

```python
task_mp20_convert("101", 2, 10)     # -> "5"
task_mp20_convert("FF", 16, 2)      # -> "11111111"
task_mp20_convert("255", 10, 16)    # -> "FF"
task_mp20_convert("-FF", 16, 10)    # -> "-255"
```

## Учебные цели

- Соединить две готовые функции через общее «промежуточное» число.
- Обработать знак срезом строки.
