# Задача MP03: Отчёт об игре

## Условие

### Как это работает

Теперь нужен не только номер попытки, а весь ход игры: подсказка на каждую попытку, пока игрок не угадал. Это **сборщик**: пустой список до цикла, `append` на каждом проходе, `return` после цикла.

Новое здесь одно: цикл надо **остановить** после ответа `"угадал"`. Попытки, которые идут дальше, в отчёт не попадают. Отчёт сначала пополняется, потом проверяется условие остановки:

```python
def until_stop(words):
    result = []
    for word in words:
        result.append(word)
        if word == "стоп":
            break
    return result
```

| words | result после каждого прохода | ответ |
|---|---|---|
| `["а", "стоп", "б"]` | `["а"]`, `["а", "стоп"]`, цикл оборвался | `["а", "стоп"]` |
| `["а", "б"]` | `["а"]`, `["а", "б"]` | `["а", "б"]` |

Слово `"стоп"` в ответе осталось, потому что `append` стоит **до** `break`. Так же и "угадал" должен остаться в отчёте.

### Задание

Напиши функцию `task_mp03_game_report(secret, guesses)`: верни список подсказок на попытки по порядку, закончив на первой подсказке `"угадал"` (она входит в список). Если угадать не удалось, верни подсказки на все попытки.

## Аргументы

- `secret` — загаданное целое число.
- `guesses` — список попыток (может быть пустым).

## Возвращает

Список строк-подсказок. Для пустого списка попыток это `[]`.

## Правила

- Меняй только тело функции `task_mp03_game_report`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `guesses` не меняй.

## Пример

```python
task_mp03_game_report(5, [3, 8, 5, 9])   # -> ["больше", "меньше", "угадал"]
task_mp03_game_report(5, [1, 2])         # -> ["больше", "больше"]
task_mp03_game_report(5, [5, 1])         # -> ["угадал"]
task_mp03_game_report(5, [])             # -> []
```

## Учебные цели

- Собрать список подсказок сборщиком.
- Остановить цикл после нужного ответа, оставив его в списке.

## Проверка понимания

Что вернётся для `(5, [6, 5, 5])`, если поставить `append` **после** проверки с `break`? Почему слово `"угадал"` тогда потеряется?
