# Задача MP13: Оценка надёжности

## Условие

### Как это работает

Список проблем — это подробно. А пользователю обычно нужна короткая оценка: **слабый**, **средний** или **надёжный**. Оценку определим по числу проблем:

| Проблем | Оценка |
|---|---|
| 0 | `"надёжный"` |
| 1 или 2 | `"средний"` |
| 3 и больше | `"слабый"` |

Считать проблемы заново не нужно: `find_problems` из прошлого шага уже лежит в файле. Функция, которая использует результат другой функции, строится так:

```python
def many_words(text):
    words = split_into_words(text)    # вызвали готовую функцию
    return len(words) > 5             # и поработали с её результатом
```

`len(список)` возвращает число элементов. Проверки идут сверху вниз: сначала самый «хороший» случай, потом средний, а то, что не подошло, — слабое. Так не нужно писать лишних условий.

| pw | find_problems | len | оценка |
|---|---|---|---|
| `"Abcdefg1"` | `[]` | 0 | `"надёжный"` |
| `"abcdefgh"` | `["no_digit", "no_upper"]` | 2 | `"средний"` |
| `"abc"` | `["short", "no_digit", "no_upper"]` | 3 | `"слабый"` |

### Задание

Напиши функцию `task_mp13_strength(pw)`: верни оценку пароля по числу проблем из `find_problems`.

## Аргументы

- `pw` — пароль, строка (может быть пустой).

## Возвращает

Одну из строк: `"надёжный"` (0 проблем), `"средний"` (1 или 2), `"слабый"` (3 и больше).

## Правила

- Меняй только тело функции `task_mp13_strength`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Проверки правил (цифры, регистр) заново не пиши: используй `find_problems`.

## Пример

```python
task_mp13_strength("Abcdefg1")    # -> "надёжный"
task_mp13_strength("abcdefgh")    # -> "средний"
task_mp13_strength("abc")         # -> "слабый"
task_mp13_strength("")            # -> "слабый"
```

## Учебные цели

- Использовать результат готовой функции для новой оценки.
- Разобрать диапазоны значений проверками сверху вниз.

## Проверка понимания

Почему для `"12345678"` оценка «средний», а не «слабый», хотя пароль состоит только из цифр? Как изменить порог, чтобы он стал «слабым»?
