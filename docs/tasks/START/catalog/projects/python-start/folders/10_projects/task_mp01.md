# Задача MP01: Подсказка игроку

## Условие

### Как это работает

Первый проект — игра «Угадай число». Компьютер загадал число, а игрок называет свои попытки. После каждой попытки нужна **подсказка**:
угадал игрок, или загаданное число больше, или меньше. Эту подсказку и будет выдавать наша первая функция.

Когда ответов несколько, их проверяют цепочкой `if`. Как только подходящий `if` сработал и сделал `return`, остальные уже не выполняются:

```python
def compare_to_ten(number):
    if number < 10:
        return "меньше десяти"
    if number > 10:
        return "больше десяти"
    return "ровно десять"
```

| number | какой `return` сработает |
|---|---|
| 3 | первый |
| 14 | второй |
| 10 | последний, оба `if` не подошли |

**Внимание на смысл слов.** Подсказка говорит про **загаданное** число, а не про попытку. Если загадано `7`, а игрок назвал `3`, то загаданное число **больше** попытки, поэтому ответ `"больше"`.

### Задание

Напиши функцию `task_mp01_check_guess(secret, guess)`: сравни попытку с загаданным числом и верни подсказку.

## Аргументы

- `secret` — загаданное целое число.
- `guess` — попытка игрока, целое число (может быть отрицательным).

## Возвращает

Строку: `"больше"`, если загаданное число больше попытки; `"меньше"`, если загаданное меньше попытки; `"угадал"`, если числа равны.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Слова в ответах пиши точно так, как в условии: проверка сравнивает строки буква в букву.

## Пример

```python
task_mp01_check_guess(7, 3)    # -> "больше"
task_mp01_check_guess(7, 9)    # -> "меньше"
task_mp01_check_guess(7, 7)    # -> "угадал"
```

## Учебные цели

- Выдать одну из трёх подсказок цепочкой `if` и `return`.
- Понять, что подсказка описывает загаданное число, а не попытку.

## Проверка понимания

Что вернёт функция для `secret = 0` и `guess = -1`? Почему ответ `"больше"`, хотя `-1` выглядит «маленьким»?
