# Задача MP04: Ограничим число попыток

## Условие

### Как это работает

**Что изменилось по сравнению с MP03: появилось ограничение.** Играть бесконечно скучно, поэтому у игрока теперь есть `max_tries` попыток. Параметр уже стоит в заголовке со значением по умолчанию `7`: если вызвать функцию без третьего аргумента, будет `max_tries = 7`.

Что должен делать отчёт теперь:

1. Принимать **не больше** `max_tries` попыток. Остальные просто игнорируются.
2. Если игрок угадал в пределах лимита, отчёт, как раньше, заканчивается на `"угадал"`.
3. Если попытки кончились (набралось ровно `max_tries` ответов), а угадать не вышло, в конец добавь строку `"попытки кончились"`.
4. Если попыток было меньше лимита и игрок не угадал, игра просто не закончена: лишних слов в отчёт не добавляй.

Пример для `secret = 5`, `max_tries = 3`:

| guesses | отчёт |
|---|---|
| `[1, 2, 3, 5]` | `["больше", "больше", "больше", "попытки кончились"]` (четвёртую попытку никто не считает) |
| `[1, 2, 5]` | `["больше", "больше", "угадал"]` (угадал на последней, сообщения нет) |
| `[1, 2]` | `["больше", "больше"]` (попытки ещё есть) |

Хороший способ работать с изменением: сначала запусти старые примеры и убедись, что они дают прежний ответ, потом добавляй новое правило.

### Задание

В файле лежит `game_report` из MP03, у неё уже есть параметр `max_tries=7`. Измени тело функции `task_mp04_game_report(secret, guesses, max_tries=7)` по правилам выше.

## Аргументы

- `secret` — загаданное целое число.
- `guesses` — список попыток (может быть пустым).
- `max_tries` — разрешённое число попыток, целое от `1`; по умолчанию `7`.

## Возвращает

Список строк-подсказок: не более `max_tries` подсказок, в конце либо `"угадал"`, либо `"попытки кончились"`, если лимит исчерпан без победы.

## Правила

- Заголовок функции не меняй: параметр `max_tries=7` уже на месте.
- Функция `check_guess` из блока «готово с прошлого шага» остаётся как есть: вызывай её.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `guesses` не меняй.

## Пример

```python
task_mp04_game_report(5, [1, 2, 3, 5], 3)   # -> ["больше", "больше", "больше", "попытки кончились"]
task_mp04_game_report(5, [1, 2, 5], 3)      # -> ["больше", "больше", "угадал"]
task_mp04_game_report(5, [1, 2], 3)         # -> ["больше", "больше"]
task_mp04_game_report(5, [5, 1])            # -> ["угадал"]
```

## Учебные цели

- Изменить готовую функцию под новое правило, не ломая старое поведение.
- Использовать параметр со значением по умолчанию.

## Проверка понимания

Почему при `max_tries = 3` и `guesses = [1, 2, 5]` сообщения «попытки кончились» нет, хотя использованы все три попытки?
