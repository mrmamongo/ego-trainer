# Задача MP18: Обратно: из записи в число

## Условие

### Как это работает

Теперь в обратную сторону: по записи `"101"` в системе с основанием `base` найти число. Идём по цифрам **слева направо** и держим текущее число `n`. Новая цифра сдвигает уже собранное на один разряд влево (умножение на основание) и сама встаёт в разряд единиц:

```python
n = n * base + digit
```

Номер цифры в алфавите `"0123456789ABCDEF"` даёт `digits.find(ch)`: для `"7"` это `7`, для `"B"` это `11`.

Пример: `"101"` при `base = 2`.

| Проход | ch | значение цифры | `n * 2 + цифра` | n после |
|---|---|---|---|---|
| 1 | `1` | 1 | `0 * 2 + 1` | 1 |
| 2 | `0` | 0 | `1 * 2 + 0` | 2 |
| 3 | `1` | 1 | `2 * 2 + 1` | 5 |

Ответ: `5`. Начальное значение `n = 0` — это ответ для пустой записи, как у любого накопителя. Эта функция «обратная» к `to_binary` и `to_base`: `from_base(to_base(n, b), b)` должно вернуть `n`.

### Задание

Напиши функцию `task_mp18_from_base(text, base)`: верни число, записанное строкой `text` в системе с основанием `base`.

## Аргументы

- `text` — непустая строка из цифр `0`–`9` и заглавных `A`–`F`, подходящих для основания (знака `-` нет).
- `base` — основание, целое от `2` до `16`.

## Возвращает

Целое неотрицательное число.

## Правила

- Меняй только тело функции `task_mp18_from_base`; функции из блока «готово с прошлого шага» не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функцию `int` не используй совсем (ни `int(text, base)`, ни `int(ch)`), а также `hex`, `oct`, `eval`.

## Пример

```python
task_mp18_from_base("101", 2)     # -> 5
task_mp18_from_base("FF", 16)     # -> 255
task_mp18_from_base("377", 8)     # -> 255
task_mp18_from_base("0", 2)       # -> 0
```

## Учебные цели

- Собрать число из цифр формулой `n * base + digit`.
- Увидеть связь прямого и обратного перевода.

## Проверка понимания

Что даст формула `n = n + digit * base`? Почему такая формула неверна даже для `"101"`?
