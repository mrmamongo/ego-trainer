# Проект «Угадай число»

Компьютер загадал число, игрок называет попытки. Мы строим «мозги» игры по шагам: каждая функция чистая, то есть берёт аргументы и возвращает ответ (никакого `input` и `print`).

## Шаги проекта

| Шаг | Функция | Что нового |
|---|---|---|
| MP01 | `check_guess(secret, guess)` | подсказка: `"больше"`, `"меньше"`, `"угадал"` |
| MP02 | `count_tries(secret, guesses)` | номер удачной попытки или `-1` |
| MP03 | `game_report(secret, guesses)` | список подсказок до победы |
| MP04 | `game_report(..., max_tries=7)` | **изменение**: лимит попыток и фраза «попытки кончились» |
| MP05 | `best_strategy_steps(low, high, secret)` | деление отрезка пополам |

## Инструменты проекта

`if` и `return` (MP01), счётчик и ранний `return` (MP02), сборщик и `break` (MP03), параметр по умолчанию (MP04), цикл `while` с двумя границами (MP05).

## Главная идея: подсказка про загаданное число

Подсказка описывает **загаданное** число. Если `secret = 7`, а `guess = 3`, то загаданное больше, и ответ `"больше"`.

## Разбор шага: отчёт об игре

```python
def game_report(secret, guesses):
    answers = []                                  # 1
    for guess in guesses:                         # 2
        answer = check_guess(secret, guess)       # 3
        answers.append(answer)                    # 4
        if answer == "угадал":                    # 5
            break                                 # 6
    return answers                                # 7
```

Для `secret = 5` и `guesses = [3, 8, 5, 9]`:

| Проход | guess | answer | answers после прохода |
|---|---|---|---|
| 1 | 3 | `"больше"` | `["больше"]` |
| 2 | 8 | `"меньше"` | `["больше", "меньше"]` |
| 3 | 5 | `"угадал"` | `["больше", "меньше", "угадал"]`, затем `break` |

Девятка в конце списка даже не просматривается.

## Частые ошибки

Поставить `return -1` внутрь цикла: функция сдастся уже после первой неудачной попытки.

```python
for guess in guesses:
    tries = tries + 1
    if check_guess(secret, guess) == "угадал":
        return tries
    else:
        return -1             # неверно: выйдем после первой же попытки
```

```python
for guess in guesses:
    tries = tries + 1
    if check_guess(secret, guess) == "угадал":
        return tries
return -1                     # верно: -1 только если не нашли нигде
```

## Проверь себя

1. Сколько шагов нужно, чтобы деление пополам нашло число на отрезке `1..100`: не более 7 или не более 70?
2. Что вернёт `game_report(5, [], 3)`?

<details><summary>Ответ</summary>

1. Не более 7: каждый шаг вдвое сужает отрезок (`100 -> 50 -> 25 -> 12 -> 6 -> 3 -> 1`).
2. `[]`: попыток не было, ответов нет, и «попытки кончились» тоже нет, потому что их не использовали.

</details>
