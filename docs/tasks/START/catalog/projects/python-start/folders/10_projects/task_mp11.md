# Задача MP11: Достаточно ли длинный пароль

## Условие

### Как это работает

Третий проект — **проверка пароля**. Сервис не должен пускать слишком простые пароли, и мы построим проверялку по шагам. Первое правило: пароль не должен быть коротким.

Длину строки возвращает `len`. Условие вида `len(pw) >= 8` само является значением `True` или `False`, и его можно сразу вернуть, не оборачивая в `if`:

```python
def is_adult(age):
    return age >= 18
```

В заголовке `min_len=8` значит: «если второй аргумент не передали, считай, что он равен 8». Такое значение называется **значением по умолчанию**.

| Вызов | min_len внутри функции |
|---|---|
| `check_length("abcdefgh")` | 8 (взято по умолчанию) |
| `check_length("abc", 3)` | 3 (передали явно) |

Результат — `True`, если пароль **не короче** `min_len`, и `False`, если короче.

### Задание

Напиши функцию `task_mp11_check_length(pw, min_len=8)`: верни `True`, если длина пароля не меньше `min_len`, иначе `False`.

## Аргументы

- `pw` — пароль, строка (может быть пустой).
- `min_len` — минимальная длина, целое число; по умолчанию `8`.

## Возвращает

`True`, если `len(pw) >= min_len`, иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры (вместе с `min_len=8`) оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_mp11_check_length("abcdefgh")      # -> True
task_mp11_check_length("abcdefg")       # -> False
task_mp11_check_length("abc", 3)        # -> True
task_mp11_check_length("", 0)           # -> True
```

## Учебные цели

- Вернуть результат сравнения напрямую.
- Использовать параметр со значением по умолчанию.

## Проверка понимания

Почему при длине ровно 8 ответ `True`, а не `False`? Какой знак сравнения даст неверный ответ именно для длины 8?
