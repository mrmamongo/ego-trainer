# Задача MP10: Взлом перебором

## Условие

### Как это работает

Последний шаг проекта: ключ неизвестен, зато известно слово, которое точно есть в сообщении (например, имя отправителя). Вариантов ключа немного, поэтому можно **перебрать все**: расшифровать шифровку каждым ключом и посмотреть, появилось ли знакомое слово.

Проверка «слово встречается внутри текста» — это оператор `in`:

```python
"cat" in "concatenate"     # True
"dog" in "concatenate"     # False
```

Перебор с досрочным выходом знаком тебе по поиску в списке: ответ возвращаем, как только нашли, а `-1` оставляем на после цикла.

```python
for k in range(33):
    if known_word in decode(cipher, k):
        return k
return -1
```

`range(33)` даёт ключи от `0` до `32`: этого хватает для обоих алфавитов (в русском 33 буквы, латинский повторяется через 26). Если подходят несколько ключей, нужен **наименьший**: перебор идёт по возрастанию, поэтому первый найденный и есть ответ.

Регистр важен: слово ищется ровно в том виде, в каком записано. Файл содержит готовые `shift_letter`, `encode` (с русским алфавитом) и `decode`.

### Задание

Напиши функцию `task_mp10_crack(cipher, known_word)`: найди наименьший ключ `k` из `0..32`, при котором расшифровка `cipher` содержит `known_word`. Если такого ключа нет, верни `-1`.

## Аргументы

- `cipher` — шифровка (строка, может быть пустой).
- `known_word` — непустая строка: слово, которое есть в исходном тексте.

## Возвращает

Целое число от `0` до `32` или `-1`.

## Правила

- Меняй только тело функции `task_mp10_crack`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Ключ перебирай циклом: подбирать его «в уме» нельзя.

## Пример

```python
task_mp10_crack("Khoor, Zruog!", "World")   # -> 3
task_mp10_crack("abc", "abc")               # -> 0
task_mp10_crack("abc", "zzz")               # -> -1
```

## Учебные цели

- Перебрать все варианты ключа и вернуть первый подходящий.
- Использовать готовые `decode` и `encode` в новой функции.

## Проверка понимания

Почему перебор не нужно продолжать после первой находки? Что вернётся, если слово подходит сразу двум ключам?
