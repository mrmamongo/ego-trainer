# Проект «Надёжный пароль»

Сервис не должен принимать слабые пароли. Мы построим проверялку: сначала правила, потом список проблем, потом оценка и совет по-русски.

## Шаги проекта

| Шаг | Функция | Что нового |
|---|---|---|
| MP11 | `check_length(pw, min_len=8)` | значение по умолчанию |
| MP12 | `find_problems(pw)` | флаги и список кодов: `short`, `no_digit`, `no_upper`, `no_lower` |
| MP13 | `strength(pw)` | оценка по числу проблем |
| MP14 | `find_problems(pw)` | **изменение**: правило `no_special` и запрещённые пароли (`common` первым) |
| MP15 | `suggest(pw)` | совет по-русски f-строкой |

## Инструменты проекта

Параметр со значением по умолчанию (MP11), флаги в цикле и методы `isdigit`, `isupper`, `islower` (MP12), вызов готовой функции и `len` списка (MP13), чтение внешнего списка и проверка `in` (MP14), `join` и f-строка (MP15).

## Разбор шага: флаги за один проход

```python
has_digit = False
has_upper = False
for ch in "aB3":                    # 1
    if ch.isdigit():                # 2
        has_digit = True            # 3
    if ch.isupper():                # 4
        has_upper = True            # 5
```

| Проход | ch | has_digit | has_upper |
|---|---|---|---|
| 1 | `a` | `False` | `False` |
| 2 | `B` | `False` | `True` |
| 3 | `3` | `True` | `True` |

Порядок кодов в списке проблем фиксирован. Поэтому список собирают **после** цикла, по очереди проверяя флаги.

## Частые ошибки

Сбросить флаг в `else`: следующий символ «стирает» то, что нашли раньше.

```python
for ch in pw:
    if ch.isdigit():
        has_digit = True
    else:
        has_digit = False        # неверно: пароль "1a" покажет, что цифры нет
```

```python
for ch in pw:
    if ch.isdigit():
        has_digit = True         # верно: только поднимаем флаг, назад не опускаем
```

## Проверь себя

1. Что вернёт `find_problems("")` на шаге MP12?
2. Как изменится ответ для `"Password"` после MP14?

<details><summary>Ответ</summary>

1. `["short", "no_digit", "no_upper", "no_lower"]`: пустой пароль нарушает все четыре правила.
2. Раньше был `["no_digit"]`. Теперь `["common", "no_digit", "no_special"]`: `"password"` есть в списке известных паролей, и нет спецсимвола.

</details>
