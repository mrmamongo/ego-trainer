# Задача MP15: Совет по исправлению

## Условие

### Как это работает

Финал проекта: пользователю нужно не «плохо», а понятный **совет** по-русски. Для каждого кода проблемы есть своя фраза:

| Код | Фраза |
|---|---|
| `"common"` | `замени слишком известный пароль` |
| `"short"` | `сделай пароль не короче 8 символов` |
| `"no_digit"` | `добавь цифру` |
| `"no_upper"` | `добавь заглавную букву` |
| `"no_lower"` | `добавь строчную букву` |
| `"no_special"` | `добавь символ из !@#$%^&*` |

Шаги функции: взять `find_problems(pw)`; если пусто, вернуть похвалу; иначе в цикле собрать список фраз (сборщик, по одной на каждый код, в том же порядке). Склеить фразы через запятую поможет метод `", ".join(фразы)`. Потом вставляем всё в шаблон f-строкой:

```python
parts = ["раз", "два", "три"]
text = ", ".join(parts)           # "раз, два, три"
message = f"Считаем: {text}."     # "Считаем: раз, два, три."
```

Формат ответа (всё до последней точки совпадает буква в букву):

- нет проблем: `Пароль надёжный: всё в порядке.`
- есть проблемы: `Пароль <оценка>. Что исправить: <фразы через запятую>.`, где оценку даёт готовая `strength`.

Например, для `"Abcdefg1"` проблема одна (`no_special`), оценка «средний»:
`Пароль средний. Что исправить: добавь символ из !@#$%^&*.`

### Задание

Напиши функцию `task_mp15_suggest(pw)`: верни сообщение с советами по формату выше. Используй готовые `find_problems` и `strength`.

## Аргументы

- `pw` — пароль, строка (может быть пустой).

## Возвращает

Строку-сообщение. Сам пароль в сообщение не включай.

## Правила

- Меняй только тело функции `task_mp15_suggest`; функции и список `COMMON` из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Итоговое сообщение собери f-строкой.

## Пример

```python
task_mp15_suggest("Abcdefg1!")   # -> "Пароль надёжный: всё в порядке."
task_mp15_suggest("Abcdefg1")    # -> "Пароль средний. Что исправить: добавь символ из !@#$%^&*."
task_mp15_suggest("abcdefgh1!")  # -> "Пароль средний. Что исправить: добавь заглавную букву."
```

## Учебные цели

- Превратить коды в человеческие фразы и склеить их через `join`.
- Собрать итоговый текст f-строкой из результатов готовых функций.

## Проверка понимания

Почему в сообщение не стоит подставлять сам пароль? Что изменится в ответе, если порядок фраз не совпадёт с порядком кодов?
