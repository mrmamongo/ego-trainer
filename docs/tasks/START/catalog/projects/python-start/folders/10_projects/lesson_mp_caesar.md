# Проект «Шифр Цезаря»

Цезарь шифровал письма так: каждую букву заменял на ту, что стоит на `k` мест дальше в алфавите. При `k = 3`: `a` -> `d`, `b` -> `e`, а после `z` счёт идёт сначала: `x` -> `a`.

## Шаги проекта

| Шаг | Функция | Что нового |
|---|---|---|
| MP06 | `shift_letter(ch, k)` | сдвиг одной буквы `a`–`z`, остальное не трогаем |
| MP07 | `encode(text, k)` | цикл по тексту, регистр сохраняется |
| MP08 | `decode(text, k)` | расшифровка как шифрование с `-k` |
| MP09 | `encode(text, k)` | **изменение**: добавляем русский алфавит (33 буквы, `ё` после `е`) |
| MP10 | `crack(cipher, known_word)` | перебор всех ключей |

## Инструменты проекта

Строка-алфавит и метод `find` (MP06), `%` для зацикливания (MP06), сборка новой строки в цикле и `lower`, `upper`, `isupper` (MP07), вызов готовой функции (MP08), ещё одна ветка `if` (MP09), `range`, `in` и ранний `return` (MP10).

## Разбор шага: сдвиг по кругу

```python
alphabet = "abcdefghijklmnopqrstuvwxyz"
position = alphabet.find("y")            # 24
alphabet[(position + 3) % 26]            # (24 + 3) % 26 = 1 -> "b"
```

| Буква | position | `position + 3` | `% 26` | Результат |
|---|---|---|---|---|
| `a` | 0 | 3 | 3 | `d` |
| `y` | 24 | 27 | 1 | `b` |
| `A` | -1 (`find` не нашёл) | не считаем | | `A` без изменений |

## Строки не изменяются

Нельзя написать `text[0] = "b"`: строку нельзя поправить на месте. Собирай **новую**: `result = result + новый_символ`.

## Частые ошибки

Забыть про зацикливание: `alphabet[position + k]` падает с `IndexError`, когда сумма больше 25.

```python
return alphabet[position + k]            # неверно: для "y" и k = 3 индекс 27
```

```python
return alphabet[(position + k) % 26]     # верно: остаток возвращает в пределы 0..25
```

Ещё одна ошибка — взять длину алфавита `26` для русского текста: там `33`, и `я` при сдвиге на 1 должна стать `а`.

## Проверь себя

1. Что вернёт `shift_letter("z", 2)`?
2. Каким будет `encode("Яя", 1)` после MP09?

<details><summary>Ответ</summary>

1. `"b"`: позиция 25, `(25 + 2) % 26 = 1`.
2. `"Аа"`: после `я` русский алфавит замыкается на `а`, регистр сохраняется.

</details>
