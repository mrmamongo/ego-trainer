# Задача MP12: Список проблем пароля

## Условие

### Как это работает

Теперь проверяем пароль по нескольким правилам сразу и хотим получить **список проблем**, а не просто «плохо». Каждая проблема описана кодом (короткой строкой на английском):

| Код | Проблема |
|---|---|
| `"short"` | пароль короче 8 символов |
| `"no_digit"` | нет ни одной цифры |
| `"no_upper"` | нет ни одной заглавной буквы |
| `"no_lower"` | нет ни одной строчной буквы |

Порядок кодов в ответе **всегда такой**, как в таблице. Только так тест сможет сравнить списки.

Что искать в пароле, мы уже знаем по циклам: «есть ли хоть один такой символ» — это **флаг**. Заводим `False`, в цикле ставим `True` и больше не трогаем. Для проверки символов есть методы `ch.isdigit()`, `ch.isupper()`, `ch.islower()`.

```python
has_digit = False
for ch in pw:
    if ch.isdigit():
        has_digit = True
```

Три флага (цифра, заглавная, строчная) заполняем одним проходом по паролю. А список собираем уже **после** цикла по порядку из таблицы: `if not has_digit: problems.append("no_digit")`. Проверку длины делает готовая `check_length`.

Пример для `"abc"`: длина 3 (`short`), цифр нет (`no_digit`), заглавных нет (`no_upper`), строчные есть. Ответ: `["short", "no_digit", "no_upper"]`.

### Задание

Напиши функцию `task_mp12_find_problems(pw)`: верни список кодов найденных проблем в порядке `"short"`, `"no_digit"`, `"no_upper"`, `"no_lower"`. Если проблем нет, верни `[]`.

## Аргументы

- `pw` — пароль, строка (может быть пустой).

## Возвращает

Список строк (кодов проблем) в фиксированном порядке. Для надёжного пароля — пустой список.

## Правила

- Меняй только тело функции `task_mp12_find_problems`; функции из блока «готово с прошлого шага» не меняй, а вызывай.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Встроенные `any` и `all` не используй: пройди по символам циклом и заведи флаги.

## Пример

```python
task_mp12_find_problems("Abcdefg1")   # -> []
task_mp12_find_problems("abc")        # -> ["short", "no_digit", "no_upper"]
task_mp12_find_problems("ABCDEFGH1")  # -> ["no_lower"]
task_mp12_find_problems("")           # -> ["short", "no_digit", "no_upper", "no_lower"]
```

## Учебные цели

- Собрать три флага за один проход по строке.
- Вернуть список кодов в заданном порядке.

## Проверка понимания

Что будет, если в цикле написать `if ch.isdigit(): has_digit = True else: has_digit = False`? Какой пароль вернёт неверный результат?
