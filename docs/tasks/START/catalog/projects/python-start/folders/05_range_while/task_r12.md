# Задача R12: Цифры числа в цикле while

## Условие

### Как это работает

Бывает, что число проходов заранее неизвестно. Тогда вместо `for` берут **`while`** («пока»): тело выполняется, **пока условие истинно**. Условие проверяется перед каждым проходом, в том числе перед первым.

Цифры числа достают двумя операциями (они из первой папки):

- `n % 10` — **последняя цифра**: `507 % 10` равно `7`;
- `n // 10` — число **без последней цифры**: `507 // 10` равно `50`.

```python
n = 25                       # 1
total = 0                    # 2
while n > 0:                 # 3
    digit = n % 10           # 4
    total = total + digit    # 5
    n = n // 10              # 6
```

| Проход | digit | n после тела | total после тела |
|---|---|---|---|
| 1 | 5 | 2 | 5 |
| 2 | 2 | 0 | 7 |

После второго прохода `n` стало `0`, условие `n > 0` ложно, и цикл остановился. Это важно: **тело `while` обязано менять то, от чего зависит условие** (здесь — `n`). Иначе цикл не закончится никогда.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_r12_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что `while` проверяет условие перед каждым проходом.
- Доставать последнюю цифру через `% 10` и отбрасывать её через `// 10`.
- Видеть, как `n` уменьшается до нуля и останавливает цикл.

## Проверка понимания

Сколько проходов сделает этот цикл для `n = 40`? Что случится, если убрать строку `n = n // 10`?
