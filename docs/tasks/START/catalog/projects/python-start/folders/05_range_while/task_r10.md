# Задача R10: Потерянное последнее число

## Условие

### Как это работает

Самая частая ошибка с `range` — забыть, что **конец не входит**. Если нужны числа от `1` до `n` включительно, пишут `range(1, n + 1)`.

```python
def sum_to(n):
    total = 0
    for i in range(1, n):         # плохо: n не попадает в набор
        total = total + i
    return total
```

Для `n = 3` набор `range(1, 3)` — это `1, 2`, тройка потерялась:

| Проход | i | total после тела |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |

Вместо `6` получилось `3`. Исправление — сдвинуть конец: `range(1, n + 1)`. Ошибку такого рода называют «ошибкой на единицу». Хорошая привычка: проверить код на самом маленьком `n` (например, `n = 1`) и убедиться, что число проходов именно такое, как нужно.

### Задание

Функция `task_r10_sum_squares(n)` должна вернуть сумму квадратов `1² + 2² + ... + n²`, но результат получается меньше правильного. Найди ошибку и исправь.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Сумму квадратов всех целых от `1` до `n` включительно; для `n = 0` — `0`.

## Правила

- Исправь границу в `range`; остальной код оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_r10_sum_squares(3)   # -> 14
task_r10_sum_squares(1)   # -> 1
task_r10_sum_squares(0)   # -> 0
```

## Учебные цели

- Находить ошибку «на единицу» в конце `range`.
- Проверять границы на маленьких значениях.

## Проверка понимания
