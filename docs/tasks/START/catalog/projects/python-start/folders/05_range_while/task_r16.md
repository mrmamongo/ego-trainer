# Задача R16: Первая цифра пропала

## Условие

### Как это работает

Условие `while` решает, **будет ли ещё один проход**. Если поставить его неточно, последний проход потеряется. Посмотрим на сумму цифр с условием `n > 9`:

```python
def digit_sum(n):
    total = 0
    while n > 9:                 # плохо: однозначное n уже не проходит условие
        total = total + n % 10
        n = n // 10
    return total
```

Для `n = 507`:

| Проход | n до тела | total после | n после |
|---|---|---|---|
| 1 | 507 | 7 | 50 |
| 2 | 50 | 7 | 5 |
| (3) | 5 | — | условие `5 > 9` ложно, цикл остановился |

Цифра `5` так и не прибавилась: получилось `7` вместо `12`. Чтобы обработать **все** цифры, включая последнюю однозначную, цикл должен идти, пока в `n` что-то осталось, то есть пока `n > 0`.

Полезный приём при проверке `while`: подставь самый маленький «последний» случай (однозначное число) и посмотри, выполнится ли для него тело.

### Задание

Функция `task_r16_digit_sum(n)` должна вернуть сумму цифр числа `n`, но возвращает слишком мало. Найди ошибку и исправь.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Сумму цифр десятичной записи `n`; для `0` — `0`.

## Правила

- Исправь условие цикла; остальной код оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Функции `str` и `sum` не используй.

## Пример

```python
task_r16_digit_sum(507)   # -> 12
task_r16_digit_sum(5)     # -> 5
task_r16_digit_sum(0)     # -> 0
```

## Учебные цели

- Находить условие `while`, при котором теряется последний проход.
- Проверять цикл на однозначном числе.

## Проверка понимания

Что вернёт исходная функция для `n = 5` и для `n = 99`? Почему при условии `n > 0` цикл всё равно остановится?
