# Задача R17: Сколько лет копить

## Условие

### Как это работает

Иногда мы не знаем заранее, сколько проходов понадобится: нужно повторять, **пока цель не достигнута**. Это работа для `while`. Заводим счётчик и ведём то, что меняется:

```python
def days_to_read(pages_total, per_day):
    days = 0
    done = 0
    while done < pages_total:       # пока прочитано меньше, чем нужно
        done = done + per_day
        days = days + 1
    return days
```

| Проход | done после тела | days после тела |
|---|---|---|
| до цикла | 0 | 0 |
| 1 | 30 | 1 |
| 2 | 60 | 2 |
| 3 | 90 | 3 |
| 4 | 120 | 4 |

(для `pages_total = 100`, `per_day = 30`). Условие проверяется **до** каждого прохода, поэтому если цель уже достигнута с самого начала, тело не выполнится ни разу, и ответ равен начальному значению счётчика `0`.

Главное правило: **тело цикла должно двигать нас к остановке.** Здесь `done` растёт на положительное число, и рано или поздно условие станет ложным.

| Роль | Имя | Где заводим | Начальное значение | Как меняем в теле |
|---|---|---|---|---|
| счётчик | `years` | до цикла | `0` | `years = years + 1` |

### Задание

Напиши функцию `task_r17_years_to_target(balance, percent, target)`. Каждый год баланс растёт на процент от текущего:
`balance = balance + balance * percent // 100` (проценты целые, дробная часть отбрасывается).
Верни, через сколько лет баланс станет **не меньше** `target`. Если `target <= balance`, ответ `0`.

## Аргументы

- `balance` — начальный баланс, целое число, `balance >= 100`.
- `percent` — годовой процент, целое число, `percent >= 1`.
- `target` — желаемая сумма, целое число.

## Возвращает

Количество лет (целое число), через которое баланс станет не меньше `target`; `0`, если `target <= balance`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Параметры внутри функции менять можно.
- Нужен цикл `while`: заранее число лет неизвестно.

## Пример

```python
task_r17_years_to_target(1000, 10, 1500)   # -> 5   (1100, 1210, 1331, 1464, 1610)
task_r17_years_to_target(1000, 10, 1000)   # -> 0
task_r17_years_to_target(100, 100, 1000)   # -> 4   (200, 400, 800, 1600)
```

## Учебные цели

- Выбирать `while`, когда число проходов заранее неизвестно.
- Следить, чтобы тело двигало цикл к остановке (баланс растёт).

## Проверка понимания

Почему в условии стоит `balance < target`, а не `balance <= target`? Что изменилось бы, если бы `balance * percent // 100` всегда давало `0`?
