# for или while: что выбрать

Любой из этих циклов можно написать другим, но удобнее каждый в своём случае.

## Правило выбора

- **Число проходов известно заранее** (n раз, числа от a до b, все элементы списка) — используй `for` с `range` или списком.
- **Число проходов неизвестно** и зависит от данных (пока не достигли цели, пока остались цифры, пока не стало единицей) — используй `while`.

## Одна задача двумя способами

Сумма чисел от `1` до `n`:

```python
def sum_for(n):
    total = 0
    for i in range(1, n + 1):
        total = total + i
    return total
```

```python
def sum_while(n):
    total = 0
    i = 1
    while i <= n:
        total = total + i
        i = i + 1
    return total
```

| | `for` | `while` |
|---|---|---|
| где заводится `i` | сам `for` | до цикла: `i = 1` |
| условие остановки | `range` знает конец | `i <= n` |
| как меняется `i` | `for` подставляет следующее | тело сам: `i = i + 1` |

В `while` придётся самому завести `i`, проверить его и **не забыть увеличить**. Забудешь `i = i + 1` — цикл бесконечный. Поэтому, если можно, берут `for`: он безопаснее и короче.

## Когда `for` не подходит

Задачу «сколько раз можно разделить число на 10, пока не станет нулём» через `for` естественно не написать: число проходов заранее неизвестно.

```python
def digits_count(n):          # для n > 0
    count = 0
    while n > 0:
        count = count + 1
        n = n // 10
    return count
```

Здесь число проходов определяют сами данные, поэтому подходит именно `while`.

## Памятка

| Вопрос | Ответ |
|---|---|
| «Повтори 10 раз» | `for i in range(10)` |
| «Все числа от 1 до n» | `for i in range(1, n + 1)` |
| «Все элементы списка» | `for x in numbers` |
| «Пока не достигнем суммы» | `while` |
| «Пока остались цифры» | `while n > 0` |

## Частые ошибки

Использовать `while` там, где хватило бы `for`, и забыть увеличить счётчик:

```python
i = 1
while i <= n:
    total = total + i         # неверно: i не меняется, цикл бесконечный
```

```python
i = 1
while i <= n:
    total = total + i
    i = i + 1                 # верно: i движется к остановке
```

## Проверь себя

Какой цикл выберешь для каждой задачи?

1. Вывести квадраты чисел от 1 до 10.
2. Посчитать, сколько лет вклад будет расти, пока не достигнет цели.
3. Найти сумму цифр числа.

<details><summary>Ответ</summary>

1. `for i in range(1, 11)`: границы известны.
2. `while`: число лет заранее неизвестно.
3. `while n > 0`: число цифр определяется самим числом.

</details>
