# Задача R20: Ближайшая степень двойки

## Условие

### Как это работает

В R11 мы получали степени двойки, умножая переменную на `2` в цикле `for`. Теперь нужно умножать, **пока не дойдём до нужной величины**. Сколько раз умножать, заранее не ясно, значит, нужен `while`.

```python
def first_square_at_least(n):
    k = 1
    while k * k < n:           # пока квадрат ещё маловат
        k = k + 1
    return k
```

Идея: есть переменная-«кандидат», пока она не дотягивает до цели, меняем её. Когда условие станет ложным, кандидат подходит, и его возвращаем.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `1` | `power = power * 2` | после цикла |

Начальное значение `1` — тоже ответ: для `n = 1` тело не выполнится, и первая степень двойки, не меньшая `1`, — это сама `1`.

### Задание

Напиши функцию `task_r20_power_of_two_at_least(n)`: верни наименьшую степень двойки (`1, 2, 4, 8, ...`), которая **не меньше** `n`.

## Аргументы

- `n` — целое число, `n >= 1`.

## Возвращает

Наименьшую степень двойки, которая не меньше `n`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Оператор `**` и модуль `math` не используй: умножай на `2` в цикле `while`.

## Пример

```python
task_r20_power_of_two_at_least(5)    # -> 8
task_r20_power_of_two_at_least(8)    # -> 8
task_r20_power_of_two_at_least(1)    # -> 1
```

## Учебные цели

- Использовать `while` для поиска первого подходящего значения.
- Выбирать между `<` и `<=` в условии продолжения.
