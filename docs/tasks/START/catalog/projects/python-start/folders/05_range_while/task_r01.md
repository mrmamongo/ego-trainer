# Задача R01: Что выдаёт range(4)

## Условие

### Как это работает

До сих пор цикл `for` шёл по готовому списку. Но часто списка нет, а нужно просто **повторить действие N раз** или перебрать числа подряд.
Для этого есть `range`. Запись `range(4)` даёт числа **0, 1, 2, 3**: начинается с нуля, всего четыре штуки, а число `4` в набор **не входит**.

```python
passes = 0                   # 1
for i in range(3):           # 2
    passes = passes + 1      # 3
```

| Проход | i | passes после тела |
|---|---|---|
| 1 | 0 | 1 |
| 2 | 1 | 2 |
| 3 | 2 | 3 |

Тело выполнилось три раза, а `i` принимал значения `0, 1, 2`. Правило: **`range(n)` — это n проходов, значения от `0` до `n - 1`.**
Переменная `passes` здесь играет роль **счётчика**: на каждом проходе к ней прибавляется единица.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_r01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Знать, что `range(n)` даёт числа от `0` до `n - 1`.
- Понимать, что последнее число (`n`) в набор не входит, а проходов ровно `n`.

## Проверка понимания
