# Задача R15: Число наоборот

## Условие

### Как это работает

Чтобы «перевернуть» число, цифры берут с конца и **приписывают справа** к новому числу. Чтобы приписать цифру справа, число сначала умножают на `10` (освобождая разряд единиц), а потом прибавляют цифру:

```python
result = result * 10 + digit
```

Разберём `1230`:

| Проход | digit | result после тела | n после тела |
|---|---|---|---|
| 1 | 0 | 0 | 123 |
| 2 | 3 | 3 | 12 |
| 3 | 2 | 32 | 1 |
| 4 | 1 | 321 | 0 |

Ответ `321`. Нуль на конце исходного числа стал бы нулём в начале ответа, а у чисел нулей в начале не бывает, поэтому он просто «исчез». Это нормально.

**Паспорт роли «накопитель»** (имя `result`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `result = result * 10 + digit` | после цикла |

Накопитель опять один и тот же, меняется только формула в теле. Остальное — как в сумме цифр.

### Задание

Напиши функцию `task_r15_reverse_number(n)`: верни число, записанное теми же цифрами в обратном порядке.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Целое число с цифрами `n` в обратном порядке. Нули на конце `n` в ответе исчезают (`1230` даёт `321`); для `0` — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Работай только с числами: `while`, `% 10`, `// 10`. Функции `str`, `int` и срезы не используй.

## Пример

```python
task_r15_reverse_number(123)    # -> 321
task_r15_reverse_number(1230)   # -> 321
task_r15_reverse_number(0)      # -> 0
```

## Учебные цели

- Использовать накопитель с формулой `result * 10 + digit`.
- Понимать, как умножение на `10` сдвигает уже собранные цифры влево.

## Проверка понимания

Чему равен `result` после каждого прохода для `n = 408`? Почему для `n = 100` ответ `1`?
