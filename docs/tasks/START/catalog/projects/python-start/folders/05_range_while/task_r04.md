# Задача R04: Сумма от 1 до n

## Условие

### Как это работает

Накопитель по числам записывается так же, как накопитель по списку. Нужно только правильно выбрать границы `range`: чтобы получить все числа от `1` до `n` **включительно**, конец ставят на единицу больше — `n + 1`.

```python
def sum_to_three():
    total = 0
    for i in range(1, 4):      # 1, 2, 3
        total = total + i
    return total               # 6
```

**Паспорт роли «накопитель»** (имя `total`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + i` | после цикла |

Если `n` равно `0`, то `range(1, 1)` пуст, тело не выполнится, и вернётся начальное значение `0`: сумма пустого набора чисел равна нулю.

### Задание

Напиши функцию `task_r04_sum_to(n)`: верни сумму всех целых чисел от `1` до `n` включительно.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Сумму `1 + 2 + ... + n`; для `n = 0` — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй цикл `for` и `range`. Встроенную `sum` и формулу `n * (n + 1) // 2` не используй.

## Пример

```python
task_r04_sum_to(4)   # -> 10   (1 + 2 + 3 + 4)
task_r04_sum_to(1)   # -> 1
task_r04_sum_to(0)   # -> 0
```

## Учебные цели

- Применять накопитель в цикле по `range(1, n + 1)`.
- Помнить, что конец `range` не входит, поэтому нужен `n + 1`.
