# Задача R08: Чётные от a до b

## Условие

### Как это работает

Теперь границы приходят в параметрах: `range(a, b + 1)` даёт все числа от `a` до `b` **включительно**.
Внутри цикла можно использовать `if`, как и раньше: накопитель прибавляет число только тогда, когда оно подошло.

```python
def sum_odd(a, b):
    total = 0
    for i in range(a, b + 1):
        if i % 2 == 1:
            total = total + i
    return total
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + i` — только если число подошло | после цикла |

Это сочетание двух ролей, которые ты уже знаешь: условие «подошло» из счётчика и прибавление значения из накопителя.
Если подходящих чисел нет (например, `a = b = 3`, а нам нужны чётные), останется начальное `0`.

### Задание

Напиши функцию `task_r08_sum_even(a, b)`: верни сумму чётных чисел от `a` до `b` включительно (`a <= b`).

## Аргументы

- `a`, `b` — целые числа, `a <= b` (могут быть отрицательными).

## Возвращает

Сумму всех чётных чисел из отрезка `[a, b]` (обе границы включаются); если чётных нет — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `for` по `range(a, b + 1)` и условие `i % 2 == 0`; `sum` не используй.

## Пример

```python
task_r08_sum_even(1, 10)   # -> 30
task_r08_sum_even(3, 3)    # -> 0
task_r08_sum_even(2, 2)    # -> 2
```

## Учебные цели

- Задавать границы цикла параметрами: `range(a, b + 1)`.
- Сочетать условие и накопитель.
