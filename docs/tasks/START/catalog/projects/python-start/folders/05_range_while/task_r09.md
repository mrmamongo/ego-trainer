# Задача R09: Собери обратный отсчёт

## Условие

### Как это работает

Третье число в `range` — **шаг** — может быть и отрицательным. Тогда значения не растут, а убывают:

```python
for i in range(5, 0, -1):    # 5, 4, 3, 2, 1
    print(i)
```

| Запись | Что даёт |
|---|---|
| `range(5, 0, -1)` | `5, 4, 3, 2, 1` — вниз от `5`, пока не дойдём до `0`; **ноль не входит** |
| `range(3, 0, -1)` | `3, 2, 1` |
| `range(0, 0, -1)` | пусто: идти некуда |

Правило то же, что и раньше: начало берётся, конец — нет. Только теперь начало **больше** конца, а шаг **отрицательный**. Если при отрицательном шаге начало меньше конца (например, `range(1, 5, -1)`), набор пуст.

Результат мы будем складывать в список методом `append` (роль **сборщика**):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `[]` | `result.append(i)` | после цикла |

### Задание

В файле задачи в комментарии записаны строки функции `task_r09_countdown(n)`, но они перемешаны и без отступов.
Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали.
Функция должна вернуть список `[n, n - 1, ..., 1]`.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Новый список `[n, n - 1, ..., 1]`; для `n = 0` — `[]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_r09_countdown(3)   # -> [3, 2, 1]
task_r09_countdown(1)   # -> [1]
task_r09_countdown(0)   # -> []
```

## Учебные цели

- Читать и составлять `range` с отрицательным шагом.
- Собрать шаблон сборщика поверх `range`: `[]` до цикла, `append` в теле, `return` после цикла.
