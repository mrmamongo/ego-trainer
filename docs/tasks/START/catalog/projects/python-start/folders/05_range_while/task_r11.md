# Задача R11: Степени двойки

## Условие

### Как это работает

Иногда `range` нужен только затем, чтобы **повторить действие нужное число раз**. Сам номер прохода (`i`) тогда не используется, а нужное значение хранится в другой переменной и меняется на каждом проходе.

```python
def first_ones(k):
    result = []
    for i in range(k):         # i не нужен: важно только число проходов
        result.append(7)
    return result
```

Так получаются `k` одинаковых элементов. А если рядом завести переменную `power` и на каждом проходе **умножать** её на `2`, то в список попадут разные числа:

| Проход | в `result` добавили | `power` после тела |
|---|---|---|
| 1 | 1 | 2 |
| 2 | 2 | 4 |
| 3 | 4 | 8 |

Порядок важен: сначала добавляем текущее значение, потом увеличиваем.

| Роль | Имя | Где заводим | Начальное значение | Как меняем в теле |
|---|---|---|---|---|
| сборщик | `result` | до цикла | `[]` | `result.append(power)` |
| текущая степень | `power` | до цикла | `1` | `power = power * 2` |

Для `k = 0` цикл не выполнится, и вернётся начальное значение сборщика — пустой список.

### Задание

Напиши функцию `task_r11_powers_of_two(k)`: верни список первых `k` степеней двойки `[1, 2, 4, 8, ...]`.

## Аргументы

- `k` — целое число, `k >= 0`.

## Возвращает

Новый список из первых `k` степеней двойки, начиная с `1`; для `k = 0` — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Оператор `**` не используй: получай каждую степень умножением предыдущей на `2`.

## Пример

```python
task_r11_powers_of_two(4)   # -> [1, 2, 4, 8]
task_r11_powers_of_two(1)   # -> [1]
task_r11_powers_of_two(0)   # -> []
```

## Учебные цели

- Использовать `range(k)` как «повтори `k` раз», не обращаясь к номеру прохода.
- Вести вторую переменную, которая меняется на каждом проходе.

## Проверка понимания

Что получится, если поменять местами `append` и `power = power * 2`? Почему список начинается с `1`, а не с `2`?
