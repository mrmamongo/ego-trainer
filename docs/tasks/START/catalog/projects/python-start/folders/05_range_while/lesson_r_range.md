# range: цикл по числам

До сих пор `for` ходил по готовому списку. Но часто нужно просто **повторить действие N раз** или перебрать числа подряд. Для этого есть `range`.

## Три формы

| Запись | Что даёт | Сколько проходов |
|---|---|---|
| `range(4)` | `0, 1, 2, 3` | 4 |
| `range(2, 6)` | `2, 3, 4, 5` | 6 - 2 = 4 |
| `range(2, 11, 3)` | `2, 5, 8` | 3 |
| `range(5, 0, -1)` | `5, 4, 3, 2, 1` | 5 |

- `range(n)` — от `0` до `n - 1`;
- `range(a, b)` — от `a` до `b - 1`;
- `range(a, b, step)` — от `a` с шагом `step`, пока не дошли до `b`.

**Главное правило: начало входит, конец не входит.** Поэтому `range(1, 5)` — это `1, 2, 3, 4`, а не до пяти включительно.
Если нужны числа от `1` до `n` **включительно**, пишут `range(1, n + 1)`.

## Пустой range

Если идти некуда, набор пуст, и тело цикла не выполнится ни разу:

```python
for i in range(5, 2):      # от 5 вверх до 2? Уже пришли
    print(i)               # не выполнится
```

`range(0)` и `range(3, 3)` тоже пустые. Это как пустой список: начальное значение накопителя или счётчика станет ответом.

## Шаг

Шаг может быть отрицательным: тогда идём вниз, и начало должно быть **больше** конца.

```python
for i in range(3, 0, -1):  # 3, 2, 1  (ноль не входит)
    ...
```

## Пример с трассировкой

```python
total = 0                   # 1
for i in range(1, 4):       # 2: i = 1, 2, 3
    total = total + i       # 3
```

| Проход | i | total после тела |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |

Три прохода: `4 - 1 = 3`. Число проходов у `range(a, b)` всегда `b - a` (если `a < b`).

## range как «повтори N раз»

Если номер прохода не нужен, `range(n)` просто повторяет тело `n` раз:

```python
for i in range(3):
    ...                     # выполнится 3 раза; i здесь не используем
```

## Частые ошибки

Потерять последнее число:

```python
for i in range(1, n):       # неверно: n не попадает в набор
    total = total + i
```

```python
for i in range(1, n + 1):   # верно: от 1 до n включительно
    total = total + i
```

## Проверь себя

1. Какие значения даёт `range(3, 8)`? Сколько в нём проходов?
2. Какие значения даёт `range(10, 0, -3)`?
3. Сколько раз выполнится тело `for i in range(4, 4)`?

<details><summary>Ответ</summary>

1. `3, 4, 5, 6, 7`; проходов `8 - 3 = 5`.
2. `10, 7, 4, 1` (следующее было бы `-2`, это уже не дошли до `0`).
3. Ни разу: `range(4, 4)` пуст.

</details>
