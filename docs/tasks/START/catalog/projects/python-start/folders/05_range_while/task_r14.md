# Задача R14: Сумма цифр

## Условие

### Как это работает

Теперь в цикле по цифрам копим не количество, а **сумму самих цифр**. Это накопитель: цифру берём через `% 10`, прибавляем к `total`, а число уменьшаем через `// 10`.

Так выглядит тот же шаблон для произведения цифр (для `n >= 1`):

```python
def digit_product(n):
    product = 1
    while n > 0:
        digit = n % 10
        product = product * digit
        n = n // 10
    return product
```

**Паспорт роли «накопитель»** (имя `total`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + digit` | после цикла |

В теле три шага, и порядок важен: взять цифру, прибавить, **отрезать** (`n = n // 10`). Если забыть последний шаг, `n` никогда не станет нулём, и цикл не закончится.

Особого случая для `0` здесь нет: цикл не выполнится, а сумма цифр нуля — это `0`, то есть начальное значение накопителя. Снова работает правило «начальное значение — ответ для пустого».

### Задание

Напиши функцию `task_r14_digit_sum(n)`: верни сумму цифр числа `n`.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Сумму цифр десятичной записи `n`; для `0` — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй цикл `while`, `% 10` и `// 10`. Функции `str`, `sum` и преобразование числа в список цифр не используй.

## Пример

```python
task_r14_digit_sum(507)   # -> 12
task_r14_digit_sum(9)     # -> 9
task_r14_digit_sum(0)     # -> 0
```

## Учебные цели

- Копить в `while` не количество, а значение (цифру).
- Держать в теле правильный порядок: взять цифру, прибавить, отрезать.

## Проверка понимания

Почему для `n = 0` не нужен отдельный `if`? Что будет с циклом, если пропустить строку `n = n // 10`?
