# Задача R06: Сколько делителей

## Условие

### Как это работает

Число `d` **делит** `n` нацело, если остаток `n % d` равен нулю: `12 % 4 == 0`, а `12 % 5 == 2`.
Чтобы посчитать делители, переберём все кандидаты от `1` до `n` и будем считать подходящих. Это роль **счётчика**:

```python
def count_even_up_to(n):
    count = 0
    for i in range(1, n + 1):
        if i % 2 == 0:
            count = count + 1
    return count
```

**Паспорт роли «счётчик»** (имя `count`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` — только если число подошло | после цикла |

Здесь меняется только условие: вместо «чётное» проверяем «`n` делится на `d` без остатка». Кандидат на делитель — переменная цикла, назови её `d`.

### Задание

Напиши функцию `task_r06_count_divisors(n)`: верни, сколько у числа `n` натуральных делителей (считая `1` и само `n`).

## Аргументы

- `n` — целое число, `n >= 1`.

## Возвращает

Количество натуральных делителей `n`; для `n = 1` — `1`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Перебирай кандидатов циклом `for` по `range`; никаких формул и готовых функций для делителей.

## Пример

```python
task_r06_count_divisors(6)    # -> 4   (1, 2, 3, 6)
task_r06_count_divisors(7)    # -> 2   (1, 7)
task_r06_count_divisors(1)    # -> 1
```

## Учебные цели

- Использовать счётчик в цикле по `range(1, n + 1)`.
- Проверять делимость через остаток `n % d == 0`.

## Проверка понимания
