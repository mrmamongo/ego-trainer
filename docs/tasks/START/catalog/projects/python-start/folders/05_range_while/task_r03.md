# Задача R03: Накопитель по числам

## Условие

### Как это работает

Роли переменных те же, что и в цикле по списку, только вместо элемента списка в цикле теперь число из `range`.
Накопитель по-прежнему заводится до цикла, а в теле к нему прибавляют текущее число:

```python
total = 0                    # 1
for i in range(1, 4):        # 2: i = 1, 2, 3
    total = total + i        # 3
```

| Проход | i | total после тела |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |

Обрати внимание: `range(1, 4)` — это три прохода (`1, 2, 3`), а не четыре. Чтобы число проходов не потерять, рядом заведём **счётчик**.

| Роль | Имя | Где заводим | Начальное значение | Как меняем в теле |
|---|---|---|---|---|
| накопитель | `total` | до цикла | `0` | `total = total + i` |
| счётчик | `passes` | до цикла | `0` | `passes = passes + 1` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_r03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, как накопитель растёт при цикле по `range`.
- Связывать границы `range(a, b)` с числом проходов `b - a`.
