# Задача R13: Сколько цифр

## Условие

### Как это работает

Тот же приём «отрезаем последнюю цифру», но теперь мы их **считаем**. Это роль счётчика: на каждом проходе прибавляем единицу, а число уменьшаем.

Для примера посчитаем, сколько раз число можно разделить пополам (целочисленно), пока не получится `0`:

```python
def count_halvings(n):
    count = 0
    while n > 0:
        count = count + 1
        n = n // 2
    return count
```

| Проход | n до тела | count после | n после |
|---|---|---|---|
| 1 | 9 | 1 | 4 |
| 2 | 4 | 2 | 2 |
| 3 | 2 | 3 | 1 |
| 4 | 1 | 4 | 0 |

С цифрами то же самое, только число делим не на `2`, а на `10`: каждое `n // 10` отрезает одну цифру.

**Паспорт роли «счётчик»** (имя `count`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `count = count + 1` | после цикла |

Параметр `n` внутри функции можно менять: это обычная переменная, и на вызывающий код это не влияет.

Но есть особый случай: число `0` записывается **одной** цифрой, а условие `n > 0` для него сразу ложно, и цикл не выполнится ни разу. Начальное значение `0` дало бы неверный ответ. Поэтому такой случай разбирают отдельно, до цикла.

### Задание

Напиши функцию `task_r13_count_digits(n)`: верни, сколько цифр в записи числа `n`. Для `0` ответ `1`.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Количество цифр в десятичной записи `n`; для `0` — `1`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Считай цифры циклом `while` и операцией `// 10`. Функции `str` и `len` не используй.

## Пример

```python
task_r13_count_digits(507)   # -> 3
task_r13_count_digits(7)     # -> 1
task_r13_count_digits(0)     # -> 1
```

## Учебные цели

- Применить счётчик в цикле `while` по цифрам числа.
- Заметить особый случай `0`, на котором условие `n > 0` не срабатывает.

## Проверка понимания

Что вернула бы функция для `0` без проверки `n == 0` и почему? Сколько проходов сделает цикл для `n = 1000`?
