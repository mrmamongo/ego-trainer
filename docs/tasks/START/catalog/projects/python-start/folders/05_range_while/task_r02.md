# Задача R02: Шаг и пустой range

## Условие

### Как это работает

У `range` бывает до трёх чисел в скобках:

| Запись | Что даёт |
|---|---|
| `range(5)` | `0, 1, 2, 3, 4` — от нуля |
| `range(2, 6)` | `2, 3, 4, 5` — от `2` до `6`, **шестёрка не входит** |
| `range(2, 11, 3)` | `2, 5, 8` — от `2` с шагом `3`, пока не дойдём до `11` |

Третье число — **шаг**: на сколько увеличиваем значение. Начало берётся всегда, конец — никогда.

Если начало уже не меньше конца (при положительном шаге), набор получается **пустым**, и тело цикла не выполнится ни разу:

```python
count = 0                    # 1
for i in range(5, 2):        # 2: от 5 до 2? вперёд уже некуда
    count = count + 1        # 3: не выполнится ни разу
```

После такого цикла `count` останется `0`. Это тот же принцип, что и с пустым списком: начальное значение — ответ для пустого набора.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_r02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать `range(начало, конец, шаг)`: начало входит, конец нет.
- Узнавать пустой `range` и понимать, что тело в нём не выполнится ни разу.

## Проверка понимания

Какие значения даёт `range(1, 10, 4)`? Сколько проходов у `range(3, 3)`?
