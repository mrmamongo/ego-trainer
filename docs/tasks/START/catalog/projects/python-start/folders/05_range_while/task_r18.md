# Задача R18: Шаги Коллатца

## Условие

### Как это работает

Есть известная игра с числами: возьми любое число `n >= 1` и повторяй:

- если `n` чётное, раздели его пополам (`n // 2`);
- если нечётное, умножь на `3` и прибавь `1` (`3 * n + 1`).

Каждый раз число меняется, и (как проверено на очень больших числах) всегда в итоге получается `1`. Сколько шагов понадобится, заранее не угадать, поэтому нужен `while`.

Для `n = 6`:

| Шаг | n до | чётное? | n после |
|---|---|---|---|
| 1 | 6 | да | 3 |
| 2 | 3 | нет | 10 |
| 3 | 10 | да | 5 |
| 4 | 5 | нет | 16 |
| 5 | 16 | да | 8 |
| 6 | 8 | да | 4 |
| 7 | 4 | да | 2 |
| 8 | 2 | да | 1 |

Получилось `8` шагов. Шаблон прежний: счётчик `steps`, в теле `if` / `else` выбирает, как менять `n`, а `steps = steps + 1` выполняется на каждом проходе. Цикл идёт, пока `n != 1` (то есть пока ещё не добрались до единицы).

| Роль | Имя | Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|---|---|
| счётчик | `steps` | до цикла | `0` | `steps = steps + 1` на каждом проходе | после цикла |

Для `n = 1` тело не выполнится ни разу: ответ `0`.

### Задание

Напиши функцию `task_r18_collatz_steps(n)`: верни, за сколько шагов число `n` превратится в `1`.

## Аргументы

- `n` — целое число, `n >= 1`.

## Возвращает

Количество шагов, за которое `n` превращается в `1`; для `n = 1` — `0`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Параметр `n` внутри функции менять можно.

## Пример

```python
task_r18_collatz_steps(6)   # -> 8
task_r18_collatz_steps(2)   # -> 1
task_r18_collatz_steps(1)   # -> 0
```

## Учебные цели

- Сочетать `while`, счётчик и `if`/`else` в теле.
- Понимать, что число проходов определяется самими данными.
