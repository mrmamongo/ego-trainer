# Задача R22: НОД по Евклиду

## Условие

### Как это работает

**Наибольший общий делитель** (НОД) двух чисел — самое большое число, на которое делятся оба. У `12` и `18` это `6`.
Древний способ — **алгоритм Евклида**: пока второе число не равно нулю, заменяем пару `(a, b)` на `(b, a % b)`. Когда `b` стало `0`, ответ — `a`.

Для `a = 48`, `b = 18`:

| Проход | a до | b до | остаток `a % b` | a после | b после |
|---|---|---|---|---|---|
| 1 | 48 | 18 | 12 | 18 | 12 |
| 2 | 18 | 12 | 6 | 12 | 6 |
| 3 | 12 | 6 | 0 | 6 | 0 |

Теперь `b` равно `0`, цикл остановился, ответ — `a`, то есть `6`.

В теле нужно аккуратно поменять **обе** переменные. Чтобы не потерять старое значение, остаток сначала сохраняют отдельно:

```python
def step_example(a, b):
    remainder = a % b      # 1: считаем по ещё не изменённым a и b
    a = b                  # 2
    b = remainder          # 3
    return a, b
```

Если сделать `a = b` до расчёта остатка, получится `b % b`, то есть `0`, и всё сломается. Порядок строк здесь решает.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| параметры `a`, `b` | приходят в функцию | остаток, затем `a = b`, `b = остаток` | `a` — после цикла |

Число проходов зависит от самих чисел, поэтому нужен `while b != 0`. Каждый проход `b` строго уменьшается (остаток всегда меньше делителя), значит, цикл закончится.

### Задание

Напиши функцию `task_r22_gcd(a, b)`: верни наибольший общий делитель `a` и `b` по алгоритму Евклида.

## Аргументы

- `a`, `b` — целые числа, `a >= 0`, `b >= 0`, не равные нулю одновременно.

## Возвращает

Наибольший общий делитель `a` и `b`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- `math.gcd` и перебор всех делителей не используй: нужен цикл `while` по Евклиду.

## Пример

```python
task_r22_gcd(12, 18)   # -> 6
task_r22_gcd(7, 13)    # -> 1
task_r22_gcd(0, 5)     # -> 5
```

## Учебные цели

- Менять в теле `while` сразу две переменные, не потеряв старые значения.
- Видеть, почему цикл Евклида конечен: второе число строго убывает.
