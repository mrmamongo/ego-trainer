# Цикл while

`for` хорош, когда число проходов известно. Но бывает так: «повторяй, **пока** не случится то-то», и сколько это займёт, заранее непонятно. Для этого есть `while` («пока»).

```python
x = 20                       # 1
count = 0                    # 2
while x > 5:                 # 3
    x = x - 8                # 4
    count = count + 1        # 5
```

Как работает `while`: **перед каждым проходом** проверяется условие. Если оно верно, выполняется тело, потом проверка снова. Если ложно, цикл заканчивается и программа идёт дальше.

| Проверка | x до | условие `x > 5` | x после тела | count после |
|---|---|---|---|---|
| 1-я | 20 | верно | 12 | 1 |
| 2-я | 12 | верно | 4 | 2 |
| 3-я | 4 | ложно | цикл остановился | 2 |

Тело выполнилось **два** раза, а условие проверялось **три**: проверок всегда на одну больше. Если условие ложно с самого начала, тело не выполнится ни разу (как пустой `range`).

## Тело должно что-то менять

Условие зависит от переменных. Если тело ничего из них не меняет, условие никогда не станет ложным, и цикл **не закончится** — получится **бесконечный цикл**. Программа зависает, а проверка в тренажёре остановит её по таймауту и сообщит об ошибке.

Как это бывает:

```python
x = 20
while x > 5:
    count = count + 1       # неверно: x не меняется, условие всегда верно
```

```python
x = 20
while x > 5:
    x = x + 8               # неверно: x растёт, а условие «x > 5» от этого только вернее
```

```python
x = 20
while x > 5:
    x = x - 8               # верно: x убывает и дойдёт до 5 или ниже
    count = count + 1
```

Перед тем как запускать цикл, ответь себе на три вопроса:

1. Какая переменная входит в условие?
2. Где в теле она меняется?
3. В какую сторону: приближает ли это условие к «ложно»?

## Граница условия

Разница между `>` и `>=` заметна ровно на границе: при `x = 5` условие `x > 5` ложно (цикл остановится), а `x >= 5` — верно (будет ещё проход).

## Роли переменных те же

Счётчик, накопитель, флаг, сборщик в `while` выглядят точно так же, как в `for`: заводятся **до** цикла, меняются **в теле**, возвращаются **после**. Но кроме них в `while` обычно есть ещё переменная из условия (`x` выше), которую вы меняете сами. Для `for` это делал сам `for`.

## Частые ошибки

Забыть изменить переменную из условия — цикл бесконечный.

Поставить `return` внутри цикла без `if`: функция выйдет на первом же проходе.

## Проверь себя

```python
n = 40
steps = 0
while n > 3:
    n = n // 3
    steps = steps + 1
```

1. Чему равно `n` после каждого прохода?
2. Сколько раз проверялось условие?

<details><summary>Ответ</summary>

1. Первый проход: `40 // 3 = 13`; второй: `13 // 3 = 4`; третий: `4 // 3 = 1`. Дальше `1 > 3` ложно, остановка.
2. Условие проверялось четыре раза: три раза верно и один раз ложно. Тело выполнилось три раза, `steps = 3`.

</details>
