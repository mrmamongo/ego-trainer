# Задача R21: Цифровой корень

## Условие

### Как это работает

**Цифровой корень** получают так: считаем сумму цифр числа; если результат всё ещё не однозначный, считаем сумму цифр уже у него — и так, пока не останется одна цифра.

Для `9875`:

| Шаг | число | сумма его цифр |
|---|---|---|
| 1 | 9875 | 9 + 8 + 7 + 5 = 29 |
| 2 | 29 | 2 + 9 = 11 |
| 3 | 11 | 1 + 1 = 2 |

Число стало однозначным (`2`) и повторять больше не надо. Ответ: `2`.

Тут два цикла, и один вложен в другой:

- **внешний** `while n > 9` повторяет «посчитай сумму цифр» — пока число не однозначное;
- **внутренний** `while n > 0` — это уже знакомая сумма цифр из R14.

```python
def digital_root(n):
    while n > 9:                   # внешний: пока число не однозначное
        total = 0                  # накопитель заводим заново на каждом проходе внешнего
        while n > 0:               # внутренний: обычная сумма цифр
            total = total + n % 10
            n = n // 10
        n = total                  # теперь работаем с суммой
    return n
```

Две вещи, на которых спотыкаются: `total = 0` стоит **внутри внешнего, но до внутреннего** цикла (каждая сумма цифр считается с нуля); а `n = total` стоит **после** внутреннего цикла (иначе `n` так и остаётся `0`).

Можно проще: если уже написана функция суммы цифр, вызови её во внешнем цикле. Работает и то и другое: выбирай, что тебе понятнее.

Для однозначного `n` (включая `0`) внешнее условие `n > 9` ложно, тело не выполнится, и вернётся само `n`.

### Задание

Напиши функцию `task_r21_digital_root(n)`: верни цифровой корень числа `n`.

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Однозначное число — цифровой корень `n`; для однозначного `n` — само `n`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Работай только с числами: `while`, `% 10`, `// 10`. Функции `str`, `sum` и преобразование числа в список цифр не используй.
- Вложенный цикл разрешён; можно также написать вспомогательную функцию суммы цифр над основной.

## Пример

```python
task_r21_digital_root(38)    # -> 2   (38 -> 11 -> 2)
task_r21_digital_root(507)   # -> 3   (507 -> 12 -> 3)
task_r21_digital_root(7)     # -> 7
```

## Учебные цели

- Собрать большую задачу из уже известной (сумма цифр) внутри внешнего цикла.
- Правильно расставить инициализацию накопителя во вложенных циклах.
