# Роли переменных над числами

Роли, которые ты знаешь по спискам, работают и в цикле по `range`. Меняется только то, **откуда берётся текущий элемент**: теперь это число из `range`.
Паспорт каждой роли остаётся прежним, а главное правило тоже: **начальное значение — ответ для пустого набора**.

## Накопитель: сумма 1..n

```python
def sum_to(n):
    total = 0
    for i in range(1, n + 1):
        total = total + i
    return total
```

| Проход (n = 3) | i | total после тела |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |

Для `n = 0` набор `range(1, 1)` пуст, остаётся `0`: сумма «ничего» равна нулю.

## Накопитель-произведение: старт с 1

Если вместо суммы нужно **произведение** (например, факториал), накопитель начинают с `1`:

```python
def product_to(n):
    product = 1
    for i in range(1, n + 1):
        product = product * i
    return product
```

Для пустого набора произведение равно `1` (поэтому `0! = 1`). Начни с `0` — и всё умножится в ноль. Правило «начальное значение — ответ для пустого» подсказывает и здесь: сумма пустого — `0`, произведение пустого — `1`.

## Счётчик: сколько делителей

Число `d` делит `n`, если `n % d == 0`. Считаем подходящих:

```python
def count_even_divisors(n):
    count = 0
    for d in range(1, n + 1):
        if n % d == 0 and d % 2 == 0:
            count = count + 1
    return count
```

Счётчик прибавляет **единицу**, и только когда условие верно.

## Флаг: есть ли такое число

Для вопроса «есть ли такое?» флаг начинается с `False` и становится `True`, когда нашли. Например, «является ли `n` точным квадратом»:

```python
def is_square(n):
    found = False
    for d in range(0, n + 1):
        if d * d == n:
            found = True
    return found
```

Для вопроса «все ли такие?» (или «нет ли нарушителя?») флаг, наоборот, начинается с `True` и меняется на `False` при находке нарушителя. Так устроена проверка на простое число: нарушитель — любой делитель между `2` и `n - 1`. Если нарушителей нет (в том числе когда `range(2, n)` пуст), флаг остаётся `True`. Но числа меньше `2` простыми не считаются, их разбирают отдельно, до цикла.

## Все паспорта числового цикла

| Роль | Начальное значение | Как меняем в теле |
|---|---|---|
| накопитель-сумма | `0` | `total = total + i` |
| накопитель-произведение | `1` | `product = product * i` |
| счётчик | `0` | `count = count + 1` под `if` |
| сборщик | `[]` | `result.append(i)` |
| флаг | `False` или `True` | меняем при находке |

## Частые ошибки

Начать произведение с нуля:

```python
product = 0                       # неверно: всё умножится в 0
for i in range(1, n + 1):
    product = product * i
```

```python
product = 1                       # верно: 1 не портит произведение
```

## Проверь себя

1. С какого значения начинать накопитель, если считаешь произведение чисел от 1 до n?
2. Что вернёт функция суммы 1..n при `n = 0` и почему?
3. Какую роль взять для вопроса «сколько чисел от 1 до 20 делятся на 3»?

<details><summary>Ответ</summary>

1. С `1`: оно не меняет произведение.
2. `0`: набор `range(1, 1)` пуст, остаётся начальное значение накопителя.
3. Счётчик: `count = 0`, `count = count + 1` под условием `i % 3 == 0`.

</details>
