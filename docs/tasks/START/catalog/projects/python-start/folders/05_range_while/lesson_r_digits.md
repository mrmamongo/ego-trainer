# Цифры числа в цикле while

Достать из числа его цифры по одной позволяют две операции, знакомые по первой папке:

| Операция | Что делает | `507` |
|---|---|---|
| `n % 10` | **последняя цифра** | `7` |
| `n // 10` | число **без последней цифры** | `50` |

Если брать последнюю цифру, а потом отбрасывать её, цифры кончатся ровно тогда, когда число станет `0`. Сколько цифр в числе, заранее для программы неизвестно, поэтому здесь нужен `while n > 0`.

## Шаблон

```python
while n > 0:
    digit = n % 10      # взять последнюю цифру
    ...                 # что-то с ней сделать
    n = n // 10         # отбросить её
```

Эти три шага нужны почти в каждой задаче про цифры. Что именно делать с `digit` — решает роль переменной.

## Сумма цифр (накопитель)

```python
n = 507                      # 1
total = 0                    # 2
while n > 0:                 # 3
    digit = n % 10           # 4
    total = total + digit    # 5
    n = n // 10              # 6
```

| Проход | digit | n после тела | total после тела |
|---|---|---|---|
| 1 | 7 | 50 | 7 |
| 2 | 0 | 5 | 7 |
| 3 | 5 | 0 | 12 |

После третьего прохода `n` равно `0`, и цикл остановился.

## Количество цифр (счётчик)

Вместо `total = total + digit` пишем `count = count + 1`. Сама цифра не нужна, нужен только факт «ещё одна цифра». Но тут есть особый случай: число `0` записывается одной цифрой, а `while 0 > 0` не выполнится ни разу. Поэтому для `0` ответ задают отдельно, до цикла.

## Число наоборот (накопитель с формулой)

```python
result = result * 10 + digit
```

Умножение на `10` сдвигает уже собранные цифры влево, а `digit` встаёт в разряд единиц. Для `123` получится `3`, потом `32`, потом `321`.

## Частые ошибки

Забыть `n = n // 10` — число не уменьшается, цикл бесконечный.

Поставить условие `n > 9` вместо `n > 0` — последняя цифра теряется:

```python
while n > 9:              # неверно: однозначное n уже не проходит
    total = total + n % 10
    n = n // 10
```

```python
while n > 0:              # верно: пока в n остались цифры
```

Для `507` с условием `n > 9` получится `7` вместо `12`.

## Проверь себя

1. Что получится после `d = 4096 % 10` и `m = 4096 // 10`?
2. Сколько проходов сделает цикл `while n > 0` с отрезанием цифры для `n = 90`?
3. Чему равна сумма цифр числа `0` в такой схеме и почему?

<details><summary>Ответ</summary>

1. `d = 6`, `m = 409`.
2. Два: `90` -> `9` -> `0`.
3. `0`: цикл не выполнится, остаётся начальное значение накопителя.

</details>
