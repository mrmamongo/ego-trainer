# Задача R19: Когда условие ложно

## Условие

### Как это работает

Условие `while` проверяется **перед каждым проходом, включая тот, после которого цикл заканчивается**. Если на проверке условие ложно, тело не выполняется, и программа идёт дальше.

```python
x = 20                        # 1
count = 0                     # 2
while x > 5:                  # 3
    x = x - 8                 # 4
    count = count + 1         # 5
```

| Проверка `x > 5` | x до тела | тело выполнилось? | x после | count после |
|---|---|---|---|---|
| 1-я | 20 | да | 12 | 1 |
| 2-я | 12 | да | 4 | 2 |
| 3-я | 4 | нет, `4 > 5` ложно | 4 | 2 |

Проверок было **три**, а проходов тела — **два**: последняя проверка нашла ложь и остановила цикл. Проверок всегда на одну больше, чем проходов.
Обрати внимание и на границу: если бы `x` стало ровно `5`, условие `5 > 5` тоже было бы ложным.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`.
Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть,
что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный:
найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_r19_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что условие `while` проверяется перед каждым проходом и один раз сверх числа проходов.
- Замечать границу: при `x = 10` условие `x > 10` уже ложно.

## Проверка понимания

Сколько проходов сделал бы цикл, если бы условие было `x >= 10`? Сколько проверок условия при этом было бы?
