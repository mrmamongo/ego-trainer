# Задача R07: Простое число

## Условие

### Как это работает

Число **простое**, если у него ровно два делителя: `1` и оно само (`2, 3, 5, 7, 11, ...`). Единица и всё, что меньше, простыми не считаются.
Чтобы это проверить, достаточно поискать делитель среди чисел от `2` до `n - 1`. Нашли хоть один — число составное. Это роль **флага**: сначала «считаем простым», а при находке делителя меняем на «нет».

```python
def all_positive(numbers):
    all_ok = True
    for number in numbers:
        if number <= 0:
            all_ok = False
    return all_ok
```

**Паспорт роли «флаг»** (имя `is_prime`, флаг «наоборот», как `all_ok`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `True` («пока делителей не нашли») | `is_prime = False` — когда нашли делитель | после цикла |

Для `n = 2` и `n = 3` диапазон `range(2, n)` пуст или не содержит делителей, флаг остаётся `True`: они простые. Числа меньше `2` обрабатываем отдельно, до цикла: сразу `return False`.

### Задание

Напиши функцию `task_r07_is_prime(n)`: верни `True`, если `n` — простое число, и `False` иначе.

## Аргументы

- `n` — целое число (может быть отрицательным или нулём).

## Возвращает

`True`, если `n` — простое число; иначе `False`. Для `n < 2` ответ `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Ищи делитель циклом по `range(2, n)`; готовых проверок простоты не используй.

## Пример

```python
task_r07_is_prime(7)    # -> True
task_r07_is_prime(9)    # -> False
task_r07_is_prime(1)    # -> False
task_r07_is_prime(2)    # -> True
```

## Учебные цели

- Применить флаг «наоборот» (`True` по умолчанию) в цикле по `range`.
- Не забыть про границы: числа меньше `2` не простые, у `2` цикл пуст.

## Проверка понимания
