# Задача R05: Факториал

## Условие

### Как это работает

**Факториал** числа `n` — это произведение всех целых чисел от `1` до `n`: `5! = 1 * 2 * 3 * 4 * 5 = 120`.
Это снова накопитель, только он не складывает, а **умножает**. И начинать его надо не с `0`, а с `1`:

```python
def product_to_three():
    product = 1
    for i in range(1, 4):         # 1, 2, 3
        product = product * i
    return product                # 6
```

| Проход | i | product после тела |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 6 |

Если начать с `0`, то любое произведение останется нулём. А `1` не меняет произведение: это «нейтральный» элемент для умножения.

**Паспорт роли «накопитель-произведение»** (имя `product`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `1` | `product = product * i` | после цикла |

Правило прежнее: **начальное значение — ответ для пустого набора.** Для `n = 0` набор `range(1, 1)` пуст, цикл не выполнится, и вернётся `1`. Так и надо: по определению `0! = 1`.

### Задание

Напиши функцию `task_r05_factorial(n)`: верни `n!` (произведение всех целых от `1` до `n`).

## Аргументы

- `n` — целое число, `n >= 0`.

## Возвращает

Целое число `n!`; для `n = 0` — `1`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- `math.factorial` и рекурсию не используй: только цикл `for` и `range`.

## Пример

```python
task_r05_factorial(4)   # -> 24   (1 * 2 * 3 * 4)
task_r05_factorial(1)   # -> 1
task_r05_factorial(0)   # -> 1
```

## Учебные цели

- Перенести идею накопителя с суммы на произведение.
- Выбрать начальное значение `1` как ответ для пустого набора множителей.

## Проверка понимания

Что вернёт функция, если начать с `product = 0`? Почему для `n = 0` правильный ответ `1`, а не `0`?
