# Сортировка словаря: sorted и key

Сам словарь не сортируют: он помнит порядок добавления. Сортируют **список** из ключей или пар, который получают из словаря.

```python
stock = {"яблоки": 5, "груши": 2, "сливы": 9}
```

| Запись | Что получится |
|---|---|
| `sorted(stock)` | список **ключей** по алфавиту: `["груши", "сливы", "яблоки"]` |
| `sorted(stock.items())` | список **пар** `(ключ, значение)`, упорядоченный по ключу |
| `sorted(stock.items(), key=...)` | пары, упорядоченные по тому, что вернёт `key` |

`sorted` возвращает **новый** список и не трогает словарь.

## key= и lambda

По умолчанию пары сравниваются по первому элементу, то есть по ключу. А нам часто нужно по значению. Для этого в `key=` передают маленькую функцию, которая из элемента достаёт «что сравнивать». Короткую функцию без имени записывают словом `lambda`:

```python
sorted(stock.items(), key=lambda kv: kv[1])
```

Читается так: «для пары `kv` сравнивай `kv[1]`», то есть значение (`kv[0]` — ключ). Слово `lambda` в этой папке нужно **только** для `key=`; других применений пока не будет.

```python
pairs = sorted(stock.items(), key=lambda kv: kv[1])
# [("груши", 2), ("яблоки", 5), ("сливы", 9)]
```

Результат — список пар (кортежей). Первая пара: `pairs[0]`, её ключ `pairs[0][0]`, её значение `pairs[0][1]`.

## По убыванию

```python
sorted(stock.items(), key=lambda kv: kv[1], reverse=True)
# [("сливы", 9), ("яблоки", 5), ("груши", 2)]
```

## Равные ключи сохраняют порядок

Сортировка **устойчива**: элементы с одинаковым ключом остаются в том порядке, в каком были в словаре (а значит, в порядке добавления). Это верно и с `reverse=True`: равные по значению пары не переворачиваются.

```python
d = {"b": 1, "a": 1, "c": 0}
sorted(d.items(), key=lambda kv: kv[1])    # [("c", 0), ("b", 1), ("a", 1)]
```

Пары `"b"` и `"a"` равны по значению `1`, поэтому `"b"` остаётся перед `"a"`, как в словаре.

## Два критерия: сначала по значению, потом по имени

Чтобы при равных значениях был порядок по алфавиту, сделай ключом пару `(что главное, что второе)`. Для убывания числа поставь перед ним минус:

```python
sorted(d.items(), key=lambda kv: (-kv[1], kv[0]))
# значение по убыванию, при равенстве ключ по алфавиту
```

Минус работает только с числами. Строки так «перевернуть» нельзя, для них используют `reverse=True` на всей сортировке.

## Сортировка списка словарей

Для списка словарей `key` достаёт поле:

```python
users = [{"name": "Боря", "level": 2}, {"name": "Аня", "level": 2}]
sorted(users, key=lambda user: (-user["level"], user["name"]))
```

Входной список при этом не меняется, пока ты используешь `sorted`, а не `users.sort()`.

## Частые ошибки

Ждать, что сортировка изменит словарь: `sorted(stock)` возвращает список ключей, сам `stock` остаётся прежним.

Забыть скобки в `key=lambda kv: kv[1]` или поставить вызов: `key=kv[1]` не сработает, `key` ждёт функцию.

Сравнить `sorted(d)` и `sorted(d.items())`: в первом только ключи, во втором пары.

## Проверь себя

```python
d = {"x": 3, "y": 1, "z": 3}
a = sorted(d.items(), key=lambda kv: kv[1])
b = sorted(d.items(), key=lambda kv: (-kv[1], kv[0]))
```

1. Что за ключ в `a[0]`?
2. Чему равен `b`?

<details><summary>Ответ</summary>

1. `"y"`: у него наименьшее значение `1`.
2. `[("x", 3), ("z", 3), ("y", 1)]`: по убыванию значения, а `"x"` и `"z"` равны, поэтому по алфавиту.

</details>
