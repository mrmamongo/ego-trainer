# Задача DI01: Читаем и меняем словарь

## Условие

### Как это работает

Словарь хранит пары «ключ → значение». Значение достают по ключу в квадратных скобках, а запись `d[k] = v` либо добавляет пару, либо заменяет значение.

```python
stock = {"яблоки": 5}      # 1
a = stock["яблоки"]        # 2
b = stock.get("киви", 0)   # 3
stock["киви"] = 7          # 4
c = "киви" in stock        # 5
```

| После строки | stock | Что получилось |
|---|---|---|
| 1 | `{"яблоки": 5}` | |
| 2 | не менялся | `a` равно `5` |
| 3 | не менялся | `b` равно `0`: ключа нет, вернулось запасное значение |
| 4 | `{"яблоки": 5, "киви": 7}` | добавили новую пару |
| 5 | не менялся | `c` равно `True` |

Слово `in` проверяет **ключи**, а не значения.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_di01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать значение по ключу и через `get` с запасным значением.
- Отличать проверку ключа через `in` от поиска значения.
- Видеть, как присваивание по ключу меняет словарь.

## Проверка понимания
