# Задача DI14: Активные пользователи

## Условие

### Как это работает

Список словарей обходят обычным циклом: на каждом проходе `user` — это словарь, и его поля берут по ключу. Сборщик с условием по полю:

```python
def big_levels(users, limit):
    result = []
    for user in users:
        if user["level"] > limit:
            result.append(user["name"])
    return result
```

В результат кладём не весь словарь, а нужное поле: `user["name"]`. Порядок остаётся таким же, как во входном списке.

### Задание

Напиши функцию `task_di14_active_names(users)`: верни список имён тех пользователей, у которых `"active"` равно `True`, в исходном порядке.

## Аргументы

- `users` — список словарей `{"name": строка, "level": целое, "active": True или False}` (может быть пустым).

## Возвращает

Список имён активных пользователей в исходном порядке; если таких нет — `[]`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `users` и словари в нём менять нельзя.

## Пример

```python
task_di14_active_names([{"name": "Аня", "level": 3, "active": True}, {"name": "Боря", "level": 1, "active": False}])   # -> ["Аня"]
task_di14_active_names([])   # -> []
```

## Учебные цели

- Обойти список словарей и взять поле по ключу.
- Применить сборщик с условием по полю словаря.

## Проверка понимания

Что вернёт функция, если ни у кого нет `"active": True`? Что бы изменилось, если бы мы клали в результат `user`, а не `user["name"]`?
