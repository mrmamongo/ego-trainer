# Задача DI08: Собери группировку по первой букве

## Условие

### Как это работает

Чтобы разложить элементы по группам, значением в словаре делают **список**. При первой встрече ключа нужно создать пустой список, иначе `append` будет не к чему применять:

```python
groups = {}
for number in numbers:
    key = number % 2
    if key not in groups:
        groups[key] = []
    groups[key].append(number)
```

**Паспорт роли «группировщик»** (имя `result`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | если ключа нет: `result[key] = []`; затем `result[key].append(item)` | после цикла |

**Отступы** показывают вложенность: `result[key] = []` стоит под `if`, а `if` и `append` — под `for`.

### Задание

В файле задачи в комментарии записаны строки функции `task_di08_group_by_first(words)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция должна разложить слова по первой букве.

## Аргументы

- `words` — список непустых строк (может быть пустым).

## Возвращает

Словарь «первая буква → список слов на эту букву» в порядке появления слов; для пустого списка `{}`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.

## Пример

```python
task_di08_group_by_first(["ананас", "банан", "арбуз"])   # -> {"а": ["ананас", "арбуз"], "б": ["банан"]}
task_di08_group_by_first([])                            # -> {}
```

## Учебные цели

- Собрать шаблон группировщика: `{}` до цикла, создание списка при первой встрече, `append`, `return` после цикла.
- Увидеть, где место для отступов в цикле с `if`.

## Проверка понимания
