# Задача DI11: Расходы по категориям

## Условие

### Как это работает

Счётчик может копить не `1`, а **значение**: тогда это счётчик и накопитель вместе. Главная строка:

```python
totals[category] = totals.get(category, 0) + amount
```

| Проход | запись | totals после тела |
|---|---|---|
| 1 | `[100, "еда"]` | `{"еда": 100}` |
| 2 | `[50, "еда"]` | `{"еда": 150}` |
| 3 | `[30, "транспорт"]` | `{"еда": 150, "транспорт": 30}` |

Запись `[сумма, категория]` раскладывается прямо в заголовке цикла: `for amount, category in entries`, как пара из `items()`. Это ровно данные проекта «Расходы».

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | `totals[cat] = totals.get(cat, 0) + amount` | после цикла |

### Задание

Напиши функцию `task_di11_total_by_category(entries)`: верни словарь «категория → общая сумма расходов в этой категории».

## Аргументы

- `entries` — список записей `[сумма, категория]`; сумма — целое число, категория — строка (список может быть пустым).

## Возвращает

Словарь «категория → сумма всех расходов этой категории»; для пустого списка `{}`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `Counter`, модуль `collections` и `setdefault`: словарь нужно собрать самому.
- Входные данные менять нельзя.

## Пример

```python
task_di11_total_by_category([[100, "еда"], [50, "еда"], [30, "транспорт"]])
# -> {"еда": 150, "транспорт": 30}
task_di11_total_by_category([])   # -> {}
```

## Учебные цели

- Накапливать суммы по ключам словаря.
- Читать запись `[сумма, категория]` как пару значений в цикле.

## Проверка понимания

Что вернёт функция для `[]`? Почему слово `get` здесь нужно, а `totals[category] + amount` не подходит?
