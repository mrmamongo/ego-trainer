# Задача DI06: Сколько раз слово

## Условие

### Как это работает

Для слов нужен словарь-**счётчик**: ключ — слово, значение — сколько раз оно встретилось. Главная строка цикла:

```python
counts[word] = counts.get(word, 0) + 1
```

`counts.get(word, 0)` даёт прежнее число (или `0` для нового слова), к нему прибавляется `1`.

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | `counts[key] = counts.get(key, 0) + 1` | после цикла |

Список слов из строки получается так: `"да нет да".split()` даёт `["да", "нет", "да"]`.

### Задание

Напиши функцию `task_di06_count_words(text)`: верни словарь «слово → сколько раз оно встретилось в `text`». Слова разделены пробелами.

## Аргументы

- `text` — строка из слов в нижнем регистре, разделённых пробелами (может быть пустой).

## Возвращает

Словарь, где ключ — слово, значение — число его появлений; для пустой строки `{}`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `Counter`, модуль `collections` и метод `count`: счётчик нужно написать самому.
- Входные данные менять нельзя.

## Пример

```python
task_di06_count_words("да нет да")   # -> {"да": 2, "нет": 1}
task_di06_count_words("один")       # -> {"один": 1}
task_di06_count_words("")           # -> {}
```

## Учебные цели

- Собрать счётчик на словаре: `{}` до цикла и `get(key, 0) + 1` в теле.
- Помнить, что начальное значение счётчика — ответ для пустых данных.

## Проверка понимания

Что вернёт функция для пустой строки? Что будет, если написать `counts[word] = counts[word] + 1`?
