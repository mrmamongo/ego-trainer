# Индекс: быстрый поиск по id

Допустим, есть список пользователей и нужно много раз искать одного по `id`. Если каждый раз обходить весь список, придётся перебирать его заново. Лучше **один раз** построить словарь `id → пользователь` и дальше искать за один шаг.

```python
users = [{"id": 1, "name": "Аня"}, {"id": 2, "name": "Боря"}]

def index_by_id(users):
    by_id = {}                         # 1
    for user in users:                 # 2
        by_id[user["id"]] = user       # 3
    return by_id                       # 4
```

| Проход | user | by_id после тела |
|---|---|---|
| 1 | `{"id": 1, "name": "Аня"}` | `{1: {"id": 1, "name": "Аня"}}` |
| 2 | `{"id": 2, "name": "Боря"}` | `{1: {...Аня}, 2: {...Боря}}` |

Теперь `by_id[2]["name"]` даёт `"Боря"` без перебора.

## Паспорт роли «индекс»

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла, **один раз** | `{}` | `by_id[item["id"]] = item` | после цикла |

## Что важно знать

- **Строим один раз, а не внутри поиска.** Если построить индекс при каждом обращении, выигрыша нет.
- **Значение в индексе — тот же объект, что в списке.** Индекс не копирует пользователей, он лишь хранит на них ссылки. Изменишь `by_id[1]["name"]` — изменится и пользователь в исходном списке. Подробнее в карточке про копии.
- **Ключ должен быть уникален.** Если у двух пользователей один `id`, второй затрёт первого. Для индекса это нормально, если `id` уникальны по условию.
- **Не найден ключ.** `by_id[9]` упадёт с `KeyError`, а `by_id.get(9)` вернёт `None`. Заранее проверить можно через `9 in by_id`.

## Частые ошибки

Записать в значение только имя, когда нужен весь объект:

```python
by_id[user["id"]] = user["name"]     # так получится индекс имён, а не пользователей
```

Строить индекс внутри цикла по запросам:

```python
for wanted in wanted_ids:
    by_id = {}                       # неверно: каждый раз строим заново и теряем смысл
    ...
```

## Проверь себя

```python
by_id = {}
for user in [{"id": 5, "name": "Вика"}, {"id": 8, "name": "Гена"}]:
    by_id[user["id"]] = user
```

1. Что вернёт `by_id[8]["name"]`?
2. Что вернёт `by_id.get(1)`?

<details><summary>Ответ</summary>

1. `"Гена"`.
2. `None`: пользователя с `id` 1 нет, а `get` не падает.

</details>
