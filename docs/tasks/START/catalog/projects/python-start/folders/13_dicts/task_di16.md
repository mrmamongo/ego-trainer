# Задача DI16: Склад: добавить товар

## Условие

### Как это работает

Функция не должна менять переданный склад. Поэтому сначала строят **новый** словарь с теми же парами, и только потом меняют его:

```python
def with_price(prices, item, price):
    result = {}
    for key, value in prices.items():
        result[key] = value
    result[item] = price
    return result
```

Короткая запись того же копирования: `result = dict(prices)`. У словаря с числами в значениях копия верхнего уровня — полноценная копия: числа неизменяемы и делить нечего.

| Где заводим | Начальное значение | Как меняем | Когда возвращаем |
|---|---|---|---|
| до изменений | копия входного словаря | `result[item] = ...` | в конце |

Проверка сравнивает склад до и после вызова: изменение входного словаря она заметит.

### Задание

Напиши функцию `task_di16_inventory_add(inventory, item, qty)`: верни **новый** словарь-склад, в котором количество товара `item` увеличено на `qty` (если товара не было, то стало `qty`). Исходный `inventory` менять нельзя.

## Аргументы

- `inventory` — словарь «товар → количество» (целые числа, может быть пустым).
- `item` — название товара (строка).
- `qty` — сколько добавить, целое число больше нуля.

## Возвращает

Новый словарь-склад с увеличенным количеством товара `item`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Входной словарь `inventory` менять нельзя, результат должен быть другим объектом.

## Пример

```python
task_di16_inventory_add({"яблоки": 5}, "яблоки", 3)   # -> {"яблоки": 8}
task_di16_inventory_add({"яблоки": 5}, "груши", 2)   # -> {"яблоки": 5, "груши": 2}
task_di16_inventory_add({}, "чай", 1)                # -> {"чай": 1}
```

## Учебные цели

- Не менять входной словарь: сначала копия, потом изменение.
- Увеличивать значение по ключу с запасным `0` для нового товара.

## Проверка понимания

Что получится, если изменять сам `inventory` и вернуть его? Почему тест это заметит, даже если ответ выглядит правильно?
