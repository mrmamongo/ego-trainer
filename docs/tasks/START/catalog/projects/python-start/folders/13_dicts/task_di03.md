# Задача DI03: Склад падает на новом товаре

## Условие

### Как это работает

Чтение по ключу `stock[item]` работает только для ключей, которые уже есть. Для нового ключа Python остановит программу ошибкой `KeyError`:

```python
def total_stock(stock, items):
    total = 0
    for item in items:
        total = total + stock[item]    # падает, если товара нет на складе
    return total
```

| Проход | item | что происходит |
|---|---|---|
| 1 | `"яблоки"` | ключ есть, `total` растёт |
| 2 | `"киви"` | ключа нет: `KeyError`, программа остановилась |

Нужно, чтобы отсутствующий товар считался как `0`. Это ровно то, что делает `stock.get(item, 0)`.

### Задание

Функция `task_di03_total_stock(stock, items)` должна вернуть общее количество товаров из списка `items`, но падает с `KeyError`, если какого-то товара нет на складе. Найди ошибку и исправь: отсутствующий товар считается как `0`.

## Аргументы

- `stock` — словарь «товар → количество на складе» (целые числа от 0, может быть пустым).
- `items` — список названий товаров (может быть пустым, названия могут повторяться).

## Возвращает

Целое число: сумма количеств по всем названиям из `items`; товара нет на складе — считай `0`.

## Правила

- Менять нужно способ чтения значения; остальной код оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Словарь `stock` и список `items` менять нельзя.

## Пример

```python
task_di03_total_stock({"яблоки": 5, "груши": 2}, ["яблоки", "груши"])   # -> 7
task_di03_total_stock({"яблоки": 5}, ["яблоки", "киви"])             # -> 5
task_di03_total_stock({}, [])                                         # -> 0
```

## Учебные цели

- Узнавать `KeyError` от чтения несуществующего ключа.
- Заменять `d[k]` на `d.get(k, запасное)` там, где ключа может не быть.
