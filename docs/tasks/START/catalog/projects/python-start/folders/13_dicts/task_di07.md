# Задача DI07: Частоты букв

## Условие

### Как это работает

Счётчик не обязан считать слова: ключом может быть любой элемент. Строка в цикле `for` отдаёт буквы по одной, поэтому тот же приём считает буквы:

```python
counts = {}
for letter in word:
    counts[letter] = counts.get(letter, 0) + 1
```

| Проход | letter | counts после тела |
|---|---|---|
| 1 | `"о"` | `{"о": 1}` |
| 2 | `"к"` | `{"о": 1, "к": 1}` |
| 3 | `"о"` | `{"о": 2, "к": 1}` |

Ключ в словаре — буква, значение — сколько раз она встретилась.

### Задание

Напиши функцию `task_di07_letter_freq(word)`: верни словарь «буква → сколько раз она есть в слове `word`».

## Аргументы

- `word` — строка (может быть пустой).

## Возвращает

Словарь «буква → число вхождений»; для пустой строки `{}`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `Counter`, модуль `collections` и метод `count`: счётчик нужно написать самому.
- Входные данные менять нельзя.

## Пример

```python
task_di07_letter_freq("банан")   # -> {"б": 1, "а": 2, "н": 2}
task_di07_letter_freq("ааа")     # -> {"а": 3}
task_di07_letter_freq("")        # -> {}
```

## Учебные цели

- Применить счётчик к буквам строки.
- Увидеть, что счётчик не зависит от типа ключа.

## Проверка понимания

Что вернёт функция для `""`? Что в ответе для слова `"ааа"`?
