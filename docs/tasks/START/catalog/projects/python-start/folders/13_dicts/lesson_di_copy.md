# Копии словарей: b = a и неглубокая копия

Это главная карточка папки. В продуктовых задачах чаще всего ломается именно это: **одно изменение «протекает» туда, где его не ждали.** Из карточки про списки ты уже знаешь, что `b = a` не копия. Со словарями то же самое, но с одним новым подвохом.

## Словарь изменяем: b = a — второй ярлык

```python
a = {"lang": "ru"}       # 1
b = a                    # 2
b["lang"] = "en"         # 3
```

После строки 3 и `a`, и `b` равны `{"lang": "en"}`: словарь один, у него два имени. Проверить, что это один и тот же объект, можно через `is`: `a is b` даёт `True`. А `==` сравнивает только содержимое: у двух разных словарей с одинаковым содержимым `==` даст `True`, а `is` даст `False`.

## Копия: dict(a) и a.copy()

```python
c = dict(a)       # новый словарь с теми же парами
d = a.copy()      # то же самое
```

Теперь `c["lang"] = "de"` не затронет `a`. Но у этой копии есть оговорка.

## Копия неглубокая

`dict(a)` и `a.copy()` копируют только **верхний уровень**. Если значение внутри само изменяемое (список или словарь), то в копию попадает **та же** вложенная коробка, а не её копия.

```python
template = {"lang": "ru", "tags": ["new"]}     # 1
clone = dict(template)                         # 2
clone["lang"] = "fr"                           # 3
clone["tags"].append("vip")                    # 4
```

| После строки | template | clone | Что с вложенным списком |
|---|---|---|---|
| 1 | `{"lang": "ru", "tags": ["new"]}` | — | один список `["new"]` |
| 2 | не менялся | новый словарь с теми же парами | **тот же** список в обоих |
| 3 | `lang` остался `"ru"` | `lang` стал `"fr"` | не менялся |
| 4 | `tags` стал `["new", "vip"]` | `tags` тоже `["new", "vip"]` | общий список изменили через `clone` |

Вывод: значения верхнего уровня (`lang`) копируются честно, а вложенный список `tags` остаётся общим. Так «изменил копию, а испортил оригинал» приходит через вложенные данные.

## Два пользователя на одном словаре

Та же беда бывает без всяких копий: два пользователя могут ссылаться на **один** внутренний словарь, например потому, что настройки подставили из общего шаблона.

```python
shared = {"language": "ru"}                                  # 1
profiles = {"A": {"prefs": shared}, "B": {"prefs": shared}}  # 2
profiles["A"]["prefs"]["language"] = "en"                    # 3
```

| После строки | `profiles["A"]["prefs"]` | `profiles["B"]["prefs"]` | Сколько словарей настроек |
|---|---|---|---|
| 1 | — | — | 1 (`shared`) |
| 2 | `{"language": "ru"}` | `{"language": "ru"}` | 1: оба профиля указывают на него |
| 3 | `{"language": "en"}` | `{"language": "en"}` | 1: сменили у A, а язык B изменился тоже |

Менять нужно не общий словарь, а **собственную копию** настроек пользователя A.

## Как копировать вложенные данные вручную

Нужно скопировать **каждый изменяемый уровень**, который собираешься менять. Для словаря словарей:

```python
def copy_profiles(profiles):
    result = {}
    for name, profile in profiles.items():
        new_profile = dict(profile)                   # копия профиля
        new_profile["prefs"] = dict(profile["prefs"]) # копия вложенного словаря
        result[name] = new_profile
    return result
```

Для словаря списков, например `{"а": [1, 2]}`:

```python
{key: list(value) for key, value in data.items()}
```

Это **словарное выражение**: фигурные скобки, пара `ключ: значение` и `for` в конце, как у списочного выражения. Результат тот же, что у цикла с `result[key] = list(value)`.

Правило: **если глубина данных два уровня, копируй два уровня.** Для трёх уровней нужно копировать и третий.

## «Не меняй входные данные»

В задачах платформы это условие по умолчанию, пока не сказано иначе: функция не должна менять ни переданный словарь, ни его вложенные списки и словари. Если нужно изменить, **собери новую структуру**: скопируй те уровни, которые меняешь, и меняй уже копии. Проверка сравнивает данные до и после вызова и ловит даже скрытую порчу вложенных списков.

## Частые ошибки

Думать, что `dict(a)` защищает вложенное:

```python
result = dict(profiles)
result[user]["prefs"]["language"] = "en"     # неверно: внутренние словари общие с profiles
```

```python
profile = dict(profiles[user])
profile["prefs"] = dict(profile["prefs"])    # верно: копируем и профиль, и его prefs
profile["prefs"]["language"] = "en"
```

Скопировать верхний уровень, а менять вложенный список через `append`: оригинал получит лишний элемент.

## Проверь себя

```python
a = {"items": [1, 2]}
b = dict(a)
b["items"].append(3)
c = {"items": list(a["items"])}
c["items"].append(4)
```

1. Чему равен `a["items"]` в конце?
2. Что общего у `a` и `b`, а что у `a` и `c`?

<details><summary>Ответ</summary>

1. `[1, 2, 3]`. Тройку добавили через `b`, потому что список `items` общий у `a` и `b`; четвёрка попала только в `c`.
2. `a` и `b` — разные словари, но с **одним** списком внутри. `c` — отдельный словарь и отдельный список, поэтому `a` на него не влияет.

</details>
