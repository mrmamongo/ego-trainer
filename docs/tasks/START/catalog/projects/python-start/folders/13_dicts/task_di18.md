# Задача DI18: Один словарь, два имени

## Условие

### Как это работает

Запомни две вещи.

1. **Присваивание не копирует.** Если два имени (или два места в структуре) указывают на один словарь, то изменение через одно видно через другое.
2. **`dict(x)` копирует только верхний уровень.** Вложенные списки и словари остаются общими.

```python
shared = {"n": 1}                     # 1
pair = [shared, shared]               # 2
pair[0]["n"] = 5                      # 3
copy = dict(shared)                   # 4
copy["n"] = 9                         # 5
```

| После строки | `shared` | `pair[1]` | `copy` |
|---|---|---|---|
| 1 | `{"n": 1}` | — | — |
| 2 | `{"n": 1}` | тот же словарь | — |
| 3 | `{"n": 5}` | `{"n": 5}` | — |
| 4 | `{"n": 5}` | `{"n": 5}` | новый словарь `{"n": 5}` |
| 5 | `{"n": 5}` | `{"n": 5}` | `{"n": 9}` |

Выражение `x is y` отвечает `True`, только если `x` и `y` — один и тот же объект, а не просто равные.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Рисуй «коробки»: сколько всего словарей и списков создано и кто на них указывает.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_di18_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, что два пользователя могут указывать на один вложенный словарь.
- Понимать, что `dict(x)` не копирует вложенные списки и словари.
- Отличать `is` («тот же объект») от равенства значений.
