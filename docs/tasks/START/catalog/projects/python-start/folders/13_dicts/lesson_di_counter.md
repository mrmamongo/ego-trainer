# Счётчик: counts[k] = counts.get(k, 0) + 1

Нужно узнать, сколько раз каждое слово (или буква, или категория) встретилось. Для этого заводят словарь-**счётчик**: ключ — то, что считаем, значение — сколько раз.

```python
def count_items(items):
    counts = {}                                  # 1
    for item in items:                           # 2
        counts[item] = counts.get(item, 0) + 1   # 3
    return counts                                # 4
```

Главная строка 3. Справа `counts.get(item, 0)` берёт прежнее количество, а если элемент встретился впервые, то `0`. К нему прибавляется `1`, и результат записывается обратно по тому же ключу.

Пример для `["чай", "кофе", "чай"]`:

| Проход | item | counts после тела |
|---|---|---|
| 1 | `"чай"` | `{"чай": 1}` |
| 2 | `"кофе"` | `{"чай": 1, "кофе": 1}` |
| 3 | `"чай"` | `{"чай": 2, "кофе": 1}` |

## Паспорт роли «счётчик»

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | `counts[key] = counts.get(key, 0) + 1` | после цикла |

**Начальное значение — ответ для пустых данных.** Для пустого списка тело не выполнится, и вернётся `{}`.

Это тот же приём, что у обычного счётчика из папки про циклы: `count = count + 1`. Разница лишь в том, что счётчиков теперь много, по одному на каждый ключ, и `get` даёт каждому стартовое `0`.

## Что считать: ключ выбираешь ты

Ключом не обязан быть сам элемент. Чтобы посчитать слова по длине, ключом будет длина:

```python
counts[len(word)] = counts.get(len(word), 0) + 1
```

А чтобы считать **суммы**, а не количество, прибавляют не `1`, а значение: `totals[category] = totals.get(category, 0) + amount`. Это счётчик и накопитель вместе.

## Частые ошибки

Забыть про первую встречу:

```python
counts[item] = counts[item] + 1       # неверно: на первом слове KeyError
```

Обнулять словарь внутри цикла:

```python
for item in items:
    counts = {}                        # неверно: каждый проход начинает с пустого
    counts[item] = counts.get(item, 0) + 1
```

Всегда писать `1` вместо прибавления к старому: `counts[item] = 1` запомнит только «встретилось».

## Проверь себя

```python
counts = {}
for letter in "аба":
    counts[letter] = counts.get(letter, 0) + 1
```

1. Чему равен `counts` после каждого прохода?
2. Что вернёт такая функция для пустой строки?

<details><summary>Ответ</summary>

1. `{"а": 1}`, затем `{"а": 1, "б": 1}`, затем `{"а": 2, "б": 1}`.
2. `{}`: цикл не выполнится ни разу.

</details>
