# Задача DI05: Проход по парам items()

## Условие

### Как это работает

Метод `items()` отдаёт пары «ключ, значение», а `for name, grade in ...` сразу раскладывает пару на две переменные. Цикл идёт в порядке добавления ключей.

```python
prices = {"чай": 50, "кофе": 120}    # 1
total = 0                            # 2
for item, price in prices.items():   # 3
    total = total + price            # 4
```

| Проход | item | price | total после тела |
|---|---|---|---|
| 1 | `"чай"` | 50 | 50 |
| 2 | `"кофе"` | 120 | 170 |

Если в теле есть `if`, то на проходах, где условие не выполнилось, переменные просто не меняются.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ: `total_after_iter_1` .. `total_after_iter_4` — значение `total` после тела цикла на каждом проходе; `last_after_iter_2` — значение `last` после 2-го прохода; `last_final` — после всего цикла.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по проходам цикла.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_di05_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать цикл по `items()` и распаковку пары.
- Видеть, как условие внутри цикла пропускает часть проходов.
- Помнить, что цикл идёт в порядке добавления ключей.

## Проверка понимания

В каком порядке цикл увидит ключи словаря? Что останется в `last`, если ни одна оценка не дойдёт до порога?
