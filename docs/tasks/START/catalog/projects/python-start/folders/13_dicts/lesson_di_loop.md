# Цикл по словарю: keys, values, items

Словарь можно обойти циклом `for`, как список. Но у пары два куска, поэтому есть три способа.

```python
scores = {"Аня": 5, "Боря": 3, "Вика": 4}
```

| Запись | Что даёт на каждом проходе |
|---|---|
| `for name in scores:` | только **ключ** (то же, что `scores.keys()`) |
| `for score in scores.values():` | только **значение** |
| `for name, score in scores.items():` | **пару**: ключ и значение сразу |

```python
total = 0                                    # 1
for name, score in scores.items():           # 2
    total = total + score                    # 3
```

| Проход | name | score | total после тела |
|---|---|---|---|
| 1 | `"Аня"` | 5 | 5 |
| 2 | `"Боря"` | 3 | 8 |
| 3 | `"Вика"` | 4 | 12 |

`for name, score in ...` — это распаковка пары, как `a, b = min_max(...)`: первая часть пары попадает в `name`, вторая в `score`. Роли переменных прежние: `total` — накопитель, `name` и `score` — текущие элементы.

## Порядок сохраняется

Словарь помнит порядок, в котором в него **добавляли** ключи. Цикл идёт именно в этом порядке: `Аня`, `Боря`, `Вика`. Если заменить значение существующего ключа, его место не меняется. Если ключ удалить и добавить снова, он встанет в конец.

## Не меняй размер словаря внутри цикла

Пока ты идёшь по словарю циклом, нельзя добавлять и удалять ключи в нём же: Python остановит программу ошибкой `RuntimeError`.

```python
for name in scores:
    if scores[name] < 4:
        scores["новый"] = 0       # неверно: меняем размер во время обхода
```

Если нужно получить изменённый вариант, строй **новый** словарь рядом:

```python
result = {}
for name, score in scores.items():
    result[name] = score + 1      # верно: обходим scores, пишем в result
```

## Частые ошибки

Забыть `.items()` и получить только ключ:

```python
for pair in scores:        # pair это "Аня", а не пара
    print(pair)
```

Распаковать ключ в две переменные:

```python
for name, score in scores:       # неверно: строку "Аня" не разложить на имя и балл
```

## Проверь себя

```python
d = {"a": 1, "b": 2, "c": 3}
s = 0
for k, v in d.items():
    if v != 2:
        s = s + v
```

1. Чему равно `s`?
2. В каком порядке цикл увидит ключи?

<details><summary>Ответ</summary>

1. `4` (прибавили `1` и `3`, значение `2` пропустили).
2. `"a"`, `"b"`, `"c"`: в порядке добавления.

</details>
