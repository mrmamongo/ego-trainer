# Задача DI24: Что даёт sorted для словаря

## Условие

### Как это работает

`sorted(d.items(), key=lambda kv: kv[1])` возвращает **список пар**, упорядоченный по значению. В `key` написано «из пары `kv` возьми `kv[1]`» (значение). Первая пара — `pairs[0]`, её ключ — `pairs[0][0]`.

```python
d = {"x": 3, "y": 1, "z": 3}                          # 1
p = sorted(d.items(), key=lambda kv: kv[1])           # 2
q = sorted(d.items(), key=lambda kv: kv[1], reverse=True)   # 3
r = sorted(d)                                         # 4
```

| Строка | Результат |
|---|---|
| 2 | `[("y", 1), ("x", 3), ("z", 3)]` |
| 3 | `[("x", 3), ("z", 3), ("y", 1)]` |
| 4 | `["x", "y", "z"]` |

Правило равных значений: пары с одинаковым ключом сортировки остаются в том порядке, в котором были в словаре. Это верно и для `reverse=True`: `"x"` остаётся перед `"z"`.

## Учебные цели

- Читать `sorted(d.items(), key=lambda kv: kv[1])` как «список пар по значению».
- Помнить, что при равных значениях сохраняется порядок словаря, в том числе с `reverse=True`.
