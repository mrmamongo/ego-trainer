# Задача DI19: Язык меняется у другого пользователя

## Условие

### Как это работает

Допустим, настройки подставили из общего шаблона, и у двух пользователей `prefs` — **один и тот же** словарь. Функция «сменить язык одному» делает копию и меняет её:

```python
def set_language(profiles, user, lang):
    result = dict(profiles)                          # 1
    result[user]["prefs"]["language"] = lang         # 2
    return result                                    # 3
```

| Шаг | Что происходит |
|---|---|
| 1 | `result` — новый словарь, но профили `A` и `B` внутри него **те же**, что в `profiles` |
| 2 | меняем `prefs` профиля `A`; это общий словарь, поэтому язык меняется и у `B`, и в самом `profiles` |

`dict(profiles)` копирует только верхний уровень, а менять мы собираемся третий (`profiles[user]["prefs"]["language"]`). Нужно скопировать каждый уровень, который лежит на пути к изменению: профиль и его `prefs`.

```python
profile = dict(profiles[user])            # копия профиля
profile["prefs"] = dict(profile["prefs"]) # копия prefs
profile["prefs"]["language"] = lang       # теперь можно менять
```

Чтобы результат не делился с входом ни одним словарём, копируй так **каждый** профиль, а не только выбранный.

### Задание

Функция `task_di19_set_language(profiles, user, lang)` должна вернуть новые профили, где язык изменён только у пользователя `user`. Сейчас она меняет и входные данные, и язык другого пользователя, у которого общие настройки. Найди ошибку и исправь.

## Аргументы

- `profiles` — словарь «имя пользователя → профиль»; профиль `{"name": строка, "prefs": {"language": строка, "theme": строка}}` (может быть пустым). У разных пользователей словарь `prefs` может быть общим.
- `user` — имя пользователя (строка), может отсутствовать в `profiles`.
- `lang` — новый язык (строка).

## Возвращает

Новый словарь профилей: у `user` изменён `prefs["language"]`, остальное и остальные пользователи как были. Для неизвестного `user` — копия без изменений. Результат не делит с `profiles` ни одного вложенного словаря.

## Правила

- Найди и исправь ошибку; имя функции и параметры оставь как есть.
- Входные данные менять нельзя: ни `profiles`, ни вложенные словари.
- Результат должен быть независим от входа: изменение результата не должно задевать `profiles`.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
shared = {"language": "ru", "theme": "dark"}
profiles = {"A": {"name": "Аня", "prefs": shared}, "B": {"name": "Боря", "prefs": shared}}
task_di19_set_language(profiles, "A", "en")
# -> A: "en"; B остаётся "ru"; profiles и shared не изменились
```

## Учебные цели

- Узнавать утечку изменения через неглубокую копию.
- Копировать вложенный словарь на каждом уровне, который меняешь.

## Проверка понимания

Почему `dict(profiles)` не защитил `B`? Что вернёт исправленная функция для неизвестного `user`?
