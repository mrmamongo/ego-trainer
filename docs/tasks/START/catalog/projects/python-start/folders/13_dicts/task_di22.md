# Задача DI22: Самые большие категории

## Условие

### Как это работает

Чтобы упорядочить словарь по значениям, из него берут пары через `items()` и сортируют их с `key`:

```python
sorted(stock.items(), key=lambda kv: kv[1])
```

`kv` — это пара «ключ, значение», `kv[1]` — значение. Для убывания значений при равных значениях по алфавиту ключ делают парой, где число идёт со знаком минус:

```python
sorted(stock.items(), key=lambda kv: (-kv[1], kv[0]))
```

Результат — список пар (кортежей). Первые `n` из них даёт срез `pairs[:n]`; если пар меньше `n`, срез просто возьмёт все.

### Задание

Напиши функцию `task_di22_top_categories(totals, n)`: верни список из `n` самых больших категорий. Каждый элемент — список `[категория, сумма]`. Порядок: по убыванию суммы, при равных суммах по названию категории (по алфавиту).

## Аргументы

- `totals` — словарь «категория → сумма» (целые числа, может быть пустым).
- `n` — сколько категорий вернуть, целое число от 0.

## Возвращает

Список списков `[категория, сумма]` длиной не больше `n`: суммы по убыванию, при равных суммах по названию.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Словарь `totals` менять нельзя.
- Внутри результата — **списки** `[категория, сумма]`, а не кортежи.

## Пример

```python
task_di22_top_categories({"еда": 300, "кино": 300, "книги": 50}, 2)   # -> [["еда", 300], ["кино", 300]]
task_di22_top_categories({"а": 1}, 5)                               # -> [["а", 1]]
task_di22_top_categories({}, 3)                                     # -> []
```

## Учебные цели

- Отсортировать пары словаря по значению, а при равенстве по ключу.
- Превратить пары в списки `[ключ, значение]` и взять первые `n`.

## Проверка понимания

Что вернёт функция при `n = 0` и при `n`, большем числа категорий? Почему «еда» и «кино» с равными суммами идут в таком порядке?
