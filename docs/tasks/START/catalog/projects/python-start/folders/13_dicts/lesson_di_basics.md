# Словарь: ключ и значение

Список хранит элементы по номерам: `prices[0]`, `prices[1]`. Но номер ничего не говорит о смысле. Если нужно хранить «цену чая» и «цену кофе», удобнее искать **по названию**. Для этого есть **словарь** (`dict`): набор пар «**ключ → значение**».

```python
prices = {"чай": 50, "кофе": 120}
```

Ключ стоит слева от двоеточия, значение справа. Ключи в словаре **не повторяются**: у одного ключа одно значение.

## Основные действия

```python
prices = {"чай": 50, "кофе": 120}   # 1
a = prices["чай"]                   # 2  взять значение по ключу
prices["сок"] = 80                  # 3  добавить новую пару
prices["чай"] = 60                  # 4  изменить существующую
b = "кофе" in prices                # 5  есть ли такой КЛЮЧ
c = prices.get("хлеб", 0)           # 6  значение или запасное
n = len(prices)                     # 7  сколько пар
```

| После строки | prices | Что получилось |
|---|---|---|
| 1 | `{"чай": 50, "кофе": 120}` | |
| 2 | не изменился | `a` равно `50` |
| 3 | `{"чай": 50, "кофе": 120, "сок": 80}` | добавили |
| 4 | `{"чай": 60, "кофе": 120, "сок": 80}` | заменили |
| 5 | не изменился | `b` равно `True` |
| 6 | не изменился | `c` равно `0` (ключа нет) |
| 7 | не изменился | `n` равно `3` |

Запись `d[k] = v` делает одно из двух: если ключа не было, **добавляет** пару, если был, **заменяет** значение. Отдельного слова «добавить» не нужно.

## `d[k]` и `d.get(k, запасное)`

- `d[k]` — значение по ключу. Если ключа нет, программа падает с ошибкой `KeyError`.
- `d.get(k, запасное)` — то же, но для отсутствующего ключа вернёт `запасное` и **не упадёт**. Без второго аргумента вернёт `None`.
- `k in d` — проверяет **ключи**, а не значения. `50 in prices` даст `False`.

## Какие бывают ключи

Ключом может быть только **неизменяемое** значение: строка, число, кортеж. Список ключом быть не может: `{[1, 2]: "x"}` вызовет ошибку. Почему так, станет понятнее в карточке про копии. Значением может быть что угодно: число, строка, список, другой словарь.

## Частые ошибки

Взять значение по ключу, которого нет:

```python
prices = {"чай": 50}
cost = prices["сок"]            # неверно: KeyError
```

```python
cost = prices.get("сок", 0)     # верно: 0, если ключа нет
```

Проверять значение вместо ключа: `50 in prices` не найдёт цену, `"чай" in prices` найдёт.

## Проверь себя

```python
stock = {"яблоки": 5}
stock["груши"] = 2
stock["яблоки"] = stock["яблоки"] + 1
```

1. Чему равен `stock` в конце?
2. Что вернёт `stock.get("киви", 0)`, а что `"киви" in stock`?

<details><summary>Ответ</summary>

1. `{"яблоки": 6, "груши": 2}`.
2. `0` и `False`. Ключа `"киви"` нет, ошибки при этом не будет.

</details>
