# Задача DI12: Расходы: сумма и количество

## Условие

### Как это работает

Сейчас функция считает сумму по каждой категории:

```python
def task_di12_total_by_category(entries):             # 1
    totals = {}                                       # 2
    for amount, category in entries:                  # 3
        totals[category] = totals.get(category, 0) + amount   # 4
    return totals                                     # 5
```

**Где реализовано старое правило:** в строке 4. Значение по ключу — число, сумма.

**Что меняется:** теперь для каждой категории нужно хранить ещё и **количество** записей. Значением становится маленький словарь `{"total": ..., "count": ...}`. Новое значение нужно создать при первой встрече категории (как список в группировщике), а потом обновлять оба поля.

```python
if category not in result:
    result[category] = {"total": 0, "count": 0}
result[category]["total"] = result[category]["total"] + amount
result[category]["count"] = result[category]["count"] + 1
```

**Что нельзя трогать:** цикл по записям и смысл суммы: поле `"total"` должно равняться старому ответу.

### Задание

Раньше функция возвращала `{категория: сумма}`. Теперь она должна вернуть для каждой категории словарь с двумя полями: `{категория: {"total": сумма, "count": сколько записей}}`. Измени готовую функцию.

## Аргументы

- `entries` — список записей `[сумма, категория]` (может быть пустым).

## Возвращает

Словарь «категория → `{"total": сумма, "count": число записей}`»; для пустого списка `{}`.

## Правила

- Не переписывай функцию с нуля: измени значение, которое хранится по ключу.
- Сумма в поле `"total"` считается как раньше.
- Не используй `Counter` и модуль `collections`.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_di12_total_by_category([[100, "еда"], [50, "еда"], [30, "транспорт"]])
# -> {"еда": {"total": 150, "count": 2}, "транспорт": {"total": 30, "count": 1}}
task_di12_total_by_category([])   # -> {}
```

## Учебные цели

- Заменить число-значение словарём-значением в счётчике.
- Создавать вложенный словарь при первой встрече ключа и сохранять старый смысл суммы.

## Проверка понимания
