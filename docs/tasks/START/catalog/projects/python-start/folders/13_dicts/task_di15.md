# Задача DI15: Журнал квестов: открыто и сделано

## Условие

### Как это работает

Словарь можно строить по списку словарей: на каждом проходе берём поле `"id"` как ключ, а значение определяем по условию.

```python
def parity(items):
    result = {}
    for item in items:
        if item["n"] % 2 == 0:
            result[item["id"]] = "even"
        else:
            result[item["id"]] = "odd"
    return result
```

Проверка `x in список` отвечает `True`, если `x` есть среди элементов списка. Она годится и для списка идентификаторов.

### Задание

Напиши функцию `task_di15_quest_progress(quests, done_ids)`: для каждого квеста из `quests` положи в результат пару «`id` квеста → `"done"`», если его `id` есть в списке `done_ids`, иначе «`id` → `"open"`».

## Аргументы

- `quests` — список словарей `{"id": строка, "title": строка}`; `id` не повторяются (может быть пустым).
- `done_ids` — список `id` выполненных квестов (может быть пустым и содержать лишние `id`).

## Возвращает

Словарь «`id` квеста → `"done"` или `"open"`» ровно по квестам из `quests`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Входные списки и словари менять нельзя.

## Пример

```python
task_di15_quest_progress([{"id": "q1", "title": "Найти ключ"}, {"id": "q2", "title": "Победить дракона"}], ["q1"])
# -> {"q1": "done", "q2": "open"}
task_di15_quest_progress([], ["q1"])   # -> {}
```

## Учебные цели

- Построить словарь по списку словарей, беря ключ из поля `"id"`.
- Выбирать значение по условию с проверкой `in` по списку.

## Проверка понимания
