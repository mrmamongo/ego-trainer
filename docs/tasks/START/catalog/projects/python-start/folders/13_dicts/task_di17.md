# Задача DI17: Объединить два склада

## Условие

### Как это работает

Чтобы объединить два словаря и сложить значения у общих ключей, начинают с копии первого, а потом по очереди прибавляют пары второго:

```python
def merge_prices(a, b):
    result = dict(a)
    for key, value in b.items():
        result[key] = result.get(key, 0) + value
    return result
```

| Шаг | Что происходит |
|---|---|
| 1 | `result` — копия `a` |
| 2 | для каждой пары из `b`: если ключ уже есть, значение складывается, иначе используется `0` |

Оба исходных словаря остаются нетронутыми: изменяется только `result`.

### Задание

Напиши функцию `task_di17_merge_inventories(a, b)`: верни **новый** словарь, в котором для каждого товара количество равно сумме количеств из `a` и `b` (если товара нет в одном из словарей, там считай `0`). Словари `a` и `b` менять нельзя.

## Аргументы

- `a`, `b` — словари «товар → количество» (целые числа от 0, могут быть пустыми).

## Возвращает

Новый словарь «товар → общее количество» по всем товарам из `a` и `b`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Входные словари `a` и `b` менять нельзя, результат должен быть новым объектом.

## Пример

```python
task_di17_merge_inventories({"яблоки": 5}, {"яблоки": 3, "груши": 2})   # -> {"яблоки": 8, "груши": 2}
task_di17_merge_inventories({}, {"чай": 1})                          # -> {"чай": 1}
task_di17_merge_inventories({}, {})                                  # -> {}
```

## Учебные цели

- Объединять два словаря в новый, суммируя значения общих ключей.
- Не менять входные словари.

## Проверка понимания

Что вернёт функция для двух пустых словарей? Что случится с `a`, если начать с `result = a`?
