# Четыре роли словаря: паспорта

Как и у переменных цикла, у словаря бывает **роль**. Роль отвечает на вопрос «зачем я завёл этот словарь?». Если роль выбрана верно, код получается почти механически. Ниже четыре роли, у каждой свой **паспорт**.

## Все роли одной таблицей

| Роль | Вопрос, на который отвечает | Ключ | Значение | Начальное значение |
|---|---|---|---|---|
| запись | «какие данные у одного объекта?» | название поля (`"name"`) | значение поля | сразу все поля: `{"id": 1, "name": "Аня"}` |
| счётчик | «сколько раз встретилось?» | то, что считаем | число | `{}` |
| группировщик | «что относится к каждому ключу?» | признак группы | список элементов | `{}` |
| индекс | «где найти объект по номеру?» | id объекта | сам объект | `{}` |

## Запись: поля одного объекта

Ключи известны заранее и подписывают поля. Запись не строят циклом, её описывают целиком.

```python
user = {"id": 7, "name": "Аня", "active": True}
```

| Где заводим | Начальное значение | Как читаем и меняем | Когда возвращаем |
|---|---|---|---|
| где угодно, обычно целиком | все поля сразу | `user["name"]`, `user["active"] = False` | как любое значение |

Пример из продукта: сообщение чата `{"id": "m1", "role": "user", "text": "привет", "tokens": 3}`.

## Счётчик: сколько раз встретилось

```python
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | `counts[key] = counts.get(key, 0) + 1` | после цикла |

Подробности в карточке «Счётчик».

## Группировщик: ключ → список

```python
groups = {}
for word in words:
    key = word[0]
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | если ключа нет: `groups[key] = []`; затем `groups[key].append(item)` | после цикла |

Подробности в карточке «Группировщик».

## Индекс: id → объект

```python
by_id = {}
for user in users:
    by_id[user["id"]] = user
```

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла, **один раз** | `{}` | `by_id[item["id"]] = item` | после цикла |

Подробности в карточке «Индекс».

## Как выбрать роль

- В словаре **разные поля одного** объекта: запись.
- Нужен **ответ-число** «сколько раз»: счётчик.
- Нужен **ответ-список** «что относится к ключу»: группировщик.
- Нужно быстро **найти объект по его id**: индекс.

Счётчик и группировщик отличаются значением: у счётчика это число и стартует оно с `0` (через `get`), у группировщика это список, и его нужно **создать при первой встрече** ключа.

## Частые ошибки

Выбрать неверную роль: для вопроса «в каких словах есть буква `а`?» нужен группировщик или обычный сборщик, а не счётчик. Счётчик ответит только «сколько».

Начинать счётчик с ключа, которого нет:

```python
counts[word] = counts[word] + 1       # неверно: на первой встрече KeyError
```

```python
counts[word] = counts.get(word, 0) + 1    # верно
```

## Проверь себя

Какую роль взять?

1. «Сколько раз каждая буква встречается в слове?»
2. «Какие слова начинаются на каждую букву?»
3. «Найти пользователя по его `id` без перебора всего списка.»

<details><summary>Ответ</summary>

1. Счётчик: `{буква: сколько раз}`.
2. Группировщик: `{буква: [слова]}`.
3. Индекс: `{id: пользователь}`, построенный один раз до поиска.

</details>
