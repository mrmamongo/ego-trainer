# Задача DI09: Слова по длине

## Условие

### Как это работает

Ключом группировки может быть не сама буква, а любое значение, которое считается от элемента: длина, остаток от деления, категория.

```python
groups = {}
for word in words:
    key = len(word)
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
```

| Проход | word | key | groups после тела |
|---|---|---|---|
| 1 | `"кот"` | 3 | `{3: ["кот"]}` |
| 2 | `"мышь"` | 4 | `{3: ["кот"], 4: ["мышь"]}` |
| 3 | `"дом"` | 3 | `{3: ["кот", "дом"], 4: ["мышь"]}` |

На третьем проходе список для длины 3 уже есть, поэтому слово просто дописывается в конец.

### Задание

Напиши функцию `task_di09_group_by_length(words)`: верни словарь «длина → список слов этой длины». Слова внутри группы идут в том порядке, в каком были в `words`.

## Аргументы

- `words` — список непустых строк (может быть пустым).

## Возвращает

Словарь, где ключ — длина слова (целое число), значение — список слов с такой длиной в исходном порядке.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Не используй `setdefault` и модуль `collections`: создавай список при первой встрече ключа сам.
- Список `words` менять нельзя.

## Пример

```python
task_di09_group_by_length(["кот", "мышь", "дом"])   # -> {3: ["кот", "дом"], 4: ["мышь"]}
task_di09_group_by_length(["а"])                  # -> {1: ["а"]}
task_di09_group_by_length([])                     # -> {}
```

## Учебные цели

- Применить группировщик с вычисляемым ключом.
- Создавать список при первой встрече ключа.

## Проверка понимания

Что вернёт функция для `[]`? Почему ключи этого словаря — числа, а не строки?
