# Задача DI02: Цена товара

## Условие

### Как это работает

Обычное чтение `prices[item]` падает с `KeyError`, если ключа нет. Метод `get` принимает запасное значение и возвращает его вместо ошибки:

```python
def stock_of(stock, item):
    return stock.get(item, 0)
```

`stock.get("киви", 0)` вернёт количество `киви`, а если такого товара нет в словаре, то `0`. Ветвление не нужно: `get` уже делает всё сам.

### Задание

Напиши функцию `task_di02_price_of(prices, item)`: верни цену товара `item` из словаря `prices`, а если такого товара нет, верни `0`.

## Аргументы

- `prices` — словарь «название товара → цена» (целые числа, может быть пустым).
- `item` — название товара (строка).

## Возвращает

Цену товара (целое число) или `0`, если товара нет в `prices`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Используй `get`: ветвления `if` и `try` здесь не нужны.

## Пример

```python
task_di02_price_of({"чай": 50, "кофе": 120}, "кофе")   # -> 120
task_di02_price_of({"чай": 50}, "сок")                 # -> 0
task_di02_price_of({}, "чай")                          # -> 0
```

## Учебные цели

- Читать значение словаря с запасным значением через `get`.
- Не проверять наличие ключа ветвлением там, где хватает `get`.
