# Задача DI10: Индекс пользователей

## Условие

### Как это работает

Если пользователей много, а искать нужно по `id`, один раз строят **индекс**: словарь «`id` → пользователь». Потом поиск делается за один шаг, без перебора списка.

```python
def index_by_name(people):
    by_name = {}
    for person in people:
        by_name[person["name"]] = person
    return by_name
```

**Паспорт роли «индекс»** (имя `by_name`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла, один раз | `{}` | `by_name[item["name"]] = item` | после цикла |

Значением в индексе служит **сам объект** (словарь пользователя), а не его копия: индекс лишь указывает на те же пользовательские словари.

### Задание

Напиши функцию `task_di10_index_by_id(users)`: верни словарь «`id` пользователя → сам пользователь (словарь)».

## Аргументы

- `users` — список словарей `{"id": ..., "name": ...}`; `id` у разных пользователей разные (может быть пустым).

## Возвращает

Словарь «`id` → словарь пользователя»; для пустого списка `{}`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `users` и словари в нём менять нельзя.

## Пример

```python
task_di10_index_by_id([{"id": 1, "name": "Аня"}, {"id": 2, "name": "Боря"}])
# -> {1: {"id": 1, "name": "Аня"}, 2: {"id": 2, "name": "Боря"}}
task_di10_index_by_id([])   # -> {}
```

## Учебные цели

- Построить индекс «id → объект» одним циклом.
- Помнить, что значение индекса — сам объект.

## Проверка понимания
