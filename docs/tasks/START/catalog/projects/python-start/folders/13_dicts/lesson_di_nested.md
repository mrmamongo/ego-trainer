# Вложенные данные: списки и словари внутри

В настоящих задачах данные почти всегда вложенные: в словаре лежит список, в списке словари, в словаре ещё словари. Читать их нужно **по одному шагу слева направо**.

## Три частых формата

| Формат | Пример | Откуда берётся |
|---|---|---|
| список словарей | `[{"id": 1, "name": "Аня"}, {"id": 2, "name": "Боря"}]` | сообщения чата, пользователи, задачи |
| словарь списков | `{"а": ["ананас", "арбуз"], "б": ["банан"]}` | результат группировщика |
| словарь словарей | `{"q1": {"reward": 5, "done": True}, "q2": {"reward": 20, "done": False}}` | журнал квестов, профили, настройки |

## Читаем по шагам

```python
data = {
    "users": [
        {"name": "Аня", "tags": ["admin", "dev"]},
        {"name": "Боря", "tags": ["dev"]},
    ],
    "total": 2,
}
```

Выражение `data["users"][0]["name"]` читается так:

| Шаг | Выражение | Что получилось |
|---|---|---|
| 1 | `data` | весь словарь |
| 2 | `data["users"]` | список из двух пользователей |
| 3 | `data["users"][0]` | первый пользователь: `{"name": "Аня", "tags": [...]}` |
| 4 | `data["users"][0]["name"]` | `"Аня"` |

А `data["users"][1]["tags"][0]` даёт `"dev"`: второй пользователь, его теги, первый тег.

Подсказка: на каждом шаге смотри, **что сейчас в руках** — словарь (тогда нужен ключ в квадратных скобках) или список (тогда нужен номер).

## Обход вложенных данных

Вложенный цикл или промежуточные переменные делают код понятнее:

```python
names = []
for user in data["users"]:          # user это словарь
    names.append(user["name"])      # поле словаря

tag_count = 0
for user in data["users"]:
    for tag in user["tags"]:        # tags это список
        tag_count = tag_count + 1
```

Одно имя на одно значение: вместо длинной цепочки `data["users"][i]["tags"][j]` заведи переменную `user` или `tags`. Меньше шансов запутаться в скобках.

## Форматы продуктовых задач

Во всех продуктовых задачах платформы данные устроены так:

- **сообщение чата**: `{"id": "m1", "role": "user", "text": "привет", "tokens": 3}`; история сообщений — список таких словарей;
- **журнал квестов**: `{"gold": 10, "quests": {"q1": {"reward": 5, "done": True, "rewarded": False}}}` — словарь словарей;
- **профили пользователей**: `{"A": {"name": "Аня", "prefs": {"language": "ru"}}}` — словарь внутри словаря.

Вложенность — повод помнить про изменяемость: внутренний словарь или список можно случайно сделать общим для двух пользователей. Об этом следующая карточка.

## Частые ошибки

Перепутать список и словарь на шаге:

```python
data["users"]["name"]       # неверно: users это список, нужен номер
data["users"][0]["name"]    # верно
```

Взять поле не того уровня: `data["name"]` упадёт, имя лежит внутри пользователя.

## Проверь себя

```python
data = {"users": [{"name": "Аня", "tags": ["admin"]}, {"name": "Боря", "tags": []}]}
```

1. Что вернёт `data["users"][0]["tags"][0]`?
2. Что вернёт `len(data["users"][1]["tags"])`?

<details><summary>Ответ</summary>

1. `"admin"`.
2. `0`: у второго пользователя нет тегов.

</details>
