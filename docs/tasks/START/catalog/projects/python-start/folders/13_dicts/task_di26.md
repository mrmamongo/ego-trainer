# Задача DI26: Награда только один раз

## Условие

### Как это работает

Журнал квестов — словарь словарей:

```python
journal = {
    "gold": 10,
    "quests": {
        "q1": {"reward": 5, "done": True, "rewarded": False},
    },
}
```

Поле `"rewarded"` отвечает на вопрос «награду за этот квест уже выдали?». Именно оно защищает от двойной награды: выдавать нужно, только если квест выполнен (`done`) и награда ещё не выдана (`rewarded` равно `False`). После выдачи ставим `"rewarded": True`, и повторный вызов уже ничего не даст.

Чтобы не менять входной журнал, сначала собери **независимую копию** (журнал, `quests` и каждый квест — три уровня), и только потом меняй копию:

```python
quests = {}
for qid, quest in journal["quests"].items():
    quests[qid] = dict(quest)
new_journal = dict(journal)
new_journal["quests"] = quests
```

Функция возвращает пару: новый журнал и признак «награда выдана в этом вызове» (`True` или `False`). `return new_journal, True` упаковывает пару в кортеж.

### Задание

Напиши функцию `task_di26_grant_reward(journal, quest_id)`: выдай награду за квест `quest_id`, если такой квест есть, он выполнен и награда за него ещё не выдавалась. Верни пару `(новый_журнал, награда_выдана)`. Если награду выдали, к `"gold"` прибавляется `"reward"` квеста и у квеста `"rewarded"` становится `True`. Иначе журнал остаётся прежним по значению. Исходный `journal` менять нельзя, новый журнал всегда независим от входного.

### Что дальше

Это упрощённая версия продуктовой задачи [XL-A05](task:XL-A05): в ней та же ошибка «награда пришла два раза», только вместо флага `"rewarded"` используется список `claimed`, а ответ содержит статус отказа. Идея защиты одинакова: запомнить, что награда уже выдана, и не менять входной журнал.

## Аргументы

- `journal` — словарь `{"gold": целое, "quests": {id: {"reward": целое >= 0, "done": bool, "rewarded": bool}}}`.
- `quest_id` — строка, может отсутствовать в `journal["quests"]`.

## Возвращает

Кортеж `(new_journal, reward_given)`: новый журнал и `True`, если награда выдана в этом вызове, иначе `False`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Входной журнал менять нельзя, включая вложенные словари квестов.
- Новый журнал всегда новый объект, даже если ничего не изменилось и результат `False`.

## Пример

```python
journal = {"gold": 10, "quests": {"q1": {"reward": 5, "done": True, "rewarded": False}}}
first, given = task_di26_grant_reward(journal, "q1")
# given -> True, first["gold"] -> 15, first["quests"]["q1"]["rewarded"] -> True
second, given = task_di26_grant_reward(first, "q1")
# given -> False, second["gold"] -> 15: второй раз награды нет
```

## Учебные цели

- Не выдавать награду дважды: хранить в данных признак «уже выдана».
- Копировать вложенные словари перед изменением и не менять входные данные.
- Вернуть пару «новое состояние, результат».
