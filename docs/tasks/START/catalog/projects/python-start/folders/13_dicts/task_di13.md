# Задача DI13: Вложенный доступ

## Условие

### Как это работает

Вложенные данные читают по одному шагу слева направо. На каждом шаге смотри, что у тебя «в руках»: словарь (нужен ключ) или список (нужен номер).

```python
team = {"members": [{"name": "Ира", "skills": ["python"]}], "size": 1}   # 1
a = team["members"]                  # 2
b = team["members"][0]               # 3
c = team["members"][0]["skills"][0]  # 4
```

| Строка | Что получилось |
|---|---|
| 2 | список из одного участника |
| 3 | словарь `{"name": "Ира", "skills": ["python"]}` |
| 4 | строка `"python"`: участник 0, его навыки, навык 0 |

Внутри `data` пользователи не копируются: в списке лежат **те же** словари, что и в переменных `anna` и `boris`. Если изменить вложенный список через одно имя, это будет видно через другое.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, разбирая каждое выражение по шагам.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_di13_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать выражения вида `data["users"][1]["tags"][0]` по шагам.
- Видеть, что вложенный словарь доступен и через переменную, и через внешнюю структуру.

## Проверка понимания
