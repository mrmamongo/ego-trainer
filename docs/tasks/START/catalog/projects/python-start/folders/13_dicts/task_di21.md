# Задача DI21: Новый профиль вместо правки старого

## Условие

### Как это работает

Сейчас функция меняет переданный профиль на месте и ничего не возвращает:

```python
def task_di21_add_tag(profile, tag):             # 1
    if tag not in profile["tags"]:               # 2
        profile["tags"].append(tag)              # 3
```

**Где реализовано старое правило:** в строках 2–3. Тег добавляется в конец списка `tags`, и только если его там ещё нет.

**Что меняется:** вызывающий код не хочет, чтобы его профиль менялся. Правило добавления остаётся тем же, но результат нужно **вернуть новым профилем**. Для этого сначала сделай копию профиля и **копию списка `tags`** (иначе `append` испортит оригинал, ведь `dict(profile)` делит список с ним), а потом применяй старое правило к копии.

```python
new_profile = dict(profile)
new_profile["tags"] = list(profile["tags"])
```

**Что нельзя трогать:** само правило: тег добавляется в конец и не дублируется.

### Задание

Раньше функция добавляла тег в сам профиль и ничего не возвращала. Теперь она должна вернуть **новый** профиль с добавленным тегом, а переданный профиль оставить без изменений. Измени готовую функцию.

## Аргументы

- `profile` — словарь `{"name": строка, "tags": список строк, ...}` (могут быть и другие поля).
- `tag` — добавляемый тег (строка).

## Возвращает

Новый профиль: тег в конце `tags`, если его там не было; остальные поля те же. Исходный `profile` не меняется.

## Правила

- Не переписывай функцию с нуля: сохрани правило добавления и сделай копию.
- Входной `profile` и его список `tags` менять нельзя; результат не должен делить с ним `tags`.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
old = {"name": "Аня", "tags": ["dev"]}
new = task_di21_add_tag(old, "admin")
# new -> {"name": "Аня", "tags": ["dev", "admin"]}, old не изменился
```

## Учебные цели

- Превратить функцию, меняющую данные на месте, в функцию, возвращающую новый объект.
- Копировать вложенный список, прежде чем менять его.

## Проверка понимания

Что останется общим у профиля и его копии, если не копировать `tags`? Какие старые случаи проверяют, что правило не сломалось?
