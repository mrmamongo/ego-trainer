# Задача DI25: Контекст чата по бюджету

## Условие

### Как это работает

Сообщение чата — словарь с четырьмя полями:

```python
{"id": "m3", "role": "assistant", "text": "Здравствуйте", "tokens": 8}
```

`tokens` — сколько токенов (условных «единиц стоимости») занимает сообщение. Нужно выбрать сообщения, которые поместятся в **бюджет**: сумма `tokens` выбранных не больше `budget`.

План решения:

1. Если есть сообщение с ролью `"system"`, оно берётся **всегда**, а его `tokens` вычитаются из бюджета.
2. Остальные сообщения просматривай **от новых к старым**. Если сообщение помещается в остаток, бери его и вычитай `tokens`. Если не помещается, **пропусти** и иди дальше: более старое и короткое ещё может поместиться.
3. Верни выбранные сообщения **в исходном порядке**.

Удобно запоминать выбранные `id` в списке: `id` уникальны. А итог собрать вторым проходом по `messages` в прямом порядке.

| Шаг | Что делаем |
|---|---|
| проход 1 | находим `system`, уменьшаем остаток, запоминаем его `id` |
| проход 2 | `for message in reversed(messages)`: помещается — запоминаем `id` и вычитаем |
| проход 3 | `for message in messages`: если `id` запомнен — добавляем в результат |

### Задание

Напиши функцию `task_di25_chat_context(messages, budget)`: верни список сообщений для контекста бота. Правила: сообщение `"system"` (если есть) берётся всегда; остальные просматриваются от новых к старым, сообщение берётся целиком, если помещается в оставшийся бюджет, иначе пропускается. Итоговый список идёт в исходном порядке. Входные данные менять нельзя.

## Аргументы

- `messages` — список сообщений `{"id": строка, "role": "system" | "user" | "assistant", "text": строка, "tokens": целое > 0}` в хронологическом порядке; `id` уникальны; `system` бывает не больше одного и стоит первым (список может быть пустым).
- `budget` — целое число от 0; если есть `system`, он помещается в бюджет.

## Возвращает

Новый список выбранных сообщений (те же словари) в исходном порядке; сумма их `tokens` не превышает `budget`.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `messages` и словари в нём менять нельзя.

## Пример

```python
messages = [
    {"id": "m1", "role": "system", "text": "Ты помощник", "tokens": 10},
    {"id": "m2", "role": "user", "text": "Привет", "tokens": 5},
    {"id": "m3", "role": "user", "text": "Расскажи про словари", "tokens": 20},
    {"id": "m4", "role": "assistant", "text": "Словарь хранит пары", "tokens": 6},
]
task_di25_chat_context(messages, 25)
# system (10) всегда; m4 (6) помещается; m3 (20) не помещается, пропущен; m2 (5) помещается
# -> [m1, m2, m4]
```

## Учебные цели

- Читать и использовать сообщения как словари с полями `role` и `tokens`.
- Выбирать элементы по остатку бюджета, пропуская неподходящие.
- Не менять входной список и сообщения в нём.
