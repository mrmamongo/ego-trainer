# Задача DI20: Глубокая копия профилей вручную

## Условие

### Как это работает

Когда внутри словаря лежат списки, копия верхнего уровня делит эти списки со старым словарём. Чтобы получить полностью независимую копию, копируй **каждый уровень**: внешний словарь, внутренние словари и списки в них.

```python
def copy_teams(teams):
    result = {}
    for name, members in teams.items():
        result[name] = list(members)       # новый список, а не тот же
    return result
```

Для словаря словарей со списками получается три уровня:

| Уровень | Что копируем |
|---|---|
| 1 | внешний словарь: новый `result = {}` |
| 2 | каждый внутренний словарь: новый `{}` |
| 3 | каждый список в нём: `list(items)` |

Это называется **глубокая копия**. В языке для неё есть готовая функция, но здесь её нужно написать самому, чтобы понять, что происходит.

### Задание

Напиши функцию `task_di20_deep_copy_profiles(profiles)`: верни полностью независимую копию словаря профилей. Изменение результата (в том числе вложенных списков) не должно влиять на исходные данные.

## Аргументы

- `profiles` — словарь «имя → профиль»; профиль — словарь «поле → список строк» (может быть пустым).

## Возвращает

Новый словарь с теми же данными; ни один словарь и ни один список не общий с `profiles`.

## Правила

- Модуль `copy` и функцию `deepcopy` использовать нельзя: копируй вручную.
- Входные данные менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
src = {"A": {"tags": ["dev"], "langs": ["ru"]}}
copy_ = task_di20_deep_copy_profiles(src)
copy_["A"]["tags"].append("qa")   # src не изменился
```

## Учебные цели

- Скопировать данные из трёх уровней вложенности вручную.
- Понимать, зачем нужно копировать каждый изменяемый уровень.

## Проверка понимания

Что останется общим, если скопировать только внешний словарь? Что вернёт функция для `{}`?
