# Задача DI04: Переименуй ключ

## Условие

### Как это работает

Чтобы получить словарь с другим названием ключа, не меняй исходный, а строй **новый**: обойди пары и перепиши каждую.

```python
def double_values(d):
    result = {}
    for key, value in d.items():
        result[key] = value * 2
    return result
```

Для пары, которая нас интересует, ключ заменяется, для остальных остаётся прежним. Исходный `d` только читается. Так вызывающий код сохраняет свои данные.

### Задание

Напиши функцию `task_di04_rename_key(d, old, new)`: верни **новый** словарь, в котором ключ `old` заменён на `new`, а значение осталось тем же. Остальные пары не меняются. Если ключа `old` в словаре нет, верни копию без изменений.

## Аргументы

- `d` — словарь со строковыми ключами и целыми значениями (может быть пустым).
- `old` — ключ, который нужно переименовать.
- `new` — новое имя ключа; такого ключа в `d` ещё нет, и он не равен `old`.

## Возвращает

Новый словарь: значение по `old` лежит теперь под ключом `new`; всё остальное как было.

## Правила

- Меняй только тело функции; имя функции и параметры оставь как есть.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Входной словарь `d` менять нельзя, результат должен быть другим объектом.

## Пример

```python
task_di04_rename_key({"a": 1, "b": 2}, "a", "x")   # -> {"x": 1, "b": 2}
task_di04_rename_key({"a": 1}, "z", "x")          # -> {"a": 1}
task_di04_rename_key({}, "a", "b")                # -> {}
```

## Учебные цели

- Обходить пары через `items()` и строить новый словарь.
- Не менять входной словарь.

## Проверка понимания

Что вернёт функция для `({}, "a", "b")`? Почему результат нельзя собирать в самом `d`?
