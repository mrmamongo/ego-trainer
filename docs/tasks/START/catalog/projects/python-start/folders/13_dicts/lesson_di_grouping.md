# Группировщик: ключ → список

Иногда нужно не посчитать, а **разложить по группам**: слова по первой букве, заказы по клиенту, сообщения по автору. Значением тогда будет **список** элементов группы.

```python
def group_by_first(words):
    result = {}                        # 1
    for word in words:                 # 2
        key = word[0]                  # 3
        if key not in result:          # 4
            result[key] = []           # 5
        result[key].append(word)       # 6
    return result                      # 7
```

Главная мысль в строках 4–5: при **первой встрече** ключа нужно создать для него пустой список. Иначе `result[key].append(...)` не к чему применить, и будет `KeyError`.

Пример для `["ананас", "банан", "арбуз"]`:

| Проход | word | key | result после тела |
|---|---|---|---|
| 1 | `"ананас"` | `"а"` | `{"а": ["ананас"]}` |
| 2 | `"банан"` | `"б"` | `{"а": ["ананас"], "б": ["банан"]}` |
| 3 | `"арбуз"` | `"а"` | `{"а": ["ананас", "арбуз"], "б": ["банан"]}` |

На третьем проходе ключ `"а"` уже есть, поэтому строка 5 пропускается, а `append` дописывает в тот же список.

## Паспорт роли «группировщик»

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | если ключа нет: `result[key] = []`; затем `result[key].append(item)` | после цикла |

Внутри каждой группы элементы идут в том порядке, в каком были во входном списке.

## Группировщик и счётчик

| | Счётчик | Группировщик |
|---|---|---|
| Значение | число | список |
| Что делаем на проходе | `counts[k] = counts.get(k, 0) + 1` | создать `[]` при первой встрече, `append` |
| Ответ на вопрос | «сколько?» | «какие именно?» |

Если нужна только длина группы, можно сгруппировать и взять `len(result[key])`, но проще сразу завести счётчик.

## Частые ошибки

Создавать список на каждом проходе и терять накопленное:

```python
for word in words:
    key = word[0]
    result[key] = []              # неверно: очищаем группу при каждой встрече
    result[key].append(word)
```

Класть в словарь сам элемент вместо списка:

```python
result[key] = word                # неверно: в группе останется только последнее слово
```

Забыть проверку `if key not in result`: на первой встрече ключа будет `KeyError`.

## Проверь себя

```python
result = {}
for number in [1, 2, 3, 4, 5]:
    key = number % 2
    if key not in result:
        result[key] = []
    result[key].append(number)
```

1. Чему равен `result`?
2. Что произойдёт, если убрать строки `if key not in result` и `result[key] = []`?

<details><summary>Ответ</summary>

1. `{1: [1, 3, 5], 0: [2, 4]}`: ключ `1` появился первым (число `1` нечётное).
2. На первом проходе `result[key].append(number)` упадёт с `KeyError`: списка для ключа ещё нет.

</details>
