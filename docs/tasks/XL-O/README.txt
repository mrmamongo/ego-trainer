## Статус материалов XL-O

Это самостоятельные учебные заготовки для работы с `student.py`. Стартовый
код может содержать намеренные ошибки или незавершённые реализации; он не
является эталоном и не свидетельствует о прохождении задания.

Эти файлы не импортируются платформой как задачи без подготовки условий
`task_*.md`, эталонов `.solution.py`, тестов `.tests.py` и метаданных каталога.
Проверка и уточнение учебных контрактов отслеживаются в Beads: `ego-trainer-uom`.
В наборе сохранены исходные идентификаторы, примеры и варианты стартового кода;
неоднозначные условия требуют уточнения перед автоматической оценкой.

# XL-O — продуктовые задачи для LLM, agents и MMO

Набор из 27 задач. Каждая задача находится в отдельной папке и содержит `student.py`.
Описание, входные данные и критерии поведения находятся в docstring в начале файла.

| Задачи | Тема | Типы |
|---|---|---|
| 01–09 | LLM | баги, правки, новый код |
| 10–17 | Agents | баги, правки, новый код |
| 18–27 | Игры и MMO | баги, правки, новый код |

Задачи с намеренно неисправным стартовым кодом: 01, 04, 07, 10, 12, 15, 18, 21, 24.
Остальные задачи содержат каркас, который студент должен реализовать или расширить.
