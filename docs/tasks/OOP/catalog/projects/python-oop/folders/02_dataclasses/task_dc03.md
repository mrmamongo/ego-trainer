# Задача DC03: Профиль, который нельзя править

## Условие

### Как это работает

`@dataclass(frozen=True)` делает запись неизменяемой: присвоить полю нельзя, Python бросит `FrozenInstanceError`. Чтобы получить запись с другим значением, делают **новую** через `replace`, а старая остаётся как была.

```python
from dataclasses import dataclass, replace, FrozenInstanceError

@dataclass(frozen=True)
class Coin:
    kind: str
    value: int = 1

c = Coin("медь")                       # 1
try:
    c.value = 5                        # 2
except FrozenInstanceError:
    note = "заморожено"                # 3
d = replace(c, value=5)                # 4
```

| После строки | Что получилось |
|---|---|
| 1 | `c.value` равно `1` |
| 2 | запись frozen, поле не меняется, Python бросает `FrozenInstanceError` |
| 3 | сработал `except`, `note` равно `"заморожено"` |
| 4 | новая запись `d` с `value=5`; у `c` по-прежнему `value=1`, и `c is d` равно `False` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_dc03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Предсказывать, что произойдёт при попытке изменить frozen-запись.
- Понимать, что `replace` создаёт новую запись и не трогает старую.
- Сравнивать записи по полям через `==` и по объекту через `is`.
