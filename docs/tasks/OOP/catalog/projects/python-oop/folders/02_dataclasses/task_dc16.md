# Задача DC16: Бонус без правки записей

## Условие

### Как это работает

Сейчас запись `Score` изменяемая, а функция меняет очки прямо в тех записях, которые ей передали:

```python
def apply_bonus(scores, bonus):                    # 1
    for score in scores:                           # 2
        if score.points >= 50:                     # 3
            score.points = score.points + bonus    # 4
    return scores                                  # 5
```

**Где реализовано старое правило:** условие в строке 3 («бонус от 50 очков») и сумма в строке 4.

**Что меняется:** результаты матча правке не подлежат. Запись становится `frozen=True`, а функция больше не трогает переданные записи, а возвращает **новый список**. Для нужных записей в него кладут копию с другими очками (`replace`), для остальных ту же запись:

```python
if score.points >= 50:
    score = replace(score, points=score.points + bonus)
result.append(score)
```

**Что нельзя трогать:** порог в 50 очков и порядок записей.

### Задание

Раньше функция `apply_bonus(scores, bonus)` меняла очки в переданных записях. Теперь:

- класс `Score` должен быть неизменяемым (`frozen=True`);
- `apply_bonus` возвращает **новый** список записей в прежнем порядке: игрокам с очками `>= 50` добавлен `bonus`, остальные без изменений;
- исходный список `scores` и его записи остаются как были.

Рамка внизу файла проверяет все три пункта: что запись заморожена, что исходные записи не изменились и что бонус начислен в новом списке. Измени готовый код.

## Аргументы

- `rows` — список пар `[игрок, очки]` (может быть пустым).
- `bonus` — сколько очков добавить, целое (может быть отрицательным).

## Возвращает

Словарь с тремя ключами: `"frozen"` (`True`, если запись `Score` нельзя менять), `"before"` (пары `[игрок, очки]` исходных записей после вызова `apply_bonus`), `"after"` (пары из списка, который вернула `apply_bonus`).

## Правила

- Класс `Score` и функцию `apply_bonus` пиши выше строки «Ниже ничего не меняй». Рамку не трогай.
- Записи `Score` должны быть неизменяемыми, исходные записи после вызова менять нельзя.
- Порог `>= 50` остаётся прежним.

## Пример

```python
task_dc16_bonus([["Аня", 60], ["Боря", 20]], 10)
# -> {"frozen": True, "before": [["Аня", 60], ["Боря", 20]], "after": [["Аня", 70], ["Боря", 20]]}
```

## Учебные цели

- Сделать запись frozen и обновлять её через `replace`.
- Перейти от изменения «на месте» к возврату нового списка.
- Сохранить старое правило (порог бонуса), меняя способ работы с записью.

## Проверка понимания
