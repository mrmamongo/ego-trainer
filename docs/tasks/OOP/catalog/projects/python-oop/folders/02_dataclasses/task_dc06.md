# Задача DC06: Очки в замороженной записи

## Условие

### Как это работает

Запись с `frozen=True` менять нельзя. Присваивание полю падает с `FrozenInstanceError`:

```python
@dataclass(frozen=True)
class Coin:
    kind: str
    value: int

coins = [Coin("медь", 1), Coin("серебро", 5)]
coins[0].value = 2                          # FrozenInstanceError
coins[0] = replace(coins[0], value=2)       # верно: в списке теперь новая запись
```

| Запись | Что происходит |
|---|---|
| `coins[0].value = 2` | ошибка, запись неизменяема |
| `coins[0] = replace(coins[0], value=2)` | в ячейку списка кладётся новая запись с другим `value` |

Менять приходится не запись, а **то, что лежит в списке на этом месте**.

### Задание

Функция `add_points(scores, player, bonus)` добавляет бонусные очки игроку в списке записей `Score`, но падает с `FrozenInstanceError`. Запись `Score` должна остаться замороженной (результат матча менять нельзя): рамка внизу файла проверяет и это. Исправь функцию: вместо присваивания полю положи в список новую запись через `replace`.

## Аргументы

- `rows` — список пар `[игрок, очки]` (может быть пустым, имена могут повторяться).
- `player` — имя игрока, строка.
- `bonus` — сколько очков добавить, целое число (может быть отрицательным).

## Возвращает

Словарь с двумя ключами: `"frozen"` (`True`, если запись `Score` нельзя менять) и `"table"` (пары `[игрок, очки]` в прежнем порядке; у каждой записи игрока `player` очки увеличены на `bonus`).

## Правила

- Класс `Score` остаётся `frozen=True`, его менять не нужно.
- Исправь только строку, которая меняет очки в функции `add_points`. Рамку внизу файла не трогай.
- Список `rows` менять нельзя.

## Пример

```python
task_dc06_add_points([["Аня", 10], ["Боря", 5]], "Аня", 3)
# -> {"frozen": True, "table": [["Аня", 13], ["Боря", 5]]}
task_dc06_add_points([], "Аня", 5)   # -> {"frozen": True, "table": []}
```

## Учебные цели

- Узнавать `FrozenInstanceError` и понимать, откуда он.
- Заменять изменение поля на `replace` и подстановку новой записи в список.
- Не снимать `frozen`, когда по смыслу запись менять нельзя.

## Проверка понимания

Почему достаточно заменить запись в списке, а сам класс `Score` менять не нужно? Что случится, если вызвать `replace(...)` и не сохранить результат?
