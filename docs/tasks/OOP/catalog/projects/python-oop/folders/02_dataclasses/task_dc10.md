# Задача DC10: Квест с тегами

## Условие

### Как это работает

Поле-список в dataclass всегда объявляют через `default_factory`, чтобы у каждого объекта был свой список:

```python
@dataclass
class Cart:
    owner: str
    items: list = field(default_factory=list)

    def add(self, product):
        self.items.append(product)
        return len(self.items)
```

| Действие | Результат | Почему |
|---|---|---|
| `["new", "Аня"]` | `"ok"` | создан объект со своим пустым `items` |
| `["add", "чай"]` | `1` | в списке один товар |
| `["new", "Боря"]` | `"ok"` | новая корзина, список снова пуст |
| `["get", "items"]` | `[]` | чужие товары сюда не попали |

### Задание

Напиши класс `Quest`: dataclass с полями `title` (строка), `reward` (целое, по умолчанию `10`) и `tags` (список, по умолчанию свой пустой) и двумя методами:

- `add_tag(tag)` добавляет тег в `tags`, если такого ещё нет, и возвращает, сколько тегов теперь в квесте;
- `has_tag(tag)` возвращает `True`, если тег есть, иначе `False`.

Импорт `dataclass` и `field` уже написан.

## Аргументы

- `actions` — список действий сценария. Первое действие — `["new", ...]`: создать объект класса `Quest` с этими аргументами. Дальше: `["get", "поле"]` прочитать поле, `["set", "поле", значение]` записать поле, `["имя_метода", аргументы...]` вызвать метод.

## Возвращает

Список результатов, по одному на действие: `"ok"` для `new` и `set`, значение поля для `get`, то, что вернул метод. Если действие бросило ошибку, результат такой: `["error", "ИмяОшибки", "сообщение"]`. Объект вместо значения превращается в имя его класса.

## Правила

- Пиши только класс выше строки «Ниже ничего не меняй». Рамку (`def task_...` и `given_...`) не трогай: она создаёт объект и выполняет сценарий.
- Методы должны **возвращать** значения, а не печатать их.
- `Quest` должен быть dataclass и иметь методы `add_tag` и `has_tag`.

## Пример

```python
task_dc10_quest([["new", "Волки"], ["add_tag", "бой"], ["has_tag", "бой"]])   # -> ["ok", 1, True]
task_dc10_quest([["new", "Лис", 50], ["get", "reward"]])                      # -> ["ok", 50]
```

## Учебные цели

- Объявлять поле-список через `field(default_factory=list)`.
- Писать метод, который изменяет список внутри объекта.
- Проверять, что объекты не делят изменяемое поле.

## Проверка понимания

Почему после `add_tag` у второго квеста список остаётся пустым? Что вернёт повторный `add_tag` с тем же тегом?
