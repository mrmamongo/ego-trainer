# Задача DC01: Две записи с одинаковыми полями

## Условие

### Как это работает

Декоратор `@dataclass` превращает класс в запись: сам пишет создание объекта, вывод и сравнение. Сравнение `==` смотрит на **поля**, а `is` проверяет, один ли это объект.

```python
from dataclasses import dataclass

@dataclass
class Player:
    name: str
    hp: int

a = Player("Аня", 100)     # 1
b = Player("Аня", 100)     # 2
c = a                      # 3
a.hp = 70                  # 4
```

| После строки | Что получилось |
|---|---|
| 1 | создан объект, `a.hp` равно `100` |
| 2 | создан **другой** объект с теми же полями: `a == b` равно `True`, а `a is b` равно `False` |
| 3 | `c` — второе имя того же объекта, что и `a` |
| 4 | поле изменили у объекта `a`, значит и `c.hp` стало `70`; у `b` осталось `100`, и теперь `a == b` равно `False` |

Печать записи показывает класс и все поля: `Player(name='Аня', hp=100)`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_dc01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что `==` у dataclass сравнивает поля, а `is` — сам объект.
- Видеть, что два имени одного объекта меняют его вместе, а другой объект остаётся прежним.
- Узнавать вид `repr` записи: `Имя(поле=значение, ...)`.
