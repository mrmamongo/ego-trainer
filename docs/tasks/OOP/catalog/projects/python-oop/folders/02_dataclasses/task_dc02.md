# Задача DC02: Значения по умолчанию в квесте

## Условие

### Как это работает

Поле dataclass может иметь значение по умолчанию. Для списка его задают через `field(default_factory=list)`: для **каждого** нового объекта создаётся свой пустой список.

```python
from dataclasses import dataclass, field

@dataclass
class Order:
    client: str
    discount: int = 0
    items: list = field(default_factory=list)

x = Order("Аня")                 # 1
y = Order("Боря", 15)            # 2
x.items.append("чай")            # 3
z = Order("Вика")                # 4
```

| После строки | Что получилось |
|---|---|
| 1 | `x.discount` равно `0` (взято по умолчанию), `x.items` равно `[]` |
| 2 | `y.discount` равно `15` (передали), `y.items` равно `[]` (свой список) |
| 3 | `x.items` равно `["чай"]`, у `y` список не изменился |
| 4 | `z.items` равно `[]`: у каждого объекта список новый, а не общий |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_dc02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, какое значение поле получает, если его не передали.
- Понимать, что `default_factory` создаёт отдельный список для каждого объекта.
- Помнить, что `==` у dataclass сравнивает все поля, включая списки.

## Проверка понимания

Что изменилось бы в ответах, если бы у всех квестов список тегов был один общий? Какая строка кода делает его отдельным у каждого?
