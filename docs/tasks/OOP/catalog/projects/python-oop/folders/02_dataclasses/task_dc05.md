# Задача DC05: Склад не находит свой товар

## Условие

### Как это работает

Сравнение `==` по полям пишет сам `@dataclass`. Его можно выключить параметром `eq=False`: тогда запись сравнивается как обычный объект, то есть так же, как `is`. Два объекта с одинаковыми полями считаются разными, и `in` по списку ничего не находит:

```python
@dataclass(eq=False)
class Coin:
    value: int

Coin(5) == Coin(5)          # False: это два разных объекта
Coin(5) in [Coin(5)]        # False
```

Без `eq=False` (по умолчанию `eq=True`) тот же код работает:

```python
@dataclass
class Coin:
    value: int

Coin(5) == Coin(5)          # True
Coin(5) in [Coin(5)]        # True
```

| Декоратор | `Coin(5) in [Coin(5)]` |
|---|---|
| `@dataclass(eq=False)` | `False` |
| `@dataclass` | `True` |

### Задание

Функция `task_dc05_has_item(stock, name, qty)` должна ответить, есть ли на складе запись `Item(name, qty)`. Но она всегда возвращает `False`: у класса `Item` выключено сравнение по полям. Исправь декоратор класса `Item`, чтобы записи с равными полями считались равными.

## Аргументы

- `stock` — список пар `[название, количество]` (может быть пустым).
- `name` — название товара, строка.
- `qty` — количество, целое число.

## Возвращает

`True`, если в `stock` есть пара с этим названием **и** этим количеством, иначе `False`.

## Правила

- Исправляй только строку с декоратором класса `Item`; остальной код оставь как есть.
- Класс `Item` должен остаться dataclass.
- Список `stock` менять нельзя.

## Пример

```python
task_dc05_has_item([["Меч", 3], ["Щит", 1]], "Щит", 1)   # -> True
task_dc05_has_item([["Меч", 3], ["Щит", 1]], "Щит", 2)   # -> False
task_dc05_has_item([], "Меч", 1)                         # -> False
```

## Учебные цели

- Объяснять, что именно делает параметр `eq` у `@dataclass`.
- Понимать, почему при `eq=False` равные по полям записи считаются разными.
- Видеть, что `in` для списка опирается на `==`.

## Проверка понимания

Что вернёт `Item('Меч', 3) == Item('Меч', 3)` при `eq=False` и при обычном `@dataclass`? Почему?
