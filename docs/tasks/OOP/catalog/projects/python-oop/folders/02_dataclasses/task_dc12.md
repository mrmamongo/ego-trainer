# Задача DC12: Сообщение из словаря и обратно

## Условие

### Как это работает

Переход «запись → словарь» делает метод: он знает свои поля через `self`. Переход «словарь → запись» делает обычная функция, потому что объекта ещё нет.

```python
@dataclass
class Point:
    x: int
    y: int = 0

    def to_dict(self):
        return {"x": self.x, "y": self.y}


def point_from_dict(data):
    return Point(data["x"], data.get("y", 0))
```

| Вызов | Результат |
|---|---|
| `point_from_dict({"x": 3})` | запись `Point(x=3, y=0)` |
| `point_from_dict({"x": 3, "y": 4, "z": 9}).to_dict()` | `{"x": 3, "y": 4}`: лишний ключ `z` пропал |

Необязательный ключ достают через `data.get("ключ", запасное)`, обязательный через `data["ключ"]`.

### Задание

Напиши класс `Message` (dataclass с полями `author`, `text` и `likes`, по умолчанию `0`) с методом `to_dict()`, который возвращает словарь из трёх ключей `"author"`, `"text"`, `"likes"`. Напиши функцию `message_from_dict(data)`: она создаёт `Message` из словаря. Ключ `"likes"` может отсутствовать (тогда `0`), лишние ключи игнорируются.

Рамка внизу файла (`task_dc12_normalize`) проверяет их вместе: превращает словарь в запись и обратно в словарь.

## Аргументы

- `data` — словарь с ключами `"author"` и `"text"` (строки), необязательным `"likes"` (целое) и, возможно, другими лишними ключами.

## Возвращает

Словарь `{"author": ..., "text": ..., "likes": ...}` ровно с тремя ключами; если `"likes"` не было, то `0`.

## Правила

- Класс и функцию пиши выше строки «Ниже ничего не меняй». Рамку `task_dc12_normalize` не трогай.
- `Message` должен быть dataclass с методом `to_dict`.
- Словарь `data` менять нельзя.

## Пример

```python
task_dc12_normalize({"author": "Аня", "text": "привет", "likes": 3})   # -> {"author": "Аня", "text": "привет", "likes": 3}
task_dc12_normalize({"author": "Боря", "text": "hi", "id": 5})          # -> {"author": "Боря", "text": "hi", "likes": 0}
```

## Учебные цели

- Написать метод `to_dict`, который собирает словарь из полей `self`.
- Написать обычную функцию, которая создаёт запись из словаря.
- Подставлять значение по умолчанию для необязательного ключа.
