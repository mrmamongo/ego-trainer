# Сравнение записей и вывод: `__eq__` и `__repr__`

В папке 01 два разных объекта с одинаковыми полями **не были равны**: обычный класс сравнивает их так же, как `is`. У dataclass `==` сравнивает **поля по порядку**. А `is` по-прежнему спрашивает: «это один и тот же объект?»

```python
@dataclass
class Item:
    name: str
    qty: int

a = Item("Меч", 3)     # 1
b = Item("Меч", 3)     # 2
c = a                  # 3
```

| Выражение | Результат | Почему |
|---|---|---|
| `a == b` | `True` | все поля равны |
| `a is b` | `False` | два разных объекта |
| `a is c` | `True` | `c` и `a` — одно имя для одного объекта |
| `a == Item("Меч", 4)` | `False` | поле `qty` отличается |
| `a == {"name": "Меч", "qty": 3}` | `False` | запись и словарь — разные типы |

Поэтому записи удобно искать в списке: `Item("Меч", 3) in items` сравнивает по полям и находит нужную.

## repr: как запись выглядит в выводе

`print(a)` и `repr(a)` дают читаемую строку с именем класса и всеми полями:

```python
repr(a)     # "Item(name='Меч', qty=3)"
```

Такую же строку ты увидишь внутри списка: `[Item(name='Меч', qty=3)]`. В результатах проверки объект класса часто показывается именно так, а в сценариях рамка заменяет объект на имя его класса.

## order=True: порядок «меньше-больше»

Если написать `@dataclass(order=True)`, записи можно сравнивать через `<` и сортировать через `sorted(records)`. Сравнение идёт по полям слева направо: сначала первое поле, при равенстве второе, и так далее.

```python
@dataclass(order=True)
class Score:
    points: int
    player: str

Score(5, "Аня") < Score(7, "Боря")      # True, по первому полю
```

Для большинства задач проще явная сортировка с `key=`, о ней в последней карточке папки.

## Частые ошибки

Ждать равенства от обычного класса:

```python
class Item:                       # неверно: нет @dataclass
    def __init__(self, name, qty): ...

Item("Меч", 3) == Item("Меч", 3)  # False: сравниваются как разные объекты
```

Верно: `@dataclass` перед классом, и `==` сравнит поля.

## Проверь себя

```python
@dataclass
class Player:
    name: str
    hp: int

p = Player("Аня", 100)
q = Player("Аня", 100)
r = q
r.hp = 50
```

1. Чему равно `p == q` **после** строки `r.hp = 50`?
2. Чему равно `q is r`?
3. Что покажет `repr(q)`?

<details><summary>Ответ</summary>

1. `False`: `r` и `q` один объект, у него теперь `hp=50`, а у `p` осталось `100`.
2. `True`.
3. `"Player(name='Аня', hp=50)"`.

</details>
