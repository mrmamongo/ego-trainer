# Задача DC08: Собери стоимость склада по записям

## Условие

### Как это работает

Данные часто приходят словарями. Чтобы работать с ними как с записями, на каждом проходе цикла создают запись из словаря и дальше берут поля через точку:

```python
total = 0
for data in rows:
    item = Item(data["name"], data["qty"], data["price"])
    total = total + item.qty * item.price
return total
```

**Паспорт роли «накопитель суммы»** (имя `total`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + ...` внутри цикла | после цикла |

**Отступы** показывают вложенность: запись создаётся под `for`, а прибавление под `if` ещё глубже.

### Задание

В файле задачи в комментарии записаны строки функции `task_dc08_stock_value(rows, min_price)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция считает стоимость склада (количество на цену) только по товарам с ценой не ниже `min_price`.

## Аргументы

- `rows` — список словарей `{"name": строка, "qty": целое, "price": целое}` (может быть пустым).
- `min_price` — наименьшая цена, с которой товар учитывается, целое число.

## Возвращает

Целое число: сумма `qty * price` по товарам, у которых `price >= min_price`; для пустого списка `0`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Класс `Item` не меняй.

## Пример

```python
rows = [{"name": "Меч", "qty": 2, "price": 100}, {"name": "Щит", "qty": 1, "price": 50}]
task_dc08_stock_value(rows, 0)    # -> 250
task_dc08_stock_value(rows, 60)   # -> 200
task_dc08_stock_value([], 10)     # -> 0
```

## Учебные цели

- Создавать запись из словаря на каждом проходе цикла.
- Собрать шаблон «накопитель суммы» с условием внутри цикла.
- Расставлять отступы для цикла и вложенного `if`.
