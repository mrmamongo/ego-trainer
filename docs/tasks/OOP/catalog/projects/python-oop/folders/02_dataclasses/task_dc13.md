# Задача DC13: Топ таблицы результатов

## Условие

### Как это работает

Список записей сортируют через `sorted` и `key=`: функция в `key` достаёт из записи то, по чему сравнивать. Для убывания числа ставят минус; для нескольких критериев `key` возвращает кортеж.

```python
@dataclass
class Item:
    name: str
    qty: int

items = [Item("чай", 5), Item("кофе", 9), Item("сок", 5)]
ordered = sorted(items, key=lambda item: (-item.qty, item.name))
# кофе (9), затем сок (5) и чай (5): при равном qty порядок по имени
```

| Запись | Порядок |
|---|---|
| `key=lambda item: item.qty` | по возрастанию количества |
| `key=lambda item: -item.qty` | по убыванию количества |
| `key=lambda item: (-item.qty, item.name)` | по убыванию, при равных по имени |

Результат наружу отдают простыми списками, а не записями: `[item.name, item.qty]`.

### Задание

Класс `Score` уже написан. Напиши функцию `task_dc13_top_scores(rows, n)`: создай запись `Score` для каждой пары, отсортируй записи по очкам по убыванию (при равных очках по имени игрока по алфавиту) и верни первые `n` как пары `[игрок, очки]`.

## Аргументы

- `rows` — список пар `[игрок, очки]` (может быть пустым, имена могут повторяться).
- `n` — сколько лучших вернуть, целое от 0.

## Возвращает

Список из не более чем `n` пар `[игрок, очки]` в порядке убывания очков; при равных очках по имени игрока по алфавиту.

## Правила

- Класс `Score` не меняй, он нужен для записей.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `rows` менять нельзя.

## Пример

```python
task_dc13_top_scores([["Аня", 50], ["Боря", 70], ["Вика", 60]], 2)   # -> [["Боря", 70], ["Вика", 60]]
task_dc13_top_scores([], 5)                                         # -> []
```

## Учебные цели

- Построить список записей из списка пар.
- Отсортировать записи через `sorted` и `key` с двумя критериями.
- Вернуть простые списки вместо записей.

## Проверка понимания
