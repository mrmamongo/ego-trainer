# @dataclass: запись без лишнего кода

Рамку-сценарий, по которой проверяются задачи про классы, мы разобрали в папке 01. Здесь она та же: ты пишешь класс, а готовая рамка внизу файла создаёт объект и выполняет действия.

Часто класс нужен просто как **запись**: несколько полей, собранных вместе. В «Python с нуля» такая запись была словарём `{"name": "Меч", "qty": 3}`. Класс из папки 01 делает то же, но кода в нём много:

```python
class Item:
    def __init__(self, name, qty):
        self.name = name
        self.qty = qty
```

Декоратор `@dataclass` пишет этот `__init__` за тебя. Тебе остаётся перечислить **поля** и их типы:

```python
from dataclasses import dataclass

@dataclass
class Item:
    name: str
    qty: int
```

Теперь `Item("Меч", 3)` работает: аргументы по порядку попадают в поля `name` и `qty`. Кроме `__init__`, Python сам напишет `__repr__` (как объект печатается) и `__eq__` (как объекты сравниваются, об этом следующая карточка).

```python
item = Item("Меч", 3)          # 1
a = item.name                  # 2
item.qty = item.qty + 1        # 3
text = repr(item)              # 4
```

| После строки | Что получилось |
|---|---|
| 1 | запись с полями `name="Меч"`, `qty=3` |
| 2 | `a` равно `"Меч"` |
| 3 | поле `qty` стало `4` |
| 4 | `text` равно `"Item(name='Меч', qty=4)"` |

Было `item["qty"]`, стало `item.qty`: поле берут через точку, а не через квадратные скобки. Методы в dataclass пишут как в обычном классе: `def total(self): ...`.

Типы после двоеточия (`str`, `int`) нужны читателю и редактору. Python их **не проверяет**: `Item("Меч", "много")` тоже создастся. Порядок полей в классе равен порядку аргументов при создании.

## Частые ошибки

Забыть декоратор:

```python
class Item:                 # неверно: нет @dataclass
    name: str
    qty: int

Item("Меч", 3)              # TypeError: класс не принимает аргументов
```

```python
@dataclass                  # верно
class Item:
    name: str
    qty: int
```

Ещё одна ловушка: поле без типа. `name = ""` внутри dataclass **не поле**, а обычная переменная класса. Поле всегда записывают как `имя: тип`.

## Проверь себя

```python
@dataclass
class Player:
    name: str
    hp: int

p = Player("Аня", 100)
p.hp = p.hp - 30
```

1. Чему равно `p.hp`?
2. Что напечатает `print(p)`?
3. Что произойдёт при `Player("Боря")`?

<details><summary>Ответ</summary>

1. `70`.
2. `Player(name='Аня', hp=70)`.
3. Ошибка `TypeError`: не передан обязательный аргумент `hp`.

</details>
