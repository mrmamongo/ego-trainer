# Задача DC14: Популярные сообщения чата

## Условие

### Как это работает

Типичная цепочка работы с данными: **словари → записи → отбор и сортировка → словари**.

```python
def top_names(rows, limit):
    people = []
    for data in rows:
        person = Person(data["name"], data.get("age", 0))   # словарь -> запись
        if person.age >= limit:                              # отбор по полю
            people.append(person)
    ordered = sorted(people, key=lambda person: person.age)  # сортировка
    return [person.to_dict() for person in ordered]          # запись -> словарь
```

| Шаг | Что происходит |
|---|---|
| `Person(data["name"], data.get("age", 0))` | необязательный ключ получает запасное значение |
| `if person.age >= limit` | условие читается по полю записи |
| `sorted(..., key=lambda person: person.age)` | порядок задаёт поле |
| `person.to_dict()` | наружу уходят словари, а не записи |

### Задание

Класс `Message` с методом `to_dict()` уже написан. Напиши функцию `task_dc14_popular(items, min_likes)`: для каждого словаря из `items` создай запись `Message` (ключа `"likes"` может не быть, тогда `0`), оставь сообщения с `likes >= min_likes`, отсортируй по лайкам по убыванию (при равных по автору по алфавиту) и верни список словарей через `to_dict()`.

## Аргументы

- `items` — список словарей `{"author": строка, "text": строка}` с необязательным ключом `"likes"` (целое). Список может быть пустым.
- `min_likes` — наименьшее число лайков, целое.

## Возвращает

Список словарей `{"author": ..., "text": ..., "likes": ...}` в порядке убывания лайков, при равных по автору по алфавиту; для пустого результата `[]`.

## Правила

- Класс `Message` не меняй.
- Функция должна **вернуть** значение через `return`, а не печатать его.
- Список `items` и словари в нём менять нельзя.

## Пример

```python
task_dc14_popular([{"author": "Аня", "text": "раз", "likes": 5}, {"author": "Боря", "text": "два"}], 1)
# -> [{"author": "Аня", "text": "раз", "likes": 5}]
task_dc14_popular([], 1)   # -> []
```

## Учебные цели

- Пройти цепочку словарь → запись → отбор → сортировка → словарь.
- Использовать метод `to_dict` готового класса.
- Задать порядок сортировки по двум полям.

## Проверка понимания

Что вернёт функция, если ни у кого нет нужных лайков? Почему в ответе стоят словари, а не записи `Message`?
