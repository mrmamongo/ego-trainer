# Задача DC09: Игрок со здоровьем

## Условие

### Как это работает

Запись и поведение живут в одном классе: поля перечисляют после `@dataclass`, а методы пишут ниже, как в обычном классе. В методах поля берут через `self`.

```python
@dataclass
class Wallet:
    owner: str
    coins: int = 0

    def add(self, amount):
        self.coins = self.coins + amount
        return self.coins
```

Сценарий для такого класса:

| Действие | Результат | Почему |
|---|---|---|
| `["new", "Аня"]` | `"ok"` | `coins` взят по умолчанию |
| `["add", 5]` | `5` | `0 + 5` |
| `["get", "owner"]` | `"Аня"` | поле читается напрямую |

Рамка внизу файла (`given_play`) создаёт объект и выполняет действия по списку.

### Задание

Напиши класс `Player`: dataclass с полями `name` (строка) и `hp` (целое, по умолчанию `100`) и тремя методами:

- `take_damage(amount)` вычитает урон из `hp` (но `hp` не бывает меньше `0`) и возвращает новое `hp`. Если `amount` отрицательный, бросает `ValueError("урон не может быть отрицательным")`, а `hp` не меняется;
- `heal(amount)` прибавляет `amount` к `hp` (но `hp` не бывает больше `100`) и возвращает новое `hp`;
- `is_alive()` возвращает `True`, если `hp` больше `0`, иначе `False`.

Импорт `dataclass` уже написан.

## Аргументы

- `actions` — список действий сценария. Первое действие — `["new", ...]`: создать объект класса `Player` с этими аргументами. Дальше: `["get", "поле"]` прочитать поле, `["set", "поле", значение]` записать поле, `["имя_метода", аргументы...]` вызвать метод.

## Возвращает

Список результатов, по одному на действие: `"ok"` для `new` и `set`, значение поля для `get`, то, что вернул метод. Если действие бросило ошибку, результат такой: `["error", "ИмяОшибки", "сообщение"]`. Объект вместо значения превращается в имя его класса.

## Правила

- Пиши только класс выше строки «Ниже ничего не меняй». Рамку (`def task_...` и `given_...`) не трогай: она создаёт объект и выполняет сценарий.
- Методы должны **возвращать** значения, а не печатать их.
- `Player` должен быть dataclass и иметь методы `take_damage`, `heal`, `is_alive`.

## Пример

```python
task_dc09_player([["new", "Аня"], ["take_damage", 30], ["is_alive"]])   # -> ["ok", 70, True]
task_dc09_player([["new", "Боря", 50], ["take_damage", 80]])           # -> ["ok", 0]
```

## Учебные цели

- Написать dataclass с полем по умолчанию и несколькими методами.
- Менять поля через `self` и возвращать результат из метода.
- Бросать `ValueError` из метода и не менять состояние при ошибке.

## Проверка понимания

Что вернёт `take_damage(500)` для игрока со здоровьем 40? Чему будет равно `hp` после `take_damage(-5)` с ошибкой?
