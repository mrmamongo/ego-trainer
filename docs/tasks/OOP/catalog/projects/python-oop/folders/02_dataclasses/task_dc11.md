# Задача DC11: Профиль, который не меняют

## Условие

### Как это работает

Запись, которую нельзя менять после создания, объявляют как `@dataclass(frozen=True)`. Методы в ней только читают поля:

```python
@dataclass(frozen=True)
class Coupon:
    code: str
    percent: int = 10

    def label(self):
        return f"{self.code}: -{self.percent}%"
```

| Действие | Результат | Почему |
|---|---|---|
| `["new", "SALE"]` | `"ok"` | `percent` взят по умолчанию |
| `["label"]` | `"SALE: -10%"` | метод читает поля |
| `["set", "percent", 50]` | `["error", "FrozenInstanceError", "cannot assign to field 'percent'"]` | запись заморожена |

Рамка ловит ошибку и записывает её в результат, поэтому программа не падает.

### Задание

Напиши класс `Profile`: неизменяемая запись (dataclass с `frozen=True`) с полями `name` (строка) и `level` (целое, по умолчанию `1`) и методом `describe()`, который возвращает строку вида `"Аня, уровень 1"`.

Импорт, декоратор `@dataclass(frozen=True)` и заготовка метода уже написаны: допиши поля и тело метода.

## Аргументы

- `actions` — список действий сценария. Первое действие — `["new", ...]`: создать объект класса `Profile` с этими аргументами. Дальше: `["get", "поле"]` прочитать поле, `["set", "поле", значение]` записать поле, `["имя_метода", аргументы...]` вызвать метод.

## Возвращает

Список результатов, по одному на действие: `"ok"` для `new` и `set`, значение поля для `get`, то, что вернул метод. Если действие бросило ошибку, результат такой: `["error", "ИмяОшибки", "сообщение"]`. Объект вместо значения превращается в имя его класса.

## Правила

- Пиши только класс выше строки «Ниже ничего не меняй». Рамку (`def task_...` и `given_...`) не трогай: она создаёт объект и выполняет сценарий.
- Методы должны **возвращать** значения, а не печатать их.
- `Profile` должен быть dataclass и иметь метод `describe`; менять поля после создания нельзя.

## Пример

```python
task_dc11_profile([["new", "Аня"], ["describe"]])               # -> ["ok", "Аня, уровень 1"]
task_dc11_profile([["new", "Аня"], ["set", "level", 9]])       # -> ["ok", ["error", "FrozenInstanceError", "cannot assign to field 'level'"]]
```

## Учебные цели

- Объявить frozen-запись и увидеть `FrozenInstanceError` в сценарии.
- Писать метод, который только читает поля.
- Собирать строку из полей через f-строку.
