# Задача DC15: Квест получает статус

## Условие

### Как это работает

Сейчас класс описывает квест двумя полями и умеет показывать описание:

```python
@dataclass
class Quest:                                   # 1
    title: str                                 # 2
    reward: int                                # 3

    def summary(self):                         # 4
        return f"{self.title}: {self.reward}"  # 5
```

**Где реализовано старое правило:** метод `summary` в строках 4-5.

**Что меняется:** у квеста появляется состояние «выполнен». Новое поле нужно с **значением по умолчанию**, иначе старый вызов `Quest("Волки", 100)` сломается:

```python
    done: bool = False
```

А метод `summary` для выполненного квеста должен дописывать в конец текст `" (готово)"`.

**Что нельзя трогать:** порядок и смысл полей `title`, `reward` и вид описания для невыполненного квеста.

### Задание

Раньше у квеста были поля `title` и `reward` и метод `summary()`. Теперь добавь:

- поле `done` (`True` или `False`), по умолчанию `False`;
- метод `finish()`: помечает квест выполненным и возвращает награду `reward`; если квест уже выполнен, бросает `ValueError("квест уже выполнен")`;
- в `summary()` выполненный квест получает в конце `" (готово)"`: `"Волки: 100 (готово)"`. Невыполненный выглядит как раньше: `"Волки: 100"`.

Измени готовый класс, не переписывай его с нуля.

## Аргументы

- `actions` — список действий сценария. Первое действие — `["new", ...]`: создать объект класса `Quest` с этими аргументами. Дальше: `["get", "поле"]` прочитать поле, `["set", "поле", значение]` записать поле, `["имя_метода", аргументы...]` вызвать метод.

## Возвращает

Список результатов, по одному на действие: `"ok"` для `new` и `set`, значение поля для `get`, то, что вернул метод. Если действие бросило ошибку, результат такой: `["error", "ИмяОшибки", "сообщение"]`. Объект вместо значения превращается в имя его класса.

## Правила

- Пиши только класс выше строки «Ниже ничего не меняй». Рамку (`def task_...` и `given_...`) не трогай: она создаёт объект и выполняет сценарий.
- Методы должны **возвращать** значения, а не печатать их.
- Старые вызовы `Quest(title, reward)` и результат `summary()` для невыполненного квеста должны остаться прежними.

## Пример

```python
task_dc15_quest([["new", "Волки", 100], ["summary"]])             # -> ["ok", "Волки: 100"]
task_dc15_quest([["new", "Волки", 100], ["finish"], ["summary"]]) # -> ["ok", 100, "Волки: 100 (готово)"]
```

## Учебные цели

- Добавить в dataclass поле со значением по умолчанию, не ломая старые вызовы.
- Расширить существующий метод новой веткой, сохранив старый результат.
- Написать метод, меняющий состояние и бросающий ошибку.
