# Задача DC07: Допиши поле строки заказа

## Условие

### Как это работает

Поле со значением по умолчанию записывают так: `имя: тип = значение`. Такие поля идут **после** полей без значения.

```python
@dataclass
class Task:
    title: str
    done: bool = False

Task("Купить хлеб")             # done равно False
Task("Купить хлеб", True)       # done равно True
```

| Запись | Что значит |
|---|---|
| `title: str` | обязательное поле, без него объект не создать |
| `done: bool = False` | поле необязательное, по умолчанию `False` |

### Задание

Класс `OrderLine` описывает строку заказа: товар, цену и количество. Метод `total` уже использует поле `count`, но самого поля нет. Допиши одну недостающую строку: поле `count` (целое число) со значением по умолчанию `1`.

## Аргументы

- `actions` — список действий сценария. Первое действие — `["new", ...]`: создать объект класса `OrderLine` с этими аргументами. Дальше: `["get", "поле"]` прочитать поле, `["set", "поле", значение]` записать поле, `["имя_метода", аргументы...]` вызвать метод.

## Возвращает

Список результатов, по одному на действие: `"ok"` для `new` и `set`, значение поля для `get`, то, что вернул метод. Если действие бросило ошибку, результат такой: `["error", "ИмяОшибки", "сообщение"]`. Объект вместо значения превращается в имя его класса.

## Правила

- Допиши одну недостающую строку, остальной код не меняй.
- Рамку (`def task_...` и `given_...`) не трогай.

## Пример

```python
task_dc07_line([["new", "Чай", 50], ["total"]])         # -> ["ok", 50]
task_dc07_line([["new", "Кофе", 120, 3], ["total"]])    # -> ["ok", 360]
```

## Учебные цели

- Объявлять поле dataclass с типом и значением по умолчанию.
- Помнить порядок: поля без значения идут первыми.
- Видеть, как метод опирается на поля класса через `self`.

## Проверка понимания

Что вернёт `total()` для `OrderLine('Чай', 50)` после исправления? Что будет, если поставить `count` выше `price`?
