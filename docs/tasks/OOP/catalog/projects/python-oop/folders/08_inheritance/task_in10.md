# Задача IN10: Премия вместо зарплаты

## Условие

### Как это работает

Переопределённый метод **заменяет** родительский целиком. Часто нужно не заменить, а **добавить**: тогда внутри нового метода зовут `super().метод()` и дописывают своё.

```python
class Pay:
    def __init__(self, base):
        self.base = base

    def total(self):
        return self.base


class Bonus(Pay):
    def total(self):
        return 500                     # заменил: оклад потерялся
```

```python
class Bonus(Pay):
    def total(self):
        return super().total() + 500   # оклад и добавка
```

| Объект | `total()` до исправления | после |
|---|---|---|
| `Bonus(1000)` | `500` | `1500` |

### Задание

Зарплата менеджера должна быть окладом плюс премия, а сейчас метод `salary` возвращает только премию. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Меняй только метод `Manager.salary`; рамку внизу файла не трогай.
- Оклад бери у родителя через `super()`, а не считай сам.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Manager", "Аня", 100, 30]` | `"ok"` |
| `["salary"]` | `130` |
| `["new", "Employee", "Боря", 100]` | `"ok"` |
| `["salary"]` | `100` |

## Учебные цели

- Заметить разницу между заменой и расширением метода.
- Читать сценарий: ответ есть, но он не тот.

## Проверка понимания

Что вернёт `salary()` менеджера с окладом 100 и премией 30 до исправления и после? Почему менеджер не пострадает, если у `Employee` изменят формулу оклада?
