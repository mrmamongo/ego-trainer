# Наследование: класс на основе класса

Бывает, что два класса почти одинаковы. У воина и мага есть имя, здоровье и умение получать урон, а отличается только удар. Копировать код глупо: поправишь в одном месте, забудешь в другом. **Наследование** решает это: новый класс строится на готовом.

```python
class Unit:                      # родитель
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def attack(self):
        return 5


class Warrior(Unit):             # наследник: в скобках родитель
    def attack(self):
        return 12


w = Warrior("Грок", 40)          # 1
a = w.name                       # 2
b = w.attack()                   # 3
c = Unit("Тень", 1).attack()     # 4
```

| Строка | Что происходит |
|---|---|
| 1 | в `Warrior` нет `__init__`, Python берёт его у `Unit`: появляются `name` и `hp` |
| 2 | `a` равно `"Грок"` |
| 3 | в `Warrior` есть свой `attack`, он и срабатывает: `b` равно `12` |
| 4 | родитель остался прежним: `c` равно `5` |

Всё, что есть у родителя, достаётся наследнику бесплатно. Наследник пишет только то, что **отличается**. Связь читается как «воин — это юнит».

Слова: `Unit` — родитель (базовый класс), `Warrior` — наследник (дочерний класс). Наследник можно строить и от наследника, цепочка получится длиннее, но принцип тот же.

В этой папке мы обходимся **одним** родителем. Класс сразу от нескольких родителей (множественное наследование) здесь не нужен.

## Частые ошибки

Наследовать «просто чтобы переиспользовать код», когда связи «это — разновидность» нет. Игрок **имеет** инвентарь, но игрок не является инвентарём. Если «имеет», храни объект в атрибуте, а не наследуй.

```python
class Player(Inventory):         # неверно: игрок — не разновидность инвентаря
    pass
```

```python
class Player:                    # верно: игрок хранит инвентарь в атрибуте
    def __init__(self):
        self.inventory = Inventory()
```

## Проверь себя

```python
class Tool:
    def __init__(self, name):
        self.name = name

    def use(self):
        return "работаю"


class Saw(Tool):
    pass


s = Saw("пила")
x = s.name
y = s.use()
```

Чему равны `x` и `y`? Откуда у `Saw` метод `use`?

<details><summary>Ответ</summary>

`x` равно `"пила"`, `y` равно `"работаю"`. В `Saw` нет ни `__init__`, ни `use`, поэтому Python берёт оба у `Tool`.

</details>
