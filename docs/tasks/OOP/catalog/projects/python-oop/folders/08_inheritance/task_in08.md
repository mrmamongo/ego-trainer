# Задача IN08: Собери урон отряда

## Условие

### Как это работает

Когда у объектов разных классов есть **одноимённый** метод, их можно обработать одним циклом. Цикл не спрашивает «кто ты?», он просто зовёт `unit.attack()`. Класс сам решает, что вернуть.

```python
total = 0
for kind in kinds:
    unit = given_make(kind)          # объект нужного класса
    total = total + unit.attack()    # без if по виду
return total
```

**Паспорт роли «накопитель суммы»** (имя `total`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `0` | `total = total + ...` внутри цикла | после цикла |

Готовый помощник `given_make(kind)` создаёт юнита по названию вида: `"Warrior"`, `"Mage"` или `"Unit"`.

### Задание

В файле задачи записаны строки функции `task_in08_total_damage(kinds)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция складывает удары всех юнитов отряда.

## Аргументы

- `kinds` — список названий видов юнитов: `"Unit"`, `"Warrior"` или `"Mage"` (может быть пустым).

## Возвращает

Целое число: сумма ударов всех юнитов; для пустого списка `0`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Классы и `given_make` не меняй.

## Пример

```python
task_in08_total_damage(["Warrior", "Mage", "Unit"])   # -> 26
task_in08_total_damage(["Mage"])                      # -> 9
task_in08_total_damage([])                            # -> 0
```

## Учебные цели

- Собрать цикл, который вызывает один метод у объектов разных классов.
- Расставить отступы у цикла и накопителя.

## Проверка понимания

Что вернёт функция, если в отряде нет воинов? Почему в цикле нет проверки вида юнита?
