# Задача IN14: Собери комиссии по способам

## Условие

### Как это работает

Результат цикла можно складывать в словарь: ключ — вид, значение — ответ объекта. Вызов `method.fee(amount)` одинаковый для всех видов, а числа получаются разные: за это отвечает класс объекта.

```python
result = {}
for kind in kinds:
    method = given_make(kind)             # объект нужного класса
    result[kind] = method.fee(amount)     # без if по виду
return result
```

**Паспорт роли «словарь-накопитель»** (имя `result`):

| Где заводим | Начальное значение | Как меняем в теле | Когда возвращаем |
|---|---|---|---|
| до цикла | `{}` | `result[ключ] = значение` внутри цикла | после цикла |

Готовый помощник `given_make(kind)` создаёт способ оплаты по названию: `"Cash"`, `"Card"` или `"Crypto"`.

### Задание

В файле задачи записаны строки функции `task_in14_fees(kinds, amount)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция возвращает словарь «название способа → комиссия» для заданной суммы.

## Аргументы

- `kinds` — список названий способов: `"Cash"`, `"Card"` или `"Crypto"` (может быть пустым).
- `amount` — сумма платежа, целое число не меньше нуля.

## Возвращает

Словарь `{название: комиссия}`; для пустого списка пустой словарь `{}`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Классы и `given_make` не меняй.

## Пример

```python
task_in14_fees(["Cash", "Card", "Crypto"], 1000)   # -> {"Cash": 0, "Card": 20, "Crypto": 11}
task_in14_fees(["Card"], 250)                      # -> {"Card": 5}
task_in14_fees([], 500)                            # -> {}
```

## Учебные цели

- Собрать цикл, который складывает ответы полиморфного вызова в словарь.
- Расставить отступы у цикла.

## Проверка понимания
