# Задача IN04: Один цикл, разные уведомления

## Условие

### Как это работает

**Полиморфизм** — когда один и тот же вызов `obj.метод()` делает своё для объектов разных классов. Не нужно проверять, кто перед тобой: каждый объект сам знает, как выполнить метод.

```python
class Pet:                                  # 1
    def voice(self): return "..."           # 2
class Cat(Pet):                             # 3
    def voice(self): return "мяу"           # 4
class Fish(Pet):                            # 5
    pass                                    # 6
words = []                                  # 7
for p in [Cat(), Fish(), Cat()]:            # 8
    words.append(p.voice())                 # 9
```

| Проход | Объект | Какой `voice` сработал | Что добавилось |
|---|---|---|---|
| 1 | `Cat` | свой | `"мяу"` |
| 2 | `Fish` | унаследованный от `Pet` | `"..."` |
| 3 | `Cat` | свой | `"мяу"` |

В итоге `words` равно `["мяу", "...", "мяу"]`. Цикл один и тот же, а работа разная.

### Задание

В списке лежат уведомления разных видов. Один цикл отправляет всем одно и то же сообщение. Найди, что вернёт каждое.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_in04_poly():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Увидеть полиморфизм: один вызов `n.send(...)` ведёт себя по-разному.
- Помнить, что наследник без своего метода использует метод родителя.

## Проверка понимания

Какой из трёх вызовов `send` пришёл из `Notification`? Что пришлось бы писать в цикле, если бы у классов не было общего метода `send`?
