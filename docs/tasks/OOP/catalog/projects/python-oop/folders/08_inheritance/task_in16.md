# Задача IN16: Скидка, которая молчит

## Условие

### Как это работает

Метод наследника заменяет родительский, **только если имя совпало буква в букву**. Если в имени опечатка, Python не заметит ошибку: он просто решит, что это новый метод, а вызов `obj.apply(...)` уйдёт к родителю. Никакой ошибки нет, результат просто неверный.

```python
class Tool:
    def use(self):
        return "ничего"


class Hammer(Tool):
    def usee(self):              # опечатка: это новый метод, а не замена use
        return "бьёт"

Hammer().use()                   # "ничего", а ожидали "бьёт"
```

Как искать: сценарий вернул ответ, но он совпал с ответом **родителя**. Сравни имена методов в наследнике и родителе.

### Задание

`Percent(10).apply(200)` должен вернуть `180`, а возвращает `200`. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Меняй только то, что нужно для исправления; рамку внизу файла не трогай.
- Имена классов и параметры `__init__` оставь как есть.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Percent", 10]` | `"ok"` |
| `["apply", 200]` | `180` |
| `["new", "Fixed", 30]` | `"ok"` |
| `["apply", 100]` | `70` |

## Учебные цели

- Замечать опечатку в имени переопределяемого метода.
- Понимать: ошибки может и не быть, а ответ всё равно будет родительским.

## Проверка понимания

Почему программа не упала, хотя метод назван неверно? Какой метод сработал в `Percent(10).apply(200)` до исправления?
