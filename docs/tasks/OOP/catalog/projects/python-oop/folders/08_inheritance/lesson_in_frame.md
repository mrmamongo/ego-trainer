# Рамка для нескольких классов

В прошлых папках сценарий создавал объект **одного** класса. В этой папке классов несколько (родитель и наследники), поэтому рамка немного расширена. Читается она так же, как карточка «Как читать сценарий», с двумя отличиями.

| Действие | Что делает рамка |
|---|---|
| `["new", "Warrior", "Грок", 40]` | **первым идёт имя класса**: создаёт `Warrior("Грок", 40)`, результат `"ok"` |
| `["is", "Unit"]` | спрашивает `isinstance(obj, Unit)` и возвращает `True` или `False` |
| `["get", "hp"]`, `["set", "hp", 5]` | как раньше: читают и пишут атрибут |
| `["attack"]` | любое другое слово — вызов метода: `obj.attack()` |

В каждом сценарии «текущий» объект один: последний созданный. Новое `"new"` заменяет его.

## Пример

Классы: `Unit(name, hp)` с `attack()` → `5`, `Warrior(Unit)` с `attack()` → `12`.

| Действие | Результат | Почему |
|---|---|---|
| `["new", "Warrior", "Грок", 40]` | `"ok"` | создан воин |
| `["attack"]` | `12` | сработал метод `Warrior` |
| `["is", "Unit"]` | `True` | воин — тоже юнит |
| `["is", "Warrior"]` | `True` | и воин |
| `["new", "Unit", "Тень", 1]` | `"ok"` | теперь текущий объект — юнит |
| `["is", "Warrior"]` | `False` | родитель не наследник |

Ошибки как результат работают как раньше: `["error", тип, сообщение]`. В задачах про абстрактные классы показан только тип: `["error", "TypeError"]`.

Иногда вместо сценария рамка собирает **список объектов разных классов** по описанию и возвращает простые значения (имена, числа). Это написано в условии задачи.

## Частые ошибки

Забыть имя класса в `"new"`: `["new", "Грок", 40]` попросит класс `"Грок"`, и сценарий вернёт ошибку. Имя класса всегда первое.

Ждать, что `["is", "Unit"]` вернёт сам объект: он возвращает только `True` или `False`.

## Проверь себя

Классы те же. Сценарий: `["new", "Unit", "А", 1]`, `["is", "Warrior"]`, `["new", "Warrior", "Б", 2]`, `["is", "Unit"]`, `["attack"]`.

Какой список результатов получится?

<details><summary>Ответ</summary>

`["ok", False, "ok", True, 12]`.

</details>
