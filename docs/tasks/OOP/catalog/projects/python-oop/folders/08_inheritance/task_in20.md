# Задача IN20: Ошибки магазина

## Условие

### Как это работает

Свои исключения — тоже классы-наследники. Ты уже писал `class MyError(Exception): pass`. Если сделать общий класс ошибок проекта и от него наследовать частные, то один `except Общий` поймает их все, а `except Частный` — только свою.

```python
class AppError(Exception):
    pass


class FileError(AppError):
    def __init__(self, name):
        super().__init__("нет файла " + name)     # текст ошибки задаёт родитель


try:
    raise FileError("a.txt")
except AppError as error:                          # поймали наследника через родителя
    print(type(error).__name__, error)             # FileError нет файла a.txt
```

Подробнее про ошибки — в следующей папке. Сейчас важно одно: наследник исключения ведёт себя как обычный наследник.

### Задание

Дополни два класса ошибок магазина. Базовый `ShopError(Exception)` уже написан.

- `OutOfStock(ShopError)` — `__init__(item)` передаёт родителю текст `"нет на складе: "` и название товара;
- `PriceError(ShopError)` — `__init__(price)` передаёт родителю текст `"цена "`, число, `" меньше нуля"` (например, `"цена -5 меньше нуля"`).

Передавай текст через `super().__init__(...)`.

## Аргументы

- `rows` — список строк `[вид, значение]`, где вид — `"stock"`, `"price"`, `"shop"` или любой другой (список может быть пустым).

## Возвращает

Список строк `"ИмяКласса: текст"`; для чужой ошибки `"не наша ошибка: текст"`. Рамка и помощник `given_catch` готовы.

## Правила

- Пиши только классы ошибок; рамку внизу файла не трогай.
- Оба класса наследуют `ShopError`.

## Пример

```python
task_in20_errors([["stock", "меч"], ["price", -5], ["other", "x"]])
# -> ["OutOfStock: нет на складе: меч", "PriceError: цена -5 меньше нуля", "не наша ошибка: x"]
task_in20_errors([])   # -> []
```

## Учебные цели

- Написать наследников исключения с собственным текстом.
- Понять, что `except Родитель` ловит и наследников.

## Проверка понимания
