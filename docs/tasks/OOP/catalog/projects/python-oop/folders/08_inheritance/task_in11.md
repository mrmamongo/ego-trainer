# Задача IN11: Email, Sms и Push

## Условие

### Как это работает

Хороший приём: общий алгоритм держит родитель, а наследники подменяют **только одну маленькую часть**. Родитель вызывает `self.format(text)`, а какой именно `format` сработает, решает класс объекта.

```python
class Printer:
    def line(self, text):
        return "> " + self.style(text)       # общий алгоритм

    def style(self, text):
        return text


class Loud(Printer):
    def style(self, text):
        return text.upper()                  # поменяли только одну часть
```

| Объект | `line("привет")` |
|---|---|
| `Printer()` | `"> привет"` |
| `Loud()` | `"> ПРИВЕТ"` |

`line` написан один раз, а работает для обоих классов. Так наследники не дублируют общий код.

### Задание

Напиши четыре класса уведомлений:

- `Notification(to)` — запоминает адресата в `to` и заводит счётчик `sent = 0`. Метод `format(text)` возвращает текст как есть. Метод `send(text)` увеличивает `sent` на 1 и возвращает строку `адресат + ": " + self.format(text)`;
- `Email(Notification)` — `format` возвращает `"Письмо: " + text`;
- `Sms(Notification)` — `format` возвращает первые 10 символов текста;
- `Push(Notification)` — `format` возвращает текст большими буквами (`upper()`).

Метод `send` пиши **только в родителе**, наследники его не переопределяют.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только классы; рамку внизу файла не трогай.
- Наследники переопределяют только `format`.
- Все три вида наследуют `Notification`.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Sms", "+7900"]` | `"ok"` |
| `["send", "Очень длинное сообщение"]` | `"+7900: Очень длин"` |
| `["get", "sent"]` | `1` |
| `["is", "Notification"]` | `true` |

## Учебные цели

- Вынести общий алгоритм в родителя, а различия — в переопределяемый метод.
- Увидеть, что унаследованный `send` сам находит нужный `format`.
