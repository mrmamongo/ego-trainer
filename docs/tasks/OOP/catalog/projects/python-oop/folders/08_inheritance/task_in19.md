# Задача IN19: Фиксированная скидка

## Условие

### Как это работает

Сейчас есть базовая `Discount` (цену не трогает) и `Percent` (скидка в процентах):

```python
class Discount:
    def apply(self, price):
        return price

class Percent(Discount):
    def __init__(self, percent):
        self.percent = percent
    def apply(self, price):
        return price - price * self.percent // 100
```

**Где реализовано старое правило:** метод `apply` в `Discount` (нет скидки) и в `Percent` (проценты).

**Что меняется:** нужен ещё один вид скидки и подпись у всех видов. Добавляется класс `Fixed(Discount)`: `__init__(amount)`, `apply` вычитает `amount`, но цена не бывает меньше нуля. Всем трём классам добавляется метод `label()`.

**Что нельзя трогать:** результаты `apply` у `Discount` и `Percent`. Старые сценарии должны отвечать так же.

### Задание

Раньше были только `Discount` и `Percent`. Теперь добавь класс `Fixed` (скидка фиксированной суммой) и метод `label()` для всех трёх видов: `Discount` возвращает `"без скидки"`, `Percent(25)` возвращает `"-25%"`, `Fixed(30)` возвращает `"-30"`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Добавляй новое, старый код `apply` не ломай; рамку внизу файла не трогай.
- `Fixed` должен наследовать `Discount`.
- Подпись `label` у каждого класса своя.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Fixed", 30]` | `"ok"` |
| `["apply", 100]` | `70` |
| `["label"]` | `"-30"` |
| `["new", "Percent", 25]` | `"ok"` |
| `["label"]` | `"-25%"` |
| `["new", "Discount"]` | `"ok"` |
| `["label"]` | `"без скидки"` |

## Учебные цели

- Расширить иерархию новым наследником и новым методом, не трогая старое поведение.
- Видеть, что общий вызов `label()` работает у всех видов благодаря полиморфизму.

## Проверка понимания

Что вернёт `Fixed(500).apply(100)`? Что вернёт `label()` у объекта, если в наследнике его не написать?
