# Задача IN15: Ведомость зарплат

## Условие

### Как это работает

Сила наследования видна, когда в одном списке лежат объекты разных классов, а код с ними один. Готовая функция-рамка проходит по сотрудникам и зовёт у каждого `salary()`. Ей всё равно, кто менеджер, а кто стажёр.

```python
class Shape:
    def __init__(self, side):
        self.side = side

    def area(self):
        return self.side * self.side


class Half(Shape):
    def area(self):
        return super().area() // 2


figures = [Shape(4), Half(4), Shape(3)]
areas = [f.area() for f in figures]        # [16, 8, 9]
```

Здесь `Half` не повторяет формулу квадрата, а берёт её у родителя и меняет результат.

### Задание

Напиши классы сотрудников:

- `Employee(name, base)` — запоминает `name` и `base`; `salary()` возвращает оклад `base`;
- `Manager(Employee)` — `__init__(name, base, bonus)` запоминает ещё и `bonus`; `salary()` возвращает оклад плюс премию;
- `Intern(Employee)` — `salary()` возвращает половину оклада (целочисленное деление на 2).

Оклад в `Manager` и `Intern` бери через `super().salary()`.

## Аргументы

- `rows` — список строк `[класс, аргументы...]`, например `["Manager", "Аня", 100, 20]` (список может быть пустым). Проверка сама создаёт объекты из твоих классов.

## Возвращает

Список строк `"имя: зарплата"` в том же порядке; для пустого списка `[]`. Функция-рамка и помощник `given_payroll` уже готовы.

## Правила

- Пиши только классы; рамку внизу файла не трогай.
- `Manager` и `Intern` наследуют `Employee`.
- Не проверяй тип сотрудника через `isinstance` или `if`: каждый класс сам знает свою зарплату.

## Пример

```python
task_in15_payroll([["Manager", "Аня", 100, 20], ["Intern", "Боря", 60], ["Employee", "Вика", 80]])
# -> ["Аня: 120", "Боря: 30", "Вика: 80"]
task_in15_payroll([])   # -> []
```

## Учебные цели

- Написать иерархию, в которой каждый класс по-своему отвечает на `salary()`.
- Использовать `super().salary()` вместо копирования формулы.

## Проверка понимания
