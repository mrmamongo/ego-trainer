# Задача IN06: Маг без имени

## Условие

### Как это работает

Если наследник пишет **свой** `__init__`, то `__init__` родителя автоматически **не вызывается**. Поля родителя не появятся, пока наследник сам не попросит об этом: `super().__init__(...)`.

```python
class Item:
    def __init__(self, name):
        self.name = name

class Sword(Item):
    def __init__(self, name, power):
        self.power = power        # родителя никто не позвал

s = Sword("меч", 3)
s.power                           # 3
s.name                            # AttributeError: у объекта нет атрибута name
```

В сценарии такая ошибка видна как `["error", "AttributeError", "..."]`.

| Действие | Результат |
|---|---|
| `["new", "Sword", "меч", 3]` | `"ok"` |
| `["get", "name"]` | сейчас `["error", "AttributeError", "'Sword' object has no attribute 'name'"]`, а должно быть `"меч"` |

### Задание

Класс `Mage` наследует `Unit` и добавляет ману, но имя и здоровье у мага пропадают. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Меняй только код класса `Mage`; `Unit` и рамку внизу файла не трогай.
- `Mage` должен остаться наследником `Unit`, параметры `__init__` оставь как есть.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Mage", "Мерлин", 30, 50]` | `"ok"` |
| `["get", "mana"]` | `50` |
| `["get", "name"]` | `"Мерлин"` |
| `["is_alive"]` | `true` |

## Учебные цели

- Узнавать `AttributeError` из-за забытого `super().__init__(...)`.
- Помнить: свой `__init__` наследника заменяет родительский, а не дополняет его.

## Проверка понимания

Почему `Mage("Мерлин", 30, 50)` не падает при создании, а ошибка видна только при чтении `name`? Что вернёт `["is", "Unit"]` для мага?
