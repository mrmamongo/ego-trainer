# Задача IN07: Удвой удар лучника

## Условие

### Как это работает

Наследник может не переписывать метод родителя, а **построить на нём**: `super().метод()` вызывает версию родителя, и результат можно изменить.

```python
class Item:
    def __init__(self, price):
        self.price = price

    def cost(self):
        return self.price


class Gift(Item):
    def cost(self):
        return super().cost() + 10      # цена родителя и ещё 10 за упаковку
```

| Объект | `cost()` |
|---|---|
| `Item(100)` | `100` |
| `Gift(100)` | `110` |

Выгода: если правило подсчёта у родителя изменится, наследник подхватит это сам.

### Задание

В классе `Archer` метод `attack` пока возвращает `None`. Впиши вместо `None` выражение: удар родителя, умноженный на 2. Удар родителя бери через `super()`, не пиши число руками.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Замени `None` в `Archer.attack` одним выражением, остальной код не меняй.
- Рамку внизу файла не трогай.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Archer", "Робин", 3]` | `"ok"` |
| `["attack"]` | `14` |
| `["new", "Unit", "Ополченец", 3]` | `"ok"` |
| `["attack"]` | `7` |

## Учебные цели

- Использовать `super().метод()` внутри выражения.
- Видеть, что удар лучника меняется вместе с уровнем, потому что берётся у родителя.

## Проверка понимания

Что вернёт `attack()` у `Archer` уровня 5? Что сломается, если вместо `super().attack()` написать число `10`?
