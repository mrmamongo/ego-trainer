# Задача IN01: Что досталось воину

## Условие

### Как это работает

Класс можно построить на основе другого: `class Warrior(Unit):`. Тогда `Unit` называют **родителем**, а `Warrior` — **наследником**. Всё, что есть у родителя (атрибуты, которые кладёт `__init__`, и методы), доступно наследнику без единой строчки кода. Свои методы наследник дописывает рядом, и если имя совпало, побеждает метод наследника.

```python
class Item:                              # 1
    def __init__(self, name):            # 2
        self.name = name                 # 3
    def title(self):                     # 4
        return "предмет " + self.name    # 5
class Sword(Item):                       # 6
    def power(self):                     # 7
        return 10                        # 8
s = Sword("меч")                         # 9
a = s.title()                            # 10
b = s.power()                            # 11
```

| После строки | Что получилось |
|---|---|
| 9 | `Sword("меч")` нашёл `__init__` у родителя: `s.name` равно `"меч"` |
| 10 | `title` в `Sword` нет, Python берёт его у `Item`: `a` равно `"предмет меч"` |
| 11 | `power` есть только у `Sword`: `b` равно `10` |

### Задание

Класс `Warrior` наследует `Unit` и меняет только удар. Определи, что получат разные юниты.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_in01_inherit():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понять, что наследник получает атрибуты и методы родителя без копирования кода.
- Видеть, что собственный метод наследника побеждает метод родителя с тем же именем.
