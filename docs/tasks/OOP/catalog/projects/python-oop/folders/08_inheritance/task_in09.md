# Задача IN09: Отряд: воин, маг, лучник

## Условие

### Как это работает

Базовый класс хранит общее, наследники меняют только отличия. Для тех, у кого появляются **новые поля**, нужен свой `__init__` с `super().__init__(...)`. Тем, у кого новых полей нет, `__init__` писать не надо: сработает родительский.

```python
class Item:
    def __init__(self, name):
        self.name = name

    def cost(self):
        return 10


class Gem(Item):
    def __init__(self, name, carat):
        super().__init__(name)
        self.carat = carat

    def cost(self):
        return super().cost() * self.carat


class Stone(Item):
    pass                                  # ничего своего: всё от Item
```

В сценарии первым после `"new"` идёт **имя класса**, и работает действие `["is", "Класс"]`: оно спрашивает `isinstance`. Об этом подробнее в карточке «Рамка для нескольких классов».

### Задание

Напиши четыре класса:

- `Unit(name, hp)` — запоминает `name` и `hp`; `attack()` возвращает `5`; `take_damage(damage)` уменьшает `hp` на `damage`, но не ниже нуля, и возвращает новое `hp`;
- `Warrior(Unit)` — `attack()` возвращает `12`; `take_damage(damage)` ослабляет удар на `2` (но не ниже нуля) и дальше делает то же, что у `Unit` (вызови родителя);
- `Mage(Unit)` — `__init__(name, hp, mana)` добавляет атрибут `mana`; `attack()` возвращает `5 + mana // 10`;
- `Archer(Unit)` — `attack()` возвращает `8`; больше ничего своего.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только классы; рамку внизу файла не трогай.
- Все три наследника должны наследовать `Unit`.
- Не копируй `take_damage` из `Unit` в `Warrior` целиком: вызови родительский через `super()`.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Warrior", "Грок", 40]` | `"ok"` |
| `["attack"]` | `12` |
| `["take_damage", 10]` | `32` |
| `["get", "hp"]` | `32` |
| `["is", "Unit"]` | `true` |

## Учебные цели

- Построить небольшую иерархию: общий родитель и три наследника.
- Расширять метод родителя через `super()` и не дублировать код.

## Проверка понимания

Почему у `Archer` и `Warrior` нет `__init__`, а у `Mage` он есть? Что вернёт `take_damage(1)` у воина с `hp` 5?
