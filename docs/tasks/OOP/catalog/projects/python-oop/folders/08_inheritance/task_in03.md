# Задача IN03: Где Python ищет атрибут

## Условие

### Как это работает

Когда ты пишешь `obj.x`, Python ищет `x` по порядку и останавливается на первой находке:

1. в самом объекте (то, что записано через `self.x = ...`);
2. в классе объекта;
3. в родителе класса, потом в родителе родителя и так далее.

Поэтому **атрибут класса** можно переопределить в наследнике: у него будет своё значение. А если записать `obj.x = ...`, значение появится в самом объекте и закроет собой всё, что лежит выше.

```python
class Tool:                      # 1
    size = 1                     # 2
class Axe(Tool):                 # 3
    size = 4                     # 4
class Knife(Tool):               # 5
    pass                         # 6
a = Axe()                        # 7
k = Knife()                      # 8
x = a.size                       # 9
y = k.size                       # 10
k.size = 2                       # 11
z = k.size                       # 12
```

| Строка | Выражение | Значение | Где нашлось |
|---|---|---|---|
| 9 | `a.size` | `4` | в классе `Axe` |
| 10 | `k.size` | `1` | в `Knife` нет, берётся из `Tool` |
| 12 | `k.size` | `2` | теперь есть в самом объекте `k` |

### Задание

Определи скорость разных юнитов и посмотри, что изменит запись в один из объектов.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_in03_lookup():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Знать порядок поиска атрибута: объект, класс, родитель.
- Понимать, что запись `obj.x = ...` создаёт атрибут в объекте и не трогает класс.
