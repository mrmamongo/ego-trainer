# Задача IN13: Способы оплаты

## Условие

### Как это работает

Наследнику не обязательно что-то переопределять. Класс, который ничего не меняет в алгоритме, остаётся пустым (`pass`) и получает всё от родителя. А метод родителя, который зовёт другой метод через `self`, сам подхватит версию наследника.

```python
class Ticket:
    label = "билет"

    def extra(self, price):
        return 0

    def total(self, price):
        return price + self.extra(price)     # extra выберется по классу объекта


class Vip(Ticket):
    label = "VIP"

    def extra(self, price):
        return 50


class Plain(Ticket):
    pass
```

| Объект | `total(100)` | `label` |
|---|---|---|
| `Plain()` | `100` | `"билет"` |
| `Vip()` | `150` | `"VIP"` |

`label` — атрибут класса. Он лежит в классе, и наследник может задать своё значение.

### Задание

Напиши классы способов оплаты:

- `Payment` — атрибут класса `name = "платёж"`; метод `fee(amount)` возвращает комиссию `0`; метод `total(amount)` возвращает `amount` плюс `self.fee(amount)`;
- `Card(Payment)` — `name = "карта"`, комиссия `amount * 2 // 100`;
- `Cash(Payment)` — `name = "наличные"`, больше ничего (комиссия нулевая от родителя);
- `Crypto(Payment)` — `name = "крипта"`, комиссия `1 + amount // 100`.

Метод `total` пиши **только в `Payment`**.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточках «Как читать сценарий» и «Рамка для нескольких классов».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только классы; рамку внизу файла не трогай.
- У `Card` и `Crypto` нужен только `fee`, у `Cash` метода нет вовсе.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Card"]` | `"ok"` |
| `["fee", 500]` | `10` |
| `["total", 500]` | `510` |
| `["get", "name"]` | `"карта"` |
| `["new", "Cash"]` | `"ok"` |
| `["total", 500]` | `500` |

## Учебные цели

- Использовать атрибут класса, который наследник переопределяет.
- Опираться на общий метод родителя, который зовёт `self.fee(...)`.
