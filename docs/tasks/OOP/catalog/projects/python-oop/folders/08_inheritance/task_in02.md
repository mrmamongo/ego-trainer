# Задача IN02: Вызов родителя через super

## Условие

### Как это работает

Если наследнику нужны **свои** поля, он пишет свой `__init__`, а внутри просит родителя сделать его часть работы: `super().__init__(...)`. Без этого поля родителя не появятся. Так же можно **расширить** метод: вызвать `super().метод()` и добавить своё. Если `super()` не звать, метод родителя будет полностью заменён.

```python
class Item:                                      # 1
    def __init__(self, name):                    # 2
        self.name = name                         # 3
    def title(self):                             # 4
        return self.name                         # 5
class Sword(Item):                               # 6
    def __init__(self, name, power):             # 7
        super().__init__(name)                   # 8
        self.power = power                       # 9
    def title(self):                             # 10
        return super().title() + " +" + str(self.power)   # 11
s = Sword("меч", 3)                              # 12
a = s.title()                                    # 13
```

| Шаг | Что происходит |
|---|---|
| строка 12 | `Sword.__init__` зовёт `Item.__init__`: появляется `s.name`; потом появляется `s.power` |
| строка 13 | `Sword.title` зовёт `Item.title`, получает `"меч"` и добавляет `" +3"`: `a` равно `"меч +3"` |

### Задание

У мага есть мана, у лучника только свой способ описывать себя. Найди значения.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_in02_super():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понять, что делает `super().__init__(...)` и почему без него поля родителя не появятся.
- Отличать расширение метода (`super().метод() + ...`) от полной замены.
