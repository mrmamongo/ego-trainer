# Переопределение и порядок поиска

Если наследник пишет метод с тем же именем, что у родителя, он **переопределяет** его: для объектов наследника срабатывает новая версия. Родитель при этом не меняется.

Чтобы понять, какая версия сработает, запомни порядок поиска для `obj.имя`:

1. в самом объекте (то, что записали через `self.имя = ...`);
2. в классе объекта;
3. в родителе, затем в родителе родителя и так до конца.

Python останавливается на первой находке.

```python
class Tool:
    size = 1                      # атрибут класса

    def title(self):
        return "инструмент"


class Axe(Tool):
    size = 4                      # переопределили атрибут

    def title(self):
        return "топор"


class Knife(Tool):
    pass


a = Axe()
k = Knife()
k.size = 2                        # запись в объект
```

| Выражение | Значение | Где нашлось |
|---|---|---|
| `a.size` | `4` | в классе `Axe` |
| `Knife().size` | `1` | в `Knife` нет, берётся из `Tool` |
| `k.size` | `2` | в самом объекте `k` |
| `Tool.size` | `1` | запись в `k` родителя не меняет |
| `a.title()` | `"топор"` | метод `Axe` закрыл метод `Tool` |
| `k.title()` | `"инструмент"` | в `Knife` метода нет |

Опечатка в имени переопределяемого метода не вызывает ошибку: Python решит, что это новый метод, а вызов пойдёт к родителю.

## Частые ошибки

Опечатка в имени:

```python
class Hammer(Tool):
    def titel(self):              # неверно: это не переопределение
        return "молоток"
```

```python
class Hammer(Tool):
    def title(self):              # верно: имя совпадает
        return "молоток"
```

## Проверь себя

```python
class A:
    kind = "a"

class B(A):
    pass

class C(B):
    kind = "c"

x = B().kind
y = C().kind
z = A().kind
```

Чему равны `x`, `y`, `z`?

<details><summary>Ответ</summary>

`x` равно `"a"` (в `B` нет, берётся из `A`), `y` равно `"c"`, `z` равно `"a"`.

</details>
