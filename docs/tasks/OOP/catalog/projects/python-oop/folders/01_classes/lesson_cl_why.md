# От словаря к классу

В папке про словари ты хранил игрока записью и писал функции над ней:

```python
hero = {"name": "Аня", "hp": 30}

def hit(player, damage):
    player["hp"] = player["hp"] - damage
```

Это работает, но данные (`hero`) и действия (`hit`) живут порознь. Функция верит, что ей передадут словарь именно с такими ключами. Опечатка `player["hb"]` найдётся только при запуске.

**Класс** связывает их: он описывает, какие данные есть у игрока и что с ним можно делать. Каждый конкретный игрок — **объект** этого класса.

```python
class Player:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def hit(self, damage):
        self.hp = self.hp - damage

hero = Player("Аня", 30)
hero.hit(10)
```

| Словарь | Класс |
|---|---|
| `{"name": "Аня", "hp": 30}` | `Player("Аня", 30)` |
| `hero["hp"]` | `hero.hp` |
| `hero["hp"] = 20` | `hero.hp = 20` |
| `hit(hero, 10)` | `hero.hit(10)` |

## Когда хватит словаря

Не всё нужно превращать в класс. Словаря достаточно, если:

- это просто запись для передачи данных, и действий над ней почти нет;
- ключи заранее неизвестны (счётчик слов, индекс по id);
- запись живёт коротко: разобрали файл, превратили в ответ.

Класс нужен, когда у данных есть **правила и действия**: баланс нельзя уводить в минус, квест нельзя завершить дважды, здоровье не бывает ниже нуля. Правило записывают один раз в методе, и им пользуется весь код.

## Частые ошибки

Заводить класс там, где хватило бы обычной функции:

```python
class Adder:                       # неверно: хранить нечего, класс лишний
    def add(self, a, b):
        return a + b
```

```python
def add(a, b):                     # верно: данных нет, нужна только функция
    return a + b
```

## Проверь себя

1. Что в записи `hero.hp = 20` соответствует `hero["hp"] = 20` для словаря?
2. В какой задаче лучше словарь, а в какой класс: «посчитать слова в тексте» или «банковский счёт с правилом: баланс не уходит в минус»?

<details><summary>Ответ</summary>

1. Это то же самое: поле записи меняется. Разница в синтаксисе: точка вместо квадратных скобок и ключа-строки.
2. Слова считать удобнее словарём `{слово: сколько}`: ключи заранее неизвестны, правил нет. Счёт лучше классом: баланс и правило «не в минус» живут вместе в методе `withdraw`.

</details>
