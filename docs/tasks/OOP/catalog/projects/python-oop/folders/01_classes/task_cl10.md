# Задача CL10: Метод вызывает метод

## Условие

### Как это работает

Один метод может вызвать другой метод **того же объекта**. Для этого перед именем пишут `self.`: `self.is_alive()`. Этот вызов работает точно так же, как `p.is_alive()` снаружи, ведь `self` — это и есть тот самый объект.

```python
class Lamp:                                   # 1
    def __init__(self, power):                # 2
        self.power = power                    # 3
    def is_on(self):                          # 4
        return self.power > 0                 # 5
    def drain(self, k):                       # 6
        self.power = self.power - k           # 7
        return self.is_on()                   # 8
lamp = Lamp(3)                                # 9
x = lamp.drain(2)                             # 10
y = lamp.drain(2)                             # 11
```

| После строки | lamp.power | Что вернулось |
|---|---|---|
| 9 | `3` | |
| 10 | `1` | `x` равно `True`: `drain` вызвал `self.is_on()`, и `1 > 0` |
| 11 | `-1` | `y` равно `False` |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Следи за двумя вещами: что лежит в `p.hp` и что вернул очередной метод.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cl10_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать метод, который вызывает другой метод через `self`.
- Совмещать в одном методе изменение состояния и возврат ответа.
