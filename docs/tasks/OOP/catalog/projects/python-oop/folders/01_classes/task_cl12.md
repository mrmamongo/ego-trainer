# Задача CL12: Квест нельзя выполнить дважды

## Условие

### Как это работает

Метод может защищать объект от неправильных вызовов: если действие уже невозможно, он бросает исключение, а состояние остаётся прежним. Строка `raise` обрывает метод, всё, что ниже, не выполняется.

```python
class Door:
    def __init__(self):
        self.is_open = False

    def open(self):
        if self.is_open:
            raise ValueError("уже открыта")
        self.is_open = True
```

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["open"]` | `None` |
| `["open"]` | `["error", "ValueError", "уже открыта"]` |

### Задание

В классе `Quest` метод `complete()` должен завершать квест, а при повторном вызове бросать `ValueError("квест уже выполнен")`. Одной строки не хватает. Допиши её вместо `pass`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Текст сообщения должен совпадать с условием слово в слово.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Охота"]` | `"ok"` |
| `["complete"]` | `None` |
| `["complete"]` | `["error", "ValueError", "квест уже выполнен"]` |
| `["get", "status"]` | `"done"` |

## Учебные цели

- Закрыть недопустимое повторное действие исключением из метода.
- Читать ошибку внутри списка результатов сценария.

## Проверка понимания

Какое значение будет в `status` после второго `complete()`? Что случилось бы, если бы `raise` стоял после строки `self.status = "done"`?
