# Как читать сценарий

В задачах, где ты пишешь **класс**, проверка не вызывает одну функцию с аргументами. Она проигрывает **сценарий**: список действий над объектом твоего класса. В конце файла лежит готовая рамка, которую менять нельзя, а ты пишешь только класс сверху.

Каждое действие — это список, в котором первое слово говорит, что делать:

| Действие | Что делает рамка |
|---|---|
| `["new", "Аня", 30]` | создаёт объект: `Player("Аня", 30)`, результат `"ok"` |
| `["get", "hp"]` | читает атрибут: результат — `obj.hp` |
| `["set", "hp", 5]` | записывает атрибут: `obj.hp = 5`, результат `"ok"` |
| `["heal", 10]` | любое другое слово — имя метода: `obj.heal(10)`, результат — то, что метод вернул |

Результатов столько же, сколько действий, и идут они в том же порядке. Если метод ничего не вернул, в результате стоит `None`.

## Пример

Класс:

```python
class Wallet:
    def __init__(self, money):
        self.money = money

    def spend(self, price):
        if price > self.money:
            raise ValueError("мало денег")
        self.money = self.money - price
        return self.money
```

Сценарий и результаты:

| Действие | Результат | Почему |
|---|---|---|
| `["new", 100]` | `"ok"` | объект создан |
| `["spend", 30]` | `70` | метод вернул остаток |
| `["get", "money"]` | `70` | атрибут изменился |
| `["spend", 500]` | `["error", "ValueError", "мало денег"]` | метод бросил исключение |
| `["get", "money"]` | `70` | при ошибке объект остался прежним |

## Ошибки как результат

Если действие бросает исключение, сценарий **не обрывается**. Рамка ловит ошибку и записывает результат `["error", тип, сообщение]`, а следующее действие выполняется как обычно. Поэтому:

- `raise ValueError("мало денег")` в методе даёт `["error", "ValueError", "мало денег"]`; текст сообщения должен совпасть буква в букву;
- забытый `self.` даёт `["error", "AttributeError", ...]` или `["error", "NameError", ...]`;
- если вместо многих ответов пришли ошибки, смотри на тип: чаще всего не хватает `__init__` или у него другие параметры.

Так проверка видит не только правильные ответы, но и правильный отказ.

## Что попадает в результат

Числа, строки, `True`/`False`, `None`, списки и словари попадают в результат как есть. Если метод вернул сам объект, в результате будет только имя его класса, например `"Player"`.

## Частые ошибки

Не совпал текст сообщения: `ValueError("мало")` вместо `ValueError("мало денег")` проверка считает другим ответом.

Метод считает ответ, но не записывает его в объект: `["get", ...]` потом покажет старое значение.

## Проверь себя

Класс:

```python
class Box:
    def __init__(self, size):
        self.size = size

    def grow(self, k):
        if k < 0:
            raise ValueError("нельзя")
        self.size = self.size + k
```

Сценарий: `["new", 3]`, `["grow", 2]`, `["grow", -1]`, `["get", "size"]`.

Какой список результатов получится?

<details><summary>Ответ</summary>

`["ok", None, ["error", "ValueError", "нельзя"], 5]`. Первое `grow` ничего не вернуло, второе бросило ошибку, а размер остался `5`.

</details>
