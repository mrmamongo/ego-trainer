# Задача CL01: Что лежит в объектах

## Условие

### Как это работает

Раньше игрока можно было хранить словарём: `{"name": "Аня", "hp": 30}`. **Класс** описывает такую запись один раз, а потом по нему создают сколько угодно **объектов**. У каждого объекта свои значения полей, они называются **атрибутами** и читаются через точку: `hero.hp`.

```python
class Coin:                      # 1
    def __init__(self, value):   # 2
        self.value = value       # 3
c1 = Coin(5)                     # 4
c2 = Coin(10)                    # 5
c1.value = 7                     # 6
```

| После строки | c1.value | c2.value | Что произошло |
|---|---|---|---|
| 4 | `5` | — | `Coin(5)` вызвал `__init__`, в нём `self` это новый объект: `value` записан в него |
| 5 | `5` | `10` | второй объект, свои данные |
| 6 | `7` | `10` | изменили только `c1`, у `c2` ничего не поменялось |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что лежит в каждом объекте, без компьютера. Нарисуй для каждого объекта табличку «атрибут → значение» и обновляй её по строкам.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cl01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понять, что `Player("Аня", 30)` создаёт объект и вызывает `__init__`.
- Читать и менять атрибуты через точку.
- Видеть, что у каждого объекта свои данные.

## Проверка понимания
