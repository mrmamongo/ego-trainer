# Задача CL07: Собери удар по игроку

## Условие

### Как это работает

Тело метода можно собрать из строк, как головоломку. Порядок важен: сначала меняем состояние, потом проверяем границу, в конце возвращаем результат. Отступы показывают вложенность: строка под `if` сдвинута вправо.

```python
def spend(self, price):
    self.money = self.money - price
    if self.money < 0:
        self.money = 0
    return self.money
```

Здесь `self.money = 0` стоит под `if`, а `return` стоит на уровне метода и выполняется всегда.

### Задание

В файле задачи записаны строки метода `take_damage(damage)`, но они перемешаны и без отступов. Собери из них тело метода: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Метод уменьшает `hp` на `damage`, но не ниже нуля, и возвращает новое `hp`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Остальной код класса и рамку не меняй.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["take_damage", 10]` | `20` |
| `["take_damage", 50]` | `0` |

## Учебные цели

- Собрать метод «изменить, ограничить, вернуть».
- Расставить отступы у `if` внутри метода.

## Проверка понимания

Что вернёт метод, если убрать строку с `self.hp = 0`? Что случится при `damage`, равном текущему `hp`?
