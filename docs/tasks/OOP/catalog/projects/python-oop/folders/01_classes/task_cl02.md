# Задача CL02: Метод меняет или возвращает

## Условие

### Как это работает

Метод — это функция внутри класса. Он получает объект первым параметром `self`. Методы бывают двух видов, и ты уже знаешь их по обычным функциям:

- **меняет состояние** объекта: присваивает `self.что_то = ...`, а `return` у него нет, поэтому наружу выходит `None`;
- **возвращает значение**: считает ответ через `return` и объект при этом не трогает.

```python
class Box:                                # 1
    def __init__(self):                   # 2
        self.n = 0                        # 3
    def add(self, k):                     # 4
        self.n = self.n + k               # 5
    def doubled(self):                    # 6
        return self.n * 2                 # 7
box = Box()                               # 8
box.add(3)                                # 9
x = box.doubled()                         # 10
```

| После строки | box.n | Что получилось |
|---|---|---|
| 8 | `0` | пустая коробка |
| 9 | `3` | `add` изменил состояние, вернул `None` |
| 10 | `3` | `x` равно `6`: `doubled` только посчитал и объект не изменил |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ.

**Сначала реши в голове или на бумаге, код не запускай.** После каждого вызова метода запиши, какое теперь `hp` у объекта и что вернул метод.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cl02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать метод, который меняет объект, от метода, который возвращает значение.
- Помнить, что метод без `return` возвращает `None`.
