# Задача CL20: Броня игрока

## Условие

### Как это работает

Сейчас класс умеет принимать урон и не опускает `hp` ниже нуля:

```python
class Player:                                         # 1
    def __init__(self, name, hp):                     # 2
        self.name = name                              # 3
        self.hp = hp                                  # 4
    def take_damage(self, damage):                    # 5
        self.hp = self.hp - damage                    # 6
        if self.hp < 0:                               # 7
            self.hp = 0                               # 8
        return self.hp                                # 9
```

**Где реализовано старое правило:** в строках 6–8. Урон целиком вычитается из `hp`, потом `hp` подрезается до нуля.

**Что меняется:** у игрока появляется броня. Она уменьшает каждый удар. Броню принимает `__init__` третьим параметром со значением по умолчанию `0`, чтобы старые вызовы `Player("Аня", 30)` продолжали работать, и сохраняет в атрибуте `armor`. Реальный урон равен `damage - armor`, но не меньше нуля.

**Что нельзя трогать:** подрезку `hp` до нуля и то, что `take_damage` возвращает новое `hp`.

### Задание

Раньше игрок получал урон целиком. Теперь у него есть броня `armor`, и каждый удар ослабляется на её величину. Измени готовый класс.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Не переписывай класс с нуля: добавь параметр `armor=0` и поправь расчёт урона.
- Без брони (`armor` равна `0`) всё работает как раньше.
- Рамку внизу файла не трогай.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30, 4]` | `"ok"` |
| `["take_damage", 10]` | `24` |
| `["take_damage", 3]` | `24` |
| `["get", "armor"]` | `4` |

## Учебные цели

- Добавить в класс новый атрибут и параметр по умолчанию, не ломая старые вызовы.
- Поменять расчёт внутри метода, сохранив прежние границы.

## Проверка понимания

Что вернёт `take_damage(2)` при `armor`, равной `5`? Что будет, если создать `Player("Аня", 30)` без брони?
