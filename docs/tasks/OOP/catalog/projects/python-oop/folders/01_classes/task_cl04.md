# Задача CL04: Допиши лечение

## Условие

### Как это работает

Чтобы метод **изменил** объект, он присваивает атрибут: `self.n = ...`. Новое значение обычно считают из старого, поэтому справа тоже стоит `self.n`:

```python
class Counter:
    def __init__(self):
        self.n = 0

    def add(self, k):
        self.n = self.n + k      # прочитали старое n, прибавили k, записали обратно
```

| Действие | Результат | Что в объекте |
|---|---|---|
| `["new"]` | `"ok"` | `n = 0` |
| `["add", 5]` | `None` | `n = 5` |
| `["add", 2]` | `None` | `n = 7` |
| `["get", "n"]` | `7` | |

`None` в результате значит: метод ничего не вернул, он только изменил объект.

### Задание

В классе `Player` метод `heal(amount)` должен увеличить здоровье игрока на `amount`. Одной строки не хватает. Допиши её вместо `pass`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Метод ничего не возвращает: в сценарии его результат `None`.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["heal", 10]` | `None` |
| `["get", "hp"]` | `40` |

## Учебные цели

- Менять атрибут объекта внутри метода через `self.hp = ...`.
- Видеть, что метод-«команда» возвращает `None`, а результат проверяют по состоянию.

## Проверка понимания
