# Задача CL08: Лечение не сохраняется

## Условие

### Как это работает

Выражение `self.hp + amount` только **считает** число. Объект от этого не меняется: чтобы значение осталось в нём, его нужно записать обратно в атрибут.

```python
class Coin:
    def __init__(self, value):
        self.value = value

    def grow(self, k):
        return self.value + k        # посчитали и отдали, а в объекте всё по-старому
```

| Действие | Результат | `value` после |
|---|---|---|
| `["new", 5]` | `"ok"` | `5` |
| `["grow", 3]` | `8` | всё ещё `5` |
| `["get", "value"]` | `5` | |

Это та же разница, что между `print` и `return`: метод показал ответ, но память объекта не обновил.

### Задание

Метод `heal(amount)` должен увеличить здоровье игрока на `amount` **и вернуть новое здоровье**. Сейчас он возвращает правильное число, но здоровье в объекте не меняется. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Метод должен и изменить `hp`, и вернуть новое значение.
- Рамку внизу файла не трогай.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["heal", 10]` | `40` |
| `["get", "hp"]` | `40` |

## Учебные цели

- Замечать метод, который считает, но не сохраняет результат в объект.
- Объединять «изменить состояние» и «вернуть значение» в одном методе.

## Проверка понимания

Какой результат даёт сценарий `new 30, heal 10, heal 10` в исправленной версии? А в исходной?
