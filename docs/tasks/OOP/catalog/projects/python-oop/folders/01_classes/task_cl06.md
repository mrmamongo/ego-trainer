# Задача CL06: Счётчик сообщений

## Условие

### Как это работает

Класс собирает данные и действия над ними в одном месте. Раньше счётчик сообщений был бы словарём `{"count": 0, "last_author": None}` и отдельными функциями. Теперь данные заводятся в `__init__`, а действия — методы:

```python
class Visits:
    def __init__(self):
        self.total = 0

    def visit(self):
        self.total = self.total + 1

    def is_empty(self):
        return self.total == 0
```

| Действие | Результат | `total` после |
|---|---|---|
| `["new"]` | `"ok"` | `0` |
| `["is_empty"]` | `True` | `0` |
| `["visit"]` | `None` | `1` |
| `["is_empty"]` | `False` | `1` |

### Задание

Напиши класс `MessageCounter` — счётчик сообщений чата:

- в `__init__` без параметров заведи атрибуты `count = 0` и `last_author = None`;
- `post(author)` увеличивает `count` на 1 и запоминает автора в `last_author`; ничего не возвращает;
- `is_quiet()` возвращает `True`, если сообщений ещё не было, иначе `False`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `MessageCounter`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `post` и `is_quiet`, имена атрибутов — как в условии.

## Пример

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["is_quiet"]` | `True` |
| `["post", "Аня"]` | `None` |
| `["post", "Боря"]` | `None` |
| `["get", "count"]` | `2` |
| `["get", "last_author"]` | `"Боря"` |

## Учебные цели

- Написать свой первый класс: `__init__` с атрибутами и два метода.
- Различать метод-команду (`post`) и метод-вопрос (`is_quiet`).
