# Задача CL18: Корзина покупок

## Условие

### Как это работает

Большой метод удобно собирать из маленьких: `summary` не считает всё сам, а вызывает соседние методы через `self`. Каждый метод отвечает за одно, а общий ответ складывается из них. Параметр со значением по умолчанию (`qty=1`) работает в методе так же, как в функции.

```python
class Tank:
    def __init__(self):
        self.parts = []

    def fill(self, name, litres=1):
        self.parts.append([name, litres])

    def volume(self):
        v = 0
        for name, litres in self.parts:
            v = v + litres
        return v

    def label(self):
        return f"всего {self.volume()} л"
```

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["fill", "вода", 3]` | `None` |
| `["fill", "сок"]` | `None` (литров по умолчанию 1) |
| `["label"]` | `"всего 4 л"` |

### Задание

Напиши класс `ShoppingCart` — корзину покупок:

- `__init__()` заводит пустой список `lines`;
- `add(name, price, qty=1)` добавляет в корзину товар; если `qty` не указали, берётся `1`; ничего не возвращает;
- `count()` возвращает общее число штук;
- `total()` возвращает общую стоимость: сумму `price * qty` по всем добавленным товарам;
- `summary()` возвращает строку `"N шт. на S"`, где `N` — результат `count()`, а `S` — результат `total()`. Используй сами методы через `self`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `ShoppingCart`; рамку внизу файла не трогай.
- В `summary` вызывай `self.count()` и `self.total()`, а не считай всё заново.
- Нужны методы `__init__`, `add`, `count`, `total` и `summary`.

## Пример

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["add", "хлеб", 50, 2]` | `None` |
| `["add", "чай", 30]` | `None` |
| `["count"]` | `3` |
| `["total"]` | `130` |
| `["summary"]` | `"3 шт. на 130"` |

## Учебные цели

- Собрать класс из нескольких методов, где один вызывает другие через `self`.
- Использовать параметр по умолчанию в методе.
