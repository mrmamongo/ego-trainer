# Задача CL09: Таймер

## Условие

### Как это работает

Метод может сначала проверить состояние объекта, а потом решить, менять ли его. Условие читает `self.что_то`, как и обычное выражение:

```python
class Stock:
    def __init__(self, n):
        self.n = n

    def take_one(self):
        if self.n > 0:
            self.n = self.n - 1
```

| Действие | Результат | `n` после |
|---|---|---|
| `["new", 1]` | `"ok"` | `1` |
| `["take_one"]` | `None` | `0` |
| `["take_one"]` | `None` | `0`: условие не выполнилось, менять нечего |

### Задание

Напиши класс `Timer` — таймер обратного отсчёта:

- `__init__(seconds)` запоминает `seconds` в атрибуте `seconds_left`;
- `tick()` уменьшает `seconds_left` на 1, но не ниже нуля; ничего не возвращает;
- `is_over()` возвращает `True`, если `seconds_left` равно нулю, иначе `False`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Timer`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `tick` и `is_over`.

## Пример

| Действие | Результат |
|---|---|
| `["new", 2]` | `"ok"` |
| `["tick"]` | `None` |
| `["is_over"]` | `False` |
| `["tick"]` | `None` |
| `["is_over"]` | `True` |

## Учебные цели

- Написать класс, где метод меняет состояние только при условии.
- Обработать границу: время не уходит ниже нуля.

## Проверка понимания

Чему равен `seconds_left` после `new 0` и трёх вызовов `tick`? Зачем нужна проверка в `tick`?
