# Класс, `__init__` и `self`

Класс — это чертёж. По нему создают объекты, вызывая имя класса как функцию:

```python
class Player:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

hero = Player("Аня", 30)
boss = Player("Орк", 80)
```

Что здесь происходит:

- `Player("Аня", 30)` создаёт **новый пустой объект** и сразу вызывает для него `__init__`;
- первый параметр `self` — это и есть этот новый объект. Его не передают руками, Python подставляет его сам;
- строка `self.name = name` записывает значение в **атрибут** объекта. Слева атрибут, справа обычная переменная (параметр);
- у каждого объекта свои атрибуты.

## Таблица состояния объекта

Проще всего понять код, если вести табличку: что лежит в каждом объекте после каждой строки.

```python
hero = Player("Аня", 30)      # 1
boss = Player("Орк", 80)      # 2
hero.hp = 25                  # 3
x = hero.hp + boss.hp         # 4
```

| После строки | hero | boss | Другое |
|---|---|---|---|
| 1 | `name="Аня", hp=30` | — | |
| 2 | `name="Аня", hp=30` | `name="Орк", hp=80` | |
| 3 | `name="Аня", hp=25` | не менялся | |
| 4 | не менялся | не менялся | `x` равно `105` |

Атрибут читают и меняют через точку: `hero.hp`, `hero.hp = 25`.

## Частые ошибки

Забыть `self.` в `__init__`: данные тогда исчезают вместе с методом.

```python
def __init__(self, name, hp):
    name = name          # неверно: просто локальная переменная
    hp = hp
```

```python
def __init__(self, name, hp):
    self.name = name     # верно: запомнили в объекте
    self.hp = hp
```

Забыть `self` первым параметром метода: Python сообщит, что передано лишних аргументов.

## Проверь себя

```python
class Coin:
    def __init__(self, value):
        self.value = value

a = Coin(5)
b = Coin(10)
a.value = 7
c = a.value + b.value
```

1. Чему равны `a.value`, `b.value` и `c`?
2. Что произойдёт при `Coin()` без аргумента?

<details><summary>Ответ</summary>

1. `7`, `10` и `17`. Изменили только объект `a`.
2. `TypeError`: у `__init__` обязательный параметр `value`, а его не передали.

</details>
