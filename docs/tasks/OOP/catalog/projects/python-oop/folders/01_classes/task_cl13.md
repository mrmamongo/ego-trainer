# Задача CL13: Список объектов

## Условие

### Как это работает

В список можно положить объекты. Список хранит **ярлыки** на них, а не копии: если один объект положить в список дважды, в нём окажется два ярлыка на один объект. Изменишь объект через любой ярлык — изменится везде.

```python
class Box:
    def __init__(self, n):
        self.n = n
p = Box(1)           # 1
q = Box(1)           # 2
row = [p, q, p]      # 3
row[2].n = 5         # 4
```

| После строки | `p.n` | `q.n` | `row[0].n` | Объектов `Box` |
|---|---|---|---|---|
| 3 | `1` | `1` | `1` | 2 (в `row` три ярлыка) |
| 4 | `5` | `1` | `5` | 2: `row[2]` и `p` — один объект |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Нарисуй два объекта и стрелки из списка к ним.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cl13_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что в списке лежат ссылки на объекты, а не их копии.
- Видеть, что один объект может встречаться в списке несколько раз.
