# Задача CL16: Собери сумму корзины

## Условие

### Как это работает

Метод может пройти циклом по данным, которые лежат в самом объекте: `for x in self.items:`. Шаблон тот же, что и у обычной функции-сумматора: заводим `total = 0` до цикла, прибавляем в теле, возвращаем после цикла.

```python
class Bag:
    def __init__(self):
        self.weights = []

    def add(self, w):
        self.weights.append(w)

    def total_weight(self):
        total = 0
        for w in self.weights:
            total = total + w
        return total
```

Список `self.weights` живёт столько же, сколько объект, поэтому каждый `add` пополняет его, а `total_weight` каждый раз считает заново.

### Задание

В файле задачи записаны строки метода `total()` корзины `ShoppingCart`, но они перемешаны и без отступов. Собери из них тело метода: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Метод возвращает сумму всех цен из `self.prices`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Остальной код класса и рамку не меняй.

## Пример

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["add", 100]` | `None` |
| `["add", 50]` | `None` |
| `["total"]` | `150` |

## Учебные цели

- Собрать сумматор по данным внутри объекта.
- Расставить отступы у цикла внутри метода.
