# Задача CL14: Инвентарь игрока

## Условие

### Как это работает

Атрибут объекта может быть любым значением: числом, строкой, списком или **словарём**. Обычно такой словарь создают в `__init__`, а методы потом читают и меняют его через `self.имя`. Приёмы со словарями те же, что и раньше: `get` с запасным значением, цикл по `values()`.

```python
class Shelf:
    def __init__(self):
        self.books = {}

    def put(self, title, n):
        self.books[title] = self.books.get(title, 0) + n

    def how_many(self, title):
        return self.books.get(title, 0)
```

| Действие | Результат | `books` после |
|---|---|---|
| `["new"]` | `"ok"` | `{}` |
| `["put", "Python", 2]` | `None` | `{"Python": 2}` |
| `["put", "Python", 1]` | `None` | `{"Python": 3}` |
| `["how_many", "Go"]` | `0` | |

### Задание

Напиши класс `Inventory` — инвентарь игрока:

- в `__init__` без параметров создай атрибут `items = {}` (предмет → количество);
- `add(name, qty)` увеличивает количество предмета `name` на `qty` (если предмета не было, считай, что было `0`); ничего не возвращает;
- `count(name)` возвращает количество предмета, а если его нет — `0`;
- `total()` возвращает общее количество всех предметов (сумму по словарю).

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Inventory`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `add`, `count` и `total`; словарь хранится в атрибуте `items`.

## Пример

| Действие | Результат |
|---|---|
| `["new"]` | `"ok"` |
| `["add", "зелье", 3]` | `None` |
| `["add", "зелье", 2]` | `None` |
| `["count", "зелье"]` | `5` |
| `["count", "щит"]` | `0` |
| `["total"]` | `5` |

## Учебные цели

- Держать словарь внутри объекта и менять его из методов.
- Применять `get` с запасным значением и цикл по `values()` внутри класса.
