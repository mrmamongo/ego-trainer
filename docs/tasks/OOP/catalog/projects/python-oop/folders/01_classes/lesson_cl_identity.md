# Два имени — один объект

С объектами работает то же правило, что со списками и словарями: **имя — это ярлык, а не сам объект.** Строка `b = a` вешает второй ярлык на тот же объект, копии не создаётся.

```python
class Player:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

a = Player("Аня", 30)        # 1
b = a                        # 2
b.hp = 10                    # 3
c = Player("Аня", 10)        # 4
```

| После строки | Объектов | a.hp | b.hp | c.hp |
|---|---|---|---|---|
| 1 | 1 | `30` | — | — |
| 2 | 1 | `30` | `30` (тот же объект) | — |
| 3 | 1 | `10` | `10` | — |
| 4 | 2 | `10` | `10` | `10` (другой объект) |

Метод тоже меняет объект «на месте»: после `a.hit(5)` изменение увидят все, у кого есть ярлык на этот объект. Функция, получив объект параметром, получает ещё один ярлык и может его изменить.

## `is` и `==`

- `a is b` — «это один и тот же объект?». После строки 2 это `True`.
- `a == b` — «они равны?». Пока класс не научили сравнивать себя особым образом, `==` для объектов отвечает **так же, как `is`**.

Поэтому `a == c` даёт `False`, хотя поля у `a` и `c` одинаковые: это два разных объекта. Сравнивать содержимое придётся самому: `a.hp == c.hp`.

## Список объектов

Список хранит ярлыки. Один объект можно положить дважды, тогда в списке два ярлыка на него:

```python
team = [a, c, a]
team[2].hp = 1
```

Здесь `a.hp` стало `1`, потому что `team[2]` и `a` — один объект. Объектов в этом коде всего два, а ячеек в списке три.

## Частые ошибки

Думать, что `b = a` делает копию, и менять `b`, «чтобы не испортить `a`»:

```python
b = a
b.hp = 0                       # неверно: сломали и a
```

```python
b = Player(a.name, a.hp)       # верно: новый объект с теми же данными
b.hp = 0
```

Сравнивать объекты через `==` и ждать совпадения по полям.

## Проверь себя

```python
x = Player("Боря", 5)
y = Player("Боря", 5)
z = x
z.hp = 9
```

1. Чему равен `x.hp`, а чему `y.hp`?
2. Что дадут `x is z`, `x is y` и `x == y`?

<details><summary>Ответ</summary>

1. `x.hp` равно `9` (через `z` изменили тот же объект), `y.hp` равно `5`.
2. `True`, `False` и `False`: `x == y` без особого сравнения работает как `is`.

</details>
