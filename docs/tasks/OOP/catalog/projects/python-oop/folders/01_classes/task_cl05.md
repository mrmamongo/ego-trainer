# Задача CL05: Два имени, один объект

## Условие

### Как это работает

Как и список, объект лежит в памяти один раз, а имя — лишь ярлык на него. Строка `b = a` не создаёт второй объект, а вешает **второй ярлык на тот же**. Изменишь через `b` — увидишь через `a`.

`a is b` спрашивает «это один и тот же объект?». Оператор `==` у обычных объектов спрашивает то же самое: пока класс не научили сравнивать себя по-другому, `==` работает как `is`. Одинаковые данные внутри ничего не решают.

```python
class Coin:
    def __init__(self, value):
        self.value = value
x = Coin(5)         # 1
y = x               # 2
z = Coin(5)         # 3
y.value = 9         # 4
```

| После строки | Сколько объектов | x.value | `x is y` | `x is z` | `x == z` |
|---|---|---|---|---|---|
| 2 | 1 | `5` | `True` | — | — |
| 3 | 2 | `5` | `True` | `False` | `False` |
| 4 | 2 | `9` | `True` | `False` | `False` |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Подсказка: нарисуй объекты кружками, а имена — стрелками к ним.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cl05_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понять, что `b = a` для объектов даёт второе имя, а не копию.
- Отличать `is` (тот же объект) от `==` (без `__eq__` это то же самое).
