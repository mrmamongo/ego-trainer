# Задача CL19: Урон по отряду

## Условие

### Как это работает

Объекты можно складывать в список и работать с ними циклом: `for player in squad:` даёт по очереди **ярлыки** на объекты. Вызов метода через такой ярлык меняет сам объект, а не копию, поэтому в списке потом лежат уже изменённые игроки.

```python
class Cup:
    def __init__(self, ml):
        self.ml = ml

    def drink(self, k):
        self.ml = max(0, self.ml - k)

cups = [Cup(300), Cup(50)]        # 1
for cup in cups:                  # 2
    cup.drink(100)                # 3
result = [cup.ml for cup in cups] # 4
```

| После строки | cups[0].ml | cups[1].ml | Что происходит |
|---|---|---|---|
| 1 | `300` | `50` | два объекта в списке |
| 3, проход 1 | `200` | `50` | `cup` — ярлык на `cups[0]` |
| 3, проход 2 | `200` | `0` | `cup` — ярлык на `cups[1]` |
| 4 | | | `result` равно `[200, 0]` |

### Задание

В файле уже есть готовый класс `GivenPlayer` (`name`, `hp`, метод `take_damage(damage)`, который не опускает `hp` ниже нуля). Напиши функцию `task_cl19_squad_hp(hps, damage)`: создай по одному `GivenPlayer("бот", hp)` на каждое число из `hps`, нанеси каждому `damage` урона методом `take_damage` и верни список оставшегося здоровья в том же порядке.

## Аргументы

- `hps` — список целых чисел от 0 (здоровье каждого игрока отряда; может быть пустым).
- `damage` — целое число от 0, урон каждому игроку.

## Возвращает

Список целых чисел: здоровье каждого игрока после урона, порядок как в `hps`. Для пустого `hps` — `[]`.

## Правила

- Класс `GivenPlayer` не меняй и не переписывай, пользуйся его методом.
- Список `hps` менять нельзя.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_cl19_squad_hp([30, 5, 10], 7)   # -> [23, 0, 3]
task_cl19_squad_hp([], 5)            # -> []
```

## Учебные цели

- Создавать объекты в цикле и хранить их в списке.
- Вызывать метод каждого объекта списка и читать его атрибут.

## Проверка понимания

Что вернёт функция для `([10, 10], 10)`? Что будет, если создать одного игрока и положить его в список дважды?
