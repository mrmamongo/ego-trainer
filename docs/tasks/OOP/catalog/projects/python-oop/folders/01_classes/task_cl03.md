# Задача CL03: Игрок без памяти

## Условие

### Как это работает

Внутри `__init__` обычные имена `name` и `hp` — это локальные переменные: они исчезают, когда метод заканчивается. Чтобы данные остались **в объекте**, их записывают в атрибуты через `self`:

```python
class Coin:
    def __init__(self, value):
        value = value          # просто локальная переменная, объект ничего не запомнил

c = Coin(5)
c.value                        # AttributeError: у объекта нет атрибута value
```

В сценарии такая ошибка видна как результат вида `["error", "AttributeError", "..."]`: проверка ловит ошибку и записывает её в список результатов.

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["get", "hp"]` | сейчас `["error", "AttributeError", "'Player' object has no attribute 'hp'"]`, а должно быть `30` |

### Задание

Класс `Player` должен хранить имя и здоровье игрока, а метод `describe()` возвращает строку вида `"Аня: 30"`. Сейчас данные в объекте не сохраняются. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Меняй только код класса `Player`; рамку внизу файла не трогай.
- Имя класса и параметры `__init__` оставь как есть.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["get", "hp"]` | `30` |
| `["describe"]` | `"Аня: 30"` |

## Учебные цели

- Узнавать `AttributeError` из-за забытого `self.` в `__init__`.
- Помнить: данные объекта лежат в `self.что_то`, а не в обычных переменных.

## Проверка понимания

Почему `describe()` не ломается на самой строке с `f"{self.name}"`, а ломается только при вызове? Что вернёт `["get", "name"]` в исправленном классе после `["new", "Боря", 5]`?
