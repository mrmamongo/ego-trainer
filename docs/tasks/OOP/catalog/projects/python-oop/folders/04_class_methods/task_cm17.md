# Задача CM17: Квест из строки

## Условие

### Как это работает

Сейчас в классе есть один альтернативный конструктор:

```python
class Quest:                                              # 1
    def __init__(self, title, reward):                    # 2
        self.title = title                                # 3
        self.reward = reward                              # 4
    @classmethod                                          # 5
    def from_dict(cls, data):                             # 6
        return cls(data["title"], data.get("reward", 0))  # 7
```

**Где реализовано старое правило:** в строках 5–7. Квест создаётся из словаря, награда по умолчанию `0`.

**Что меняется:** нужен второй способ создать квест, из строки. Он живёт в том же классе рядом с `from_dict`, тоже помечен `@classmethod` и тоже создаёт объект через `cls(...)`. Строку делят по двоеточию: после него идёт награда, а если двоеточия нет, награда `0`.

**Что нельзя трогать:** `__init__` и `from_dict`, они должны работать как раньше.

### Задание

Раньше квест создавался только из словаря (`from_dict`). Теперь добавь метод класса `from_string(text)`: строка `"Волки:50"` даёт квест с названием `"Волки"` и наградой `50`, строка `"Лис"` без двоеточия даёт награду `0`. Заглушка метода уже стоит в классе, замени её своим кодом.

## Аргументы

- `kind` — способ создания: `"dict"` или `"string"`.
- `value` — словарь с ключами `"title"` и, возможно, `"reward"` (для `"dict"`) либо строка вида `"название:награда"` (для `"string"`).

## Возвращает

Список из двух элементов: `title` и `reward` созданного квеста.

## Правила

- Не переписывай класс с нуля: допиши `from_string`, остальное не меняй.
- `from_string` должен быть помечен `@classmethod`.
- Награда в строке — целое число. Рамку внизу файла не трогай.

## Пример

```python
task_cm17_quest("dict", {"title": "Волки", "reward": 50})   # -> ["Волки", 50]
task_cm17_quest("string", "Волки:50")                       # -> ["Волки", 50]
task_cm17_quest("string", "Лис")                            # -> ["Лис", 0]
```

## Учебные цели

- Добавить в класс второй альтернативный конструктор рядом с существующим.
- Не сломать старый способ создания.

## Проверка понимания

Что вернёт `from_string("Драконы:0")`? Что произойдёт, если разобрать строку, но забыть `return`?
