# Задача CM16: Цена из текста

## Условие

### Как это работает

Помощник, которому не нужны ни объект, ни класс, делают статическим методом. Метод класса может вызывать его через `cls`.

```python
class Weight:
    def __init__(self, grams):
        self.grams = grams

    @staticmethod
    def parse(text):                      # "2 кг" -> 2000
        return int(text.replace(" кг", "")) * 1000

    @classmethod
    def from_text(cls, text):
        return cls(cls.parse(text))
```

| Вызов | Результат |
|---|---|
| `Weight.parse("2 кг")` | число `2000`, объекта нет |
| `Weight.from_text("3 кг")` | объект с `grams = 3000` |

`parse` разбирает текст и не знает про объекты, а `from_text` по этому числу создаёт объект.

### Задание

Напиши класс `Price` — цену в рублях:

- `__init__(rubles)` запоминает число в атрибуте `rubles`;
- статический метод `parse(text)` превращает текст вида `"1 250 руб"` в число `1250`: убирает слово `руб` и все пробелы и вызывает `int`;
- метод класса `from_text(text)` создаёт `Price` из текста, используя `parse`;
- `show()` возвращает строку вида `"1250 руб"`.

Функция-рамка `task_cm16_price` вызывает всё вместе.

## Аргументы

- `text` — строка: число (возможно, с пробелами между тысячами) и слово `руб`, например `"1 250 руб"`, `"7руб"`.

## Возвращает

Список из трёх элементов: результат `Price.parse(text)`, поле `rubles` объекта из `from_text(text)` и результат его `show()`.

## Правила

- Класс пиши выше строки «Ниже ничего не меняй». Рамку `task_cm16_price` не трогай.
- `parse` должен быть `@staticmethod` (без `self` и `cls`), `from_text` — `@classmethod`.
- Нужны методы `__init__`, `parse`, `from_text` и `show`.

## Пример

```python
task_cm16_price("120 руб")      # -> [120, 120, "120 руб"]
task_cm16_price("1 250 руб")    # -> [1250, 1250, "1250 руб"]
```

## Учебные цели

- Написать статический метод-помощник и вызвать его из метода класса.
- Отличить, когда метод нужен без `self` и без `cls`.

## Проверка понимания

Почему `parse` не получил `self`? Чем `Price.parse("5 руб")` отличается по результату от `Price.from_text("5 руб")`?
