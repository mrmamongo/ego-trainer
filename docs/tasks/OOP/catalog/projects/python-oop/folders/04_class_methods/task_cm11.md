# Задача CM11: Реестр команд чата

## Условие

### Как это работает

Словарь «имя команды → функция» называют **реестром**. Чтобы выполнить команду, функцию достают по ключу и сразу вызывают:

```python
commands = {"double": lambda n: n * 2, "neg": lambda n: -n}

def run(name, n):
    if name not in commands:
        return "нет такой команды"
    return commands[name](n)
```

| Вызов | Результат |
|---|---|
| `run("double", 4)` | `8` |
| `run("neg", 4)` | `-4` |
| `run("stop", 4)` | `"нет такой команды"` |

Строку вида `"/shout привет"` делят на имя команды и аргумент методом `partition`: `"shout привет".partition(" ")` даёт `("shout", " ", "привет")`. Если пробела нет, третья часть пустая.

### Задание

Напиши функцию `run_command(handlers, line)` для чата. `handlers` — словарь «имя команды → функция-обработчик», обработчик принимает один аргумент-строку. Строка `line` — это команда `"/имя аргумент"`. Функция:

- если `line` не начинается с `"/"`, возвращает `"это не команда"`;
- берёт имя команды (слово после `/`) и аргумент (всё после первого пробела; если пробела нет, то пустая строка);
- если имени нет в `handlers`, возвращает `"неизвестная команда: "` и имя;
- иначе вызывает обработчик с аргументом и возвращает его результат.

Три обработчика (`hello`, `shout`, `count`) уже написаны в рамке внизу файла.

## Аргументы

- `line` — строка сообщения из чата (может быть пустой).

## Возвращает

Результат обработчика (строка или число), либо строка `"это не команда"`, либо строка `"неизвестная команда: имя"`.

## Правила

- Пиши только функцию `run_command` выше строки «Ниже ничего не меняй». Рамку `task_cm11_chat` не трогай.
- Обработчик достань из словаря и вызови, не перебирая команды `if`-ами.
- Функция должна **вернуть** значение через `return`, а не печатать его.

## Пример

```python
task_cm11_chat("/hello Аня")       # -> "Привет, Аня!"
task_cm11_chat("/count а б в")     # -> 3
task_cm11_chat("/dance")           # -> "неизвестная команда: dance"
task_cm11_chat("привет")           # -> "это не команда"
```

## Учебные цели

- Хранить функции в словаре и вызывать их по имени.
- Разделить строку команды на имя и аргумент.

## Проверка понимания

Что вернёт `task_cm11_chat("/count")`? Что изменится, если добавить в реестр ещё одну команду: придётся ли править `run_command`?
