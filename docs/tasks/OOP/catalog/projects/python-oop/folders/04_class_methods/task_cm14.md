# Задача CM14: Номера заявок

## Условие

### Как это работает

Генератор номеров — типичное применение атрибута класса: счётчик общий для всех объектов, а полученный номер у каждого свой.

```python
class Badge:
    last = 0                           # общий счётчик в теле класса

    def __init__(self, owner):
        Badge.last = Badge.last + 1    # сдвигаем общий счётчик
        self.number = Badge.last       # запоминаем номер в этом объекте
        self.owner = owner
```

| Действие | Результат | `Badge.last` |
|---|---|---|
| `["new", "Аня"]` | `"ok"` | `1` |
| `["get", "number"]` | `1` | |
| `["new", "Боря"]` | `"ok"` | `2` |
| `["get", "number"]` | `2` | |

Рамка кладёт в сценарий только последний созданный объект, поэтому номер читают сразу после `new`.

### Задание

Напиши класс `Ticket` — заявку в службу поддержки:

- атрибут класса `next_id`, он начинается с `1` и хранит номер, который получит следующая заявка;
- `__init__(title)` запоминает `title`, записывает в `id` текущий `next_id` и увеличивает `next_id` на `1`;
- `describe()` возвращает строку вида `"№1: Баг"` (номер и название).

Перед каждой проверкой рамка ставит `Ticket.next_id = 1`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Ticket`; рамку внизу файла не трогай.
- Счётчик должен называться `next_id` и быть атрибутом **класса**.
- Нужны методы `__init__` и `describe`.
- Сообщения и формат `"№1: Баг"` должны совпасть буква в букву.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Баг"]` | `"ok"` |
| `["new", "Идея"]` | `"ok"` |
| `["get", "id"]` | `2` |
| `["describe"]` | `"№2: Идея"` |
| `["get", "next_id"]` | `3` |

## Учебные цели

- Завести атрибут класса и менять его из `__init__` через имя класса.
- Выдать каждому объекту собственный номер из общего счётчика.

## Проверка понимания

Какой номер получит третья заявка? Что покажет `["get", "next_id"]` после трёх `new`?
