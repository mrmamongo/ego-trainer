# Задача CM08: Допиши счётчик заказов

## Условие

### Как это работает

Общий счётчик лежит в теле класса, а увеличивают его **через имя класса**: так меняется значение, которое одно на всех.

```python
class Visit:
    count = 0
    def __init__(self, page):
        self.page = page
        Visit.count = Visit.count + 1     # прочитали общий, прибавили, записали обратно в класс
```

| Действие | `Visit.count` |
|---|---|
| `Visit("главная")` | `1` |
| `Visit("каталог")` | `2` |

Запись `self.count = self.count + 1` не подойдёт: она создаст личный `count` в одном объекте, а общий не изменит.

### Задание

В классе `Order` счётчик `created` должен показывать, сколько заказов создано. Одной строки в `__init__` не хватает. Допиши её вместо `pass`.

## Аргументы

- `products` — список названий товаров (строк), может быть пустым. Рамка создаёт по заказу на каждый товар.

## Возвращает

Список из двух элементов: значение `Order.created` и список названий из созданных заказов в том же порядке.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Счётчик увеличивай через имя класса: `Order.created`, а не `self.created`.

## Пример

```python
task_cm08_orders(["чай", "кофе"])   # -> [2, ["чай", "кофе"]]
task_cm08_orders([])                # -> [0, []]
```

## Учебные цели

- Увеличить атрибут класса из `__init__`.
- Отличить `Order.created` от `self.created`.

## Проверка понимания

Чему равно `Order.created` после трёх заказов? Что останется в `Order.created`, если написать `self.created = self.created + 1`?
