# Задача CM02: Что делает обёртка

## Условие

### Как это работает

Строка `@loud` над функцией — это то же самое, что `hello = loud(hello)` после неё. Имя `hello` после этого указывает уже не на исходную функцию, а на обёртку `wrapper`, которую вернул декоратор.

```python
def loud(func):                       # 1
    def wrapper(x):                   # 2
        return func(x).upper()        # 3
    return wrapper                    # 4
@loud                                 # 5
def hello(name):                      # 6
    return "привет, " + name          # 7
r = hello("аня")                      # 8
```

| После строки | Что получилось |
|---|---|
| 5–7 | `hello = loud(hello)`: `hello` теперь `wrapper` |
| 8 | вызван `wrapper("аня")`: он вызвал исходную функцию, получил `"привет, аня"` и поднял буквы; `r` равно `"ПРИВЕТ, АНЯ"` |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Помни, что вызов `inc(...)` запускает обёртку, а не исходную функцию, и обёртка хранит журнал.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cm02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать декоратор и понимать, что после `@имя` функция заменена обёрткой.
- Следить за состоянием, которое обёртка хранит на себе (`wrapper.log`).

## Проверка понимания

Что вернёт `inc(5)`, если в обёртке убрать `* 2`? Что лежало бы в `inc.log`, если бы строку с `append` поставили после `return`?
