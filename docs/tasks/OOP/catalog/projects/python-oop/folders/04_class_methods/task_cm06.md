# Задача CM06: Бонус к удару пропал

## Условие

### Как это работает

Обёртка заменяет исходную функцию, поэтому **её** ответ и увидит вызывающий. Всё, что обёртка посчитала, нужно вернуть через `return`. Без него она отработает и вернёт `None`, как функция без `return`.

```python
def shown(func):
    def wrapper(x):
        answer = func(x)       # посчитали
        print(answer)          # показали
        # забыли return answer
    return wrapper

f = shown(abs)
r = f(-3)                      # напечатает 3, но r равно None
```

### Задание

Декоратор `add_bonus(func)` должен добавлять `5` к результату функции: `hit(3, 2)` с исходным ответом `6` должен дать `11`. Сейчас любой вызов возвращает `None`. Найди ошибку и исправь.

## Аргументы

- `power` — сила удара, целое число от 0.
- `level` — уровень, целое число от 0. Исходная функция `given_hit` возвращает `power * level`.

## Возвращает

Целое число: `power * level + 5`.

## Правила

- Исправь только декоратор `add_bonus`; рамку внизу файла не трогай.
- Обёртка должна принимать любые аргументы (`*args`) и вернуть изменённый результат.

## Пример

```python
task_cm06_bonus(3, 2)    # -> 11
task_cm06_bonus(0, 5)    # -> 5
```

## Учебные цели

- Замечать обёртку, которая считает ответ, но не возвращает его.
- Связывать `None` в ответе с пропущенным `return`.

## Проверка понимания

Что вернёт обёртка, если оставить `result = result + 5` и убрать `result = func(*args)`? Чем эта ошибка отличается от забытого `return wrapper` в предыдущей задаче?
