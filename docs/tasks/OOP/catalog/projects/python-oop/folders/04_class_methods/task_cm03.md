# Задача CM03: Общий счётчик и личный атрибут

## Условие

### Как это работает

Атрибут, объявленный в теле класса, один на весь класс. Объекты видят его, пока не заведут себе одноимённый личный атрибут: присваивание через объект создаёт новый атрибут только в этом объекте.

```python
class Door:                                # 1
    opened = 0                             # 2
    def open(self):                        # 3
        Door.opened = Door.opened + 1      # 4
d1 = Door()                                # 5
d2 = Door()                                # 6
d1.open()                                  # 7
d2.open()                                  # 8
d2.open()                                  # 9
n = d1.opened                              # 10
```

| После строки | Что получилось |
|---|---|
| 6 | `Door.opened` равно `0` |
| 7 | `Door.opened` равно `1` |
| 9 | `Door.opened` равно `3` |
| 10 | `n` равно `3`: у `d1` своего `opened` нет, читается общий |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Следи за строкой 10 кода: после неё у объекта `a` появляется личный атрибут.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cm03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Различать атрибут класса и атрибут объекта.
- Видеть, что присваивание через объект создаёт личный атрибут и не меняет общий.
