# Задача CM12: Защита чата от спама

## Условие

### Как это работает

Счётчик вызовов декоратор хранит на самой обёртке, как `wrapper.calls`. Его проверяют перед вызовом исходной функции и могут отказаться её вызывать:

```python
def only_twice(func):
    def wrapper(*args):
        wrapper.calls = wrapper.calls + 1
        if wrapper.calls > 2:
            return "хватит"
        return func(*args)
    wrapper.calls = 0
    return wrapper
```

| Вызов | `wrapper.calls` | Что вернулось |
|---|---|---|
| первый | `1` | результат `func` |
| второй | `2` | результат `func` |
| третий | `3` | `"хватит"`, `func` не вызвана |

Каждый вызов `only_twice(...)` создаёт **новую** обёртку со своим счётчиком, поэтому две обёртки не мешают друг другу.

### Задание

Напиши декоратор `limit_three(func)`: он возвращает обёртку, которая пропускает первые три вызова (вызывает `func` и возвращает её результат), а начиная с четвёртого возвращает `None` и `func` не вызывает. Рамка применяет его к функции отправки сообщения два раза и проверяет, что счётчики независимы.

## Аргументы

- `first` — список текстов для первой обёрнутой функции (может быть пустым).
- `second` — список текстов для второй обёрнутой функции (может быть пустым).

## Возвращает

Список из двух списков: ответы первой и второй обёрнутой функции по порядку вызовов. Исходная функция возвращает `"отправлено: "` и текст.

## Правила

- Пиши только декоратор `limit_three` выше строки «Ниже ничего не меняй». Рамку не трогай.
- Обёртка принимает любые аргументы (`*args`) и возвращает результат исходной функции.
- Счётчик у каждой обёртки свой.

## Пример

```python
task_cm12_limit(["а", "б"], ["в"])
# -> [["отправлено: а", "отправлено: б"], ["отправлено: в"]]
task_cm12_limit(["а", "б", "в", "г"], [])
# -> [["отправлено: а", "отправлено: б", "отправлено: в", None], []]
```

## Учебные цели

- Написать декоратор с состоянием на обёртке.
- Отказывать в вызове исходной функции по условию.

## Проверка понимания

Что вернёт пятый вызов? Что пошло бы не так, если бы счётчик был общей переменной модуля?
