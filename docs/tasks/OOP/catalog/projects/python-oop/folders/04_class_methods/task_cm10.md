# Задача CM10: Собери игрока из строки

## Условие

### Как это работает

Альтернативный конструктор `from_string` разбирает строку и создаёт объект. Сначала разбирают текст на части, потом создают объект из частей. Необязательную часть берут по условию: если она есть, читают её, иначе остаётся значение по умолчанию.

```python
parts = text.split(":")
size = 1
if len(parts) > 1:
    size = int(parts[1])
box = Box(parts[0], size)
```

Отступы показывают вложенность: присваивание `size = int(parts[1])` стоит под `if`, остальные строки на общем уровне. В классе то же самое станет телом `Player.from_string`; здесь мы собираем его как обычную функцию.

### Задание

В файле задачи в комментарии записаны строки функции `task_cm10_player_from_text(text)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция разбирает строку вида `"Аня:30"` (имя и здоровье) или `"Аня"` (здоровье тогда `100`), создаёт `Player` и возвращает его имя и здоровье.

## Аргументы

- `text` — непустая строка: имя, а после двоеточия, возможно, целое здоровье.

## Возвращает

Список из двух элементов: имя игрока и его здоровье (целое число).

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Класс `Player` не меняй.

## Пример

```python
task_cm10_player_from_text("Аня:30")    # -> ["Аня", 30]
task_cm10_player_from_text("Боря")      # -> ["Боря", 100]
```

## Учебные цели

- Собрать разбор строки и создание объекта в правильном порядке.
- Поставить отступ у присваивания под `if`.

## Проверка понимания

Что вернёт функция для `"Вика:0"`? Что случится, если строку `hp = 100` поставить после `if`?
