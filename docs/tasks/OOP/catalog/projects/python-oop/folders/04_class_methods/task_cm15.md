# Задача CM15: Игрок из сохранения

## Условие

### Как это работает

Альтернативный конструктор достаёт поля из словаря и передаёт их в `cls(...)`. Необязательный ключ берут через `data.get("ключ", запасное)`, обязательный через `data["ключ"]`.

```python
class Box:
    def __init__(self, size, color="серый"):
        self.size = size
        self.color = color

    @classmethod
    def from_dict(cls, data):
        return cls(data["size"], data.get("color", "серый"))
```

| Вызов | Результат |
|---|---|
| `Box.from_dict({"size": 2})` | `size = 2`, `color = "серый"` |
| `Box.from_dict({"size": 5, "color": "красный", "id": 9})` | лишний ключ `id` не мешает |

### Задание

Напиши класс `Player` — игрока из сохранения:

- `__init__(name, hp, level=1)` запоминает три значения в атрибутах с теми же именами;
- метод класса `from_dict(data)` создаёт игрока из словаря сохранения: ключ `"name"` обязателен, `"hp"` по умолчанию `100`, `"level"` по умолчанию `1`, лишние ключи игнорируются.

Функция-рамка `task_cm15_load` создаёт игрока из словаря и возвращает его поля.

## Аргументы

- `save` — словарь с обязательным ключом `"name"` (строка), необязательными `"hp"` и `"level"` (целые) и, возможно, лишними ключами.

## Возвращает

Список из трёх элементов: `name`, `hp`, `level` созданного игрока.

## Правила

- Класс пиши выше строки «Ниже ничего не меняй». Рамку `task_cm15_load` не трогай.
- `from_dict` должен быть помечен `@classmethod`.
- Внутри класса создавай объект через `cls(...)`, не по имени `Player`.
- Словарь `save` менять нельзя.

## Пример

```python
task_cm15_load({"name": "Аня", "hp": 30, "level": 3})   # -> ["Аня", 30, 3]
task_cm15_load({"name": "Боря"})                        # -> ["Боря", 100, 1]
task_cm15_load({"name": "Вика", "hp": 0})               # -> ["Вика", 0, 1]
```

## Учебные цели

- Написать метод класса, который создаёт объект из словаря.
- Подставить значения по умолчанию для отсутствующих ключей и не затереть нули.

## Проверка понимания

Что вернёт `from_dict`, если в сохранении `hp` равно `0`? Почему для `"hp"` подходит `data.get`, а для `"name"` лучше `data["name"]`?
