# Задача CM01: Список обработчиков

## Условие

### Как это работает

Функцию можно положить в список и вызвать потом: `ops[0](5)` — это «достань первую функцию из списка и вызови её с пятёркой». Без скобок получается сама функция, со скобками — её результат.

```python
def double(x):                    # 1
    return x * 2
def neg(x):                       # 2
    return -x
ops = [double, neg]               # 3
a = ops[0](5)                     # 4
b = ops[1](5)                     # 5
f = ops[0]                        # 6
c = f(f(1))                       # 7
```

| После строки | Что получилось |
|---|---|
| 3 | `ops` — список из двух функций, ничего ещё не вызвано |
| 4 | `a` равно `10` |
| 5 | `b` равно `-5` |
| 6 | `f` — второе имя функции `double`, вызова не было |
| 7 | `c` равно `4`: `double(double(1))` |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Следи, где стоят скобки: со скобками функция вызывается, без них она просто лежит в переменной.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cm01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать функцию в списке от результата её вызова.
- Понимать, что присваивание `g = bye` даёт второе имя той же функции.
- Читать функцию, которая создаёт и возвращает другую функцию.
