# Функция — это значение

До сих пор ты **вызывал** функции: `len(text)`, `greet("Аня")`. Но имя функции устроено так же, как имя переменной: за ним лежит значение, и это значение — сама функция. Скобки с аргументами её **запускают**, а без скобок получается просто ссылка на неё.

```python
def shout(text):
    return text.upper() + "!"

f = shout            # без скобок: f теперь указывает на ту же функцию
print(f("да"))       # ДА!
```

Раз функция — значение, с ней можно делать то же, что с числом или строкой: класть в список и словарь, передавать в другую функцию, возвращать из функции.

```python
def shout(text):                               # 1
    return text.upper() + "!"
def whisper(text):                             # 2
    return text.lower() + "..."

handlers = [shout, whisper]                    # 3
a = handlers[0]("Привет")                      # 4
commands = {"loud": shout, "soft": whisper}    # 5
b = commands["soft"]("ПОКА")                   # 6

def make_adder(k):                             # 7
    def add(x):
        return x + k
    return add
plus3 = make_adder(3)                          # 8
c = plus3(10)                                  # 9
```

| После строки | Что получилось |
|---|---|
| 3 | `handlers` — список из двух **функций** (не результатов!) |
| 4 | `a` равно `"ПРИВЕТ!"`: взяли первую функцию из списка и вызвали |
| 6 | `b` равно `"пока..."`: функцию нашли в словаре по ключу и вызвали |
| 8 | `plus3` — функция `add`, которая помнит `k = 3` |
| 9 | `c` равно `13` |

Так устроены **реестры команд**: словарь «имя команды → функция-обработчик». Чтобы выполнить команду, достают функцию по имени и вызывают: `commands[name](argument)`.

## Функция — объект: у неё можно завести атрибут

К функции, как и к объекту класса, можно прикрепить значение через точку:

```python
def ping():
    return "pong"

ping.calls = 0                       # прикрепили число к функции
ping.calls = ping.calls + 1          # и изменили его
```

Этим пользуются декораторы (следующая карточка): они хранят счётчик вызовов прямо на функции.

## Частые ошибки

Вызвать функцию там, где нужна сама функция:

```python
handlers = [shout()]       # неверно: shout() запускается сразу и требует аргумент
```

```python
handlers = [shout]         # верно: в списке лежит сама функция
```

То же при возврате из функции: `return add()` вернёт результат вызова, а `return add` отдаст функцию.

## Проверь себя

```python
def twice(f, x):
    return f(f(x))

def inc(n):
    return n + 1

r = twice(inc, 5)
s = [inc, inc][1](0)
t = inc
```

Чему равны `r`, `s` и `t(10)`?

<details><summary>Ответ</summary>

`r` равно `7`: `inc(inc(5))`. `s` равно `1`: из списка взяли вторую функцию и вызвали с `0`. `t(10)` равно `11`: `t` — второе имя той же функции `inc`.

</details>
