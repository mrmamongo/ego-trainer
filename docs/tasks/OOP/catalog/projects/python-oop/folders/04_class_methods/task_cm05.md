# Задача CM05: Декоратор ничего не возвращает

## Условие

### Как это работает

Декоратор обязан **вернуть** новую функцию. Если в конце нет `return wrapper`, Python молча вернёт `None`, и после `greet = log_calls(greet)` в имени `greet` окажется `None`.

```python
def shout(func):
    def wrapper(text):
        return func(text).upper()
    # забыли return wrapper

hi = shout(len)       # hi теперь None
hi("мир")             # TypeError: 'NoneType' object is not callable
```

Ошибка видна не там, где она сделана: падает вызов, а виновата последняя строка декоратора.

### Задание

Декоратор `log_calls(func)` должен вернуть обёртку, которая записывает аргументы каждого вызова в список `wrapper.log` и возвращает результат исходной функции. Сейчас проверка вместо ответов показывает `["error", "TypeError", ...]`. Найди ошибку и исправь.

## Аргументы

- `names` — список имён (строк), может быть пустым. Рамка применяет `log_calls` к готовой функции `given_greet` и вызывает результат по одному разу для каждого имени.

## Возвращает

Список из двух элементов: список ответов `given_greet` и содержимое `wrapper.log` — по списку аргументов на каждый вызов, например `[["Привет, Аня!"], [["Аня"]]]`.

## Правила

- Исправь только декоратор `log_calls`; рамку внизу файла не трогай.
- Журнал `wrapper.log` и результат вызова должны остаться такими же, как задумано.

## Пример

```python
task_cm05_log(["Аня", "Боря"])   # -> [["Привет, Аня!", "Привет, Боря!"], [["Аня"], ["Боря"]]]
task_cm05_log([])                # -> [[], []]
```

## Учебные цели

- Замечать декоратор, который забыл вернуть обёртку.
- Читать `TypeError: 'NoneType' object is not callable` как «в имени лежит None».

## Проверка понимания

Почему ошибка проявилась только при вызове, а не при `log_calls(given_greet)`? Что лежало бы в `greet`, если бы декоратор вернул `wrapper()` со скобками?
