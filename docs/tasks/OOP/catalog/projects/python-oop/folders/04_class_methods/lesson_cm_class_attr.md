# Атрибут класса и атрибут объекта

Атрибуты, которые ты знаешь, живут в **объекте**: `self.name = name` даёт свой `name` каждому игроку. Но значение можно положить и в сам **класс**, прямо в его тело. Оно будет одно на всех.

```python
class Item:
    created = 0                           # атрибут класса: один на весь класс

    def __init__(self, name):
        self.name = name                  # атрибут объекта: свой у каждого
        Item.created = Item.created + 1   # счётчик общий, меняем через имя класса

a = Item("меч")          # 1
b = Item("щит")          # 2
n = Item.created         # 3
m = a.created            # 4
a.created = 10           # 5
k = Item.created         # 6
j = b.created            # 7
```

| После строки | Что получилось |
|---|---|
| 1 | `Item.created` равно `1` |
| 2 | `Item.created` равно `2` |
| 3 | `n` равно `2` |
| 4 | `m` равно `2`: у `a` своего `created` нет, Python берёт его у класса |
| 5 | у `a` появился **свой** `created = 10`, он закрыл общий |
| 6 | `k` равно `2`: класс не изменился |
| 7 | `j` равно `2`: у `b` своего нет, видно общее |

Читать атрибут класса можно и через объект, и через класс. А вот **менять общий счётчик нужно через имя класса**: `Item.created = ...`. Присваивание через объект создаёт личный атрибут и общее значение не трогает.

Так делают счётчики созданных объектов и генераторы номеров: `Ticket.next_id` хранит номер, который получит следующая заявка.

## Ловушка: изменяемое значение в классе

Список в теле класса тоже один на всех:

```python
class Quest:
    tags = []                  # неверно: один список на все квесты

    def add_tag(self, tag):
        self.tags.append(tag)  # append меняет общий список
```

Если сделать `a.add_tag("бой")`, то `b.tags` у другого квеста тоже станет `["бой"]`. Это та же ловушка, что со значением по умолчанию в функции (`fd-defaults`) и в dataclass (`dc-defaults`). Личный список создают в `__init__`:

```python
class Quest:
    def __init__(self, title):
        self.title = title
        self.tags = []         # верно: у каждого квеста свой список
```

## Частые ошибки

Увеличить счётчик через `self`:

```python
self.created = self.created + 1     # неверно: справа общий, слева создался личный
```

```python
Item.created = Item.created + 1     # верно: изменился общий счётчик
```

Забыть начальное значение счётчика в теле класса: тогда `Item.created` не существует, и первое чтение даст `AttributeError`.

## Проверь себя

```python
class Ticket:
    next_id = 1

    def __init__(self):
        self.id = Ticket.next_id
        Ticket.next_id = Ticket.next_id + 1

a = Ticket()
b = Ticket()
```

1. Чему равны `a.id`, `b.id` и `Ticket.next_id`?
2. Что изменится, если в `__init__` написать `self.next_id = self.next_id + 1` вместо второй строки?

<details><summary>Ответ</summary>

1. `1`, `2` и `3`.
2. Счётчик перестанет считать: у каждого объекта появится личный `next_id`, а `Ticket.next_id` так и останется `1`. Оба билета получат `id`, равный `1`.

</details>
