# Задача CM04: Три вида методов

## Условие

### Как это работает

Метод с `@classmethod` получает первым параметром класс (`cls`), с `@staticmethod` не получает ничего лишнего. Оба вызывают через имя класса, объект не нужен.

```python
class Box:                                  # 1
    @staticmethod                           # 2
    def twice(n):                           # 3
        return n * 2                        # 4
    @classmethod                            # 5
    def make(cls, n):                       # 6
        return cls(Box.twice(n))            # 7
    def __init__(self, size):               # 8
        self.size = size                    # 9
a = Box.twice(4)                            # 10
b = Box.make(3)                             # 11
c = b.size                                  # 12
```

| После строки | Что получилось |
|---|---|
| 10 | `a` равно `8`: просто число, объекта нет |
| 11 | `b` — новый `Box`, его `size` равен `6` |
| 12 | `c` равно `6` |

### Задание

Открой файл задачи. Впиши вместо `None` ответы. **Сначала реши в голове или на бумаге, код не запускай.** Следи за счётчиком `Score.total`: метод класса меняет общий атрибут через `cls`.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_cm04_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понимать, что метод класса получает класс и создаёт объект через `cls(...)`.
- Видеть, что статический метод не зависит ни от объекта, ни от класса.
