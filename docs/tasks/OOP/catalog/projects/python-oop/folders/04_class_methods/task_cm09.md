# Задача CM09: Допиши предмет из сохранения

## Условие

### Как это работает

Метод класса создаёт объект и возвращает его. Для этого он вызывает сам класс по имени `cls`: `cls(...)` делает то же, что вызов `Item(...)`, но не привязан к имени.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    @classmethod
    def from_pair(cls, pair):
        return cls(pair[0], pair[1])
```

| Вызов | Результат |
|---|---|
| `Point.from_pair([3, 4])` | новая точка, `x = 3`, `y = 4` |

Объекта для вызова не нужно: метод вызывают прямо у класса.

### Задание

В классе `Item` метод `from_dict(data)` должен создать предмет из словаря сохранения с ключами `"name"` и `"price"`. Одной строки не хватает. Допиши её вместо `pass`.

## Аргументы

- `data` — словарь с ключами `"name"` (строка) и `"price"` (целое), возможно, с другими лишними ключами.

## Возвращает

Список из двух элементов: `name` и `price` созданного предмета.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Объект создавай через `cls(...)`, не через `Item(...)`.
- Декоратор `@classmethod` уже стоит, не убирай его.

## Пример

```python
task_cm09_item({"name": "Меч", "price": 120})              # -> ["Меч", 120]
task_cm09_item({"name": "Лук", "price": 40, "count": 3})   # -> ["Лук", 40]
```

## Учебные цели

- Вернуть из метода класса новый объект через `cls(...)`.
- Достать поля из словаря и передать их в конструктор.

## Проверка понимания

Что вернёт `from_dict`, если забыть слово `return`? Зачем в сигнатуре метода стоит `cls`, а не `self`?
