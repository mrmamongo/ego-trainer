# `@staticmethod`: помощник без `self` и `cls`

Иногда внутри класса нужна функция, которой не нужны ни данные объекта, ни сам класс. Например, разобрать цену из текста:

```python
class Price:
    def __init__(self, rubles):
        self.rubles = rubles

    @staticmethod
    def parse(text):                       # "1 250 руб" -> 1250
        return int(text.replace("руб", "").replace(" ", ""))

    @classmethod
    def from_text(cls, text):
        return cls(cls.parse(text))
```

`parse` — **статический метод**: у него нет `self` и нет `cls`, это обычная функция, которая просто живёт в классе. Вызывают её через класс (можно и через объект, но так не пишут):

```python
a = Price.parse("1 250 руб")           # 1
p = Price.from_text("90 руб")          # 2
```

| После строки | Что получилось |
|---|---|
| 1 | `a` равно `1250`: объекта нет, получилось просто число |
| 2 | `p.rubles` равно `90`: `from_text` вызвал `cls.parse` и по числу создал объект |

Внутри других методов статический помощник вызывают через `cls.parse(...)`, `self.parse(...)` или `Price.parse(...)`. Голое `parse(...)` Python не найдёт.

## Какой метод выбрать

| Что нужно методу | Какой он |
|---|---|
| данные конкретного объекта (`self.hp`) | обычный метод |
| сам класс: создать объект, общий счётчик (`cls(...)`) | `@classmethod` |
| ничего из этого | `@staticmethod` или обычная функция |

## Когда лучше обычная функция

Статический метод отличается от функции только местом, где он лежит. Если помощник относится именно к этому классу и его удобно вызывать как `Price.parse`, оставь его в классе. Если он общий, нужен в разных местах или с классом никак не связан, напиши обычную функцию на уровне модуля: `def parse_price(text)`. Не превращай всё подряд в `@staticmethod`.

## Частые ошибки

Написать `self` в статическом методе: `def parse(self, text)`. Вызов `Price.parse("90 руб")` тогда отдаст строку в `self`, а `text` останется пустым: `TypeError`.

```python
@staticmethod
def parse(text):          # верно: ни self, ни cls
    ...
```

Забыть `@staticmethod`, оставив `def parse(text)` без `self`. Через класс вызов сработает, а через объект (`p.parse("5 руб")`) Python подставит объект первым аргументом и сломает вызов.

## Проверь себя

```python
class Score:
    @staticmethod
    def bonus(points):
        return points * 2

a = Score.bonus(5)
b = Score().bonus(1)
```

1. Чему равны `a` и `b`?
2. Почему `bonus` не нужен ни `self`, ни `cls`?

<details><summary>Ответ</summary>

1. `10` и `2`.
2. Он считает ответ только из своего аргумента `points` и не читает ни атрибуты объекта, ни атрибуты класса.

</details>
