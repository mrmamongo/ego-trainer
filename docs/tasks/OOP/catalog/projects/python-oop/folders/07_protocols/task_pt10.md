# Задача PT10: Собери подсчёт ошибок в журнале

## Условие

### Как это работает

Файл можно обходить циклом `for` построчно, как список. В задачах мы берём `io.StringIO(текст)` — «файл в памяти»; с настоящим `open(...)` код был бы тем же.

```python
import io

file = io.StringIO("раз\nдва\n")
count = 0
for line in file:
    if line.startswith("д"):
        count += 1
# count == 1
```

**Паспорт роли «счётчик»** (имя `count`):

| Где заводим | Начальное значение | Как меняем в теле | Когда используем |
|---|---|---|---|
| до цикла | `0` | `count += 1` под `if` | после цикла, `return count` |

**Отступы** показывают вложенность: `if` стоит под `for`, а `count += 1` под `if`.

### Задание

В файле задачи в комментарии записаны строки функции `task_pt10_count(text)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция считает строки журнала, которые начинаются со слова `ERROR`.

В файле задачи строки записаны в комментарии: собери из них тело функции и удали строку `return None`.

## Аргументы

- `text` — содержимое журнала: строки, разделённые `\n` (может быть пустой строкой).

## Возвращает

Количество строк журнала, начинающихся с `ERROR` (целое число); для пустого текста `0`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Строка `import io` выше уже есть, её не трогай.

## Пример

```python
task_pt10_count('INFO a\nERROR b\nERROR c\n')   # -> 2
task_pt10_count('')   # -> 0
```

## Учебные цели

- Собрать шаблон «счётчик»: `count = 0` до цикла, проверка и `count += 1` под `if`, `return` после цикла.
- Обходить файлоподобный объект циклом `for`.

## Проверка понимания

Что вернёт функция для текста `"  ERROR a\nERROR b"` и почему? Что изменится, если поставить `return count` под `for`?
