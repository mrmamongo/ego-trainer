# Задача PT12: Журнал квестов: только невыполненные

## Условие

### Как это работает

В генераторе `__iter__` можно фильтровать: `yield` стоит под `if`, и подходящие значения отдаются по одному.

```python
class Inbox:
    def __init__(self):
        self.mails = []        # пары [тема, прочитано]

    def __iter__(self):
        for subject, read in self.mails:
            if not read:
                yield subject
```

| `mails` | `list(inbox)` |
|---|---|
| `[["a", True], ["b", False]]` | `["b"]` |
| `[]` | `[]` |

Обход можно повторять: каждый `for` запускает `__iter__` заново.

### Задание

Напиши класс `QuestLog` — журнал квестов:

- `add(title)` добавляет квест; если такое название уже есть, выбрасывает `ValueError("квест уже есть")`;
- `finish(title)` отмечает квест выполненным; если названия нет в журнале, выбрасывает `ValueError("нет такого квеста")`; повторное `finish` для выполненного квеста ошибкой не считается;
- `__iter__()` — генератор: отдаёт названия **невыполненных** квестов в порядке добавления.

Рамка выполняет действия по порядку и в конце дважды обходит журнал.

## Аргументы

- `actions` — список пар `[имя метода, название квеста]`, имя метода `"add"` или `"finish"`.

## Возвращает

Список: для каждого действия `"ok"` или текст ошибки, а в конце два списка названий невыполненных квестов (первый и второй обход).

## Правила

- Пиши только класс `QuestLog`; рамку внизу не трогай.
- Нужны методы `__init__`, `add`, `finish` и `__iter__`.
- Тексты ошибок должны совпадать с условием символ в символ.

## Пример

```python
task_pt12_quests([['add', 'a'], ['add', 'b'], ['finish', 'a']])   # -> ['ok', 'ok', 'ok', ['b'], ['b']]
task_pt12_quests([['add', 'a']])   # -> ['ok', ['a'], ['a']]
```

## Учебные цели

- Написать `__iter__`-генератор с фильтром.
- Хранить в объекте два набора: порядок названий и выполненные.

## Проверка понимания

Какие квесты отдаст обход после `add("а")`, `add("б")`, `finish("а")`, `add("в")`? Что произойдёт, если `finish` вызвать для названия, которого нет?
