# Задача PT17: Таблица лидеров: места и топ

## Условие

### Как это работает

В генераторе `__iter__` можно менять то, что отдаётся, и ограничивать сколько. Срез `[:n]` берёт первые `n` элементов, `enumerate(..., start=1)` нумерует с единицы:

```python
rows = [["Аня", 5], ["Боря", 9]]

for place, (name, score) in enumerate(rows, start=1):
    print(place, name, score)         # 1 Аня 5, потом 2 Боря 9

rows[:1]                              # [["Аня", 5]]
```

| Выражение | Результат |
|---|---|
| `rows[:1]` | `[["Аня", 5]]` |
| `rows[:10]` | оба элемента: срез не выходит за конец |
| `f"{1}. {'Аня'}: {5}"` | `"1. Аня: 5"` |

### Задание

Раньше `Leaderboard(rows)` при обходе отдавал имена всех игроков по убыванию очков. Теперь:

- каждая запись — строка `место. имя: очки`, например `1. Боря: 80`; места считаются с единицы;
- `Leaderboard(rows, top)` принимает необязательный `top`: если он задан, отдаются только первые `top` мест; без него отдаются все.

Порядок прежний: по убыванию очков, равные очки идут в том порядке, в каком были в `rows`.

## Аргументы

- `rows` — список пар `[имя, очки]`, может быть пустым.
- `top` — сколько мест показать (необязательное целое неотрицательное число).

## Возвращает

Список из двух одинаковых списков строк `место. имя: очки` (первый и второй обход таблицы).

## Правила

- Меняй только класс `Leaderboard`; рамку внизу не трогай.
- `__iter__` остаётся генератором.
- Список `rows` менять нельзя.

## Пример

```python
task_pt17_board([['Аня', 50], ['Боря', 80], ['Вика', 65]])   # -> [['1. Боря: 80', '2. Вика: 65', '3. Аня: 50'], ['1. Боря: 80', '2. Вика: 65', '3. Аня: 50']]
task_pt17_board([['Аня', 50], ['Боря', 80], ['Вика', 65]], 2)   # -> [['1. Боря: 80', '2. Вика: 65'], ['1. Боря: 80', '2. Вика: 65']]
```

## Учебные цели

- Изменить значение, которое отдаёт `yield`.
- Добавить необязательный параметр и ограничить обход срезом.

## Проверка понимания

Что вернёт обход для `top=0`? Для `top`, большего длины `rows`? Почему равные очки не меняются местами?
