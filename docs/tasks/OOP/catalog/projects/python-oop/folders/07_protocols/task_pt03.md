# Задача PT03: Когда генератор выполняется

## Условие

### Как это работает

Вызов функции-генератора ничего не выполняет: он только создаёт генератор. Тело работает кусками, каждый `next` доходит до очередного `yield`.

```python
log = []                          # 1
def gen():                        # 2
    log.append("a")               # 3
    yield 1                       # 4
    log.append("b")               # 5
g = gen()                         # 6
n0 = len(log)                     # 7
v = next(g)                       # 8
n1 = len(log)                     # 9
rest = list(g)                    # 10
n2 = len(log)                     # 11
```

| После строки | Значение |
|---|---|
| 7 | `n0` равно `0`: тело не запускалось |
| 8 | `v` равно `1`, в `log` один элемент |
| 9 | `n1` равно `1` |
| 11 | `rest` равно `[]`, `n2` равно `2`: `list` дошёл до конца функции |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит в каждой строке, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pt03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Понять, что тело генератора не запускается при вызове, а идёт кусками между `yield`.
- Видеть, что `list(g)` доводит генератор до конца и выполняет код после последнего `yield`.
- Помнить, что исчерпанный генератор пуст.

## Проверка понимания

Сколько записей будет в `log`, если после `g = gen()` ни разу не вызвать `next`? Что изменится, если вместо `yield 1` написать `return 1`?
