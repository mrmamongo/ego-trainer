# Задача PT16: Сохранить профиль игрока в JSON

## Условие

### Как это работает

Чтобы сохранить объект, его превращают в словарь (`to_dict`), словарь в текст JSON (`json.dumps`) и пишут текст в файл. Загрузка идёт в обратную сторону: прочитать текст, `json.loads`, собрать объект из словаря.

```python
import io
import json

file = io.StringIO()
file.write(json.dumps({"hp": 5}))       # 1
file.seek(0)                            # 2
data = json.loads(file.read())          # 3
```

| После строки | Что получилось |
|---|---|
| 1 | в файле текст `{"hp": 5}` |
| 2 | указатель вернулся в начало |
| 3 | `data` равно `{"hp": 5}` |

`io.StringIO` ведёт себя как файл из `open(...)`: те же `write`, `read`, `seek`. Поэтому функции, которые получают файл параметром, годятся и для памяти, и для диска. Русские буквы оставляй читаемыми: `json.dumps(данные, ensure_ascii=False)`.

### Задание

Класс `Profile` (игрок: имя, уровень, предметы), его метод `to_dict` и функция `profile_from_dict` уже готовы. Напиши две функции:

- `save_profile(profile, file)` записывает в файл `file` текст JSON из `profile.to_dict()` (`ensure_ascii=False`); ничего не возвращает;
- `load_profile(file)` читает из файла весь текст и возвращает `Profile`, собранный через `profile_from_dict`.

Рамка записывает профиль в `io.StringIO`, возвращается в начало, загружает его обратно и сообщает, что получилось.

## Аргументы

- `name` — имя игрока (строка).
- `level` — уровень (целое число).
- `items` — список названий предметов (строки), может быть пустым.

## Возвращает

Список из четырёх значений: записанный в файл текст JSON, а также имя, уровень и список предметов загруженного профиля.

## Правила

- Пиши только функции `save_profile` и `load_profile`; остальное выше и рамку внизу не трогай.
- Файл приходит параметром: не вызывай `open` и не создавай `StringIO` сам.
- Текст JSON получай через `json.dumps` с `ensure_ascii=False`.

## Пример

```python
task_pt16_roundtrip('Аня', 3, ['меч', 'щит'])   # -> ['{"name": "Аня", "level": 3, "items": ["меч", "щит"]}', 'Аня', 3, ['меч', 'щит']]
task_pt16_roundtrip('Боря', 1, [])   # -> ['{"name": "Боря", "level": 1, "items": []}', 'Боря', 1, []]
```

## Учебные цели

- Сохранять объект в файл через `to_dict` и `json.dumps`.
- Загружать объект через `json.loads` и `profile_from_dict`.
