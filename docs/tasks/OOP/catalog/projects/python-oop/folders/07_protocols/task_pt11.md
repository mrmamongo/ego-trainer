# Задача PT11: Постраничная история чата

## Условие

### Как это работает

`__iter__`, написанный как генератор, удобен для пагинации: он отдаёт историю порциями (страницами), а каждый обход начинается заново.

```python
class Shelf:
    def __init__(self, items, size):
        self.items = items
        self.size = size

    def __iter__(self):
        start = 0
        while start < len(self.items):
            yield self.items[start:start + self.size]
            start += self.size

list(Shelf(["a", "b", "c"], 2))      # [["a", "b"], ["c"]]
```

| Вызов | Результат |
|---|---|
| `list(Shelf(["a", "b", "c"], 2))` | `[["a", "b"], ["c"]]` |
| `list(Shelf([], 2))` | `[]` |

Срез `items[start:start + size]` берёт не больше `size` элементов, даже если список закончился раньше.

### Задание

Напиши класс `ChatHistory` — история сообщений чата, которую можно листать по страницам:

- `__init__(messages, size)` запоминает список сообщений и размер страницы; если `size` меньше 1, выбрасывает `ValueError("размер страницы должен быть больше нуля")`;
- `__iter__()` — генератор: отдаёт страницы-списки по `size` сообщений, последняя может быть короче.

Рамка внизу файла дважды обходит историю и собирает страницы в списки.

## Аргументы

- `messages` — список сообщений (строки), может быть пустым.
- `size` — размер страницы, целое число.

## Возвращает

Список из двух списков страниц (первый и второй обход, они одинаковые). Если `size` меньше 1: `["error", "размер страницы должен быть больше нуля"]`.

## Правила

- Пиши только класс `ChatHistory`; рамку внизу не трогай.
- Нужны методы `__init__` и `__iter__`.
- Список `messages` менять нельзя.

## Пример

```python
task_pt11_pages(['a', 'b', 'c'], 2)   # -> [[['a', 'b'], ['c']], [['a', 'b'], ['c']]]
task_pt11_pages(['a', 'b'], 2)   # -> [[['a', 'b']], [['a', 'b']]]
```

## Учебные цели

- Написать `__iter__` как генератор страниц.
- Проверять параметр в `__init__` и поднимать `ValueError` своим текстом.
