# Задача PT14: Читатель журнала: цепочка генераторов

## Условие

### Как это работает

Генераторы можно вкладывать друг в друга: внешний берёт значения у внутреннего по одному. Пока никто не попросил результат, ничего не читается.

```python
def numbers(items):
    for item in items:
        yield int(item)

def only_big(values):
    for value in values:
        if value > 10:
            yield value

gen = only_big(numbers(["3", "20", "7", "40"]))
first = next(gen, 0)         # 20: прочитаны только "3" и "20"
```

| Шаг | Что прочитано из исходного списка |
|---|---|
| собрали `gen` | ничего |
| `next(gen, 0)` | `"3"`, затем `"20"`: нашлось первое подходящее, остальное не тронуто |

Если в `numbers` собрать список целиком (`return [int(i) for i in items]`), цепочка прочитает всё сразу и перестанет быть ленивой.

### Задание

Напиши две функции-генератора для чтения журнала:

- `non_empty(lines)` отдаёт строки без пробелов и переводов строки по краям (`strip()`), пропуская пустые;
- `only_errors(lines)` отдаёт только те строки, которые начинаются с `ERROR`.

Рамка собирает цепочку `only_errors(non_empty(...))` над «файлом» из текста, берёт первую ошибку через `next(..., "нет ошибок")` и считает, сколько строк исходного файла при этом прочитано.

## Аргументы

- `text` — содержимое журнала: строки, разделённые `\n` (может быть пустой строкой).

## Возвращает

Список из двух значений: первая найденная ошибка (строка без пробелов по краям) или `"нет ошибок"`, и число прочитанных из файла строк.

## Правила

- Пиши только функции `non_empty` и `only_errors`; рамку внизу не трогай.
- Обе функции должны быть генераторами (`yield`), без `list` и без сбора результата в список.
- Строку после `strip()` считай пустой, если в ней ничего нет.

## Пример

```python
task_pt14_first_error('INFO a\nERROR b\nERROR c\n')   # -> ['ERROR b', 2]
task_pt14_first_error('\nINFO a\n\nERROR disk\nINFO z\n')   # -> ['ERROR disk', 4]
```

## Учебные цели

- Написать два генератора и соединить их в ленивую цепочку.
- Использовать `next(gen, запасное)` для «первого или ничего».

## Проверка понимания

Сколько строк прочитает рамка, если в журнале нет ни одной ошибки? Что изменится, если в `non_empty` вернуть список?
