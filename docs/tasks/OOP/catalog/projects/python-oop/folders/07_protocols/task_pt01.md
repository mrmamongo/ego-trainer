# Задача PT01: Итератор и next

## Условие

### Как это работает

Цикл `for` внутри вызывает `iter(...)`, а потом `next(...)` до `StopIteration`. Ту же работу можно сделать руками:

```python
letters = ["a", "b"]         # 1
it = iter(letters)           # 2
x = next(it)                 # 3
y = list(it)                 # 4
z = next(it, "-")            # 5
```

| После строки | Значение | Почему |
|---|---|---|
| 3 | `x` равно `"a"` | первый `next` |
| 4 | `y` равно `["b"]` | `list` забрал всё, что осталось |
| 5 | `z` равно `"-"` | элементов нет, вернулось запасное значение |

Итератор одноразовый, а список можно обходить снова: каждый `iter(список)` даёт новый итератор.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит в каждой строке, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pt01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать `iter` и `next` как шаги, из которых состоит `for`.
- Помнить, что итератор одноразовый, а список можно обойти заново.
- Различать `next(it)` и `next(it, запасное)`.
