# Задача PT13: Таймер как свой итератор

## Условие

### Как это работает

Итератор «вручную» — это класс с двумя методами: `__iter__` возвращает `self`, `__next__` отдаёт очередное значение или бросает `StopIteration`, когда значения кончились.

```python
class Upto:
    def __init__(self, n):
        self.i = 0
        self.n = n

    def __iter__(self):
        return self

    def __next__(self):
        if self.i >= self.n:
            raise StopIteration
        self.i += 1
        return self.i

list(Upto(3))        # [1, 2, 3]
```

| После вызова | `self.i` | Что вернул `__next__` |
|---|---|---|
| первый `next` | `1` | `1` |
| третий `next` | `3` | `3` |
| четвёртый `next` | `3` | исключение `StopIteration` |

Такой объект одноразовый: второй `list(...)` даст `[]`.

### Задание

Напиши класс `Countdown` — таймер обратного отсчёта, который сам является итератором:

- `__init__(start)` запоминает, с какого числа идти вниз;
- `__iter__()` возвращает сам таймер;
- `__next__()` отдаёт `start`, `start - 1`, ... до `1`; когда числа кончились, бросает `StopIteration`.

Рамка обходит один таймер дважды (второй обход должен быть пустым, это нормально для итератора), а у второго таймера берёт два значения через `next(..., "конец")`.

## Аргументы

- `start` — число, с которого идёт отсчёт (целое; `0` и меньше значит, что отсчитывать нечего).

## Возвращает

Список из четырёх элементов: первый обход, второй обход (пустой), первое и второе значение второго таймера (или `"конец"`, если значений не хватило).

## Правила

- Пиши только класс `Countdown`; рамку внизу не трогай.
- Нужны методы `__init__`, `__iter__` и `__next__`.
- `StopIteration` нужно бросить самому.

## Пример

```python
task_pt13_countdown(3)   # -> [[3, 2, 1], [], 3, 2]
task_pt13_countdown(1)   # -> [[1], [], 1, 'конец']
```

## Учебные цели

- Написать итератор вручную: `__iter__` с `self`, `__next__` с `raise StopIteration`.
- Хранить позицию в атрибуте объекта.
