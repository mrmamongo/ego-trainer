# Как работает `for`: `iter` и `next`

Цикл `for x in что_то` умеет обходить списки, строки, словари, файлы. Внутри он всегда делает одно и то же:

1. вызывает `iter(что_то)` и получает **итератор** — объект, который помнит, где он остановился;
2. снова и снова вызывает `next(итератор)`, пока не получит исключение `StopIteration`;
3. `StopIteration` для цикла значит «всё, конец», это не ошибка.

```python
nums = [10, 20]          # 1
it = iter(nums)          # 2
a = next(it)             # 3
b = next(it)             # 4
c = next(it, -1)         # 5
d = list(it)             # 6
```

| После строки | Значение | Почему |
|---|---|---|
| 3 | `a` равно `10` | первый `next` |
| 4 | `b` равно `20` | итератор помнит позицию |
| 5 | `c` равно `-1` | элементов нет, `next(it, -1)` вернул запасное значение вместо `StopIteration` |
| 6 | `d` равно `[]` | итератор уже дошёл до конца |

## Итерируемое и итератор

- **Итерируемое** (iterable) — то, у чего можно запросить итератор через `iter(...)`: список, строка, словарь, файл. Список сам не «помнит позицию»: каждый `iter(nums)` даёт новый итератор, поэтому по списку можно ходить много раз.
- **Итератор** (iterator) — тот, у кого есть `next`. Он одноразовый: дошёл до конца — больше элементов не отдаст. Для итератора `iter(it) is it` (он сам себе итерируемое).

## Файл тоже итерируемое

Цикл `for line in file` отдаёт файл построчно. В задачах этой папки настоящий диск не трогаем: вместо `open(...)` берём `io.StringIO(текст)`. Это «файл в памяти» с теми же методами `read`, `write`, `readline` и обходом по строкам. Код, который работает с `StringIO`, так же работает и с `open(...)`.

```python
import io
file = io.StringIO("раз\nдва\n")
lines = [line.strip() for line in file]       # ["раз", "два"]
```

## Частые ошибки

Обойти итератор дважды и удивиться пустому результату:

```python
it = iter([1, 2, 3])
print(sum(it), sum(it))      # 6 0
```

Правильно: обходи сам список (`sum(nums)` хоть сколько раз) или заводи новый итератор через `iter(nums)`.

## Проверь себя

```python
it = iter("ab")
x = next(it)
y = list(it)
z = next(it, "-")
```

1. Чему равны `x`, `y`, `z`?
2. Чему равно `iter(it) is it`?

<details><summary>Ответ</summary>

1. `x` равно `"a"`, `y` равно `["b"]`, `z` равно `"-"`.
2. `True`: у итератора `iter` возвращает его самого.

</details>
