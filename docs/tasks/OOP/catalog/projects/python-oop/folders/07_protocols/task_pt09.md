# Задача PT09: Допиши закрытие секции

## Условие

### Как это работает

Функция с `@contextmanager` и одним `yield` работает как менеджер контекста: всё до `yield` выполняется на входе в `with`, а то, что в `finally`, — на выходе, даже если внутри блока случилась ошибка.

```python
from contextlib import contextmanager

@contextmanager
def door(log):
    log.append("открыли")
    try:
        yield
    finally:
        log.append("закрыли")

log = []
with door(log):
    log.append("вошли")
# log: ["открыли", "вошли", "закрыли"]
```

| Момент | Что в `log` |
|---|---|
| вход в `with` | `"открыли"` |
| тело блока | `"вошли"` |
| выход, даже при ошибке | `"закрыли"` |

### Задание

Функция `section(log, name)` отмечает в журнале начало и конец секции работы. Допиши строку в `finally`: замени `None` на строку `конец ` и имя секции (например, `конец загрузка`), чтобы конец записывался и при ошибке.

## Аргументы

- `name` — название секции (строка).
- `fail` — `True`, если внутри блока должна случиться ошибка `ValueError`.

## Возвращает

Список строк журнала: `начало ...`, `работа`, `конец ...`, а при ошибке в конце ещё `ошибка` (её добавляет рамка уже после `with`).

## Правила

- Замени `None` в строке `log.append(...)` под `finally` одним выражением, остальной код не меняй.
- Функцию `section` нужно сохранить с декоратором `@contextmanager`.

## Пример

```python
task_pt09_section('загрузка', False)   # -> ['начало загрузка', 'работа', 'конец загрузка']
task_pt09_section('загрузка', True)   # -> ['начало загрузка', 'работа', 'конец загрузка', 'ошибка']
```

## Учебные цели

- Читать устройство `@contextmanager`: до `yield`, `yield`, после `yield`.
- Понимать, что код в `finally` выполняется и при ошибке.

## Проверка понимания

Что окажется в журнале, если записать «конец» не в `finally`, а просто после `yield`, и в блоке будет ошибка?
