# Задача PT15: Транзакция через contextmanager

## Условие

### Как это работает

Менеджер контекста можно написать функцией-генератором с `@contextmanager`. Ошибка из блока `with` попадает в генератор прямо на строке с `yield`, и её можно перехватить `try`:

```python
from contextlib import contextmanager

@contextmanager
def checked(log):
    log.append("начало")
    try:
        yield log
    except Exception:
        log.append("откат")
        raise
    log.append("готово")
```

| Что внутри `with` | Что в `log` |
|---|---|
| всё прошло | `"начало"`, `"готово"` |
| поднята ошибка | `"начало"`, `"откат"`, ошибка летит дальше из-за `raise` |

Голый `raise` в `except` пробрасывает перехваченную ошибку дальше. Без него `with` проглотил бы её.

### Задание

Напиши менеджер контекста `transaction(wallet)` через `@contextmanager`: он запоминает баланс кошелька на входе, отдаёт кошелёк в блок `with`, а при ошибке внутри блока возвращает прежний баланс и пробрасывает ошибку дальше. Без ошибки баланс остаётся таким, каким его оставил блок.

Кошелёк `GivenWallet` и рамка готовы внизу файла.

## Аргументы

- `balance` — начальный баланс (целое число).
- `spends` — список трат; трата больше текущего баланса вызывает `ValueError` внутри блока.

## Возвращает

Список из двух значений: баланс после блока и `True`, если ошибка дошла до вызывающего кода.

## Правила

- Пиши только функцию `transaction`; кошелёк и рамку внизу файла не трогай.
- Функция должна быть с декоратором `@contextmanager` и содержать `yield`.
- Ошибку нельзя подавлять.

## Пример

```python
task_pt15_run(100, [30, 20])   # -> [50, False]
task_pt15_run(100, [30, 90])   # -> [100, True]
```

## Учебные цели

- Написать менеджер контекста через `@contextmanager` и `try/except`.
- Пробросить ошибку голым `raise`.
