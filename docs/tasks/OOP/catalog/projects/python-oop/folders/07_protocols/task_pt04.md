# Задача PT04: Что делает return в __exit__

## Условие

### Как это работает

Метод `__exit__` вызывается при выходе из `with` всегда. Если он вернул `True`, ошибка из блока подавляется и программа идёт дальше. Если `False`, ошибка летит наружу.

```python
events = []                              # 1
class Door:                              # 2
    def __init__(self, quiet):           # 3
        self.quiet = quiet               # 4
    def __enter__(self):                 # 5
        events.append("open")            # 6
        return self                      # 7
    def __exit__(self, t, e, tb):        # 8
        events.append("close")           # 9
        return self.quiet                # 10
with Door(True):                         # 11
    raise KeyError("x")                  # 12
events.append("next")                    # 13
```

| После строки | `events` | Почему |
|---|---|---|
| 12 | `["open"]` | ошибка уже случилась, но `__exit__` ещё не вызван |
| 13 | `["open", "close"]` | `__exit__` вернул `True`, ошибка проглочена |
| конец | `["open", "close", "next"]` | выполнение пошло дальше |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит в каждой строке, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pt04_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, что `__exit__` вызывается и при ошибке, и без неё.
- Понимать, что `True` из `__exit__` подавляет ошибку, а `False` пропускает её наружу.
- Следить за порядком событий «вход, тело, выход».

## Проверка понимания

Какие события окажутся в `events`, если в обоих блоках не будет `raise`? А если `__exit__` вообще ничего не вернёт (то есть вернёт `None`)?
