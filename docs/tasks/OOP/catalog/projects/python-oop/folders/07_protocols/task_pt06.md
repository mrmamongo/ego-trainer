# Задача PT06: Страницы таблицы лидеров

## Условие

### Как это работает

Генератор отдаёт значения через `yield`. `return` в той же функции просто завершает её и отдаёт одно значение:

```python
def halves(items):
    middle = len(items) // 2
    return items[:middle]           # функция закончилась на первой же порции
    return items[middle:]           # сюда управление не дойдёт

list(halves([1, 2, 3, 4]))          # [1, 2]: это обход списка [1, 2], а не две порции
```

| Что в функции | Что получает `list(...)` |
|---|---|
| `return порция` | одну порцию, и `list` обходит её элементы |
| `yield порция` | поток порций, каждая остаётся целой |

### Задание

Функция `leaderboard_pages(names, size)` должна отдавать таблицу лидеров по страницам: каждая страница — список из не более чем `size` имён. Сейчас вместо страниц возвращается что-то другое. Найди ошибку и исправь.

## Аргументы

- `names` — список имён игроков (строки), может быть пустым.
- `size` — размер страницы, целое число не меньше 1.

## Возвращает

Список страниц; страница — список имён. Все страницы, кроме последней, полные. Для пустого списка `[]`.

## Правила

- Менять нужно только функцию `leaderboard_pages`, рамку внизу файла не трогай.
- Страницы должны отдаваться по одной, через `yield`.
- Список `names` менять нельзя.

## Пример

```python
task_pt06_pages(['a', 'b', 'c'], 2)   # -> [['a', 'b'], ['c']]
task_pt06_pages(['a', 'b'], 5)   # -> [['a', 'b']]
```

## Учебные цели

- Узнавать `return` вместо `yield` по тому, что страницы «слипаются».
- Писать генератор порций со срезом `names[start:start + size]`.

## Проверка понимания

Что вернёт `leaderboard_pages(["a"], 5)` до исправления и после? Что произойдёт после `yield` в следующий вызов `next`?
