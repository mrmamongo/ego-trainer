# Задача PT02: Обратный отсчёт в одном объекте

## Условие

### Как это работает

Если `__iter__` возвращает `self`, объект сам итератор: его позиция хранится в атрибуте, и обойти такой объект можно один раз.

```python
class Steps:                                   # 1
    def __init__(self, n):                     # 2
        self.left = n                          # 3
    def __iter__(self):                        # 4
        return self                            # 5
    def __next__(self):                        # 6
        if self.left == 0:                     # 7
            raise StopIteration                # 8
        self.left -= 1                         # 9
        return self.left                       # 10
s = Steps(2)                                   # 11
a = next(s)                                    # 12
b = list(s)                                    # 13
c = list(s)                                    # 14
```

| После строки | Значение |
|---|---|
| 12 | `a` равно `1`, `s.left` равно `1` |
| 13 | `b` равно `[0]`, `s.left` равно `0` |
| 14 | `c` равно `[]`: `__next__` сразу бросил `StopIteration` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что происходит в каждой строке, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pt02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Следить за позицией, которая хранится в атрибуте `current`.
- Понять, почему второй обход такого объекта пустой.
- Видеть, как `StopIteration` превращается в запасное значение `next(t, ...)`.
