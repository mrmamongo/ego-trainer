# Задача PT18: Транзакция гасит только нехватку денег

## Условие

### Как это работает

`__exit__` получает класс пришедшей ошибки в `exc_type` (если ошибки не было, там `None`). По нему можно решить, какие ошибки подавлять, а какие пропускать:

```python
class OnlyValueErrors:
    def __enter__(self):
        return self

    def __exit__(self, exc_type, exc, tb):
        return exc_type is not None and issubclass(exc_type, ValueError)
```

| Что случилось в блоке | `__exit__` вернул | Итог |
|---|---|---|
| ничего | `False` | блок завершился нормально |
| `ValueError` | `True` | ошибка подавлена, код идёт дальше |
| `KeyError` | `False` | ошибка летит наружу |

### Задание

Раньше `Transaction` откатывала баланс при любой ошибке и пробрасывала её дальше. Теперь:

- если в блоке случилась `ValueError` (нехватка денег), баланс откатывается и ошибка **подавляется**: код после `with` продолжает работать;
- любая другая ошибка (например, `KeyError`) по-прежнему откатывает баланс и летит наружу.

Рамка показывает баланс, итог (`"ok"`, `"ValueError"` или `"KeyError"` — какая ошибка дошла до внешнего `try`) и достигнута ли строка после `with`.

## Аргументы

- `balance` — начальный баланс (целое число).
- `spends` — список трат: `0` вызывает `KeyError`, трата больше баланса вызывает `ValueError`.

## Возвращает

Список из трёх значений: баланс после блока, итог (`"ok"`, `"ValueError"` или `"KeyError"`) и `True`, если выполнение дошло до строки после `with`.

## Правила

- Меняй только метод `__exit__` в классе `Transaction`; кошелёк и рамку внизу не трогай.
- Откат баланса при любой ошибке сохраняется.
- Без ошибок поведение не меняется.

## Пример

```python
task_pt18_run(100, [30, 20])   # -> [50, 'ok', True]
task_pt18_run(100, [30, 90])   # -> [100, 'ok', True]
```

## Учебные цели

- Решать по `exc_type`, какую ошибку подавлять.
- Возвращать из `__exit__` логическое значение через `issubclass`.

## Проверка понимания

Что вернёт рамка для `balance=100`, `spends=[30, 0]` до и после изменения? А для `spends=[30, 90]`?
