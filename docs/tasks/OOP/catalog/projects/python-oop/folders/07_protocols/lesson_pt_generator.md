# Генератор: `yield` вместо `return`

Писать класс с `__next__` долго. Функция, внутри которой есть `yield`, — **генератор**: Python сам делает из неё итератор.

```python
log = []

def gen():
    log.append("старт")
    yield 1
    log.append("середина")
    yield 2

g = gen()              # 1
a = next(g)            # 2
b = next(g)            # 3
rest = list(g)         # 4
```

| После строки | `log` | Что получилось |
|---|---|---|
| 1 | `[]` | тело функции **не** запускалось, получили объект-генератор |
| 2 | `["старт"]` | выполнилось до первого `yield`, `a` равно `1` |
| 3 | `["старт", "середина"]` | `b` равно `2`, генератор «спит» на втором `yield` |
| 4 | то же | `rest` равно `[]`: конец функции — это `StopIteration` |

Два свойства:

- **Лень.** Значение считается, только когда его попросили через `next` или `for`.
- **Одноразовость.** Генератор — итератор: исчерпанный, он больше ничего не отдаст.

## `yield` против `return`

`return` завершает функцию и отдаёт одно значение. `yield` отдаёт значение и **приостанавливает** функцию, переменные цикла сохраняются:

```python
def pages(names, size):
    start = 0
    while start < len(names):
        yield names[start:start + size]      # страница, потом продолжаем
        start += size
```

`list(pages(["a", "b", "c"], 2))` даёт `[["a", "b"], ["c"]]`.

## `__iter__` как генератор

Самый удобный способ сделать коллекцию, которую можно обходить много раз:

```python
class Leaderboard:
    def __init__(self, names):
        self.names = names

    def __iter__(self):
        for name in self.names:
            yield name
```

Каждый `for` вызывает `__iter__` заново, а значит получает новый генератор. Состояние не общее, второй обход не пустой.

## Частые ошибки

`return` вместо `yield` внутри цикла: функция вернёт только первую порцию и закончится. `print` вместо `yield` тоже не то: напечатанное нельзя собрать в `list`.

Объект-генератор нельзя вернуть как готовый ответ, который сравнивают с ожидаемым: превращай его в список через `list(gen)`.

## Проверь себя

```python
def evens(limit):
    n = 0
    while n <= limit:
        yield n
        n += 2

g = evens(4)
a = next(g)
b = list(g)
c = list(g)
```

<details><summary>Ответ</summary>

`a` равно `0`, `b` равно `[2, 4]`, `c` равно `[]`: генератор исчерпан после `b`.

</details>
