# Задача PT08: Допиши обратный отсчёт

## Условие

### Как это работает

`__iter__`, написанный как генератор, при каждом `for` создаёт новый генератор с нуля. Поэтому объект можно обходить много раз. `yield` отдаёт очередное значение:

```python
class Steps:
    def __init__(self, n):
        self.n = n

    def __iter__(self):
        i = 1
        while i <= self.n:
            yield f"шаг {i}"
            i += 1

list(Steps(2))      # ["шаг 1", "шаг 2"]
list(Steps(2))      # то же самое: новый обход начался заново
```

| Выражение | Результат |
|---|---|
| `list(Steps(2))` | `["шаг 1", "шаг 2"]` |
| `list(Steps(0))` | `[]` |

### Задание

В классе `Countdown` (таймер обратного отсчёта) метод `__iter__` почти готов. Допиши одну строку: замени `None` после `yield` на f-строку вида `3 сек`, то есть текущее `n`, пробел и `сек`.

## Аргументы

- `start` — с какого числа начинается отсчёт (целое число; при `0` и меньше отсчёта нет).

## Возвращает

Список из двух списков строк: первый и второй обход таймера. Для `start=3` оба равны `["3 сек", "2 сек", "1 сек"]`.

## Правила

- Замени `None` в строке с `yield` одним выражением, остальной код не меняй.
- Метод должен отдавать значения через `yield`, а не возвращать список.

## Пример

```python
task_pt08_timer(3)   # -> [['3 сек', '2 сек', '1 сек'], ['3 сек', '2 сек', '1 сек']]
task_pt08_timer(1)   # -> [['1 сек'], ['1 сек']]
```

## Учебные цели

- Писать значение после `yield` в генераторе `__iter__`.
- Понимать, что `__iter__` на генераторе даёт одинаковые обходы.

## Проверка понимания
