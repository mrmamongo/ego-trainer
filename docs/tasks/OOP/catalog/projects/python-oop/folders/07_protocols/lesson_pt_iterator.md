# Свой итератор: `__iter__` и `__next__`

Чтобы по твоему объекту работал `for`, классу нужен метод `__iter__`. Он должен вернуть **итератор**, то есть объект с методом `__next__`. Есть два способа.

**Способ 1: объект сам итератор** (`__iter__` возвращает `self`). Тогда в классе есть и `__next__`:

```python
class Countdown:
    def __init__(self, start):
        self.current = start            # позиция хранится в самом объекте

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration         # «элементы кончились»
        value = self.current
        self.current -= 1
        return value

c = Countdown(2)                        # 1
a = next(c)                             # 2
b = list(c)                             # 3
d = list(c)                             # 4
```

| После строки | Что получилось |
|---|---|
| 2 | `a` равно `2`, `c.current` равно `1` |
| 3 | `b` равно `[1]`, `c.current` равно `0` |
| 4 | `d` равно `[]`: позиция лежит в самом объекте, она уже на нуле |

Такой объект одноразовый: второй `for` по нему пустой.

**Способ 2: `__iter__` отдаёт свежий итератор.** Данные остаются в объекте, а позиция живёт в новом итераторе при каждом обходе:

```python
class QuestLog:
    def __init__(self):
        self.titles = []

    def __iter__(self):
        return iter(self.titles)        # новый итератор на каждый for
```

Теперь `list(log)` можно вызывать сколько угодно раз. Для коллекции (журнал, чат, таблица) почти всегда нужен именно способ 2.

## Частые ошибки

Коллекция, которая сама себе итератор:

```python
def __iter__(self):
    return self          # позиция self.pos запомнится, и второй обход пустой
```

Правильно: `return iter(self.titles)` или `__iter__` как генератор (следующая карточка).

Забыть `raise StopIteration` в `__next__`: цикл `for` не остановится никогда. Вернуть `None` вместо исключения нельзя: `None` цикл примет за обычный элемент.

## Проверь себя

```python
c = Countdown(3)
x = next(c)
y = sum(c)
z = sum(c)
```

1. Чему равны `x`, `y`, `z`?
2. Как изменить класс, чтобы `z` был равен `y`? Подсказка: что должен вернуть `__iter__`?

<details><summary>Ответ</summary>

1. `x` равно `3`, `y` равно `3` (это `2 + 1`), `z` равно `0`.
2. Хранить в объекте только `start`, а `__iter__` сделать генератором с локальной `n`: `n = self.start; while n > 0: yield n; n -= 1`. Тогда каждый обход начинается заново.

</details>
