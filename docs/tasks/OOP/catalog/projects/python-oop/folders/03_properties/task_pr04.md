# Задача PR04: Цена со скидкой

## Условие

### Как это работает

Свойство-«вычисление» — это метод с `@property`, который что-то считает и **возвращает** через `return`. Скидка в процентах уменьшает цену на её долю: от цены остаётся `100 - discount` процентов.

```python
class Ticket:
    def __init__(self, price, discount):
        self._price = price
        self._discount = discount

    @property
    def to_pay(self):
        return self._price * (100 - self._discount) // 100
```

| Действие | Результат | Пояснение |
|---|---|---|
| `["new", 200, 25]` | `"ok"` | |
| `["get", "to_pay"]` | `150` | `200 * 75 // 100` |

`//` — целочисленное деление: копейки отбрасываются.

### Задание

В классе `Product` у свойства `final_price` не хватает одной строки. Допиши её вместо `pass`: свойство должно вернуть цену с учётом скидки `discount` (в процентах), целым числом.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Свойство должно вернуть число через `return`, а не печатать его.
- Цена и скидка в объекте не меняются.

## Пример

| Действие | Результат |
|---|---|
| `["new", 200, 10]` | `"ok"` |
| `["get", "final_price"]` | `180` |
| `["get", "price"]` | `200` |

## Учебные цели

- Написать тело вычисляемого свойства одной строкой с `return`.
- Считать скидку в процентах целыми числами.
- Помнить, что свойство читают без скобок.
