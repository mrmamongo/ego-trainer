# Задача PR16: Квест и награда

## Условие

### Как это работает

Один класс обычно сочетает три вида доступа:

- **обычный атрибут**, если правил нет (`self.base_reward`);
- **свойство с сеттером**, если значение меняют, но по правилам (`level` от 1 до 5);
- **свойство только для чтения**, если значение либо вычисляется (`reward`), либо меняется только методом (`done`).

```python
class Ticket:
    def __init__(self, price):
        self.price = price                 # правил нет: обычный атрибут
        self._used = False

    @property
    def used(self):                        # только чтение
        return self._used

    def use(self):                         # меняет состояние метод
        if self._used:
            raise ValueError("билет уже использован")
        self._used = True
```

| Действие | Результат |
|---|---|
| `["new", 50]` | `"ok"` |
| `["use"]` | `None` |
| `["get", "used"]` | `True` |
| `["set", "used", False]` | `["error", "AttributeError", ""]` |
| `["use"]` | `["error", "ValueError", "билет уже использован"]` |

Порядок в `__init__` важен: поля, от которых зависят сеттеры или свойства, создают до того, как к ним обратятся.

### Задание

Напиши класс `Quest`:

- `__init__(title, base_reward, level=1)`: `title` хранится в `_title`, `base_reward` — обычный атрибут, `level` записывается **через свойство**; квест сначала не выполнен;
- свойство `title` и свойство `done` только для чтения;
- свойство `level` (чтение и запись): от `1` до `5` включительно, иначе `ValueError("уровень от 1 до 5")`, значение не меняется;
- свойство `reward` только для чтения: `base_reward * level`, считается заново при каждом чтении;
- `complete()` отмечает квест выполненным и возвращает награду; если квест уже выполнен, бросает `ValueError("квест уже выполнен")`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Quest`; рамку внизу файла не трогай.
- Награду не храни в поле: она считается из `base_reward` и `level`.
- Тексты ошибок должны совпасть с условием слово в слово.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Гоблин", 40, 2]` | `"ok"` |
| `["get", "reward"]` | `80` |
| `["complete"]` | `80` |
| `["get", "done"]` | `True` |
| `["complete"]` | `["error", "ValueError", "квест уже выполнен"]` |
| `["set", "reward", 1]` | `["error", "AttributeError", ""]` |

## Учебные цели

- Выбирать вид доступа для каждого поля: атрибут, свойство с сеттером, свойство только для чтения.
- Менять состояние `done` только методом.
- Считать награду из текущих данных при каждом чтении.
