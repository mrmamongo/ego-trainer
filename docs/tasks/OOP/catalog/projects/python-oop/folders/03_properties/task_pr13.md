# Задача PR13: Здоровье игрока в границах

## Условие

### Как это работает

Сеттер не обязан бросать ошибку: он может **подогнать** значение под правило. Здесь здоровье всегда лежит в границах от `0` до `max_hp`: что бы ни присвоили, сеттер подрежет.

```python
class Gauge:
    def __init__(self, limit):
        self.limit = limit
        self.level = 0                   # через сеттер

    @property
    def level(self):
        return self._level

    @level.setter
    def level(self, value):
        if value < 0:
            value = 0
        if value > self.limit:
            value = self.limit
        self._level = value

    def fill(self, k):
        self.level = self.level + k       # подрезка сработает сама
```

| Действие | Результат | Пояснение |
|---|---|---|
| `["new", 10]` | `"ok"` | |
| `["fill", 25]` | `None` | `25` подрезано до `10` |
| `["get", "level"]` | `10` | |

Методы `damage` и `heal` не копируют границы: они пишут через свойство, и правило сработает само. Это тот же приём «одно место для проверки».

### Задание

Напиши класс `Player`:

- `__init__(name, max_hp)` запоминает `name` и `max_hp` в одноимённых атрибутах; здоровье сначала равно `max_hp`;
- свойство `hp` (чтение и запись): сеттер подрезает значение до границ от `0` до `max_hp` и запоминает в `_hp`;
- свойство `is_alive` только для чтения: `True`, если `hp` больше нуля;
- `damage(amount)` уменьшает здоровье, `heal(amount)` увеличивает; оба пишут через свойство `hp` и ничего не возвращают.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Player`; рамку внизу файла не трогай.
- Снаружи класса к `_hp` обращаться нельзя, только к `hp`.
- Границы проверяются в одном месте: в сеттере.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 30]` | `"ok"` |
| `["damage", 100]` | `None` |
| `["get", "hp"]` | `0` |
| `["get", "is_alive"]` | `False` |
| `["heal", 100]` | `None` |
| `["get", "hp"]` | `30` |

## Учебные цели

- Написать сеттер, который подрезает значение, а не отклоняет его.
- Делать методы через свойство, не копируя границы.
- Объявить свойство только для чтения (`is_alive`).
