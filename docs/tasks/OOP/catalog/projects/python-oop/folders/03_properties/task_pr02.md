# Задача PR02: Градусы без скобок

## Условие

### Как это работает

`@property` делает из метода **свойство**: его читают без скобок (`t.fahrenheit`), а значение каждый раз считается заново из текущего состояния. Хранить его отдельно не нужно, поэтому оно не устаревает.

```python
class Rect:                               # 1
    def __init__(self, w, h):             # 2
        self._w = w                       # 3
        self._h = h                       # 4
    def grow(self, k):                    # 5
        self._w = self._w + k             # 6
    @property                             # 7
    def area(self):                       # 8
        return self._w * self._h          # 9
r = Rect(2, 3)                            # 10
x = r.area                                # 11
r.grow(2)                                 # 12
y = r.area                                # 13
```

| После строки | `r._w` | `r._h` | Что произошло |
|---|---|---|---|
| 10 | `2` | `3` | |
| 11 | `2` | `3` | `x` равно `6`, без скобок |
| 12 | `4` | `3` | изменили только ширину |
| 13 | `4` | `3` | `y` равно `12`: свойство посчитано заново |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что лежит в объекте после каждой строки, без компьютера. Веди табличку «поле → значение» для каждого объекта.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pr02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать свойство без круглых скобок.
- Видеть, что значение свойства пересчитывается при каждом чтении.
- Считать по формуле перевода градусов Цельсия в Фаренгейта.
