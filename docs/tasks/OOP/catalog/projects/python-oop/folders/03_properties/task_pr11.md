# Задача PR11: Запись запрещена

## Условие

### Как это работает

У свойства без сеттера присваивание бросает `AttributeError`. Поэтому в `try` оно срабатывает не до конца: строка после присваивания не выполняется, и управление уходит в `except`. Свойство с сеттером при этом присваивается спокойно.

```python
class Door:                               # 1
    def __init__(self):                   # 2
        self._opened = 0                  # 3
    @property                             # 4
    def opened(self):                     # 5
        return self._opened               # 6
    def open(self):                       # 7
        self._opened = self._opened + 1   # 8
d = Door()                                # 9
try:                                      # 10
    d.opened = 5                          # 11  AttributeError
    r = "записали"                        # 12  не выполняется
except AttributeError:                    # 13
    r = "запрет"                          # 14
d.open()                                  # 15
x = d.opened                              # 16
```

| После строки | `d._opened` | Что произошло |
|---|---|---|
| 9 | `0` | |
| 11 | `0` | у `opened` нет сеттера: ошибка, поле не тронуто |
| 14 | `0` | `r` равно `"запрет"` |
| 15 | `1` | менять состояние можно только методом |
| 16 | `1` | `x` равно `1` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что лежит в объекте после каждой строки, без компьютера. Веди табличку «поле → значение» для каждого объекта.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pr11_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Видеть, что присваивание свойству без сеттера бросает `AttributeError`.
- Отличать свойство с сеттером от свойства только для чтения.
- Понимать, что состояние такого объекта меняют методами.
