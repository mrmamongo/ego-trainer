# Подчёркивание: не трогай снаружи

У банковского счёта есть правило: баланс не уходит в минус. Правило записано в методе `withdraw`. Но если любой код может написать `acc.balance = -500`, правило обходится одной строкой.

**Инкапсуляция** — это когда объект сам отвечает за свои данные: снаружи с ними работают через методы, а правила проверки живут внутри класса, в одном месте.

В Python нет настоящих «закрытых» полей. Есть **соглашение**: имя с одним подчёркиванием в начале — `_balance` — значит «это внутреннее, снаружи не трогай». Python ничего не запрещает и не проверяет, это уговор между программистами. Нарушишь — код заработает, но правило класса ты обошёл.

```python
class Wallet:
    def __init__(self, money):
        self._money = money           # внутреннее поле

    def add(self, k):
        self._money = self._money + k

    def total(self):
        return self._money            # безопасный способ прочитать
```

Внутри класса (в методах) `self._money` использовать можно и нужно. Снаружи — только `w.add(...)` и `w.total()`.

Есть ещё имена с двумя подчёркиваниями (`__money`): Python переименовывает их внутри класса. Это не защита, а способ избежать случайных совпадений имён при наследовании; нам он пока не нужен.

## Трассировка

```python
w = Wallet(100)       # 1
w.add(50)             # 2
a = w.total()         # 3
w._money = 10         # 4  так делать нельзя, но Python позволит
b = w.total()         # 5
```

| После строки | `w._money` | Что получилось |
|---|---|---|
| 1 | `100` | |
| 2 | `150` | метод изменил внутреннее поле |
| 3 | `150` | `a` равно `150` |
| 4 | `10` | поле перезаписали в обход класса |
| 5 | `10` | `b` равно `10`: правил класса никто не спросил |

## Частые ошибки

Менять внутреннее поле снаружи:

```python
acc._balance = 500           # неверно: класс не узнал и не проверил
```

```python
acc.deposit(500)             # верно: правило класса сработало
```

Думать, что `_balance` Python «спрячет». Он не прячет: поле видно и меняется. Охраняет его только договорённость.

## Проверь себя

```python
class Jar:
    def __init__(self, n):
        self._n = n

    def take(self):
        self._n = self._n - 1

    def count(self):
        return self._n

j = Jar(3)
j.take()
j._n = 10
x = j.count()
```

1. Чему равен `x`?
2. Как правильно добавить в банку ещё штуки, не трогая `_n` снаружи?

<details><summary>Ответ</summary>

1. `10`: после `take` было `2`, но потом поле перезаписали снаружи.
2. Дописать в класс метод (например, `put(k)`, который делает `self._n = self._n + k`) и вызывать его. Внутреннее поле снаружи не меняют.

</details>
