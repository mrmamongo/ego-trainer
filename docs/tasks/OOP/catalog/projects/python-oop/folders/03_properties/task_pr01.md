# Задача PR01: Что лежит во внутреннем поле

## Условие

### Как это работает

Имя с подчёркиванием `_money` говорит: «это внутреннее поле, снаружи не трогай». Но Python это только **просит**, а не запрещает. Если снаружи всё-таки написать `w._money = 10`, значение поменяется. Поэтому при трассировке честно ведут таблицу состояния, даже когда строку «писать не стоило».

```python
class Jar:                         # 1
    def __init__(self, n):         # 2
        self._n = n                # 3
    def take(self):                # 4
        self._n = self._n - 1      # 5
    def count(self):               # 6
        return self._n             # 7
j = Jar(3)                         # 8
j.take()                           # 9
j._n = 7                           # 10  в обход метода
x = j.count()                      # 11
```

| После строки | `j._n` | Что произошло |
|---|---|---|
| 8 | `3` | `__init__` записал внутреннее поле |
| 9 | `2` | метод изменил `_n` |
| 10 | `7` | поле перезаписали снаружи, метод об этом не знает |
| 11 | `7` | `x` равно `7`: `count` читает то, что лежит в `_n` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что лежит в объекте после каждой строки, без компьютера. Веди табличку «поле → значение» для каждого объекта.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pr01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать код класса, где данные лежат в поле `_имя`.
- Видеть, что запись снаружи меняет поле, хотя по соглашению так делать нельзя.
- Понимать, что метод читает то, что лежит в поле сейчас.
