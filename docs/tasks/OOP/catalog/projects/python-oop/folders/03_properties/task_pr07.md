# Задача PR07: Допиши запись email

## Условие

### Как это работает

У сеттера две части: **проверка** (отклонить плохое значение через `raise ValueError`) и **запись** (положить подходящее значение в «склад» `_поле`). Если проверка есть, а записи нет, ничего не сохранится, и чтение свойства упадёт.

```python
class Nick:
    def __init__(self, text):
        self.text = text                  # идёт через сеттер

    @property
    def text(self):
        return self._text

    @text.setter
    def text(self, value):
        if value == "":
            raise ValueError("ник пустой")    # проверка
        self._text = value.strip()            # запись
```

| Действие | Результат | Пояснение |
|---|---|---|
| `["new", " Аня "]` | `"ok"` | проверку прошло, запись сняла пробелы |
| `["get", "text"]` | `"Аня"` | |
| `["set", "text", ""]` | `["error", "ValueError", "ник пустой"]` | запись не дошла, `_text` прежний |

### Задание

В классе `Profile` адрес почты хранится в свойстве `email`. Сеттер уже проверяет, что в адресе есть `@`, но сам адрес никуда не записывает. Допиши одну строку вместо `pass`: запомни в `_email` значение без пробелов по краям.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Замени `pass` одной строкой, остальной код не меняй.
- Пиши в `_email`, а не в `email`: иначе сеттер будет вызывать сам себя.
- Адрес без `@` по-прежнему отклоняется (проверка уже написана).

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", "  anya@mail.ru "]` | `"ok"` |
| `["get", "email"]` | `"anya@mail.ru"` |
| `["set", "email", "anya"]` | `["error", "ValueError", "в email нужна @"]` |
| `["get", "email"]` | `"anya@mail.ru"` |

## Учебные цели

- Дописать «склад» в сеттере: проверка плюс запись в `_поле`.
- Чистить строку методом `strip()`.
- Видеть, что `__init__` проходит через сеттер и получает ту же проверку.

## Проверка понимания

Что вернёт `["get", "email"]` после неудачного `["set", "email", "anya"]` и почему? Зачем писать в `_email`, а не в `email`?
