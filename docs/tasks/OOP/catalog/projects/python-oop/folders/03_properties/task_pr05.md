# Задача PR05: Здоровье в границах

## Условие

### Как это работает

Присваивание `p.hp = 70` вызывает **сеттер** — метод с `@hp.setter`. Он получает значение в параметр `value`, проверяет или подправляет его и кладёт в `_hp`. Читать `p.hp` — значит вызвать свойство, которое возвращает `_hp`.

```python
class Dial:                              # 1
    def __init__(self):                  # 2
        self._pos = 0                    # 3
    @property                            # 4
    def pos(self):                       # 5
        return self._pos                 # 6
    @pos.setter                          # 7
    def pos(self, value):                # 8
        if value > 10:                   # 9
            value = 10                   # 10
        self._pos = value                # 11
d = Dial()                               # 12
d.pos = 4                                # 13
d.pos = 40                               # 14
x = d.pos                                # 15
d._pos = 99                              # 16  в обход сеттера
y = d.pos                                # 17
```

| После строки | `d._pos` | Что произошло |
|---|---|---|
| 12 | `0` | |
| 13 | `4` | `4` не больше десяти, записано как есть |
| 14 | `10` | `40` слишком много, сеттер подрезал до `10` |
| 15 | `10` | `x` равно `10` |
| 16 | `99` | запись прямо в `_pos` сеттер не видит |
| 17 | `99` | `y` равно `99` |

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, что лежит в объекте после каждой строки, без компьютера. Веди табличку «поле → значение» для каждого объекта.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_pr05_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Проследить, что делает сеттер при каждом присваивании свойству.
- Видеть, что сеттер может подправить значение (не только отклонить).
- Понимать, что запись прямо в `_hp` обходит проверку сеттера.
