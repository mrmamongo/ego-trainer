# Задача PR08: Собери загрузку с отказами

## Условие

### Как это работает

Присваивание свойству может бросить `ValueError`. Чтобы одна плохая запись не остановила всю функцию, присваивание кладут в `try`, а в `except ValueError` решают, что делать дальше: посчитать, пропустить, запомнить.

```python
def count_bad(values):
    bad = 0
    for value in values:
        try:
            gauge.level = value          # может бросить ValueError
        except ValueError:
            bad = bad + 1                # плохое значение посчитали
    return bad
```

**Отступы** показывают вложенность: присваивание стоит под `try`, `except` на одном уровне с `try`, а счётчик ошибок под `except`.

Класс `Progress` в файле уже готов: ты собираешь только функцию, которая им пользуется.

### Задание

В файле задачи в комментарии записаны строки функции `task_pr08_apply(steps)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция заводит полосу `Progress`, по очереди присваивает ей значения из `steps`, считает отклонённые значения и возвращает проценты в конце и число отклонённых.

## Аргументы

- `steps` — список целых чисел: проценты, которые по очереди присваивают полосе (может быть пустым).

## Возвращает

Список из двух элементов: процент полосы в конце и число значений, которые полоса отклонила (бросила `ValueError`). Для пустого списка `[0, 0]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Класс `Progress` готов, его не меняй.

## Пример

```python
task_pr08_apply([10, 50, 120, 80])   # -> [80, 1]
task_pr08_apply([])                  # -> [0, 0]
```

## Учебные цели

- Собрать шаблон «присвоить свойству, поймать `ValueError`, посчитать отказы».
- Расставить отступы у `try`/`except` внутри цикла.
- Видеть, что отклонённое значение не меняет полосу.

## Проверка понимания

Чему будет равен процент, если все значения отклонены? Что изменится, если вынести `bar = Progress()` внутрь цикла?
