# Задача PR03: Товар, который не создаётся

## Условие

### Как это работает

Если у свойства есть только `@property` и нет сеттера, **присваивать его нельзя**: `obj.price = 5` даёт `AttributeError`. Значит, и внутри `__init__` нельзя написать `self.price = price`. Данные кладут в «склад» с подчёркиванием, а свойство их отдаёт:

```python
class Coin:
    def __init__(self, value):
        self.value = value            # AttributeError: у value нет сеттера

    @property
    def value(self):
        return self._value
```

```python
class Coin:
    def __init__(self, value):
        self._value = value           # верно: пишем в «склад»

    @property
    def value(self):
        return self._value
```

В сценарии такая ошибка видна на первом же действии: объект не создаётся.

| Действие | Результат |
|---|---|
| `["new", "Чай", 120]` | сейчас `["error", "AttributeError", ""]`, а должно быть `"ok"` |
| `["get", "price"]` | должно быть `120` |

Текст ошибки зависит от версии Python, поэтому рамка его убирает и оставляет только тип: третий элемент всегда пустая строка.

### Задание

Класс `Product` хранит название и цену товара. Название и цена — свойства **только для чтения**: после создания их менять нельзя. Метод `describe()` возвращает строку вида `"Чай: 120"`. Сейчас объект даже не создаётся. Найди ошибку и исправь.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Меняй только код класса `Product`; рамку внизу файла не трогай.
- Название и цена остаются свойствами только для чтения: присвоить их снаружи нельзя.
- Имя класса и параметры `__init__` оставь как есть.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Чай", 120]` | `"ok"` |
| `["get", "price"]` | `120` |
| `["describe"]` | `"Чай: 120"` |
| `["set", "price", 50]` | `["error", "AttributeError", ""]` |
| `["get", "price"]` | `120` |

## Учебные цели

- Узнавать `AttributeError` при создании объекта: `__init__` пишет в свойство без сеттера.
- Помнить: в `__init__` для свойства только для чтения пишут в `_поле`.
- Отличать «свойство читают» от «поле хранят».
