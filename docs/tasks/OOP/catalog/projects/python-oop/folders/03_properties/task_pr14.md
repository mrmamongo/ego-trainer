# Задача PR14: Счёт, который всегда корректен

## Условие

### Как это работает

Правило «баланс не меньше нуля» должно держаться везде: при создании, при присваивании и в методах. Для этого проверка живёт **только в сеттере**, а все остальные места пишут через свойство `self.balance`. Метод сам проверяет только то, что относится к нему лично (например, сумма операции).

```python
class Tank:
    def __init__(self, volume):
        self.volume = volume                  # через сеттер

    @property
    def volume(self):
        return self._volume

    @volume.setter
    def volume(self, value):
        if value < 0:
            raise ValueError("объём не бывает отрицательным")
        self._volume = value

    def drain(self, k):
        if k <= 0:                            # правило самого метода
            raise ValueError("нужно слить больше нуля")
        self.volume = self.volume - k         # правило объекта проверит сеттер
```

| Действие | Результат |
|---|---|
| `["new", 5]` | `"ok"` |
| `["drain", 0]` | `["error", "ValueError", "нужно слить больше нуля"]` |
| `["drain", 9]` | `["error", "ValueError", "объём не бывает отрицательным"]` |
| `["get", "volume"]` | `5` |

### Задание

Напиши класс `BankAccount`:

- `__init__(owner, balance)`: `owner` хранится в `_owner`, а `balance` записывается **через свойство**;
- свойство `owner` только для чтения;
- свойство `balance` (чтение и запись): отрицательное значение отклоняется через `ValueError("баланс не может быть отрицательным")`, значение не меняется;
- `deposit(amount)` и `withdraw(amount)`: если `amount` не больше нуля, бросают `ValueError("сумма должна быть больше нуля")`; иначе меняют баланс **через свойство**, проверять баланс в самих методах не нужно.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `BankAccount`; рамку внизу файла не трогай.
- Снаружи класса к `_balance` и `_owner` обращаться нельзя.
- Проверку баланса не копируй: она только в сеттере.
- Тексты ошибок должны совпасть с условием слово в слово.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Аня", 100]` | `"ok"` |
| `["withdraw", 500]` | `["error", "ValueError", "баланс не может быть отрицательным"]` |
| `["deposit", 0]` | `["error", "ValueError", "сумма должна быть больше нуля"]` |
| `["get", "balance"]` | `100` |
| `["set", "owner", "Боря"]` | `["error", "AttributeError", ""]` |

## Учебные цели

- Собрать вместе свойство с проверкой, свойство только для чтения и методы.
- Передать создание объекта через сеттер, чтобы объект не мог родиться некорректным.
- Хранить правило в одном месте, а не в каждом методе.
