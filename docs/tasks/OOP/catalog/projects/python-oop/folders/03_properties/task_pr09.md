# Задача PR09: Температура в двух шкалах

## Условие

### Как это работает

Класс может держать одно **основное** значение с проверкой, а остальное вычислять. Здесь основное — градусы Цельсия: у них есть сеттер, который не пускает температуру ниже абсолютного нуля. А Фаренгейт считается из Цельсия, поэтому он только для чтения.

```python
class Weight:
    def __init__(self, kg):
        self.kg = kg                       # через сеттер: проверка и при создании

    @property
    def kg(self):
        return self._kg

    @kg.setter
    def kg(self, value):
        if value < 0:
            raise ValueError("вес не бывает отрицательным")
        self._kg = value

    @property
    def grams(self):                       # только чтение, считается из _kg
        return self._kg * 1000
```

| Действие | Результат |
|---|---|
| `["new", 2]` | `"ok"` |
| `["get", "grams"]` | `2000` |
| `["set", "kg", -1]` | `["error", "ValueError", "вес не бывает отрицательным"]` |
| `["set", "grams", 5]` | `["error", "AttributeError", ""]` |

Текст `AttributeError` зависит от версии Python, поэтому рамка заменяет его пустой строкой.

### Задание

Напиши класс `Temperature`:

- `__init__(celsius)` записывает температуру **через свойство** `celsius`;
- свойство `celsius` читается и записывается; если значение меньше `-273.15`, сеттер бросает `ValueError("ниже абсолютного нуля")`, а температура не меняется;
- свойство `fahrenheit` только для чтения: `celsius * 9 / 5 + 32`.

Значение хранится в `_celsius`.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Temperature`; рамку внизу файла не трогай.
- Текст ошибки должен совпасть с условием слово в слово.
- Нужны свойства `celsius` (с сеттером) и `fahrenheit`.

## Пример

| Действие | Результат |
|---|---|
| `["new", 100]` | `"ok"` |
| `["get", "fahrenheit"]` | `212.0` |
| `["set", "celsius", -300]` | `["error", "ValueError", "ниже абсолютного нуля"]` |
| `["get", "celsius"]` | `100` |
| `["set", "fahrenheit", 50]` | `["error", "AttributeError", ""]` |

## Учебные цели

- Написать свойство с сеттером и проверкой диапазона.
- Сделать вычисляемое свойство только для чтения.
- Пройти через сеттер уже в `__init__`.

## Проверка понимания

Почему `Temperature(-300)` бросает ошибку при создании? Что произойдёт, если записать в `__init__` прямо `self._celsius = celsius`?
