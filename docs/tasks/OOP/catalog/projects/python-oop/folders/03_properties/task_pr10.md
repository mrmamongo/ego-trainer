# Задача PR10: Цена товара со скидкой

## Условие

### Как это работает

Каждое поле со своим правилом получает свою пару «свойство + сеттер», а правило записывается ровно один раз. Итоговое значение, которое выводится из других, остаётся свойством без сеттера:

```python
class Ticket:
    def __init__(self, price, seats=1):
        self.price = price
        self.seats = seats

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value <= 0:
            raise ValueError("цена должна быть больше нуля")
        self._price = value

    @property
    def seats(self):
        return self._seats

    @seats.setter
    def seats(self, value):
        if value < 1:
            raise ValueError("нужно хотя бы одно место")
        self._seats = value

    @property
    def total(self):                         # только чтение
        return self._price * self._seats
```

| Действие | Результат |
|---|---|
| `["new", 50, 3]` | `"ok"` |
| `["get", "total"]` | `150` |
| `["set", "seats", 0]` | `["error", "ValueError", "нужно хотя бы одно место"]` |
| `["get", "total"]` | `150`: ошибка ничего не изменила |

Внутри `__init__` значения присваивают в том порядке, в каком перечислены параметры, поэтому при двух ошибках сработает первая.

### Задание

Напиши класс `Product`:

- `__init__(name, price, discount=0)`: `name` хранится как обычный атрибут, а `price` и `discount` записываются **через свойства** (в этом порядке);
- свойство `price` (чтение и запись): цена должна быть больше нуля, иначе `ValueError("цена должна быть больше нуля")`;
- свойство `discount` (чтение и запись): скидка в процентах от `0` до `100` включительно, иначе `ValueError("скидка от 0 до 100")`;
- свойство `final_price` только для чтения: `price * (100 - discount) // 100`.

При ошибке значение не меняется.

## Аргументы

- `actions` — список действий сценария. Его подаёт проверка, ты его не пишешь. Как читать сценарий, объяснено в карточке «Как читать сценарий».

## Возвращает

Список результатов: по одному на каждое действие сценария, в том же порядке. Функция-рамка в конце файла уже готова.

## Правила

- Пиши только класс `Product`; рамку внизу файла не трогай.
- Тексты ошибок должны совпасть с условием слово в слово.
- Итоговую цену не храни в поле: она считается из цены и скидки.

## Пример

| Действие | Результат |
|---|---|
| `["new", "Чай", 200, 25]` | `"ok"` |
| `["get", "final_price"]` | `150` |
| `["set", "discount", 150]` | `["error", "ValueError", "скидка от 0 до 100"]` |
| `["get", "discount"]` | `25` |
| `["set", "final_price", 1]` | `["error", "AttributeError", ""]` |

## Учебные цели

- Написать два свойства с разными правилами в одном классе.
- Пересчитывать итоговую цену при каждом чтении.
- Поймать ошибку при создании объекта: правило одно и работает и в `__init__`.
