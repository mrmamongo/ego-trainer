# Задача MG08: Допиши красивую строку игрока

## Условие

### Как это работает

`__str__` отвечает за то, как объект выглядит для человека: `print(obj)`, `str(obj)` и f-строка `f"{obj}"` зовут именно его. Метод должен вернуть строку:

```python
class Coin:
    def __init__(self, value):
        self.value = value

    def __str__(self):
        return f"{self.value} монет"

print(Coin(5))            # 5 монет
```

| Выражение | Результат |
|---|---|
| `str(Coin(5))` | `"5 монет"` |
| `f"{Coin(5)}"` | `"5 монет"` |

`__repr__` остаётся для разработчика и списков, это отдельный метод.

### Задание

В классе `Player` уже есть `__repr__`. Допиши в `__str__` одну строку: он должен вернуть строку вида `Аня: 120` (имя, двоеточие, пробел, очки). Замени `None` в строке с `return`.

## Аргументы

- `rows` — список пар `[имя, очки]` (список может быть пустым).

## Возвращает

Список троек строк `[str(игрок), repr(игрок), f"{игрок}"]` для каждой пары; для пустого списка `[]`.

## Правила

- Замени `None` в методе `__str__` одним выражением, остальной код не меняй.
- Метод должен **вернуть** строку, а не напечатать её.

## Пример

```python
task_mg08_lines([["Аня", 120]])   # -> [["Аня: 120", "Player('Аня', 120)", "Аня: 120"]]
task_mg08_lines([])               # -> []
```

## Учебные цели

- Писать `__str__` с f-строкой и `return`.
- Видеть, что `str` и f-строка используют `__str__`, а `repr` остаётся прежним.
