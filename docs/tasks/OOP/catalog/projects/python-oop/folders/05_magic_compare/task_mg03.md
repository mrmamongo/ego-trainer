# Задача MG03: Версии 1.9 и 1.10

## Условие

### Как это работает

Метод `__lt__` отвечает на вопрос «должен ли `self` стоять раньше `other`?». Сравнение кортежей идёт по первому элементу, а при равенстве по второму.

```python
class Task:                                                      # 1
    def __init__(self, prio, title):                             # 2
        self.prio = prio                                         # 3
        self.title = title                                       # 4
    def __lt__(self, other):                                     # 5
        return (self.prio, self.title) < (other.prio, other.title)   # 6
a = Task(2, "б")                                                 # 7
b = Task(2, "а")                                                 # 8
c = Task(1, "я")                                                 # 9
```

| Выражение | Результат | Почему |
|---|---|---|
| `c < a` | `True` | `1 < 2` |
| `b < a` | `True` | приоритеты равны, `"а" < "б"` |
| `a < b` | `False` | наоборот |
| `a > b` | `True` | Python превращает это в `b < a` |
| `sorted([a, b, c])` | `[c, b, a]` | сортировка использует `<` |

Числа в тексте `"1.9"` и `"1.10"` как строки сравниваются по символам, это совсем другой порядок.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — понять, как один метод `__lt__` управляет и `<`, и `sorted`. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_mg03_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Читать `__lt__` с кортежем как «сначала главное поле, потом второе».
- Видеть, что `a > b` работает через `b < a`, если написан только `__lt__`.
- Отличать сравнение чисел (1.9 меньше 1.10) от сравнения строк.

## Проверка понимания

Почему `"1.9" < "1.10"` ложно, а `Version(1, 9) < Version(1, 10)` истинно? Что вернёт `sorted([b, a, c])[0]`?
