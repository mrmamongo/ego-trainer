# Задача MG16: Забеги: dataclass с порядком

## Условие

### Как это работает

`@dataclass(order=True)` добавляет сравнения `<`, `>` и сортировку. Записи сравниваются по **кортежу полей в порядке их объявления**: сначала первое поле, при равенстве второе. Поэтому главное поле пишут первым.

`field(compare=False)` исключает поле из сравнений: данные хранятся, но на `==` и порядок не влияют.

```python
from dataclasses import dataclass, field

@dataclass(order=True)
class Item:
    price: int
    name: str
    comment: str = field(default="", compare=False)
```

| Выражение | Результат | Почему |
|---|---|---|
| `Item(5, "а") < Item(7, "а")` | `True` | первое поле решило |
| `Item(5, "а") < Item(5, "б")` | `True` | цены равны, имя решило |
| `Item(5, "а", "x") == Item(5, "а", "y")` | `True` | `comment` не сравнивается |

Поле с `field(...)` и значением по умолчанию ставят после полей без умолчания.

### Задание

Напиши запись `Run` — результат забега. Это dataclass с тремя полями **в таком порядке**: `seconds` (целое, время), `name` (строка, имя), `note` (строка, пометка, по умолчанию пустая). Запись нужно уметь сортировать: быстрее забег идёт раньше, при равном времени раньше имя по алфавиту. Пометка не должна влиять ни на порядок, ни на равенство записей.

## Аргументы

- `rows` — список троек `[секунды, имя, пометка]` (список может быть пустым).

## Возвращает

Словарь: `"names"` — имена в порядке `sorted(runs)`, `"first_two_equal"` — `True`, если первые две записи равны (`==`); для списка короче двух записей `False`.

## Правила

- Пиши только класс `Run` со своим декоратором; рамку внизу файла не трогай.
- Запись должна быть помечена `@dataclass`.
- Порядок и равенство получи средствами dataclass, а не вручную.

## Пример

```python
task_mg16_results([[60, "Аня", ""], [55, "Вика", ""], [60, "Боря", "рекорд"]])
# -> {"names": ["Вика", "Аня", "Боря"], "first_two_equal": False}
task_mg16_results([[60, "Аня", "первая"], [60, "Аня", "вторая"]])
# -> {"names": ["Аня", "Аня"], "first_two_equal": True}
```

## Учебные цели

- Включить сравнения у dataclass через `order=True`.
- Выбрать порядок полей под нужную сортировку.
- Исключить служебное поле из сравнения через `field(compare=False)`.

## Проверка понимания
