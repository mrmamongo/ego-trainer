# Задача MG04: Карты в множестве

## Условие

### Как это работает

Множество и ключи словаря сначала смотрят на **хеш** объекта (его даёт `__hash__`), а потом, если хеши совпали, сверяют объекты через `__eq__`. Поэтому два объекта, равных по смыслу и с одинаковым хешем, считаются одним элементом.

```python
class Tag:                                       # 1
    def __init__(self, name):                    # 2
        self.name = name                         # 3
    def __eq__(self, other):                     # 4
        return self.name == other.name           # 5
    def __hash__(self):                          # 6
        return hash(self.name)                   # 7
tags = {Tag("a"), Tag("a"), Tag("b")}            # 8
n = len(tags)                                    # 9
```

| После строки | Значение | Почему |
|---|---|---|
| 8 | в `tags` два элемента | две метки `"a"` равны по `__eq__` и хешу, слились в одну |
| 9 | `n` равно `2` | `Tag("a")` и `Tag("b")` |

У класса **без** `__eq__` и `__hash__` равенство такое же, как `is`, поэтому два `Token()` в множестве остаются двумя.

## Учебные цели

- Понимать, что равные объекты (одинаковые `__eq__` и `__hash__`) в множестве сливаются.
- Видеть, что у класса без `__eq__` каждый новый объект считается отдельным.
- Находить значение в словаре по ключу, равному по смыслу, но созданному заново.
