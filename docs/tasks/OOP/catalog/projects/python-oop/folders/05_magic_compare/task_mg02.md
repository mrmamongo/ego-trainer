# Задача MG02: Равны ли карты

## Условие

### Как это работает

Метод `__eq__` решает, что значит `==` для объектов класса. `is` его не использует: он всегда спрашивает «один ли это объект?».

```python
class Point:                                         # 1
    def __init__(self, x):                           # 2
        self.x = x                                   # 3
    def __eq__(self, other):                         # 4
        if not isinstance(other, Point):             # 5
            return NotImplemented                    # 6
        return self.x == other.x                     # 7
p = Point(1)                                         # 8
q = Point(1)                                         # 9
```

| Выражение | Результат | Почему |
|---|---|---|
| `p == q` | `True` | `__eq__` сравнил поле `x` |
| `p is q` | `False` | два разных объекта |
| `p == 1` | `False` | другой тип: `NotImplemented`, итог `False` |
| `p != Point(2)` | `True` | `!=` выводится из `__eq__` само |

`in` и `count` у списка тоже сравнивают элементы через `==`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — понять, когда объекты равны по смыслу, а когда это один и тот же объект. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_mg02_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать `==` (равны по смыслу) от `is` (один объект).
- Знать, что `__eq__` вернёт `NotImplemented` для объекта другого типа, и итог станет `False`.
- Понимать, что `!=`, `in` и `count` используют тот же `__eq__`.
