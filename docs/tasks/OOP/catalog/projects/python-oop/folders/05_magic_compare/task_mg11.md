# Задача MG11: Деньги в копейках: repr и str

## Условие

### Как это работает

Суммы в программах часто хранят целым числом копеек: так нет ошибок округления дробных чисел. Для разработчика сумму показывают как создание объекта (`__repr__`), а для человека как рубли и копейки (`__str__`).

Чтобы из целого числа получить «рубли.копейки», рубли берут целочисленным делением, а копейки остатком. Остаток записывают с двумя цифрами: формат `:02d` добавляет ведущий ноль.

```python
n = 1205
f"{n // 100}.{n % 100:02d}"      # "12.05"
```

| `n` | `n // 100` | `n % 100` | Строка |
|---|---|---|---|
| `1205` | `12` | `5` | `"12.05"` |
| `1250` | `12` | `50` | `"12.50"` |
| `7` | `0` | `7` | `"0.07"` |

Сценарий вызывает методы прямо по имени: действие `["__str__"]` значит `obj.__str__()`.

### Задание

Напиши класс `Money` — сумма в копейках:

- `__init__(kopecks)` запоминает `kopecks` в атрибуте с тем же именем;
- `__repr__()` возвращает строку `Money(1250)`, то есть имя класса и число копеек в скобках;
- `__str__()` возвращает рубли и копейки через точку и слово `руб.`: `12.50 руб.`; копейки всегда двумя цифрами.

Оба метода **возвращают** строку, а не печатают.

## Правила

- Пиши только класс `Money`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__repr__` и `__str__`.
- Формат строк должен совпадать с условием символ в символ.

## Пример

| Действие | Результат |
|---|---|
| `["new", 1250]` | `"ok"` |
| `["__repr__"]` | `"Money(1250)"` |
| `["__str__"]` | `"12.50 руб."` |

## Учебные цели

- Написать `__repr__` и `__str__`, которые возвращают строки.
- Получить рубли и копейки из целого числа через `//`, `%` и формат `:02d`.
