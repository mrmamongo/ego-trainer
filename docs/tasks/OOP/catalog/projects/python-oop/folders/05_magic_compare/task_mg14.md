# Задача MG14: Таблица лидеров

## Условие

### Как это работает

В таблице лидеров «раньше» значит «больше очков». А при равных очках игроков упорядочивают по имени, иначе порядок получится случайным. Это правило «сначала главное, потом второе» пишут явной веткой:

```python
def __lt__(self, other):
    if self.score != other.score:
        return self.score > other.score      # больше очков идёт раньше
    return self.name < other.name            # при равенстве по алфавиту
```

| Игрок слева | Игрок справа | `левый < правый` | Почему |
|---|---|---|---|
| Аня, 100 | Боря, 150 | `False` | у Бори больше очков, он раньше |
| Вика, 100 | Аня, 100 | `False` | очки равны, `"Вика" < "Аня"` ложно |
| Аня, 100 | Вика, 100 | `True` | очки равны, `"Аня" < "Вика"` истинно |

Минус перед очками в кортеже здесь не нужен: ветка проще и понятнее.

### Задание

Напиши класс `Player` — игрок в таблице лидеров:

- `__init__(name, score)` запоминает `name` и `score`;
- `__lt__(other)` возвращает `True`, если этот игрок должен стоять в таблице **раньше**: у кого больше очков, тот раньше; при равных очках раньше тот, чьё имя идёт раньше по алфавиту.

Рамка сортирует игроков через `sorted` и возвращает имена.

## Аргументы

- `rows` — список пар `[имя, очки]`: имя строка, очки целое (список может быть пустым, имена могут повторяться).

## Возвращает

Список имён игроков в порядке таблицы: очки по убыванию, при равенстве имя по возрастанию; для пустого списка `[]`.

## Правила

- Пиши только класс `Player`; рамку внизу файла не трогай.
- Нужны методы `__init__` и `__lt__`; сортировать самому не нужно.
- Метод `__lt__` возвращает `True` или `False`.

## Пример

```python
task_mg14_board([["Аня", 100], ["Боря", 150], ["Вика", 100]])   # -> ["Боря", "Аня", "Вика"]
task_mg14_board([["Вика", 50], ["Аня", 50]])                    # -> ["Аня", "Вика"]
```

## Учебные цели

- Написать `__lt__` с главным и вторым критерием.
- Развернуть порядок для очков (больше значит раньше), не трогая порядок имён.

## Проверка понимания

Что вернёт `Player("Аня", 100) < Player("Аня", 100)`? Что изменится, если во втором `return` написать `>`?
