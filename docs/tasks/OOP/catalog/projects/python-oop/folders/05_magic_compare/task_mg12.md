# Задача MG12: Равны ли суммы

## Условие

### Как это работает

Хороший `__eq__` состоит из двух шагов: сначала проверить тип, потом сравнить поля. Для чужого типа возвращают не `False`, а `NotImplemented`: тогда Python даст высказаться второй стороне, и класс не мешает чужим сравнениям.

```python
class Point:
    def __init__(self, x):
        self.x = x

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return self.x == other.x
```

| Выражение | Результат | Почему |
|---|---|---|
| `Point(1) == Point(1)` | `True` | типы те же, поля равны |
| `Point(1) != Point(2)` | `True` | `!=` выводится из `__eq__` |
| `Point(1) == 1` | `False` | `NotImplemented`, у числа тоже нет ответа |
| `Point(1) == X`, где `X.__eq__` всегда `True` | `True` | Python спросил `X` и получил ответ |

### Задание

Напиши класс `Money` — сумма в копейках:

- `__init__(kopecks)` запоминает `kopecks`;
- `__eq__(other)`: суммы равны, если равны их копейки; если `other` не `Money`, верни `NotImplemented`.

Рамка проверяет равенство и неравенство двух сумм, сравнение суммы с обычным числом (оно должно быть неравно) и сравнение с готовым объектом `GivenAnything`, который считает себя равным чему угодно: если ты вернул `NotImplemented`, он ответит `True`.

## Аргументы

- `pairs` — список пар целых чисел `[копейки_слева, копейки_справа]` (список может быть пустым).

## Возвращает

Для каждой пары список из четырёх значений `[a == b, a != b, a == число, a == GivenAnything()]`, где `a` и `b` — суммы из пары, `число` — копейки первой суммы.

## Правила

- Пиши только класс `Money`; рамку внизу файла не трогай.
- Нужны методы `__init__` и `__eq__`.
- Для объекта другого типа возвращай `NotImplemented`, а не `False`.

## Пример

```python
task_mg12_compare([[500, 500]])   # -> [[True, False, False, True]]
task_mg12_compare([[500, 700]])   # -> [[False, True, False, True]]
```

## Учебные цели

- Написать `__eq__` с проверкой типа и сравнением полей.
- Возвращать `NotImplemented` для чужих типов и понимать, зачем.

## Проверка понимания

Что даст `Money(500) == 500` и почему не ошибка `AttributeError`? Что даст сравнение с `GivenAnything()`, если вместо `NotImplemented` вернуть `False`?
