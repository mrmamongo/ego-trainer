# Задача MG01: Как объекты печатаются

## Условие

### Как это работает

У класса могут быть два метода, которые отвечают за то, как объект превращается в текст:

```python
class Tag:                                   # 1
    def __init__(self, name):                # 2
        self.name = name                     # 3
    def __repr__(self):                      # 4
        return f"Tag({self.name})"           # 5
    def __str__(self):                       # 6
        return "#" + self.name               # 7
t = Tag("python")                            # 8
a = str(t)                                   # 9
b = repr(t)                                  # 10
c = str([t])                                 # 11
```

| После строки | Значение | Кто сработал |
|---|---|---|
| 9 | `a` равно `"#python"` | `str` зовёт `__str__` |
| 10 | `b` равно `"Tag(python)"` | `repr` зовёт `__repr__` |
| 11 | `c` равно `"[Tag(python)]"` | элементы списка показываются через `__repr__` |

Если `__str__` у класса нет, `str(obj)` берёт `__repr__`.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — научиться видеть, какой из двух методов вызывается в каждой строке, без компьютера. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_mg01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Отличать `__repr__` (для разработчика, списки) от `__str__` (для человека, `print`, f-строки).
- Помнить, что без `__str__` Python использует `__repr__`.
- Видеть, что элементы списка показываются через `__repr__`.
