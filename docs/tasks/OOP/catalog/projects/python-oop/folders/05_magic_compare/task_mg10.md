# Задача MG10: Собери удаление дублей в чате

## Условие

### Как это работает

Замороженная запись `@dataclass(frozen=True)` умеет `__eq__` и `__hash__` по полям, поэтому её можно класть в множество. Так удобно отбрасывать повторы и при этом сохранять порядок: заводят множество уже виденных элементов и список-результат.

```python
seen = set()
result = []
for item in items:
    if item not in seen:
        seen.add(item)
        result.append(item)
```

**Паспорт роли «уже встречали»** (имя `seen`):

| Где заводим | Начальное значение | Как меняем в теле | Когда используем |
|---|---|---|---|
| до цикла | `set()` | `seen.add(x)` после проверки | `x not in seen` на каждом шаге |

**Отступы** показывают вложенность: `seen.add` и `append` стоят под `if`, а `if` — под `for`.

### Задание

В файле задачи в комментарии записаны строки функции `task_mg10_dedupe(rows)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция должна убрать повторяющиеся сообщения (одинаковые автор и текст), оставив первое вхождение каждого, в исходном порядке.

## Аргументы

- `rows` — список пар `[автор, текст]`, обе строки (список может быть пустым).

## Возвращает

Список пар `[автор, текст]` без повторов, в порядке первого появления; для пустого списка `[]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Класс `Message` выше не меняй.

## Пример

```python
task_mg10_dedupe([["Аня", "привет"], ["Боря", "привет"], ["Аня", "привет"]])   # -> [["Аня", "привет"], ["Боря", "привет"]]
task_mg10_dedupe([])                                                            # -> []
```

## Учебные цели

- Собрать шаблон «уже встречали»: `set()` и список-результат до цикла, проверка `not in`, `add` и `append` под `if`.
- Понять, зачем записи, которые кладут в множество, делают `frozen=True`.
