# Задача MG15: Чат без повторов

## Условие

### Как это работает

Чтобы объект можно было положить в множество или сделать ключом словаря, нужны два согласованных метода: `__eq__` (когда два объекта считаются одним и тем же) и `__hash__` (число, по которому объект ищут). Равные объекты обязаны иметь равный хеш, поэтому хеш берут от кортежа тех же полей.

```python
class Tag:
    def __init__(self, name):
        self.name = name

    def __eq__(self, other):
        if not isinstance(other, Tag):
            return NotImplemented
        return self.name == other.name

    def __hash__(self):
        return hash(self.name)
```

| Выражение | Результат |
|---|---|
| `len({Tag("a"), Tag("a")})` | `1` |
| `list(dict.fromkeys([Tag("a"), Tag("b"), Tag("a")]))` | два тега, `"a"` и `"b"`, в порядке появления |

### Задание

Напиши класс `Message` — сообщение в чате:

- `__init__(author, text)` запоминает `author` и `text`;
- `__eq__(other)`: сообщения равны, если совпали автор **и** текст; для объекта другого типа верни `NotImplemented`;
- `__hash__()` возвращает хеш, согласованный с `__eq__`.

Рамка собирает из сообщений множество и словарь `dict.fromkeys`, чтобы посчитать разные сообщения и вернуть их в порядке первого появления.

## Аргументы

- `rows` — список пар `[автор, текст]`, обе строки (список может быть пустым).

## Возвращает

Словарь: `"count"` — сколько разных сообщений, `"first_seen"` — список пар `[автор, текст]` без повторов в порядке первого появления.

## Правила

- Пиши только класс `Message`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__eq__` и `__hash__`.
- Хеш бери от тех же полей, по которым сравниваешь.

## Пример

```python
task_mg15_dedupe([["Аня", "привет"], ["Боря", "привет"], ["Аня", "привет"]])
# -> {"count": 2, "first_seen": [["Аня", "привет"], ["Боря", "привет"]]}
```

## Учебные цели

- Написать согласованную пару `__eq__` и `__hash__` по кортежу полей.
- Использовать объект как элемент множества и ключ словаря.
