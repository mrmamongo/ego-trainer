# `__repr__` и `__str__`: как объект выглядит в выводе

Обычный объект печатается невнятно: `<student.Coin object at 0x7f3a...>`. Это имя класса и адрес в памяти, из него не видно, что внутри. Два специальных метода, **магических**, объясняют Python, как показывать объект. Их имена начинаются и заканчиваются двумя подчёркиваниями, и вызываешь ты их не сам: Python вызывает их в нужный момент.

| Метод | Для кого | Что принято возвращать |
|---|---|---|
| `__repr__` | для разработчика: отладка, списки, логи | однозначную запись, похожую на создание объекта: `Coin(5)` |
| `__str__` | для человека: `print`, `f"{obj}"`, `str(obj)` | красивую строку: `5 монет` |

Оба метода обязаны **вернуть строку** через `return`. Не напечатать, а вернуть.

```python
class Coin:
    def __init__(self, value):
        self.value = value

    def __repr__(self):
        return f"Coin({self.value})"

    def __str__(self):
        return f"{self.value} монет"

c = Coin(5)              # 1
a = repr(c)              # 2
b = str(c)               # 3
d = f"{c}"               # 4
e = str([c])             # 5
```

| После строки | Значение | Кто сработал |
|---|---|---|
| 2 | `a` равно `"Coin(5)"` | `repr` зовёт `__repr__` |
| 3 | `b` равно `"5 монет"` | `str` зовёт `__str__` |
| 4 | `d` равно `"5 монет"` | f-строка и `print` зовут `__str__` |
| 5 | `e` равно `"[Coin(5)]"` | внутри списка объекты показываются через `__repr__` |

Запомни правило: **`print(obj)` берёт `__str__`, а список, словарь и отладчик берут `__repr__`.** Если `__str__` не написан, `str(obj)` берёт `__repr__`, поэтому один `__repr__` уже спасает вывод. Обратного нет: если не написан `__repr__`, а есть только `__str__`, списки по-прежнему печатают `<...object at 0x...>`.

## Что пишет dataclass

`@dataclass` создаёт `__repr__` за тебя: `Item(name='Меч', qty=3)`. Метода `__str__` он не пишет, поэтому `print(item)` показывает ту же строку. Если у dataclass нужен красивый вывод для человека, `__str__` дописывают руками, `__repr__` остаётся автоматическим.

## Частые ошибки

Напечатать вместо `return`:

```python
def __repr__(self):
    print(f"Coin({self.value})")        # неверно: вернётся None, repr() упадёт с TypeError
```

```python
def __repr__(self):
    return f"Coin({self.value})"        # верно
```

Вернуть не строку: `return self.value` в `__str__` даёт `TypeError: __str__ returned non-string`. Число надо превратить в строку: `str(self.value)` или f-строка.

## Проверь себя

```python
class Gem:
    def __init__(self, name):
        self.name = name

    def __repr__(self):
        return f"Gem('{self.name}')"

g = Gem("рубин")
```

1. Что вернёт `str(g)`?
2. Что вернёт `str([g])`?

<details><summary>Ответ</summary>

1. `"Gem('рубин')"`: `__str__` нет, поэтому `str` берёт `__repr__`.
2. `"[Gem('рубин')]"`: внутри списка всегда `__repr__`.

</details>
