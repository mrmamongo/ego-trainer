# Задача MG17: Полка: порядок при равном годе

## Условие

### Как это работает

Сейчас книги сортируются только по году издания:

```python
class Book:                                       # 1
    def __init__(self, title, year):              # 2
        self.title = title                        # 3
        self.year = year                          # 4
    def __lt__(self, other):                      # 5
        return self.year < other.year             # 6
```

**Где реализовано старое правило:** в строке 6. Раньше книга идёт раньше другой, если вышла в более раннем году.

**Что меняется:** у книг одного года порядок сейчас случайный, он зависит от того, как книги лежали в списке. Нужен второй критерий: при равных годах по названию. Для этого сравнивают кортежи:

```python
return (self.year, self.title) < (other.year, other.title)
```

**Что нельзя трогать:** главный критерий. Книги разных лет по-прежнему идут по году, от старых к новым.

### Задание

Раньше книги на полке упорядочивались только по году издания. Теперь, если год один и тот же, раньше идёт книга, название которой стоит раньше по алфавиту. Измени метод `__lt__` готового класса.

## Аргументы

- `rows` — список пар `[название, год]`: строка и целое (список может быть пустым).

## Возвращает

Список названий в порядке `sorted(books)`: год по возрастанию, при равных годах название по алфавиту; для пустого списка `[]`.

## Правила

- Не переписывай класс с нуля: измени метод `__lt__`.
- Книги разных лет упорядочиваются так же, как раньше.
- Рамку внизу файла не трогай.

## Пример

```python
task_mg17_shelf([["Дюна", 1965], ["Солярис", 1961]])   # -> ["Солярис", "Дюна"]
task_mg17_shelf([["Б", 2000], ["А", 2000]])            # -> ["А", "Б"]
```

## Учебные цели

- Добавить второй критерий сортировки в готовый `__lt__` через кортеж.
- Сохранить главный критерий и проверить, что старое поведение не сломано.
