# Задача MG05: Карта, которая печатается вместо возврата

## Условие

### Как это работает

`__repr__` должен **вернуть** строку, а не напечатать её. Python вызывает его сам, когда нужно показать объект: в `repr(card)` и когда карта лежит внутри списка. Если метод только печатает, он вернёт `None`:

```python
class Coin:
    def __init__(self, value):
        self.value = value

    def __repr__(self):
        print(f"Coin({self.value})")       # печатает и возвращает None

repr(Coin(5))                               # TypeError: __repr__ returned non-string (type NoneType)
```

| Что вызвали | Что произошло |
|---|---|
| `repr(Coin(5))` | метод напечатал строку в консоль, вернул `None`, `repr` упал с `TypeError` |
| `str([Coin(5)])` | список зовёт `__repr__` у каждого элемента, тоже `TypeError` |

Исправление: заменить `print(...)` на `return ...`.

### Задание

Класс `Card` должен показываться как `Card('Q', 'червы')`, но его `__repr__` печатает строку вместо того, чтобы вернуть. Найди ошибку и исправь. Рамка внизу файла вызывает `repr` у каждой карты и `str` у списка карт; если `__repr__` сломан, она запишет в результат слово `TypeError`.

## Аргументы

- `rows` — список пар `[ранг, масть]`, обе строки (список может быть пустым).

## Возвращает

Словарь с двумя ключами: `"one"` — список строк `repr` для каждой карты, `"in_list"` — строка, которую даёт `str` от всего списка карт.

## Правила

- Исправь только метод `__repr__`; остальной код класса и рамку не трогай.
- Метод должен **вернуть** строку через `return`, а не печатать её.
- Формат строки: `Card('Q', 'червы')`, то есть ранг и масть в одинарных кавычках через запятую с пробелом.

## Пример

```python
task_mg05_show([["Q", "червы"], ["10", "пики"]])
# -> {"one": ["Card('Q', 'червы')", "Card('10', 'пики')"],
#     "in_list": "[Card('Q', 'червы'), Card('10', 'пики')]"}
task_mg05_show([])   # -> {"one": [], "in_list": "[]"}
```

## Учебные цели

- Узнавать ошибку «`__repr__` напечатал, а не вернул».
- Понимать, что список показывает элементы через `__repr__`.
