# Задача MG18: Счётчик карт: карта как ключ

## Условие

### Как это работает

Сейчас в классе есть `__eq__`, и карты сравниваются по рангу и масти:

```python
class Card:                                                          # 1
    def __init__(self, rank, suit):                                  # 2
        self.rank = rank                                             # 3
        self.suit = suit                                             # 4
    def __eq__(self, other):                                         # 5
        if not isinstance(other, Card):                              # 6
            return NotImplemented                                    # 7
        return self.rank == other.rank and self.suit == other.suit   # 8
```

**Где реализовано старое правило:** в строках 5–8. Равенство работает.

**Что меняется:** карты нужны ещё и как ключи словаря-счётчика. Но класс с `__eq__` без `__hash__` нехешируем: `counts[card]` падает с `TypeError: unhashable type: 'Card'`. Нужно дописать `__hash__` по тем же полям, что и в `__eq__`:

```python
def __hash__(self):
    return hash((self.rank, self.suit))
```

**Что нельзя трогать:** `__eq__`. Он остаётся как есть, а хеш обязан с ним согласоваться.

### Задание

Раньше карты можно было только сравнивать через `==`. Теперь рамка считает, сколько раз встретилась каждая карта, складывая счётчики в словарь, где ключ — сама карта. Дополни класс так, чтобы равные карты были одним ключом.

## Аргументы

- `rows` — список пар `[ранг, масть]`, обе строки (список может быть пустым).

## Возвращает

Список троек `[ранг, масть, сколько раз встретилась]` в порядке первого появления карты; для пустого списка `[]`.

## Правила

- Не переписывай класс с нуля: добавь недостающий метод.
- Метод `__eq__` оставь как есть.
- Хеш бери от тех же полей, что и в `__eq__`.
- Рамку внизу файла не трогай.

## Пример

```python
task_mg18_tally([["Q", "червы"], ["K", "пики"], ["Q", "червы"]])   # -> [["Q", "червы", 2], ["K", "пики", 1]]
task_mg18_tally([])                                                # -> []
```

## Учебные цели

- Сделать класс с `__eq__` хешируемым, дописав согласованный `__hash__`.
- Понимать, что равные карты после правки становятся одним ключом словаря.

## Проверка понимания

Почему пустой список проходит и до правки, а непустой нет? Что случится, если в `__hash__` взять только `rank`?
