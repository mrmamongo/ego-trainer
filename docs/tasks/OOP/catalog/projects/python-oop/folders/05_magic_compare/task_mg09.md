# Задача MG09: Допиши равенство карт

## Условие

### Как это работает

`__eq__` решает, что значит `==` для объектов. Обычно он состоит из двух частей: проверка типа (для чужого типа возвращают `NotImplemented`) и сравнение полей:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return self.x == other.x and self.y == other.y
```

| Выражение | Результат |
|---|---|
| `Point(1, 2) == Point(1, 2)` | `True` |
| `Point(1, 2) == Point(1, 3)` | `False` |
| `Point(1, 2) == 5` | `False` (`NotImplemented`) |

Обе части условия через `and`: равенство только тогда, когда совпали **все** поля.

### Задание

В классе `Card` метод `__eq__` уже проверяет тип, но последняя строка не дописана. Замени `None` условием: карты равны, когда совпали и ранг, и масть.

## Аргументы

- `pairs` — список пар карт `[[ранг, масть], [ранг, масть]]` (список может быть пустым).

## Возвращает

Для каждой пары список из трёх значений `[a == b, a != b, a == ранг_первой]`; последнее сравнивает карту со строкой и всегда `False`.

## Правила

- Замени `None` одним выражением; остальной код и рамку не меняй.
- Строку с `NotImplemented` не удаляй.

## Пример

```python
task_mg09_compare([[["Q", "червы"], ["Q", "червы"]]])   # -> [[True, False, False]]
task_mg09_compare([[["Q", "червы"], ["Q", "пики"]]])    # -> [[False, True, False]]
```

## Учебные цели

- Дописать сравнение полей в `__eq__` через `and`.
- Видеть, что `!=` получается из `__eq__` сам.
