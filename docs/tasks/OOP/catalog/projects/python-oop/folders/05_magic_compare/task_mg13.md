# Задача MG13: Версии 1.9 и 1.10

## Условие

### Как это работает

Строки сравниваются по символам, поэтому `"1.9" < "1.10"` ложно: символ `"9"` больше символа `"1"`. Чтобы версии шли по-человечески, текст разбирают на числа и сравнивают списки чисел:

```python
text = "1.10"
parts = [int(part) for part in text.split(".")]      # [1, 10]
[1, 9] < [1, 10]                                     # True
```

| Версия | `parts` |
|---|---|
| `"1.9"` | `[1, 9]` |
| `"1.10"` | `[1, 10]` |
| `"2.0.1"` | `[2, 0, 1]` |

Списки, как и кортежи, сравниваются по первому элементу, при равенстве по второму и так далее. Достаточно написать `__lt__`: `sorted` и `max` обойдутся им.

### Задание

Напиши класс `Version` — номер версии программы:

- `__init__(text)` запоминает `text` (строка вида `"1.10"` или `"2.0.1"`) в атрибуте `text` и числа из неё в атрибуте `parts` (список целых);
- `__lt__(other)` возвращает `True`, если эта версия старше (меньше) другой, сравнивая числа версии по порядку.

Рамка сортирует версии и ищет самую новую через `max`.

## Аргументы

- `texts` — список строк-версий: числа через точку, все версии одной длины для сравнений (список может быть пустым).

## Возвращает

Словарь: `"sorted"` — список строк-версий от старой к новой, `"newest"` — строка самой новой версии или `None` для пустого списка.

## Правила

- Пиши только класс `Version`; рамку внизу файла не трогай.
- Нужны методы `__init__` и `__lt__`; в атрибуте `text` должна лежать исходная строка.
- Сравнивай числа, а не строки.

## Пример

```python
task_mg13_versions(["1.9", "1.10"])   # -> {"sorted": ["1.9", "1.10"], "newest": "1.10"}
task_mg13_versions([])                # -> {"sorted": [], "newest": None}
```

## Учебные цели

- Разбирать строку версии на числа и сравнивать списки чисел.
- Написать один `__lt__` и получить `sorted` и `max`.

## Проверка понимания

Почему достаточно `__lt__`, хотя `max` сравнивает через `>`? Что получится, если сравнивать `self.text < other.text`?
