# Задача MG06: Чат не складывается в множество

## Условие

### Как это работает

Как только в классе написан `__eq__`, Python отключает ему `__hash__`. Такой объект нельзя положить в множество или сделать ключом словаря:

```python
class Tag:
    def __init__(self, name):
        self.name = name

    def __eq__(self, other):
        return isinstance(other, Tag) and self.name == other.name

len({Tag("a"), Tag("a")})        # TypeError: unhashable type: 'Tag'
```

| Что есть в классе | Что с `set` |
|---|---|
| только `__eq__` | `TypeError: unhashable type` |
| `__eq__` и `__hash__` по тем же полям | равные объекты сливаются в один |

Исправление: дописать `__hash__`, который берёт хеш кортежа из тех же полей, что и `__eq__`.

### Задание

Класс `Message` умеет сравнивать сообщения по автору и тексту, но множество из сообщений не собирается: рамка получает `TypeError`. Исправь класс: два сообщения с одинаковыми автором и текстом должны считаться одним.

## Аргументы

- `rows` — список пар `[автор, текст]`, обе строки (список может быть пустым).

## Возвращает

Целое число: сколько разных сообщений в множестве, собранном из всех пар.

## Правила

- Добавь в класс `Message` недостающий метод; метод `__eq__` менять не нужно.
- Хеш бери от тех же полей, что и в `__eq__`.
- Рамку внизу файла не трогай.

## Пример

```python
task_mg06_unique([["Аня", "привет"], ["Боря", "привет"], ["Аня", "привет"]])   # -> 2
task_mg06_unique([])                                                            # -> 0
```

## Учебные цели

- Узнавать `TypeError: unhashable type` как следствие `__eq__` без `__hash__`.
- Писать `__hash__` из тех же полей, что и `__eq__`.
