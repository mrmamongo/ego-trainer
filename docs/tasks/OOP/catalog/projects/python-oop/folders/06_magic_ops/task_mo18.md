# Задача MO18: Вектор: число слева и справа

## Условие

### Как это работает

Сейчас вектор растягивается только числом справа:

```python
class Vector2:                                          # 1
    def __init__(self, x, y):                           # 2
        self.x = x                                      # 3
        self.y = y                                      # 4
    def __mul__(self, k):                               # 5
        if not isinstance(k, (int, float)):             # 6
            return NotImplemented                       # 7
        return Vector2(self.x * k, self.y * k)          # 8
```

**Где реализовано старое правило:** в строках 5–8. `v * 3` работает, а `v * "a"` даёт `TypeError`.

**Что меняется:** по-человечески пишут и `3 * v`. Тогда число стоит слева, `int.__mul__` не умеет, и Python зовёт у вектора зеркальный метод `__rmul__(3)`.

**Что нельзя трогать:** `__mul__` и ошибку для нечислового множителя.

### Задание

Раньше работало только `v * k`. Теперь должно работать и `k * v` с тем же результатом, а с нечисловым множителем (строкой) оба порядка по-прежнему дают `TypeError`. Допиши класс.

## Аргументы

- `x`, `y` — координаты вектора.
- `k` — множитель: число или строка.

## Возвращает

Список из двух элементов: результат `v * k` и результат `k * v`. Каждый элемент — `[x, y]` вектора или строка `"TypeError"`.

## Правила

- Не переписывай класс с нуля: добавь недостающий метод.
- Метод `__mul__` оставь как есть.
- Рамку внизу файла не трогай.

## Пример

```python
task_mo18_scale(1, 2, 3)     # -> [[3, 6], [3, 6]]
task_mo18_scale(1, 2, "a")   # -> ["TypeError", "TypeError"]
```

## Учебные цели

- Добавить `__rmul__`, чтобы число могло стоять слева.
- Сохранить `NotImplemented` для чужого типа.

## Проверка понимания

Почему `3 * v` без `__rmul__` падает, хотя `v * 3` работает? Что даст `__rmul__ = __mul__` внутри класса?
