# Задача MO05: Шаг героя портит старую позицию

## Условие

### Как это работает

Метод `__add__` обязан вернуть **новый** объект. Если он меняет `self` и возвращает его, то `позиция + шаг` испортит старую позицию:

```python
class Counter:
    def __init__(self, n):
        self.n = n

    def __add__(self, other):
        self.n += other.n
        return self            # возвращает тот же объект, который изменил

a = Counter(1)
b = a + Counter(2)             # b.n равно 3, но и a.n тоже стало 3, и b is a
```

| Что проверили | Результат |
|---|---|
| `b.n` | `3` |
| `a.n` | `3`, а должно остаться `1` |
| `b is a` | `True`, а должно быть `False` |

Исправление: создать и вернуть `Counter(self.n + other.n)`, а `self` не трогать.

### Задание

Класс `Vector2` складывает два вектора, но после сложения меняется левый вектор. Найди ошибку и исправь. Рамка внизу складывает старт и шаг и смотрит, что стало со всеми векторами.

## Аргументы

- `start` — список `[x, y]` (начальная позиция).
- `step` — список `[dx, dy]` (шаг).

## Возвращает

Словарь с ключами `"result"` (`[x, y]` суммы), `"start"` (`[x, y]` стартового вектора после сложения), `"step"` (`[dx, dy]` вектора шага после сложения) и `"same_object"` (`True`, если сумма и есть стартовый объект).

## Правила

- Исправь только метод `__add__`; рамку внизу файла не трогай.
- Метод не должен менять ни `self`, ни `other`.

## Пример

```python
task_mo05_move([1, 2], [3, 4])
# -> {"result": [4, 6], "start": [1, 2], "step": [3, 4], "same_object": False}
```

## Учебные цели

- Находить ошибку «сложение изменило левый операнд».
- Возвращать из `__add__` новый объект.

## Проверка понимания

Что вернёт рамка для исходного класса: чему равны `start` и `same_object`? Как эта ошибка проявилась бы в игре, где позиция героя хранится в двух местах?
