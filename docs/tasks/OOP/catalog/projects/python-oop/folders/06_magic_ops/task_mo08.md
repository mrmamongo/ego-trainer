# Задача MO08: Допиши растяжение вектора

## Условие

### Как это работает

Метод `__mul__(self, k)` вызывается для `v * k`, где `k` обычное число. Он возвращает **новый** вектор с умноженными координатами:

```python
class Size:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    def __mul__(self, k):
        return Size(self.w * k, self.h * k)

big = Size(2, 3) * 4              # Size(8, 12), исходный Size(2, 3) не менялся
```

| Выражение | Результат |
|---|---|
| `big.w` | `8` |
| `big.h` | `12` |

### Задание

В классе `Vector2` метод `__mul__` пока возвращает `None`. Замени `None` на выражение, которое создаёт и возвращает новый вектор с обеими координатами, умноженными на `k`.

## Аргументы

- `x`, `y` — координаты вектора.
- `k` — число, на которое умножаем.

## Возвращает

Словарь с ключами `"scaled"` (`[x, y]` результата) и `"original"` (`[x, y]` исходного вектора после умножения).

## Правила

- Замени `None` в методе `__mul__` одним выражением, остальной код не меняй.
- Исходный вектор менять нельзя.

## Пример

```python
task_mo08_scale(2, 3, 4)   # -> {"scaled": [8, 12], "original": [2, 3]}
```

## Учебные цели

- Написать `__mul__`, который возвращает новый объект.
- Умножать каждую координату на число справа.

## Проверка понимания

Что будет в `original`, если `__mul__` напишет `self.x *= k`? Чему равен `Vector2(1, 2) * 0`?
