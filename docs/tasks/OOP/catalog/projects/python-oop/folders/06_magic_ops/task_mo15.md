# Задача MO15: Инвентарь: ключи, in и len

## Условие

### Как это работает

У коллекции с ключами `__getitem__` получает не число, а ключ, например название предмета. Если ключа нет, словарь внутри сам бросает `KeyError`. А `in` и `len` живут в отдельных методах:

| Выражение | Метод | Что должен вернуть |
|---|---|---|
| `inv["меч"]` | `__getitem__("меч")` | количество, для неизвестного названия `KeyError` |
| `"меч" in inv` | `__contains__("меч")` | `True`, если количество больше нуля |
| `len(inv)` | `__len__()` | сколько разных названий хранится |

Обрати внимание: предмет с количеством `0` в словаре **есть** (`inv["зелье"]` даст `0`), но `in` по нашему правилу отвечает «нет».

### Задание

Напиши класс `Inventory`: `__init__(items)` запоминает словарь `{название: количество}`; `__getitem__(name)` возвращает количество (неизвестное название даёт `KeyError`); `__contains__(name)` возвращает `True`, если количество больше нуля; `__len__()` возвращает число названий в словаре, включая предметы с нулём.

## Аргументы

- `items` — словарь `{название: количество}` (может быть пустым).
- `names` — список названий для запросов.

## Возвращает

Словарь: `"kinds"` — `len(инвентарь)`; `"rows"` — по списку `[название, название in инвентарь, количество]` на каждое имя, где вместо количества стоит `"KeyError"`, если ключа нет.

## Правила

- Пиши только класс `Inventory`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__getitem__`, `__contains__` и `__len__`.
- Количество для известного названия возвращай как есть, даже `0`.

## Пример

```python
task_mo15_inventory({"меч": 1, "зелье": 0}, ["меч", "зелье", "лук"])
# -> {"kinds": 2, "rows": [["меч", True, 1], ["зелье", False, 0], ["лук", False, "KeyError"]]}
```

## Учебные цели

- Различать `__getitem__` по ключу, `__contains__` и `__len__`.
- Помнить, что неизвестный ключ даёт `KeyError`.

## Проверка понимания

Почему для предмета с количеством 0 `in` ложно, а `inv[name]` не падает? Что вернёт `len` для пустого словаря?
