# Задача MO14: Плейлист как коллекция

## Условие

### Как это работает

`len(p)` вызывает `__len__`, а `p[i]` вызывает `__getitem__`. Метод хранит список внутри и обращается к нему. Для индекса за границей принято бросать `IndexError`:

```python
def __getitem__(self, index):
    if not -len(self.tracks) <= index < len(self.tracks):
        raise IndexError("нет такого трека")
    return self.tracks[index]
```

| Выражение | Результат для `["rock", "jazz"]` |
|---|---|
| `len(p)` | `2` |
| `p[0]` | `"rock"` |
| `p[-1]` | `"jazz"` |
| `p[2]` | `IndexError` |

### Задание

Напиши класс `Playlist`: `__init__(tracks)` запоминает список названий, `__len__()` возвращает их количество, `__getitem__(index)` возвращает название по индексу (отрицательные индексы тоже работают), а за границей бросает `IndexError("нет такого трека")`.

## Аргументы

- `tracks` — список названий треков (может быть пустым).
- `indexes` — список индексов, которые нужно запросить.

## Возвращает

Словарь с ключами `"len"` (число треков) и `"items"` (по одному элементу на индекс: название или список `["IndexError", текст ошибки]`).

## Правила

- Пиши только класс `Playlist`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__len__` и `__getitem__`.
- Текст ошибки ровно `нет такого трека`.

## Пример

```python
task_mo14_playlist(["rock", "jazz"], [0, -1, 2])
# -> {"len": 2, "items": ["rock", "jazz", ["IndexError", "нет такого трека"]]}
```

## Учебные цели

- Написать `__len__` и `__getitem__` для своего класса.
- Знать, что граница индекса даёт `IndexError`, а отрицательный индекс считает с конца.

## Проверка понимания

Какие индексы допустимы для плейлиста из трёх треков? Что вернёт `len(Playlist([]))`?
