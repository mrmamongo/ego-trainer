# Задача MO09: Допиши __radd__ для sum

## Условие

### Как это работает

`sum` начинает с `0`, поэтому первый шаг это `0 + первый_объект`. Число слева не умеет складываться с объектом, и Python зовёт `__radd__` у правого операнда, передав ему этот `0`. Метод пропускает только `0` и возвращает сам объект:

```python
def __radd__(self, other):
    if other == 0:
        return self
    return NotImplemented
```

| Выражение | Что зовётся | Результат |
|---|---|---|
| `sum([a, b])` | `a.__radd__(0)`, затем `a + b` | сумма объектов |
| `3 + a` | `a.__radd__(3)` | `TypeError`, число не ноль |

### Задание

Класс `Score` уже умеет `__add__`, но в `__radd__` вместо нужного числа стоит `None`, поэтому `sum` падает. Впиши вместо `None` число, с которого начинается `sum`.

## Аргументы

- `points` — список очков за раунды (может быть пустым).

## Возвращает

Сумма очков через `sum` (число); для пустого списка `0`.

## Правила

- Замени `None` в условии метода `__radd__` одним числом, остальной код не меняй.

## Пример

```python
task_mo09_total([5, 7, 3])   # -> 15
task_mo09_total([])          # -> 0
```

## Учебные цели

- Понять, зачем нужен `__radd__` и какое число он получает от `sum`.
- Видеть, что объекты складываются через `sum`.

## Проверка понимания

Почему при пустом списке исходный код всё равно не падает? Что получится, если разрешить `__radd__` любое число?
