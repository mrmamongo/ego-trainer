# Задача MO16: Корзина: пустая или бесплатная

## Условие

### Как это работает

`if cart:` и `bool(cart)` сначала ищут `__bool__`. Если его нет, берётся `__len__` (ноль значит «ложь»). Свой `__bool__` нужен, когда «пусто» понимают иначе, чем длина ноль.

```python
def __bool__(self):
    return any(price > 0 for _, price in self.items)
```

| Корзина | `len` | Без `__bool__` | С `__bool__` выше |
|---|---|---|---|
| `[]` | `0` | ложь | ложь |
| `[["чай", 80]]` | `1` | правда | правда |
| `[["пакет", 0]]` | `1` | правда | ложь: платить не за что |

### Задание

Напиши класс `Cart`: `__init__(items)` запоминает список пар `[название, цена]`; `__len__()` возвращает число товаров; `__bool__()` возвращает `True`, только если есть хотя бы один товар с ценой больше нуля.

## Аргументы

- `items` — список пар `[название, цена]` (может быть пустым).

## Возвращает

Список из трёх элементов: `bool(корзина)`, `len(корзина)` и строка `"есть что оплатить"` или `"нечего оплачивать"` (её выбирает рамка через `if корзина`).

## Правила

- Пиши только класс `Cart`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__len__` и `__bool__`.
- Метод `__bool__` должен вернуть именно `True` или `False`.

## Пример

```python
task_mo16_cart([["чай", 80], ["пакет", 0]])   # -> [True, 2, "есть что оплатить"]
task_mo16_cart([["пакет", 0]])                 # -> [False, 1, "нечего оплачивать"]
```

## Учебные цели

- Написать `__bool__`, который отвечает на `if obj`.
- Видеть, что `__bool__` важнее `__len__`.

## Проверка понимания
