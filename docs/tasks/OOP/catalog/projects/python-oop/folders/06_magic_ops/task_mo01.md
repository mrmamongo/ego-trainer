# Задача MO01: Новый вектор, а не старый

## Условие

### Как это работает

Метод `__add__` вызывается, когда Python видит `a + b`, а `__mul__`, когда видит `a * k`. Оба должны **вернуть новый объект**, а старые не менять.

```python
class Vector2:                                       # 1
    def __init__(self, x, y):                        # 2
        self.x = x                                   # 3
        self.y = y                                   # 4
    def __add__(self, other):                        # 5
        return Vector2(self.x + other.x, self.y + other.y)   # 6
p = Vector2(1, 1)                                    # 7
q = Vector2(2, 3)                                    # 8
r = p + q                                            # 9
```

| После строки | Значение | Почему |
|---|---|---|
| 9 | `r.x` равно `3`, `r.y` равно `4` | `p + q` позвал `p.__add__(q)` |
| 9 | `p.x` всё ещё `1`, `r is p` равно `False` | метод создал новый вектор |

Это очки координат героя в игре: сдвиг `позиция + шаг` не должен портить прежнюю позицию.

### Задание

Открой файл задачи. В нём код для трассировки и строчки-ответы с `None`. Впиши вместо каждого `None` ответ. Названия переменных-ответов описаны в комментарии под кодом.

**Сначала реши в голове или на бумаге, код не запускай.** Цель — увидеть, что `+` и `*` создают новые объекты и не трогают старые. Если ответ неверный, проверка не подскажет правильный: найди ошибку сам, построив таблицу по строкам кода.

## Правила

- Меняй только строчки с `None`.
- Строки `def task_mo01_trace():` и `return ...` самой рамки не трогай: так проверка читает твои ответы.

## Учебные цели

- Увидеть, что `+` и `*` создают новые объекты и не трогают старые.
- Строить таблицу значений по строкам кода и не полагаться на догадку.

## Проверка понимания
