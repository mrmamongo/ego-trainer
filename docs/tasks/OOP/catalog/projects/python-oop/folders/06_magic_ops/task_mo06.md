# Задача MO06: Деньги плюс число дают None

## Условие

### Как это работает

Для чужого типа `__add__` должен вернуть `NotImplemented`. Тогда `Money(100) + 5` закончится понятной ошибкой `TypeError`. Если вернуть `None`, ошибки не будет, а в переменной окажется `None`:

```python
class Money:
    def __init__(self, kopecks):
        self.kopecks = kopecks

    def __add__(self, other):
        if not isinstance(other, Money):
            return None                    # ошибка молчит
        return Money(self.kopecks + other.kopecks)

total = Money(100) + 5                     # total равно None, никакой ошибки
```

Исправление: вместо `return None` написать `return NotImplemented`.

### Задание

Класс `Money` складывает деньги, но `Money + число` и `Money + строка` не падают, а дают `None`. Найди ошибку и исправь. Рамка складывает каждую пару и записывает, что получилось.

## Аргументы

- `rows` — список троек `[копейки, вид, значение]`. Вид `"money"` значит, что справа `Money(значение)`, любой другой вид (`"number"`, `"text"`) значит, что справа лежит само значение (число или строка). Список может быть пустым.

## Возвращает

Список результатов по одному на тройку: число копеек суммы, а если сложение закончилось `TypeError`, то слово `"TypeError"`. Если ошибки не было, а результат не `Money`, будет строка `"без ошибки: <тип>"`.

## Правила

- Исправь только метод `__add__`; рамку внизу файла не трогай.
- Для чужого типа нужно **вернуть** `NotImplemented`, а не бросать ошибку сам.

## Пример

```python
task_mo06_add([[100, "money", 50], [100, "number", 5]])   # -> [150, "TypeError"]
task_mo06_add([])                                         # -> []
```

## Учебные цели

- Узнавать ошибку «молчаливый `None` вместо `NotImplemented`».
- Понимать, что `NotImplemented` в итоге даёт `TypeError`.
