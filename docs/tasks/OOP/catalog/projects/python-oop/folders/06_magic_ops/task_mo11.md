# Задача MO11: Деньги: плюс, минус, умножить

## Условие

### Как это работает

Деньги удобно хранить целым числом копеек. Чтобы с ними можно было писать `a + b`, `a - b` и `a * 3`, в классе нужны методы `__add__`, `__sub__` и `__mul__`. Каждый возвращает **новый** объект:

```python
def __add__(self, other):
    return Money(self.kopecks + other.kopecks)
```

| Выражение | Какой метод | Что внутри |
|---|---|---|
| `a + b` | `a.__add__(b)` | `Money(a.kopecks + b.kopecks)` |
| `a - b` | `a.__sub__(b)` | `Money(a.kopecks - b.kopecks)` |
| `a * 3` | `a.__mul__(3)` | `Money(a.kopecks * 3)` |

### Задание

Напиши класс `Money`: `__init__(kopecks)` запоминает `kopecks` в атрибуте с тем же именем; `__add__(other)` и `__sub__(other)` принимают другой `Money`; `__mul__(k)` принимает число. Все три возвращают новый `Money`. Рамка внизу проверяет и результаты, и то, что `a` и `b` не изменились.

## Аргументы

- `a`, `b` — копейки двух сумм.
- `k` — целое число, на которое умножаем `a`.

## Возвращает

Словарь: `"sum"`, `"diff"` и `"times"` — копейки результатов `a + b`, `a - b` и `a * k`; `"a"` и `"b"` — копейки исходных сумм после всех действий; `"new_objects"` — `True`, если сумма не совпала ни с `a`, ни с `b` как объект.

## Правила

- Пиши только класс `Money`; рамку внизу файла не трогай.
- Нужны методы `__init__`, `__add__`, `__sub__` и `__mul__`.
- Исходные суммы менять нельзя.

## Пример

```python
task_mo11_calc(500, 120, 3)
# -> {"sum": 620, "diff": 380, "times": 1500, "a": 500, "b": 120, "new_objects": True}
```

## Учебные цели

- Написать три арифметических метода, каждый возвращает новый объект.
- Не менять операнды.

## Проверка понимания

Чему равна разность `Money(100) - Money(250)`? Что нарушится, если `__sub__` изменит `self.kopecks`?
