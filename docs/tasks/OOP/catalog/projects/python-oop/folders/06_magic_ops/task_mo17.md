# Задача MO17: Корзина: товар по названию

## Условие

### Как это работает

Сейчас корзина отвечает на `cart[i]` названием товара по номеру:

```python
class Cart:                                       # 1
    def __init__(self, items):                    # 2
        self.items = items                        # 3
    def __len__(self):                            # 4
        return len(self.items)                    # 5
    def __getitem__(self, key):                   # 6
        return self.items[key][0]                 # 7
```

**Где реализовано старое правило:** в строках 6–7. Число `key` означает номер товара, отрицательные номера считаются с конца, а за границей возникает `IndexError`.

**Что меняется:** теперь `cart` можно спросить и по названию: `cart["чай"]` возвращает цену этого товара, а если такого товара нет, бросает `KeyError`. Ключ-число работает как раньше.

**Что нельзя трогать:** `__init__`, `__len__` и поведение для чисел.

### Задание

Раньше `cart[номер]` возвращал название товара. Теперь `cart[строка]` должен возвращать цену товара с таким названием, а для неизвестного названия бросать `KeyError`. Дополни метод `__getitem__`, не ломая работу с номерами.

## Аргументы

- `items` — список пар `[название, цена]` (может быть пустым).
- `keys` — список ключей: числа (номера) и строки (названия).

## Возвращает

Список результатов по одному на ключ: название товара (для числа), цена (для строки) или строка `"IndexError"`, `"KeyError"`, `"TypeError"` с названием возникшей ошибки.

## Правила

- Не переписывай класс с нуля: дополни `__getitem__`.
- Поведение для чисел (включая отрицательные и ошибку за границей) оставь как есть.
- Рамку внизу файла не трогай.

## Пример

```python
task_mo17_cart([["чай", 80], ["хлеб", 45]], [0, -1, "хлеб", "сыр", 5])
# -> ["чай", "хлеб", 45, "KeyError", "IndexError"]
```

## Учебные цели

- Расширить `__getitem__` вторым видом ключа, не сломав первый.
- Выбирать ветку по типу ключа через `isinstance`.

## Проверка понимания

Что вернёт `cart[0]` и `cart["чай"]` для одной и той же корзины и почему это разные величины? Какую цену вернёт `cart['чай']`, если в корзине два товара с таким названием?
