# Задача MO10: Собери маршрут героя

## Условие

### Как это работает

Сложение векторов позволяет собрать маршрут одним циклом: заводим нулевой вектор и прибавляем к нему каждый шаг. Каждый `+` создаёт новый вектор, поэтому присваиваем результат обратно в `total`.

```python
total = Vector2(0, 0)
for x, y in steps:
    total = total + Vector2(x, y)
```

**Паспорт роли «накопитель»** (имя `total`):

| Где заводим | Начальное значение | Как меняем в теле | Когда используем |
|---|---|---|---|
| до цикла | `Vector2(0, 0)` | `total = total + шаг` | после цикла, в `return` |

**Отступы** показывают вложенность: две строки с шагом стоят внутри `for`.

### Задание

В файле задачи в комментарии записаны строки функции `task_mo10_path(steps)`, но они перемешаны и без отступов. Собери из них тело функции: расставь строки в правильном порядке, добавь отступы, а строку `return None` удали. Функция должна сложить все шаги и вернуть итоговую позицию `[x, y]`.

## Аргументы

- `steps` — список шагов `[dx, dy]` (список может быть пустым).

## Возвращает

Итоговая позиция героя `[x, y]`, начиная с `[0, 0]`; для пустого списка `[0, 0]`.

## Правила

- Используй только строки из комментария, новых строк не добавляй.
- Удали строку `return None`.
- Класс `Vector2` выше не меняй.

## Пример

```python
task_mo10_path([[1, 2], [3, 4], [-1, 0]])   # -> [3, 6]
task_mo10_path([])                           # -> [0, 0]
```

## Учебные цели

- Собрать шаблон «накопитель»: объект до цикла, `total = total + шаг` в цикле.
- Использовать `+` для своих объектов.

## Проверка понимания

Что вернёт функция, если поставить `total = Vector2(0, 0)` внутрь цикла? Почему нельзя написать просто `total + step` без присваивания?
