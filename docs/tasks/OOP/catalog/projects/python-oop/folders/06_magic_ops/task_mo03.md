# Задача MO03: Сумма очков через sum

## Условие

### Как это работает

`sum(items)` начинает с `0`, то есть первый шаг это `0 + items[0]`. Для объектов Python в этом месте зовёт `__radd__` правого операнда (слева обычное число). Если метод вернул `NotImplemented`, получится `TypeError`.

```python
class Score:                                  # 1
    def __init__(self, points):               # 2
        self.points = points                  # 3
    def __add__(self, other):                 # 4
        return Score(self.points + other.points)   # 5
    def __radd__(self, other):                # 6
        if other == 0:                        # 7
            return self                       # 8
        return NotImplemented                 # 9
a = Score(5)                                  # 10
s = sum([a])                                  # 11
```

| После строки | Значение | Почему |
|---|---|---|
| 11 | `s is a` равно `True` | `0 + a` позвал `a.__radd__(0)`, а он вернул `self` |
