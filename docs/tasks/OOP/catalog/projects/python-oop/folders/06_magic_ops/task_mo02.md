# Задача MO02: Плейлист: len и индексы

## Условие

### Как это работает

`len(p)` вызывает `p.__len__()`, а `p[i]` вызывает `p.__getitem__(i)`. Отрицательный индекс считает с конца, а индекс за границей даёт `IndexError`, если метод передаёт запрос списку.

```python
class Playlist:                          # 1
    def __init__(self, tracks):          # 2
        self.tracks = tracks             # 3
    def __len__(self):                   # 4
        return len(self.tracks)          # 5
    def __getitem__(self, index):        # 6
        return self.tracks[index]        # 7
p = Playlist(["rock", "jazz"])           # 8
n = len(p)                               # 9
last = p[-1]                             # 10
```

| После строки | Значение | Почему |
|---|---|---|
| 9 | `n` равно `2` | `__len__` вернул длину списка |
| 10 | `last` равно `"jazz"` | индекс `-1` это последний элемент |
