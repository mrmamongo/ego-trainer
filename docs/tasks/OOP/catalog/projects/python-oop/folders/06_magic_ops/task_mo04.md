# Задача MO04: Корзина: in и if

## Условие

### Как это работает

`x in obj` вызывает `__contains__`. Для `bool(obj)` и `if obj:` Python сначала ищет `__bool__`, если его нет, то смотрит `__len__` (ноль значит «ложь»), а если нет и его, объект всегда «правда».

```python
class Cart:                                   # 1
    def __init__(self, items):                # 2
        self.items = items                    # 3
    def __len__(self):                        # 4
        return len(self.items)                # 5
empty = Cart([])                              # 6
full = Cart(["чай"])                          # 7
a = bool(empty)                               # 8
b = bool(full)                                # 9
```

| После строки | Значение | Почему |
|---|---|---|
| 8 | `a` равно `False` | `__bool__` нет, длина `0` |
| 9 | `b` равно `True` | длина `1` |
