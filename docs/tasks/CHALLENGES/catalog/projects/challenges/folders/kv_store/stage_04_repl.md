# Задача KV04: Цикл команд

## Условие

### Что добавить

Пока функции `parse_command` и `execute` лежат отдельно. Пора собрать из них **программу**: пусть она сама читает строки с клавиатуры и печатает ответы.

В файле `main.py` есть заготовка: цикл, который читает строку за строкой с помощью `input()` и сам выходит, когда ввод закончился (урок `kv-repl`). Допиши внутри цикла (там стоит `TODO`):

1. разбери строку функцией `parse_command`;
2. если команда пустая (`""`) — ничего не делай, переходи к следующей строке;
3. если команда `EXIT` — выйди из цикла;
4. иначе выполни команду через `execute` и **напечатай** ответ.

Программа заканчивается, когда пришла команда `EXIT` **или** ввод кончился.

Пример сессии (слева то, что вводишь ты, справа — что печатает программа):

| Ты вводишь | Программа печатает |
|---|---|
| `SET a 1` | `OK` |
| `GET a` | `1` |
| `KEYS` | `a` |
| `EXIT` | (ничего, программа закончилась) |

Попробовать самому можно в терминале: `python main.py`, потом вводи команды по одной.

### Подсказка

Меняй только файл `main.py`. Импорты уже стоят вверху файла. Словарь `store` создаётся один раз до цикла, поэтому хранилище помнит всё между командами. После `EXIT` ничего читать не нужно: команды дальше не выполняются.

## Правила

- Ответ нужно **напечатать** через `print`: теперь это работа `main.py`, а не `execute`.
- Не печатай приглашение вроде `> ` и лишние слова: проверка сравнивает вывод строка в строку.
- Пустые строки ничего не печатают.
- Команды можно писать маленькими буквами: `set a 1` работает так же, как `SET a 1`.

## Пример

```text
SET a 1
GET a
EXIT
```

печатает:

```text
OK
1
```

## Учебные цели

- Прочитать ввод в цикле до команды `EXIT` или до конца ввода.
- Собрать программу из функций, лежащих в разных файлах.
- Отличать работу программы (печатать) от работы функций (возвращать).

## Проверка понимания

Что произойдёт, если после `EXIT` в вводе есть ещё строки? Почему словарь `store` создаётся до цикла, а не внутри него?
