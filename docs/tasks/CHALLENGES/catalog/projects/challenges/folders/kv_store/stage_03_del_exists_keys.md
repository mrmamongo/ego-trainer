# Задача KV03: DEL, EXISTS и KEYS

## Условие

### Что добавить

Научи `execute` ещё трём командам. Все ответы — строки.

| Команда | Что делает | Ответ |
|---|---|---|
| `DEL ключ` | удаляет ключ из словаря | `1`, если ключ был и удалён; `0`, если такого ключа не было |
| `EXISTS ключ` | проверяет, есть ли ключ | `1` — есть, `0` — нет |
| `KEYS` | перечисляет все ключи | ключи **по алфавиту**, через пробел; если хранилище пустое — `(empty)` |

Пример сессии:

| Вызов | Что в `store` потом | Ответ |
|---|---|---|
| `SET b 2` | `{"b": "2"}` | `OK` |
| `SET a 1` | `{"b": "2", "a": "1"}` | `OK` |
| `KEYS` | без изменений | `a b` |
| `EXISTS a` | без изменений | `1` |
| `DEL b` | `{"a": "1"}` | `1` |
| `DEL b` | без изменений | `0` |
| `EXISTS b` | без изменений | `0` |
| `DEL a` | `{}` | `1` |
| `KEYS` | без изменений | `(empty)` |

### Подсказка

Меняй только файл `storage.py`: допиши ветки в `execute`. Удалять ключ из словаря умеет `del store[ключ]`, но только если ключ есть, иначе будет ошибка. Сначала проверь `ключ in store`. Для `KEYS` пригодятся `sorted(store)` (ключи по порядку) и `" ".join(...)` (склеить через пробел).

## Правила

- Ответ нужно **вернуть** через `return`, а не печатать.
- `DEL` должен удалять ключ из `store` на самом деле.
- `KEYS` ничего не меняет в словаре.
- Старые команды `SET` и `GET` должны отвечать как раньше.

## Пример

```python
store = {"b": "2", "a": "1"}
execute(store, "KEYS", [])           # -> "a b"
execute(store, "DEL", ["b"])         # -> "1"
execute(store, "EXISTS", ["b"])      # -> "0"
execute({}, "KEYS", [])              # -> "(empty)"
```

## Учебные цели

- Проверять наличие ключа оператором `in` и удалять его через `del`.
- Собирать строку из списка методом `join`.
- Отдавать числа ответом строкой: `"1"` и `"0"`.

## Проверка понимания

Что случится с `del store["x"]`, если ключа `x` нет, и как этого избежать? Почему ответ `DEL` — строка `"1"`, а не число `1`?
