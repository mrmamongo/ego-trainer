# Задача KV05: Ошибки текстом

## Условие

### Что добавить

Люди ошибаются: пишут несуществующую команду или забывают аргумент. Сейчас `GET` без ключа роняет программу ошибкой `IndexError`. Настоящая программа так не делает: она **отвечает текстом об ошибке и работает дальше**.

Научи `execute` двум видам ошибок. Текст ответа должен совпадать до символа:

| Что случилось | Ответ |
|---|---|
| команды с таким именем нет | `ERR unknown command 'FOO'` |
| команде дали не то число аргументов | `ERR wrong number of arguments for 'SET'` |

В кавычках стоит имя команды заглавными буквами. Сначала проверь, что команда **вообще известна**, потом — что аргументов **нужное количество**. Нужное количество аргументов:

| Команда | Аргументов |
|---|---|
| `SET` | 2 |
| `GET` | 1 |
| `DEL` | 1 |
| `EXISTS` | 1 |
| `KEYS` | 0 |

Пример сессии:

| Ты вводишь | Программа печатает |
|---|---|
| `foo bar` | `ERR unknown command 'FOO'` |
| `SET a` | `ERR wrong number of arguments for 'SET'` |
| `GET a` | `(nil)` |
| `KEYS x` | `ERR wrong number of arguments for 'KEYS'` |

Ошибочная команда **ничего не меняет** в хранилище: после `SET a` ключа `a` нет.

### Подсказка

Меняй файл `storage.py`, а `main.py` почти не трогай: он уже печатает всё, что вернул `execute`. Удобно завести словарь `ARITY = {"SET": 2, "GET": 1, ...}` с числом аргументов каждой команды и проверять в начале `execute`: `name not in ARITY`, а потом `len(args) != ARITY[name]`.

## Правила

- Ошибки **возвращаются текстом**, исключения (`raise`) здесь не нужны: программа не падает.
- Проверки стоят в начале `execute`, до того как ты обращаешься к `args[0]`.
- Правильные команды работают как раньше.

## Пример

```python
execute({}, "FOO", [])             # -> "ERR unknown command 'FOO'"
execute({}, "SET", ["a"])          # -> "ERR wrong number of arguments for 'SET'"
execute({}, "SET", ["a", "1"])     # -> "OK"
```

## Учебные цели

- Проверять входные данные до того, как с ними работать.
- Возвращать ошибку обычным текстом и не ронять программу.
- Хранить «таблицу правил» в словаре вместо цепочки `if`.

## Проверка понимания

Почему сначала проверяют, известна ли команда, а потом число аргументов? Что напечатает программа на вводе `SET a`, `GET a`?
