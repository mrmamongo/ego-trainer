# Задача KV07: Сохранение в JSON

## Условие

### Что добавить

Пока хранилище живёт, пока работает программа: закрыл — всё пропало. Научим его **сохраняться в файл**.

Новая команда:

| Команда | Что делает | Ответ |
|---|---|---|
| `SAVE` | записывает всё хранилище в файл `data/store.json` | `OK` |

И новое поведение при старте: если файл `data/store.json` уже есть, `main.py` **читает** его в `store` до первой команды. Если файла нет — хранилище просто пустое, программа не падает.

Файл — это JSON, как словарь в записи:

```json
{"a": "1", "name": "Аня"}
```

Требования к файлу:

- папки `data` может не быть: создай её, если её нет;
- русские буквы пишем буквами, а не кодами: `json.dump(store, f, ensure_ascii=False)`;
- файл открывай с `encoding="utf-8"` и при записи, и при чтении.

Пример сессии (в `data/store.json` уже лежит `{"x": "5"}`):

| Ты вводишь | Программа печатает | Что в файле |
|---|---|---|
| `GET x` | `5` | `{"x": "5"}` |
| `SET a 1` | `OK` | `{"x": "5"}` |
| `SAVE` | `OK` | `{"x": "5", "a": "1"}` |
| `EXIT` | (конец) | `{"x": "5", "a": "1"}` |

Без `SAVE` файл не меняется: `EXIT` сам ничего не сохраняет.

### Подсказка

Меняй файлы `storage.py` и `main.py`. В `storage.py` напиши две функции: одна читает файл и возвращает словарь (если файла нет, `{}`), другая записывает. В `execute` добавь ветку `SAVE` и не забудь добавить `"SAVE": 0` в `ARITY`. В `main.py` вместо `store = {}` начни с чтения файла. Проверить, есть ли файл, поможет `os.path.exists(путь)`, а папку создаёт `os.makedirs(папка, exist_ok=True)`.

## Правила

- Для хранения используй `json`. Другие форматы вроде `pickle` не нужны.
- Путь к файлу один: `data/store.json`.
- Все прошлые команды работают как раньше.

## Пример

```text
SET имя Аня
SAVE
EXIT
```

печатает `OK`, `OK`, а в `data/store.json` оказывается `{"имя": "Аня"}`.

## Учебные цели

- Читать и писать JSON-файл через `json.load` и `json.dump`.
- Создавать папку и проверять, что файл существует.
- Загружать состояние программы при старте.
