# Задача KV02: SET и GET

## Условие

### Что добавить

Теперь у программы появляется память. Хранилище — обычный словарь `store`: ключи и значения в нём **строки**.

В файле `storage.py` напиши функцию `execute(store, name, args)`. Она выполняет одну команду над словарём и **возвращает ответ строкой**:

| Команда | Что делает | Ответ |
|---|---|---|
| `SET ключ значение` | кладёт значение в словарь (старое заменяется) | `OK` |
| `GET ключ` | читает значение | значение или `(nil)`, если такого ключа нет |

`name` — имя команды заглавными буквами (так её уже отдаёт `parse_command`), `args` — список аргументов.

Маленький пример сессии:

| Вызов | Что в `store` потом | Ответ |
|---|---|---|
| `execute(store, "SET", ["a", "1"])` | `{"a": "1"}` | `OK` |
| `execute(store, "GET", ["a"])` | `{"a": "1"}` | `1` |
| `execute(store, "GET", ["b"])` | `{"a": "1"}` | `(nil)` |

Функция **меняет словарь на месте**, как `handle` в проекте «учёт расходов». Заводить новый словарь внутри не нужно.

### Подсказка

Меняй только файл `storage.py`. Начало лежит в заготовке: там уже стоит `execute` с описанием. Для `GET` пригодится `store.get(ключ, запасное_значение)`. Другие команды пока не нужны; для них функция может ничего не возвращать.

## Правила

- Функция должна **вернуть** ответ через `return`, а не печатать его.
- Значения остаются строками: `SET code 007`, потом `GET code` даёт `007`, а не `7`.
- Не создавай новый словарь вместо `store`: изменения должны быть видны снаружи.

## Пример

```python
store = {}
execute(store, "SET", ["name", "Anna"])   # -> "OK"
execute(store, "GET", ["name"])           # -> "Anna"
execute(store, "GET", ["age"])            # -> "(nil)"
print(store)                              # {'name': 'Anna'}
```

## Учебные цели

- Менять словарь внутри функции и возвращать ответ строкой.
- Читать ключ методом `get` с запасным значением.
- Вызывать функцию из другого файла проекта.

## Проверка понимания

Почему `execute` не возвращает словарь, а меняет `store`? Что будет, если вызвать `GET` для ключа, которого нет?
