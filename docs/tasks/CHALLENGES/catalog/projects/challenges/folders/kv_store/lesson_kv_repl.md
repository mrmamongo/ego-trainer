# Читаем ввод до конца: цикл команд

Наше хранилище работает так: прочитала команду, ответила, прочитала следующую. Это называют **циклом команд** (по-английски REPL: читать, выполнить, напечатать, повторить).

## input() в цикле

`input()` читает одну строку с клавиатуры. Чтобы читать строки, пока они есть, ставим `input()` в бесконечный цикл `while True` и выходим из него сами:

```python
while True:
    line = input()
    if line == "EXIT":
        break
    print("получил:", line)
```

| Ввод | Что делает программа |
|---|---|
| `hello` | печатает `получил: hello` |
| `abc` | печатает `получил: abc` |
| `EXIT` | `break` выходит из цикла |

## Что, если ввод закончился

Ввод бывает не только с клавиатуры. Проверка подаёт программе строки из файла или из другой программы. Когда строки кончились, а `EXIT` так и не пришёл, `input()` падает с ошибкой `EOFError` (конец ввода). Её ловят через `try`/`except`:

```python
while True:
    try:
        line = input()
    except EOFError:
        break
    print("получил:", line)
```

Теперь программа заканчивается сама, когда ввод иссяк. Именно так устроена заготовка в `main.py`.

## break и continue

| Слово | Что делает |
|---|---|
| `break` | выходит из цикла совсем |
| `continue` | пропускает остаток этого шага и идёт к следующей строке |

Пустая команда не нужна ни программе, ни пользователю: `continue` просто переходит к следующей строке.

```python
name, args = parse_command(line)
if name == "":
    continue
if name == "EXIT":
    break
print(execute(store, name, args))
```

## Где живёт состояние

Словарь `store` создают **до** цикла. Тогда он один на всю работу программы, и каждая команда видит то, что сделали прошлые:

```python
store = {}
while True:
    ...
```

Если создать его внутри цикла, на каждой строке он станет новым пустым словарём, и `GET` ничего не найдёт.

## Пример целиком: трассировка

Ввод `SET a 1`, `GET a`, пустая строка, `EXIT`:

| Шаг | Прочитали | `name` | Что делаем | Печатаем |
|---|---|---|---|---|
| 1 | `SET a 1` | `SET` | `execute` кладёт `a` в `store` | `OK` |
| 2 | `GET a` | `GET` | `execute` достаёт `a` | `1` |
| 3 | `` (пусто) | `""` | `continue` | — |
| 4 | `EXIT` | `EXIT` | `break` | — |

## Попробовать руками

В терминале `python main.py`, затем вводи команды по одной. Закончить можно командой `EXIT` или сочетанием клавиш `Ctrl+Z` и Enter (Windows) либо `Ctrl+D` (Linux, macOS): они говорят «ввод закончился».

## Частые ошибки

Печатать приглашение в `input("> ")`: проверка сравнивает вывод до символа, и лишние `> ` её ломают. Пиши просто `input()`.

Забыть `break` после `EXIT`: цикл будет работать дальше.

Забыть про `EOFError`: на конце ввода программа упадёт с ошибкой.

## Проверь себя

```python
while True:
    try:
        line = input()
    except EOFError:
        break
    if line == "":
        continue
    print(line.upper())
```

Ввод: `ab`, пустая строка, `cd`.

1. Что напечатает программа?
2. Чем закончится работа программы?

<details><summary>Ответ</summary>

1. `AB`, потом `CD`: пустая строка пропущена через `continue`.
2. Ввод кончился, `input()` вызвал `EOFError`, `except` сделал `break`, и цикл закончился.

</details>
