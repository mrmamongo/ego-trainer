# Задача KV01: Разбор команды

## Условие

### Что мы строим

Ты напишешь маленькую базу данных «ключ-значение». Это как словарь, только с командами: пользователь вводит строки вроде `SET name Anna`, а программа отвечает. Такие базы есть в настоящих сервисах, например Redis.

Программа состоит из трёх файлов, у каждого своя работа:

| Файл | Что в нём |
|---|---|
| `commands.py` | разбор строки команды на имя и аргументы |
| `storage.py` | хранилище: функция `execute`, которая выполняет команду над словарём |
| `main.py` | главная программа: читает строки, отправляет их в остальные файлы, печатает ответы |

Файлы связаны между собой через `import` (урок `kv-modules`). Классов в этом челлендже не будет: хватит функций, словарей и модулей.

Каждый этап добавляет программе одну новую способность. Проверка этапа запускает тесты этого этапа **и всех прошлых**: сломал старое, дописывая новое, — этап не засчитан.

### Этап 1

Начнём с самого простого. Пользователь вводит строку целиком: `set a 1`. Программе нужно знать отдельно **команду** и отдельно **аргументы**.

Напиши в файле `commands.py` функцию `parse_command(line)`. Она возвращает пару `(имя, аргументы)`:

- имя — первое слово, **заглавными буквами**;
- аргументы — список остальных слов;
- пробелы по краям и лишние пробелы между словами не мешают;
- пустая строка (или одни пробелы) — пара `("", [])`.

### Подсказка

Меняй только файл `commands.py`. Метод `split()` без аргументов режет строку на слова и сам выбрасывает лишние пробелы. Заглавные буквы даёт `upper()`, а всё, кроме первого слова, — срез `words[1:]`.

## Правила

- Функция должна **вернуть** пару через `return`, а не печатать её.
- Верни именно кортеж из двух частей: `(имя, список)`.
- Аргументы остаются такими, как их ввели: `upper()` нужен только для имени команды.
- Классов в решении не должно быть.

## Пример

Вызовы функции:

```python
parse_command("set a 1")        # -> ("SET", ["a", "1"])
parse_command("  GET   a  ")    # -> ("GET", ["a"])
parse_command("keys")           # -> ("KEYS", [])
parse_command("   ")            # -> ("", [])
```

Что получится после разбора:

| Строка | Имя | Аргументы |
|---|---|---|
| `set a 1` | `SET` | `["a", "1"]` |
| `GET a` | `GET` | `["a"]` |
| `keys` | `KEYS` | `[]` |
| (пусто) | (пусто) | `[]` |

## Учебные цели

- Разобрать строку на слова методами `split()` и `upper()`.
- Вернуть из функции пару значений.
- Понять, как файлы программы делят работу между собой.

## Проверка понимания

Что вернёт `parse_command("  Set   x  ")` и почему лишние пробелы не попали в аргументы?
