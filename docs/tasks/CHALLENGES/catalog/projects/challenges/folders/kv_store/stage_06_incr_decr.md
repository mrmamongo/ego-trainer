# Задача KV06: INCR и DECR

## Условие

### Что добавить

Хранилище умеет считать. Две новые команды работают с числами:

| Команда | Что делает | Ответ |
|---|---|---|
| `INCR ключ` | прибавляет 1 к числу под этим ключом | новое число |
| `DECR ключ` | отнимает 1 | новое число |

Правила такие:

- если ключа нет, считаем, что там `0`: `INCR` даст `1`, `DECR` даст `-1`;
- число хранится **текстом**, как и всё остальное в словаре: после `INCR` в `store` лежит `"1"`, а не `1`. Поэтому в ответе и в словаре стоят строки;
- если под ключом лежит **не число** (например `Anna` или `2.5`), ответ `ERR value is not an integer`, а значение не меняется.

Эти команды берут ровно один аргумент. Добавь их в таблицу `ARITY` из прошлого этапа, и проверка числа аргументов заработает сама.

Пример сессии:

| Ты вводишь | Программа печатает |
|---|---|
| `INCR hits` | `1` |
| `INCR hits` | `2` |
| `DECR hits` | `1` |
| `SET name Anna` | `OK` |
| `INCR name` | `ERR value is not an integer` |
| `GET name` | `Anna` |

### Подсказка

Меняй файл `storage.py`. Чтобы не писать одно и то же дважды, сделай вспомогательную функцию, которой передают ключ и шаг (`1` или `-1`). В ней: возьми `store.get(key, "0")`, преврати в число через `int(...)` внутри `try`, при `ValueError` верни ошибку, иначе запиши `str(число + шаг)` обратно в словарь и верни эту же строку.

## Правила

- В словаре число всегда лежит **строкой**.
- Ответ — тоже строка: `"6"`, а не `6`.
- При ошибке словарь остаётся как был.
- Проверка числа аргументов работает и для `INCR`, и для `DECR`.

## Пример

```python
store = {}
execute(store, "INCR", ["n"])      # -> "1"
execute(store, "INCR", ["n"])      # -> "2"
execute(store, "DECR", ["n"])      # -> "1"
print(store)                       # {'n': '1'}
execute({"x": "abc"}, "INCR", ["x"])   # -> "ERR value is not an integer"
```

## Учебные цели

- Превращать строку в число через `int` и обрабатывать ошибку через `try`/`except`.
- Хранить числа текстом и вовремя переводить туда и обратно.
- Вынести повторяющийся кусок кода во вспомогательную функцию.

## Проверка понимания

Почему в словаре лежит `"1"`, а не `1`? Что вернёт `INCR` для значения `2.5` и почему `int("2.5")` здесь не поможет?
