# Аргументы командной строки, коды выхода и stderr

До сих пор твои программы получали данные через `input()`. Утилиты вроде `grep` устроены иначе: всё нужное передают прямо в команде запуска.

## sys.argv

В команде `python main.py -i error logs/app.log` слова после `python` — это аргументы. Python кладёт их в список `sys.argv`:

```python
import sys

print(sys.argv)
```

запущенная как `python main.py -i error logs/app.log`, программа напечатает

```text
['main.py', '-i', 'error', 'logs/app.log']
```

| Элемент | Значение |
|---|---|
| `sys.argv[0]` | имя самого скрипта, оно обычно не нужно |
| `sys.argv[1:]` | сами аргументы, все строками |

Поэтому в заготовке `main(argv)` получает уже `sys.argv[1:]`. Такую функцию легко проверять: ей можно передать любой список.

## Флаги и позиционные аргументы

**Флаг** — аргумент с дефисом: `-i`, `-v`. **Позиционные** аргументы — всё остальное: шаблон и файлы, их смысл определяет порядок. Договорённость такая: флаги идут первыми. Разбирают их циклом, пока аргумент начинается с `-`:

```python
position = 0
ignore_case = False
while position < len(argv) and argv[position].startswith("-"):
    if argv[position] == "-i":
        ignore_case = True
    position += 1
rest = argv[position:]       # шаблон и файлы
```

Флаги со значением (`-A 2`) занимают **два** аргумента: сам флаг и число после него, поэтому `position` увеличивают на `2`. Число из `argv` — это строка. В целое его превращает `int(...)`, а проверить, что в строке только цифры, можно через `value.isdigit()`.

## Коды выхода

Когда программа заканчивается, она отдаёт системе число: **код выхода**. `0` значит «всё хорошо», остальное — «что-то не так». У `grep` три значения:

| Код | Значение |
|---|---|
| `0` | что-то найдено |
| `1` | ничего не найдено (но ошибок нет) |
| `2` | ошибка: нет файла, неверные аргументы |

Скрипты и `if` в терминале читают этот код и решают, что делать дальше. Задать его проще всего так: `main` **возвращает** число, а последняя строка файла передаёт его в `sys.exit`:

```python
if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

`sys.exit(2)` завершает программу сразу с кодом 2. `return 2` из `main` делает то же самое, но проще проверяется.

## stdout и stderr

У программы два выхода: обычный `stdout` (его печатает `print`) и `stderr` для сообщений об ошибках. Терминал показывает оба вместе, а вот при `python main.py ... > out.txt` в файл попадёт только `stdout`, а ошибка останется на экране. Поэтому найденные строки идут в `stdout`, а жалобы в `stderr`:

```python
print(f"grep: {path}: нет такого файла", file=sys.stderr)
```

## Ошибки как исключения

Когда разбор аргументов растёт, удобно сообщать о проблеме исключением. Функция не знает, как печатать и какой код вернуть, она только говорит «неверно»:

```python
def parse_args(argv):
    if len(argv) < 2:
        raise ValueError("использование: python main.py ШАБЛОН ФАЙЛ")
    return argv[0], argv[1]

def main(argv):
    try:
        pattern, path = parse_args(argv)
    except ValueError as error:
        print(error, file=sys.stderr)
        return 2
    ...
```

Так вся работа с выводом и кодами остаётся в одном месте: `main`.

## Пример целиком: путь команды

`python main.py -i error a.log b.log`:

| Шаг | Что происходит | Результат |
|---|---|---|
| 1 | `sys.argv[1:]` | `["-i", "error", "a.log", "b.log"]` |
| 2 | флаги до первого аргумента без `-` | `ignore_case = True`, остаток `["error", "a.log", "b.log"]` |
| 3 | шаблон и файлы | `"error"`, `["a.log", "b.log"]` |
| 4 | каждый файл читается и обрабатывается | вывод в `stdout`, жалобы в `stderr` |
| 5 | `return 0`, `1` или `2` | код выхода программы |

## Попробовать руками

Запусти `python main.py error logs/app.log` в терминале. Код выхода последней команды можно посмотреть так: в PowerShell `$LASTEXITCODE`, в bash и zsh `echo $?`.

## Частые ошибки

Брать `sys.argv[0]` за шаблон: там имя скрипта. Шаблон начинается с `sys.argv[1]`.

Печатать ошибки обычным `print`: они смешаются с найденными строками и испортят вывод. Нужен `file=sys.stderr`.

Забыть `sys.exit(main(...))` в конце: `main` вернёт число, а программа завершится с кодом `0` при любом результате.

Сравнить число с флагом без `int`: `"2" + 1` падает с `TypeError`.

## Проверь себя

```python
import sys

def main(argv):
    if not argv:
        print("пусто", file=sys.stderr)
        return 2
    print(argv[0])
    return 0

sys.exit(main(sys.argv[1:]))
```

1. Что выведет и какой код выхода будет у `python prog.py hello world`?
2. Что произойдёт при запуске `python prog.py` без аргументов и куда пойдёт слово «пусто»?

<details><summary>Ответ</summary>

1. Напечатает `hello` (в `stdout`), код выхода `0`: `argv[0]` здесь первое слово после имени скрипта.
2. Условие `not argv` истинно: в `stderr` уйдёт «пусто», а код выхода будет `2`.

</details>
