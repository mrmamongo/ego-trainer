# Задача GR05: Флаги -n и -c

## Условие

### Что добавить

Ещё два флага: один говорит, **где** нашлось, другой — **сколько**.

| Флаг | Что делает | Пример строки вывода |
|---|---|---|
| `-n` | перед каждой строкой печатает её номер в файле и двоеточие | `2:ERROR disk full` |
| `-c` | не печатает строки, а печатает **только число** найденных строк | `3` |

Правила:

- Номер — настоящий номер строки в файле (с единицы), даже при `-v`: если выбраны строки 2, 4 и 5, печатаются именно они.
- `-c` главнее `-n`: при `-c -n` печатается только число, строки не печатаются.
- `-c` печатает число и когда ничего не найдено: тогда это `0`, а код выхода `1`.
- `-c` работает вместе с `-i` и `-v`: считаются строки, которые выбрал бы обычный поиск.
- Код выхода считается так же, как раньше: нашлась хотя бы одна строка — `0`, иначе `1`; ошибки (нет файла, неизвестный флаг, не хватает аргументов) — `2`.

Флаги можно ставить в любом порядке и в любом наборе, как в этапе 4.

### Подсказка

Меняй `main.py`. Разбор флагов теперь вырос: вынеси его в отдельную функцию `parse_args(argv)`. Пусть она возвращает флаги в словаре, например `{"i": False, "v": False, "n": False, "c": False}`, шаблон и файл. Если аргументы плохие, поднимай в ней `raise ValueError("текст ошибки")`, а в `main` лови `except ValueError as error` и печатай текст в `stderr`. Тогда `main` остаётся коротким. Печать строки с номером: `print(f"{number}:{text}")`.

## Правила

- Формат номера строго `<номер>:<строка>`, без пробелов.
- Строки с `-c` не печатаются вовсе.
- Все прошлые флаги и ошибки работают как раньше.

## Пример

Файл `logs/app.log`:

```text
INFO server started
ERROR disk full
INFO retry in 5s
error: timeout
WARN slow response
ERROR disk full again
```

| Команда | Что печатается |
|---|---|
| `main.py -n ERROR logs/app.log` | `2:ERROR disk full` и `6:ERROR disk full again` |
| `main.py -c ERROR logs/app.log` | `2` |
| `main.py -c -i error logs/app.log` | `3` |
| `main.py -n -v INFO logs/app.log` | `2:ERROR disk full`, `4:error: timeout`, `5:WARN slow response`, `6:ERROR disk full again` |
| `main.py -c CRITICAL logs/app.log` | `0` (и код выхода `1`) |

## Учебные цели

- Вынести разбор аргументов в отдельную функцию.
- Сообщать об ошибке через `raise ValueError` и перехватывать её в `main`.
- Менять формат вывода по флагам.

## Проверка понимания

Что напечатает `main.py -n -c ERROR logs/app.log` и почему? Почему `parse_args` лучше поднять исключение, чем сразу вызвать `sys.exit(2)`?
