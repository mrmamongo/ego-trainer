# Задача GR08: Свои шаблоны: . ^ $

## Условие

### Что добавить

Последний этап. Сейчас шаблон — это просто кусок текста. У настоящего `grep` шаблон умеет больше: он описывает *форму* строки. Научим этому свою программу, причём **без модуля `re`**: проверку напишешь сам, по символам.

Три особых символа:

| Символ | Где | Что значит |
|---|---|---|
| `.` | где угодно | любой **один** символ (ровно один, не ноль и не два) |
| `^` | только самый первый символ шаблона | шаблон должен подходить к **началу** строки |
| `$` | только самый последний символ шаблона | шаблон должен подходить к **концу** строки |

Всё остальное — обычные символы, которые должны совпасть сами с собой. Если `^` стоит не первым, а `$` не последним, они тоже обычные символы: шаблон `a^b` ищет именно текст `a^b`. Экранирования нет, найти настоящую точку нельзя (точка подходит и к ней, и к любому другому символу). Для этого челленджа так задумано.

Шаблон без особых символов — это просто подстрока. Поэтому всё, что ты написал на этапах 1–7, должно работать как раньше.

Примеры для `matcher.matches(line, pattern)`:

| `line` | `pattern` | Ответ | Почему |
|---|---|---|---|
| `abc` | `a.c` | `True` | точка заменила `b` |
| `ac` | `a.c` | `False` | между `a` и `c` ничего нет, а точка требует символ |
| `abc` | `^b` | `False` | `b` не в начале |
| `abc` | `c$` | `True` | `c` в самом конце |
| `abab` | `b$` | `True` | второе `b` стоит в конце, хотя первое — нет |
| `abc` | `^abc$` | `True` | шаблон равен всей строке |
| `` (пусто) | `^$` | `True` | так ищут пустые строки |
| `x` | `^$` | `False` | строка не пустая |
| `a$b` | `a$b` | `True` | `$` не в конце: обычный символ |

И в программе:

```text
python main.py "^ERROR" logs/app.log     # строки, которые начинаются с ERROR
python main.py "done$" logs/app.log      # строки, которые заканчиваются на done
python main.py -c "^$" logs/app.log      # сколько пустых строк
python main.py "d..k" logs/app.log       # disk, desk, dusk...
```

(кавычки вокруг шаблона нужны терминалу, а не твоей программе: в аргумент они не попадают)

### Подсказка

Меняй `matcher.py`, остальные файлы трогать почти не нужно. Разбей работу на два шага. Сначала отдели `^` и `$`: `pattern.startswith("^")` и `pattern.endswith("$")`, срезы `pattern[1:]` и `pattern[:-1]`. Потом напиши вспомогательную функцию «подходит ли шаблон к самому **началу** текста»: пройди по позициям шаблона и сравни `pattern[i]` с `text[i]`, при этом `.` подходит к любому символу. Не забудь длину: текст короче шаблона не подходит. Если нужен конец (`$`), текст после шаблона должен быть пуст. Без `^` попробуй эту проверку с каждой начальной позиции строки: `line[start:]`. Подробности в уроке `gr-patterns`.

## Правила

- **Нельзя импортировать `re`** (и `fnmatch`): проверка не пропустит решение с ними.
- `matches(line, pattern)` сохраняет свои два параметра, `find_matches` и `main.py` менять не обязательно.
- Флаг `-i` работает и с особыми символами: регистр букв игнорируется, а `.`, `^` и `$` ведут себя как обычно.
- `^$` подходит к пустой строке, одиночные `^` и `$` — к любой строке.
- Всё прошлое (флаги, файлы, контекст, коды выхода) работает как раньше.

## Пример

Файл `logs/app.log`:

```text
INFO server started
ERROR disk full
INFO retry in 5s
error: timeout
WARN slow response
ERROR disk full again
INFO done

note: ERROR is not at start
```

| Команда | Что печатается |
|---|---|
| `main.py "^ERROR" logs/app.log` | `ERROR disk full`, `ERROR disk full again` |
| `main.py ERROR logs/app.log` | те же и ещё `note: ERROR is not at start` |
| `main.py "done$" logs/app.log` | `INFO done` |
| `main.py -n "^$" logs/app.log` | `8:` |
| `main.py -n -i "^error" logs/app.log` | `2:ERROR disk full`, `4:error: timeout`, `6:ERROR disk full again` |

## Учебные цели

- Разобрать шаблон по символам вручную, без готовых библиотек.
- Разбить задачу на вспомогательную функцию и главную функцию.
- Аккуратно обработать границы: пустая строка, пустой шаблон, конец строки.

## Проверка понимания
