# Задача GR03: Программа: шаблон и файл

## Условие

### Что добавить

Функции готовы, пора собрать из них **программу**. Она запускается из терминала и получает всё нужное в **аргументах командной строки**:

```text
python main.py ERROR logs/app.log
```

Первый аргумент — шаблон, второй — путь к файлу. Программа читает файл, ищет в нём строки с шаблоном и печатает их. В `main.py` есть заготовка: функция `main(argv)` получает список аргументов (`argv` — без имени самого скрипта) и **возвращает код выхода**. Нижние две строки файла уже передают `sys.argv[1:]` в `main` и отдают ответ в `sys.exit`. Подробнее в уроках `gr-argv` и `gr-files`.

Что должна делать программа:

| Ситуация | Что в `stdout` | Что в `stderr` | Код выхода |
|---|---|---|---|
| есть подходящие строки | эти строки, по одной в строке, **без** номеров и приставок | — | `0` |
| подходящих строк нет | ничего | — | `1` |
| файла с таким именем нет | ничего | `grep: <файл>: нет такого файла` | `2` |
| аргументов меньше двух | ничего | строка, начинающаяся со слова `использование:` | `2` |

Три разных кода нужны, чтобы другие программы могли понять результат, не читая текст: `0` — нашлось, `1` — не нашлось, `2` — что-то пошло не так. Сообщения об ошибках печатаются в `stderr`, а найденные строки — в `stdout`: тогда их можно сохранить в файл, не перемешав с ошибками.

Пример: файл `logs/app.log`

```text
INFO server started
ERROR disk full
INFO retry in 5s
error: timeout
ERROR disk full again
```

`python main.py ERROR logs/app.log` печатает

```text
ERROR disk full
ERROR disk full again
```

и завершается с кодом `0`.

### Подсказка

Меняй только файл `main.py`. Файл читают так: `with open(path, encoding="utf-8") as handle:`, а строки собирают спискомным циклом с `rstrip("\n")`. Если файла нет, `open` бросает `FileNotFoundError`: поймай её через `try`/`except` и верни `2`. Сообщение в `stderr` печатает `print(..., file=sys.stderr)`. Найденные строки приходят из `find_matches` парами `(номер, строка)`: печатай только вторую часть.

## Правила

- Пиши ровно `grep: <файл>: нет такого файла`, где `<файл>` — путь так, как его ввели.
- Сообщения об ошибках — только в `stderr`, не в `stdout`.
- Печатай найденные строки как есть, без номеров, приставок и лишних пробелов.
- Шаблон с пробелами приходит одним аргументом: `"disk full"`.
- Файл читай с `encoding="utf-8"`.

## Пример

```text
python main.py disk logs/app.log      # две строки, код 0
python main.py CRITICAL logs/app.log  # ничего не печатает, код 1
python main.py disk nope.log          # stderr: grep: nope.log: нет такого файла, код 2
python main.py disk                   # stderr: использование: ..., код 2
```

## Учебные цели

- Прочитать аргументы командной строки из `sys.argv`.
- Читать файл построчно и ловить `FileNotFoundError`.
- Различать `stdout` и `stderr` и возвращать осмысленные коды выхода.

## Проверка понимания

Почему сообщение «нет такого файла» печатается в `stderr`, а не обычным `print`? Что покажет терминал, если запустить программу без аргументов и почему она не падает с `IndexError`?
