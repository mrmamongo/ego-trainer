# Задача GR06: Несколько файлов

## Условие

### Что добавить

Настоящий `grep` ищет сразу в нескольких файлах: `python main.py ERROR a.log b.log c.log`. Научим этому свою программу. После шаблона теперь может идти **один или больше** файлов, и они обрабатываются **в том порядке, в каком названы**.

Когда файлов несколько, нужно показать, откуда пришла строка. Поэтому перед каждой выведенной строкой ставится **имя файла и двоеточие**:

```text
python main.py apple a.txt b.txt
a.txt:apple pie
a.txt:apple tart
b.txt:apple juice
```

Правила:

| Что | Как |
|---|---|
| один файл | вывод как раньше, без имени файла |
| несколько файлов | перед каждой строкой `<файл>:`; имя печатается так, как оно было в аргументах (`logs/x.log:...`) |
| `-n` | приставки идут в таком порядке: `<файл>:<номер>:<строка>` |
| `-c` | на каждый файл одна строка `<файл>:<число>`, в том числе `b.txt:0` |
| файла нет | в `stderr` строка `grep: <файл>: нет такого файла`; программа **не останавливается**, продолжает с остальными файлами |
| код выхода | `2`, если хотя бы одного файла не нашлось (даже если в других что-то есть); иначе `0`, если нашлась хотя бы одна строка во всех файлах вместе, иначе `1` |

Для файла, которого нет, строка `-c` не печатается: нечего считать.

Пример со всем сразу. Файлы:

```text
a.txt:           b.txt:
apple pie        cherry
banana           apple juice
apple tart
```

| Команда | Вывод | Код |
|---|---|---|
| `main.py apple a.txt b.txt` | `a.txt:apple pie`, `a.txt:apple tart`, `b.txt:apple juice` | `0` |
| `main.py -n apple a.txt b.txt` | `a.txt:1:apple pie`, `a.txt:3:apple tart`, `b.txt:2:apple juice` | `0` |
| `main.py -c apple a.txt b.txt` | `a.txt:2`, `b.txt:1` | `0` |
| `main.py apple a.txt nope.txt b.txt` | вывод как в первой строке + в stderr: `grep: nope.txt: нет такого файла` | `2` |
| `main.py zzz a.txt b.txt` | пусто | `1` |

### Подсказка

Меняй `main.py`. `parse_args` теперь возвращает не один файл, а **список** файлов: `rest[1:]`. Всё, что раньше делалось с файлом, оберни в цикл `for path in files:`. Для кода выхода заведи две переменные до цикла: «была ли ошибка» и «нашлось ли хоть что-то». Если файл не открылся, поставь отметку об ошибке и сделай `continue`: цикл пойдёт к следующему файлу. Приставку к строке удобно собирать маленькой функцией `format_line(path, number, text, options, show_file)`.

## Правила

- Имя файла печатается только если файлов больше одного.
- Порядок файлов в выводе — порядок аргументов.
- Потерянный файл не останавливает программу и всегда даёт код `2`.
- Все прошлые флаги работают с любым числом файлов.

## Пример

Файлы из таблицы выше. Если запустить `main.py -c apple a.txt nope.txt b.txt`, программа напечатает в `stdout`

```text
a.txt:2
b.txt:1
```

в `stderr` — `grep: nope.txt: нет такого файла`, и завершится с кодом `2`.

## Учебные цели

- Обрабатывать список файлов в цикле и не прерываться на ошибке одного файла.
- Накапливать итоговый код выхода по нескольким признакам.
- Собирать строку вывода из частей по условиям.

## Проверка понимания

Почему код выхода `2` важнее нахождения строк в других файлах? Что изменится в выводе, если один и тот же файл назвать в аргументах дважды?
