# Задача GR02: Поиск по списку строк

## Условие

### Что добавить

Одна строка проверяется. Теперь проверим **много**: файл — это список строк, и нужно найти все подходящие вместе с их номерами. Номер нужен потому, что в настоящих логах и коде «строка 2417» значит куда больше, чем «какая-то строка».

В файле `search.py` лежит заготовка `find_matches(lines, pattern)`. Допиши её:

- пройди по списку `lines` по порядку;
- для каждой строки спроси у `matches` (из `matcher.py`, уже импортирована), подходит ли она;
- верни **список пар** `(номер, строка)` только для подходящих строк.

Правила номеров и строк:

- номера считаются **с единицы**, как в редакторе кода;
- строки в результате — **без `"\n"` на конце**. Из файла строки приходят вместе с переводом строки (`"cat\n"`), а ответ должен содержать `"cat"`;
- порядок как в исходном списке;
- ничего не нашлось — верни пустой список `[]`;
- сам список `lines` менять нельзя.

### Подсказка

Меняй только файл `search.py`. Цикл `for number, line in enumerate(lines, start=1)` сам отдаёт и номер (с единицы), и строку. Лишний `"\n"` убирает `line.rstrip("\n")`. Пары собирай в список через `append((number, text))`: двойные скобки, потому что добавляется один кортеж.

## Правила

- Функция **возвращает** список, ничего не печатает.
- Каждый элемент — кортеж из двух частей: `(int, str)`.
- Решение этапа 1 (`matches`) должно остаться рабочим: ты пользуешься им.

## Пример

```python
find_matches(["INFO start", "ERROR disk", "INFO ok", "ERROR net"], "ERROR")
# -> [(2, "ERROR disk"), (4, "ERROR net")]

find_matches(["cat\n", "dog\n", "cow\n"], "o")
# -> [(2, "dog"), (3, "cow")]

find_matches(["a", "b"], "zzz")
# -> []
```

| Строка | Номер | Подходит под `ERROR` | В результате |
|---|---|---|---|
| `INFO start` | 1 | нет | — |
| `ERROR disk` | 2 | да | `(2, "ERROR disk")` |
| `INFO ok` | 3 | нет | — |
| `ERROR net` | 4 | да | `(4, "ERROR net")` |

## Учебные цели

- Обойти список циклом с номерами через `enumerate`.
- Собрать результат в новый список.
- Вызывать функцию из соседнего файла и не дублировать её работу.

## Проверка понимания

Почему номер в результате — это `3`, а не `2`, для третьей строки списка? Что будет, если не убрать `"\n"` и потом напечатать найденную строку через `print`?
