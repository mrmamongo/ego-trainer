# Задача GR04: Флаги -i и -v

## Условие

### Что добавить

Настоящий `grep` умеет больше, чем просто искать. Его поведение меняют **флаги**: короткие аргументы с дефисом, которые стоят **перед** шаблоном. Добавим два.

| Флаг | Что делает |
|---|---|
| `-i` | не различает большие и маленькие буквы: `error` найдёт и `ERROR`, и `Error` |
| `-v` | переворачивает поиск: печатает строки, в которых шаблона **нет** |

Флаги можно ставить вместе и в любом порядке, каждый отдельным аргументом:

```text
python main.py -i -v error logs/app.log
```

Эта команда печатает строки, где нет слова `error` ни в каком регистре.

Подробности:

- Флаги идут до шаблона. Всё, что начинается с `-`, пока не встретился первый аргумент без дефиса, — флаги. Первый аргумент без дефиса — шаблон, дальше файл.
- При `-i` строки печатаются **как в файле** (не маленькими буквами): регистр игнорируется только при сравнении.
- Код выхода считается по **напечатанным** строкам: напечатана хотя бы одна — `0`, иначе `1`. При `-v` это значит «нашлась строка, в которой шаблона нет».
- Неизвестный флаг (например, `-x`) — ошибка: в `stderr` строка, начинающаяся с `grep:`, например `grep: неизвестный флаг -x`, код `2`.
- Если после флагов не хватает шаблона или файла — снова строка `использование:` в `stderr` и код `2`.
- Остальное работает как в этапе 3, в том числе сообщение о пропавшем файле.

### Подсказка

Меняй `search.py` и `main.py`. В `search.py` добавь функции два необязательных параметра: `find_matches(lines, pattern, ignore_case=False, invert=False)`. Для `-i` приведи к нижнему регистру и шаблон, и строку на время сравнения (`lower()`), но в результат положи исходную строку. Для `-v` сравни результат `matches(...)` с флагом: `matches(...) != invert`. Прежние вызовы с двумя аргументами должны работать как раньше. В `main.py` флаги разбирай циклом `while`, пока `argv[position].startswith("-")`.

## Правила

- `matches` не меняется: он знает только про подстроку. Регистр и переворот решает `find_matches`.
- Сравнение без учёта регистра не должно портить напечатанные строки.
- Флаги встречаются только до шаблона.
- Каждый флаг — отдельный аргумент: `-i -v`, а не `-iv`.

## Пример

Файл `logs/app.log`:

```text
INFO server started
ERROR disk full
INFO retry in 5s
error: timeout
```

| Команда | Что печатается | Код |
|---|---|---|
| `main.py ERROR logs/app.log` | `ERROR disk full` | `0` |
| `main.py -i error logs/app.log` | `ERROR disk full`, `error: timeout` | `0` |
| `main.py -v INFO logs/app.log` | `ERROR disk full`, `error: timeout` | `0` |
| `main.py -i -v error logs/app.log` | `INFO server started`, `INFO retry in 5s` | `0` |
| `main.py -x ERROR logs/app.log` | (stderr: `grep: неизвестный флаг -x`) | `2` |

## Учебные цели

- Разобрать флаги из `sys.argv` перед позиционными аргументами.
- Расширить функцию необязательными параметрами, не ломая старые вызовы.
- Сравнивать строки без учёта регистра и переворачивать условие.
