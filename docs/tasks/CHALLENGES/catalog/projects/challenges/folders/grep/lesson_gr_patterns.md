# Свои шаблоны: сравнение по символам

Для подстроки хватало оператора `in`. Когда в шаблоне появляются особые символы, готовых средств уже мало: придётся сравнивать строку и шаблон **символ за символом**.

## Индексы и срезы

К символу строки обращаются по номеру с нуля, а часть строки берут срезом:

```python
text = "hello"
text[0]       # 'h'
text[1:]      # 'ello'   всё, кроме первого
text[:-1]     # 'hell'   всё, кроме последнего
text[2:]      # 'llo'    начиная с третьего
```

Для проверки краёв удобны `startswith` и `endswith`:

```python
"^abc".startswith("^")     # True
"abc$".endswith("$")       # True
```

## Сначала один вопрос: подходит ли шаблон к началу текста

Сложную задачу удобно разбить на простую. Простая такая: **подходит ли шаблон к самому началу текста** (не ищем по всей строке). Для шаблона без особых символов это сравнение по позициям:

```python
def matches_here(text, pattern):
    if len(text) < len(pattern):
        return False
    for index in range(len(pattern)):
        if pattern[index] != text[index]:
            return False
    return True
```

Сначала проверяем длину, иначе `text[index]` может выйти за пределы строки. Дальше каждая позиция должна совпасть. Одно несовпадение — сразу `False`. Прошли весь шаблон без несовпадений — `True`.

Теперь «любой один символ» — это просто ещё одно условие в сравнении. Точка подходит всегда:

```python
if pattern[index] != "." and pattern[index] != text[index]:
    return False
```

| `text` | `pattern` | Ответ | Почему |
|---|---|---|---|
| `abc` | `a.c` | `True` | `.` взяла `b` |
| `ac` | `a.c` | `False` | текст короче шаблона |
| `abd` | `a.c` | `False` | `d` не равно `c` |

## Поиск по всей строке

Чтобы найти шаблон в любом месте, пробуй `matches_here` с каждой начальной позиции. Срез `line[start:]` отбрасывает начало:

```python
for start in range(len(line) + 1):
    if matches_here(line[start:], pattern):
        return True
return False
```

`+ 1` нужно, чтобы попробовать и пустой остаток в самом конце: так находится шаблон `$` и пустой шаблон. Если шаблон начинается с `^`, пробовать нужно только одну позицию: самое начало.

## Края: ^ и $

Эти символы не сравниваются с текстом, они меняют условия поиска. Их отделяют до основной работы:

```python
at_start = pattern.startswith("^")
if at_start:
    pattern = pattern[1:]
at_end = pattern.endswith("$")
if at_end:
    pattern = pattern[:-1]
```

После этого `at_start` решает, пробовать ли только начало, а `at_end` добавляет условие в `matches_here`: после шаблона в тексте ничего не должно остаться, то есть `len(text) == len(pattern)`.

Порядок важен: сначала `^`, потом `$`. Иначе шаблон `^$` испортится: после отрезания `$` останется `^`, а ты уже решал про начало.

## Пример целиком: abab и b$

Шаблон `b$` и строка `abab`: `at_start = False`, после отрезания `$` шаблон `b`, `at_end = True`.

| `start` | Остаток `line[start:]` | Подходит ли `b` и конец |
|---|---|---|
| 0 | `abab` | нет: первая буква `a` |
| 1 | `bab` | `b` сошлась, но дальше остались символы: нет |
| 2 | `ab` | нет |
| 3 | `b` | да: `b` сошлась и текст закончился |

Итог `True`: второе `b` стоит в конце.

## Частые ошибки

Не проверить длину перед сравнением: `IndexError` на коротких строках.

Забыть `range(len(line) + 1)`: тогда шаблоны `$` и `^$` не находят пустой остаток.

Считать `$` и `^` особыми везде: в этом челлендже они особые только на краях шаблона.

Сравнивать `.` с текстом буквально: точка подходит к любому символу, но *к одному*, а не к пустому месту.

## Проверь себя

Функция из урока вызвана как `matches_here("cat", "c.t")`, потом как `matches_here("ct", "c.t")`.

1. Что вернёт каждый вызов?
2. Какая строка проверки отвечает за второй результат?

<details><summary>Ответ</summary>

1. Первый вызов вернёт `True` (точка взяла `a`), второй `False`.
2. `if len(text) < len(pattern): return False`. В тексте `ct` только два символа, а шаблон просит три, и до сравнения по позициям дело даже не доходит.

</details>
