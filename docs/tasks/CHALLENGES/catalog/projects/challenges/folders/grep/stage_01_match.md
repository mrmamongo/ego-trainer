# Задача GR01: Совпадение строки

## Условие

### Что мы строим

Ты напишешь свою версию `grep`: утилиты командной строки, которая ищет в файлах строки с нужным словом. Настоящий `grep` есть на каждом сервере: им ищут ошибки в логах, имена функций в коде, нужную строку в длинном конфиге.

К концу челленджа твоя программа будет запускаться так:

```text
python main.py -i -n error logs/app.log
```

и печатать строки файла, в которых есть слово `error`, с номерами и без различия больших и маленьких букв. По пути ты научишься читать аргументы командной строки, возвращать коды выхода и писать ошибки в `stderr`.

Программа состоит из трёх файлов, у каждого своя работа:

| Файл | Что в нём |
|---|---|
| `matcher.py` | проверка: подходит ли **одна строка** под шаблон |
| `search.py` | поиск по **списку строк**: что нашлось и под каким номером |
| `main.py` | главная программа: читает аргументы и файлы, печатает результат, возвращает код выхода |

Файлы связаны через `import` (об этом коротко в уроке `gr-files`). Классов в этом челлендже не будет: хватит функций, циклов, строк и списков.

Каждый этап добавляет программе одну новую способность. Проверка этапа запускает тесты этого этапа **и всех прошлых**: сломал старое, дописывая новое, — этап не засчитан.

### Этап 1

Начнём с самого маленького кирпичика. Напиши в файле `matcher.py` функцию `matches(line, pattern)`. Она отвечает на вопрос: **есть ли шаблон `pattern` внутри строки `line`**.

- Верни `True`, если шаблон встречается в строке в любом месте (в начале, в середине, в конце, или шаблон равен всей строке).
- Верни `False`, если не встречается.
- Большие и маленькие буквы различаются: `"Hello"` и `"hello"` — разные строки.
- Пустой шаблон `""` есть в любой строке.

### Подсказка

Меняй только файл `matcher.py`. Не нужно ни циклов, ни `find`: в Python есть оператор `in`, который сам проверяет, лежит ли одна строка внутри другой.

## Правила

- Функция должна **вернуть** `True` или `False` через `return`, а не печатать.
- Классов в решении не должно быть.
- Меняй только `matcher.py`: остальные файлы пока заготовки.

## Пример

```python
matches("hello world", "wor")     # -> True
matches("hello world", "xyz")     # -> False
matches("Hello", "hello")         # -> False
matches("abc", "")                # -> True
```

| `line` | `pattern` | Ответ | Почему |
|---|---|---|---|
| `hello world` | `wor` | `True` | `wor` лежит в середине |
| `hello world` | `world` | `True` | в конце |
| `hello` | `hello` | `True` | равен всей строке |
| `Hello` | `hello` | `False` | `H` и `h` — разные буквы |
| `abc` | `abcd` | `False` | шаблон длиннее строки |

## Учебные цели

- Проверять вхождение одной строки в другую оператором `in`.
- Вернуть из функции логическое значение.
- Понять, как файлы программы делят работу между собой.

## Проверка понимания

Что вернёт `matches("", "a")` и что вернёт `matches("", "")`? Почему?
