# Профиль обучающегося (Джун)

## Кто

- **Профессия:** Тестировщик (QA). Тестирует Python API вручную.
- **Уровень Python:** Циклы, словари, функции. Без ООП, без библиотек.
- **Что знает точно:** `for`, `if`, `dict`, `list`, `def`, `return`, `.get()`, `zip`, `sorted`, `len`.
- **Что начинает осваивать:** Рекурсия, `while`, `try/except`, `isinstance`.
- **Что пока за гранью:** ООП, файловый I/O, сетевые запросы, numpy, join нескольких источников, flatten дерева.

## Как учится

- Учится с ментором (CTO, друг).
- Нуждается в практике: как можно больше задач, близких к реальным доменам.
- Формат: обвязка `student.py` + `checker.py` — пишет функцию, запускает, видит результат.
- Доходит сам, но иногда застревает на 10-30 минут — нужна подсказка.

## Границы комфорта

- Плоские словари — уверенно.
- Вложенные словари (dict в dict) — средне, нужна практика.
- Рекурсия — только начинает.
- Сложная агрегация — пока за гранью.
- `while` — готов, но еще не проходил.

## Почему учит Python

- Хочет автоматизировать тестирование.
- В перспективе — работа с API, написание тестов, понимание кода.
- Возможно — участие в разработке LLM-платформы ментора.
