# Карта курса «Python с нуля»

Состояние на 2026-10-29: 16 папок, 283 задачи, 82 карточки теории, проект `python-start`
(`docs/tasks/START/catalog/projects/python-start`). Дальше по курсу идут продуктовые задачи XL-A
(27 задач в одной папке, проект `xl-a`).

Источник цифр — сами файлы каталога; пересчитать можно скриптом из истории этой карты
или `scripts/verify_start_catalog.py`.

## Как устроен курс

- **Одна новая идея на папку.** Каждая папка начинается с карточек теории; у каждой задачи есть
  ссылки `theory:` на нужные карточки, и расширение после неудачной проверки предлагает их повторить.
- **Лесенка внутри папки:** трассировка → найди баг / допиши → собери из строк → напиши сам →
  (с папки 09) правки готового кода.
- **Роли переменных и словарей с «паспортами».** Главный методический приём: накопитель, счётчик,
  сборщик, флаг, лучший на данный момент; у словарей — запись, счётчик, группировщик, индекс.
- **Проверка:** сценарные и обычные тесты, скрытые ответы в трассировке, статические правила (`@rules`)
  там, где условие что-то запрещает, проверка «входные данные не изменены» в задачах на списки и словари.

## Чего в курсе нет (по убыванию важности для XL-A и работы джуна)

1. **Ошибки и исключения:** `try/except`, `raise`, свои исключения, порядок проверок и коды отказов.
   XL-A постоянно требует «вернуть отказ с кодом X, проверки в таком порядке».
2. **Тесты и воспроизведение бага:** `assert`, минимальный пример, который ломает код, основы pytest.
   В задачах «Найти баг» XL-A это прямое требование.
3. **Рекурсия и вложенные пути:** обход вложенных словарей по пути `["a", "b", "c"]`, глубокое копирование
   (XL-A22–XL-A24, память ассистента).
4. **Классы и dataclass:** объект с состоянием и методами. Встречаются в заготовках XL-O (MemoryStore,
   AuctionHouse), полезны для второго проекта.
5. **Файлы и JSON:** сохранить и загрузить состояние программы (`json.load/dump`), чтение текстовых файлов.
6. **Встроенные инструменты итерации:** `enumerate`, `zip`, `any/all`, `min/max/sorted` с `key` по кортежу —
   в курсе их часто запрещали ради ручной реализации, но нигде не учили применять.
7. **Модули и структура проекта:** `import`, свои модули, `if __name__ == "__main__"` (появилось только в проекте).
8. **Чтение договора задачи:** типы входа и выхода, предусловия, «что считается корректным входом» — стоит
   сделать отдельной короткой папкой-тренажёром на текстах в стиле XL-A.

# Курс «Python: ООП»

Отдельный проект `python-oop` (`docs/tasks/OOP/catalog/projects/python-oop`). Мягкая рекомендация в
`project.yaml`: после XL-A (21/27, не меньше 6 по каждому типу); открыть можно в любой момент.
