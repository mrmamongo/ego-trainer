# Задачи и дорожная карта

## Пройденные блоки (30 задач)

| Блок | Тема | Задач | Уровень | Что тренирует |
|------|------|-------|---------|---------------|
| **F** | Базовые паттерны | 5 | Простый | find, filter, count, all, any |
| **G** | NLP пайплайн | 7 | Простый | токены, vocab, truncation, accuracy, padding, top-k |
| **1** | Логи | 5 | Средний | ошибки по сервисам, медленные запросы, SLA-отчет |
| **D** | Разные домены | 5 | Средний | e-com, IoT, CI/CD, Game, API Gateway |
| **H** | Игры | 8 | Средний | инвентарь, лут, power score, рюкзак, XP, round-robin, combo, синтез |

## Будущие блоки

| Блок | Тема | Задач | Уровень | Статус |
|------|------|-------|---------|--------|
| **A** | Join/merge | 1 | Сложный | Слияние 3 источников в одну структуру |
| **B** | Рекурсия | 1 | Сложный | Рекурсивная санитизация email'ов |
| **C** | Flatten | 1 | Сложный | Денормализация дерева в плоскую таблицу |
| **I** | LLM компоненты | 3-5 | Средний+ | Context window, retry backoff, tool parser |

## Формат каждого блока

```
block_X_name/
  student.py    # заготовки функций с pass
  checker.py    # автопроверка: ✅ / ❌
```

## Как проходить (рекомендация ментора)

1. **F + G** — базовые паттерны, наработка скорости (10-15 минут на задачу)
2. **1 + D** — агрегация, словари как счетчики (15-20 минут на задачу)
3. **H** — вложенные структуры, разные домены (20-30 минут на задачу)
4. **A + B + C** — сложные трансформации данных
5. **I** — LLM компоненты, ближе к реальной работе

## Чек-лист перехода к следующему уровню

- [ ] Блок F — все 5 задач за 10 минут каждая
- [ ] Блок G — все 7 задач за 15 минут каждая
- [ ] Блок 1 — задача 1.2 (ошибки по сервисам) за 10 минут
- [ ] Блок H — задачи H3 (power score) и H5 (XP) без подсказок

Когда все галочки — можно брать блоки A, B, C.
