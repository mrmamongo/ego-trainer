# Работа с задачами через Cogito MCP

1. Вызови `whoami`, затем `get_catalog` и `get_task`. Убедись, что задача writable.
2. Правь три связанных файла: Markdown-условие, `.solution.py` с эталоном и
   `.tests.py` с `ego.testing.case`. Сохраняй ID, функцию и учебный уровень.
3. Описывай аргументы, результат, правила, границы и примеры согласованно с
   эталоном и тестами. Отдельный эталон скрыт от учеников. Прогресс читай через
   `get_student_progress`; наличие шаблона не доказывает выполнение задачи.
4. Для `declare` повышай версию: patch для опечатки, minor для совместимой
   правки, major для изменения сигнатуры или ожидаемого поведения. Меняются
   только тесты — версию тоже повышай. В `args` одного аргумента нужна запятая.
5. Отправь полный кандидат в `validate_task`, сохранив исходные version и etag.
   Это проверка структуры и синтаксиса, а не запуск smoke/full тестов.
6. Покажи преподавателю смысл правки и изменения версии. `save_task` сразу
   публикует файлы и синхронизирует базу; вызывай его в рамках запроса сохранить
   или опубликовать. На 409 прочитай текущую задачу и согласуй конфликт.

Чтение доступно mentor/admin. Проверка и сохранение — admin, как в Task Studio.
MCP редактирует существующие задачи. Создание, удаление, перемещение и Git
commit/push здесь не реализованы. OAuth удостоверяет Forgejo subject; права
берутся из текущей роли связанной учётки Ego Trainer.
